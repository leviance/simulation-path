# Giữ nguyên pipeline CPU cho mesh thật

## Vấn đề cần giải quyết

Nếu bỏ rasterizer cũ khi chuyển sang OpenGL, ta chỉ có bản GPU mới và không còn gì để đối chiếu. Bài này nối lại đường CPU cho mesh thật: transform, clipping, rasterization và Z-buffer.

CPU tạo ảnh RGBA8 hoàn chỉnh. Texture presenter chỉ mang ảnh ấy lên cửa sổ. Dùng GPU để present ảnh không có nghĩa GPU đã xử lý geometry.

## Hiểu ý tưởng trước khi viết code

Mỗi vertex được biến đổi thành $p_{clip}=PVMp$. Theo ba index của tam giác, ta lấy clip coordinates rồi cắt theo sáu mặt $-w\le x,y,z\le w$.

Chỉ sau khi cắt mới chia cho $w$. Đỉnh sau camera bị chia ngay có thể làm tam giác lật hoặc kéo dài vô hạn. Bỏ cả tam giác chỉ vì một đỉnh ở ngoài cũng sai: phần còn nằm trong tầm nhìn vẫn cần vẽ.

Sau perspective divide, NDC được đổi sang screen top-left. Pixel lấy mẫu ở tâm $(x+0,5,y+0,5)$. Edge functions quyết định coverage và trọng số nội suy window depth; Z-buffer dùng phép so LESS.

## Viết code từng bước

### 1. Giữ ảnh màu và depth cạnh nhau

```cpp title="include/pipeline.hpp — struct Framebuffer"
struct Framebuffer {
    int width{1};
    int height{1};
    std::vector<std::uint8_t> rgba{0U, 0U, 0U, 0U};
    std::vector<float> depth{1.0F};

    void resize(int nextWidth, int nextHeight) {
        width = std::max(1, nextWidth);
        height = std::max(1, nextHeight);
        rgba.resize(std::size_t(width) * std::size_t(height) * 4U);
        depth.resize(std::size_t(width) * std::size_t(height));
        clear();
    }

    void clear() {
        for (std::size_t pixel = 0; pixel < depth.size(); ++pixel) {
            const std::size_t offset = pixel * 4U;
            rgba[offset] = 13U;
            rgba[offset + 1U] = 21U;
            rgba[offset + 2U] = 38U;
            rgba[offset + 3U] = 255U;
        }
        std::fill(depth.begin(), depth.end(), 1.0F);
    }
};
```

`rgba` có bốn byte/pixel theo row-major, `depth` có một float/pixel. Mỗi lượt vẽ clear nền và depth về 1. Chỉ resize storage khi kích thước thay đổi.

### 2. Cắt trước perspective divide

```cpp title="include/viewer-cpu.hpp — float clipDistance"
inline float clipDistance(Vec4 point, int plane) {
    switch (plane) {
    case 0:
        return point.w + point.x;
    case 1:
        return point.w - point.x;
    case 2:
        return point.w + point.y;
    case 3:
        return point.w - point.y;
    case 4:
        return point.w + point.z;
    default:
        return point.w - point.z;
    }
}
```

Khoảng cách có dấu không âm nghĩa là ở trong mặt clip. Dạng đồng nhất cho phép kiểm điều đó trước khi chia `w`.

```cpp title="include/viewer-cpu.hpp — ClipPolygon clipViewerTriangle"
inline ClipPolygon clipViewerTriangle(Vec4 a, Vec4 b, Vec4 c) {
    ClipPolygon polygon{};
    polygon.append(a);
    polygon.append(b);
    polygon.append(c);
    for (int plane = 0; plane < 6 && polygon.count >= 3; ++plane) {
        ClipPolygon output{};
        Vec4 previous = polygon.points[polygon.count - 1];
        bool wasInside = clipDistance(previous, plane) >= 0;
        for (std::size_t index = 0; index < polygon.count; ++index) {
            const auto current = polygon.points[index];
            const bool inside = clipDistance(current, plane) >= 0;
            if (inside != wasInside)
                output.append(intersectClipEdge(previous, current, plane));
            if (inside)
                output.append(current);
            previous = current;
            wasInside = inside;
        }
        if (output.count > 1) {
            const auto first = output.points[0], last = output.points[output.count - 1];
            if (first.x == last.x && first.y == last.y && first.z == last.z && first.w == last.w)
                --output.count;
        }
        polygon = output;
    }
    return polygon;
}
```

Đi qua từng cạnh polygon: hai đầu khác phía thì thêm giao điểm; đầu hiện tại ở trong thì giữ. Sau sáu mặt, một tam giác có thể thành polygon nhiều đỉnh. Ta chia quạt polygon ấy để rasterize, không coi nó là lỗi.

`ClipPolygon` giữ tối đa 12 điểm trên stack. Đây là bộ đệm hữu hạn cho clipping tam giác lồi; không cấp phát một polygon mới cho mỗi pixel.

### 3. Đổi sang screen và window depth

```cpp title="include/viewer-cpu.hpp — ScreenVertex viewerScreenVertex"
inline ScreenVertex viewerScreenVertex(Vec4 clip, int width, int height) {
    return {(clip.x / clip.w * 0.5F + 0.5F) * width, (0.5F - clip.y / clip.w * 0.5F) * height, clip.z / clip.w * 0.5F + 0.5F, clip.w};
}
```

Screen Y được đảo một lần vì CPU dùng gốc trên trái. NDC z [-1,1] đổi thành depth [0,1]. Đừng lưu khoảng cách camera thay cho giá trị depth này.

### 4. Điền pixel theo coverage và depth

```cpp title="include/viewer-cpu.hpp — void fillViewerTriangle"
inline void fillViewerTriangle(Framebuffer& frame, ScreenVertex a, ScreenVertex b, ScreenVertex c, Rgb color, bool depthEnabled, ViewerCpuStats& stats) {
    float area = viewerEdge(a, b, c.x, c.y);
    if (std::abs(area) < 1e-7F)
        return;
    if (area < 0) {
        std::swap(b, c);
        area = -area;
    }
    const int left = std::clamp(int(std::floor(std::min({a.x, b.x, c.x}))), 0, frame.width - 1);
    const int right = std::clamp(int(std::ceil(std::max({a.x, b.x, c.x}))), 0, frame.width - 1);
    const int top = std::clamp(int(std::floor(std::min({a.y, b.y, c.y}))), 0, frame.height - 1);
    const int bottom = std::clamp(int(std::ceil(std::max({a.y, b.y, c.y}))), 0, frame.height - 1);
    const bool includeA = topLeftEdge(b, c), includeB = topLeftEdge(c, a), includeC = topLeftEdge(a, b);
    ++stats.rasterized;
    for (int y = top; y <= bottom; ++y) {
        for (int x = left; x <= right; ++x) {
            const float sampleX = x + 0.5F, sampleY = y + 0.5F;
            const float edgeA = viewerEdge(b, c, sampleX, sampleY), edgeB = viewerEdge(c, a, sampleX, sampleY), edgeC = viewerEdge(a, b, sampleX, sampleY);
            if (edgeA < 0 || (edgeA == 0 && !includeA) || edgeB < 0 || (edgeB == 0 && !includeB) || edgeC < 0 || (edgeC == 0 && !includeC))
                continue;
            const float depth = (edgeA * a.depth + edgeB * b.depth + edgeC * c.depth) / area;
            if (writeViewerPixel(frame, x, y, depth, color, depthEnabled))
                ++stats.passed;
            else
                ++stats.rejected;
        }
    }
}
```

Bounding box giới hạn phần ảnh phải duyệt. Ba edge values quyết định pixel thuộc tam giác và tạo trọng số nội suy depth. Top-left rule cho một trong hai tam giác sở hữu cạnh chung, tránh pixel bị nhận hai lần.

`writeViewerPixel` kiểm bounds, depth hữu hạn và `depth < storedDepth` trước khi ghi màu. Bài 6 sẽ so điều này với GL_DEPTH_TEST.

### 5. Duyệt indexed mesh thay vì vẽ cube cố định

```cpp title="include/viewer-cpu.hpp — struct CpuViewerRenderer"
struct CpuViewerRenderer {
    std::vector<Vec4> clipVertices{};

    ViewerCpuStats render(Framebuffer& frame, const ViewerMesh& mesh, const ViewerScene& scene, const ViewerMatrices& matrices) {
        frame.clear();
        clipVertices.resize(mesh.vertices.size());
        for (std::size_t index = 0; index < mesh.vertices.size(); ++index) {
            const auto& vertex = mesh.vertices[index];
            clipVertices[index] = transform(matrices.mvp, {vertex.positionX, vertex.positionY, vertex.positionZ, 1});
        }
        ViewerCpuStats stats{};
        stats.submitted = mesh.triangleCount();
        for (std::size_t order = 0; order < mesh.triangleCount(); ++order) {
            const auto triangle = scene.view.reverseOrder ? mesh.triangleCount() - order - 1 : order;
            const auto offset = triangle * 3;
            const auto ia = mesh.indices[offset], ib = mesh.indices[offset + 1], ic = mesh.indices[offset + 2];
            const auto polygon = clipViewerTriangle(clipVertices[ia], clipVertices[ib], clipVertices[ic]);
            if (polygon.count < 3) {
                ++stats.clipped;
                continue;
            }
            if (polygon.count != 3)
                ++stats.clipped;
            std::array<ScreenVertex, 12> screen{};
            bool valid = true;
            for (std::size_t index = 0; index < polygon.count; ++index) {
                if (polygon.points[index].w <= 1e-7F) {
                    valid = false;
                    break;
                }
                screen[index] = viewerScreenVertex(polygon.points[index], frame.width, frame.height);
            }
            if (!valid) {
                ++stats.clipped;
                continue;
            }
            float area = 0;
            for (std::size_t index = 1; index + 1 < polygon.count && std::abs(area) < 1e-7F; ++index)
                area = viewerEdge(screen[0], screen[index], screen[index + 1].x, screen[index + 1].y);
            if (std::abs(area) < 1e-7F)
                continue;
            if (scene.view.cullBackfaces && area > 0) {
                ++stats.culled;
                continue;
            }
            const auto color = viewerFaceColor(mesh.vertices[ia], scene, matrices);
            if (scene.view.wireframe) {
                for (std::size_t index = 0; index < polygon.count; ++index)
                    drawViewerLine(frame, polygon.points[index], polygon.points[(index + 1) % polygon.count], color, scene.depthEnabled);
            } else {
                for (std::size_t index = 1; index + 1 < polygon.count; ++index)
                    fillViewerTriangle(frame, screen[0], screen[index], screen[index + 1], color, scene.depthEnabled, stats);
            }
        }
        if (scene.view.grid) {
            const auto viewProjection = multiply(matrices.projection, matrices.view);
            for (int index = -6; index <= 6; ++index) {
                const float position = index * 0.5F;
                drawViewerLine(frame, transform(viewProjection, {position, -1.1F, -3, 1}), transform(viewProjection, {position, -1.1F, 3, 1}), {37, 51, 74}, scene.depthEnabled);
                drawViewerLine(frame, transform(viewProjection, {-3, -1.1F, position, 1}), transform(viewProjection, {3, -1.1F, position, 1}), {37, 51, 74}, scene.depthEnabled);
            }
        }
        if (scene.view.normals) {
            for (std::size_t triangle = 0; triangle < mesh.triangleCount(); ++triangle) {
                const auto& a = mesh.vertices[mesh.indices[triangle * 3]];
                const auto& b = mesh.vertices[mesh.indices[triangle * 3 + 1]];
                const auto& c = mesh.vertices[mesh.indices[triangle * 3 + 2]];
                const Vec4 center{(a.positionX + b.positionX + c.positionX) / 3, (a.positionY + b.positionY + c.positionY) / 3, (a.positionZ + b.positionZ + c.positionZ) / 3, 1};
                const Vec4 tip{center.x + a.normalX * 0.12F, center.y + a.normalY * 0.12F, center.z + a.normalZ * 0.12F, 1};
                drawViewerLine(frame, transform(matrices.mvp, center), transform(matrices.mvp, tip), {255, 201, 107}, scene.depthEnabled);
            }
        }
        return stats;
    }
};
```

Mỗi vertex được transform một lần vào `clipVertices`. Sau đó mỗi tam giác lấy ba index, clip, project, cull rồi fill. Scene, mesh và matrices là const reference; renderer chỉ sửa bộ đệm của nó.

Các nhánh wireframe, grid và normals giữ khả năng quan sát từ viewer cũ; bài 7 sẽ giải thích riêng. Trước tiên hãy kiểm chế độ solid.

Nhấn 1 xem rocket, 2 xem sphere, 3 xem cube. Kéo trái hoặc dùng mũi tên để xoay model. F2 chưa bật ở checkpoint này.

`ViewerBackends::render` gọi CPU renderer, upload ảnh rồi vẽ quad bằng texture presenter. Presenter không nhận mesh/MVP của model nên không làm thay rasterizer.

Ảnh lật trên-dưới nhưng framebuffer đúng: kiểm UV presenter. Mặt che nhau sai ngay trong framebuffer: kiểm raster/depth. Hai lỗi ấy không sửa bằng cùng một cách.

## Thử làm sai để hiểu đúng

1. Trong bản thử, bỏ clipping và project ba đỉnh trực tiếp. Đưa camera gần tam giác, quan sát phần bị mất hoặc vọt khỏi màn hình rồi khôi phục sáu mặt clip.
2. Thử đảo screen Y mà không xét lại dấu area khi culling. Mặt nhìn thấy sẽ đảo. Đừng đổi riêng indices CPU để giấu lỗi; bài 6 sẽ thống nhất winding.
