# Đồng bộ winding và face culling

## Vấn đề cần giải quyết

Depth test giải quyết mặt nào nhìn thấy ở từng pixel, nhưng GPU vẫn rasterize cả mặt trước lẫn mặt sau. Face culling có thể loại back faces sớm—nếu CPU/GPU thống nhất thế nào là front-facing.

Khó ở chỗ source indices được định nghĩa CCW khi nhìn từ ngoài, OpenGL xét CCW trong window convention của nó, còn CPU framebuffer có gốc trên-trái và Y tăng xuống. Phép đảo Y làm signed area đổi dấu.

## Hiểu ý tưởng trước khi viết code

Ta giữ một index buffer duy nhất. CPU làm hai bước tách biệt:

1. Dùng dấu area trong top-left screen để quyết định triangle có tương ứng front face CCW ở NDC hay không.
2. Nếu triangle được giữ, normalize `b/c` để rasterizer luôn nhận area dương.

Việc swap cho coverage không được xảy ra trước culling, nếu không ta xóa mất thông tin winding ban đầu.

### Bước 2 — CPU xét dấu trước khi normalize

```cpp title="include/pipeline.hpp — front face trong top-left screen"
float area = signedArea(a, b, c);
const bool frontFacing = area < -1.0e-6F;
if (scene.cullingEnabled && !frontFacing) {
    ++stats.culledTriangles;
    continue;
}
```

Area âm ở đây là hệ quả của top-left screen Y. Nó không có nghĩa source mesh dùng clockwise.

### Bước 3 — GPU khai báo đúng source convention

```cpp title="include/gpu_renderer.hpp — GL_CCW và GL_BACK"
if (cullingEnabled) {
    api.Enable(GL_CULL_FACE);
    api.CullFace(GL_BACK);
    api.FrontFace(GL_CCW);
} else {
    api.Disable(GL_CULL_FACE);
}
```

Phím C chỉ bật/tắt state. Nó không đảo indices và không đổi `glFrontFace` theo góc nhìn.

## Ghép các phần lại

Checkpoint 7 mặc định GPU mode. Bấm C để so cube khi culling on/off; color result phải giữ giống nhau khi depth bật, nhưng work và số triangles CPU cull sẽ khác.

```cpp title="src/main.cpp — C sửa shared scene"
}
else if (event.key.key == SDLK_C) {
    scene.cullingEnabled = !scene.cullingEnabled;
```

Ở CPU path, chỉ sau quyết định culling ta mới `std::swap(b, c)` để area dương cho barycentric coverage.

## Thử làm sai để hiểu đúng

1. Gọi `std::swap(b,c)` trước khi tính `frontFacing`. Mọi triangle sau normalize có cùng dấu; culling mất ý nghĩa.
2. Đổi GPU sang `GL_CW` nhưng giữ indices. Các mặt trước biến mất và cube trông như nhìn từ bên trong.
3. Đảo riêng indices GPU. F1/F2 có thể trông giống, nhưng shared mesh contract đã bị phá và test CPU không còn kiểm GPU input.

Hoàn tác thay đổi sau từng quan sát.

## Tự kiểm tra kết quả

- [ ] Source indices CCW khi nhìn từ ngoài từng face.
- [ ] CPU biết top-left screen làm area đổi dấu.
- [ ] Culling diễn ra trước normalize winding.
- [ ] GPU dùng GL_CCW và GL_BACK.
- [ ] Tắt culling không làm cube sai nếu depth vẫn bật.

Hãy dự đoán điều sẽ xảy ra với một mặt có hai triangles trái winding: culling tạo một nửa hình vuông bị thủng.

## Bài tập mở rộng
