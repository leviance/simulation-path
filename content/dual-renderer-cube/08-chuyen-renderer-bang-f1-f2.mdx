# Đổi backend mà không mất trạng thái

## Vấn đề cần giải quyết

Hai renderer đã vẽ được cùng mesh. Phần còn lại là biến chúng thành một ứng dụng dùng được: đổi model, kéo camera, pause, resize và chuyển backend liên tục mà không mất thao tác hoặc tạo tài nguyên lặp lại.

Đừng đặt event loop vào từng renderer. Nếu mỗi backend tự bắt phím và cập nhật góc, việc nhấn F1/F2 sẽ kéo theo hai vòng đời state khác nhau.

## Hiểu ý tưởng trước khi viết code

Ứng dụng giữ một `ViewerScene` và một `RendererKind`. Mỗi frame chỉ cập nhật scene một lần, sau đó renderer được chọn đọc const snapshot ấy.

`ViewerBackends` sở hữu tài nguyên theo backend: ảnh/depth/clip cache CPU, texture presenter, program và ba GPU mesh đã upload. Tài nguyên này tồn tại qua các lần F1/F2. Đổi backend chỉ chọn nhánh; đổi model chỉ chọn phần tử trong cache.

## Viết code từng bước

### 1. F1/F2 chỉ sửa enum

```cpp title="include/viewer-application.hpp —                     if "
if (key == SDLK_F1)
    backend = RendererKind::cpu;
else if (key == SDLK_F2)
    backend = RendererKind::gpu;
```

Không gọi initialize, không đọc lại OBJ, không reset camera trong hai nhánh này. Chúng vẫn hoạt động khi mouse đang capture. Những phím sửa pose khác bị bỏ qua trong lúc kéo để tránh một gesture có hai nguồn thay đổi state.

### 2. Phân biệt logical input với framebuffer pixels

Window input báo tọa độ logical. OpenGL viewport và CPU framebuffer lại dùng pixel thật. Với pan, ta đổi độ dịch chuột theo tỉ lệ width/logicalWidth và height/logicalHeight trước khi đưa vào công thức camera.

Kéo trái gọi `turnViewer` theo chế độ model/camera đã chọn. Kéo phải gọi `panViewer`. Wheel chỉ thay distance; không sửa matrix trực tiếp trong renderer.

Capture ghi lại mouse ID và nút bắt đầu, vì một nút khác thả ra không nên kết thúc lượt kéo hiện tại. Trước khi kéo, giữ `beforeDrag` để Escape khôi phục. Mất focus hoặc resize nhả capture và pause, không giữ chuột trong ứng dụng.

### 3. Pause và tiến một bước có nghĩa rõ ràng

Space bật/tắt xoay tự động; N pause rồi tăng angle Y đúng $\pi/18$ (10°). Delta time được giới hạn 0,05 giây để trở lại sau một frame chậm không làm model quay một bước quá lớn.

R đặt lại pose/options nhưng giữ model đang chọn và backend. Home chỉ đặt lại camera/pan target, không thay model transform. Đây là hai thao tác khác nhau, không nên cùng làm “reset mọi thứ”.

### 4. Render từ scene chung, resize storage khi cần

```cpp title="include/viewer-backends.hpp —     ViewerFrameStats render"
ViewerFrameStats render(GlApi& gl, const std::array<ViewerMesh, 3>& models, const ViewerScene& scene, RendererKind backend, int width, int height, std::uint64_t number, int originY = 0) {
    if (width <= 0 || height <= 0 || std::size_t(width) * std::size_t(height) > 16'000'000 || scene.meshIndex >= models.size()) {
        throw std::invalid_argument("Invalid viewer render dimensions or model");
    }
    ViewerFrameStats stats{};
    stats.frame = number;
    auto started = ViewerClock::now();
    const auto matrices = viewerMatrices(scene, float(width) / height);
    stats.prepareMs = viewerMilliseconds(started);
    if (frame.width != width || frame.height != height) {
        frame.resize(width, height);
        presenter.resize(gl, width, height);
    }
    gl.Disable(GL_SCISSOR_TEST);
    gl.Viewport(0, originY, width, height);
    gl.ClearColor(13.0F / 255, 21.0F / 255, 38.0F / 255, 1);
    gl.ClearDepth(1);
    gl.Clear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
    timer.poll(gl);
    if (backend == RendererKind::cpu) {
        stats.cpuPathExecuted = true;
        started = ViewerClock::now();
        cpu.render(frame, models[scene.meshIndex], scene, matrices);
        stats.cpuRenderMs = viewerMilliseconds(started);
        started = ViewerClock::now();
        presenter.upload(gl, frame);
        stats.uploadMs = viewerMilliseconds(started);
        started = ViewerClock::now();
        gl.PolygonMode(GL_FRONT_AND_BACK, GL_FILL);
        presenter.draw(gl);
        stats.submitMs = viewerMilliseconds(started);
    }
    else {
        started = ViewerClock::now();
        timer.begin(gl, number);
        meshes[scene.meshIndex].draw(gl, program, scene, matrices);
        if (scene.view.grid) {
            program.bindLine(gl, multiply(matrices.projection, matrices.view), {37.0F / 255, 51.0F / 255, 74.0F / 255});
            grid.draw(gl);
        }
        timer.end(gl);
        stats.submitMs = viewerMilliseconds(started);
    }
    return stats;
}
```

Matrix tính từ width/height của vùng model. Storage chỉ resize khi kích thước đổi. GPU resources đã được tạo ở initialize; nhánh render không gọi BufferData cho model.

CPU path gồm CPU geometry → upload → quad submission. GPU path gồm uniform/state → indexed draw. Chúng đều dùng `scene.meshIndex` và cùng matrices; không backend nào cập nhật camera bên trong.

Vùng HUD chiếm 100 pixel dưới cùng. OpenGL viewport đặt origin Y=100; ảnh CPU được present vào chính viewport ấy. Input chỉ bắt đầu drag trong phần model, không bắt trên HUD.

## Ghép các phần lại

```bash title="Terminal — viewer tương tác"
cmake --build build --config Debug --target project_34_checkpoint_8 --parallel 2
.\build\Debug\project_34_checkpoint_8.exe
```

Thực hiện một chuỗi đủ dài: chọn sphere → V đổi góc nhìn → kéo → pan → zoom → bật H → F1/F2 20 lần → resize → chọn rocket. Thử cả lúc pause và lúc Space đang chạy.

Nếu đổi backend làm hình nhảy, in scene trước/sau rồi tìm biến bị reset. Nếu chỉ resize làm nhảy, kiểm aspect/viewport/presenter storage. Không vội tạo một camera khác cho backend bị lệch.

## Thử làm sai để hiểu đúng

1. Đặt `scene = {}` trong nhánh F2 của một bản thử. Làm lại chuỗi trên để thấy vì sao “cả hai bên đều vẽ được” chưa đủ. Khôi phục nhánh chỉ sửa enum.
2. Thử gọi `initialize` mỗi lần chọn model và log IDs của VBO/VAO. Bạn sẽ thấy tài nguyên bị tạo lại. Khôi phục cache một lần; bài cuối sẽ kiểm các IDs qua switch, resize và đổi mesh.

## Tự kiểm tra kết quả

- [ ] F1/F2 không sửa bất kỳ camera/model/light/visibility value nào.
- [ ] Không nạp lại OBJ hoặc upload mesh khi switch.
- [ ] Kéo model và camera là hai chế độ riêng; pan/zoom vẫn dùng được ở hai backend.
- [ ] Escape hủy kéo, thả đúng nút kết thúc kéo, focus loss nhả capture.
- [ ] N tiến 10° khi pause; R giữ model/backend; Home chỉ reset camera.
- [ ] Resize cập nhật viewport, aspect, CPU storage và texture allocation cùng kích thước pixel.

## Bài tập mở rộng

1. Thêm preset camera front/back mà không sửa model pose.
2. Ghi resource IDs sau startup và sau một chuỗi thao tác, dự đoán ID nào phải giữ nguyên và storage nào được resize.
