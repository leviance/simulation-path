# Mở lại model viewer, tách scene khỏi renderer

## Vấn đề cần giải quyết

Ở Project 21, ta đã có viewer đọc OBJ và tự vẽ từng tam giác bằng CPU. Project 33 cho ta bộ khung OpenGL. Bây giờ cần ghép hai phần ấy thành **một viewer**, không phải hai chương trình cùng vẽ cube.

Bạn đang nhìn phía sau tên lửa, đã zoom gần và kéo camera sang phải. Nhấn F2 để xem GPU vẽ thế nào mà mô hình quay về tư thế ban đầu thì việc so sánh gần như mất ý nghĩa. Trước khi viết GPU renderer, ta cần biết dữ liệu nào phải giữ nguyên khi đổi backend.

Sản phẩm cuối phải xem được rocket và sphere 2.976 tam giác từ Project 21. Cube chỉ là fixture tìm lỗi. Bạn có thể thử tự làm theo đề bài ở trang tổng quan trước khi đọc tiếp.

## Hiểu ý tưởng trước khi viết code

Một frame làm bốn việc theo thứ tự: đọc input, cập nhật scene, vẽ scene, rồi present. Chỉ việc vẽ được chọn giữa CPU và GPU.

`ViewerScene` mô tả đang xem gì và xem thế nào: model, camera, góc quay, ánh sáng và tùy chọn hiển thị. Texture, VBO/EBO/VAO và framebuffer lại là công cụ của renderer. Đặt chúng ngoài scene giúp ta đổi cách vẽ mà không thay cảnh.

Chọn sphere, đổi góc nhìn rồi nhấn F1/F2. Tư thế không đổi vì backend là lựa chọn riêng. Canvas chỉ minh họa cách tổ chức state; chưa chứng minh OpenGL thật đã vẽ đúng.

## Viết code từng bước

### 1. Chạy bộ khung SDL/OpenGL trước

Giải nén ZIP và mở terminal tại thư mục có `CMakeLists.txt`. Source không cần include hoặc link sang Project 21. Starter giữ context và function loader đã học ở Project 33:

```cpp title="include/viewer-bootstrap.hpp —     SDL_GL_SetAttribute"
SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 3);
SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 3);
SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_CORE);
SDL_GL_SetAttribute(SDL_GL_DEPTH_SIZE, 24);
SDL_WindowFlags flags = SDL_WINDOW_OPENGL | SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY;
if (finite) {
    flags |= SDL_WINDOW_HIDDEN;
}
SDL_Window* window = SDL_CreateWindow("P34 - Viewer foundation", 960, 640, flags);
SDL_GLContext context = window ? SDL_GL_CreateContext(window) : nullptr;
```

Các thuộc tính phải được đặt trước khi tạo context. Window cần `SDL_WINDOW_OPENGL`; `SDL_WINDOW_HIGH_PIXEL_DENSITY` cho phép framebuffer có nhiều pixel hơn kích thước logical. Sau khi tạo context, make-current rồi mới load function pointers. Starter có sẵn đường báo lỗi và cleanup để bạn kiểm phần này trước.

### 2. Đặt tên rõ hai lựa chọn

```cpp title="include/pipeline.hpp — enum class RendererKind"
enum class RendererKind {
    cpu,
    gpu,
};
```

`RendererKind` là biến lựa chọn của ứng dụng. Nó không cần sở hữu một camera hay bản sao góc quay.

### 3. Mang state từ model viewer sang

```cpp title="include/viewer-scene.hpp — struct ViewerState"
struct ViewerState {
    double angleX{-0.35};
    double angleY{0.65};
    double cameraYaw{};
    double cameraPitch{};
    double distance{4.2};
    bool cameraDrag{};
    bool paused{true};
    bool wireframe{};
    bool normals{};
    bool cullBackfaces{true};
    bool reverseOrder{};
    bool debug{true};
    bool grid{true};

    bool operator==(const ViewerState&) const = default;
};
```

`angleX/angleY` quay model; `cameraYaw/cameraPitch` thay vị trí quan sát. Hai thao tác nhìn có vẻ giống nhau khi chỉ có một vật, nhưng sửa hai phép biến đổi khác nhau. `paused` bắt đầu bằng true để người học quan sát ảnh đứng yên.

```cpp title="include/viewer-scene.hpp — struct ViewerScene"
struct ViewerScene {
    ViewerState view{};
    std::size_t meshIndex{};
    float targetX{}, targetY{}, targetZ{};
    float verticalFov{std::numbers::pi_v<float> / 3};
    float nearPlane{0.2F};
    float farPlane{50};
    bool depthEnabled{true};
    bool lit{true};
    float lightX{-0.45F}, lightY{0.75F}, lightZ{1};
    float baseRed{0.28F}, baseGreen{0.64F}, baseBlue{0.91F};

    bool operator==(const ViewerScene&) const = default;
};
```

FOV, near/far, pan target và hướng sáng cũng phải dùng chung. Chỉ giữ chung góc quay mà để mỗi backend dùng một FOV khác thì vẫn chưa có phép so đúng. `operator==` giúp test kiểm toàn bộ scene thay vì chỉ nhớ kiểm hai góc.

## Ghép các phần lại

Starter kiểm lifecycle. Checkpoint 01 thêm scene và input; chưa có geometry nên nền trống là đúng ở bước này. Nhấn Right để đổi góc Y, F1/F2 để đổi nhãn backend và R để đặt lại. Quan sát title bar.

```bash title="Terminal — starter và checkpoint đầu"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_34_starter project_34_checkpoint_1 --parallel 2
.\build\Debug\project_34_starter.exe --smoke
.\build\Debug\project_34_checkpoint_1.exe
```

Đây là lệnh Visual Studio/Windows. Với generator single-config, executable nằm ngay trong `build`; chọn `-DCMAKE_BUILD_TYPE=Debug` khi configure. Lần đầu cần mạng để tải SDL 3.4.8.

Nếu không tạo được OpenGL 3.3 Core context, xử lý driver hoặc môi trường trước. Không bỏ qua lỗi rồi gọi các function pointer rỗng. Bộ khung chạy được cũng chưa phải sản phẩm cuối: bài 2 nạp mesh, bài 3 mới nối geometry vào cửa sổ.

## Thử làm sai để hiểu đúng

Trong một bản thử, giữ `cameraDistanceCpu` và `cameraDistanceGpu` riêng, rồi chỉ sửa biến của backend đang chọn. Dự đoán chuỗi F1 → đổi khoảng cách → F2 → F1 sẽ giữ được góc nhìn không.

Bạn chưa cần vẽ model để thấy state đã tách làm hai. Xóa hai biến thử và đưa camera về một nơi. Đừng tạo lại `ViewerScene` trong nhánh xử lý F1/F2.
