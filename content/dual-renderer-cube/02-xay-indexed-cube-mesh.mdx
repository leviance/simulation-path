# Dùng lại OBJ và chuẩn bị một mesh chung

## Vấn đề cần giải quyết

CPU viewer đã đọc được OBJ, nên không cần một loader mới chỉ để dùng GPU. Việc mới là chuẩn bị dữ liệu sau khi nạp: hai backend phải đọc **cùng position, normal và index**.

Một OBJ có tám vị trí không có nghĩa VBO chỉ cần tám vertex. Ở góc cube, ba mặt chung vị trí nhưng có ba normal khác nhau. Nếu gộp thành một vertex, shader không biết normal nào thuộc mặt đang vẽ.

## Hiểu ý tưởng trước khi viết code

Ta giữ parser Project 21, chuẩn hóa model về gốc và cạnh dài nhất bằng 2, rồi tạo normal phẳng cho từng tam giác:

$$
n=\operatorname{normalize}((b-a)\times(c-a)).
$$

Position và normal đi thành cặp. Hai tam giác chỉ chia sẻ vertex khi cả hai giá trị giống nhau. Vì vậy cube cần 24 vertex nhưng 36 index; sphere không bị ép về số lượng cố định của cube.

## Viết code từng bước

### 1. Dùng nguyên loader và dataset đã biết

Bốn file `include/obj21/{geometry,mesh,obj-parser,normalize}.hpp` giữ thuật toán Project 21. Namespace `obj21` tránh trùng tên kiểu float trong pipeline mới, không thay parser bằng thư viện ngoài.

`assets/` chứa rocket 32 tam giác, sphere 2.976 tam giác, cube và giấy phép CC0. Asset dùng chung một lần cho toàn project, không chép riêng vào từng checkpoint.

Parser vẫn xử lý index âm, slash token và face lồi phẳng. Nó không phải loader cho mọi OBJ: không đọc material/texture và không tự triangulate polygon lõm. Các giới hạn dung lượng, độ dài dòng, số vị trí, số góc face được giữ nguyên.

### 2. Chọn layout dùng chung

```cpp title="include/viewer-mesh.hpp — struct MeshVertex"
struct MeshVertex {
    float positionX{}, positionY{}, positionZ{};
    float normalX{}, normalY{}, normalZ{};
};
```

Ba float đầu là position, ba float sau là normal — không phải màu như vertex của triangle ở bài trước. `static_assert` sau struct kiểm standard layout, sáu float và offset normal bằng ba float.

```cpp title="include/viewer-mesh.hpp — struct ViewerMesh"
struct ViewerMesh {
    obj21::ObjMesh source{};
    std::vector<MeshVertex> vertices{};
    std::vector<std::uint32_t> indices{};
    std::string name{};

    std::size_t triangleCount() const {
        return indices.size() / 3;
    }
};
```

`vertices` là dữ liệu để vẽ, `indices` chọn ba vertex mỗi tam giác. `source` giữ OBJ đã chuẩn hóa để truy lại dữ liệu và kiểm bounds, không phải mesh riêng cho backend thứ hai.

### 3. Tạo normal rồi tìm vertex đã có

```cpp title="include/viewer-mesh.hpp — ViewerMesh prepareViewerMesh"
inline ViewerMesh prepareViewerMesh(obj21::ObjMesh source, const std::string& name) {
    if (source.triangles.size() > 400'000 || !obj21::normalizeMesh(source)) {
        throw std::invalid_argument("Invalid mesh bounds or triangle budget");
    }
    ViewerMesh result{};
    result.name = name;
    std::map<std::array<float, 6>, std::uint32_t> uniqueVertices;
    for (const auto& triangle : source.triangles) {
        for (std::size_t index : triangle.indices) {
            if (index >= source.positions.size())
                throw std::invalid_argument("OBJ index outside positions");
        }
        const auto a = source.positions[triangle.indices[0]];
        const auto b = source.positions[triangle.indices[1]];
        const auto c = source.positions[triangle.indices[2]];
        const auto normal = obj21::normalized(obj21::cross(b - a, c - a));
        if (!normal)
            continue;
        for (std::size_t index : triangle.indices) {
            const auto point = source.positions[index];
            const std::array<float, 6> key{float(point.x), float(point.y), float(point.z), float(normal->x), float(normal->y), float(normal->z)};
            const auto found = uniqueVertices.find(key);
            if (found != uniqueVertices.end()) {
                result.indices.push_back(found->second);
            } else {
                const auto vertexIndex = static_cast<std::uint32_t>(result.vertices.size());
                result.vertices.push_back({key[0], key[1], key[2], key[3], key[4], key[5]});
                result.indices.push_back(vertexIndex);
                uniqueVertices.emplace(key, vertexIndex);
            }
        }
    }
    result.source = std::move(source);
    if (!validViewerMesh(result))
        throw std::invalid_argument("Mesh has no valid drawable triangles");
    return result;
}
```

Đọc từng vòng lặp: kiểm index trước khi đọc position, lấy ba điểm, tính cross product rồi normalize. Tam giác suy biến không có normal hợp lệ nên bị bỏ.

Bảng `uniqueVertices` dùng khóa sáu số. Nếu đã có position+normal ấy, thêm index cũ. Nếu chưa có, thêm vertex mới rồi nhớ index. Bảng được dựng lúc nạp, không dựng lại mỗi frame.

Hai tam giác trên một mặt cube chia sẻ bốn vertex. Giữa các mặt, normal khác nhau buộc phải tách. Không có phép kiểm `triangleCount == 12` trong renderer mesh thật.

### 4. Chỉ nhận model dùng được

```cpp title="include/viewer-mesh.hpp — std::optional<ViewerMesh> loadViewerMesh"
inline std::optional<ViewerMesh> loadViewerMesh(const std::string& path, std::string& diagnostics) {
    obj21::ObjLoadResult loaded = obj21::loadObjFile(path);
    if (!loaded.hasRenderableMesh()) {
        diagnostics = path + ": ";
        for (const auto& error : loaded.diagnostics) {
            diagnostics += "line " + std::to_string(error.line) + ": " + error.message + "; ";
        }
        if (loaded.diagnostics.empty())
            diagnostics += "no supported faces";
        return std::nullopt;
    }
    try {
        const auto nativePath = std::filesystem::path(std::u8string(path.begin(), path.end()));
        const auto utf8Name = nativePath.stem().u8string();
        auto result = prepareViewerMesh(std::move(loaded.mesh), std::string(utf8Name.begin(), utf8Name.end()));
        diagnostics.clear();
        return result;
    } catch (const std::exception& error) {
        diagnostics = path + ": " + error.what();
        return std::nullopt;
    }
}
```

`optional` biểu thị thành công/thất bại; diagnostics giữ đường dẫn và lỗi parser. Chuẩn bị nằm trong dữ liệu tạm nên caller chỉ thay model sau khi thành công. Bản final nạp sẵn ba dataset khi startup; không có một đường nạp riêng cho GPU.

```bash title="Terminal — kiểm dữ liệu trước khi vẽ"
.\build\Debug\project_34_checkpoint_2.exe --smoke
```

Checkpoint 02 báo sphere và 2.976 tam giác ra terminal. Cửa sổ vẫn chỉ clear nền. Có lỗi nạp thì đọc diagnostics trước; shader chưa tham gia vào bước này.

Ở bài sau, CPU đọc `mesh.vertices[mesh.indices[i]]`. GPU sẽ upload chính hai mảng ấy chứ không tạo một mesh có cách đánh số khác.

## Thử làm sai để hiểu đúng

1. Tạo OBJ thử với index 0 hoặc `f 1 2 999999`. Kỳ vọng parser báo lỗi, không đọc ngoài mảng.
2. Trong một bản thử khác, bỏ normal khỏi khóa vertex. Khi xem cube ở final, các mặt không còn normal riêng nên ánh sáng không phản ánh đúng mặt đang vẽ. Khôi phục khóa position+normal; đừng sửa shader để bù cho dữ liệu đã mất.
