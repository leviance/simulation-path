# Đưa mesh lên GPU bằng VBO và EBO

## Vấn đề cần giải quyết

CPU đã vẽ được mesh thật. Giờ ta thay phần xử lý geometry/raster/depth bằng OpenGL, nhưng giữ nguyên dữ liệu đầu vào. GPU renderer không được tạo một cube khác hoặc dùng số index cố định 36.

Bài này thêm ba tài nguyên: VBO giữ vertex bytes, EBO giữ index bytes và VAO nhớ cách đọc chúng. Shader nhận position/normal cùng MVP; ứng dụng vẫn sở hữu scene.

## Hiểu ý tưởng trước khi viết code

Với triangle thứ $t$, CPU đọc ba index tại $3t,3t+1,3t+2$. `glDrawElements` thực hiện cùng cách tham chiếu ấy từ EBO.

VBO trả lời “vertex này gồm những dữ liệu gì?”. EBO trả lời “tam giác dùng các vertex nào, theo thứ tự nào?”. VAO ghi cách attributes đọc VBO và ghi EBO đang gắn với nó. VAO không tự chứa một bản sao các vertex.

## Viết code từng bước

### 1. Cho shader biết position và normal

```glsl title="include/viewer-gpu.hpp — viewerVertexShader"
#version 330 core
layout(location = 0) in vec3 aPosition;
layout(location = 1) in vec3 aNormal;
uniform mat4 uMvp;
uniform mat4 uModel;
flat out vec3 worldNormal;
void main() {
    gl_Position = uMvp * vec4(aPosition, 1.0);
    worldNormal = mat3(uModel) * aNormal;
}
```

Location 0 là position, location 1 là normal. `uMvp` biến vị trí từ local tới clip; `uModel` xoay normal sang world space. `flat` giữ normal phẳng trên mặt, giống viewer CPU.

Model ở project này chỉ có rotation sau khi mesh được chuẩn hóa bằng tỉ lệ đồng nhất. Vì thế `mat3(uModel) * aNormal` dùng được. Nếu sau này thêm non-uniform scale, phải dùng inverse-transpose normal matrix, không bê nguyên công thức này sang.

Fragment shader có sẵn cùng ánh sáng Lambert để hai đường vẽ đọc hình giống nhau. Bài 7 sẽ đi từng bước qua phép chiếu sáng ấy.

### 2. Upload đúng hai mảng, đúng một lần

```cpp title="include/viewer-gpu.hpp —     bool initialize"
bool initialize(GlApi& gl, const ViewerMesh& mesh) {
    if (!validViewerMesh(mesh))
        return false;
    gl.GenVertexArrays(1, &vao);
    gl.GenBuffers(1, &vertices);
    gl.GenBuffers(1, &elements);
    gl.GenBuffers(1, &reversedElements);
    if (!vao || !vertices || !elements || !reversedElements)
        return false;
    indexCount = static_cast<GLsizei>(mesh.indices.size());
    gl.BindVertexArray(vao);
    gl.BindBuffer(GL_ARRAY_BUFFER, vertices);
    gl.BufferData(GL_ARRAY_BUFFER, GLsizeiptr(mesh.vertices.size() * sizeof(MeshVertex)), mesh.vertices.data(), GL_STATIC_DRAW);
    gl.EnableVertexAttribArray(0);
    gl.VertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, GLsizei(sizeof(MeshVertex)), nullptr);
    gl.EnableVertexAttribArray(1);
    gl.VertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, GLsizei(sizeof(MeshVertex)), reinterpret_cast<const void*>(offsetof(MeshVertex, normalX)));
    gl.BindBuffer(GL_ELEMENT_ARRAY_BUFFER, elements);
    gl.BufferData(GL_ELEMENT_ARRAY_BUFFER, GLsizeiptr(mesh.indices.size() * sizeof(std::uint32_t)), mesh.indices.data(), GL_STATIC_DRAW);
    std::vector<std::uint32_t> reversed;
    reversed.reserve(mesh.indices.size());
    std::vector<Vec3> normalLines;
    normalLines.reserve(mesh.triangleCount() * 2);
    for (std::size_t triangle = 0; triangle < mesh.triangleCount(); ++triangle) {
        const auto offset = (mesh.triangleCount() - 1 - triangle) * 3;
        reversed.push_back(mesh.indices[offset]);
        reversed.push_back(mesh.indices[offset + 1]);
        reversed.push_back(mesh.indices[offset + 2]);
        const auto& a = mesh.vertices[mesh.indices[triangle * 3]];
        const auto& b = mesh.vertices[mesh.indices[triangle * 3 + 1]];
        const auto& c = mesh.vertices[mesh.indices[triangle * 3 + 2]];
        const Vec3 center{(a.positionX + b.positionX + c.positionX) / 3, (a.positionY + b.positionY + c.positionY) / 3, (a.positionZ + b.positionZ + c.positionZ) / 3};
        normalLines.push_back(center);
        normalLines.push_back({center.x + a.normalX * 0.12F, center.y + a.normalY * 0.12F, center.z + a.normalZ * 0.12F});
    }
    gl.BindBuffer(GL_ELEMENT_ARRAY_BUFFER, reversedElements);
    gl.BufferData(GL_ELEMENT_ARRAY_BUFFER, GLsizeiptr(reversed.size() * sizeof(std::uint32_t)), reversed.data(), GL_STATIC_DRAW);
    gl.BindVertexArray(0);
    gl.BindBuffer(GL_ARRAY_BUFFER, 0);
    return normals.initialize(gl, normalLines) && gl.GetError() == GL_NO_ERROR;
}
```

Hãy theo các lần bind thay vì đọc một loạt tên OpenGL như thủ tục bắt buộc:

- Bind VAO trước khi mô tả attributes.
- Bind VBO rồi `BufferData` từ `mesh.vertices.data()`.
- Position có 3 float, stride `sizeof(MeshVertex)`, offset 0.
- Normal có 3 float, cùng stride, offset `offsetof(MeshVertex, normalX)`.
- Bind EBO khi VAO vẫn active rồi upload `mesh.indices` với kiểu `uint32_t`.

`GL_STATIC_DRAW` phù hợp vì model không đổi vertex khi bạn orbit hoặc xoay nó; ta chỉ đổi matrix. Không gọi lại hàm initialize trong mỗi frame hay mỗi lần F1/F2.

Bản source còn chuẩn bị một EBO thứ tự tam giác đảo để làm thí nghiệm draw order. Nó đảo **thứ tự các bộ ba**, không đảo winding bên trong mỗi tam giác. Cả hai backend chọn cùng tùy chọn `reverseOrder`. Buffer normal-line phục vụ chế độ debug, không phải một mesh thay thế.

### 3. Truyền scene qua uniforms

```cpp title="include/viewer-gpu.hpp —     void bind"
void bind(GlApi& gl, const ViewerMatrices& matrices, const ViewerScene& scene) const {
    gl.UseProgram(program);
    gl.UniformMatrix4fv(mvp, 1, GL_FALSE, matrices.mvp.values.data());
    gl.UniformMatrix4fv(model, 1, GL_FALSE, matrices.model.values.data());
    gl.Uniform3f(light, scene.lightX, scene.lightY, scene.lightZ);
    gl.Uniform3f(baseColor, scene.baseRed, scene.baseGreen, scene.baseBlue);
    gl.Uniform1i(lit, scene.lit ? 1 : 0);
}
```

Uniform locations được tìm sau khi link, không tìm lại mỗi frame. Tên uniform thiếu khiến initialize thất bại kèm diagnostics. `GL_FALSE` nghĩa là không transpose array column-major; bài 5 sẽ kiểm quy ước này bằng số cụ thể.

### 4. Draw theo số index của mesh

```cpp title="include/viewer-gpu.hpp —     void draw"
void draw(GlApi& gl, const GpuViewerProgram& program, const ViewerScene& scene, const ViewerMatrices& matrices) const {
    if (scene.depthEnabled) {
        gl.Enable(GL_DEPTH_TEST);
        gl.DepthFunc(GL_LESS);
    } else
        gl.Disable(GL_DEPTH_TEST);
    if (scene.view.cullBackfaces) {
        gl.Enable(GL_CULL_FACE);
        gl.CullFace(GL_BACK);
        gl.FrontFace(GL_CCW);
    } else
        gl.Disable(GL_CULL_FACE);
    gl.PolygonMode(GL_FRONT_AND_BACK, scene.view.wireframe ? GL_LINE : GL_FILL);
    program.bind(gl, matrices, scene);
    gl.BindVertexArray(vao);
    gl.BindBuffer(GL_ELEMENT_ARRAY_BUFFER, scene.view.reverseOrder ? reversedElements : elements);
    gl.DrawElements(GL_TRIANGLES, indexCount, GL_UNSIGNED_INT, nullptr);
    gl.BindVertexArray(0);
    gl.PolygonMode(GL_FRONT_AND_BACK, GL_FILL);
    if (scene.view.normals) {
        program.bindLine(gl, matrices.mvp, {1, 201.0F / 255, 107.0F / 255});
        normals.draw(gl);
    }
}
```

`indexCount` bằng số phần tử EBO, không phải số vertex hay triangle. `GL_UNSIGNED_INT` khớp `uint32_t`. `nullptr` là byte offset 0 trong EBO đang gắn với VAO, không phải địa chỉ một mảng CPU.

Trước draw, depth và culling được đặt theo scene. Sau wireframe, polygon mode được trả về fill để không làm hỏng quad presenter khi chuyển sang F1. OpenGL state tồn tại qua các draw call; đừng mặc định nhánh trước đã để lại state phù hợp.

Nếu chỉ GPU mất hình: kiểm shader log, VAO/EBO binding, index count/type rồi mới xem matrix. Nếu chỉ sphere lỗi còn cube đúng, đừng kết luận renderer đã đúng — rất có thể count vẫn đang cố định hoặc size buffer tính sai.

## Thử làm sai để hiểu đúng

Trong bản thử, thay `indexCount` ở draw bằng 36. Cube có vẻ đúng nhưng sphere chỉ còn một phần rất nhỏ. Khôi phục count theo mesh.

Tiếp đó, detach EBO khi VAO của model còn active. Kỳ vọng draw lỗi hoặc mất geometry. Khôi phục binding và chạy lại; không thêm một mảng index CPU vào draw call để lách lỗi EBO.

## Tự kiểm tra kết quả

- [ ] Sphere giữ đủ 2.976 tam giác ở cả F1 và F2.
- [ ] VBO/EBO được tạo ở startup, không tạo khi chuyển renderer.
- [ ] VAO nhớ position/normal đúng stride/offset và đúng EBO.
- [ ] Draw count là số index của model đang chọn.
- [ ] Uniform/shader errors có diagnostics; không dùng program 0.
- [ ] VBO/EBO/VAO/program được destroy trước context.
