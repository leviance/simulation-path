# Một camera, cùng Model–View–Projection

## Vấn đề cần giải quyết

Hai backend có thể đọc cùng mesh nhưng cho ảnh lệch nếu mỗi bên tự tính một matrix, dùng FOV khác hoặc hiểu trục Z khác nhau. Ta cần một bộ phép biến đổi mà CPU và GLSL cùng dùng.

Ta cũng phải phân biệt xoay model với orbit camera. Nếu kéo chuột làm cả lưới tọa độ xoay theo model, có thể bạn đang sửa view trong khi người dùng chọn “Xoay mô hình”.

## Hiểu ý tưởng trước khi viết code

Quy ước trong project này:

| Đại lượng | Quy ước |
| --- | --- |
| Hệ tọa độ | Right-handed; camera mặc định ở +Z, nhìn về -Z |
| Model | Xoay Y trước rồi X: $M=R_xR_y$ với vector cột |
| Matrix | Column-major, `values[column*4+row]` |
| Clip | $p_{clip}=PVMp$, $-w\le x,y,z\le w$ |
| Screen CPU | Gốc trên trái; Y hướng xuống |
| OpenGL viewport | Gốc dưới trái; readback cần đảo hàng |
| Depth | NDC z [-1,1] → window depth [0,1] |

Viewer Project 21 từng dùng camera nhìn theo +Z. Ở đây ta chuyển rõ sang convention OpenGL thay vì âm thầm đổi dấu riêng trong shader. Dữ liệu model và cách xoay Y-rồi-X được giữ; cả hai backend dùng camera mới như nhau.

## Viết code từng bước

### 1. Nhớ storage khác với thứ tự phép nhân

```cpp title="include/pipeline.hpp — struct Mat4"
struct Mat4 {
    std::array<float, 16> values{};
};
```

```cpp title="include/pipeline.hpp — Mat4 multiply"
inline Mat4 multiply(const Mat4& left, const Mat4& right) {
    Mat4 result{};
    for (int column = 0; column < 4; ++column) {
        for (int row = 0; row < 4; ++row) {
            float value = 0.0F;
            for (int inner = 0; inner < 4; ++inner) {
                value += left.values[std::size_t(inner * 4 + row)] * right.values[std::size_t(column * 4 + inner)];
            }
            result.values[std::size_t(column * 4 + row)] = value;
        }
    }
    return result;
}
```

Column-major chỉ nói vị trí phần tử trong bộ nhớ. Thứ tự `P*V*M` lại nói model được áp dụng trước, view sau và projection cuối. Không đảo thứ tự nhân để “bù” cho storage.

CPU gọi `transform(mvp, position)`; GPU nhận đúng array 16 float bằng `UniformMatrix4fv(..., GL_FALSE, ...)` rồi nhân `uMvp * vec4`. Không có bước transpose riêng ở một backend.

### 2. Tạo camera từ một target chung

```cpp title="include/viewer-scene.hpp — ViewerMatrices viewerMatrices"
inline ViewerMatrices viewerMatrices(const ViewerScene& scene, float aspect) {
    const float lightSquared = scene.lightX * scene.lightX + scene.lightY * scene.lightY + scene.lightZ * scene.lightZ;
    if (!std::isfinite(scene.view.angleX) || !std::isfinite(scene.view.angleY) ||
        !std::isfinite(scene.view.cameraYaw) || !std::isfinite(scene.view.cameraPitch) ||
        !std::isfinite(scene.targetX) || !std::isfinite(scene.targetY) || !std::isfinite(scene.targetZ) ||
        !std::isfinite(scene.baseRed) || !std::isfinite(scene.baseGreen) || !std::isfinite(scene.baseBlue) ||
        (scene.lit && (!std::isfinite(lightSquared) || lightSquared <= 1e-12F)) ||
        !std::isfinite(aspect) || aspect <= 0 || !std::isfinite(scene.nearPlane) || !std::isfinite(scene.farPlane) ||
        scene.nearPlane <= 0 || scene.farPlane <= scene.nearPlane || !std::isfinite(scene.view.distance) || scene.view.distance <= 0 ||
        !std::isfinite(scene.verticalFov) || scene.verticalFov <= 0 || scene.verticalFov >= std::numbers::pi_v<float>) {
        throw std::invalid_argument("Invalid viewer projection");
    }
    ViewerMatrices result{};
    // Same Y-then-X model rotation as Project 21; column vectors multiply right-to-left.
    result.model = multiply(rotationXMatrix(float(scene.view.angleX)), rotationYMatrix(float(scene.view.angleY)));
    const float yaw = float(scene.view.cameraYaw), pitch = float(scene.view.cameraPitch), distance = float(scene.view.distance);
    const Vec3 target{scene.targetX, scene.targetY, scene.targetZ};
    result.eye = {target.x + distance * std::sin(yaw) * std::cos(pitch), target.y + distance * std::sin(pitch), target.z + distance * std::cos(yaw) * std::cos(pitch)};
    const Vec3 forward = unitVector(subtractVector(target, result.eye));
    result.right = unitVector(crossVector(forward, {0, 1, 0}));
    result.up = crossVector(result.right, forward);
    const auto right = result.right, up = result.up;
    // Right-handed view: forward is -Z; OpenGL clip depth is [-w,+w].
    result.view.values = {right.x, up.x, -forward.x, 0, right.y, up.y, -forward.y, 0, right.z, up.z, -forward.z, 0, -dotVector(right, result.eye), -dotVector(up, result.eye), dotVector(forward, result.eye), 1};
    result.projection = perspectiveMatrix(scene.verticalFov, aspect, scene.nearPlane, scene.farPlane);
    result.mvp = multiply(result.projection, multiply(result.view, result.model));
    return result;
}
```

Camera orbit nằm trên cầu quanh `target` với yaw/pitch/distance. `forward` hướng từ eye đến target, `right` và `up` tạo cơ sở camera. View matrix đưa camera về gốc và hướng nhìn về -Z.

Đầu hàm kiểm projection và các giá trị hữu hạn. Near phải dương, far lớn hơn near, aspect dương. Không đưa matrix lỗi vào cả hai renderer rồi coi “cùng sai” là đúng.

### 3. Pan theo mặt phẳng camera

```cpp title="include/viewer-scene.hpp — void panViewer"
inline void panViewer(ViewerScene& scene, float dx, float dy, int pixelHeight) {
    if (pixelHeight <= 0 || !std::isfinite(dx) || !std::isfinite(dy))
        return;
    const auto matrices = viewerMatrices(scene, 1);
    const float metresPerPixel = 2 * float(scene.view.distance) * std::tan(scene.verticalFov * 0.5F) / float(pixelHeight);
    scene.targetX += (-dx * matrices.right.x + dy * matrices.up.x) * metresPerPixel;
    scene.targetY += (-dx * matrices.right.y + dy * matrices.up.y) * metresPerPixel;
    scene.targetZ += (-dx * matrices.right.z + dy * matrices.up.z) * metresPerPixel;
    scene.view.paused = true;
}
```

Độ dịch world ứng với một pixel tại target là:

$$
s=\frac{2d\tan(\mathrm{FOV}_y/2)}{H}.
$$

`H` là chiều cao **vùng model theo pixel**, không bao gồm bảng thống kê. Di chuyển target theo right/up giữ hướng quan sát và không sửa góc model. Input logical phải đổi sang framebuffer pixels trước khi gọi.

### 4. Zoom hữu hạn bằng khoảng cách

```cpp title="include/viewer-scene.hpp — void zoomViewer"
inline void zoomViewer(ViewerState& state, double wheel) {
    if (!std::isfinite(wheel))
        return;
    state.distance = std::clamp(state.distance * std::exp(-std::clamp(wheel, -50.0, 50.0) * 0.12), 0.35, 40.0);
}
```

Mỗi nấc wheel nhân khoảng cách theo hàm mũ. Clamp giữ distance trong [0,35; 40]; near clipping vẫn làm việc khi camera tới gần hoặc đi vào model. Không ép mọi vertex có `w` âm trở thành dương để “cứu” ảnh.

V đổi chế độ kéo trái. Kéo phải để pan, wheel zoom, Home đặt lại camera; R đặt lại pose/options nhưng giữ model đang chọn và backend. Thử cùng một góc nhìn ở F1 và F2.

Aspect là width/modelHeight sau khi trừ 100 pixel của HUD. Dù HUD chưa có ở checkpoint này, vùng vẽ đã được dành riêng như bản final. Khi resize, matrix phải dùng kích thước vùng vẽ mới cùng lúc viewport đổi.

## Thử làm sai để hiểu đúng

1. Đổi transpose từ GL_FALSE sang GL_TRUE trong bản thử. Nếu ảnh mất, đừng sửa tiếp thứ tự matrix ở C++ — hãy khôi phục và trace một vertex.
2. Thử tính pan bằng window height gồm cả HUD, hoặc dùng logical height cho framebuffer high-DPI. So độ dịch ở hai kích thước cửa sổ. Khôi phục chiều cao vùng model và phép đổi logical → pixel.
