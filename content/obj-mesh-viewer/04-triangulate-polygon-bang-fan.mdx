# Chia polygon thành triangle fan

## Vấn đề cần giải quyết

Cube có sáu mặt vuông, nhưng rasterizer chỉ nhận triangle. Từ chối mọi face bốn corner sẽ khiến viewer không mở được một dạng OBJ rất thường gặp. Ta cần chuyển polygon sang triangle **một lần khi đọc file**, không chia lại mỗi frame.

Bài này giữ parser position/index từ các bài trước, thay bước “face phải có đúng ba corner” bằng bước kiểm polygon rồi tạo fan.

## Hiểu ý tưởng trước khi viết code

Với polygon phẳng, lồi có N corner theo thứ tự quanh biên, giữ corner 0 làm mốc:

```text title="Triangle fan — quad và pentagon"
quad:      (0,1,2), (0,2,3)
pentagon:  (0,1,2), (0,2,3), (0,3,4)
```

Số triangle là N−2. Các triangle giữ nguyên winding của polygon; đừng sort index theo trị số. Số vertex trong file không nói gì về thứ tự không gian.

Fan **không phải thuật toán triangulation cho mọi polygon**. Với mặt lõm, đường chéo từ corner 0 có thể chạy ra ngoài polygon. Với mặt không phẳng, “mặt” phụ thuộc cách chọn đường chéo. Tiny parser này báo lỗi cho hai trường hợp ấy; hãy export triangulated OBJ nếu model dùng chúng.

Preset pentagon dùng negative index để nhắc lại bài trước. Di chuyển thanh chọn triangle từ 0 tới 2: mỗi triangle màu vàng vẫn dùng chung corner 0. Sau đó chọn cube; sáu source face phải tạo 12 triangle.

## Viết code từng bước

### Bước 1 — Đừng thêm triangle khi vẫn đang đọc corner

Trong nhánh f, `corners` là vector tạm. Parser chỉ đi tiếp sau khi mọi token đã resolve, số corner từ 3 tới 128 và `faceValid` còn đúng. Nếu corner cuối là `999`, không triangle nào của face ấy được giữ lại.

Giới hạn 128 corner giúp thao tác kiểm polygon có chi phí hữu hạn. Nó được báo bằng diagnostic, không cắt bớt polygon để “cố mở”.

### Bước 2 — Kiểm phạm vi của triangle fan

```cpp title="include/obj-parser.hpp — chỉ fan-fill polygon phù hợp"
inline bool isConvexPlanarFace(const ObjMesh& mesh, const std::vector<std::size_t>& corners) {
    const Vec3 origin = mesh.positions[corners[0]];
    Vec3 area{};
    double extent = 0.0;
    for (std::size_t index = 0; index < corners.size(); ++index) {
        const Vec3 a = mesh.positions[corners[index]] - origin;
        const Vec3 b = mesh.positions[corners[(index + 1) % corners.size()]] - origin;
        area = area + cross(a, b);
        extent = std::max(extent, length(a));
    }
    const auto normal = normalized(area, extent * extent * 1e-12);
    if (!normal) {
        return false;
    }
    const double tolerance = std::max(1e-12, extent * 1e-6);
    for (std::size_t index = 0; index < corners.size(); ++index) {
        const Vec3 a = mesh.positions[corners[index]];
        const Vec3 b = mesh.positions[corners[(index + 1) % corners.size()]];
        const Vec3 c = mesh.positions[corners[(index + 2) % corners.size()]];
        if (std::abs(dot(a - origin, *normal)) > tolerance || dot(cross(b - a, c - b), *normal) < -tolerance * extent) {
            return false;
        }
        for (std::size_t other = index + 1; other < corners.size(); ++other) {
            if (length(a - mesh.positions[corners[other]]) < tolerance) {
                return false;
            }
        }
        // Mọi corner phải cùng phía mỗi cạnh; kiểm này còn chặn polygon tự cắt.
        for (const auto corner : corners) {
            if (dot(cross(b - a, mesh.positions[corner] - a), *normal) < -tolerance * extent) {
                return false;
            }
        }
    }
    return true;
}
```

Vector area là tổng cross product của các cạnh quanh origin tạm. Chuẩn hóa nó cho ta normal của mặt. Mỗi corner phải nằm gần mặt phẳng ấy; các lần rẽ liên tiếp không được quay ngược hướng normal. Phần kiểm corner trùng tránh cạnh có độ dài 0.

Tolerance tăng theo kích thước face để không dùng một epsilon tuyệt đối cho mọi đơn vị. Đây vẫn là tiny parser cho polygon phẳng/lồi đơn giản, không phải công cụ sửa mesh tự cắt. Với dữ liệu ngoài phạm vi, báo lỗi có ích hơn một model trông “gần đúng”.

### Bước 3 — Tạo đúng N−2 triangle

```cpp title="include/obj-parser.hpp — giữ corner đầu và winding"
inline void appendTriangleFan(
    ObjMesh& mesh,
    const std::vector<std::size_t>& corners,
    std::size_t sourceFace,
    std::size_t sourceLine
) {
    for (std::size_t index = 1; index + 1 < corners.size(); ++index) {
        mesh.triangles.push_back({
            {corners[0], corners[index], corners[index + 1]},
            sourceFace,
            sourceLine,
        });
    }
}
```

Vòng lặp bắt đầu ở index 1 và dừng khi index + 1 chạm cuối vector. Với N = 4, hai lần thêm là {0,1,2} và {0,2,3}. Mỗi triangle giữ cùng sourceFace/sourceLine; vì thế đếm source face và đếm triangle là hai thống kê khác nhau.

### Bước 4 — Chỉ fan sau khi validation thành công

```cpp title="include/obj-parser.hpp — face sai không tạo geometry một phần"
if (!isConvexPlanarFace(result.mesh, corners)) {
    addDiagnostic(result, lineNumber, "face phải phẳng, lồi và không có corner trùng");
    continue;
}
```

Ngay sau nhánh này, parser gọi `appendTriangleFan(result.mesh, corners, result.sourceFaceCount, lineNumber)`. Wireframe không cần biết triangle từng đến từ một quad hay một face tam giác.

## Thử làm sai để hiểu đúng

1. Thêm một corner lõm vào preset pentagon bằng cách kéo một vertex vào giữa hình trong source. Parser phải báo face không phù hợp, không tô phần nằm ngoài polygon. Đổi Z của một corner trong quad thành 0.2 để tạo face không phẳng; cũng phải báo lỗi.

2. Đảo **toàn bộ** thứ tự corner của quad. Triangle count không đổi nhưng winding đổi. Sau bài 6, normal/culling phải phản ánh điều đó.

## Tự kiểm tra kết quả

- Triangle, quad, pentagon tạo lần lượt 1, 2, 3 triangle.
- Mọi triangle con giữ sourceFace/sourceLine và cùng winding.
- Corner sai ở cuối không để lại triangle dở dang.
- Face lõm, không phẳng hoặc có corner trùng được báo rõ; không hứa hỗ trợ mọi polygon.
