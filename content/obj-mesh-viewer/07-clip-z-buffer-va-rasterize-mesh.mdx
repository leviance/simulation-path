# Đưa toàn bộ mesh qua clip và Z-buffer

## Vấn đề cần giải quyết

Painter chỉ ghi màu theo thứ tự face trong file. Face nằm xa nhưng được đọc sau vẫn có thể đè lên face gần. Đến gần model còn lộ vấn đề khác: một vertex đi qua near plane có thể làm cả triangle biến mất nếu ta chỉ kiểm từng vertex rồi bỏ face.

Bài này ghép near clipping → projection → top-left coverage → Z-buffer cho mọi triangle của OBJ. Đây là pipeline đã học ở Project 17–19, nay cần hoạt động với hàng nghìn triangle chứ không chỉ vài mặt được chọn sẵn.

## Hiểu ý tưởng trước khi viết code

Near plane là z = 0.7 trong camera space. Clip **trước** phép chia perspective. Một triangle cắt plane có thể thành polygon bốn corner, rồi được chia thành hai triangle để rasterize.

Với cạnh từ S tới E cắt plane:

$$
t=\frac{z_{near}-S_z}{E_z-S_z},\qquad P=S+t(E-S)
$$

Depth lưu trong buffer là NDC depth, không phải raw camera Z:

$$
d(z)=\frac{f}{f-n}-\frac{nf}{(f-n)z},\qquad n=0.7,\ f=20
$$

Sau projection, NDC depth được nội suy bằng barycentric weights tại tâm pixel. Giá trị nhỏ hơn thắng depth test. Đừng nội suy camera Z tuyến tính trên màn hình; Project 20 đã cho thấy phép chiếu thay đổi cách nội suy một thuộc tính 3D.

## Viết code từng bước

### Bước 1 — Tính một giao điểm nhất quán cho cạnh chung

```cpp title="include/render.hpp — đưa giao điểm đúng lên near plane"
inline Vec3 intersectNearPlane(Vec3 start, Vec3 end, double nearPlane) {
    // Cạnh dùng chung luôn được tính theo cùng chiều để khớp bit giao điểm.
    if (start.z > end.z) {
        std::swap(start, end);
    }
    const double denominator = end.z - start.z;
    if (std::abs(denominator) <= 1e-12) {
        return {start.x, start.y, nearPlane};
    }
    const double t = std::clamp((nearPlane - start.z) / denominator, 0.0, 1.0);
    Vec3 result = start + (end - start) * t;
    result.z = nearPlane;
    return result;
}
```

Đổi thứ tự hai đầu cạnh theo Z trước khi tính giúp hai triangle dùng chung cạnh nhận cùng cách làm tròn. Gán result.z về nearPlane để phép kiểm projection không loại một điểm vì sai số rất nhỏ ở giao tuyến.

### Bước 2 — Clip polygon rồi mới chia lại

```cpp title="include/render.hpp — Sutherland–Hodgman với một plane"
inline std::vector<Vec3> clipTriangleToNearPlane(
    Vec3 a,
    Vec3 b,
    Vec3 c,
    double nearPlane
) {
    const std::array<Vec3, 3> input{a, b, c};
    std::vector<Vec3> output{};
    Vec3 previous = input.back();
    bool previousInside = previous.z >= nearPlane;
    for (const Vec3 current : input) {
        const bool currentInside = current.z >= nearPlane;
        if (previousInside && currentInside) {
            output.push_back(current);
        } else if (previousInside && !currentInside) {
            output.push_back(intersectNearPlane(previous, current, nearPlane));
        } else if (!previousInside && currentInside) {
            output.push_back(intersectNearPlane(previous, current, nearPlane));
            output.push_back(current);
        }
        previous = current;
        previousInside = currentInside;
    }
    return output;
}
```

Đọc vòng lặp theo hai câu hỏi: cạnh có cắt plane không, và endpoint hiện tại có nằm trong không. Output giữ winding, có thể rỗng, có ba hoặc bốn corner. Không clamp Z của vertex ngoài vào plane: cách đó kéo méo geometry thay vì cắt cạnh.

### Bước 3 — Ghép các bước thành một renderer dùng chung

Đây là toàn bộ hàm render solid ở checkpoint 7. Đọc theo các đoạn, đừng bỏ qua callback cuối vì đó là nơi depth thực sự quyết định màu pixel:

```cpp title="include/render.hpp — parser mesh đi tới color và depth buffer"
inline RenderStats renderObjMesh(
    const ObjMesh& mesh,
    int width,
    int height,
    const RenderOptions& options,
    std::vector<std::uint32_t>& colors,
    DepthBuffer& depths
) {
    constexpr std::uint32_t clearColor = 0x090f1dffU;
    colors.assign(std::size_t(width) * std::size_t(height), clearColor);
    if (depths.width != width || depths.height != height) {
        depths.resize(width, height);
    } else {
        depths.clear();
    }

    RenderStats stats{};
    stats.sourceTriangles = mesh.triangles.size();
    const Color base{92, 190, 246, 255};
    const OrbitCamera camera{options.cameraYaw, options.cameraPitch, options.distance};
    const Vec3 lightDirection = worldToCamera({-0.45, -0.75, -1.0}, camera) - worldToCamera({}, camera);
    // Mỗi position chỉ transform một lần, kể cả khi nhiều face cùng tham chiếu nó.
    std::vector<Vec3> cameraPositions{};
    cameraPositions.reserve(mesh.positions.size());
    for (const Vec3 position : mesh.positions) {
        cameraPositions.push_back(worldToCamera(rotateModelPoint(position, options.angleX, options.angleY), camera));
    }
    for (std::size_t position = 0; position < mesh.triangles.size(); ++position) {
        std::size_t triangleIndex = position;
        if (options.reverseOrder) {
            triangleIndex = mesh.triangles.size() - 1 - position;
        }
        const ObjTriangle& source = mesh.triangles[triangleIndex];
        const Vec3 a = cameraPositions[source.indices[0]];
        const Vec3 b = cameraPositions[source.indices[1]];
        const Vec3 c = cameraPositions[source.indices[2]];
        const std::optional<Vec3> normal = faceNormal(a, b, c);
        if (!normal) {
            ++stats.degenerateTriangles;
            continue;
        }
        if (options.cullBackfaces && !isFrontFacing(*normal, a, b, c)) {
            ++stats.culledTriangles;
            continue;
        }

        const std::vector<Vec3> polygon = clipTriangleToNearPlane(
            a,
            b,
            c,
            options.nearPlane
        );
        if (polygon.size() < 3) {
            ++stats.clippedTriangles;
            continue;
        }
        if (polygon.size() != 3) {
            ++stats.clippedTriangles;
        }
        const Color color = shadeColor(base, lambertIntensity(*normal, lightDirection));
        for (std::size_t fanIndex = 1; fanIndex + 1 < polygon.size(); ++fanIndex) {
            const std::optional<ScreenVertex> screenA = projectVertex(
                polygon[0],
                width,
                height,
                options.nearPlane
            );
            const std::optional<ScreenVertex> screenB = projectVertex(
                polygon[fanIndex],
                width,
                height,
                options.nearPlane
            );
            const std::optional<ScreenVertex> screenC = projectVertex(
                polygon[fanIndex + 1],
                width,
                height,
                options.nearPlane
            );
            if (!screenA || !screenB || !screenC) {
                continue;
            }
            ++stats.rasterizedTriangles;
            stats.coveredFragments += rasterizeTriangle(
                {*screenA, *screenB, *screenC, color, source.sourceFace},
                width,
                height,
                [&](int x, int y, Barycentric weights, const ScreenTriangle& triangle) {
                    const std::size_t index = depths.index(x, y);
                    const double newDepth = interpolateDepth(triangle, weights);
                    if (!std::isfinite(newDepth) || newDepth < -1e-9 || newDepth > 1.0 || newDepth >= depths.values[index]) {
                        ++stats.rejectedFragments;
                        return;
                    }
                    depths.values[index] = std::max(0.0, newDepth);
                    colors[index] = packColor(triangle.color);
                    ++stats.passedFragments;
                }
            );
        }
    }
    return stats;
}
```

Đầu hàm, color/depth được clear cho frame mới. Position dùng chung được transform **một lần** vào cameraPositions, rồi mỗi face chỉ tra index. Với model 2.976 triangle, cách này tránh tính sin/cos và view transform lặp lại ba lần cho mỗi face.

Sau culling, near clipping có thể tạo một polygon. Vòng fan chiếu từng triangle con và gửi vào rasterizer. Rasterizer chuẩn hóa winding cùng dữ liệu vertex; callback nhận đúng ScreenTriangle tương ứng với weights, không dùng thứ tự vertex cũ.

Ở callback, chỉ fragment có depth hữu hạn, trong miền hợp lệ và nhỏ hơn depth đã lưu mới được ghi. Color và depth dùng cùng index. Nếu chỉ ghi color mà quên cập nhật depth, model có thể “trông đúng” ở một góc nhưng mất order independence.

## Thử làm sai để hiểu đúng

1. Trong một bản sao, bỏ phép ghi depth nhưng giữ phép so depth. CTest so toàn buffer và đối chứng ray–triangle phải bắt lỗi; một ảnh ở góc thuận tiện không đủ chứng minh renderer đúng.

2. Đổi clip thành “nếu một vertex ở ngoài thì bỏ cả face”. Khi đến gần sphere, vùng model biến mất thành từng triangle lớn. So với bản đúng: giao tuyến near plane phải cắt liên tục.

## Tự kiểm tra kết quả

- Không vertex nằm sau near plane được gửi vào projection.
- Color/depth có cùng kích thước; mọi depth lưu hữu hạn trong [0,1].
- Đảo thứ tự face không đổi color/depth của model, không chỉ tổng số pixel.
- Model 2.976 triangle render được ở viewport native.
- Depth tại tâm pixel khớp đối chứng ray–triangle độc lập, kể cả khi model cắt near plane.
