# Đọc face và đổi index 1-based

## Vấn đề cần giải quyết

Point cloud xác nhận ta đọc được tọa độ, nhưng chưa cho biết đâu là cạnh, đâu là mặt. Trong OBJ, dòng `f 1 2 3` nối ba position đã xuất hiện trước đó. Bài này biến dòng ấy thành một triangle và vẽ ba cạnh của nó.

Tiếp tục từ checkpoint 1, không tạo lại window. Phần mới nằm trong `mesh.hpp`, `obj-parser.hpp` và nhánh wireframe của `viewer.hpp`.

## Hiểu ý tưởng trước khi viết code

OBJ đếm từ **1**, còn `std::vector` đếm từ **0**:

$$
index_{vector}=index_{OBJ}-1
$$

Ví dụ, `f 1 9 10` phải truy cập `positions[0]`, `positions[8]`, `positions[9]`. Nếu dùng số trong file làm index trực tiếp, ta bỏ qua position đầu và có thể đọc quá cuối mảng.

Ta không chép ba XYZ vào từng triangle. Triangle chỉ giữ ba index; nhiều mặt có thể dùng chung một position. Đây là indexed mesh.

Chọn một triangle bằng thanh trượt. Chỉ số trước mũi tên là số trong file, sau mũi tên là số dùng trong vector. Thử nhập index 0 để thấy parser từ chối, không âm thầm đổi nó thành 0-based.

## Viết code từng bước

### Bước 1 — Thêm dữ liệu topology

```cpp title="include/mesh.hpp — triangle tham chiếu position thay vì chép tọa độ"
struct ObjTriangle {
    std::array<std::size_t, 3> indices{};
    std::size_t sourceFace{};
    std::size_t sourceLine{};
};
```

`sourceFace` và `sourceLine` ghi xuất xứ của triangle. Chúng chưa cần để vẽ, nhưng sẽ rất hữu ích khi một polygon sinh nhiều triangle hoặc người dùng hỏi lỗi ở dòng nào.

`ObjMesh` giữ `positions` và `triangles` trong hai vector. Parser sở hữu việc kiểm index; renderer chỉ nhận index nội bộ hợp lệ.

### Bước 2 — Đổi và kiểm index tại parser

Ở checkpoint 2, chỉ nhận số nguyên dương không có slash:

```cpp title="include/obj-parser.hpp — đổi 1-based và kiểm phạm vi"
inline std::optional<std::size_t> resolveObjPositionIndex(
    std::string_view token,
    std::size_t positionCount
) {
    if (token.empty()) {
        return std::nullopt;
    }

    // Chỉ nhận bốn dạng v, v/vt, v//vn và v/vt/vn.
    // Thuộc tính chưa dùng vẫn phải có cú pháp integer hợp lệ.
    int rawIndex = 0;
    const char* begin = token.data();
    const char* end = token.data() + token.size();
    const auto parsed = std::from_chars(begin, end, rawIndex);
    if (parsed.ec != std::errc{} || parsed.ptr != end || rawIndex == 0) {
        return std::nullopt;
    }

    if (rawIndex < 1) {
        return std::nullopt;
    }
    const long long resolved = static_cast<long long>(rawIndex) - 1;
    if (resolved < 0 || resolved >= static_cast<long long>(positionCount)) {
        return std::nullopt;
    }
    return static_cast<std::size_t>(resolved);
}
```

`from_chars` trả cả trạng thái lỗi lẫn vị trí dừng. Kiểm `parsed.ptr == end` để `2abc` không bị hiểu là index 2. Ta tính bằng kiểu có dấu trước; chỉ cast sang `size_t` sau khi biết số nằm trong mảng. Nếu cast một số âm quá sớm, nó có thể trở thành số unsigned rất lớn.

### Bước 3 — Chỉ thêm face sau khi đã kiểm đủ corner

Nhánh `f` đọc token vào một vector tạm tên `corners`. Nếu có token sai, ta bỏ **cả face**, không giữ lại hai corner đúng rồi cố nối tiếp. Checkpoint này còn yêu cầu đúng ba corner:

```cpp title="include/obj-parser.hpp — chưa nhận polygon ở mốc triangle đầu tiên"
if (corners.size() != 3) {
    addDiagnostic(result, lineNumber, "checkpoint này mới nhận face có đúng ba corner");
    continue;
}
```

Sau nhánh này, parser thêm `ObjTriangle` với `corners[0..2]`, source face và source line. Bài 4 mới thay phần đó bằng triangle fan.

### Bước 4 — Nối ba cạnh từ chính indexed mesh

```cpp title="include/viewer.hpp — wireframe không có geometry riêng"
inline void drawMeshEdges(Framebuffer& frame, const ObjMesh& mesh, const ViewerState& state) {
    for (const auto& triangle : mesh.triangles) {
        for (std::size_t edge = 0; edge < 3; ++edge) {
            const Vec3 a = modelToCamera(mesh.positions[triangle.indices[edge]], state);
            const Vec3 b = modelToCamera(mesh.positions[triangle.indices[(edge + 1) % 3]], state);
            drawCameraLine(frame, a, b, 0x70d6ffffU);
        }
    }
}
```

Với edge = 0, 1, 2, biểu thức `(edge + 1) % 3` lần lượt cho cạnh 0→1, 1→2, 2→0. `drawCameraLine` clip đoạn thẳng trước khi chiếu, rồi mới vẽ vào CPU framebuffer. Geometry của solid sau này cũng lấy từ mesh này.

## Thử làm sai để hiểu đúng

1. Đổi một face thành `f 1 0 3`, rồi thành `f 1 2 999`. Cả hai phải báo dòng lỗi và không thêm face. Đổi thành `f 1 2 3 4`: checkpoint 2 báo chưa hỗ trợ polygon, dù bốn index đều hợp lệ.

2. Sau đó sửa phép trừ `rawIndex - 1` trong một bản sao thành `rawIndex`. Đừng chỉ nhìn model có “na ná” rocket: test index của face đầu phải phát hiện sai ngay.

## Tự kiểm tra kết quả

- `f 1 2 3` tạo đúng bộ index {0,1,2}.
- Index 0, số ngoài mảng và token có ký tự thừa bị từ chối.
- Một face hỏng không tạo triangle dở dang.
- Rocket vẫn có 18 position, nay có 32 triangle; không hard-code lại geometry trong hàm vẽ.
