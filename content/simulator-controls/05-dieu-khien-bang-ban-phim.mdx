# Rời chuột mà vẫn điều khiển được toàn bộ bảng

## Vấn đề cần giải quyết

Một người vừa chỉnh Radius bằng bàn phím. Chuột vô tình nằm trên Reset. Nhấn Enter phải tác động vào đâu? Nếu chương trình dựa vào hover, nó có thể xóa cả thí nghiệm.

## Hiểu ý tưởng trước khi viết code

Lưu `focus` riêng với `hot` và `active`. Viền vàng trả lời câu hỏi phím sắp gửi tới ai. Tab đi theo thứ tự Pause, Reset, Neighbors, Radius, Separation; Shift+Tab đi ngược. Đừng dùng khoảng cách giữa các hình để đoán thứ tự này.

## Viết code từng bước

### Dời focus theo danh sách control

Xử lý trường hợp chưa có focus trước khi tính chỉ số vòng. Cộng kích thước danh sách trước phép modulo để đi ngược từ phần tử đầu vẫn tới được phần tử cuối.

{/* snippet include/controls.hpp#focus-order */}

```cpp title="include/controls.hpp — Dời focus theo danh sách control"
inline void nextFocus(Ui& ui, bool backwards) {
    const auto it = std::find(order.begin(), order.end(), ui.focus);
    if (it == order.end()) {
        ui.focus = order.front();
        if (backwards) ui.focus = order.back();
        return;
    }
    const int count = int(order.size());
    int step = 1;
    if (backwards) step = -1;
    ui.focus = order[(int(it - order.begin()) + count + step) % count];
}
```

### Giữ phím không biến thành nhiều lần click

Enter hoặc Space chỉ kích hoạt button/checkbox ở lần key-down đầu. Arrow có thể lặp để tinh chỉnh slider; Home và End đưa về hai đầu. Giá trị đi qua cùng `setSlider` với chuột.

{/* snippet include/controls.hpp#key-action */}

```cpp title="include/controls.hpp — Giữ phím không biến thành nhiều lần click"
if (key == Key::Space || key == Key::Enter) {
    if (!isSlider(ui.focus) && !repeat) activate(model, ui.focus);
    return true;
}
```

## Thử làm sai để hiểu đúng

Gán `focus = hot` mỗi khi chuột di chuyển. Để con trỏ nằm trên bàn rồi chỉnh radius bằng phím: chỉ một dịch chuyển nhỏ cũng có thể làm focus nhảy mất.

## Tự kiểm tra kết quả

Shift+Tab từ nút đầu quay về thanh cuối. Giữ Space không làm checkbox nhấp nháy. Nhấn phím mũi tên trên slider không truyền một thao tác thứ hai xuống cảnh.
