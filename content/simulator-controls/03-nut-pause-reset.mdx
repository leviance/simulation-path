# Một lần thả chuột, một lệnh cho đàn chim

## Vấn đề cần giải quyết

Bạn định bấm Reset nhưng đổi ý khi ngón tay còn giữ chuột. Thả ngoài nút phải cho phép hủy, không được làm cả đàn quay về điểm xuất phát.

## Hiểu ý tưởng trước khi viết code

`hot` có thể đổi liên tục khi di chuột, còn `active` nhớ control nơi thao tác bắt đầu. Chỉ khi hai giá trị khớp ở lúc thả ta mới chạy lệnh. Checkbox cũng là một lệnh, nhưng nó đổi cách nhìn đàn, không đổi cách chim bay.

## Viết code từng bước

### Chốt một lần click khi thả

Giữ lại ID đã nhấn trước khi xóa `active`. Tính lại `hot` tại tọa độ release; đừng tin sự kiện motion cuối vì chuột có thể vừa đi qua nhiều pixel. Một release lẻ không được kích hoạt button.

{/* snippet include/controls.hpp#release-once */}

```cpp title="include/controls.hpp — Chốt một lần click khi thả"
inline void pointerUp(Model& model, Ui& ui, Point point) {
    const Control pressed = ui.active;
    ui.active = Control::None;
    ui.hot = hitTest(point);
    if (pressed != Control::None && pressed == ui.hot)
        activate(model, pressed);
}
```

### Lấy lại đúng đàn ở tick 0

Reset dựng lại preset: seed 28, bán kính 64, trọng số tách 1,5 và vòng quan sát bật. Chỉ giữ ý định chạy hay dừng của người dùng. `clockRevision` báo cho vòng lặp bỏ khoảng thời gian thuộc lần chạy cũ.

{/* snippet include/simulation.hpp#reset-flock */}

```cpp title="include/simulation.hpp — Lấy lại đúng đàn ở tick 0"
inline void resetSimulation(Model& model) {
    const bool wasPaused = model.paused;
    const auto revision = model.clockRevision + 1;
    model = Model{};
    model.paused = wasPaused;
    model.clockRevision = revision;
}
```

## Thử làm sai để hiểu đúng

Tạm gọi `activate` ngay trong phần vẽ nếu chuột còn giữ. Giữ checkbox nửa giây: nó đảo đi đảo lại theo FPS. Đưa việc phát lệnh về đúng cạnh release.

## Tự kiểm tra kết quả

Nhấn Reset, kéo sang Pause rồi thả: cả hai nút đều không chạy. Bấm checkbox một lần chỉ đổi lớp quan sát một lần. Pause không cản hover hay Reset.
