# Cho đàn chim bay trước khi lắp bảng điều khiển

## Vấn đề cần giải quyết

Giả sử một con chim vừa đổi hướng khi bạn kéo thanh trượt. Làm sao biết đó là tác dụng của ngón tay, chứ không phải vì máy vừa vẽ chậm một khung hình? Ta cần một đàn chim có thể dừng lại và tiến đúng một bước trước khi làm bất kỳ chiếc nút nào.

## Hiểu ý tưởng trước khi viết code

Mở `starter`. Bạn sẽ thấy 192 con chim đứng yên. Mỗi hình hai cánh được xoay theo vận tốc của đúng một cá thể. `include/boids` và `include/grid` đi kèm ZIP là phần đã học ở Project 28: ta dùng lại chúng chứ không bắt đầu bằng việc chép lại solver. Việc còn thiếu là nối đồng hồ với đàn.

## Viết code từng bước

### Đọc đồng hồ, chuyển nano giây thành giây

Giữ thời điểm khung trước trong `previous`. Lấy hiệu hai lần đọc, sau đó cập nhật `previous` ngay. Phần vẽ vẫn chạy cả lúc Pause: dừng chim không có nghĩa là dừng cả cửa sổ.

{/* snippet src/main.cpp#frame-loop */}

```cpp title="src/main.cpp — Đọc đồng hồ, chuyển nano giây thành giây"
const Uint64 now = SDL_GetTicksNS();
double elapsed = double(now - previous) / 1e9;
previous = now;
lab::advance(model, elapsed);
```

### Một lần bấm N tương ứng một bước vật lý

Một bước là 1/60 giây, đúng như ở Project 28. Nếu mới trôi qua nửa bước, giữ lại phần dư. Nếu bạn kéo cửa sổ làm một frame quá dài, chỉ nhận tối đa 0,1 giây và xử lý tối đa sáu bước: UI không phải ngồi đợi solver chạy bù.

{/* snippet include/simulation.hpp#fixed-clock */}

```cpp title="include/simulation.hpp — Một lần bấm N tương ứng một bước vật lý"
inline void stepPhysics(Model& model) {
    model.colony.step();
    ++model.ticks;
}

inline int advance(Model& model, double elapsed) {
    if (model.paused || !std::isfinite(elapsed) || elapsed <= 0)
        return 0;
    model.accumulator += std::min(elapsed, 0.1);
    int count = 0;
    while (model.accumulator + 1e-12 >= fixedDt && count < 6) {
        stepPhysics(model);
        model.accumulator = std::max(0.0, model.accumulator - fixedDt);
        ++count;
    }
    return count;
}
```

## Ghép các phần lại

Chạy checkpoint 1, bấm Space để đóng băng đàn rồi bấm N. Số tick tăng một; chim rời vị trí cũ. N không làm đàn tự chạy trở lại.

```bash title="Terminal — cấu hình từ thư mục chứa CMakeLists.txt"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_65_checkpoint_1 --parallel 2
.\build\Release\project_65_checkpoint_1.exe
```

## Thử làm sai để hiểu đúng

Thử thay `elapsed` bằng một bước cố định cho mỗi lượt vẽ. Cùng mười giây ngoài đời, máy vẽ 120 FPS sẽ cho đàn đi xa gần gấp đôi máy vẽ 60 FPS.

## Tự kiểm tra kết quả

Pause giữ nguyên cả vị trí lẫn số tick. Bấm N ba lần tăng đúng ba tick. Thả Space sau khi giữ lâu không làm ứng dụng chạy bù khoảng thời gian đang dừng.

## Bài tập mở rộng

Tạm log số tick sau 60 frame giả lập dài 1/60 s và sau 120 frame dài 1/120 s. Hai kết quả phải bằng nhau; số lần gọi hàm vẽ thì không.
