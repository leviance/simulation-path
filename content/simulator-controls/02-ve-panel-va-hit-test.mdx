# Tô sáng đúng nút dưới con trỏ

## Vấn đề cần giải quyết

Nếu phải nhắm thấp hơn hình nút vài pixel mới thấy nó sáng, lỗi thường không nằm ở chuột: phần vẽ và phần bắt chuột đang dùng hai hình chữ nhật khác nhau.

## Hiểu ý tưởng trước khi viết code

Ta chia cửa sổ logic 960×540 thành khung bay và bảng điều khiển. `bounds(Control::Pause)` trả về đúng hình được truyền cho hàm vẽ Pause. Còn `hot` chỉ trả lời “chuột đang ở trên ai?”, chưa phải lệnh dừng đàn.

## Viết code từng bước

### Quy ước bốn cạnh của nút

Lấy nút Pause từ x=676 tới x=788. Điểm x=676 thuộc nút, còn x=788 thì không. Nhờ miền nửa mở này, hai control đặt sát nhau không thể cùng nhận điểm trên đường biên.

{/* snippet include/geometry.hpp#half-open */}

```cpp title="include/geometry.hpp — Quy ước bốn cạnh của nút"
inline bool contains(Rect rect, Point point) {
    // Cạnh phải/dưới không thuộc hình: hai control kề nhau không nhận cùng một điểm.
    return std::isfinite(point.x) && std::isfinite(point.y) && point.x >= rect.x && point.x < rect.x + rect.width && point.y >= rect.y && point.y < rect.y + rect.height;
}
```

### Tìm control từ cùng bảng bounds

Viết danh sách control theo thứ tự đọc. Với mỗi control, hỏi điểm có nằm trong bounds không. Nếu không tìm thấy, trả `None`: khoảng trống trên panel không phải là nút gần nhất. Hai slider chỉ có thể nhận chuột từ bài 4.

{/* snippet include/controls.hpp#shared-hit */}

```cpp title="include/controls.hpp — Tìm control từ cùng bảng bounds"
inline Control hitTest(Point point) {
    for (const auto control : order) {
        if (control == Control::Radius || control == Control::Separation)
            continue;
        if (contains(bounds(control), point))
            return control;
    }
    return Control::None;
}
```

## Thử làm sai để hiểu đúng

Đổi riêng điều kiện cạnh phải từ `<` thành `<=`. Đặt hai control thử nghiệm cạnh nhau: cả hai hình nay đều tự nhận rằng điểm trên đường biên thuộc về chúng.
