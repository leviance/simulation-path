# Co giãn, phản chiếu và ép phẳng hình

## Vấn đề cần giải quyết

Ở bài trước, worldPoint chưa làm gì với local point. Bây giờ ta cho hình rộng hoặc cao hơn, đồng thời giữ nguyên bốn đỉnh gốc. Đây là bước biến đổi đầu tiên; chưa cần ma trận.

## Hiểu ý tưởng trước khi viết code

Co giãn theo từng trục nghĩa là:

$$
x'=s_x x,\qquad y'=s_y y.
$$

Với P2=(1,1), scale(2,0.5) cho (2,0.5): hình rộng gấp đôi, cao bằng một nửa. Scale âm không phải input lỗi; nó đưa điểm sang phía đối diện của trục. Scale bằng 0 làm mất một chiều. Khi đó hình có thể trông như một đoạn thẳng, nhưng chương trình vẫn phải chạy bình thường.

Một phép scale mới luôn bắt đầu từ **local point gốc**, không lấy kết quả frame trước làm đầu vào.

## Viết code từng bước

### Bước 1 — Viết hàm chỉ làm một việc

```cpp title="include/lab.hpp — nhân từng thành phần với scale tương ứng"
inline Vec2 scalePoint(Vec2 point, double scaleX, double scaleY) {
    return {point.x * scaleX, point.y * scaleY};
}
```

Đừng chia cho scale để sửa input về sau; scale=0 là một trường hợp có chủ ý và không có phép nghịch đảo.

### Bước 2 — Đưa tham số vào scene

```cpp title="include/lab.hpp — tham số có giá trị identity mặc định"
struct TransformParameters {
    double scaleX{1.0};
    double scaleY{1.0};
    double angle{};
    double shearX{};
    double shearY{};
    Vec2 translation{};
};
```

Những trường chưa học tới vẫn giữ 0, riêng scaleX/Y giữ 1. Nếu mặc định scale=0 thì hình sẽ biến mất ngay khi mở cửa sổ.

### Bước 3 — Thay worldPoint bằng phép tính mới

```cpp title="include/scene.hpp — checkpoint 02 chỉ có scale"
inline Vec2 directTransform(Vec2 point, const Scene& scene) {
    const auto& p = scene.parameters;
    point = scalePoint(point, p.scaleX, p.scaleY);
    return point;
}
```

```cpp title="include/scene.hpp — mỗi lần đều bắt đầu từ hình local"
inline Square transformedSquare(const Scene& scene) {
    const Square localSquare = makeSquare(1.0);
    Square worldSquare{};
    for (std::size_t index = 0; index < localSquare.size(); ++index) {
        worldSquare[index] = worldPoint(localSquare[index], scene);
    }
    return worldSquare;
}
```

Hàm directTransform trả Vec2 mới; makeSquare không bị sửa. worldPoint của checkpoint 02 gọi directTransform. Không dùng phép nhân gán vào transformedSquare từ frame trước.

### Bước 4 — Đổi tham số trong lúc chạy

Trong nhánh SDL_EVENT_KEY_DOWN, A/D giảm/tăng scaleX, S/W giảm/tăng scaleY, mỗi lần 0.1 và clamp trong [-2,2]. Phần nhánh này có đầy đủ trong src/main.cpp của checkpoint 02. Ví dụ:

```cpp title="src/main.cpp — phím D tăng scaleX"
if (event.key.key == SDLK_D) {
    scene.parameters.scaleX = std::min(2.0, scene.parameters.scaleX + 0.1);
}
```

Panel slider của executable được tự xây ở bài 7. Canvas có slider sẵn để bạn thử toán ngay từ bài này.

## Ghép các phần lại

Build project_9_checkpoint_2. Nhấn R để về identity, rồi D năm lần: scaleX≈1.5 trong sai số floating point. Giữ scaleY=1 để phân biệt thay đổi chiều rộng với phóng to đồng đều.

F2 chọn scale âm và F3 chọn scale bằng 0. Các preset chỉ có hiệu lực cho phần toán đã học; ví dụ shear chưa được dùng trong checkpoint 02.

## Thử làm sai để hiểu đúng

1. Trong một bản sao, cho kết quả frame trước đi tiếp qua scale(1.01,1). Hình sẽ rộng dần dù tham số không đổi. Khôi phục việc tính từ makeSquare mỗi frame; hình phải đứng yên khi không có input.

2. Chọn F3 để scaleX=0, rồi dùng D kéo nó ra khỏi 0. Hình từ đoạn thẳng trở thành hình chữ nhật, không cần phép chia hay inverse. Reset và chọn F2 để so hiện tượng ép phẳng với phản chiếu.

## Tự kiểm tra kết quả

- scalePoint((4,-2),2,3)=(8,-6).
- Scale(-1,1) phản chiếu qua trục Y; đừng gọi nhầm là phản chiếu qua trục X.
- Scale(0,1) ép mọi x về 0, không tạo NaN.
- R khôi phục hình vuông; dữ liệu makeSquare vẫn là bốn điểm ban đầu.

## Bài tập mở rộng

Cho phép khóa scaleX=scaleY bằng một phím mới. Khi bật khóa, hãy chọn rõ một giá trị chung thay vì âm thầm sửa dữ liệu local.
