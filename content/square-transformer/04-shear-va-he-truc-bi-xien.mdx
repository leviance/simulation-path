# Làm xiên hình rồi tự viết Mat2

## Vấn đề cần giải quyết

Scale thay độ dài hai trục; rotation quay chúng mà giữ vuông góc. Giờ ta làm hệ trục bị xiên bằng shear. Từ đó, hai cột của một ma trận 2×2 sẽ có ý nghĩa hình học cụ thể.

## Hiểu ý tưởng trước khi viết code

Ta dùng **shear đồng thời theo hai trục**:

$$
x'=x+h_x y,\qquad y'=h_y x+y.
$$

Ví dụ p=(2,4), hx=0.5, hy=−0.25 cho (4,3.5). Nếu sửa x thành 4 rồi mới tính y, bạn sẽ ra 3: đó là một phép khác.

Ma trận H có hai cột (1,hy) và (hx,1), chính là ảnh của ex và ey. Không được nói mọi shear đều giữ diện tích: ở đây det(H)=1−hx·hy. Khi hx=hy=1, hai cột trùng nhau và hình bị ép thành đoạn. Hai shear một trục **nối tiếp** có ma trận khác và determinant 1.

## Viết code từng bước

### Bước 1 — Viết công thức thành phần để đối chiếu

```cpp title="include/lab.hpp — hai đầu ra cùng dùng đầu vào cũ"
inline Vec2 shearPoint(Vec2 point, double shearX, double shearY) {
    return {point.x + shearX * point.y, shearY * point.x + point.y};
}
```

Checkpoint 04 giữ đường tính trực tiếp scale→shear→rotate để đối chiếu với Mat2.

### Bước 2 — Tạo Mat2 và áp vào vector

```cpp title="include/lab.hpp — lưu bốn ô theo hàng"
struct Mat2 {
    std::array<double, 4> values{};

    [[nodiscard]] double at(int row, int column) const {
        return values[static_cast<std::size_t>(row * 2 + column)];
    }
};
```

```cpp title="include/lab.hpp — hai hàng nhân một vector cột"
inline Vec2 transformVector(Mat2 matrix, Vec2 vector) {
    return {matrix.at(0, 0) * vector.x + matrix.at(0, 1) * vector.y, matrix.at(1, 0) * vector.x + matrix.at(1, 1) * vector.y};
}
```

Row-major chỉ nói index=row*2+column. Ta chọn column vector độc lập với cách lưu đó. Cột đầu là ảnh của ex, cột sau là ảnh của ey.

### Bước 3 — Tự viết phép nhân hai ma trận

```cpp title="include/lab.hpp — mỗi ô là một hàng nhân một cột"
inline Mat2 multiply(Mat2 left, Mat2 right) {
    Mat2 result{};
    for (int row = 0; row < 2; ++row) {
        for (int column = 0; column < 2; ++column) {
            double value = 0.0;
            for (int index = 0; index < 2; ++index) {
                value += left.at(row, index) * right.at(index, column);
            }
            result.values[static_cast<std::size_t>(row * 2 + column)] = value;
        }
    }
    return result;
}
```

Với A=[[1,2],[3,4]] và B=[[2,0],[1,2]], A·B=[[4,4],[10,8]]. Hãy tính tay bốn ô trước khi chạy test; ví dụ ô (0,0)=1·2+2·1=4.

### Bước 4 — Dùng Mat2 thật trong đường render

```cpp title="include/scene.hpp — ghép R·H·S để áp S trước"
inline Mat2 sceneLinearMatrix(const Scene& scene) {
    const auto& p = scene.parameters;
    const double c = std::cos(p.angle);
    const double s = std::sin(p.angle);
    const Mat2 scale{{{p.scaleX, 0.0, 0.0, p.scaleY}}};
    const Mat2 shear{{{1.0, p.shearX, p.shearY, 1.0}}};
    const Mat2 rotation{{{c, -s, s, c}}};
    return multiply(rotation, multiply(shear, scale));
}
```

worldPoint của checkpoint 04 gọi transformVector(sceneLinearMatrix(scene), local). Đây là ma trận dùng để vẽ, không phải một type khai báo cho đủ. directTransform vẫn tính theo ba hàm riêng, giúp đối chiếu ở bài cuối.

## Ghép các phần lại

Build project_9_checkpoint_4. J/L đổi hx, K/I đổi hy trong [-1,1]. Reset rồi chỉ tăng hx để thấy các cạnh ngang vẫn ngang còn hai cạnh kia nghiêng. Bật cả hai shear để thấy vì sao giả định giữ diện tích không còn đúng.

Preset F4 đặt hx=hy=1; hai basis nằm cùng một đường. Hai giá trị vẫn hữu hạn và chương trình không cần nghịch đảo để vẽ.

## Thử làm sai để hiểu đúng

1. Trong một hàm thử, sửa point.x trước rồi dùng x mới để tính y. Với (2,4), hx=0.5, hy=−0.25, kết quả sai thành (4,3), không phải (4,3.5). Khôi phục hai phương trình dùng đầu vào cũ.

2. Thử đặt value=0 một lần ở ngoài cả hai vòng row/column trong multiply. So cả bốn ô với [[4,4],[10,8]]; các ô sau bị cộng dồn. Đưa value trở lại bên trong vòng column.

3. Chọn F4 để hx=hy=1. Hai cột trùng hướng và diện tích bằng 0; đây là shear đồng thời suy biến, không phải lỗi renderer. Reset sau khi quan sát.

## Tự kiểm tra kết quả

- Shear đồng thời cho (4,3.5) ở ví dụ trên.
- Mat2 multiply cho đủ bốn số [[4,4],[10,8]], không chỉ đúng một vector.
- Các cạnh đối song song sau phép tuyến tính; góc vuông không được bảo toàn nói chung.
- hx=hy=1 tạo hình suy biến, không crash và không xuất hiện số vô hạn.
