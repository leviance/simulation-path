# Dịch chuyển bằng Mat3: điểm khác hướng ở đâu?

## Vấn đề cần giải quyết

Mat2 đã xoay, co và làm xiên hình, nhưng không thể đưa gốc (0,0) tới nơi khác: bất kỳ ma trận tuyến tính nào nhân vector zero cũng trả zero. Ta cần thêm translation mà vẫn ghép được bằng phép nhân ma trận.

## Hiểu ý tưởng trước khi viết code

Thêm thành phần thứ ba để biểu diễn **điểm** bằng (x,y,1) và **hướng** bằng (x,y,0):

$$
\begin{bmatrix}a&b&t_x\\c&d&t_y\\0&0&1\end{bmatrix}
\begin{bmatrix}x\\y\\1\end{bmatrix}
=
\begin{bmatrix}ax+by+t_x\\cx+dy+t_y\\1\end{bmatrix}.
$$

Với hướng có thành phần cuối 0, translation nhân 0 nên biến mất. Vì vậy basis là direction; điểm cuối của basis trên hình phải là transformedOrigin + transformedDirection.

Ở project này Mat3 chỉ dùng cho **affine transform**, hàng cuối luôn [0,0,1]. Ta không chia cho w hay trả bừa (0,0) khi nhận một matrix projective không thuộc hợp đồng. Translation ở **cột cuối**; hàng cuối có nhiệm vụ khác.

## Viết code từng bước

### Bước 1 — Nâng cấu trúc lên chín ô

```cpp title="include/lab.hpp — row-major với ba cột"
struct Mat3 {
    std::array<double, 9> values{};

    [[nodiscard]] double at(int row, int column) const {
        return values[static_cast<std::size_t>(row * 3 + column)];
    }
};
```

```cpp title="include/lab.hpp — translation nằm ở cột cuối"
inline Mat3 translationMatrix(Vec2 offset) {
    return {{{1.0, 0.0, offset.x, 0.0, 1.0, offset.y, 0.0, 0.0, 1.0}}};
}
```

Đối chiếu kĩ vị trí offset.x/offset.y trong mảng: index 2 và 5, không phải 6 và 7.

### Bước 2 — Mở rộng phép nhân hàng–cột

```cpp title="include/lab.hpp — tự nhân ma trận 3×3"
inline Mat3 multiply(Mat3 left, Mat3 right) {
    Mat3 result{};
    for (int row = 0; row < 3; ++row) {
        for (int column = 0; column < 3; ++column) {
            double value = 0.0;
            for (int index = 0; index < 3; ++index) {
                value += left.at(row, index) * right.at(index, column);
            }
            result.values[static_cast<std::size_t>(row * 3 + column)] = value;
        }
    }
    return result;
}
```

Cách tính giống Mat2, chỉ đổi kích thước vòng lặp. Chưa nên tối ưu thành chín biểu thức khó đối chiếu.

### Bước 3 — Tách API cho điểm và hướng

```cpp title="include/lab.hpp — áp affine matrix vào điểm"
inline Vec2 transformPoint(Mat3 matrix, Vec2 point) {
    const double x = matrix.at(0, 0) * point.x + matrix.at(0, 1) * point.y + matrix.at(0, 2);
    const double y = matrix.at(1, 0) * point.x + matrix.at(1, 1) * point.y + matrix.at(1, 2);
    return {x, y};
}
```

```cpp title="include/lab.hpp — bỏ translation khi biến đổi hướng"
inline Vec2 transformDirection(Mat3 matrix, Vec2 direction) {
    return transformVector(linearPart(matrix), direction);
}
```

linearPart lấy khối 2×2 ở góc trên trái. transformDirection dùng khối đó qua transformVector. Khi vẽ basis, worldPoint((1,0))−worldPoint((0,0)) chính là direction đã biến đổi; không normalize vì ta muốn thấy scale và shear.

### Bước 4 — Thay Mat2 bằng Mat3 trong đường vẽ

```cpp title="include/scene.hpp — chuỗi T·R·H·S đầu tiên"
inline Mat3 sceneMatrix(const Scene& scene) {
    const auto& p = scene.parameters;
    return multiply(translationMatrix(p.translation), multiply(rotationMatrix(p.angle), multiply(shearMatrix(p.shearX, p.shearY), scaleMatrix(p.scaleX, p.scaleY))));
}
```

worldPoint gọi transformPoint(sceneMatrix(scene), local). Cả shape và basis đi qua đường này, nên không có hai phiên bản toán khác nhau cho hình và debug.

## Thử làm sai để hiểu đúng

1. Đưa tx/ty xuống hàng cuối rồi giữ nguyên transformPoint. Hình không dịch như dự đoán vì hàm đọc translation ở cột cuối. Khôi phục affine layout [a,b,tx; c,d,ty; 0,0,1].

2. Dùng transformPoint(matrix,ex) làm hướng mà không trừ transformedOrigin. Tăng translation: mũi tên bị dài/nghiêng theo vị trí vật thể. Sửa bằng transformDirection hoặc hiệu hai transformed point; hướng không còn nhận translation.

## Tự kiểm tra kết quả

- Identity giữ điểm và hướng.
- Translation(3,5) đưa point(2,−1) tới (5,4), nhưng direction(2,−1) vẫn là (2,−1).
- Mat3 có hàng cuối [0,0,1] ở cả hai toán hạng và tích.
- Kết quả Mat3 khớp chuỗi scale→shear→rotate→translate ở sai số nhỏ.
