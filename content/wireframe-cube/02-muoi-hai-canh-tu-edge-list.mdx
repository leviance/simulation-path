# Nối mười hai cạnh từ index

## Vấn đề cần giải quyết

Tám điểm đã đúng nhưng chưa đủ để người xem nhận ra cube. Ta cần biết **đỉnh nào nối với đỉnh nào**. Viết một loạt lệnh vẽ với tọa độ screen cố định sẽ khiến hình hỏng ngay khi xoay hoặc resize.

Bài này tách hai việc: vertex array lưu vị trí; edge list lưu quan hệ nối. Cả mười hai cạnh cùng dùng một cache tám phép chiếu.

## Hiểu ý tưởng trước khi viết code

Cube có ba nhóm cạnh: bốn cạnh quanh vòng 0–3, bốn cạnh quanh vòng 4–7, bốn cạnh nối hai vòng. Tổng cộng:

$$
4+4+4=12.
$$

Mỗi góc nối ba cạnh. Nếu đếm “đầu cạnh”, ta cũng có $8\times3=12\times2=24$. Đây là một cách kiểm tra nhanh topology, không phải công thức để vẽ đường chéo trên mặt.

Đọc **edge list**, chọn từng **Vertex index** và lần theo ba cặp có index đó. Cube chưa xoay nên hai mặt vuông lồng nhau có thể gây cảm giác như hình 2D; khác biệt Z và phép chiếu ở bài trước mới là nguồn của hình này.

## Viết code từng bước

### Bước 1 — Thêm Edge và mười hai cặp index

Trong `lab.hpp`, sau phần vertex, thêm:

```cpp title="include/lab.hpp — đoạn ghép"
struct Edge {
    std::size_t from;
    std::size_t to;
};
```

`std::size_t` dùng làm index vào `std::array`. Không đặt màu hoặc screen coordinate trong `Edge`.

```cpp title="include/lab.hpp — đoạn ghép"
constexpr std::array<Edge, 12> kCubeEdges{{
    {0, 1},
    {1, 2},
    {2, 3},
    {3, 0},
    {4, 5},
    {5, 6},
    {6, 7},
    {7, 4},
    {0, 4},
    {1, 5},
    {2, 6},
    {3, 7},
}};
```

Bốn cạnh cuối chỉ nối cùng vị trí X/Y giữa hai lớp Z. Cặp 0–6 sẽ là đường chéo xuyên khối, không phải một cạnh của cube.

Thêm kiểm tra index trước khi truy cập cache:

```cpp title="include/lab.hpp — isEdgeValid"
inline bool isEdgeValid(Edge edge) {
    return edge.from < kCubeVertexCount && edge.to < kCubeVertexCount && edge.from != edge.to;
}
```

### Bước 2 — Tạo danh sách cạnh vẽ được từ cache

Trong `pipeline.hpp`, `RenderEdge` giữ screen segment và index của cạnh. `EdgeFrame` có mảng tối đa 12 phần tử, số cạnh dùng được và bộ đếm chiếu bổ sung. Vòng lặp chính là:

```cpp title="include/pipeline.hpp — buildEdges"
inline EdgeFrame buildEdges(const ProjectedCube& projected, const Scene& scene) {
    EdgeFrame frame;
    for (std::size_t i = 0; i < kCubeEdges.size(); ++i) {
        const Edge edge = kCubeEdges[i];
        if (!isEdgeValid(edge)) {
            continue;
        }
        const auto screen = projectSegment(projected.vertices[edge.from], projected.vertices[edge.to], scene, frame.extraProjections);
        if (screen) {
            frame.edges[frame.count] = {*screen, i, 1.0};
            ++frame.count;
        }
    }
    return frame;
}
```

`projectCube` đã tạo tám kết quả. Ta chỉ tra hai đầu bằng index; không gọi lại phép chiếu cho cả 24 đầu cạnh.

Có một ngoại lệ cần nói rõ: nếu cạnh cắt near/far, ta tạo endpoint mới ở mặt phẳng cắt. Các endpoint mới chưa có trong cache, nên cần chiếu bổ sung. Vì vậy “cache 8” không đồng nghĩa mọi cảnh luôn chỉ có đúng 8 lần chiếu. HUD đếm phần bổ sung riêng, chưa tính sàn/trục.

### Bước 3 — Giữ phần cạnh vẫn nhìn thấy

Ta dùng lại cách clip từng đoạn từ P12. Xem `projectSegment`:

```cpp title="include/pipeline.hpp — projectSegment"
inline std::optional<ScreenSegment> projectSegment(const ProjectionResult& a, const ProjectionResult& b, const Scene& scene, std::size_t& extraProjections) {
    Vec3 start = a.cameraPoint;
    Vec3 end = b.cameraPoint;
    if (a.status == ProjectionStatus::Invalid || b.status == ProjectionStatus::Invalid || !clipDepth(start, end, scene.lens)) {
        return std::nullopt;
    }
    std::optional<Vec2> from = a.screen;
    std::optional<Vec2> to = b.screen;
    // Endpoint gốc hợp lệ thì dùng cache. Chỉ project lại khi clip near/far sinh endpoint mới.
    if (!from || !to) {
        Scene cameraScene = scene;
        cameraScene.camera = {};
        from = projectVertex(start, cameraScene).screen;
        to = projectVertex(end, cameraScene).screen;
        extraProjections += 2;
    }
    if (!from || !to || !clipScreen(*from, *to, viewportFor())) {
        return std::nullopt;
    }
    return ScreenSegment{*from, *to, (start.z + end.z) * 0.5};
}
```

Có hai loại biên khác nhau. Với near/far, phải cắt trong camera space **trước khi chia cho Z**. Với mép cửa sổ, giữ screen point dạng số thực rồi clip trước khi làm tròn để Bresenham không phải đi hàng triệu pixel ngoài bảng.

Nếu cả hai endpoint ở ngoài trái/phải nhưng đoạn đi xuyên màn hình, vẫn phải giữ phần giữa. Do đó không thể thay hàm này bằng điều kiện “hai đầu đều Visible”.

### Bước 4 — Raster từng cạnh bằng CPU

Trong `view.hpp`, sau khi có cache:

```cpp title="include/view.hpp — đoạn ghép"
inline RenderStats renderScene(Framebuffer& image, const Scene& scene) {
    RenderStats stats;
    image.clear(kBackground);
    drawDepthScene(image, scene);
    const CubeVertices world = worldCube(scene);
    const ProjectedCube projected = projectCube(world, scene);
    stats.vertexProjections = projected.projectionCount;
    const EdgeFrame frame = buildEdges(projected, scene);
    stats.edgeCount = frame.count;
    stats.extraProjections = frame.extraProjections;
    for (std::size_t i = 0; i < frame.count; ++i) {
        const RenderEdge& edge = frame.edges[i];
        std::uint32_t color = 0x84A9FFFFu;
        rasterSegment(image, edge.screen, color);
    }
    if (scene.debug) {
        for (const auto& vertex : projected.vertices) {
            if (vertex.status == ProjectionStatus::Visible && vertex.screen) {
                disc(image, static_cast<int>(std::lround(vertex.screen->x)), static_cast<int>(std::lround(vertex.screen->y)), 4, kWhite);
            }
        }
    }
    return stats;
}
```

`rasterSegment` làm tròn screen point đã clip rồi gọi `drawLine` Bresenham của ta. SDL chỉ nhận framebuffer cuối cùng qua texture; không có `SDL_RenderLine`.

## Thử làm sai để hiểu đúng

1. Thay cặp 0–4 thành 0–6. Bạn thấy một đường chéo xuyên khối; vertex không hề sai, lỗi nằm trong topology.
2. Thay `projectSegment` bằng kiểm tra hai status Visible. Ở preset cắt near hoặc lệch khung, những phần cạnh còn nhìn thấy cũng bị xóa.
3. Đặt index thành 8. `isEdgeValid` phải ngăn truy cập ngoài mảng; không được dùng modulo để âm thầm nối sang một đỉnh khác.

## Tự kiểm tra kết quả

- Mười hai cặp khác nhau, không có cặp tự nối; mỗi index xuất hiện đúng ba lần.
- Cube mặc định vẽ đủ 12 cạnh từ cache 8 đỉnh.
- Đường qua mép màn hình và near plane vẫn giữ phần hợp lệ.
- Không đọc screen rỗng, không đưa tọa độ chưa clip vào rasterizer.
