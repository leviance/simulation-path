### Dựng bên cạnh cây đang dùng

Parse, ánh xạ và đo bản nháp xong mới chuyển nó vào Desk. UI mới không mang active hoặc focus cũ; mô hình đàn chim thì được giữ lại.

{/* snippet include/markup/desk.hpp#replace-page */}

```cpp title="include/markup/desk.hpp — Dựng bên cạnh cây đang dùng"
inline void install(Desk& desk, std::string_view source) {
    Page draft = build(parse(source), desk.page.layout.width);
    bindExisting(draft, source);
    lab::Ui fresh;
    lab::ensureLayout(draft.layout, fresh);
    // Lần đầu đọc value. Từ lần reload sau chỉ ép tham số hiện tại vào miền mới.
    for (const auto& e : draft.document.elements) {
        if (!e.range)
            continue;
        double* value = nullptr;
        if (e.id == "radius")
            value = &desk.model.colony.params.radius;
        if (e.id == "separation")
            value = &desk.model.colony.params.separationWeight;
        if (value) {
            if (desk.edition == 0)
                *value = e.range->value;
            *value = snap(*e.range, *value);
        }
    }
    desk.page = std::move(draft);
    desk.ui = fresh;
    desk.observed = 0;
    ++desk.edition;
}
```

### Nối ngược khung trên màn hình về file

Inspector cho biết tag, ID từ file, WidgetId, parent, offset và bounds. Đây là cách kiểm một nhãn thực sự thuộc settings chứ không chỉ tình cờ được vẽ gần nó.

{/* snippet include/markup/paint.hpp#element-inspector */}

```cpp title="include/markup/paint.hpp — Nối ngược khung trên màn hình về file"
if (d.inspect && !page.handles.empty()) {
    d.observed %= page.handles.size();
    const auto& e = page.document.elements[d.observed];
    const auto id = page.handles[d.observed];
    const auto item = lab::locate(page.layout.scene.tree, id);
    bench::box(r, {30, 94, 410, 76}, {29, 52, 57, 255});
    caption(r, 42, 105, "SOURCE   <" + e.tag + "> #" + e.id + "    Widget " + std::to_string(id), {158, 235, 196, 255});
    std::string depth = "root";
    if (e.parent >= 0)
        depth = "parent #" + page.document.elements[static_cast<std::size_t>(e.parent)].id;
    caption(r, 42, 126, depth + "   |   byte " + std::to_string(e.offset), {217, 229, 225, 255});
    if (item) {
        const auto b = item->bounds;
        caption(r, 42, 146, "bounds " + decimal(b.x) + ", " + decimal(b.y) + "   " + decimal(b.width) + " x " + decimal(b.height), {249, 205, 119, 255});
        const SDL_FRect edge{float(b.x), float(b.y), float(b.width), float(b.height)};
        bench::ink(r, {249, 205, 119, 255});
        SDL_RenderRect(r, &edge);
    }
}
```

## Thử làm sai để hiểu đúng

Giữ lại focus cũ rồi nạp file thứ hai. Khi nhấn Space, bạn có thể thao tác một nút không hề chọn. Xóa tham chiếu UI khi thay cây, không reset đàn để che lỗi.
