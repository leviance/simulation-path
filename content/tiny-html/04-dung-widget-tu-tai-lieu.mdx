## Viết code từng bước

### Tạo cây đã biết từ Project 66

Không đo font hay viết lại cách xếp hàng. Tạo đúng loại node, ghi bảng đối chiếu element → widget rồi để box layout của Project 67 đo từ dữ liệu mới.

{/* snippet include/markup/bridge.hpp#attach */}

```cpp title="include/markup/bridge.hpp — Tạo cây đã biết từ Project 66"
inline Page build(Document document, double width) {
    Page p;
    auto& state = p.layout;
    state.scene = lab::Scene{};
    state.width = width;
    p.document = std::move(document);
    for (std::size_t i = 0; i < p.document.elements.size(); ++i) {
        const auto& e = p.document.elements[i];
        lab::WidgetId id = state.scene.tree.root->id;
        if (e.parent >= 0) {
            const auto parent = p.handles.at(static_cast<std::size_t>(e.parent));
            id = lab::add(state.scene.tree, parent, kindOf(e), {0, 0, 1, 1}, e.text);
        }
        p.handles.push_back(id);
        p.elements.emplace(id, i);
        if (e.range)
            p.values[id] = e.range->value;
    }
    lab::initStyles(*state.scene.tree.root, state.scene.styles);
    auto& root = state.scene.styles.at(1);
    root.height = lab::Height::Fixed;
    root.fixedHeight = 492;
    root.margin = {};
    root.padding = {14, 14, 14, 14};
    root.gap = 5;
    for (const auto id : p.handles) {
        if (id == 1)
            continue;
        auto& style = state.scene.styles.at(id);
        style.margin = {3, 2, 3, 2};
        if (style.height == lab::Height::Auto) {
            style.padding = {7, 7, 7, 7};
            style.gap = 3;
        }
    }
    return p;
}
```

### Đưa giá trị slider thật vào đàn

Lấy giá trị gần nhất theo step và chặn trong min/max. Chỉ hai ID radius và separation nối tới mô hình; mỗi slider không gắn mô hình vẫn có giá trị riêng.

{/* snippet include/markup/desk.hpp#live-value */}

```cpp title="include/markup/desk.hpp — Đưa giá trị slider thật vào đàn"
inline void applyRange(Desk& d, lab::WidgetId id, double proposed) {
    const auto found = d.page.elements.find(id);
    if (found == d.page.elements.end())
        return;
    const auto& e = d.page.document.elements[found->second];
    if (!e.range)
        return;
    const double value = snap(*e.range, proposed);
    d.page.values[id] = value;
    if (e.id == "radius")
        d.model.colony.params.radius = value;
    if (e.id == "separation")
        d.model.colony.params.separationWeight = value;
}
```
