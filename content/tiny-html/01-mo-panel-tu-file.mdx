### Đọc đủ byte trước khi phân tích

Mở ở cuối để biết kích thước. Chặn file lớn hơn 16 KiB trước khi cấp bộ nhớ rồi mới quay về đầu để đọc. File không tồn tại và file rỗng là hai trường hợp khác nhau.

{/* snippet include/markup/source.hpp#read-file */}

```cpp title="include/markup/source.hpp — Đọc đủ byte trước khi phân tích"
inline std::string readFile(const std::filesystem::path& path) {
    std::ifstream input(path, std::ios::binary | std::ios::ate);
    if (!input)
        throw Error("1:1 cannot open " + path.filename().string());
    const std::streamoff length = input.tellg();
    if (length < 0 || length > static_cast<std::streamoff>(maxBytes))
        throw Error("1:1 file exceeds 16 KiB");
    std::string bytes(static_cast<std::size_t>(length), '\0');
    input.seekg(0);
    if (!input.read(bytes.data(), length))
        throw Error("1:1 incomplete file");
    return bytes;
}
```

### Nối phím F5 với thao tác đọc

Ở snapshot này reload chỉ kiểm UTF-8, báo tên và số byte. Chạy executable với `--assets assets` từ thư mục dự án để sửa đúng bản đang mở.

{/* snippet include/markup/desk.hpp#reload */}

```cpp title="include/markup/desk.hpp — Nối phím F5 với thao tác đọc"
inline bool reload(Desk& d, const std::filesystem::path& path) {
    try {
        const auto source = readFile(path);
        checkUtf8(source);
        d.status = std::to_string(source.size()) + " bytes; original layout still active";
        d.name = path.filename().string();
        d.error = false;
        return true;
    } catch (const std::exception& e) {
        d.error = true;
        d.status = path.filename().string() + ":" + e.what();
        return false;
    }
}
```

## Ghép các phần lại

Trong bản C++, bấm Pause, mở `assets/panel.html` bằng editor, thêm một dòng trắng rồi F5. Số byte thay đổi; đàn và các nút cũ vẫn ở nguyên. Đây là bằng chứng nhỏ nhưng cần trước khi viết parser.

```bash title="Terminal — Windows, Visual Studio"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_68_checkpoint_1 --parallel 2
.\build\Release\project_68_checkpoint_1.exe
```

## Thử làm sai để hiểu đúng

Đổi tên file đang đọc. Nếu app vẫn báo thành công, có thể bạn đang sửa `assets` cạnh source trong khi nó đọc bản cạnh executable. Thử lại với `--assets assets`.
