# Mở một lát ngang của bờ suối

## Vấn đề cần giải quyết

Trên mặt có cỏ, nhưng dưới chân cây thực ra là đất hay đá? Không cần nhổ cây hoặc đào bờ để biết. Ta thêm một ô nhìn phụ đọc đúng một tầng y trong chunk đang giữ.

## Hiểu ý tưởng trước khi viết code

Xem ô `(x,y,z)` như một ống nghiệm: chọn y rồi đi theo hai chiều x/z. Lát là một phép **đọc**, không phải thao tác cắt mất phần đất phía trên. Thử đoán lớp nào có vệt nước liên tục trước khi bật bảng.

## Viết code từng bước

Làm sao biết bên dưới lớp cỏ có thật sự là đất? Ta sẽ soi một tầng của cột ở góc màn hình. Tắt bảng đi thì bờ suối ban đầu phải còn nguyên.

### Giữ con số y cần soi trong Scene

Trong `scene.hpp`, thêm `sliceY`, cờ `showSlice` và hàm đọc `inspectedBlock`. Hàm này chỉ trả `column.get(x,y,z)`; không viết `put`, không cắt mesh. Phép tính index của bài 2 giải thích vì sao mọi ô của một tầng nằm cạnh nhau.

{/* snippet include/trail/blocks.hpp#local-index */}

```cpp title="include/trail/blocks.hpp — Địa chỉ bảng và địa chỉ mesh dùng chung"
inline int localIndex(int x, int y, int z) {
    if (x < 0 || x >= side || y < 0 || y >= side || z < 0 || z >= side) {
        throw std::out_of_range("cell outside section");
    }
    return x + side * (z + side * y);
}
```

### Dùng H mở bảng, chọn tầng rồi tô ô

Trong `window.hpp`, xử lý H và hai phím PageUp/PageDown, chặn y ở 0 và 15. Sau khi đã đưa ảnh 3D lên renderer, lặp qua x/z, lấy màu từ atlas cho từng vật liệu, tô ô nhỏ và in số tầng. Nền riêng của `Air` giúp phân biệt khoảng trống với đá tối.

{/* snippet include/trail/window.hpp#slice-read */}

```cpp title="include/trail/window.hpp — Đọc một lớp mà không thay địa hình"
for (int z = 0; z < side; ++z) {
    for (int x = 0; x < side; ++x) {
        const Block block = scene.inspectedBlock(x, scene.sliceY, z);
        Color ink{30, 39, 48};
        if (block != Block::Air)
            ink = atlas.sample(block, 2, 0.25, 0.5);
        require(SDL_SetRenderDrawColor(display.renderer, ink.r, ink.g, ink.b, 255));
        const SDL_FRect cell{float(664 + x * 8), float(24 + z * 8), 8, 8};
        require(SDL_RenderFillRect(display.renderer, &cell));
    }
}
```

{/* snippet include/trail/window.hpp#slice-keys */}

```cpp title="include/trail/window.hpp — Giữ tầng đang soi trong khoảng hợp lệ"
if (key == SDLK_H)
    scene.showSlice = !scene.showSlice;
if (key == SDLK_PAGEUP)
    scene.sliceY = std::min(15, scene.sliceY + 1);
if (key == SDLK_PAGEDOWN)
    scene.sliceY = std::max(0, scene.sliceY - 1);
```

## Ghép các phần lại

## Thử làm sai để hiểu đúng

Tạm đảo x và z **chỉ** khi đọc bảng và so dáng cong của lòng suối. Hình thế giới không đổi, nhưng lát bị phản chiếu qua đường chéo.

## Tự kiểm tra kết quả

Đổi lớp làm ảnh nhỏ thay đổi; số block đặc, mesh và vị trí mắt giữ nguyên. Tắt bảng trở về viewport sạch, vẫn đọc được cỏ, cát, đất bằng mắt.
