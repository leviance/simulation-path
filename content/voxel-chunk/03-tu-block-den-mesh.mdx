# Vì sao một khối đất cần tới 49.152 tam giác?

## Vấn đề cần giải quyết

Ta đã có cả mảng nhưng vẫn chỉ đọc một viên đá. Hãy lấp kín section bằng đá rồi đi qua từng ô để dựng hình. Bề ngoài nó vẫn như một khối hộp; bên trong là con số mà Project 59 sẽ tìm cách giảm.

## Hiểu ý tưởng trước khi viết code

Mỗi ô đặc sinh 6 mặt, tức 12 tam giác. Với 16³ ô, kết quả phải là 49.152 tam giác. Dự đoán trước cho hai viên kề nhau: có 20 hay 24 tam giác ở phiên bản này?

## Viết code từng bước

Thay vì vẽ riêng ô (7,7,7), hãy cho chương trình tìm tất cả những ô có vật liệu. Ta cố ý vẽ cả các mặt nằm trong lòng đất để có một số đo gốc cho Project 59.

### Chuẩn bị một cột đặc

Trong `bank.hpp`, viết `solidCube()` từ `Column` của bài trước. Chỉ cần lấp đầy section đầu bằng `Stone`: đây là dữ liệu đầu vào, chưa có đỉnh hay tam giác nào.

### Đi qua cột từng tầng

Trong `surface.hpp`, viết `naiveMesh`: đọc `column.get(x,y,z)`, bỏ qua `Air`, đổi x/z từ local sang world rồi mới gọi `appendCube`. Hàm sáu mặt dưới đây là hàm đã viết, không viết thêm một bản cùng tên.

{/* snippet include/trail/surface.hpp#naive-mesh */}

```cpp title="include/trail/surface.hpp — Từ ô đặc tới danh sách mặt"
inline Mesh naiveMesh(const Column& column) {
    Mesh mesh;
    for (int y = 0; y < column.height(); ++y) {
        for (int z = 0; z < side; ++z) {
            for (int x = 0; x < side; ++x) {
                const Block block = column.get(x, y, z);
                if (block == Block::Air)
                    continue;
                const Vec3 cell{double(column.cx * side + x), double(y), double(column.cz * side + z)};
                appendCube(mesh, cell, block);
            }
        }
    }
    return mesh;
}
```

{/* snippet include/trail/surface.hpp#six-faces */}

```cpp title="include/trail/surface.hpp — Lý do hai viên kề nhau vẫn có 24 tam giác"
inline void appendCube(Mesh& mesh, Vec3 cell, Block block) {
    for (int face = 0; face < 6; ++face) {
        mesh.push_back({cell + faceStarts[face], face, 1, 1, block});
    }
}
```

### Dùng mesh mới thay viên đá viết tay

Sửa `Scene::generate()` để chọn cột theo preset, đếm các ô khác `Air` rồi **gán** `mesh = naiveMesh(column)`. Chọn khối đặc khi mở và lùi camera ra để nhìn thấy cả khối. Nếu cộng dồn vào mesh cũ, số mặt sẽ tăng mỗi lần tạo lại cảnh.

{/* snippet include/trail/scene.hpp#replace-mesh */}

```cpp title="include/trail/scene.hpp — Dùng mesh của cả cột"
mesh = naiveMesh(column);
```

## Ghép các phần lại

Mở bản của mình: vỏ ngoài trông như một khối, nhưng F1 phải cho 4.096 ô đặc, 24.576 quad, 49.152 tam giác. Thử đưa `Column{}` vào `naiveMesh`: mesh rỗng mới đúng; đừng dùng số pixel nhìn thấy để đếm mặt.

```bash title="Terminal — chạy bản bạn vừa viết"
cmake --build build-work --config Release --target project_58_work --parallel 1
.\build-work\Release\project_58_work.exe
```

## Thử làm sai để hiểu đúng

Tạm thay `continue` sau điều kiện Air bằng `return mesh`. Chỉ một ô không khí ở đầu mảng cũng có thể làm biến mất cả vạt đất phía sau nó.

## Tự kiểm tra kết quả

Bật F1 để xem số tam giác của khối mặc định. Muốn kiểm cặp kề nhau ngay ở bài này, cho `solidCube()` trả một cột rỗng chỉ có hai lệnh `put` tại (7,7,7) và (8,7,7): phải thấy 24 tam giác. Bỏ cả hai lệnh thì còn 0. Trả lại cột đặc: số đo trở về 49.152. Các phím chọn sẵn dữ liệu sẽ có ở bài 4.
