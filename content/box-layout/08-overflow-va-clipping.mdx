# Phần slider bị cắt có còn thuộc về nó không?

## Vấn đề cần giải quyết

Bạn thu hẹp bảng nhưng giữ Radius rộng 320. Nếu dùng chiều rộng còn nhìn thấy để đổi x thành bán kính, nửa thanh bên trái bỗng đại diện cho toàn bộ 20–140 px. Người dùng sẽ thấy mức nhạy thay đổi vô cớ.

## Hiểu ý tưởng trước khi viết code

Giữ hai hình chữ nhật: bounds là hình của chính slider, clip là chỗ tổ tiên cho phép thấy. Clip quyết định có thể bắt đầu kéo ở đâu; bounds quyết định vị trí đó tương ứng giá trị nào.

## Viết code từng bước

### Cho đúng một slider giữ width 320

Bật preset overflow chỉ đổi Style của Radius sang Fixed. Nó không ép các control khác cùng tràn và không tự thêm scrolling.

{/* snippet include/runtime.hpp#overflow */}

```cpp title="include/runtime.hpp — Cho đúng một slider giữ width 320"
inline void setOverflow(LayoutState& state, Ui& ui, bool enabled) {
    if (state.overflow == enabled)
        return;
    BoxStyle& style = state.scene.styles.at(state.scene.slider);
    style.width = Width::Fill;
    if (enabled)
        style.width = Width::Fixed;
    style.fixedWidth = 320;
    state.overflow = enabled;
    invalidate(state, ui);
}
```

### Đổi tọa độ theo toàn bộ thanh

Bảng rộng 220, slider bắt đầu ở x=756, chỉ còn 158 pixel nhìn thấy. Bấm x=836 là đi 80/320 quãng đường: bán kính 20+120×0,25=50 px.

{/* snippet include/workbench/retained-input.hpp#drag */}

```cpp title="include/workbench/retained-input.hpp — Đổi tọa độ theo toàn bộ thanh"
inline void drag(const Tree& tree, Model& model, WidgetId id, double x) {
    const auto view = locate(tree, id);
    if (view && view->enabled && view->node->kind == Kind::Slider) {
        assign(model, view->node->binding, (x - view->bounds.x) / view->bounds.width);
    }
}
```

## Ghép các phần lại

Nhấn O, thu hẹp bằng Shift+←; bấm phần bị cắt rồi bấm phần còn thấy. Chỉ lần thứ hai được bắt đầu drag. Khi đã giữ chuột, kéo ra tận bên phải rồi thả để đạt 140 px.

```bash title="Terminal — Windows, Visual Studio"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_67_checkpoint_8 --parallel 2
.\build\Release\project_67_checkpoint_8.exe
```

## Thử làm sai để hiểu đúng

Đổi mẫu số từ `bounds.width` sang `clip.width`. Cùng x=836 sẽ ra khoảng 81 thay vì 50. Tự tính hai đáp án trước khi thử.

## Tự kiểm tra kết quả

Bounds rộng 320, clip rộng 158. Click ngoài clip không chọn slider; một drag đã bắt đầu hợp lệ vẫn nhận lần thả cuối bên ngoài.
