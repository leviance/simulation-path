# Ẩn Reset, kéo Radius ngay ở chỗ mới

## Vấn đề cần giải quyết

Có lúc bạn cần thêm vài dòng ghi chú mà không muốn chúng che slider. Thử ẩn Reset khi đang quan sát một con chim: không chỉ dòng bên dưới phải dời lên, cả vị trí nhận chuột cũng phải dời lên theo.

## Hiểu ý tưởng trước khi viết code

Ẩn không phải xóa. Khi ẩn, node vẫn có ID nhưng không chiếm chỗ trong phép đo. Khi xóa, bỏ luôn style và quyền sở hữu; một Label tạo sau không được mượn lại ID của Label vừa mất.

## Viết code từng bước

### Ẩn một node và đánh dấu cần xếp lại

Reset có border height 36, margin tổng 8 và một gap 8. Bỏ nó làm các hàng sau dời đúng 52 pixel, Group từ 352 còn 300.

{/* snippet include/runtime.hpp#hide */}

```cpp title="include/runtime.hpp — Ẩn một node và đánh dấu cần xếp lại"
inline void toggleReset(LayoutState& state, Ui& ui) {
    Widget* reset = find(*state.scene.tree.root, state.scene.reset);
    reset->visible = !reset->visible;
    invalidate(state, ui);
}
```

### Cho Label mới tham gia cùng quy tắc

Một ID mới và một Style mặc định là đủ. Không cần tìm slider rồi sửa y. Giới hạn bốn Label để có thể tạo lại cùng tình huống tràn trong kiểm thử.

{/* snippet include/runtime.hpp#extra */}

```cpp title="include/runtime.hpp — Cho Label mới tham gia cùng quy tắc"
inline bool appendLabel(LayoutState& state, Ui& ui) {
    if (state.extras.size() >= 4)
        return false;
    const WidgetId id = add(state.scene.tree, state.scene.group, Kind::Label, {0, 0, 1, 24}, "Added Label");
    state.scene.styles[id] = defaultStyle(*find(*state.scene.tree.root, id));
    state.extras.push_back(id);
    invalidate(state, ui);
    return true;
}
```

Bấm H để ẩn Reset, chọn Radius ở chỗ mới rồi kéo; vòng quanh chim vàng phải đổi ngay. Bấm A bốn lần, D để bớt hàng. Bấm R: đàn trở về preset nhưng bố cục đang thử vẫn giữ nguyên.

## Thử làm sai để hiểu đúng

Thử bỏ qua child ẩn khi vẽ nhưng vẫn đo nó. Reset biến mất mà còn một lỗ trống 52 pixel; đây là lỗi layout chứ không phải lỗi render.

## Tự kiểm tra kết quả

Ẩn rồi hiện trả lại đúng Rect cũ. Khi xóa hàng cuối, cả node lẫn style biến mất; con chim đang chọn không bị đổi chỉ vì bạn sửa bảng.
