# Khi nào thực sự phải xếp lại bảng?

## Vấn đề cần giải quyết

Bạn đang kéo Radius thì thu hẹp cửa sổ. Nếu SDL đã nhận tọa độ mới mà hit-test vẫn dùng Rect cũ, bán kính sẽ nhảy dù tay bạn không hề kéo thêm. Cờ dirty giúp biết lúc nào phải tính lại.

## Hiểu ý tưởng trước khi viết code

Tách chuyển động của đàn và thay đổi hình học. Chim chạy, hover hoặc thay lực tách không đổi kích thước các nút. Thay width, padding hay visibility mới làm số đo hết hạn.

## Viết code từng bước

### Đánh dấu đúng lúc và hủy gesture cũ

Width mới hợp lệ và thật sự khác mới đi tiếp. Hủy capture đang dở để sự kiện thả không bị áp lên slider ở vị trí mới.

{/* snippet include/runtime.hpp#width */}

```cpp title="include/runtime.hpp — Đánh dấu đúng lúc và hủy gesture cũ"
inline bool setWidth(LayoutState& state, Ui& ui, double value) {
    if (!std::isfinite(value) || value < 220 || value > 420)
        return false;
    if (value != state.width) {
        state.width = value;
        invalidate(state, ui);
    }
    return true;
}
```

### Đo và xếp trước khi hỏi node nào nhận chuột

`ensureLayout` được gọi trước input lẫn trước render. Nếu dirty đã được xử lý, lần gọi thứ hai chỉ kiểm một cờ.

{/* snippet include/runtime.hpp#before-input */}

```cpp title="include/runtime.hpp — Đo và xếp trước khi hỏi node nào nhận chuột"
inline bool ensureLayout(LayoutState& state, Ui& ui) {
    if (!state.dirty)
        return false;
    state.sizes.clear();
    measure(*state.scene.tree.root, state.width, state.scene.styles, state.sizes);
    arrange(*state.scene.tree.root, 936 - state.width, 24, state.scene.styles, state.sizes);
    ++state.passes;
    state.dirty = false;
    reconcile(state.scene.tree, ui);
    return true;
}
```

## Ghép các phần lại

Kéo Radius, rồi dùng Shift+mũi tên để thay width của root. Thả chuột; lần thả mồ côi phải không đổi bán kính. Bấm vào giữa thanh mới: giá trị phải là 80 px, nằm giữa 20 và 140.

```bash title="Terminal — Windows, Visual Studio"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_67_checkpoint_7 --parallel 2
.\build\Release\project_67_checkpoint_7.exe
```

## Thử làm sai để hiểu đúng

Nếu chỉ gọi `ensureLayout` lúc vẽ, frame cuối có thể trông rất đúng trên ảnh nhưng lần bấm trước đó đã chọn sai nút. Hãy kiểm ngay sau resize, trước khi vẽ lại.

## Tự kiểm tra kết quả

Bật B, để đàn bay và theo dõi passes. Không lần bố trí nào phát sinh chỉ vì thời gian đang chạy; đổi một width có hiệu lực mới tạo một lượt.
