# Vì sao thêm một nút lại phải dời cả bảng?

## Vấn đề cần giải quyết

Hãy chạy starter, bấm Pause rồi kéo Radius. Đàn chim dừng tại chỗ nhưng vòng quanh con chim vàng vẫn nở ra; bảng điều khiển đã làm đúng việc của nó. Bây giờ thử chèn một nhãn ngay dưới Pause. Chính những tọa độ y rải rác trong hàm dựng bảng mới là việc ta cần giải quyết.

## Hiểu ý tưởng trước khi viết code

Đừng thay cả bảng ngay. Ta cần một mốc so sánh: nút nào nằm ở đâu, nhận chuột ở đâu, và việc thay bố cục có vô tình làm đổi đàn chim không?

## Viết code từng bước

### Tìm nơi đặt từng control

Ở mốc này các control là con trực tiếp của root. Số 58 là tọa độ y trong Panel, không phải pixel thứ 58 của cửa sổ.

{/* snippet include/scene.hpp#manual */}

```cpp title="include/scene.hpp — Tìm nơi đặt từng control"
inline Scene buildScene() {
    Scene scene;
    Tree& tree = scene.tree;
    tree.root->local = {616, 24, 320, 492};
    scene.title = add(tree, 1, Kind::Label, {18, 18, 284, 24}, "FLIGHT DESK / BOX LAYOUT");
    WidgetId parent = 1;
    scene.pause = add(tree, parent, Kind::Button, {22, 58, 276, 36}, "Pause", Action::Pause);
    scene.reset = add(tree, parent, Kind::Button, {22, 108, 276, 36}, "Reset", Action::Reset);
    add(tree, parent, Kind::Button, {22, 154, 276, 36}, "Neighbors", Action::Observe);
    add(tree, parent, Kind::Label, {22, 194, 276, 24}, "", Action::None, Binding::Radius);
    scene.slider = add(tree, parent, Kind::Slider, {22, 224, 276, 32}, "", Action::None, Binding::Radius);
    add(tree, parent, Kind::Label, {22, 268, 276, 24}, "", Action::None, Binding::Separation);
    add(tree, parent, Kind::Slider, {22, 298, 276, 32}, "", Action::None, Binding::Separation);
    scene.footer = add(tree, 1, Kind::Label, {18, 350, 284, 24}, "", Action::None, Binding::Time);
    return scene;
}
```

### Lần từ ID đến khung trên màn hình

Lấy cùng `bounds` mà cây đang dùng để vẽ và chọn nút. Với root ở (616,24), Pause ở (22,58) bên trong nên mép trên trái thực sự là (638,82).

{/* snippet include/app.hpp#world-observer */}

```cpp title="include/app.hpp — Lần từ ID đến khung trên màn hình"
inline std::string describePause(const LayoutState& state) {
    const auto view = locate(state.scene.tree, state.scene.pause);
    if (!view)
        return "Pause is clipped or hidden";
    return "Pause world=(" + std::to_string(int(view->bounds.x)) + "," + std::to_string(int(view->bounds.y)) + ") size=" + std::to_string(int(view->bounds.width)) + "x" + std::to_string(int(view->bounds.height));
}
```

## Ghép các phần lại

## Thử làm sai để hiểu đúng

Trong `buildScene`, tăng riêng tọa độ y của Pause thêm 32. Nút dịch xuống nhưng Reset không tránh đường: việc hai nút chồng nhau chưa phải lỗi của hit-test.

## Tự kiểm tra kết quả

Thấy cả đàn, hai slider và nút Neighbors. Khoảng lệch 24 pixel giữa y local và world đúng bằng vị trí root.
