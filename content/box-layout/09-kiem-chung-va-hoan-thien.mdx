## Viết code từng bước

### Đếm và đối chiếu các node sống

Audit giúp phát hiện một Style mồ côi hoặc một kích thước vô lý. Nó không thể tự chứng minh thuật toán cộng gap đúng; cần fixture biết trước đáp án.

{/* snippet include/audit.hpp#count */}

```cpp title="include/audit.hpp — Đếm và đối chiếu các node sống"
inline int auditLayout(const LayoutState& state) {
    if (state.dirty)
        throw std::runtime_error("layout is dirty");
    std::set<WidgetId> ids;
    checkLayoutNode(*state.scene.tree.root, state, ids, 0);
    if (ids.size() != state.scene.styles.size() || int(ids.size()) != state.scene.tree.count)
        throw std::runtime_error("ownership/style mismatch");
    return int(paintList(state.scene.tree).size());
}
```

### Để đàn chạy qua một nghìn frame

Giữ địa chỉ root, ID tiếp theo và số lần layout, rồi cho simulation tiến 1.000 bước. Cả ba giá trị phải giữ nguyên. Dùng `check` thay `assert` vì `NDEBUG` của Release loại bỏ assert.

{/* snippet tests/tests.cpp#idle-layout */}

```cpp title="tests/tests.cpp — Để đàn chạy qua một nghìn frame"
// Radius/ticks/Reset không làm dirty layout hoặc dựng lại cây.
const int passes = state.passes;
const Widget* rootAddress = state.scene.tree.root.get();
const WidgetId nextId = state.scene.tree.nextId;
setPaused(model, false);
for (int frame = 0; frame < 1000; ++frame) {
    ensureLayout(state, ui);
    paintList(state.scene.tree);
    advance(model, fixedDt);
}
check(state.passes == passes && state.scene.tree.root.get() == rootAddress && state.scene.tree.nextId == nextId, "1000 frames retain layout and ownership");
```

## Ghép các phần lại

Chạy bản final với B tắt để dùng bảng như bình thường. Sau đó thử H, A/D, O và Shift+mũi tên, bật B đọc số đo, rồi chạy CTest ở Debug và Release với `--timeout 20`.

```bash title="Terminal — Windows, Visual Studio"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_67_final --parallel 2
.\build\Release\project_67_final.exe
```
