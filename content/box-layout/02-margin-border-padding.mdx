# Bốn mép quanh một nút Pause

## Vấn đề cần giải quyết

Hai nút đang sát nhau. Bạn muốn chừa chỗ giữa chúng, còn dòng chữ bên trong nút vẫn ở nguyên vị trí so với viền. Nên tăng margin hay padding?

## Hiểu ý tưởng trước khi viết code

Hãy đọc hộp từ ngoài vào trong: margin thuộc khoảng cách giữa hai hàng; border bao nút; padding chừa chỗ phía trong; phần còn lại là content. Người dùng bấm vào border box, không bấm được vào margin.

## Viết code từng bước

### Cho bốn cạnh bốn giá trị riêng

Đừng dùng một con số thay cho cả hộp. Thử margin trái 3 và phải 9 để một lỗi tráo trái/phải không qua mắt được bạn.

{/* snippet include/style.hpp#edges */}

```cpp title="include/style.hpp — Cho bốn cạnh bốn giá trị riêng"
struct Edges {
    double left = 0;
    double top = 0;
    double right = 0;
    double bottom = 0;
};
```

### Lấy phần còn lại sau khi trừ viền và đệm

Hộp (10,20,100,60), border 1, padding bốn phía 4 có content (15,25,90,50). Dùng 0 làm đáy: không đủ chỗ cho chữ cũng không được tạo chiều rộng âm.

{/* snippet include/style.hpp#content */}

```cpp title="include/style.hpp — Lấy phần còn lại sau khi trừ viền và đệm"
inline Rect contentBox(Rect box, const BoxStyle& style) {
    return {box.x + style.border + style.padding.left, box.y + style.border + style.padding.top, std::max(0.0, box.width - 2 * style.border - style.padding.left - style.padding.right), std::max(0.0, box.height - 2 * style.border - style.padding.top - style.padding.bottom)};
}
```

## Ghép các phần lại

Trong C++ nhấn B. Mép vàng nằm ngoài nút, mép xanh dương là border, tím là phía trong viền, xanh ngọc bao content. Nhấn B lần nữa để quay về bàn quan sát.

```bash title="Terminal — Windows, Visual Studio"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Release --target project_67_checkpoint_2 --parallel 2
.\build\Release\project_67_checkpoint_2.exe
```

## Thử làm sai để hiểu đúng

Thử cộng margin vào hit area. Bấm khoảng trống sát nút sẽ làm đàn dừng, dù ngón trỏ chưa chạm nút nào.

## Tự kiểm tra kết quả

Tăng padding chỉ thu phần content của Button có chiều cao cố định. Tắt inspector không làm đổi đàn hoặc vùng chọn.

## Bài tập mở rộng

Đặt padding trái bằng 12, các cạnh còn lại bằng 4. Dự đoán cả tọa độ lẫn chiều rộng content trước khi chạy.
