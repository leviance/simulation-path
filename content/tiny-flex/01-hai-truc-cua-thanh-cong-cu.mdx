# Xoay cách nghĩ: xếp theo hàng hay theo cột?

## Vấn đề cần giải quyết

Tới đây bạn đổi được màu và khoảng đệm nhưng ba nút vẫn xếp hàng dọc. Trong bàn làm việc thật, Pause, Reset và Links hợp lý hơn khi đứng ngang nhau; hai slider dưới chúng vẫn cần chiều ngang để dễ kéo.

## Hiểu ý tưởng trước khi viết code

Đừng xoay đàn chim hay hoán đổi tọa độ chuột! Chỉ thay ý nghĩa của hai trục trong *nhóm* đang xếp. Với row, đi dọc dòng nghĩa là tăng x; với column thì tăng y. Kết thúc phép tính mới đổi lại thành Rect thông thường.

### Gói phép đổi trục vào một chỗ

Một dòng có offset chính 12, offset ngang 4, dài 80 và dày 20. Row cho Rect (12,4,80,20); column cho (4,12,20,80).

{/* snippet include/flex/line.hpp#axes */}

```cpp title="include/flex/line.hpp — Gói phép đổi trục vào một chỗ"
inline lab::Rect axisRect(Axis a, double main, double cross, double length, double thickness) {
    if (a == Axis::Row)
        return {main, cross, length, thickness};
    return {cross, main, thickness, length};
}
```

### Đọc các yêu cầu mới từ cùng một file

Parser cũ vẫn đọc selector và declaration. Từ mốc này display, flex-direction cùng những property thuộc subset Flex được nhận biết, chưa dùng hết để di chuyển widget.

{/* snippet include/style/sheet.hpp#rules */}

```cpp title="include/style/sheet.hpp — Đọc các yêu cầu mới từ cùng một file"
inline Sheet parseSheet(std::string_view source) {
    checkUtf8(source);
    Cursor c{source};
    c.take("\xef\xbb\xbf");
    Sheet sheet;
    c.skip();
    while (c.peek()) {
        if (sheet.rules.size() >= 64)
            fail(source, c.pos, "rule limit: 64");
        Rule rule;
        if (c.peek() == '#' || c.peek() == '.')
            rule.selector.prefix = source[c.pos++];
        rule.selector.name = c.word();
        if (!identifier(rule.selector.name))
            fail(source, c.pos, "expected simple selector");
        c.skip();
        c.need('{');
        c.skip();
        while (!c.take('}')) {
            Declaration d;
            d.offset = c.pos;
            d.key = c.word();
            c.skip();
            c.need(':');
            const auto begin = c.pos;
            while (c.peek() && c.peek() != ';' && c.peek() != '}')
                ++c.pos;
            d.value = trim(source.substr(begin, c.pos - begin));
            c.need(';');
            validateProperty(d, source);
            if (rule.properties.size() >= 24)
                fail(source, d.offset, "declaration limit: 24");
            rule.properties.push_back(d);
            c.skip();
        }
        sheet.rules.push_back(std::move(rule));
        c.skip();
    }
    return sheet;
}
```
