# Căn nhóm ở giữa không giống căn chữ trên nút

## Vấn đề cần giải quyết

Một hàng có thể đã đúng thứ tự mà vẫn trông lệch: các nút thấp hơn toolbar và nằm sát mép trên. Đừng sửa từng y. Hãy quyết định nhóm nằm ở đâu dọc dòng, rồi từng nút nằm ở đâu theo bề dày của dòng.

## Hiểu ý tưởng trước khi viết code

justify dùng phần dư *sau* grow; align dùng khoảng cách giữa bề dày khả dụng và bề dày của từng child. space-between chỉ chia giữa hai item trở lên; với một item, nó nằm ở đầu. Stretch chỉ kéo chiều tự động.

### Chọn vị trí trên cross axis

Toolbar cao 50, nút cao 10: start cho y=0, center cho y=20, end cho y=40. Chỉ đổi direction thì cùng phép tính này chuyển sang trục x.

{/* snippet include/flex/line.hpp#align */}

```cpp title="include/flex/line.hpp — Chọn vị trí trên cross axis"
const double extra = std::max(0.0, room - cross);
if (style.align == Align::Center)
    inset = extra / 2;
if (style.align == Align::End)
    inset = extra;
```

### Trả Rect về hệ tọa độ cửa sổ

Không đổi orientation của glyph hoặc sự kiện chuột. Một nút dời qua phải trong column vẫn nhận click trong chính border box nó đang vẽ.

{/* snippet include/flex/line.hpp#axes */}

```cpp title="include/flex/line.hpp — Trả Rect về hệ tọa độ cửa sổ"
inline lab::Rect axisRect(Axis a, double main, double cross, double length, double thickness) {
    if (a == Axis::Row)
        return {main, cross, length, thickness};
    return {cross, main, thickness, length};
}
```

## Thử làm sai để hiểu đúng

Áp justify cả sau khi grow đã dùng hết phần dư. Khi đó bạn vô tình cộng cùng một khoảng hai lần; nút cuối bị đẩy ra ngoài dù phép cộng basis đúng.
