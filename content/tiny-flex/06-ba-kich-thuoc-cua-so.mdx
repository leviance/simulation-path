## Viết code từng bước

### Dùng một lượt đo và một lượt đặt

Khi dirty, đo kích thước tự nhiên từ con lên cha, đặt khung từ cha xuống và đối chiếu lại focus. Một nghìn frame sạch không cần lặp lại công việc này.

{/* snippet include/flex/layout.hpp#reflow */}

```cpp title="include/flex/layout.hpp — Dùng một lượt đo và một lượt đặt"
inline void reflow(Desk& d, const FlexMap& optionsById) {
    auto& state = d.page.layout;
    if (!state.dirty)
        return;
    if (optionsById.empty()) {
        lab::ensureLayout(state, d.ui);
        return;
    }
    auto& root = *state.scene.tree.root;
    state.sizes.clear();
    const auto size = intrinsic(root, state.scene.styles, optionsById, state.sizes);
    placeFlex(root, {936 - state.width, 24, state.width, size.height}, state.scene.styles, optionsById, state.sizes);
    ++state.passes;
    state.dirty = false;
    lab::reconcile(state.scene.tree, d.ui);
}
```

### Đặt đáp số trước khi hỏi layout

Đoạn fixture kiểm hàng rỗng, một nút, khoảng dư và thiếu chỗ. Phần còn lại của tests đổi cả row/column, bốn justify, bốn align và chạy lại với file CSS thật.

{/* snippet tests/tests.cpp#golden */}

```cpp title="tests/tests.cpp — Đặt đáp số trước khi hỏi layout"
const Item fixed{40, 10, 0, 0, 0, 0, 0}, growing{20, 15, 2, 0, 0, 0, 0};
check(line(o, 100, 50, 8, {}).empty(), "empty row");
o.justify = Justify::Between;
const auto single = line(o, 100, 50, 8, {fixed});
check(single[0].x == 0 && single[0].width == 40, "single space-between starts at zero");
auto pair = line(o, 100, 50, 8, {fixed, growing});
check(pair[0].x == 0 && pair[1].x == 48 && pair[1].width == 52, "100 minus bases 60 and gap 8 leaves 32");
pair = line(o, 38, 50, 8, {fixed, growing});
check(pair[0].width == 40 && pair[1].x == 48 && pair[1].width == 20, "deficit clips; does not shrink");
```
