# Dựng căn phòng trước khi cho camera đi

## Vấn đề cần giải quyết

Ở P13, ta đứng ngoài nhìn một cube và thay đổi vị trí của nó. Bây giờ ta bước **vào trong một căn phòng**. Sàn, tường và các mốc đứng yên; về sau chỉ camera di chuyển. Nếu vẫn xoay cả room theo chuột, bạn chưa viết camera FPS.

Trước khi thêm WASD, hãy dựng một cảnh đủ rõ để nhận ra mình đang ở đâu. Bài này có phòng rộng 12, dài 22, cao 4 world unit, sàn lưới, khung tường/trần và hai hộp mốc lệch trái/phải.

## Hiểu ý tưởng trước khi viết code

World dùng +Y hướng lên. Phòng nằm trong X=[−6,6], Y=[0,4], Z=[0,22]. Mắt ban đầu ở (0,1.6,2), nhìn theo +Z. Điểm sàn vì thế có camera Y=−1.6; nếu đặt mắt ngay trên sàn, lưới dễ thu thành một đường ngang.

Mỗi cạnh là một `Segment3` gồm hai tọa độ world và màu. Danh sách `RoomGeometry` được tạo một lần, không sửa sau mỗi frame. Hai hộp dùng cùng quy ước tám đỉnh/mười hai cạnh của P13; chúng là **mốc quan sát, chưa có collision**.

## Viết code từng bước

### Bước 1 — Chạy bộ khung CPU trước

Tải ZIP, giải nén và mở terminal tại `CMakeLists.txt`:

```bash title="Terminal — kiểm tra Starter"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_14_starter
./build/Debug/project_14_starter.exe
```

Starter đã có framebuffer 1100×800, Bresenham, projection/near–far clipping từ P13, SDL window/texture và crosshair. Chưa có phòng. Resize/HiDPI letterbox bảng logic nên không kéo méo ảnh.

Các file toán nằm trong `projection.hpp` và `rotation.hpp`; `main.cpp` chỉ xử lý SDL, upload ảnh bằng `SDL_UpdateTexture` và present. Ta không cần viết lại vòng lặp SDL từ đầu.

### Bước 2 — Thêm dữ liệu căn phòng

`room.hpp` có `RoomBounds`, `Segment3` và alias vector. Mỗi lần thêm cạnh chỉ làm một việc:

```cpp title="include/room.hpp — appendSegment"
inline void appendSegment(RoomGeometry& room, Vec3 from, Vec3 to, std::uint32_t color) {
    room.push_back({from, to, color});
}
```

Tạo các đường sàn theo X/Z, thêm cột tường và thanh trần. Những đoạn dài vẫn an toàn vì renderer clip thật; không cần chặt đường thành nhiều mẩu để che lỗi visibility.

```cpp title="include/room.hpp — makeRoomGeometry"
inline RoomGeometry makeRoomGeometry(const RoomBounds& b, double gridSpacing) {
    RoomGeometry room;
    if (!std::isfinite(gridSpacing) || gridSpacing < 0.5 || gridSpacing > 4.0 ||
        !std::isfinite(b.minX) || !std::isfinite(b.maxX) || !std::isfinite(b.minZ) || !std::isfinite(b.maxZ) ||
        !std::isfinite(b.floorY) || !std::isfinite(b.ceilingY) ||
        b.maxX <= b.minX || b.maxZ <= b.minZ || b.ceilingY <= b.floorY ||
        b.maxX - b.minX > 100.0 || b.maxZ - b.minZ > 100.0) {
        return room;
    }
    // Đoạn dài vẫn đúng vì renderer clip near/far và screen trước Bresenham.
    for (double x = b.minX; x <= b.maxX + 1e-9; x += gridSpacing) {
        appendSegment(room, {x, b.floorY, b.minZ}, {x, b.floorY, b.maxZ}, 0x4484AEFFu);
    }
    for (double z = b.minZ; z <= b.maxZ + 1e-9; z += gridSpacing) {
        appendSegment(room, {b.minX, b.floorY, z}, {b.maxX, b.floorY, z}, 0x4484AEFFu);
        appendSegment(room, {b.minX, b.floorY, z}, {b.minX, b.ceilingY, z}, 0x7DA5EEFFu);
        appendSegment(room, {b.maxX, b.floorY, z}, {b.maxX, b.ceilingY, z}, 0x7DA5EEFFu);
        appendSegment(room, {b.minX, b.ceilingY, z}, {b.maxX, b.ceilingY, z}, 0x7570BEFFu);
    }
    for (double x = b.minX; x <= b.maxX + 1e-9; x += gridSpacing) {
        appendSegment(room, {x, b.floorY, b.minZ}, {x, b.ceilingY, b.minZ}, 0x7DA5EEFFu);
        appendSegment(room, {x, b.floorY, b.maxZ}, {x, b.ceilingY, b.maxZ}, 0x7DA5EEFFu);
    }
    appendSegment(room, {b.minX, b.ceilingY, b.minZ}, {b.minX, b.ceilingY, b.maxZ}, 0x7570BEFFu);
    appendSegment(room, {b.maxX, b.ceilingY, b.minZ}, {b.maxX, b.ceilingY, b.maxZ}, 0x7570BEFFu);
    // Các mốc lệch trái/phải giúp người xem nhận ra mình đang đi, không orbit.
    appendBox(room, {-3.0, 0.75, 8.0}, {0.8, 0.75, 0.8}, 0xFFB454FFu);
    appendBox(room, {3.0, 1.1, 16.0}, {1.0, 1.1, 1.0}, 0x53F0AEFFu);
    appendSegment(room, {b.minX, 2.0, b.maxZ}, {b.maxX, 2.0, b.maxZ}, 0xFFB454FFu);
    return room;
}
```

Vòng đầu giữ X, nối từ đầu đến cuối phòng; vòng tiếp theo giữ Z và dựng một lát khung ngang. `appendBox` tái dùng vertex/edge list của cube, rồi append các cạnh vào cùng room. Grid spacing bị giới hạn để input lỗi không tạo vòng lặp vô tận.

### Bước 3 — Đổi từ world về mắt cố định rồi clip

`viewPoint` ở checkpoint 1 trừ mắt mặc định (0,1.6,2). Chưa đọc camera position do người dùng điều khiển. Renderer xử lý từng đoạn:

```cpp title="include/view.hpp — projectRoomSegment"
inline std::optional<std::array<Vec2, 2>> projectRoomSegment(Vec3 worldA, Vec3 worldB, const Scene& scene) {
    Vec3 a = viewPoint(worldA, scene);
    Vec3 b = viewPoint(worldB, scene);
    if (!clipDepth(a, b, scene.lens)) {
        return std::nullopt;
    }
    const auto pa = projectPerspective(a, Camera3D{}, scene.lens, viewportFor());
    const auto pb = projectPerspective(b, Camera3D{}, scene.lens, viewportFor());
    if (!pa.screen || !pb.screen) {
        return std::nullopt;
    }
    Vec2 from = *pa.screen;
    Vec2 to = *pb.screen;
    if (!clipScreen(from, to, viewportFor())) {
        return std::nullopt;
    }
    return std::array<Vec2, 2>{from, to};
}
```

Near/far clip trong camera space trước khi chia Z. Hai screen point còn ở số thực được clip tiếp vào viewport trước khi làm tròn. Vì vậy một cột bị cắt một phần ở mép cửa sổ vẫn còn phần nhìn thấy, không biến mất nguyên cột.

### Bước 4 — Raster room bằng Bresenham

```cpp title="include/view.hpp — drawRoom"
inline RenderStats drawRoom(Framebuffer& image, const RoomGeometry& room, const Scene& scene) {
    RenderStats stats;
    for (const Segment3& segment : room) {
        const auto screen = projectRoomSegment(segment.from, segment.to, scene);
        if (!screen) {
            continue;
        }
        const Vec2 a = (*screen)[0];
        const Vec2 b = (*screen)[1];
        drawLine(image, static_cast<int>(std::lround(a.x)), static_cast<int>(std::lround(a.y)), static_cast<int>(std::lround(b.x)), static_cast<int>(std::lround(b.y)), segment.color);
        ++stats.visibleSegments;
    }
    return stats;
}
```

Màu sàn xanh lam đậm, tường xanh sáng, trần tím; hai hộp cam/xanh lá giúp phân biệt vị trí. SDL không vẽ line hay tính camera thay ta.

## Ghép các phần lại

Trong main, thay phần room rỗng của Starter bằng đoạn khởi tạo sau, trước vòng lặp:

```cpp title="src/main.cpp — đoạn ghép"
lab::Scene scene;
lab::RoomGeometry room;
room = lab::makeRoomGeometry(scene.bounds, 2.0);
// Geometry được tạo một lần; vòng lặp chỉ đọc const reference ở renderer.
const lab::RoomGeometry worldRoom = room;
```

Sau đó thay body `renderScene` trong `view.hpp` để gọi `drawRoom`. Nếu chỉ thêm các hàm ở trên mà giữ renderer rỗng của Starter, phòng sẽ chưa xuất hiện:

```cpp title="include/view.hpp — đoạn ghép"
inline RenderStats renderScene(Framebuffer& image, const Scene& scene, const RoomGeometry& room) {
    image.clear(kBackground);
    RenderStats stats;
    stats = drawRoom(image, room, scene);
    // Crosshair là overlay. Cảnh phòng không phụ thuộc cờ debug.
    if (scene.debug) {
        drawLine(image, 542, 400, 558, 400, kWhite);
        drawLine(image, 550, 392, 550, 408, kWhite);
    }
    return stats;
}
```

Main vẫn gọi `renderScene(image,scene,worldRoom)` mỗi lần cần vẽ lại, upload framebuffer và vẽ HUD bổ trợ. Khi tự viết, build lại target Starter của bạn; checkpoint là bản tham khảo để đối chiếu:

```bash title="Terminal — chạy checkpoint 1"
cmake --build build --config Debug --target project_14_checkpoint_1
./build/Debug/project_14_checkpoint_1.exe
```

Mặc định room có 96 segment, nhưng số segment raster được nhỏ hơn vì có phần sau mắt hoặc ngoài frustum. 96 không phải số cạnh luôn phải hiện trên ảnh.

## Thử làm sai để hiểu đúng

1. Đặt mắt ở Y=0. Các đường sàn nằm cùng cao độ với camera; cảm giác đứng trong phòng biến mất dù geometry không đổi.
2. Bỏ depth clip, thay bằng “hai đầu đều Visible”. Nhìn cạnh dài sát camera: những phần vẫn nhìn thấy cũng bị xóa.
3. Tạo room trong mỗi frame rồi trừ camera position trực tiếp vào các endpoint. Bạn đã trộn dữ liệu world với view; bài sau sẽ khó kiểm tra world có thật sự đứng yên hay không.

## Tự kiểm tra kết quả

- Thấy sàn, tường, trần và hai hộp mốc; không chỉ một cube giữa màn hình.
- Room nằm trong bounds đã chọn, mắt ở trong phòng và cao hơn sàn.
- Clip xảy ra trước int/Bresenham; không có spike hoặc đường khổng lồ.
- RoomGeometry giữ nguyên khi resize; SDL chỉ đổi cách trình bày bảng logic.
