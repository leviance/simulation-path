# Dựng chuỗi khối lượng và lò xo

## Vấn đề cần giải quyết

Hãy bắt đầu bằng một chuỗi nhìn thấy được và có dữ liệu rõ ràng. Ta cần biết mỗi khối nằm ở đâu, khối nào nối với khối nào và đầu nào được giữ cố định. Nếu nhảy thẳng vào lực Hooke, một lỗi index hoặc đổi tọa độ cũng rất dễ bị nhầm thành lỗi vật lý.

Bản cuối có chuỗi 32 khối, mở được cấu hình 20, 64 và 100 khối. Bài đầu dựng đủ 32 khối nhưng chưa cho chuyển động. Cặp hai khối ở bài 2 chỉ là thí nghiệm để hiểu lực, không phải sản phẩm cuối.

## Hiểu ý tưởng trước khi viết code

Starter đã có window, renderer, texture, framebuffer 1100×820 và event loop. Chạy Starter trước khi sửa: bạn sẽ thấy khung nhìn và giá treo, chưa có chuỗi. Cách trình bày vẫn như các project trước: **Scene → renderScene → framebuffer → SDL_UpdateTexture → present**.

Mỗi Particle giữ vị trí, vận tốc, lực và inverseMass. Mỗi Spring giữ hai index cùng restLength, stiffness và damping; nó không sao chép vị trí của khối. Với N khối, nối 0–1, 1–2,…, N−2–N−1 tạo đúng N−1 lò xo.

Ta dùng mét và giây, Y dương hướng lên. Điểm neo ở (0,0), khối sau thấp hơn khối trước 0,22 m. Vì khoảng cách ban đầu bằng restLength, mọi lò xo chưa biến dạng. Đây là trạng thái dễ kiểm, **chưa phải cân bằng khi bật trọng lực**.

### Bước 1 — Đọc dữ liệu và phần vẽ được cung cấp

Trong lab.hpp của Starter đã có các kiểu sau. Đọc chúng, không khai báo thêm bản trùng:

```cpp title="include/lab.hpp — Particle"
struct Particle {
    Vec2 position{};
    Vec2 velocity{};
    Vec2 force{};
    double inverseMass{1.0};
    double radius{0.1};
};
```

```cpp title="include/lab.hpp — Spring"
struct Spring {
    std::size_t first{};
    std::size_t second{};
    double restLength{0.4};
    double stiffness{100.0};
    double damping{1.0};
};
```

InverseMass là 1/m; riêng zero biểu thị khối không được tích phân. Bán kính ở đây chỉ phục vụ hình vẽ và chọn khối, không có collision giữa các mass.

Phần vẽ trong view.hpp đã đổi world point thành pixel bằng hàm này:

```cpp title="include/view.hpp — worldToScreen"
inline Vec2 worldToScreen(Vec2 point, const WorldView& view) {
    return {view.originX + view.scale * point.x, view.originY - view.scale * point.y};
}
```

Không ghi pixel ngược vào Particle.position. Scale hiển thị có thể đổi để chuỗi dài vừa khung, còn chiều dài vật lý vẫn là mét.

### Bước 2 — Tạo khối và liên kết trong cùng một vòng lặp

Thêm makeVerticalChain vào lab.hpp, sau các hàm kiểm dữ liệu có sẵn:

```cpp title="include/lab.hpp — makeVerticalChain"
inline SpringChain makeVerticalChain(std::size_t particleCount, Vec2 anchorPosition, double restLength, double mass, double radius, double stiffness, double damping) {
    SpringChain chain{};
    chain.anchorPosition = anchorPosition;
    if (particleCount < 2 || particleCount > 100 || !finiteVec2(anchorPosition) || !std::isfinite(restLength) || restLength <= 0.0 || !std::isfinite(mass) || mass <= 0.0 || !std::isfinite(1.0 / mass) || !std::isfinite(radius) || radius <= 0.0 || !std::isfinite(stiffness) || stiffness < 0.0 || !std::isfinite(damping) || damping < 0.0) {
        return chain;
    }
    chain.particles.reserve(particleCount);
    chain.springs.reserve(particleCount - 1);
    for (std::size_t index = 0; index < particleCount; ++index) {
        Particle particle{};
        particle.position = {anchorPosition.x, anchorPosition.y - double(index) * restLength};
        if (index == 0) {
            particle.inverseMass = 0.0;
        } else {
            particle.inverseMass = 1.0 / mass;
        }
        particle.radius = radius;
        chain.particles.push_back(particle);
        if (index > 0) {
            chain.springs.push_back({index - 1, index, restLength, stiffness, damping});
        }
    }
    if (!validChain(chain)) {
        return {};
    }
    return chain;
}
```

Giới hạn 100 được kiểm trước reserve. Index 0 có inverseMass=0; khối động có khối lượng m. Khi tạo khối i>0, nối i−1 với i. Vị trí của từng khối chỉ được lưu ở một nơi.

### Bước 3 — Đưa dữ liệu thật vào Scene

Thay rebuildScene trong scene.hpp bằng phiên bản sau:

```cpp title="include/scene.hpp — rebuildScene"
inline void rebuildScene(Scene& scene) {
    stopScene(scene);
    scene.message.clear();
    scene.chain = makeVerticalChain(static_cast<std::size_t>(scene.count), {0.0, 0.0}, scene.restLength, scene.mass, 0.10, scene.stiffness, scene.damping);
    beginMeasurement(scene);
}
```

Scene đã có count=32, mass=0,04 kg, restLength=0,22 m và các tham số cấu hình. beginMeasurement ở khung này chỉ đặt lại đồng hồ; phần đo năng lượng sẽ được viết sau.

### Bước 4 — Theo dữ liệu tới hình vẽ

Hàm này đã có trong Starter. Renderer chỉ duyệt các liên kết và khối vừa tạo:

```cpp title="include/view.hpp — drawChain"
inline void drawChain(Framebuffer& image, const Scene& scene, const WorldView& view) {
    for (const auto& spring : scene.chain.springs) {
        const auto& a = scene.chain.particles[spring.first];
        const auto& b = scene.chain.particles[spring.second];
        std::uint32_t color = 0x66738cffU;
        drawCoil(image, worldToScreen(a.position, view), worldToScreen(b.position, view), color);
    }
    for (std::size_t i = 0; i < scene.chain.particles.size(); ++i) {
        const auto& particle = scene.chain.particles[i];
        const Vec2 center = worldToScreen(particle.position, view);
        if (i == scene.selected) {
            drawNode(image, center, std::max(5.0, particle.radius * view.scale + 3.0), 0xffffffffU);
        }
        std::uint32_t color = 0x53f0aeffU;
        if (i == 0) {
            color = 0xc678ddffU;
        }
        drawNode(image, center, particle.radius * view.scale, color);
    }
}
```

Lò xo được vẽ thành đường gấp khúc bằng drawCoil; khối được tô bằng drawNode. Không có một chuỗi “để vẽ” khác với chuỗi “để mô phỏng”.

## Ghép các phần lại

Build project_25_starter rồi chạy lại. Bạn phải thấy 32 khối, 31 đoạn nối và khối trên cùng được đánh dấu là neo. R dựng lại cùng dữ liệu; F đổi debug. N chưa làm gì ở bài này vì phần tích phân chưa được viết.

Trong main, khung chạy đã gọi renderScene, upload framebuffer vào texture rồi present. Không cần tạo window/renderer thứ hai hoặc thêm một vòng lặp SDL khác.

## Thử làm sai để hiểu đúng

Chỉ đổi một chi tiết mỗi lần. Hãy dự đoán, chạy lại, ghi điều quan sát được rồi hoàn tác trước thí nghiệm tiếp theo.

1. Nối mọi spring trực tiếp từ khối 0 tới khối i, thay vì nối hai index liền kề i−1 và i. Hình trở thành nhiều nhánh cùng nối về neo, không còn là chain.

2. Đặt khoảng cách khởi tạo khác restLength rồi vẫn kết luận lò xo chưa biến dạng. Tính lại d−L₀ trước khi bật physics.

3. Đổi inverseMass của neo thành một số rất nhỏ. Nó vẫn là vật động rất nặng, không phải ràng buộc cố định.

## Tự kiểm tra kết quả

- Default tạo đúng 32 Particle và 31 Spring; link i nối i với i+1.
- Đầu trên có inverseMass=0; các khối còn lại có inverseMass=25 kg⁻¹.
- Khoảng cách ban đầu bằng 0,22 m; reset tái tạo cùng dữ liệu.
- Đổi scale hiển thị không sửa vị trí hoặc chiều dài vật lý.
