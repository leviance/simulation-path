# Cho chuỗi chuyển động bằng semi-implicit Euler

## Vấn đề cần giải quyết

Ta đã biết lực tại một thời điểm. Bây giờ cần nối lực ấy với chuyển động và vòng lặp SDL. Có hai lỗi rất dễ lẫn: sai thứ tự velocity/position trong integrator và dùng thời gian render làm dt của physics.

## Hiểu ý tưởng trước khi viết code

Semi-implicit Euler dùng:

$$
a_n=F_n w,\qquad v_{n+1}=v_n+a_n h,\qquad p_{n+1}=p_n+v_{n+1}h,\quad w=1/m.
$$

Position dùng **velocity mới**. Ví dụ F=4 N, m=2 kg, h=0,5 s và ban đầu đứng yên: a=2 m/s², v mới=1 m/s, p đi thêm 0,5 m. Đây là một đáp án tính tay cho hàm một khối, không phải dt phù hợp để chạy chuỗi mặc định.

Toàn chuỗi phải nhận lực từ cùng state n. Sau khi tính đủ lực mới tích phân mọi khối động; neo được bỏ qua. Dùng candidate rồi commit giúp một lỗi ở khối cuối không để lại nửa chuỗi đã chạy trước.

Ứng dụng mặc định h=1/480 s. Frame time chỉ nạp accumulator; mỗi frame nhận tối đa 0,05 s và chạy tối đa 32 substep. Phần thời gian không xử lý được được báo ra, không bí mật tăng h.

### Bước 1 — Viết một bước cho một khối

Thêm integrateParticle vào lab.hpp:

```cpp title="include/lab.hpp — integrateParticle"
inline bool integrateParticle(Particle& particle, double deltaSeconds) {
    if (!finiteParticle(particle) || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0) {
        return false;
    }
    if (particle.inverseMass == 0.0) {
        return true;
    }
    const Vec2 acceleration = scale(particle.force, particle.inverseMass);
    const Vec2 nextVelocity = add(particle.velocity, scale(acceleration, deltaSeconds));
    const Vec2 nextPosition = add(particle.position, scale(nextVelocity, deltaSeconds));
    if (!finiteVec2(nextVelocity) || !finiteVec2(nextPosition)) {
        return false;
    }
    particle.velocity = nextVelocity;
    particle.position = nextPosition;
    return true;
}
```

Giữ nextVelocity và nextPosition thành hai biến riêng. Đây vừa là nội dung đang học vừa là chỗ kiểm nonfinite trước khi sửa particle. inverseMass=0 trả thành công mà không tích phân.

### Bước 2 — Tính đủ lực rồi tích phân cả chuỗi

Thêm enforceAnchor và stepElasticChain:

```cpp title="include/lab.hpp — enforceAnchor"
inline void enforceAnchor(SpringChain& chain) {
    if (chain.particles.empty()) {
        return;
    }
    Particle& anchor = chain.particles.front();
    anchor.position = chain.anchorPosition;
    anchor.velocity = {};
}
```

```cpp title="include/lab.hpp — stepElasticChain"
inline bool stepElasticChain(SpringChain& chain, double deltaSeconds, Vec2 gravity, bool gravityEnabled) {
    if (!validChain(chain) || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0 || deltaSeconds > 0.1) {
        return false;
    }
    SpringChain candidate = chain;
    if (!accumulateElasticForces(candidate, gravity, gravityEnabled)) {
        return false;
    }
    for (Particle& particle : candidate.particles) {
        if (!integrateParticle(particle, deltaSeconds)) {
            return false;
        }
    }
    enforceAnchor(candidate);
    chain = std::move(candidate);
    return true;
}
```

EnforceAnchor giữ invariant cuối bước; nó không thay cho việc bỏ qua neo trong integrator. Candidate chỉ thay chain gốc khi mọi khối đã được xử lý hợp lệ.

### Bước 3 — Lập kế hoạch fixed steps có giới hạn

Thêm FixedStepPlan và planFixedSteps:

```cpp title="include/lab.hpp — FixedStepPlan"
struct FixedStepPlan {
    int steps{};
    double remainder{};
    double droppedTime{};
};
```

```cpp title="include/lab.hpp — planFixedSteps"
inline FixedStepPlan planFixedSteps(double accumulator, double frameSeconds, double fixedDeltaSeconds, int maximumSteps, double maximumFrameSeconds) {
    if (!std::isfinite(accumulator) || accumulator < 0.0 || accumulator > 1.0 || !std::isfinite(frameSeconds) || frameSeconds < 0.0 || !std::isfinite(fixedDeltaSeconds) || fixedDeltaSeconds < 1e-6 || fixedDeltaSeconds > 1.0 || maximumSteps < 1 || maximumSteps > 256 || !std::isfinite(maximumFrameSeconds) || maximumFrameSeconds <= 0.0 || maximumFrameSeconds > 1.0) {
        return {};
    }
    const double acceptedFrame = std::min(frameSeconds, maximumFrameSeconds);
    const double available = accumulator + acceptedFrame;
    const double availableSteps = std::floor((available + kSpringEpsilon) / fixedDeltaSeconds);
    const int steps = static_cast<int>(std::min(availableSteps, double(maximumSteps)));
    const double discarded = std::max(0.0, availableSteps - double(steps)) * fixedDeltaSeconds;
    const double remainder = std::max(0.0, available - availableSteps * fixedDeltaSeconds);
    const double dropped = frameSeconds - acceptedFrame + discarded;
    return {steps, remainder, dropped};
}
```

AvailableSteps vẫn là số thực cho tới sau khi đã giới hạn, tránh cast một lượng bước khổng lồ sang int. Các guard đầu hàm cũng chặn dt quá nhỏ và budget vô hạn.

Thêm withinExperiment và stepScene vào scene.hpp:

```cpp title="include/scene.hpp — withinExperiment"
inline bool withinExperiment(const SpringChain& chain) {
    if (!validChain(chain)) {
        return false;
    }
    for (const auto& particle : chain.particles) {
        if (std::abs(particle.position.x) > 1000.0 || std::abs(particle.position.y) > 1000.0 || length(particle.velocity) > 10000.0) {
            return false;
        }
    }
    return true;
}
```

```cpp title="include/scene.hpp — stepScene"
inline bool stepScene(Scene& scene) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5 || scene.selected == 0 || scene.selected >= scene.chain.particles.size()) {
        stopScene(scene);
        scene.message = "Invalid dt index.";
        return false;
    }
    SpringChain candidate = scene.chain;
    bool accepted = false;
    accepted = stepElasticChain(candidate, kStepOptions[scene.dtIndex], scene.gravity, scene.gravityEnabled);
    if (!accepted || !withinExperiment(candidate)) {
        stopScene(scene);
        scene.message = "Experiment stopped: invalid/degenerate state or envelope exceeded. Reset or reduce dt.";
        return false;
    }
    scene.traceBefore = scene.chain.particles[scene.selected];
    scene.traceAfter = candidate.particles[scene.selected];
    scene.hasTrace = true;
    scene.chain = std::move(candidate);
    ++scene.steps;
    ++scene.substeps;
    scene.elapsed = double(scene.steps) * kStepOptions[scene.dtIndex];
    refreshMetrics(scene);
    return true;
}
```

Giới hạn thí nghiệm không sửa position hoặc velocity. Nếu vượt ngưỡng hay gặp spring suy biến, dừng và giữ state trước bước lỗi. Steps/elapsed chỉ tăng sau khi candidate được chấp nhận.

Thêm advanceFrame:

```cpp title="include/scene.hpp — advanceFrame"
inline void advanceFrame(Scene& scene, double frameSeconds) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5) {
        stopScene(scene);
        return;
    }
    scene.substeps = 0;
    if (scene.paused) {
        return;
    }
    const auto plan = planFixedSteps(scene.accumulator, frameSeconds, kStepOptions[scene.dtIndex], 32, 0.05);
    scene.accumulator = plan.remainder;
    scene.droppedTime += plan.droppedTime;
    for (int i = 0; i < plan.steps; ++i) {
        if (!stepScene(scene)) {
            break;
        }
    }
}
```

## Ghép các phần lại

Build Starter, nhấn N rồi đọc trace node đang chọn: F đổi thành a, v thay đổi trước, p dùng v mới. Nhấn Space để chạy liên tục. R reset; pause không tích lũy khoảng thời gian ngồi đọc bài.

Chuỗi còn dao động lâu vì chưa có damping. Spring force lưu trong particle sau một bước là lực $F_n$ đã dùng cho bước ấy, không phải một lần tính lại tại $p_{n+1}$. Vì vậy readout gọi rõ là “lực đã dùng ở bước gần nhất”.

## Thử làm sai để hiểu đúng

Chỉ đổi một chi tiết mỗi lần. Hãy dự đoán, chạy lại, ghi điều quan sát được rồi hoàn tác trước thí nghiệm tiếp theo.

1. Đổi position trước velocity. Đó là explicit Euler, không phải semi-implicit; so sai số bằng cùng một fixture rồi hoàn tác.

2. Vừa tính xong spring đầu tiên đã tích phân hai endpoint. Spring sau đọc state khác, kết quả phụ thuộc thứ tự vòng lặp.

3. Tăng elapsed trước khi biết step có thành công không. Một thí nghiệm đã dừng sẽ báo thời gian chưa thực sự mô phỏng.

## Tự kiểm tra kết quả

- Đáp án 4 N/2 kg/0,5 s khớp v=1 m/s và p=0,5 m trong hàm một khối.
- Mọi force được tính trước lần integrate đầu tiên.
- 120 frame×1/120 s và 30 frame×1/30 s cùng tạo 480 bước ở h=1/480 s.
- N tạo đúng một bước; neo luôn ở (0,0); frame guard và thời gian bị bỏ có số đo.
- Bước lỗi không đổi một phần chain và không tăng elapsed.
