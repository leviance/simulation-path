# Làm dao động tắt dần bằng damping dọc trục

## Vấn đề cần giải quyết

Chuỗi lý tưởng có thể dao động rất lâu. Ta muốn năng lượng cơ học chuyển dần thành phần không được mô hình hóa, thay vì tiếp tục quay qua lại giữa động năng và thế năng. Cách làm phải gắn với chuyển động của lò xo, không phải một phép giảm velocity tùy ý trên mọi khối.

## Hiểu ý tưởng trước khi viết code

Tốc độ đổi chiều dài là $u=(v_B-v_A)\cdot n$. Damping dọc trục cho:

$$
F_A=(k(d-L_0)+cu)n,\qquad F_B=-F_A.
$$

Nếu hai đầu đi xa nhau, u dương và lực cản kéo chúng lại. Nếu đang gần nhau, u âm và phần damping chống lại chuyển động ấy. c có đơn vị kg/s; nó không cùng đơn vị với k.

**Bật damping rồi, vì sao dây vẫn đung đưa?** Lực cản ở đây chỉ chống lại việc hai đầu lò xo tiến lại gần hoặc rời xa nhau. Nếu một đoạn dây đang quét ngang nhưng gần như không đổi chiều dài, lực cản này rất nhỏ. Dao động co–giãn có thể giảm nhanh trong khi chuyển động đung đưa còn kéo dài; không thể hứa rằng mọi khối sẽ đứng yên sau một số giây cố định. Mô hình chưa có lực cản không khí tác dụng lên từng khối. Ta cũng không tự đặt vận tốc về 0 khi thấy dây đã chuyển động chậm.

Khi tắt damping và không kéo dây, mô hình lý tưởng không có cơ chế tiêu hao cơ năng. Chương trình vẫn có sai số tích phân, nên phải đo drift thay vì khẳng định máy tính bảo toàn năng lượng tuyệt đối.

Công suất riêng của damping là:

$$
P_D=F_{D,A}\cdot v_A+F_{D,B}\cdot v_B=-cu^2\leq0.
$$

Ví dụ c=4 kg/s, vận tốc tương đối dọc trục 2 m/s cho công suất −16 W. Thành phần tiếp tuyến 3 m/s không tự tạo lực cản dọc trục.

Đây là tính chất của mô hình lực liên tục. Phép tích phân rời rạc vẫn có sai số; không kết luận mọi sample cơ năng bắt buộc giảm tuyệt đối đơn điệu ở mọi dt.

### Bước 1 — Dùng lại hình học, bổ sung phần lực cản

Thêm sampleDampedSpring sau phần fixed-step planner trong lab.hpp:

```cpp title="include/lab.hpp — sampleDampedSpring"
inline SpringSample sampleDampedSpring(const SpringChain& chain, const Spring& spring) {
    SpringSample sample = sampleElasticSpring(chain, spring);
    if (!sample.valid) {
        return sample;
    }
    const double forceMagnitude = spring.stiffness * sample.stretch + spring.damping * sample.relativeSpeed;
    sample.forceOnFirst = scale(sample.direction, forceMagnitude);
    sample.valid = finiteVec2(sample.forceOnFirst);
    return sample;
}
```

Direction, stretch và relativeSpeed đều lấy từ sampleElasticSpring. Không gọi integrate ở đây và không sửa velocity trong một hàm được đặt tên sample.

### Bước 2 — Cộng lực có damping cho toàn chuỗi

Thêm accumulateDampedForces:

```cpp title="include/lab.hpp — accumulateDampedForces"
inline bool accumulateDampedForces(SpringChain& chain, Vec2 gravity, bool gravityEnabled) {
    if (!validChain(chain) || !finiteVec2(gravity)) {
        return false;
    }
    for (const Spring& spring : chain.springs) {
        if (!sampleDampedSpring(chain, spring).valid) {
            return false;
        }
    }
    clearForces(chain);
    if (gravityEnabled) {
        addGravity(chain, gravity);
    }
    for (const Spring& spring : chain.springs) {
        const SpringSample sample = sampleDampedSpring(chain, spring);
        Particle& first = chain.particles[spring.first];
        Particle& second = chain.particles[spring.second];
        first.force = add(first.force, sample.forceOnFirst);
        second.force = subtract(second.force, sample.forceOnFirst);
    }
    return validChain(chain);
}
```

Trình tự vẫn là kiểm dữ liệu, clear, gravity rồi từng cặp lực đối nhau. Hai endpoint không nhất thiết có cùng khối lượng nhưng vẫn nhận hai force đối nhau; gia tốc mới phụ thuộc inverseMass.

### Bước 3 — Viết một bước có damping

Thêm stepDampedChain:

```cpp title="include/lab.hpp — stepDampedChain"
inline bool stepDampedChain(SpringChain& chain, double deltaSeconds, Vec2 gravity, bool gravityEnabled) {
    if (!validChain(chain) || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0 || deltaSeconds > 0.1) {
        return false;
    }
    SpringChain candidate = chain;
    if (!accumulateDampedForces(candidate, gravity, gravityEnabled)) {
        return false;
    }
    for (Particle& particle : candidate.particles) {
        if (!integrateParticle(particle, deltaSeconds)) {
            return false;
        }
    }
    enforceAnchor(candidate);
    chain = std::move(candidate);
    return true;
}
```

Không đổi integrator. Sự khác biệt là loại force đưa vào candidate trước khi integrate.

Trong scene.hpp, thay stepScene để chọn lực có/không damping:

```cpp title="include/scene.hpp — stepScene"
inline bool stepScene(Scene& scene) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5 || scene.selected == 0 || scene.selected >= scene.chain.particles.size()) {
        stopScene(scene);
        scene.message = "Invalid dt index.";
        return false;
    }
    SpringChain candidate = scene.chain;
    bool accepted = false;
    if (scene.dampingEnabled) {
        accepted = stepDampedChain(candidate, kStepOptions[scene.dtIndex], scene.gravity, scene.gravityEnabled);
    } else {
        accepted = stepElasticChain(candidate, kStepOptions[scene.dtIndex], scene.gravity, scene.gravityEnabled);
    }
    if (!accepted || !withinExperiment(candidate)) {
        stopScene(scene);
        scene.message = "Experiment stopped: invalid/degenerate state or envelope exceeded. Reset or reduce dt.";
        return false;
    }
    scene.traceBefore = scene.chain.particles[scene.selected];
    scene.traceAfter = candidate.particles[scene.selected];
    scene.hasTrace = true;
    scene.chain = std::move(candidate);
    ++scene.steps;
    ++scene.substeps;
    scene.elapsed = double(scene.steps) * kStepOptions[scene.dtIndex];
    refreshMetrics(scene);
    return true;
}
```

### Bước 4 — Nối toggle với trạng thái đang có

Thay makeScene để cấu hình mặc định của bài bật damping:

```cpp title="include/scene.hpp — makeScene"
inline Scene makeScene() {
    Scene scene{};
    scene.gravityEnabled = true;
    scene.dampingEnabled = true;
    rebuildScene(scene);
    return scene;
}
```

Trong main, thêm D:

```cpp title="src/main.cpp — damping toggle"
if (key == SDLK_D) {
                    lab::stopScene(scene);
                    scene.dampingEnabled = !scene.dampingEnabled;
                    lab::beginMeasurement(scene);

```

D dừng mô phỏng và bắt đầu lại mốc đo, nhưng không dựng lại vị trí/vận tốc. Bấm Space chạy tiếp để thấy chính trạng thái ấy có damping hay không. R vẫn trả về preset mặc định.
