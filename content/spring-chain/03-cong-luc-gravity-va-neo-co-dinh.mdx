# Cộng lực, trọng lực và giữ điểm neo

## Vấn đề cần giải quyết

Một khối ở giữa dây được nối với hai hàng xóm, đồng thời chịu trọng lực. Nếu tính xong một lò xo rồi ghi đè force của khối, lực từ lò xo trước sẽ biến mất. Ta cần một nơi cộng dồn lực của **cùng một lần tính**, không phải cộng dồn qua nhiều frame.

## Hiểu ý tưởng trước khi viết code

Với khối i, $F_i=m_i g+\sum F_{\text{spring},i}$. Mỗi liên kết A–B cộng $+F_A$ vào A và $-F_A$ vào B. Vì đây là lực nội bộ, tổng lực của riêng cặp bằng zero; tổng toàn chuỗi vẫn có thể khác zero vì trọng lực và giá treo.

Quy trình là **xóa toàn bộ force → cộng trọng lực → duyệt mọi spring**. Chưa đổi velocity hay position trong lúc cộng. Điểm neo vẫn nhận lực spring trong accumulator, nhưng ở bài tích phân nó sẽ được bỏ qua. Giá treo cung cấp phản lực giữ điểm ấy cố định.

Một mass 0,04 kg nhận trọng lực (0,−0,3924) N. Trong trạng thái treo cân bằng, spring trên cùng phải đỡ cả phần dây phía dưới, không chỉ đỡ một khối.

```cpp title="include/lab.hpp — clearForces"
    }
}
```

Không đặt clearForces bên trong vòng duyệt spring. Một khối phải giữ tất cả đóng góp trong cùng substep.

### Bước 2 — Cộng trọng lực đúng theo khối lượng

Thêm addGravity sau clearForces:

```cpp title="include/lab.hpp — addGravity"
inline void addGravity(SpringChain& chain, Vec2 gravity) {
    if (!finiteVec2(gravity)) {
        return;
    }
    for (Particle& particle : chain.particles) {
        if (particle.inverseMass == 0.0) {
            continue;
        }
        const double mass = 1.0 / particle.inverseMass;
        particle.force = add(particle.force, scale(gravity, mass));
    }
}
```

Gravity là gia tốc m/s², không phải lực N. Nếu chỉ cộng g vào force, khối nặng/nhẹ sẽ có gia tốc sai sau khi nhân inverseMass.

### Bước 3 — Mỗi spring tác động hai đầu đối nhau

Thêm hàm duyệt liên kết:

```cpp title="include/lab.hpp — addElasticSpringForces"
inline void addElasticSpringForces(SpringChain& chain) {
    for (const Spring& spring : chain.springs) {
        const SpringSample sample = sampleElasticSpring(chain, spring);
        if (!sample.valid) {
            continue;
        }
        Particle& first = chain.particles[spring.first];
        Particle& second = chain.particles[spring.second];
        first.force = add(first.force, sample.forceOnFirst);
        second.force = subtract(second.force, sample.forceOnFirst);
    }
}
```

Lực trên neo không bị xóa riêng sau vòng này. Ta cần nó để đọc phản lực mà giá treo phải cung cấp.

### Bước 4 — Ghép ba pha thành một lần tính lực

Hàm này kiểm dữ liệu và mọi sample trước khi cộng:

```cpp title="include/lab.hpp — accumulateElasticForces"
inline bool accumulateElasticForces(SpringChain& chain, Vec2 gravity, bool gravityEnabled) {
    if (!validChain(chain) || !finiteVec2(gravity)) {
        return false;
    }
    for (const Spring& spring : chain.springs) {
        if (!sampleElasticSpring(chain, spring).valid) {
            return false;
        }
    }
    clearForces(chain);
    if (gravityEnabled) {
        addGravity(chain, gravity);
    }
    addElasticSpringForces(chain);
    return validChain(chain);
}
```

Scene quay lại 32 khối và lệch một khối giữa sang X để nhìn được lực phục hồi. Thay rebuildScene:

```cpp title="include/scene.hpp — rebuildScene"
inline void rebuildScene(Scene& scene) {
    stopScene(scene);
    scene.message.clear();
    scene.chain = makeVerticalChain(static_cast<std::size_t>(scene.count), {0.0, 0.0}, scene.restLength, scene.mass, 0.10, scene.stiffness, scene.damping);
    scene.selected = scene.chain.particles.size() / 2;
    scene.chain.particles[scene.selected].position.x += 0.35;
    beginMeasurement(scene);
    accumulateElasticForces(scene.chain, scene.gravity, scene.gravityEnabled);
}
```

Hàm trả bool để caller biết cả lượt tính có hợp lệ không. Ở solver của bài sau, ta làm trên candidate và chỉ chấp nhận khi toàn bộ bước đúng.

Fixture không còn là cặp hai khối. Thay makeWorldView về góc nhìn chuỗi và thay drawChain/renderScene để vector lực đọc accumulator:

```cpp title="include/view.hpp — makeWorldView"
inline WorldView makeWorldView(const Scene& scene) {
    const double links = double(std::max(2, scene.count) - 1);
    double expectedExtension = 0.0;
    if (scene.gravityEnabled && scene.stiffness > 0.0) {
        expectedExtension = scene.mass * std::abs(scene.gravity.y) * links * (links + 1.0) / (2.0 * scene.stiffness);
    }
    const double height = std::max(3.0, links * scene.restLength + expectedExtension + 1.6);
    return {std::min(110.0, 500.0 / height), 350.0, 130.0};
}
```

```cpp title="include/view.hpp — drawChain"
inline void drawChain(Framebuffer& image, const Scene& scene, const WorldView& view) {
    for (const auto& spring : scene.chain.springs) {
        const auto& a = scene.chain.particles[spring.first];
        const auto& b = scene.chain.particles[spring.second];
        std::uint32_t color = 0x66738cffU;
        const double stretch = length(subtract(b.position, a.position)) - spring.restLength;
        if (stretch > 0.002) {
            color = 0xe5c07bffU;
        } else if (stretch < -0.002) {
            color = 0x56b6c2ffU;
        }
        drawCoil(image, worldToScreen(a.position, view), worldToScreen(b.position, view), color);
    }
    for (std::size_t i = 0; i < scene.chain.particles.size(); ++i) {
        const auto& particle = scene.chain.particles[i];
        const Vec2 center = worldToScreen(particle.position, view);
        if (i == scene.selected) {
            drawNode(image, center, std::max(5.0, particle.radius * view.scale + 3.0), 0xffffffffU);
        }
        drawNode(image, center, particle.radius * view.scale, i == 0 ? 0xc678ddffU : 0x53f0aeffU);
        if (scene.debug) {
            const Vec2 tip = worldToScreen(add(particle.position, scale(particle.force, 0.08)), view);
            drawForceArrow(image, center, tip);
        }
    }
}
```

```cpp title="include/view.hpp — renderScene"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear();
    const WorldView view = makeWorldView(scene);
    rectangle(image, 40, 100, 690, 650, kRail, false);
    if (scene.debug) {
        for (int row = 1; row <= 10; ++row) {
            const double y = 100.0 + 50.0 * double(row);
            drawLine(image, 40, y, 690, y, kGrid);
        }
    }
    drawChain(image, scene, view);
    const Vec2 anchor = worldToScreen(scene.chain.anchorPosition, view);
    rectangle(image, int(anchor.x - 20), int(anchor.y - 25), int(anchor.x + 20), int(anchor.y - 10), 0xc678ddffU, true);
    drawLine(image, anchor.x, anchor.y - 10, anchor.x, anchor.y, 0xc678ddffU);
}
```

## Ghép các phần lại

Build Starter. Bài này vẫn là ảnh của một trạng thái, không phải animation. G bật/tắt gravity và dựng lại fixture. Các mũi tên đỏ đọc đúng accumulator; chúng có giới hạn chiều dài hiển thị nên hãy dùng số N để so độ lớn chính xác.

Khối lệch giữa dây bị hai spring kéo về gần trục. Các khối chưa biến dạng còn lại chỉ có trọng lực. Khi tắt gravity, tổng mọi lực nội bộ, kể cả lực trên neo, phải gần zero.

## Thử làm sai để hiểu đúng

Chỉ đổi một chi tiết mỗi lần. Hãy dự đoán, chạy lại, ghi điều quan sát được rồi hoàn tác trước thí nghiệm tiếp theo.

1. Gán first.force=F thay vì cộng vào force. Khối giữa sẽ mất đóng góp của một hàng xóm.

2. Xóa force ngay trước mỗi spring. Kết quả phụ thuộc thứ tự duyệt liên kết.

3. Cộng g trực tiếp vào force rồi lại nhân inverseMass. Kiểm mass 0,04 kg sẽ thấy gia tốc không còn −9,81 m/s².

## Tự kiểm tra kết quả

- Mỗi lượt chỉ xóa lực cũ một lần.
- Tổng hai lực của một spring bằng zero, nhưng từng khối có thể nhận nhiều spring force.
- Gravity của mass 0,04 kg là −0,3924 N theo Y.
- Neo có thể có force khác zero mà vẫn không chuyển động; force và acceleration không phải cùng đại lượng.

## Bài tập mở rộng

Tạo chuỗi ba khối động dưới một neo. Tính tay lực căng của từng spring ở trạng thái treo cân bằng: từ dưới lên lần lượt là mg, 2mg, 3mg. Dùng độ giãn bằng lực căng/k để dựng trạng thái ấy, rồi kiểm force trên từng khối động gần zero.
