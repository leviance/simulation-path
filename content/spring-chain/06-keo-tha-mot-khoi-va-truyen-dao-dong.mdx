# Kéo một khối và quan sát dao động lan truyền

## Vấn đề cần giải quyết

Một chuỗi chạy đúng khi không có input vẫn có thể hỏng khi kéo bằng chuột: khối nhảy tâm tới con trỏ, một pointer khác chiếm thao tác, hoặc thả ngoài cửa sổ để lại capture. Ta sẽ đưa input vào mô hình với quy tắc rõ ràng, không cho renderer tự thay state.

## Hiểu ý tưởng trước khi viết code

Trong lúc cầm, khối được chọn là **kinematic**: vị trí do target điều khiển, velocity giữ zero và nó không được tích phân. Spring vẫn đọc vị trí target để tạo lực lên hàng xóm. Nếu mô phỏng đang chạy, bạn sẽ thấy phản ứng lan từ khối ấy qua các liên kết.

Lưu grabOffset = vị trí khối − vị trí con trỏ lúc bắt đầu. Target = con trỏ + grabOffset, nhờ vậy click lệch tâm không làm khối nhảy.

Vận tốc thả được ước lượng từ hai target gần nhất và khoảng thời gian giữa chúng, giới hạn 6 m/s. Đây là chính sách input đơn giản: nếu mẫu up trùng target trước, vận tốc thả là zero. Biến dạng đang giữ trong spring vẫn tạo dao động sau khi thả; đây không phải bộ ước lượng vận tốc bàn tay.

Chuột có thể đưa công vào hệ. Trong lúc kéo không dùng ΔE để kết luận solver sai; khi bắt đầu/kết thúc/hủy một can thiệp, ta bắt lại mốc đo.

### Bước 1 — Chọn khối động và giữ độ lệch lúc cầm

Thêm DragConstraint và nearestDynamicParticle vào lab.hpp:

```cpp title="include/lab.hpp — DragConstraint"
struct DragConstraint {
    bool active{};
    std::size_t particleIndex{kNoParticle};
    Vec2 target{};
    Vec2 releaseVelocity{};
    Vec2 grabOffset{};
};
```

```cpp title="include/lab.hpp — nearestDynamicParticle"
inline std::size_t nearestDynamicParticle(const SpringChain& chain, Vec2 point, double maximumDistance) {
    if (!validChain(chain) || !finiteVec2(point) || !std::isfinite(maximumDistance) || maximumDistance < 0.0) {
        return kNoParticle;
    }
    std::size_t nearest = kNoParticle;
    double nearestDistanceSquared = maximumDistance * maximumDistance;
    for (std::size_t index = 0; index < chain.particles.size(); ++index) {
        const Particle& particle = chain.particles[index];
        if (particle.inverseMass == 0.0) {
            continue;
        }
        const double distanceSquared = lengthSquared(subtract(particle.position, point));
        if (distanceSquared <= nearestDistanceSquared) {
            nearestDistanceSquared = distanceSquared;
            nearest = index;
        }
    }
    return nearest;
}
```

Hàm tìm khối bỏ qua inverseMass=0. Bán kính chọn sẽ được đổi từ 9 logical pixel sang world unit, không nhân DPR vào world position.

Thêm beginDrag:

```cpp title="include/lab.hpp — beginDrag"
inline bool beginDrag(SpringChain& chain, DragConstraint& drag, Vec2 point, double maximumDistance) {
    const std::size_t index = nearestDynamicParticle(chain, point, maximumDistance);
    if (index == kNoParticle) {
        return false;
    }
    drag.active = true;
    drag.particleIndex = index;
    drag.target = chain.particles[index].position;
    drag.grabOffset = subtract(chain.particles[index].position, point);
    drag.releaseVelocity = {};
    chain.particles[index].velocity = {};
    return true;
}
```

### Bước 2 — Cập nhật target và dùng đúng mẫu cuối

Thêm moveDrag và endDrag:

```cpp title="include/lab.hpp — moveDrag"
inline bool moveDrag(SpringChain& chain, DragConstraint& drag, Vec2 target, double sampleSeconds, double maximumReleaseSpeed) {
    if (!drag.active || drag.particleIndex == 0 || drag.particleIndex >= chain.particles.size() || !finiteVec2(target) || !std::isfinite(sampleSeconds) || sampleSeconds <= 0.0 || !std::isfinite(maximumReleaseSpeed) || maximumReleaseSpeed < 0.0) {
        return false;
    }
    Particle& particle = chain.particles[drag.particleIndex];
    target = add(target, drag.grabOffset);
    const Vec2 displacement = subtract(target, drag.target);
    Vec2 sampledVelocity = scale(displacement, 1.0 / sampleSeconds);
    const double sampledSpeed = length(sampledVelocity);
    if (!finiteVec2(target) || !finiteVec2(sampledVelocity) || !std::isfinite(sampledSpeed)) {
        return false;
    }
    if (sampledSpeed > maximumReleaseSpeed && sampledSpeed > kSpringEpsilon) {
        sampledVelocity = scale(sampledVelocity, maximumReleaseSpeed / sampledSpeed);
    }
    drag.target = target;
    drag.releaseVelocity = sampledVelocity;
    particle.position = target;
    particle.velocity = {};
    return true;
}
```

```cpp title="include/lab.hpp — endDrag"
inline bool endDrag(SpringChain& chain, DragConstraint& drag) {
    if (!drag.active || drag.particleIndex == 0 || drag.particleIndex >= chain.particles.size() || !finiteVec2(drag.releaseVelocity)) {
        return false;
    }
    chain.particles[drag.particleIndex].velocity = drag.releaseVelocity;
    drag = {};
    return true;
}
```

SampleSeconds là thời gian giữa hai input sample, không phải fixed dt. Chỉ release velocity bị giới hạn theo chính sách input; solver không clamp velocity của một khối đang dao động tự do.

### Bước 3 — Giữ khối kinematic trong mỗi substep

Thêm stepDampedChainWithDrag:

```cpp title="include/lab.hpp — stepDampedChainWithDrag"
inline bool stepDampedChainWithDrag(SpringChain& chain, double deltaSeconds, Vec2 gravity, bool gravityEnabled, const DragConstraint& drag) {
    if (!validChain(chain) || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0 || deltaSeconds > 0.1 || (drag.active && (drag.particleIndex == 0 || drag.particleIndex >= chain.particles.size() || !finiteVec2(drag.target)))) {
        return false;
    }
    SpringChain candidate = chain;
    if (drag.active) {
        candidate.particles[drag.particleIndex].position = drag.target;
        candidate.particles[drag.particleIndex].velocity = {};
    }
    if (!accumulateDampedForces(candidate, gravity, gravityEnabled)) {
        return false;
    }
    for (std::size_t index = 0; index < candidate.particles.size(); ++index) {
        if (drag.active && index == drag.particleIndex) {
            continue;
        }
        if (!integrateParticle(candidate.particles[index], deltaSeconds)) {
            return false;
        }
    }
    enforceAnchor(candidate);
    chain = std::move(candidate);
    return true;
}
```

Đặt target trước khi cộng lực để hàng xóm đọc đúng vị trí đang giữ. Sau đó bỏ qua integration của khối được cầm, không ghim lại cả dây về một hình dạng định sẵn.

Thay stepScene và thêm cancelGesture:

```cpp title="include/scene.hpp — stepScene"
inline bool stepScene(Scene& scene) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5 || scene.selected == 0 || scene.selected >= scene.chain.particles.size()) {
        stopScene(scene);
        scene.message = "Invalid dt index.";
        return false;
    }
    SpringChain candidate = scene.chain;
    bool accepted = false;
    // Đặt c=0 ở candidate khi tắt damping; không đổi hệ số được lưu trong Scene.
    if (!scene.dampingEnabled) {
        for (auto& spring : candidate.springs) {
            spring.damping = 0.0;
        }
    }
    accepted = stepDampedChainWithDrag(candidate, kStepOptions[scene.dtIndex], scene.gravity, scene.gravityEnabled, scene.drag);
    for (auto& spring : candidate.springs) {
        spring.damping = scene.damping;
    }
    if (!accepted || !withinExperiment(candidate)) {
        stopScene(scene);
        scene.message = "Experiment stopped: invalid/degenerate state or envelope exceeded. Reset or reduce dt.";
        return false;
    }
    scene.traceBefore = scene.chain.particles[scene.selected];
    scene.traceAfter = candidate.particles[scene.selected];
    scene.hasTrace = true;
    scene.chain = std::move(candidate);
    ++scene.steps;
    ++scene.substeps;
    scene.elapsed = double(scene.steps) * kStepOptions[scene.dtIndex];
    refreshMetrics(scene);
    return true;
}
```

```cpp title="include/scene.hpp — cancelGesture"
inline void cancelGesture(Scene& scene) {
    if (!scene.drag.active) {
        return;
    }
    if (scene.drag.active && scene.drag.particleIndex < scene.chain.particles.size()) {
        scene.chain.particles[scene.drag.particleIndex].velocity = {};
    }
    scene.drag = {};
    beginMeasurement(scene);
}
```

Khi tắt damping, candidate dùng c=0 rồi khôi phục hệ số được lưu; công thức và đường đi của integration vẫn như nhau. Cancel đặt velocity của khối đang giữ về zero, không áp releaseVelocity đã lấy từ một mẫu cũ.

## Thử làm sai để hiểu đúng

Chỉ đổi một chi tiết mỗi lần. Hãy dự đoán, chạy lại, ghi điều quan sát được rồi hoàn tác trước thí nghiệm tiếp theo.

1. Gán drag.target=point ngay khi down. Click lệch tâm sẽ làm khối nhảy dù con trỏ chưa di chuyển.

2. Nhận mọi pointer move/up mà không kiểm owner. Một pointer lạ có thể kết thúc thao tác đang giữ.

3. Chỉ dùng mẫu motion cuối, không đọc vị trí up. Điểm thả và vận tốc thả sẽ sai nếu mẫu cuối chưa đi qua motion.

4. Đánh giá drift trên một history nối trước/sau kéo. Lúc ấy hệ đã nhận công từ bên ngoài.

## Tự kiểm tra kết quả

- Không kéo được neo; cầm lệch giữ đúng grabOffset.
- Candidate không được áp nếu capture thất bại.
- Chỉ owner được move/up; mất nút giữ hoặc cancel không để capture kẹt.
- Mẫu up cuối được dùng; up tới muộn sau reset không tác động cảnh mới.
- Khối đang giữ không bị tích phân nhưng spring vẫn tác động hàng xóm.
- Kết thúc hoặc hủy thao tác bắt lại mốc đo; velocity thả không vượt 6 m/s.

## Bài tập mở rộng
