# Thí nghiệm độ cứng, khối lượng và bước thời gian

## Vấn đề cần giải quyết

Một cấu hình chạy mượt chưa nói rằng phương pháp tích phân sẽ ổn với lò xo cứng hơn, khối nhẹ hơn hoặc dt lớn hơn. Bài này mở các tham số và số khối 20–100 để ta làm thí nghiệm có kiểm soát, thay vì thử ngẫu nhiên rồi chỉ nhìn ảnh.

## Hiểu ý tưởng trước khi viết code

Một oscillator đơn có tần số góc $\omega=\sqrt{k/m}$; số không thứ nguyên $q=h\sqrt{k/m}$ cho biết một bước thời gian lớn đến đâu so với chuyển động riêng của hệ.

q không phải chứng chỉ ổn định cho mọi chuỗi. Chuỗi có nhiều mode, có mode nhanh hơn oscillator đơn; damping và hình dạng tức thời cũng ảnh hưởng. Đừng lấy ngưỡng q của một mass một chiều áp thẳng cho cả dây.

Ta đo cơ năng:

$$
K=\sum_{\text{dynamic }i}\frac12m_i|v_i|^2,\quad
U_s=\sum_j\frac12k_j(d_j-L_{0,j})^2,\quad
U_g=-\sum_{\text{dynamic }i}m_i\,g\cdot(p_i-p_{\text{anchor}}).
$$

Mốc Ug ở anchor làm Ug âm khi khối nằm phía dưới. Điều đó không có gì sai. Độ biến thiên E giữa hai thời điểm không đổi nếu chỉ dời mốc thế năng của cùng hệ.

Khi đổi N mà giữ m, k và restLength, ta đang đổi chiều dài và tổng khối lượng của hệ, **không phải chia mịn cùng một sợi dây vật lý**. Để so dt công bằng, giữ N, tham số và initial state cố định.

Các phím đổi tham số bên dưới đều có giới hạn rõ: K tăng độ cứng tới 1.200 N/m rồi quay về 60 N/m; M tăng khối lượng tới 0,16 kg rồi quay về 0,02 kg. Mỗi nhánh chọn giá trị xong mới gọi `rebuildScene`. Đừng đổi k hoặc m giữa một lượt đo rồi so năng lượng với mốc của hệ trước đó.

### Bước 1 — Tính chỉ số thời gian và số đo độc lập

Tạo metrics.hpp trong starter/include, bắt đầu bằng pragma once, include lab.hpp và namespace lab. Thêm springStabilityIndex và ChainMetrics:

```cpp title="include/metrics.hpp — springStabilityIndex"
inline double springStabilityIndex(double stiffness, double mass, double deltaSeconds) {
    if (!std::isfinite(stiffness) || stiffness < 0.0 || !std::isfinite(mass) || mass <= 0.0 || !std::isfinite(deltaSeconds) || deltaSeconds < 0.0) {
        return std::numeric_limits<double>::infinity();
    }
    return deltaSeconds * std::sqrt(stiffness / mass);
}
```

```cpp title="include/metrics.hpp — ChainMetrics"
struct ChainMetrics {
    double kineticEnergy{};
    double springEnergy{};
    double gravitationalEnergy{};
    double maximumStretch{};
    double maximumSpeed{};
    double anchorError{};
    bool finite{true};
};
```

Thêm measureChain bên trong namespace ấy:

```cpp title="include/metrics.hpp — measureChain"
inline ChainMetrics measureChain(const SpringChain& chain, Vec2 gravity, bool gravityEnabled) {
    ChainMetrics metrics{};
    if (!validChain(chain) || !finiteVec2(gravity)) {
        metrics.finite = false;
        return metrics;
    }
    for (const Particle& particle : chain.particles) {
        if (!finiteParticle(particle)) {
            metrics.finite = false;
            continue;
        }
        metrics.maximumSpeed = std::max(metrics.maximumSpeed, length(particle.velocity));
        if (particle.inverseMass == 0.0) {
            continue;
        }
        const double mass = 1.0 / particle.inverseMass;
        metrics.kineticEnergy += 0.5 * mass * lengthSquared(particle.velocity);
        if (gravityEnabled) {
            metrics.gravitationalEnergy += -mass * dot(gravity, subtract(particle.position, chain.anchorPosition));
        }
    }
    for (const Spring& spring : chain.springs) {
        const double distance = length(subtract(chain.particles[spring.second].position, chain.particles[spring.first].position));
        const double stretch = distance - spring.restLength;
        metrics.maximumStretch = std::max(metrics.maximumStretch, std::abs(stretch));
        metrics.springEnergy += 0.5 * spring.stiffness * stretch * stretch;
    }
    metrics.anchorError = length(subtract(chain.particles.front().position, chain.anchorPosition));
    metrics.finite = metrics.finite && std::isfinite(metrics.kineticEnergy) && std::isfinite(metrics.springEnergy) && std::isfinite(metrics.gravitationalEnergy) && std::isfinite(metrics.maximumStretch) && std::isfinite(metrics.maximumSpeed) && std::isfinite(metrics.anchorError);
    return metrics;
}
```

Energy được đo từ state hiện tại, không tích lũy từ lời hứa rằng mỗi step “phải giữ nguyên”. Us vẫn tính được khi d=0, dù hướng lực tại đó không xác định và solver phải từ chối bước ấy.

### Bước 3 — Dựng các preset để so đúng thứ cần so

Thêm applyPreset vào scene.hpp:

```cpp title="include/scene.hpp — applyPreset"
inline void applyPreset(Scene& scene, int preset) {
    scene = makeScene();
    if (preset == 1 || preset == 2) {
        scene.gravityEnabled = false;
        scene.dampingEnabled = preset == 2;
    }
    if (preset == 3) {
        scene.gravityEnabled = false;
        scene.dampingEnabled = false;
        scene.stiffness = 1200.0;
        scene.mass = 0.02;
        scene.dtIndex = 4;
    }
    rebuildScene(scene);
}
```

Preset 1 và 2 cùng initial state, không gravity, chỉ khác damping. Preset 3 cố tình dùng k=1200, m=0,02 kg, h=1/30 s. Guard dừng khi candidate không hợp lệ hoặc vượt giới hạn thí nghiệm; đó không phải một phép sửa solver cho ổn.

Góc nhìn có sẵn ước lượng độ giãn tĩnh để chứa chuỗi dài. Công thức chỉ chọn scale hiển thị, không gán một quỹ đạo vào các khối:

```cpp title="include/view.hpp — makeWorldView"
inline WorldView makeWorldView(const Scene& scene) {
    const double links = double(std::max(2, scene.count) - 1);
    double expectedExtension = 0.0;
    if (scene.gravityEnabled && scene.stiffness > 0.0) {
        expectedExtension = scene.mass * std::abs(scene.gravity.y) * links * (links + 1.0) / (2.0 * scene.stiffness);
    }
    const double height = std::max(3.0, links * scene.restLength + expectedExtension + 1.6);
    return {std::min(110.0, 500.0 / height), 350.0, 130.0};
}
```

Độ giãn dự kiến cộng tải trọng các khối phía dưới từng spring. Chuyển động thật vẫn do lực và integrator tạo ra.

## Ghép các phần lại

Build Starter. C đổi 20/32/64/100 khối; K đổi k, M đổi m, [ và ] đổi dt. Phím 1/2 chọn hai thí nghiệm không/có damping; 3 chọn cấu hình cố ý sai.

Với preset 1, lấy E=K+Us+Ug tại t=0 và đo max |E(t)−E(0)| trong hai giây. Reset cùng preset, giảm h từ 1/480 xuống 1/960 rồi so. Với source tham khảo, sai số tối đa khoảng 7,8% E₀ ở bản thô và 4,1% ở bản mịn; đây là kết quả của **fixture cụ thể**, không phải ngưỡng mọi mô phỏng đều phải đạt.
