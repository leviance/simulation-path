# Vẽ đồ thị năng lượng và nghiệm thu ứng dụng

## Vấn đề cần giải quyết

Ta đã có mô phỏng và các số đo, nhưng để kết luận nó đúng cần giữ lại lịch sử, vẽ trục có ý nghĩa và chạy các đáp án độc lập. Một đường biểu diễn năng lượng đặt nhầm lên trục độ lệch có thể trông đẹp mà không cho phép đọc bất kỳ đại lượng vật lý nào.

## Hiểu ý tưởng trước khi viết code

Dùng $E=K+U_s+U_g$ và $\Delta E=E(t)-E(0)$. Khi không damping và không có thao tác ngoài, mô hình liên tục giữ E; semi-implicit Euler cho sai số dao động cần đo và kiểm hội tụ theo dt. Có damping thì cơ năng giảm do công suất $-cu^2$, nhưng sai số rời rạc vẫn có thể làm vài bước tăng nhẹ.

Khi E âm, “giảm” vẫn hiểu theo thứ tự số: từ −40 J xuống −50 J là giảm 10 J. Đừng lấy trị tuyệt đối của Ug hoặc E để ép graph luôn dương.

Graph năng lượng có trục ngang thời gian s, trục dọc J, bốn đường E/K/Us/Ug và mốc zero. Graph độ lệch có trục ngang index, trục dọc x (m); hai graph không dùng chung hệ tọa độ.

History lấy từ physics, không lấy theo render frame. Ta ghi mốc t=0 khi bắt đầu đo, lấy mẫu định kỳ tối đa 60 Hz và ghi thêm sau bước đơn hoặc khi job kết thúc. Bộ nhớ chỉ giữ 1201 mẫu gần nhất; khi chạy lâu hơn, các mẫu cũ, kể cả t=0, sẽ ra khỏi cửa sổ này. Một job 20 giây bắt đầu từ mốc đo mới, với dt mặc định, có 9600 physics steps và 1201 điểm graph. Mỗi frame xử lý tối đa 32 step; UI vẫn nhận được lệnh dừng.

### Bước 1 — Hoàn thiện đại lượng năng lượng và kiểu mẫu

Trong metrics.hpp, thêm hai helper của bản cuối:

```cpp title="include/metrics.hpp — totalMechanicalEnergy"
inline double totalMechanicalEnergy(const ChainMetrics& metrics) {
    return metrics.kineticEnergy + metrics.springEnergy + metrics.gravitationalEnergy;
}
```

```cpp title="include/metrics.hpp — chainWithinSafetyEnvelope"
inline bool chainWithinSafetyEnvelope(const SpringChain& chain, const ChainMetrics& metrics, double maximumStretchRatio, double maximumSpeed) {
    if (!metrics.finite || chain.springs.empty() || !std::isfinite(maximumStretchRatio) || maximumStretchRatio < 0.0 || !std::isfinite(maximumSpeed) || maximumSpeed < 0.0) {
        return false;
    }
    double smallestRestLength = std::numeric_limits<double>::infinity();
    for (const Spring& spring : chain.springs) {
        smallestRestLength = std::min(smallestRestLength, spring.restLength);
    }
    return metrics.anchorError <= 1e-9 && metrics.maximumStretch <= maximumStretchRatio * smallestRestLength && metrics.maximumSpeed <= maximumSpeed;
}
```

Safety envelope dùng trong một test cụ thể, không phải bảo đảm ổn định mọi cấu hình. Dừng thử nghiệm là khác với clamp state.

### Bước 2 — Lấy mẫu và bắt lại baseline rõ ràng

Thêm recordEnergy trước beginMeasurement:

```cpp title="include/scene.hpp — recordEnergy"
inline void recordEnergy(Scene& scene, bool force = false) {
    if (!scene.history.empty()) {
        const double interval = scene.elapsed - scene.history.back().time;
        if (interval <= 1e-12 || (!force && interval < 1.0 / 60.0 - 1e-12)) {
            return;
        }
    }
    const auto& m = scene.metrics;
    scene.history.push_back({scene.elapsed, m.kineticEnergy, m.springEnergy, m.gravitationalEnergy, totalMechanicalEnergy(m)});
    if (scene.history.size() > 1201) {
        scene.history.erase(scene.history.begin());
    }
}
```

Thay beginMeasurement để clear history, chụp E₀ và ghi t=0:

```cpp title="include/scene.hpp — beginMeasurement"
inline void beginMeasurement(Scene& scene) {
    scene.accumulator = 0.0;
    scene.elapsed = 0.0;
    scene.steps = 0;
    scene.substeps = 0;
    scene.droppedTime = 0.0;
    scene.fastRemaining = 0;
    refreshMetrics(scene);
    scene.hasTrace = false;
    scene.initialEnergy = totalMechanicalEnergy(scene.metrics);
    scene.history.clear();
    recordEnergy(scene);
}
```

Các điểm gọi ở kéo/thả, đổi damping và reset đã được ghép từ những bài trước. Giờ chúng thực sự bắt đầu một đoạn đo mới.

Thay stepScene để lấy mẫu sau commit, không phải trong renderer:

```cpp title="include/scene.hpp — stepScene"
inline bool stepScene(Scene& scene) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5 || scene.selected == 0 || scene.selected >= scene.chain.particles.size()) {
        stopScene(scene);
        scene.message = "Invalid dt index.";
        return false;
    }
    SpringChain candidate = scene.chain;
    bool accepted = false;
    // Đặt c=0 ở candidate khi tắt damping; không đổi hệ số được lưu trong Scene.
    if (!scene.dampingEnabled) {
        for (auto& spring : candidate.springs) {
            spring.damping = 0.0;
        }
    }
    accepted = stepDampedChainWithDrag(candidate, kStepOptions[scene.dtIndex], scene.gravity, scene.gravityEnabled, scene.drag);
    for (auto& spring : candidate.springs) {
        spring.damping = scene.damping;
    }
    if (!accepted || !withinExperiment(candidate)) {
        stopScene(scene);
        scene.message = "Experiment stopped: invalid/degenerate state or envelope exceeded. Reset or reduce dt.";
        return false;
    }
    scene.traceBefore = scene.chain.particles[scene.selected];
    scene.traceAfter = candidate.particles[scene.selected];
    scene.hasTrace = true;
    scene.chain = std::move(candidate);
    ++scene.steps;
    ++scene.substeps;
    scene.elapsed = double(scene.steps) * kStepOptions[scene.dtIndex];
    refreshMetrics(scene);
    recordEnergy(scene);
    return true;
}
```

### Bước 3 — Chạy 20 giây bằng các batch nhỏ

Thêm requestFastRun và thay advanceFrame:

```cpp title="include/scene.hpp — requestFastRun"
inline void requestFastRun(Scene& scene) {
    stopScene(scene);
    scene.fastRemaining = static_cast<int>(std::lround(20.0 / kStepOptions[scene.dtIndex]));
}
```

```cpp title="include/scene.hpp — advanceFrame"
inline void advanceFrame(Scene& scene, double frameSeconds) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 5) {
        stopScene(scene);
        return;
    }
    scene.substeps = 0;
    if (scene.fastRemaining > 0) {
        const int batch = std::min(32, scene.fastRemaining);
        for (int i = 0; i < batch; ++i) {
            if (!stepScene(scene)) {
                return;
            }
            --scene.fastRemaining;
            if (scene.fastRemaining == 0) {
                recordEnergy(scene, true);
            }
        }
        return;
    }
    if (scene.paused) {
        return;
    }
    const auto plan = planFixedSteps(scene.accumulator, frameSeconds, kStepOptions[scene.dtIndex], 32, 0.05);
    scene.accumulator = plan.remainder;
    scene.droppedTime += plan.droppedTime;
    for (int i = 0; i < plan.steps; ++i) {
        if (!stepScene(scene)) {
            break;
        }
    }
}
```

Số bước được tính từ fixed dt, không dùng sleep 20 giây và không chạy toàn bộ vòng lặp trong một click handler. Mẫu cuối được ép ghi để không mất endpoint vì giới hạn tần suất history.

Trong main, thêm Enter vào nhánh key-down và thay N để single-step cũng lưu endpoint:

```cpp title="src/main.cpp — fast job"
if (key == SDLK_RETURN) {

```


### Bước 4 — Vẽ graph đúng đơn vị, giữ cả phần âm

Trong view.hpp, thêm drawEnergy trước renderScene:

```cpp title="include/view.hpp — drawEnergy"
inline void drawEnergy(Framebuffer& image, const Scene& scene) {
    if (scene.history.empty()) {
        return;
    }
    double low = 0.0;
    double high = 0.0;
    for (const auto& value : scene.history) {
        low = std::min({low, value.total, value.kinetic, value.elastic, value.gravity});
        high = std::max({high, value.total, value.kinetic, value.elastic, value.gravity});
    }
    const double range = std::max(1e-6, high - low);
    const double firstTime = scene.history.front().time;
    const double span = std::max(kStepOptions[scene.dtIndex], scene.history.back().time - firstTime);
    const auto point = [&](double time, double value) {
        return Vec2{735.0 + 325.0 * (time - firstTime) / span, 610.0 - 150.0 * (value - low) / range};
    };
    rectangle(image, 735, 460, 1060, 610, kGrid, false);
    const Vec2 zero = point(firstTime, 0.0);
    drawLine(image, 735.0, zero.y, 1060.0, zero.y, kRail);
    for (std::size_t i = 1; i < scene.history.size(); ++i) {
        const auto& a = scene.history[i - 1];
        const auto& b = scene.history[i];
        const double left[]{a.total, a.kinetic, a.elastic, a.gravity};
        const double right[]{b.total, b.kinetic, b.elastic, b.gravity};
        const std::uint32_t colors[]{0xffffffffU, 0x53f0aeffU, 0xe5c07bffU, 0xc792eaffU};
        for (int component = 0; component < 4; ++component) {
            const Vec2 start = point(a.time, left[component]);
            const Vec2 end = point(b.time, right[component]);
            drawLine(image, start.x, start.y, end.x, end.y, colors[component]);
        }
    }
}
```

Low/high lấy từ cả bốn thành phần và zero. Time dùng t thật của mẫu đầu/cuối, không dùng index sample như thể nó luôn cách đều. Công thức chỉ đổi dữ liệu sang pixel; không sửa state.

Thay renderScene để gọi graph, rồi thay drawHud để hiện legend, khoảng thời gian và ΔE:

```cpp title="include/view.hpp — renderScene"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear();
    const WorldView view = makeWorldView(scene);
    rectangle(image, 40, 100, 690, 650, kRail, false);
    if (scene.debug) {
        for (int row = 1; row <= 10; ++row) {
            const double y = 100.0 + 50.0 * double(row);
            drawLine(image, 40, y, 690, y, kGrid);
        }
    }
    drawChain(image, scene, view);
    const Vec2 anchor = worldToScreen(scene.chain.anchorPosition, view);
    rectangle(image, int(anchor.x - 20), int(anchor.y - 25), int(anchor.x + 20), int(anchor.y - 10), 0xc678ddffU, true);
    drawLine(image, anchor.x, anchor.y - 10, anchor.x, anchor.y, 0xc678ddffU);
    Vec2 previous{};
    for (std::size_t i = 0; i < scene.chain.particles.size(); ++i) {
        const double x = 735.0 + 325.0 * double(i) / double(scene.chain.particles.size() - 1);
        const double y = std::clamp(260.0 - 60.0 * scene.chain.particles[i].position.x, 150.0, 360.0);
        if (i > 0) {
            drawLine(image, previous.x, previous.y, x, y, 0x53f0aeffU);
        }
        previous = {x, y};
    }
    rectangle(image, 735, 150, 1060, 360, kGrid, false);
    drawEnergy(image, scene);
}
```

```cpp title="include/presentation.hpp — drawHud"
// HUD dùng cùng state với hình vẽ; các nhãn năng lượng không tự chạy solver.
inline bool drawHud(SDL_Renderer* renderer, const Scene& scene) {
    SDL_SetRenderDrawColor(renderer, 205, 215, 235, 255);

    if (!SDL_RenderDebugText(renderer, 30, 42, "Space pause | N step (lesson 4+) | R reset | F clean/debug | Esc quit")) {

    }
    SDL_RenderDebugText(renderer, 30, 64, "G gravity | D damping (lesson 5+) | Drag or arrows move selected mass (lesson 6+)");
    SDL_RenderDebugText(renderer, 30, 680, "C: 20/32/64/100 masses | K stiffness | M mass | [ / ] dt | 1/2: no/with damping | 3: unstable");

        SDL_RenderDebugText(renderer, 30, 720, line);

        SDL_RenderDebugText(renderer, 30, 740, line);
    }
    if (scene.debug && scene.hasTrace) {
        std::snprintf(line, sizeof(line), "node %zu | p: (%.3f, %.3f) -> (%.3f, %.3f) m | v: (%.3f, %.3f) -> (%.3f, %.3f) m/s", scene.selected, scene.traceBefore.position.x, scene.traceBefore.position.y, scene.traceAfter.position.x, scene.traceAfter.position.y, scene.traceBefore.velocity.x, scene.traceBefore.velocity.y, scene.traceAfter.velocity.x, scene.traceAfter.velocity.y);
        SDL_RenderDebugText(renderer, 30, 700, line);
    }
    SDL_RenderDebugText(renderer, 735, 128, "DISPLACEMENT x (m), by node index");
    SDL_RenderDebugText(renderer, 735, 384, "Plot clips large x; physics unchanged.");
    SDL_RenderDebugText(renderer, 735, 430, "ENERGY (J): white E, green K");
    SDL_RenderDebugText(renderer, 735, 446, "yellow Us, purple Ug; zero line");
    if (!scene.history.empty()) {
        std::snprintf(line, sizeof(line), "time %.3f -> %.3f s", scene.history.front().time, scene.history.back().time);
        SDL_RenderDebugText(renderer, 735, 625, line);
    }
    std::snprintf(line, sizeof(line), "Delta E=%.6f J | samples=%zu | fast steps=%d | Enter: +20 s", totalMechanicalEnergy(scene.metrics) - scene.initialEnergy, scene.history.size(), scene.fastRemaining);
    SDL_RenderDebugText(renderer, 30, 760, line);
    if (!scene.message.empty()) {
        SDL_RenderDebugText(renderer, 30, 790, scene.message.c_str());
    }
    return true;
}
```

## Ghép các phần lại

Bản cuối mặc định có 32 khối, gravity và damping bật. Chọn preset không damping rồi chạy Enter đủ 20 giây; đọc ΔE và khoảng thời gian graph. Chọn preset có damping từ cùng initial state để đối chiếu cơ năng, không so với một chuỗi bạn vừa kéo khác đi.

F ẩn vector/grid/readout thừa nhưng giữ chuỗi và graph. Graph displacement bị cắt ở khoảng trục của nó khi độ lệch lớn; số đo vẫn là state thật. Main viewport là cảnh chuyển động, không phải một graph giả thay cho chuỗi.

Source cuối ở dưới và ZIP có README, CMake, Starter, 8 checkpoint, final cùng tests. Ứng dụng C++ chạy độc lập, không cần browser. --smoke chỉ kiểm cửa sổ ẩn trong 32 frame, render/resize và cấu hình lớn; nó không thay kiểm GUI thật.

## Thử làm sai để hiểu đúng

Chỉ đổi một chi tiết mỗi lần. Hãy dự đoán, chạy lại, ghi điều quan sát được rồi hoàn tác trước thí nghiệm tiếp theo.

1. Chụp một mẫu history mỗi render frame. Cùng một mô phỏng ở FPS khác nhau sẽ có dữ liệu graph khác.

2. Bỏ t=0 hoặc endpoint cuối của job. Đường vẽ không còn cho biết đúng đoạn đo đã chạy.

## Tự kiểm tra kết quả

- 32 khối mặc định và cả 20/64/100 khối chạy đủ job 20 giây, anchor không trôi, số bước đúng fixed dt.
- Không damping: có max drift, chia đôi dt làm sai số giảm; không hứa E đúng tuyệt đối.
- Có damping: cùng fixture g=0 cho E(10 s) dưới 15% E₀; công suất damping khớp đáp án âm độc lập.
- Bắt đầu đo có mẫu t=0; kết thúc job có mẫu cuối. History giữ tối đa 1201 mẫu gần nhất; graph ghi đúng trục giây/Joule và không sửa state.
- Job dừng/hủy được; lỗi không làm elapsed chạy vượt số bước chấp nhận.
- Capture, final sample, cancel/reset/blur và bàn phím được kiểm; không dùng screenshot làm bằng chứng duy nhất.
- Starter, 8 checkpoint và final build Debug/Release; tests thật còn hiệu lực ở Release; ZIP khớp source.
