# Từ tâm màn hình đến hướng nhìn trong thế giới

## Vấn đề cần giải quyết

Hãy đứng đối diện thân cây. Ta muốn biết mình đang ngắm vào đâu dù cửa sổ rộng hay hẹp. Đừng bắt đầu bằng việc sửa block: trước hết chỉ cần vẽ một dấu cộng và tạo một tia từ đúng vị trí mắt.

## Hiểu ý tưởng trước khi viết code

Màn hình là cửa sổ nhìn qua, không phải mặt phẳng đất. Ở giữa cửa sổ, hai độ lệch ngang và dọc đều bằng 0, nên tia đi theo trục nhìn. Ở mép phải, tia phải nghiêng sang phải; tỷ lệ phụ thuộc FOV và kích thước viewport.

## Viết code từng bước

Dấu cộng ở giữa màn hình trả lời “mình đang nhìn theo hướng nào?”, chưa trả lời “trước mặt là gì?”. Bài này dừng đúng ở bước thứ nhất.

### Từ tâm ảnh lấy một hướng trong thế giới

Thêm `eyeRay` vào `probe.hpp`. Lấy vị trí mắt làm gốc, cộng các độ lệch theo hai trục của camera rồi chuẩn hóa. Ở tâm ảnh cả hai độ lệch đều bằng 0: tia nhìn thẳng theo `forward`. Đối chiếu với phép biến đổi camera có sẵn bên dưới: trình vẽ đi từ thế giới tới ảnh, còn ta đang đi từ một điểm ảnh ra thế giới.

{/* snippet include/trail/probe.hpp#eye-ray */}

```cpp title="include/trail/probe.hpp — Đổi một điểm ảnh thành vector đơn vị"
inline Vec3 eyeRay(const Camera& camera, double screenX, double screenY, int width, int height) {
    const Basis axes = basis(camera);
    const double focal = focalLength(height, camera.verticalFov);
    const double u = (screenX - width * 0.5) / focal;
    const double v = (height * 0.5 - screenY) / focal;
    return normalized(axes.forward + axes.right * u + axes.up * v);
}
```

{/* snippet include/trail/camera.hpp#camera-space */}

```cpp title="include/trail/camera.hpp — Kiểm bằng phép biến đổi theo chiều ngược lại"
inline Vec3 cameraSpace(Vec3 world, Vec3 eye, const Basis& axes) {
    const Vec3 offset = world - eye;
    return {dot(offset, axes.right), dot(offset, axes.up), dot(offset, axes.forward)};
}
```

## Ghép các phần lại

Đứng trên bờ, xoay sang thân gỗ rồi lên trời. Nhấn F3 hai lần: dấu cộng hiện rồi mất đúng giữa cửa sổ. Chưa thấy ô viền hay tên block là kết quả đúng ở mốc này.

Mở terminal cạnh `CMakeLists.txt` của ZIP đã giải nén. Lần cấu hình đầu tạo `work/` từ starter; chỉnh tệp trong đó, rồi build lại cùng target. Cấu hình lần nữa không ghi đè bài làm.

```bash title="Terminal — chạy bản bạn vừa viết"
cmake -S . -B build-work -DVOXEL_WORKBOOK=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build-work --config Release --target project_60_work --parallel 1
.\build-work\Release\project_60_work.exe
```

Với Ninja hoặc Make trên Linux/macOS, chạy `./build-work/project_60_work` thay cho dòng mở `.exe`.

## Thử làm sai để hiểu đúng

Lấy tọa độ tâm làm điểm world. Khi đi sang bên, dấu cộng vẫn đứng giữa ảnh nhưng tia tưởng tượng không xuất phát từ camera nữa.

## Tự kiểm tra kết quả

Tia giữa song song với hướng nhìn và dài một đơn vị; tia bên phải có tích vô hướng dương với trục phải. Kiểm lại ở hai khung hình khác tỉ lệ.
