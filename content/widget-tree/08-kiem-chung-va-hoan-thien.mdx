# Kiểm cây vẫn còn nguyên sau một nghìn frame

## Vấn đề cần giải quyết

Nếu mỗi lần Reset đàn lại dựng một cây trông hệt cây cũ, người dùng có thể chẳng nhận thấy đến khi đang kéo dở slider. Ta cần kiểm điều ảnh chụp không thể cho biết.

## Hiểu ý tưởng trước khi viết code

Chọn hai dấu mốc trước khi cho chạy: địa chỉ root và ID tiếp theo sẽ cấp. Tính/vẽ nhiều frame, cho Boids tiến bước rồi Reset. Các dấu mốc của cây phải còn nguyên. Chỉ thao tác cố ý thay cây mới được đổi chúng.

## Viết code từng bước

### Đọc toàn cây mà không sửa trạng thái

Đếm node thực, kiểm ID duy nhất. Đối chiếu với một bản sao UI đã reconcile: nếu hot/active/focus cũ khác bản hợp lệ, báo lỗi thay vì lặng lẽ sửa giúp test.

{/* snippet include/audit.hpp#tree-audit */}

```cpp title="include/audit.hpp — Đọc toàn cây mà không sửa trạng thái"
inline int audit(const Tree& tree, const Ui& ui) {
    if (!tree.root || tree.root->kind != Kind::Panel || tree.nextId > maxId + 1)
        throw std::runtime_error("invalid root");
    std::set<WidgetId> ids;
    int count = 0;
    checkNode(*tree.root, 0, tree, ids, count);
    if (count != tree.count)
        throw std::runtime_error("invalid tree count");
    Ui repaired = ui;
    reconcile(tree, repaired);
    if (repaired.hot != ui.hot || repaired.active != ui.active || repaired.focus != ui.focus)
        throw std::runtime_error("stale widget id");
    return count;
}
```

### Thử nghiệm đủ dài nhưng hữu hạn

Một nghìn frame không phải thử tải vô hạn. Duyệt, hit-test, cập nhật đàn rồi Reset; sau đó đối chiếu root, nextId và số node với fixture. CTest dùng điều kiện chạy cả khi có NDEBUG.

{/* snippet tests/tests.cpp#retained-check */}

```cpp title="tests/tests.cpp — Thử nghiệm đủ dài nhưng hữu hạn"
auto retained = buildTree();
const Widget* rootAddress = retained.tree.root.get();
const WidgetId lastId = retained.tree.nextId;
setPaused(model, false);
for (int frame = 0; frame < 1000; ++frame) {
    paintList(retained.tree);
    hitTest(retained.tree, {700, 90});
    advance(model, fixedDt);
}
resetSimulation(model);
check(retained.tree.root.get() == rootAddress && retained.tree.nextId == lastId && audit(retained.tree, Ui{}) == 11, "retained state survives render/query/physics/reset");
```

## Ghép các phần lại

Chạy bản final. F2 bật/tắt inspector, Shift+mũi tên dịch Panel, P đổi preset, H/E/D/A thử biến đổi, T dựng lại cây. Giữ giao diện sạch để quan sát đàn sau mỗi thí nghiệm.

```bash title="Terminal — chạy checkpoint 8"
cmake --build build --config Release --target project_66_checkpoint_8 --parallel 2
.\build\Release\project_66_checkpoint_8.exe
```

## Thử làm sai để hiểu đúng

Tạm cấp lại toàn bộ ID sau khi xóa nhóm. Kiểm màu và vận tốc có thể vẫn đúng nhưng test về ID không tái sử dụng phải thất bại.

## Tự kiểm tra kết quả

Kiểm đúng bounds (688,80), phần Reset bị clip 36 pixel, reverse pick, Tab và việc hủy capture. Debug và Release đều qua CTest.

```bash title="Terminal — kiểm cả hai cấu hình"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --parallel 2
ctest --test-dir build -C Debug --output-on-failure --timeout 20
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure --timeout 20
.\build\Release\project_66_final.exe
```
