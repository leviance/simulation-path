# Xóa một nhóm ngay khi tay còn giữ slider

## Viết code từng bước

### Hủy nhánh sau khi bảo vệ root

Xóa qua parent và cập nhật số lượng node. Những child phía dưới được hủy theo `unique_ptr`; không tái sử dụng ID vừa mất cho một button mới.

{/* snippet include/mutation.hpp#remove */}

```cpp title="include/mutation.hpp — Hủy nhánh sau khi bảo vệ root"
inline bool removeSubtree(Tree& tree, WidgetId id, Ui& ui) {
    if (id == tree.root->id)
        return false;
    const bool removed = eraseChild(*tree.root, id, tree);
    reconcile(tree, ui);
    return removed;
}
```

### So active, focus và hot với cây mới

Không chỉ hỏi ID có tồn tại. Kiểm cả visible/enabled kế thừa và loại node. Hành động dọn state phải diễn ra trước khi sự kiện tiếp theo có thể dùng ID.

{/* snippet include/input.hpp#reconcile */}

```cpp title="include/input.hpp — So active, focus và hot với cây mới"
inline void reconcile(const Tree& tree, Ui& ui) {
    // Kiểm cả visibility kế thừa: child vẫn tồn tại nhưng parent có thể đã ẩn.
    const auto valid = [&tree](WidgetId id) {
        const auto view = locate(tree, id);
        return view && view->enabled && (view->node->kind == Kind::Button || view->node->kind == Kind::Slider);
    };
    if (!valid(ui.active))
        ui.active = 0;
    if (!valid(ui.focus))
        ui.focus = 0;
    if (!locate(tree, ui.hot))
        ui.hot = 0;
}
```
