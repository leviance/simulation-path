## Viết code từng bước

### Tính bounds tại node đang thăm

Chỉ lấy vị trí từ origin của cha; chiều rộng và chiều cao vẫn thuộc node hiện tại. `WidgetView` là kết quả quan sát tạm thời, không phải cái cây thứ hai.

{/* snippet include/traversal.hpp#world-frame */}

```cpp title="include/traversal.hpp — Tính bounds tại node đang thăm"
inline std::optional<WidgetView> place(const Widget& node, Point origin, Rect clip, bool enabled, int depth) {
    const Rect bounds{origin.x + node.local.x, origin.y + node.local.y, node.local.width, node.local.height};
    if (clip.width <= 0 || clip.height <= 0)
        return std::nullopt;
    return WidgetView{&node, bounds, clip, enabled, depth};
}
```

### Đưa đúng gốc xuống một cấp

Vẽ cha trước rồi duyệt các con theo thứ tự thêm. Truyền góc trái vừa tính cho cấp kế tiếp; nếu truyền mãi gốc cửa sổ, các cháu sẽ tách khỏi Panel khi dịch chuyển.

{/* snippet include/traversal.hpp#visit-children */}

```cpp title="include/traversal.hpp — Đưa đúng gốc xuống một cấp"
inline void visit(const Widget& node, Point origin, Rect clip, bool enabled, int depth, const std::function<void(const WidgetView&)>& draw) {
    const auto placed = place(node, origin, clip, enabled, depth);
    if (!placed)
        return;
    draw(*placed);
    for (const auto& child : node.children) {
        visit(*child, {placed->bounds.x, placed->bounds.y}, placed->clip, placed->enabled, depth + 1, draw);
    }
}
```
