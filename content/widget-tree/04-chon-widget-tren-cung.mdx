# Hai nút chồng nhau: nút nào nhận chuột?

## Vấn đề cần giải quyết

Xếp Reset ở đúng chỗ Pause trong preset chồng. Nếu cứ trả ngay node đầu tiên chứa con trỏ, bạn sẽ kích hoạt nút ở bên dưới – nút mà người dùng không thấy.

## Hiểu ý tưởng trước khi viết code

Node vẽ sau nằm phía trước. Vì thế cần thử child cuối trước, rồi mới xét child trước nó hoặc chính parent. Tại mỗi bước phải loại cả phần ngoài bounds lẫn ngoài clip.

## Viết code từng bước

### Tìm từ phần nhìn thấy ở trên cùng

Dùng `rbegin()` để đi ngược các child. Label có thể che một phần nét vẽ nhưng không phải control nhận input. Panel trống vẫn chặn click để con chim sau panel không bị chọn.

{/* snippet include/traversal.hpp#topmost */}

```cpp title="include/traversal.hpp — Tìm từ phần nhìn thấy ở trên cùng"
inline WidgetId pick(const Widget& node, Point origin, Rect clip, bool enabled, int depth, Point point) {
    const auto placed = place(node, origin, clip, enabled, depth);
    if (!placed || !contains(placed->clip, point) || !contains(placed->bounds, point))
        return 0;
    // Con vẽ sau nằm trên: tìm ngược thứ tự paint, rồi mới xét parent.
    for (auto it = node.children.rbegin(); it != node.children.rend(); ++it) {
        const WidgetId hit = pick(**it, {placed->bounds.x, placed->bounds.y}, placed->clip, placed->enabled, depth + 1, point);
        if (hit != 0)
            return hit;
    }
    if (node.kind == Kind::Panel)
        return node.id;
    if (node.kind == Kind::Button || node.kind == Kind::Slider)
        return node.id;
    return 0;
}
```

### Điểm ngoài viewport không trúng node nào

Từ chối điểm ngoài cửa sổ trước khi gọi tìm trong root. Kết quả là ID, không phải một con trỏ mà lần sau rất có thể đã hết hiệu lực.

{/* snippet include/traversal.hpp#hit */}

```cpp title="include/traversal.hpp — Điểm ngoài viewport không trúng node nào"
inline WidgetId hitTest(const Tree& tree, Point point) {
    if (!contains(viewport, point))
        return 0;
    return pick(*tree.root, {}, viewport, true, 0, point);
}
```

Chọn preset hai nút chồng bằng P; đưa chuột vào vùng chung và bật F2. Đối chiếu ID của node với nút đang vẽ trên cùng.

## Thử làm sai để hiểu đúng

Đổi `rbegin()` thành thứ tự thêm ban đầu. Hai nút vẫn vẽ giống hệt trước đó; chỉ ID ở inspector đổi sai.
