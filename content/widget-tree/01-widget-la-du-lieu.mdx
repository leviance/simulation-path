Hãy nghĩ đến thẻ tên của một con chim: nó vẫn là con ấy dù đổi vị trí. Widget cũng cần ID không phụ thuộc vào chỗ con trỏ đang trỏ trong bộ nhớ. Parent sở hữu từng child; UI chỉ nhớ ID.

## Viết code từng bước

### Node chứa gì?

`Widget` chứa hình học local, loại, nhãn và danh sách con. Không nhét vận tốc đàn vào widget: hai phần có vòng đời khác nhau.

{/* snippet include/tree.hpp#identity */}

```cpp title="include/tree.hpp — Node chứa gì?"
struct Widget {
    WidgetId id = 0;
    Kind kind = Kind::Panel;
    Rect local;
    std::string text;
    Action action = Action::None;
    Binding binding = Binding::None;
    std::vector<std::unique_ptr<Widget>> children;
};
```

### Trao child cho parent

Lấy ID trước khi `std::move` chuyển quyền sở hữu. Từ đây không giữ con trỏ tạm qua lần thay đổi cây; tìm lại bằng ID khi cần.

{/* snippet include/tree.hpp#own-child */}

```cpp title="include/tree.hpp — Trao child cho parent"
inline WidgetId add(Tree& tree, WidgetId parentId, Kind kind, Rect local, const std::string& text = "", Action action = Action::None, Binding binding = Binding::None) {
    Widget* parent = find(*tree.root, parentId);
    if (!parent || parent->kind != Kind::Panel || tree.count >= maxWidgets || tree.nextId > maxId || depthOf(*tree.root, parentId) >= maxDepth || !validRect(local) || text.size() > 40) {
        throw std::out_of_range("widget parent, geometry or capacity");
    }

    auto child = std::make_unique<Widget>();
    child->id = tree.nextId;
    child->kind = kind;
    child->local = local;
    child->text = text;
    child->action = action;
    child->binding = binding;
    const WidgetId id = child->id;
    parent->children.push_back(std::move(child));
    ++tree.nextId;
    ++tree.count;
    ++tree.revision;
    return id;
}
```

## Thử làm sai để hiểu đúng

Thử dựng cây ở đầu mỗi frame. Nút có thể vẫn nằm đúng chỗ trên ảnh, nhưng bộ đếm dựng và giá trị focus sẽ tố cáo lỗi.

Node thuộc đúng một parent. Một lần Reset đàn không thay địa chỉ root hoặc bộ cấp ID; không cần hoạt động chuột cho các nút ở mốc đầu này.
