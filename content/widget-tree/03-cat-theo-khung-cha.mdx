# Phần nút bị cắt vẫn tồn tại trong cây

## Vấn đề cần giải quyết

Chuyển sang preset bảng thấp. Reset vẫn cao 44 px, nhưng chỉ còn thấy 36 px. Tám pixel biến mất ở đâu? Nếu sửa chiều cao của Reset thành 36, khi mở rộng Panel nó sẽ không trở lại như cũ.

## Hiểu ý tưởng trước khi viết code

Tách `bounds` – nơi widget đáng lẽ xuất hiện – khỏi `clip` – phần màn hình thực sự cho phép xuất hiện. Giao của hai khoảng nửa mở (half-open) cũng là nửa mở: pixel đúng ngay dưới cạnh đáy không nằm trong khung.

## Viết code từng bước

### Giao hai hình chữ nhật

Bên trái lấy giá trị lớn hơn, bên phải lấy giá trị nhỏ hơn. Nếu hai cạnh vượt qua nhau, chiều rộng bằng 0, không được lật chúng để tạo một khung giả.

{/* snippet include/geometry.hpp#clip */}

```cpp title="include/geometry.hpp — Giao hai hình chữ nhật"
inline Rect intersect(Rect a, Rect b) {
    const double x = std::max(a.x, b.x);
    const double y = std::max(a.y, b.y);
    return {x, y, std::max(0.0, std::min(a.x + a.width, b.x + b.width) - x), std::max(0.0, std::min(a.y + a.height, b.y + b.height) - y)};
}
```

### Giữ bounds đủ, thu hẹp clip

Lưu cả hai vào `WidgetView` và truyền clip đã thu hẹp xuống child. Child bị khuất hoàn toàn có thể không có view, nhưng `find` vẫn tìm thấy ID trong cây.

{/* snippet include/traversal.hpp#world-frame */}

```cpp title="include/traversal.hpp — Giữ bounds đủ, thu hẹp clip"
inline std::optional<WidgetView> place(const Widget& node, Point origin, Rect clip, bool enabled, int depth) {
    const Rect bounds{origin.x + node.local.x, origin.y + node.local.y, node.local.width, node.local.height};
    clip = intersect(bounds, clip);
    if (clip.width <= 0 || clip.height <= 0)
        return std::nullopt;
    return WidgetView{&node, bounds, clip, enabled, depth};
}
```
