# Vẽ hai trục và đặt điểm đầu tiên

## Vấn đề cần giải quyết

Bạn đã biết tạo window, renderer và texture; ở Project 04, bạn còn tự vẽ được các hình cơ bản. Lần này ta dùng những phần ấy để làm một mặt phẳng tọa độ: đặt vài điểm, kéo góc nhìn, phóng to một vùng rồi đọc tọa độ của nó.

Ta chưa cần học hết Camera2D ngay. Hãy bắt đầu bằng cửa sổ 960 × 540, hai trục cắt nhau ở giữa và điểm xanh tại (2,1). Bạn sẽ tự tính điểm ấy phải được vẽ ở pixel nào, sau đó mới viết hàm chuyển đổi.

## Hiểu ý tưởng trước khi viết code

“Điểm nằm ở đâu trên bản đồ?” khác với “phải tô pixel nào để nhìn thấy điểm?”. Ta gọi câu trả lời thứ nhất là **world coordinate**, thứ hai là **screen coordinate**.

World có X sang phải, Y hướng lên. Screen có gốc ở góc trên trái, X sang phải, Y xuống dưới. Chọn 55 screen pixel cho một đơn vị world. Khi camera nhìn vào gốc:

| Điểm world | Điểm screen, viewport 960 × 540 | Vị trí |
|---|---|---|
| (0,0) | (480,270) | Giữa ảnh |
| (2,1) | (590,215) | Trên phải |
| (−1,−2) | (425,380) | Dưới trái |

Y của (2,1) là 270 − 55 = 215, không phải 325: hai hệ có chiều Y ngược nhau.

## Viết code từng bước

### Bước 1 — Chạy bộ khung trước

Tải ZIP, giải nén và mở terminal tại thư mục có CMakeLists.txt:

```bash title="Terminal — configure và chạy starter trên Windows"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_5_starter --parallel 2
.\build\Debug\project_5_starter.exe
```

Starter phải hiện nền xanh đen, resize được, Space tạm dừng và Escape thoát. Linux/macOS dùng target tương tự, thường chạy executable trực tiếp trong build. Chưa thấy nền thì sửa SDL trước khi thêm hình.

Bộ khung đã tách Framebuffer, presentation và main. Hàm ghi pixel vẫn như Project 01:

```cpp title="include/framebuffer.hpp — ghi một pixel trong ảnh CPU"
void putPixel(int x, int y, std::uint32_t color) {
    if (x < 0 || y < 0 || x >= width || y >= height) {
        return;
    }
    pixels[static_cast<std::size_t>(y) * width + x] = color;
}
```

Screen ở đây là **pixel logic của window**. Trên màn hình HiDPI, renderer có thể xuất nhiều pixel vật lý hơn. Không tự nhân tọa độ chuột với DPI.

### Bước 2 — Lưu điểm bằng đơn vị world

Thêm Camera2D trong include/lab.hpp; ở bài đầu nó mới chỉ giữ dữ liệu:

```cpp title="include/lab.hpp — dữ liệu camera"
struct Camera2D {
    Vec2 centerWorld{};
    double pixelsPerUnit{55.0};
    Vec2 viewportPixels{960.0, 540.0};

    [[nodiscard]] double scale() const {
        if (!std::isfinite(pixelsPerUnit) || pixelsPerUnit <= 0.0) {
            return 55.0;
        }
        return std::clamp(pixelsPerUnit, 5.0, 800.0);
    }

};
```

centerWorld là vị trí nhìn vào, không phải vị trí vật thể. viewportPixels là kích thước ảnh logic. scale() dùng 55 khi tỉ lệ không hợp lệ, còn tỉ lệ hợp lệ được giới hạn 5–800.

Trong Scene, lưu điểm (2,1), không lưu (590,215):

```cpp title="include/scene.hpp — điểm lưu trong world"
struct Scene {
    Camera2D camera;
    std::vector<Vec2> points{{2.0, 1.0}};
};
```

Vector points chuẩn bị cho nhiều điểm ở bài sau. Tọa độ screen phụ thuộc góc nhìn nên sẽ được tính lại khi vẽ.

### Bước 3 — Vẽ trục và chấm điểm

renderScene xóa nền, đặt gốc giữa ảnh, vẽ một hàng làm trục X và một cột làm trục Y. Các primitive chỉ gọi putPixel:

```cpp title="include/framebuffer.hpp — vẽ một hàng của ảnh CPU"
inline void horizontal(Framebuffer& image, int y, std::uint32_t color) {
    for (int x = 0; x < image.width; ++x) {
        image.putPixel(x, y, color);
    }
}
```

Trong vòng lặp qua points, tính:

```cpp title="include/view.hpp — tính vị trí chấm trên ảnh"
const Vec2 markerScreen{
    origin.x + world.x * scene.camera.pixelsPerUnit,
    origin.y - world.y * scene.camera.pixelsPerUnit,
};
```

X tăng một đơn vị làm screen X tăng 55 px; Y tăng một đơn vị làm screen Y giảm 55 px. Sau khi kiểm tra vùng nhìn, làm tròn x/y rồi gọi disc để tô chấm tròn. Bạn có thể đọc trọn renderScene ở phần source cuối bài.

### Bước 4 — Đưa ảnh lên window

Main gọi renderScene khi dirty, sau đó chép ảnh sang texture:

```cpp title="include/presentation.hpp — chép ảnh CPU sang texture"
inline bool uploadFramebuffer(SDL_Texture* texture, const Framebuffer& image) {
    return SDL_UpdateTexture(texture, nullptr, image.pixels.data(), image.width * static_cast<int>(sizeof(std::uint32_t)));
}
```

SDL_UpdateTexture chỉ chép pixel, không đổi world coordinate. presentFramebuffer vẽ texture và gọi SDL_RenderPresent.

```bash title="Terminal — chạy hình đầu tiên"
cmake --build build --config Debug --target project_5_checkpoint_1 --parallel 2
.\build\Debug\project_5_checkpoint_1.exe
```

## Ghép các phần lại

points (2,1) → renderScene tính markerScreen → disc ghi ảnh CPU → SDL_UpdateTexture → renderer hiển thị. Resize cập nhật framebuffer và viewport, không sửa points.

Hãy thay điểm bằng (−1,−2), build lại và kiểm tra nó nằm dưới trái. Bạn chưa cần chuột hay zoom để kiểm chứng quy ước.

## Thử làm sai để hiểu đúng

1. Đổi dấu trừ trước world.y thành cộng. Điểm (2,1) xuống dưới trục X. Giải thích bằng chiều tăng của screen Y rồi hoàn tác.
2. Lưu (590,215) như world point. Nó bị nhân thêm 55 và đi khỏi ảnh. Đổi về (2,1).
3. Bỏ uploadFramebuffer. Vector đã đổi nhưng window không nhận ảnh mới: đây là lỗi trình bày, không phải công thức.
