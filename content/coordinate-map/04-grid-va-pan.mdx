# Lưới động và kéo camera

## Vấn đề cần giải quyết

Hai trục cho biết gốc và chiều, nhưng chưa giúp bạn đọc một điểm ở xa gốc. Ta cần lưới world-space và cách kéo góc nhìn tới vùng muốn quan sát.

Nếu cứ kẻ cách nhau 55 pixel trên ảnh, lưới sẽ không còn đại diện đúng đơn vị world khi đổi zoom. Bài này sinh lưới từ camera, rồi thêm pan bằng chuột phải.

## Hiểu ý tưởng trước khi viết code

Đổi hai góc ảnh về world để biết khoảng đang nhìn thấy. Với một bước lưới h, các đường đứng nằm tại x = k × h; đường ngang tại y = k × h. Đường đầu tiên bên trái là ceil(left/h) × h.

Ta chọn h trong dãy 1, 2, 5 nhân lũy thừa của 10 sao cho mỗi ô rộng ít nhất 40 pixel. Ví dụ s = 55 thì h = 1; s = 5 thì h = 10; s = 800 thì h = 0,05. Đổi bước lưới chỉ đổi đường kẻ phụ, không đổi điểm hoặc trục.

Pan có nghĩa là dời cảnh theo tay. Kéo sang phải dx pixel, camera phải nhìn sang trái dx/s world unit:

$$
c_x' = c_x - \frac{d_x}{s},\qquad
c_y' = c_y + \frac{d_y}{s}
$$

## Viết code từng bước

### Bước 1 — Chọn bước lưới dễ đọc

```cpp title="include/lab.hpp — chọn bước từ dãy 1–2–5"
inline double gridSpacing(double pixelsPerUnit) {
    if (!std::isfinite(pixelsPerUnit) || pixelsPerUnit <= 0.0) {
        return 1.0;
    }
    const double target = 40.0 / pixelsPerUnit;
    const double power = std::pow(10.0, std::floor(std::log10(target)));
    for (double multiplier : {1.0, 2.0, 5.0, 10.0}) {
        const double step = multiplier * power;
        if (step >= target) {
            return step;
        }
    }
    return power * 10.0;
}
```

target là khoảng world tương ứng 40 screen pixel. power chọn hàng đơn vị, hàng chục hoặc phần thập phân; vòng for chọn mức đầu tiên không nhỏ hơn target. Khoảng cách screen nằm khoảng 40–100 px.

### Bước 2 — Vẽ phần lưới đang thấy

```cpp title="include/view.hpp — sinh lưới từ world bounds"
inline void drawGrid(Framebuffer& image, const Camera2D& camera) {
    const Vec2 bottomLeft = camera.screenToWorld({0.0, static_cast<double>(image.height)});
    const Vec2 topRight = camera.screenToWorld({static_cast<double>(image.width), 0.0});
    const double spacing = gridSpacing(camera.scale());
    const double firstX = std::ceil(bottomLeft.x / spacing) * spacing;
    const double firstY = std::ceil(bottomLeft.y / spacing) * spacing;
    const int columns = static_cast<int>(std::ceil((topRight.x - bottomLeft.x) / spacing)) + 1;
    const int rows = static_cast<int>(std::ceil((topRight.y - bottomLeft.y) / spacing)) + 1;
    for (int index = 0; index < columns; ++index) {
        const double worldX = firstX + index * spacing;
        const int x = static_cast<int>(std::lround(camera.worldToScreen({worldX, 0.0}).x));
        vertical(image, x, kGrid);
    }
    for (int index = 0; index < rows; ++index) {
        const double worldY = firstY + index * spacing;
        const int y = static_cast<int>(std::lround(camera.worldToScreen({0.0, worldY}).y));
        horizontal(image, y, kGrid);
    }
}
```

bottomLeft/topRight là hai góc world của viewport. ceil đưa đường đầu tiên vào vùng nhìn. columns/rows được tính từ độ rộng vùng nhìn, không phải tọa độ tuyệt đối.

Vòng lặp dùng index nguyên rồi tính first + index × spacing. Không cộng dồn worldX cho tới khi vượt right: cách đó dễ mắc lỗi số thực ở tọa độ rất lớn. Mỗi đường được worldToScreen rồi vẽ qua vertical/horizontal.

Trong renderScene, gọi drawGrid trước khi vẽ trục và điểm. Trục có màu riêng, không phụ thuộc một đường grid có tình cờ rơi đúng số 0 hay không. presentation.hpp thêm nhãn số cạnh đường kẻ; khi gốc đi khỏi ảnh, nhãn được giữ gần mép để vẫn đọc được.

### Bước 3 — Viết pan trong Camera2D

```cpp title="include/lab.hpp — đổi pixel delta sang world delta"
void pan(Vec2 deltaPixels) {
    if (!finite(deltaPixels)) {
        return;
    }
    centerWorld.x -= deltaPixels.x / scale();
    centerWorld.y += deltaPixels.y / scale();
}
```

scale là pixel/world, nên deltaPixels/scale là world. Dấu của X âm vì camera đi ngược cảnh. Dấu Y dương vì screen Y hướng xuống.

### Bước 4 — Nối kéo chuột phải

Main giữ owner là mouse đang kéo, ownerButton là nút, previousScreen là mẫu trước. Khi nhấn phải bên trong ảnh, bật panning và capture. Khi motion của đúng owner tới, khối này xử lý:

```cpp title="src/main.cpp — cập nhật từ từng mẫu chuột"
if (ownerButton != 0 && event.motion.which == owner) {
    if ((event.motion.state & SDL_BUTTON_MASK(ownerButton)) == 0) {
        cancelDrag();
    } else if (scene.panning) {
        const lab::Vec2 delta{scene.cursorScreen.x - scene.previousScreen.x, scene.cursorScreen.y - scene.previousScreen.y};
        scene.camera.pan(delta);
        scene.previousScreen = scene.cursorScreen;
    }
}
```

Cập nhật previousScreen ngay sau pan. Nếu quên, mẫu tiếp theo sẽ cộng lại quãng kéo cũ và cảnh chạy nhanh dần.

Khi thả đúng nút/owner, main còn áp dụng delta cuối trong button-up rồi cancelDrag. Mất focus, window hidden, resize hoặc pause cũng hủy capture. Không cần tiếp tục giữ nút sau khi ứng dụng đã mất focus.

## Ghép các phần lại

Camera quyết định bounds → gridSpacing chọn đơn vị đường kẻ → drawGrid tạo ảnh mới. Pan chỉ sửa centerWorld rồi đặt dirty; nó không kéo bitmap cũ và không sửa points.

Resize tạo framebuffer/texture đúng kích thước logic mới, cập nhật viewportPixels, hủy drag cũ rồi dựng lại. Với world point giữ nguyên, screen coordinate thay đổi theo tâm viewport mới là đúng.

## Thử làm sai để hiểu đúng

1. Giữ gridSpacing luôn bằng 1 rồi đặt tỉ lệ 5 px/unit. Lưới trở nên quá dày. Trả lại bước thích nghi.
2. Đổi dấu X trong pan thành cộng. Cảnh đi ngược tay.
3. Bỏ cập nhật previousScreen. Kéo đều và quan sát cảnh tăng tốc vì delta bị tính lặp.
4. Chỉ đổi kích thước texture mà không đổi viewportPixels. Gốc camera không còn ở giữa ảnh sau resize.

## Tự kiểm tra kết quả

- Grid và điểm dùng cùng worldToScreen; nhãn thể hiện đơn vị world.
- Ở 55 px/unit, kéo (55, 27.5) px làm centerWorld đổi thành (−1, 0.5).
- Điểm trên screen dịch đúng (55, 27.5) px theo tay, points không đổi.
- Chỉ đúng nút và đúng mouse owner được kéo camera.
- Thả chuột, resize, pause hoặc mất focus không để trạng thái pan bị kẹt.
