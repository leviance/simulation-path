# Chia cho w và tìm pixel trên màn hình

## Vấn đề cần giải quyết

Ta đã có clip vector nhưng chưa có pixel. Nếu chia mọi thứ cho w rồi vẽ ngay, điểm trên hoặc sau mặt phẳng camera có thể cho số vô hạn, lật ngược hoặc kéo một đường rất dài.

Bài này tách ba câu hỏi: **có tính được NDC không, điểm có nằm trong vùng nhìn không, và được phép vẽ gì?** Chúng liên quan nhưng không phải một điều kiện duy nhất.

## Hiểu ý tưởng trước khi viết code

Với w dương và đủ xa 0:

$$
p_{NDC}=(x_{clip}/w,\ y_{clip}/w,\ z_{clip}/w).
$$

Trong convention của project, vùng nhìn thỏa −w≤x,y≤w và 0≤z≤w. Một điểm có w>0 nhưng vượt near/far hoặc biên X/Y vẫn có thể có NDC hữu hạn. Ta **giữ số đó để soi**, nhưng không vẽ marker như thể điểm còn visible.

Ngược lại, khi w≤epsilon, code không thực hiện phép chia. Dòng NDC/SCREEN phải là —, không phải tọa độ (0,0) giả. Epsilon=10⁻⁹ là chính sách số học của ứng dụng này, không phải khẳng định rằng mọi w dương đều chia an toàn ở mọi quy mô.

Chọn lần lượt Before near, Behind camera, Beyond far, Outside XY và w=0. Với Outside XY, số SCREEN có thể vượt viewport; điều đó hữu ích để tìm lỗi. Với Behind/w=0, NDC/SCREEN không tồn tại. Một vertex bị loại không có nghĩa mọi cạnh còn lại của mô hình cũng phải biến mất.

## Viết code từng bước

### Bước 1 — Không dùng số 0 làm giá trị mặc định

Thêm enum và trace trong lab.hpp:

```cpp title="include/lab.hpp — trạng thái tách khỏi tọa độ"
enum class PipelineStatus {
    Visible,
    BehindCamera,
    BeforeNearPlane,
    BeyondFarPlane,
    OutsideFrustum,
    Invalid,
};
```

```cpp title="include/lab.hpp — stage có thể chưa có giá trị"
struct PipelineTrace {
    std::optional<Vec4> local;
    std::optional<Vec4> world;
    std::optional<Vec4> camera;
    std::optional<Vec4> clip;
    std::optional<Vec3> ndc;
    std::optional<Vec2> screen;
    PipelineStatus status = PipelineStatus::Invalid;
};
```

optional diễn đạt việc một phép toán chưa được thực hiện hoặc không hợp lệ. Status lại cho biết vì sao một vertex không được vẽ. Hai khái niệm này không thay thế nhau.

### Bước 2 — Guard rồi chia, sau đó đổi viewport

```cpp title="include/lab.hpp — không chia w bằng 0"
inline std::optional<Vec3> perspectiveDivide(Vec4 clipPoint) {
    if (!finite(clipPoint) || clipPoint.w <= kDivideEpsilon) {
        return std::nullopt;
    }
    const Vec3 ndc{clipPoint.x / clipPoint.w, clipPoint.y / clipPoint.w, clipPoint.z / clipPoint.w};
    if (!finite(ndc)) {
        return std::nullopt;
    }
    return ndc;
}
```

```cpp title="include/lab.hpp — đổi sang logical pixels"
inline std::optional<Vec2> ndcToScreen(Vec3 ndc, Viewport viewport) {
    if (!finite(ndc) || !validViewport(viewport)) {
        return std::nullopt;
    }
    const Vec2 screen{(ndc.x + 1.0) * 0.5 * viewport.width, (1.0 - ndc.y) * 0.5 * viewport.height};
    if (!finite(screen)) {
        return std::nullopt;
    }
    return screen;
}
```

SCREEN X dùng (xNDC+1)·width/2. SCREEN Y đảo dấu vì framebuffer đi từ trên xuống. Điểm NDC=(0,0,...) nằm giữa viewport, không phải góc trái trên.

Viewport là vùng cảnh 1100×560 khi debug bật. CSS pixel, pixel thiết bị HiDPI và logical pixel không phải cùng một đơn vị.

SCREEN vẫn là tọa độ số thực. NDC X=1 ánh xạ đúng ra biên X=1100, trong khi index pixel cuối là 1099. Renderer kiểm riêng vùng index hợp lệ trước khi vẽ marker; không sửa số trên bảng thành 1099 để che khác biệt giữa tọa độ liên tục và chỉ số mảng.

### Bước 3 — Viết trace theo đúng trình tự

```cpp title="include/lab.hpp — giữ dữ liệu trung gian và lý do dừng"
inline PipelineTrace tracePipeline(Vec3 localVertex, const ModelTransform& model, const Camera3D& camera, const PerspectiveLens& lens, Viewport viewport) {
    PipelineTrace trace;
    if (!finite(localVertex)) {
        return trace;
    }
    trace.local = toPoint(localVertex);
    if (!finite(model.position) || !finite(model.scale) || !std::isfinite(model.yaw)) {
        return trace;
    }
    const Vec4 world = transform(modelMatrix(model), *trace.local);
    if (!finite(world)) {
        return trace;
    }
    trace.world = world;
    if (!finite(camera.position) || !std::isfinite(camera.yaw) || !std::isfinite(camera.pitch)) {
        return trace;
    }
    const Vec4 view = transform(viewMatrix(camera), world);
    if (!finite(view)) {
        return trace;
    }
    trace.camera = view;
    if (!validLens(lens) || !validViewport(viewport)) {
        return trace;
    }
    const Vec4 clip = transform(projectionMatrix(lens, viewport.width / viewport.height), view);
    if (!finite(clip)) {
        return trace;
    }
    trace.clip = clip;
    if (clip.w <= kDivideEpsilon) {
        trace.status = PipelineStatus::BehindCamera;
        return trace;
    }
    trace.ndc = perspectiveDivide(clip);
    if (!trace.ndc) {
        return trace;
    }
    trace.screen = ndcToScreen(*trace.ndc, viewport);
    if (!trace.screen) {
        return trace;
    }
    // Giữ NDC/screen hữu hạn kể cả điểm bị clip; không dùng (0,0) làm giá trị giả.
    const double epsilon = 1e-10 * std::max(1.0, std::abs(clip.w));
    if (clip.z < -epsilon) {
        trace.status = PipelineStatus::BeforeNearPlane;
    } else if (clip.z > clip.w + epsilon) {
        trace.status = PipelineStatus::BeyondFarPlane;
    } else if (std::abs(clip.x) > clip.w + epsilon || std::abs(clip.y) > clip.w + epsilon) {
        trace.status = PipelineStatus::OutsideFrustum;
    } else {
        trace.status = PipelineStatus::Visible;
    }
    return trace;
}
```

Đọc hàm thành từng chặng:

- Kiểm local rồi tính WORLD. Chỉ lưu khi kết quả hữu hạn.
- Tính VIEW từ WORLD; lens sai không được xóa những dữ liệu trước đó đã có.
- Lens/viewport hợp lệ mới xây P và tính CLIP.
- w quá nhỏ hoặc âm dừng trước divide.
- Positive w cho phép tính NDC/SCREEN để kiểm tra, rồi phân loại các bất đẳng thức clip.

Tolerance ở phép so clip tỉ lệ với |w| để điểm đúng tại near/far không bị loại do sai số làm tròn. Nó không clamp tọa độ để đẩy một điểm outside trở lại visible.

### Bước 4 — Thay projection tham chiếu trong renderer

Thay projectViewPoint trong view.hpp:

```cpp title="include/view.hpp — ảnh thật dùng P mới"
inline std::optional<Vec2> projectViewPoint(Vec3 view, const Scene& scene) {
    const Viewport viewport = viewportFor(scene);
    if (!finite(view) || !validLens(scene.lens) || !validViewport(viewport) || view.z <= kDivideEpsilon) {
        return std::nullopt;
    }
    const Vec4 clip = transform(projectionMatrix(scene.lens, viewport.width / viewport.height), toPoint(view));
    const auto ndc = perspectiveDivide(clip);
    if (!ndc) {
        return std::nullopt;
    }
    return ndcToScreen(*ndc, viewport);
}
```

Từ đây ảnh không dùng đường tham chiếu P11 nữa. drawWorldLine vẫn clip đoạn trong view trước, rồi gọi hàm này cho hai endpoint, clip screen và mới chuyển sang int/Bresenham.

Không thay clipping đoạn bằng “chỉ vẽ khi cả hai vertex Visible”. Một cạnh đi xuyên màn hình có thể có cả hai đầu outside mà phần giữa vẫn cần vẽ. Project 18 sẽ đi sâu vào clipping tam giác; ở đây ta chỉ giữ các cạnh wireframe đúng.

## Ghép các phần lại

Thay inspectScene bằng bản đầy đủ ở checkpoint 6 để chuyển optional sang các dòng hiển thị:

```cpp title="include/scene.hpp — đủ sáu dòng, không tạo giá trị giả"
inline Inspection inspectScene(const Scene& scene) {
    Inspection result;
    if (scene.selectedVertex >= scene.vertices.size()) {
        result.status = "invalid vertex index";
        return result;
    }
    const Vec3 local = scene.vertices[scene.selectedVertex];
    if (finite(local)) {
        result.rows[0].value = Vec4{local.x, local.y, local.z, 1.0};
    }
    const Vec4 world = transform(modelMatrix(scene.model), toPoint(local));
    if (finite(world)) {
        result.rows[1].value = world;
    }
    const Vec4 view = transform(viewMatrix(scene.camera), world);
    if (finite(view)) {
        result.rows[2].value = view;
    }
    const Viewport viewport = viewportFor(scene);
    if (validLens(scene.lens) && validViewport(viewport)) {
        const Vec4 clip = transform(projectionMatrix(scene.lens, viewport.width / viewport.height), view);
        if (finite(clip)) {
            result.rows[3].value = clip;
        }
    }
    const PipelineTrace trace = tracePipeline(local, scene.model, scene.camera, scene.lens, viewport);
    result.rows[0].value = trace.local;
    result.rows[1].value = trace.world;
    result.rows[2].value = trace.camera;
    result.rows[3].value = trace.clip;
    if (trace.ndc) {
        result.rows[4].value = Vec4{trace.ndc->x, trace.ndc->y, trace.ndc->z, 0.0};
    }
    if (trace.screen) {
        result.rows[5].value = Vec4{trace.screen->x, trace.screen->y, 0.0, 0.0};
    }
    result.status = statusName(trace.status);
    return result;
}
```

## Thử làm sai để hiểu đúng

1. Xóa guard w rồi chọn preset w=0. Kiểm tra có Infinity/NaN xuất hiện không; khôi phục optional rỗng trước khi vẽ.
2. Trả SCREEN=(0,0) khi Outside XY. Người đọc tưởng điểm nằm ở góc cửa sổ; giữ tọa độ thật ngoài viewport và chỉ chặn việc raster marker.
3. Đổi SCREEN Y thành (yNDC+1)·height/2. Điểm ở trên camera chạy xuống dưới ảnh; sửa đúng phép đảo Y.
4. Bỏ clip đoạn và lọc cả hai endpoint bằng status Visible. Các cạnh dài mất nguyên đoạn ở mép; phục hồi clipViewDepth/clipScreen.

## Tự kiểm tra kết quả

- Ví dụ clip=(0,1,27/8,4) cho NDC=(0,1/4,27/32), SCREEN=(550,210).
- w=0/âm không sinh NDC/SCREEN; không có giá trị 0 giả.
- Điểm bị clip do near/far/X/Y vẫn có số hữu hạn để soi khi phép chia hợp lệ.
- Near/far được tính inclusive trong tolerance; không đổi dấu depth convention.
- Renderer đã dùng P, divide và viewport mới; các cạnh được clip trước Bresenham.

## Bài tập mở rộng

Chọn một điểm view ở cùng x,y nhưng z tăng gấp đôi. Giữ lens cố định rồi dự đoán độ lệch khỏi tâm screen giảm ra sao. Sau đó thử thay near/far: vị trí X/Y không đổi, còn NDC Z có thể đổi.
