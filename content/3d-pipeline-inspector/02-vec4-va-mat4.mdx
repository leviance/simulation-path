# Thêm w để tịnh tiến bằng ma trận

## Vấn đề cần giải quyết

Ma trận 3×3 nhân Vec3 có thể scale hoặc xoay quanh origin. Nhưng làm sao biểu diễn **cộng thêm một độ dời** bằng cùng phép nhân?

Ta thêm thành phần w để đưa phép cộng translation vào ma trận. Đây không phải thêm một chiều không gian để vẽ; nó là cách viết các phép biến đổi sao cho ghép được bằng phép nhân.

## Hiểu ý tưởng trước khi viết code

Xét cùng xyz=(1,2,3). Point là một vị trí nên translation(2,1,3) phải đưa nó tới (3,3,6). Direction chỉ mô tả hướng/độ dài, không có “chỗ đứng” cần dời, nên vẫn là (1,2,3).

Ta quy ước point có w=1, direction có w=0. Hàng X của translation matrix tính x'=x+tx·w; vì vậy hai trường hợp khác nhau đúng ở phần translation.

## Viết code từng bước

### Bước 1 — Lưu Mat4 và chốt column vector

Thêm Mat4 vào lab.hpp, trong namespace lab. Vec4 đã có trong bộ khung:

```cpp title="include/lab.hpp — 16 phần tử theo row-major"
struct Mat4 {
    std::array<double, 16> values{};

    double& at(int row, int column) {
        return values[static_cast<std::size_t>(row * 4 + column)];
    }

    double at(int row, int column) const {
        return values[static_cast<std::size_t>(row * 4 + column)];
    }
};
```

at(row,column) dùng index row*4+column: hàng đầu là index 0–3. **row-major chỉ nói cách lưu**. Ta vẫn viết p'=M·p, vector đứng bên phải; không suy ra convention từ layout của mảng.

### Bước 2 — Tạo point và direction rõ nghĩa

```cpp title="include/lab.hpp — đặt w cho vị trí"
inline Vec4 toPoint(Vec3 point) {
    return {point.x, point.y, point.z, 1.0};
}
```

```cpp title="include/lab.hpp — đặt w cho hướng"
inline Vec4 toDirection(Vec3 direction) {
    return {direction.x, direction.y, direction.z, 0.0};
}
```

Chỉ các phép affine M/V đang học giữ ý nghĩa point w=1, direction w=0 như trên. Sau perspective projection, w có nhiệm vụ khác: giữ mẫu số để chia. Không dùng quy tắc “w lúc nào cũng bằng 1” cho clip space.

### Bước 3 — Viết identity và hai phép nhân

```cpp title="include/lab.hpp — đường chéo bằng 1"
inline Mat4 identityMatrix() {
    Mat4 result;
    for (int index = 0; index < 4; ++index) {
        result.at(index, index) = 1.0;
    }
    return result;
}
```

Ma trận được khởi tạo bằng 0. Vòng lặp chỉ đặt bốn phần tử đường chéo thành 1.

```cpp title="include/lab.hpp — mỗi hàng tính một thành phần"
inline Vec4 transform(const Mat4& matrix, Vec4 vector) {
    Vec4 result;
    result.x = matrix.at(0, 0) * vector.x + matrix.at(0, 1) * vector.y + matrix.at(0, 2) * vector.z + matrix.at(0, 3) * vector.w;
    result.y = matrix.at(1, 0) * vector.x + matrix.at(1, 1) * vector.y + matrix.at(1, 2) * vector.z + matrix.at(1, 3) * vector.w;
    result.z = matrix.at(2, 0) * vector.x + matrix.at(2, 1) * vector.y + matrix.at(2, 2) * vector.z + matrix.at(2, 3) * vector.w;
    result.w = matrix.at(3, 0) * vector.x + matrix.at(3, 1) * vector.y + matrix.at(3, 2) * vector.z + matrix.at(3, 3) * vector.w;
    return result;
}
```

Đọc dòng result.x: cả bốn cột của hàng 0 nhân tương ứng x,y,z,w. Không chỉ nhân ba tọa độ đầu rồi cộng translation riêng trong hàm này; hàm phải nhân được mọi Mat4, kể cả P về sau.

```cpp title="include/lab.hpp — ghép hai ma trận"
inline Mat4 multiply(const Mat4& left, const Mat4& right) {
    Mat4 result;
    for (int row = 0; row < 4; ++row) {
        for (int column = 0; column < 4; ++column) {
            double sum = 0.0;
            for (int index = 0; index < 4; ++index) {
                sum += left.at(row, index) * right.at(index, column);
            }
            result.at(row, column) = sum;
        }
    }
    return result;
}
```

Với C=A·B, phần tử C[row,column] là tổng A[row,index]·B[index,column]. result mới tránh ghi đè left/right khi vẫn còn cần đọc chúng.

### Bước 4 — Viết translation matrix rồi thử số

```cpp title="include/lab.hpp — translation ở cột cuối"
inline Mat4 translationMatrix(Vec3 translation) {
    Mat4 result = identityMatrix();
    result.at(0, 3) = translation.x;
    result.at(1, 3) = translation.y;
    result.at(2, 3) = translation.z;
    return result;
}
```

Ba độ dời nằm ở cột 3, không phải hàng 3. Hàng cuối vẫn là (0,0,0,1), nên transform giữ nguyên w ở bước affine này.

## Thử làm sai để hiểu đúng

1. Đổi toDirection thành w=1. Direction nhận cả translation; test phải thấy kết quả đổi từ (1,2,3) thành (3,3,6) trong ví dụ trên.
2. Đặt tx/ty/tz ở hàng cuối. Bạn sẽ thay w chứ không dịch xyz. Đọc từng hàng của transform để tìm đúng phần tử sai.
3. Trong multiply, dùng left.at(index,row). Identity có thể vẫn che được lỗi ở vài phép thử; thử một cặp có cả translation và scale, đừng chỉ nhân identity.

## Tự kiểm tra kết quả

- Identity giữ cả x/y/z/w.
- Point(1,2,3,1) qua translation(2,1,3) thành (3,3,6,1).
- Direction(1,2,3,0) qua cùng matrix vẫn là (1,2,3,0).
- Mat4 lưu row-major nhưng phép biến đổi dùng column vector.
- Không có thư viện matrix làm thay các vòng lặp.
