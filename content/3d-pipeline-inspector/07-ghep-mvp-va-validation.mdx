# Ghép MVP và kiểm chứng bản hoàn chỉnh

## Vấn đề cần giải quyết

M, V và P đã chạy rời. Bây giờ ta ghép chúng thành một ma trận mà vẫn giữ inspector đọc được từng bước. Nếu chỉ giữ MVP rồi xóa các giá trị trung gian, công cụ sẽ mất đúng mục đích của nó.

Bài cuối còn phải trả lời câu hỏi quan trọng hơn: **làm sao biết cả ba ma trận cùng đúng, chứ không chỉ cùng mắc một lỗi?**

## Hiểu ý tưởng trước khi viết code

Với column vector:

$$
p_{clip}=P\,V\,M\,p_{local},\qquad MVP=P\,V\,M.
$$

Đây là clip vector, chưa phải NDC hoặc pixel. Perspective divide vẫn nằm sau phép nhân MVP.

Ta dùng hai loại bằng chứng: tính tay một trường hợp để khóa convention, rồi so pipeline rời với MVP trên nhiều dữ liệu. Phép so thứ hai bắt lỗi ghép nhưng không thay bằng chứng thứ nhất.

Chọn preset “Ví dụ tính tay”, vertex 0. Bảng phải khớp:

| Stage | Giá trị |
| --- | --- |
| LOCAL/model space | (1,1,0,1) |
| Sau scale (2,1,1) | (2,1,0,1) |
| Sau yaw 90° | (0,1,−2,1) |
| WORLD sau translation(1,0,6) | (1,1,4,1) |
| VIEW, camera position(1,0,0), yaw=pitch=0 | (0,1,4,1) |
| CLIP, FOV=90°, near=1, far=9 | (0,1,27/8,4) |
| NDC sau chia w=4 | (0,1/4,27/32) |
| SCREEN trên viewport 1100×560 | (550,210) |

Các số ở bảng được suy từ scale, sin/cos 90°, phép trừ position và công thức P, không lấy output MVP làm expected. Sai số double nhỏ quanh các giá trị này là bình thường.

## Viết code từng bước

### Bước 1 — Ghép P×V×M

Trong lab.hpp:

```cpp title="include/lab.hpp — model tác động trước"
inline Mat4 mvpMatrix(const ModelTransform& model, const Camera3D& camera, const PerspectiveLens& lens, double aspectRatio) {
    const Mat4 viewModel = multiply(viewMatrix(camera), modelMatrix(model));
    return multiply(projectionMatrix(lens, aspectRatio), viewModel);
}
```

Tính V×M trước hay P×V trước đều được do tính kết hợp. Không được đổi thành M×V×P: tính kết hợp không phải tính giao hoán.

### Bước 2 — Đo chênh lệch ở clip space

```cpp title="include/lab.hpp — sai số lớn nhất của bốn thành phần"
inline double maxAbsDifference(Vec4 left, Vec4 right) {
    if (!finite(left) || !finite(right)) {
        return std::numeric_limits<double>::infinity();
    }
    double error = 0.0;
    error = std::max(error, std::abs(left.x - right.x));
    error = std::max(error, std::abs(left.y - right.y));
    error = std::max(error, std::abs(left.z - right.z));
    return std::max(error, std::abs(left.w - right.w));
}
```

```cpp title="include/lab.hpp — đối chiếu ghép và chạy rời"
inline double pipelineAgreementError(Vec3 localVertex, const ModelTransform& model, const Camera3D& camera, const PerspectiveLens& lens, Viewport viewport) {
    const PipelineTrace separate = tracePipeline(localVertex, model, camera, lens, viewport);
    if (!separate.local || !separate.clip) {
        return std::numeric_limits<double>::infinity();
    }
    const Vec4 composed = transform(mvpMatrix(model, camera, lens, viewport.width / viewport.height), *separate.local);
    return maxAbsDifference(*separate.clip, composed);
}
```

So trước perspective divide để không che lỗi qua một phép chia chung. Nếu input sai và chưa có clip, hàm trả Infinity, không báo error=0 giả.

Inspector vẫn gọi tracePipeline để giữ WORLD/VIEW/CLIP/NDC/SCREEN. MVP chỉ là một đường tính thứ hai để so và để tái sử dụng về sau.

### Bước 3 — Thêm tự quay, pause và step

```cpp title="include/lab.hpp — góc tăng theo thời gian"
inline double advanceModelYaw(double yaw, double angularSpeed, double deltaTime) {
    if (!std::isfinite(yaw) || !std::isfinite(angularSpeed) || !std::isfinite(deltaTime) || deltaTime <= 0.0) {
        return yaw;
    }
    const double next = yaw + angularSpeed * std::min(deltaTime, 0.1);
    if (!std::isfinite(next)) {
        return yaw;
    }
    return wrapAngle(next);
}
```

```cpp title="include/scene.hpp — một đường update chung"
inline void advanceScene(Scene& scene, double deltaTime) {
    if (!scene.paused) {
        scene.model.yaw = advanceModelYaw(scene.model.yaw, 35.0 * kPi / 180.0, deltaTime);
    }
}
```

Một frame khựng bị giới hạn dt=0.1s; ta không cố bù một khoảng nghỉ dài bằng một bước nhảy lớn. Bản đầu paused=true, chỉ tự quay khi người dùng chọn tiếp tục.

Trong handleKey, thêm các nhánh sau:

```cpp title="src/main.cpp — pause, step và chế độ sạch"
if (!repeat && key == SDLK_SPACE) {
    scene.paused = !scene.paused;
}
if (!repeat && key == SDLK_N && scene.paused) {
    scene.model.yaw = lab::advanceModelYaw(scene.model.yaw, 35.0 * lab::kPi / 180.0, 1.0 / 30.0);
}
if (!repeat && key == SDLK_F) {
    scene.debug = !scene.debug;
    scene.paused = true;
}
```

N chỉ hoạt động khi paused, tăng đúng góc tương ứng 1/30s. F ẩn bảng/HUD và cho scene dùng viewport 1100×800. Aspect và SCREEN thay đổi theo viewport mới là đúng; LOCAL/WORLD/VIEW không được tự đổi. Lưới sàn và mesh không nằm trong nhánh debug nên vẫn còn.

### Bước 4 — Đưa sai số vào bảng kiểm và chạy tests

inspectScene đã có chỗ chứa agreement. Sau trace, thêm:

```cpp title="include/scene.hpp — chỉ hiện agreement hữu hạn"
const double agreement = pipelineAgreementError(local, scene.model, scene.camera, scene.lens, viewport);
if (std::isfinite(agreement)) {
    result.agreement = agreement;
}
```

Trong presentFramebuffer, sau phần nhắc phím, thêm trạng thái và agreement. Buffer value đã có ở đầu hàm; không tạo một buffer nằm ngoài phạm vi rồi vô tình đọc nó sau khi hết lifetime:

```cpp title="include/presentation.hpp — hiện sai số cùng trạng thái pause"
const char* state = "PAUSED";
if (!scene.paused) {
    state = "ROTATING";
}
if (inspection.agreement) {
    std::snprintf(value, sizeof(value), "MVP agreement %.2e | %s | Space pause/resume, N step | w=depth, not a screen coordinate", *inspection.agreement, state);
} else {
    std::snprintf(value, sizeof(value), "MVP agreement -- invalid input | %s", state);
}
if (!text(renderer, 16, 764, value)) {
    return false;
}
```

Bảng sáu dòng vẫn dùng cùng inspection; không tính riêng một agreement khác chỉ để vẽ HUD.

Trong tests/tests.cpp, helper check ghi lỗi và tăng failures; cuối main trả EXIT_FAILURE nếu có lỗi, nên Release không thể bỏ qua test như assert bị NDEBUG tắt. Đoạn oracle đọc rõ expected bằng số:

```cpp title="tests/tests.cpp — oracle tính tay xuyên pipeline"
lab::Scene scene;
lab::applyPreset(scene, 1);
const auto trace = lab::tracePipeline(scene.vertices[0], scene.model, scene.camera, scene.lens, lab::viewportFor(scene));
check(trace.world && same(lab::xyz(*trace.world), {1.0, 1.0, 4.0}), "hand world oracle");
check(trace.camera && same(lab::xyz(*trace.camera), {0.0, 1.0, 4.0}), "hand view oracle");
check(trace.clip && same(lab::xyz(*trace.clip), {0.0, 1.0, 27.0 / 8.0}) && near(trace.clip->w, 4.0), "hand clip oracle and camera depth in w");
check(trace.ndc && same(*trace.ndc, {0.0, 0.25, 27.0 / 32.0}), "hand NDC oracle");
check(trace.screen && near(trace.screen->x, 550.0) && near(trace.screen->y, 210.0), "hand screen oracle 1100x560");
check(trace.status == lab::PipelineStatus::Visible, "hand oracle visible");
check(lab::inspectScene(scene).rows[5].value.has_value(), "all six rows expose real runtime values");
```

Hàm check/near/same và mọi include đều có trong file test hoàn chỉnh. Ngoài oracle, tests còn kiểm T×S khác S×T, point/direction, model/view đối chiếu vô hướng, các biên clip, finite guards, chọn vertex, tốc độ quay và pixel cảnh khi debug tắt.

## Ghép các phần lại

```bash title="Terminal — build bản hoàn chỉnh và kiểm chứng"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --parallel 2
ctest --test-dir build -C Debug --output-on-failure --timeout 30
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure --timeout 30
./build/Release/project_15_final.exe
```

Cần C++20, CMake≥3.24, Visual Studio 2022 trên Windows. SDL **3.4.8** được FetchContent tải theo checksum, link qua SDL3::SDL3. Với Ninja/Makefiles, chọn CMAKE_BUILD_TYPE và tìm executable trực tiếp trong build/.

Nếu tự viết trong starter/, CTest mặc định vẫn kiểm final/include của bản tham khảo. Trong CMakeLists.txt của **bản ZIP đang học**, đổi target_include_directories(project_15_tests PRIVATE final/include) thành target_include_directories(project_15_tests PRIVATE starter/include), configure lại rồi build target project_15_tests. Chỉ khi đó test mới kiểm chính phần bạn vừa viết.

Source chia theo trách nhiệm, không cần dồn thành một main.cpp khổng lồ:

- lab.hpp: Vec4/Mat4, M/V/P, trace và correctness.
- scene.hpp: vertex/edge list, state, presets, tham số và inspector.
- framebuffer.hpp: pixel/Bresenham từ các project trước.
- view.hpp: clip/project/raster, marker và picking.
- presentation.hpp: SDL texture, bảng sáu dòng và HUD.
- src/main.cpp: SDL lifecycle, key binding, timing, resize và upload.
- tests/tests.cpp: kiểm chứng không mở window.

ZIP chứa Starter, bảy checkpoint, final, tests, README và CMakeLists độc lập. Phần **Toàn bộ mã nguồn của dự án** cuối bài hiển thị các file final để bạn đọc/copy; không phải một snippet rời thay executable.

## Thử làm sai để hiểu đúng

1. Đổi MVP thành M×V×P. Oracle và phép so chạy rời phải bắt lỗi; đừng chỉ nhìn một point ở origin.
2. Sửa cả trace lẫn MVP theo cùng một convention sai. Agreement có thể còn nhỏ, nhưng bảng tính tay và T×S/S×T phải báo lệch.
3. Đặt drawContext/mesh trong nhánh debug rồi nhấn F. Cảnh biến mất là lỗi; chế độ sạch chỉ bỏ phần giải thích, không bỏ sản phẩm chính.
4. Chỉ chạy test trên final nhưng tiếp tục sửa starter. Test xanh không chứng minh mã tự viết đúng; đổi include path như hướng dẫn trên.

## Tự kiểm tra kết quả

- Preset tính tay khớp đủ sáu dòng; agreement dưới 10⁻⁹ ở quy mô scene.
- Sửa FOV/near/far không đổi local/world/view, còn sửa camera không đổi world.
- Native: V/click chọn vertex, mũi tên/PageUp/Down sửa local, A/D/W/S/Q/E/U/O sửa model, J/L/I/K/Z/X sửa camera.
- [/] đổi FOV, −/= đổi near, 9/0 đổi far; F1–F7 có đủ bảy tình huống.
- Space pause, N step khi pause, R reset; F giữ cảnh 3D sạch.
- Alt-Tab, hidden/minimize và resize dừng tự quay; trở lại không tự tiếp tục.
- Canvas có pointer owner, mẫu thả cuối, reset/preset/resize/blur hủy kéo; reduced-motion chặn auto nhưng không chặn step.
- Hai chế độ kéo không lẫn nhau: Xoay mô hình giữ camera và lưới world cố định; Đổi góc nhìn giữ LOCAL/WORLD của vertex không đổi. Chuyển chế độ phải nhả pointer capture và dừng tự quay.
- Thử input và HiDPI trực tiếp trên desktop sau CTest. --smoke chỉ chạy 12 frame ẩn, không chứng minh thao tác chuột thật.
