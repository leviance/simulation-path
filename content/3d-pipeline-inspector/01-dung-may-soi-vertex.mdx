# Dựng cảnh 3D và bảng theo dõi vertex

## Vấn đề cần giải quyết

Ở Project 14, bạn đã biết đưa một điểm world về phía camera rồi chiếu lên màn hình. Nhưng nếu hình đột nhiên lệch sang trái, bạn sẽ tìm lỗi ở phép scale, camera hay projection?

Ta sẽ làm một **máy soi pipeline**: chọn một vertex trên mô hình và đọc tọa độ của chính nó ở từng bước Local → World → View → Clip → NDC → Screen. Bài đầu dựng nơi quan sát trước; chưa viết ma trận mà vẫn có cảnh 3D chạy được để đối chiếu.

Trước khi đọc tiếp, hãy thử đề bài ở trang tổng quan. Đích đến không phải một cửa sổ có mỗi dòng tọa độ trên title bar: bản cuối phải hiện đủ sáu dòng ngay trong cửa sổ, có điều khiển transform, FOV, near/far và chế độ xem sạch.

## Hiểu ý tưởng trước khi viết code

Một vertex không có sáu vị trí độc lập. Đó là **cùng một điểm được mô tả trong sáu hệ tọa độ**. Local còn gọi là model space; nhân model matrix mới cho world, không phải Local và Model là hai phép biến đổi liên tiếp.

Ta dùng lại tám vertex và mười hai cạnh từ Project 13. Điểm đang chọn được tô vàng. Lưới sàn và ba trục là hình học 3D thật, giúp bạn nhận ra độ sâu; chúng không thay thế bảng số.

## Viết code từng bước

### Bước 1 — Chạy Starter trong thư mục học riêng

Tải ZIP ở trang project, giải nén riêng và mở terminal tại CMakeLists.txt:

```bash title="Terminal — chạy bộ khung"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_15_starter --parallel 2
./build/Debug/project_15_starter.exe
```

Starter có SDL window/renderer/texture, framebuffer 1100×800, Bresenham và clip đoạn từ P13/P14. Bạn sẽ thấy lưới sàn, còn mô hình và sáu dòng dữ liệu chưa có.

Trong suốt project, viết vào starter/include và starter/src rồi build target project_15_starter. Các target checkpoint/final chạy **bản tham khảo riêng**, không tự nhận phần bạn vừa sửa. Không viết bài tập trong source-template của repository website: hãy làm trong bản ZIP.

### Bước 2 — Hiểu state trước khi nối renderer

Trong scene.hpp, bộ khung đã có state và vertex/edge list. Không cần tự đoán một biến model hoặc camera ở đâu ra:

```cpp title="include/scene.hpp — state đã có trong Starter"
struct Scene {
    std::array<Vec3, 8> vertices = kVertices;
    std::size_t selectedVertex = 6;
    int selectedStage = 0;
    ModelTransform model{};
    Camera3D camera{};
    PerspectiveLens lens{};
    bool debug = true;
    bool paused = true;
};
```

selectedVertex là index 0–7. selectedStage chỉ chọn dòng cần chú ý, không làm năm dòng khác biến mất. model/camera/lens được chuẩn bị sẵn để mỗi bài thêm phép toán mà không phải đổi interface của cả ứng dụng.

### Bước 3 — Vẽ cạnh và đánh dấu vertex

Thay drawScene trong view.hpp bằng bản sau. drawContext, activeModelPoint, activeViewPoint, drawWorldLine và visibleVertex đã có trong Starter; các bài 3/4/6 sẽ thay từng bộ chuyển tiếp đó bằng Mat4:

```cpp title="include/view.hpp — vẽ mô hình từ vertex list"
inline void drawScene(Framebuffer& image, const Scene& scene) {
    image.clear(kBackground);
    drawContext(image, scene);
    for (const auto& edge : kEdges) {
        const Vec3 a = activeModelPoint(scene.vertices[edge[0]], scene);
        const Vec3 b = activeModelPoint(scene.vertices[edge[1]], scene);
        drawWorldLine(image, a, b, scene, kGhost);
    }
    for (std::size_t index = 0; index < scene.vertices.size(); ++index) {
        const auto point = visibleVertex(scene.vertices[index], scene);
        if (!point) {
            continue;
        }
        std::uint32_t color = kShape;
        int radius = 3;
        if (index == scene.selectedVertex) {
            color = kMarker;
            radius = 7;
        }
        disc(image, static_cast<int>(std::lround(point->x)), static_cast<int>(std::lround(point->y)), radius, color);
    }
    // Cảnh không nằm trong nhánh debug. Chỉ có đường phân cách bảng số là overlay.
    if (scene.debug) {
        drawLine(image, 0, 560, 1099, 560, kGhost);
    }
}
```

Với mỗi cạnh, ta đổi cả hai local endpoint sang world rồi mới gọi drawWorldLine. Hàm này tiếp tục đổi sang view, clip near/far, chiếu, clip screen và gọi Bresenham. Chỉ sửa mô hình trong một nơi; không vẽ thêm một bản 2D khác để đánh dấu vị trí điểm.

Vòng sau vẽ vertex nhỏ màu xanh, riêng điểm được chọn có bán kính 7 và màu vàng. SDL chỉ trình bày framebuffer, không vẽ mesh thay ta.

### Bước 4 — Đưa Local vào bảng số

Thay inspectScene trong scene.hpp. Inspector không tính lại một vị trí “gần giống” để minh họa; nó đọc đúng vertex mà renderer đang dùng:

```cpp title="include/scene.hpp — dòng LOCAL đầu tiên"
inline Inspection inspectScene(const Scene& scene) {
    Inspection result;
    if (scene.selectedVertex >= scene.vertices.size()) {
        result.status = "invalid vertex index";
        return result;
    }
    const Vec3 local = scene.vertices[scene.selectedVertex];
    if (finite(local)) {
        result.rows[0].value = Vec4{local.x, local.y, local.z, 1.0};
    }
    return result;
}
```

Vec4 ở đây mới là kiểu chứa dữ liệu để bảng có đủ chỗ cho w. Chưa có phép nhân Mat4. Bốn thành phần Local là (x,y,z,1); bài sau sẽ giải thích số 1 cuối cùng.

## Ghép các phần lại

Main của Starter đã tạo Scene và Framebuffer trước vòng lặp. Mỗi khi dirty, nó gọi drawScene, inspectScene, SDL_UpdateTexture rồi presentFramebuffer. Bạn chỉ thay hai hàm trên, không thêm một vòng lặp SDL thứ hai.

presentFramebuffer đã dành sáu dòng cho inspector. optional rỗng được in thành —, không phải (0,0,0). V chọn vertex tiếp theo; click gần một điểm cũng chọn được. Mũi tên sửa local X/Y, PageUp/PageDown sửa local Z; R đặt lại.

```bash title="Terminal — đối chiếu checkpoint 1"
cmake --build build --config Debug --target project_15_checkpoint_1
./build/Debug/project_15_checkpoint_1.exe
```

Sau khi đối chiếu, nhớ build Starter của bạn để kiểm phần tự viết. Hai target này không phải hai tên của cùng source.

## Thử làm sai để hiểu đúng

1. Chọn vertex 6 rồi đổi Local X. Nếu cả mô hình cùng dịch, bạn đang sửa model.position thay vì scene.vertices[6]. Khôi phục phép sửa đúng field và quan sát các cạnh nối với vertex đó.
2. Đặt giá trị 0 vào mọi stage chưa viết. Bạn sẽ không phân biệt được một kết quả thật ở origin với bước còn thiếu. Trả các optional về rỗng.
3. Xóa depth clip rồi chọn điểm sát camera. Các cạnh có thể kéo dài bất thường; khôi phục đường clip đoạn đã có trong bộ khung.

## Tự kiểm tra kết quả

- Lưới sàn có chiều sâu, mô hình là tám vertex nối bằng mười hai cạnh.
- Chọn vertex 0–7 làm marker vàng và dòng LOCAL cùng chuyển sang điểm đó.
- Sửa local XYZ không tự sửa model hoặc camera.
- Năm stage chưa xây hiện —. Không quảng cáo ảnh tham chiếu là pipeline mới đã hoàn chỉnh.
- Resize chỉ đổi cách trình bày bảng logic; không tạo framebuffer bằng kích thước màn hình không giới hạn.
