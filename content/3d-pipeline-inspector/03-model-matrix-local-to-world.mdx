# Đưa mô hình từ local ra world

## Vấn đề cần giải quyết

Tám vertex đang nằm quanh local origin. Ta muốn kéo rộng mô hình, xoay nó quanh trục Y rồi đặt vào một vị trí trong cảnh. Thay vì cập nhật dồn từng vertex, ta sẽ giữ local data và tính world mới từ cùng bộ tham số.

Bước này phải đổi cả hình lẫn bảng. Nếu WORLD thay số nhưng hình không đổi, bạn mới nối một nửa pipeline.

## Hiểu ý tưởng trước khi viết code

Với column vector:

$$
p_{world}=T\,R_y\,S\,p_{local}.
$$

Translation × Rotation × Scale được đọc từ phải sang trái: scale trước, xoay sau, cuối cùng mới tịnh tiến. Nếu tịnh tiến trước rồi xoay, độ dời cũng bị xoay; vật có thể chạy vòng quanh world origin thay vì xoay quanh tâm local.

Giữ nguyên một vertex rồi đổi Model X, Model Z, Model yaw và Scale X. LOCAL không được đổi. Thử Scale X=0 và −1: phép biến đổi forward vẫn có nghĩa, dù mô hình có thể bị ép phẳng hoặc lật một trục.

Trong mục **Thao tác kéo**, chọn **Xoay mô hình** rồi kéo ngang để đổi model yaw. Khối phải quay quanh trục Y của nó, còn lưới world và camera giữ nguyên. Kéo dọc không làm đổi góc nhìn; chế độ điều khiển camera sẽ được mở ở bài sau.

## Viết code từng bước

### Bước 1 — Viết scale matrix

Thêm trong lab.hpp, sau các phép toán Mat4:

```cpp title="include/lab.hpp — scale trên đường chéo"
inline Mat4 scaleMatrix(Vec3 scale) {
    Mat4 result = identityMatrix();
    result.at(0, 0) = scale.x;
    result.at(1, 1) = scale.y;
    result.at(2, 2) = scale.z;
    return result;
}
```

Không scale hàng/cột w. Nếu đổi phần tử (3,3), bạn đã đổi tọa độ homogeneous chứ không chỉ kích thước hình.

### Bước 2 — Đưa công thức rotateY vào matrix

```cpp title="include/lab.hpp — giữ dấu như P12"
inline Mat4 rotationYMatrix(double angle) {
    Mat4 result = identityMatrix();
    const double cosine = std::cos(angle);
    const double sine = std::sin(angle);
    result.at(0, 0) = cosine;
    result.at(0, 2) = sine;
    result.at(2, 0) = -sine;
    result.at(2, 2) = cosine;
    return result;
}
```

Hai hàng X/Z phải đúng với x'=cos(a)x+sin(a)z và z'=−sin(a)x+cos(a)z. Ta không đổi convention chỉ vì chuyển từ hàm sin/cos sang Mat4.

### Bước 3 — Ghép M và giữ đường tính tham chiếu

```cpp title="include/lab.hpp — scale rồi xoay rồi tịnh tiến"
inline Mat4 modelMatrix(const ModelTransform& model) {
    const Mat4 scale = scaleMatrix(model.scale);
    const Mat4 rotation = rotationYMatrix(model.yaw);
    const Mat4 translation = translationMatrix(model.position);
    return multiply(translation, multiply(rotation, scale));
}
```

```cpp title="include/lab.hpp — đối chiếu không nhân matrix"
inline Vec3 modelPointDirect(Vec3 localPoint, const ModelTransform& model) {
    const Vec3 scaled{localPoint.x * model.scale.x, localPoint.y * model.scale.y, localPoint.z * model.scale.z};
    return add(rotateY(scaled, model.yaw), model.position);
}
```

modelPointDirect dùng các phép tính thành phần làm đối chứng. Nó không gọi modelMatrix rồi tự so với chính mình. Trong tests, dùng thêm cặp T×S/S×T có đáp án tính tay ở cuối bài trước.

### Bước 4 — Đổi bộ chuyển tiếp của renderer

Thay activeModelPoint trong scene.hpp:

```cpp title="include/scene.hpp — nối model matrix vào hình"
inline Vec3 activeModelPoint(Vec3 local, const Scene& scene) {
    return xyz(transform(modelMatrix(scene.model), toPoint(local)));
}
```

Đây là điểm mọi cạnh và marker đã đi qua ở bài 1. Vì thế không cần tìm rồi sửa từng chỗ vẽ. Kết quả mới là world point; không đem nó ghi ngược vào scene.vertices.

## Ghép các phần lại

Thay inspectScene bằng bản checkpoint 3 dưới đây. Dòng WORLD lấy cùng local point và cùng M như hình:

```cpp title="include/scene.hpp — thêm WORLD vào bảng"
inline Inspection inspectScene(const Scene& scene) {
    Inspection result;
    if (scene.selectedVertex >= scene.vertices.size()) {
        result.status = "invalid vertex index";
        return result;
    }
    const Vec3 local = scene.vertices[scene.selectedVertex];
    if (finite(local)) {
        result.rows[0].value = Vec4{local.x, local.y, local.z, 1.0};
    }
    const Vec4 world = transform(modelMatrix(scene.model), toPoint(local));
    if (finite(world)) {
        result.rows[1].value = world;
    }
    return result;
}
```

Trong handleKey ở main.cpp, nối Q/E để thử yaw. setParameter và enum Parameter đã có trong Starter; hàm này giới hạn giá trị và dừng tự quay khi bạn sửa tay:

## Thử làm sai để hiểu đúng

1. Đổi M thành R×T×S. Cho Model X khác 0 rồi xoay: vật chạy quanh world origin vì translation đã bị quay. Khôi phục T×R×S.
2. Mỗi frame gán world point trở lại local vertex. Để chương trình chạy một lúc rồi reset transform; hình không về nguyên dạng. Giữ local làm nguồn dữ liệu.
3. Chỉ thay inspectScene mà quên activeModelPoint. WORLD trên bảng đổi nhưng ảnh tham chiếu không dùng M mới; nối lại cả hai.

## Tự kiểm tra kết quả

- LOCAL giữ nguyên khi chỉ sửa transform của model.
- Model yaw 90° đưa local +X thành hướng −Z theo convention rotateY đã học.
- M cho cùng world point với scale→sin/cos→cộng position, trong sai số 10⁻⁹.
- Scale X bằng 0 hoặc âm không sinh NaN; ta chưa hề cần inverse M.
- Cạnh và marker đều đi qua activeModelPoint.
