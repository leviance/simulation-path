# Giữ mẫu số trong clip.w

## Vấn đề cần giải quyết

Ở P11, phối cảnh chứa phép chia x/z và y/z. Một phép nhân ma trận là tuyến tính, không thể tự chia cho một tọa độ đang thay đổi. Vậy “projection matrix” làm được phần nào?

Nó tạo **tử số và mẫu số riêng**. Ta lưu z của view point vào clip.w, rồi bài sau mới thực hiện phép chia.

## Hiểu ý tưởng trước khi viết code

Gọi f=1/tan(FOV/2), a=viewportWidth/viewportHeight, n=near, F=far. Ta muốn:

$$
x_{clip}=(f/a)x_{view},\quad y_{clip}=f y_{view},\quad
z_{clip}=A z_{view}+B,\quad w_{clip}=z_{view}.
$$

Sau chia, zNDC=A+B/z. Hai điều kiện z=n→0 và z=F→1 cho:

$$
A=\frac{F}{F-n},\qquad B=-\frac{nF}{F-n}.
$$

Đó là toàn bộ nguồn gốc của hai hệ số depth, không phải một bảng số cần học thuộc. Convention ở đây nhìn **+Z** và depth NDC trong [0,1]; đừng chép nguyên P dùng view nhìn −Z từ một tài liệu OpenGL.

Đổi FOV: VIEW giữ nguyên, clip X/Y đổi. Đổi near/far: clip Z đổi, clip W không đổi. Ở mọi cấu hình hợp lệ, clip.w=camera.z (dòng VIEW chính là camera-space point).

## Viết code từng bước

### Bước 1 — Giữ lens hợp lệ trước khi xây P

validLens đã có trong bộ khung:

```cpp title="include/lab.hpp — tiền điều kiện của projection"
inline bool validLens(const PerspectiveLens& lens) {
    return std::isfinite(lens.verticalFovRadians) && lens.verticalFovRadians > 0.0 && lens.verticalFovRadians < kPi &&
        std::isfinite(lens.nearPlane) && std::isfinite(lens.farPlane) &&
        lens.nearPlane > 0.0 && lens.farPlane > lens.nearPlane;
}
```

Near phải dương, far phải lớn hơn near và FOV phải nằm giữa 0 và π. Tất cả đều phải hữu hạn. Đây là kiểm tra trước phép toán; không chờ đến lúc xuất hiện Infinity trên ảnh mới sửa.

### Bước 2 — Dựng bốn hàng của P

Thêm vào lab.hpp:

```cpp title="include/lab.hpp — tạo clip numerator và denominator"
inline Mat4 projectionMatrix(const PerspectiveLens& lens, double aspectRatio) {
    Mat4 result;
    const double focalScale = 1.0 / std::tan(lens.verticalFovRadians * 0.5);
    const double depthRange = lens.farPlane - lens.nearPlane;
    result.at(0, 0) = focalScale / aspectRatio;
    result.at(1, 1) = focalScale;
    result.at(2, 2) = lens.farPlane / depthRange;
    result.at(2, 3) = -lens.nearPlane * lens.farPlane / depthRange;
    result.at(3, 2) = 1.0;
    return result;
}
```

Hàng 0 chia focalScale cho aspect vì FOV được định nghĩa theo chiều đứng. Hàng 1 giữ focalScale. Hàng 2 chứa A và B vừa suy ra. Hàng 3 có duy nhất phần tử (3,2)=1, tạo w'=z.

P không gọi perspectiveDivide và không đổi trực tiếp sang pixel. Với view=(0,1,4), FOV=90°, n=1, F=9, clip phải là (0,1,27/8,4).

### Bước 3 — Thêm CLIP mà chưa giả có NDC

Thay inspectScene bằng bản checkpoint 5:

```cpp title="include/scene.hpp — bảng có CLIP nhưng chưa chia"
inline Inspection inspectScene(const Scene& scene) {
    Inspection result;
    if (scene.selectedVertex >= scene.vertices.size()) {
        result.status = "invalid vertex index";
        return result;
    }
    const Vec3 local = scene.vertices[scene.selectedVertex];
    if (finite(local)) {
        result.rows[0].value = Vec4{local.x, local.y, local.z, 1.0};
    }
    const Vec4 world = transform(modelMatrix(scene.model), toPoint(local));
    if (finite(world)) {
        result.rows[1].value = world;
    }
    const Vec4 view = transform(viewMatrix(scene.camera), world);
    if (finite(view)) {
        result.rows[2].value = view;
    }
    const Viewport viewport = viewportFor(scene);
    if (validLens(scene.lens) && validViewport(viewport)) {
        const Vec4 clip = transform(projectionMatrix(scene.lens, viewport.width / viewport.height), view);
        if (finite(clip)) {
            result.rows[3].value = clip;
        }
    }
    return result;
}
```

Viewport của bảng debug là 1100×560, không phải toàn bộ window 1100×800. Phần dưới dành cho inspector, nên aspect phải lấy từ viewport vẽ cảnh. Nếu dùng chiều cao cả window, ảnh và bảng có thể dùng hai projection khác nhau.

### Bước 4 — Nối đủ FOV, near và far

Trong handleKey, thêm các nhánh sau. angleStep là nấc 5° đã khai báo ở bài 3:

```cpp title="src/main.cpp — phím điều chỉnh lens"
if (key == SDLK_LEFTBRACKET) {
    lab::setParameter(scene, lab::Parameter::Fov, scene.lens.verticalFovRadians - angleStep);
}
if (key == SDLK_RIGHTBRACKET) {
    lab::setParameter(scene, lab::Parameter::Fov, scene.lens.verticalFovRadians + angleStep);
}
if (key == SDLK_MINUS) {
    lab::setParameter(scene, lab::Parameter::Near, scene.lens.nearPlane - 0.1);
}
if (key == SDLK_EQUALS || key == SDLK_PLUS) {
    lab::setParameter(scene, lab::Parameter::Near, scene.lens.nearPlane + 0.1);
}
if (key == SDLK_9) {
    lab::setParameter(scene, lab::Parameter::Far, scene.lens.farPlane - 1.0);
}
if (key == SDLK_0) {
    lab::setParameter(scene, lab::Parameter::Far, scene.lens.farPlane + 1.0);
}
```

setParameter đã giới hạn FOV 25–110°, near/far cách nhau ít nhất 0.05. Phím [/] đổi FOV, −/= đổi near, 9/0 đổi far. Sau mỗi lần sửa, thông số hiện tại phải được đọc lại từ state, không chỉ ghi một lời nhắc phím cố định.

## Thử làm sai để hiểu đúng

1. Bỏ /aspect ở hàng X rồi resize viewport hoặc thay chiều cao vùng vẽ. Tỉ lệ ngang/dọc sai dù VIEW đúng; sửa lại focalScale/aspect.
2. Đổi phần tử (3,2) từ 1 thành 0. clip.w không còn chứa depth, nên phép chia ở bài sau mất mẫu số.
3. Cho far=near bằng cách bỏ guard. Hệ số depth có phép chia cho 0. Khôi phục quy tắc lens hợp lệ trước khi gọi projectionMatrix.
4. Nhân P với world thay vì view. Đổi camera mà CLIP không phản ánh đúng hướng nhìn; đưa V vào trước P.

## Tự kiểm tra kết quả

- FOV/near/far không thay LOCAL, WORLD hoặc VIEW.
- clip.w luôn khớp view.z trong sai số số thực.
- Ví dụ view=(0,1,4), n=1, F=9, FOV=90° cho clip=(0,1,3.375,4).
- Sau phép chia dự kiến, near phải cho zNDC=0, far cho zNDC=1.
- Native và Canvas đều chỉnh được **cả** near lẫn far.
