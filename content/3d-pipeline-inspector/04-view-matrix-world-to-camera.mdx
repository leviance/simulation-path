# Viết lại camera bằng view matrix

## Vấn đề cần giải quyết

Model matrix đã đặt vật vào world. Tiếp theo, ta cần mô tả world point so với người nhìn. Đây chính là công thức camera của Project 14, không phải một loại camera khác chỉ vì dùng ma trận.

Một dấu hiệu tốt để kiểm tra: sửa camera thì WORLD giữ nguyên, chỉ VIEW và các bước sau được đổi.

## Hiểu ý tưởng trước khi viết code

Camera nhìn theo +Z, yaw dương quay về +X, pitch dương nhìn lên. P14 đã cho:

$$
p_{view}=R_x(pitch)\,R_y(-yaw)\,(p_{world}-camera.position).
$$

Dùng Mat4, phép trừ position trở thành translation matrix:

$$
V=R_x(pitch)\,R_y(-yaw)\,T(-camera.position).
$$

T nằm bên phải nên chạy trước. Hai phép quay cũng đảo **thứ tự** so với camera pose, không chỉ đổi dấu từng góc.

Giữ Model cố định. Đổi Camera Z rồi camera yaw/pitch. Dòng WORLD phải đứng yên.

Canvas có hai chế độ kéo riêng. Chọn **Xoay mô hình**, rồi kéo ngang: khối quay quanh trục Y của nó, còn camera và lưới world đứng yên; kéo dọc không có tác dụng. Chọn **Đổi góc nhìn**, rồi kéo ngang hoặc dọc để đổi camera yaw/pitch: cả khối và lưới sẽ đổi vị trí trên màn hình, nhưng tọa độ WORLD của vertex vẫn giữ nguyên. Ta đang đổi hướng nhìn, không xoay hệ tọa độ world hay sửa Model.

Hãy thử lần lượt hai chế độ và quan sát WORLD, VIEW. Đây là cách phân biệt xoay vật với đổi hướng camera bằng số liệu, thay vì chỉ đoán từ hình ảnh. Mỗi lần đổi chế độ, Canvas kết thúc phiên kéo và tạm dừng tự quay để bạn quan sát riêng phép biến đổi vừa chọn.

## Viết code từng bước

### Bước 1 — Bổ sung rotation X

Trong lab.hpp:

```cpp title="include/lab.hpp — công thức rotateX dưới dạng Mat4"
inline Mat4 rotationXMatrix(double angle) {
    Mat4 result = identityMatrix();
    const double cosine = std::cos(angle);
    const double sine = std::sin(angle);
    result.at(1, 1) = cosine;
    result.at(1, 2) = -sine;
    result.at(2, 1) = sine;
    result.at(2, 2) = cosine;
    return result;
}
```

Hàng Y/Z giữ đúng dấu của rotateX đã có trong bộ khung. Hàng cuối vẫn giữ w=1 với point affine.

### Bước 2 — Ghép inverse camera pose

```cpp title="include/lab.hpp — đổi world sang hệ camera"
inline Mat4 viewMatrix(const Camera3D& camera) {
    const Mat4 inverseTranslation = translationMatrix(scaleVector(camera.position, -1.0));
    const Mat4 inverseYaw = rotationYMatrix(-camera.yaw);
    const Mat4 inversePitch = rotationXMatrix(camera.pitch);
    return multiply(inversePitch, multiply(inverseYaw, inverseTranslation));
}
```

inverseTranslation đổi gốc về mắt; inverseYaw và inversePitch đổi các trục về hướng chuẩn. Camera xoay quanh chính vị trí mắt, không quay quanh world origin.

Thứ tự này đặc biệt quan trọng khi position, yaw và pitch đều khác 0. Các phép thử camera ở origin và chỉ xoay một góc dễ bỏ sót lỗi.

### Bước 3 — Giữ công thức P14 làm đối chứng

```cpp title="include/lab.hpp — đường tham chiếu vô hướng"
inline Vec3 worldToCameraDirect(Vec3 worldPoint, const Camera3D& camera) {
    const Vec3 relative = subtract(worldPoint, camera.position);
    return rotateX(rotateY(relative, -camera.yaw), camera.pitch);
}
```

Với camera=(1,2,3), yaw=90°, pitch=0, world=(4,2,3), đáp án view=(0,0,3). Điểm nằm theo +X world trở thành điểm ngay trước mắt. Đây là một oracle đơn giản, không cần dùng viewMatrix để sinh expected.

### Bước 4 — Đổi bộ chuyển tiếp sang V

Thay activeViewPoint trong scene.hpp:

```cpp title="include/scene.hpp — nối V vào renderer"
inline Vec3 activeViewPoint(Vec3 world, const Scene& scene) {
    return xyz(transform(viewMatrix(scene.camera), toPoint(world)));
}
```

drawWorldLine đã gọi hàm này cho cả lưới sàn, trục và mesh. Không chỉ thay transform của marker rồi để sàn dùng hệ trục cũ.

## Ghép các phần lại

Thêm VIEW sau WORLD trong inspectScene. Dùng bản đầy đủ để kiểm tra thứ tự và không bỏ sót biến world từ bài trước:

```cpp title="include/scene.hpp — Local và World không bị ghi đè"
inline Inspection inspectScene(const Scene& scene) {
    Inspection result;
    if (scene.selectedVertex >= scene.vertices.size()) {
        result.status = "invalid vertex index";
        return result;
    }
    const Vec3 local = scene.vertices[scene.selectedVertex];
    if (finite(local)) {
        result.rows[0].value = Vec4{local.x, local.y, local.z, 1.0};
    }
    const Vec4 world = transform(modelMatrix(scene.model), toPoint(local));
    if (finite(world)) {
        result.rows[1].value = world;
    }
    const Vec4 view = transform(viewMatrix(scene.camera), world);
    if (finite(view)) {
        result.rows[2].value = view;
    }
    return result;
}
```

Nối các nhánh sau trong handleKey của main. Camera trong inspector này được chỉnh theo nấc để dễ đọc số; đây không phải thay thế bộ WASD theo dt của P14:

```cpp title="src/main.cpp — phím thay camera"
if (key == SDLK_J) {

if (key == SDLK_L) {
```

## Thử làm sai để hiểu đúng

1. Đặt T(-position) bên trái hai rotation. Với camera không ở origin, thao tác quay tạo một chuyển động giả quanh gốc. Đưa translation về vị trí tác động đầu tiên.
2. Dùng +yaw trong view. Chọn yaw=90° và đối chiếu oracle +X→+Z; nó phải báo sai.
3. Sửa scene.model.position để giả di chuyển camera. Bảng WORLD sẽ đổi theo, chứng tỏ bạn đang dời vật chứ chưa đổi hệ người nhìn.

## Tự kiểm tra kết quả

- Camera thay đổi không sửa local vertices hoặc WORLD.
- Oracle yaw=90° cho view=(0,0,3).
- viewMatrix khớp worldToCameraDirect ở nhiều pose có cả yaw và pitch.
- Mọi hình học đi qua cùng activeViewPoint; sàn không “trượt riêng” so với mô hình.
- Chưa có CLIP/NDC/SCREEN mới ở bài này; ảnh vẫn dùng projection tham chiếu P11.
