# Đo sai số trạng thái và độ lệch năng lượng

## Vấn đề cần giải quyết

Nhìn ba khối chạy cạnh nhau giúp phát hiện sai lệch lớn, nhưng chưa đủ để kết luận. Một khối có thể ở đúng x mà sai v; một phương pháp có thể giữ năng lượng gần đúng nhưng lệch nhịp dao động.

Ta sẽ ghi state sau từng bước physics, đo bằng cùng một nghiệm chính xác rồi vẽ ba loại đồ thị. Chạy lại một frame đang pause không được tạo thêm mẫu.

## Hiểu ý tưởng trước khi viết code

Sai số vị trí là |x_num−x_exact|. Muốn so cả state, phải xử lý việc x mang mét còn v mang m/s. Với ω>0, chia độ lệch vận tốc cho ω để cùng có đơn vị mét:

$$
e_s=\sqrt{(x_{\rm num}-x_{\rm exact})^2+
\left(\frac{v_{\rm num}-v_{\rm exact}}{\omega}\right)^2}.
$$

Đây là **sai số trạng thái trong phase space**, không phải sai số góc pha. Nó chỉ có nghĩa theo cách chuẩn hóa này khi ω>0. Nếu k=0, hiển thị “không xác định” cho metric đó; vẫn có thể xem sai số x riêng.

Độ lệch năng lượng tương đối là (E−E₀)/E₀. Dương nghĩa là thừa năng lượng; âm nghĩa là thiếu. Khi E₀=0, tỉ số không xác định, không trả 0 để làm đẹp bảng. Đồ thị dùng tỉ số, không dùng phần trăm: 0.1 tương đương 10%.

### Bước 1 — Đo so với đúng thời điểm

Thêm kiểu dữ liệu và hàm dưới vào lab.hpp:

```cpp title="include/lab.hpp — giá trị chưa xác định không mang zero giả"
struct IntegratorMetrics {
    double positionError = std::numeric_limits<double>::quiet_NaN();
    double phaseSpaceError = std::numeric_limits<double>::quiet_NaN();
    double relativeEnergyDrift = std::numeric_limits<double>::quiet_NaN();
};
```


```cpp title="include/lab.hpp — so cả x, v và năng lượng"
inline IntegratorMetrics integratorMetrics(const OscillatorState& numerical, const OscillatorState& initial, const OscillatorParameters& parameters) {
    if (!finiteState(numerical) || !finiteState(initial) || !validParameters(parameters) || numerical.elapsed < initial.elapsed) {
        return {};
    }
    const OscillatorState exact = analyticOscillatorState(initial, parameters, numerical.elapsed - initial.elapsed);
    const double positionDifference = numerical.position - exact.position;
    const double velocityDifference = numerical.velocity - exact.velocity;
    const double omega = angularFrequency(parameters);
    IntegratorMetrics metrics;
    metrics.positionError = std::abs(positionDifference);
    if (omega > 0.0) {
        metrics.phaseSpaceError = std::hypot(positionDifference, velocityDifference / omega);
    }
    const double initialEnergy = oscillatorEnergy(initial, parameters);
    if (initialEnergy > 0.0 && std::isfinite(initialEnergy)) {
        metrics.relativeEnergyDrift = (oscillatorEnergy(numerical, parameters) - initialEnergy) / initialEnergy;
    }
    return metrics;
}
```

Nghiệm chính xác nhận numerical.elapsed trừ mốc initial.elapsed. Không lấy thời gian đồng hồ máy làm t đối chứng.

Thêm recordSample sau Scene và trước resetExperiment:

```cpp title="include/scene.hpp — không lấy mẫu trong renderer"
inline void recordSample(Scene& scene) {
    HistorySample sample;
    sample.time = scene.elapsed;
    sample.exactPosition = analyticOscillatorState(scene.initial, scene.parameters, scene.elapsed).position;
    for (std::size_t index = 0; index < scene.race.lanes.size(); ++index) {
        const auto& state = scene.race.lanes[index].state;
        const auto metrics = integratorMetrics(state, scene.initial, scene.parameters);
        sample.positions[index] = state.position;
        sample.errors[index] = metrics.phaseSpaceError;
        sample.energies[index] = metrics.relativeEnergyDrift;
    }
    scene.history.push_back(sample);
    if (scene.history.size() > kHistoryLimit) {
        scene.history.pop_front();
    }
}
```

Trong resetExperiment, sau khi đã reset race và elapsed, thêm:

```cpp title="include/scene.hpp — giữ cả mẫu ban đầu t=0"
scene.history.clear();
recordSample(scene);
```

Trong stepScene, ghi mẫu ngay sau khi tăng elapsed:

```cpp title="include/scene.hpp — giữ cả từng bước khi chạy nhiều substep"
scene.elapsed += dt;
++scene.substeps;
recordSample(scene);
```

### Bước 3 — Đưa history thành đồ thị có thang đo rõ ràng

Thêm các helper sau vào view.hpp trước renderScene. Cả ba đường dùng **cùng một thang dọc**. Chỗ không có metric hữu hạn thì không được vẽ thành 0:

```cpp title="include/view.hpp — scale và các đường dữ liệu"
struct GraphScale {
    double extent = 1.0;
    double firstTime = 0.0;
    double lastTime = 1.0;
};

inline double graphValue(const HistorySample& sample, Graph graph, std::size_t lane) {
    if (graph == Graph::error) {
        return sample.errors[lane];
    }
    if (graph == Graph::energy) {
        return sample.energies[lane];
    }
    return sample.positions[lane];
}

inline GraphScale graphScale(const Scene& scene) {
    GraphScale scale;
    double largest = 1e-6;
    for (const auto& sample : scene.history) {
        if (scene.graph == Graph::position) {
            largest = std::max(largest, std::abs(sample.exactPosition));
        }
        for (std::size_t index = 0; index < 3; ++index) {
            const double value = graphValue(sample, scene.graph, index);
            if (std::isfinite(value)) {
                largest = std::max(largest, std::abs(value));
            }
        }
    }
    scale.extent = largest * 1.1;
    if (!scene.history.empty()) {
        scale.firstTime = scene.history.front().time;
        scale.lastTime = std::max(scale.firstTime + fixedDelta(scene), scene.history.back().time);
    }
    return scale;
}

inline double graphY(double value, const Scene& scene, const GraphScale& scale) {
    if (scene.graph == Graph::error) {
        return 650.0 - value / scale.extent * 210.0;
    }
    return 545.0 - value / scale.extent * 105.0;
}

inline void drawGraph(Framebuffer& image, const Scene& scene) {
    const auto scale = graphScale(scene);
    if (scene.debug) {
        for (int y = 440; y <= 650; y += 35) {
            drawLine(image, 40, y, 1060, y, kGrid);
        }
    }
    for (std::size_t index = 1; index < scene.history.size(); ++index) {
        const auto& a = scene.history[index - 1];
        const auto& b = scene.history[index];
        const double x0 = 40.0 + 1020.0 * (a.time - scale.firstTime) / (scale.lastTime - scale.firstTime);
        const double x1 = 40.0 + 1020.0 * (b.time - scale.firstTime) / (scale.lastTime - scale.firstTime);
        if (scene.graph == Graph::position) {
            drawLine(image, x0, graphY(a.exactPosition, scene, scale), x1, graphY(b.exactPosition, scene, scale), kExact);
        }
        for (std::size_t lane = 0; lane < 3; ++lane) {
            drawLine(image, x0, graphY(graphValue(a, scene.graph, lane), scene, scale), x1, graphY(graphValue(b, scene.graph, lane), scene, scale), kColors[lane]);
        }
    }
}
```

Cuối renderScene, sau khi vẽ các làn, gọi:

```cpp title="include/view.hpp — vẽ history đã được physics ghi trước đó"
drawGraph(image, scene);
```

Đường Euler có thể làm thang dọc rộng ra và các đường kia nằm sát 0. Đó không phải bằng chứng chúng chính xác tuyệt đối; đọc số đo scientific notation và ghi lại thang dọc trước khi so hai ảnh.

## Thử làm sai để hiểu đúng

1. Chuyển recordSample sang renderScene rồi pause. Resize hoặc vẽ lại sẽ thêm các mẫu trùng dù physics không tiến. Khôi phục vị trí ghi trong stepScene.

2. Dùng frame time làm thời gian đối chứng. Chạy nhanh 20 giây simulation gần như ngay lập tức, bạn sẽ so t mô phỏng với một wall-clock rất ngắn.

3. Đặt x₀=v₀=0. Năng lượng tuyệt đối bằng 0, nhưng relative drift phải ghi không xác định. Đừng gán 0 cho một tỉ số 0/0.

## Tự kiểm tra kết quả

- History có mẫu t=0, mỗi bước physics và state cuối của job tua nhanh.
- Render/pause không thêm mẫu; đồ thị không chứa hai cấu hình khác nhau.
- Sai số state đã đưa dv/ω về cùng đơn vị mét với dx.
- Khi ω=0 hoặc E₀=0, metric tương ứng không giả thành zero.
- Ba đường dùng cùng scale, có đơn vị và khoảng thời gian hiện trên đồ thị.

## Bài tập mở rộng

Tạo hai state có cùng x nhưng khác v. Sai số vị trí có thể bằng 0 trong khi sai số trạng thái vẫn dương. Giải thích vì sao chỉ quan sát vị trí dễ bỏ sót lỗi.
