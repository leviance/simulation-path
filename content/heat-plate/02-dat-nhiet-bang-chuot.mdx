# Dùng chuột đặt vùng nóng và lạnh

## Vấn đề cần giải quyết

Tấm đã hiện đúng nhưng vùng nóng còn cố định trong source. Ta muốn chạm vào đâu thì làm nóng ở đó, kéo nhanh vẫn có nét liền, và thu nhỏ cửa sổ không khiến bút lệch khỏi con trỏ. Bài này chỉ sửa dữ liệu bằng input; **chưa cho nhiệt tự lan**.

Bắt đầu từ checkpoint 1. Dự kiến đọc 20 phút, viết 40 phút, thử 25 phút; setup không tính vào thời lượng. Sau bài, chuột trái đặt mức đang chọn, chuột phải đặt lạnh; mũi tên/Enter làm được thao tác tương đương.

## Hiểu ý tưởng trước khi viết code

Chuột trả tọa độ cửa sổ, nhưng tấm chỉ chiếm một vùng trong hệ logical. Cần đi qua hai lần đổi tọa độ: window → logical bằng SDL, rồi logical → cell bằng hình chữ nhật của tấm.

Sau khi có ô `(x,y)`, brush tròn giữ các điểm thỏa `offsetX² + offsetY² ≤ radius²`. Bán kính tính bằng **ô**, không bằng pixel màn hình, nên cùng radius cho cùng dấu bút sau resize.

Đây là bút đặt nhiệt độ: ghi theta bằng 0 hoặc 1 tại những mẫu input. Giữ chuột đứng yên không liên tục cấp năng lượng. Một nguồn giữ nóng sẽ được xây riêng ở bài 5.

Trước khi kéo, đoán xem radius 0 tô mấy ô. Sau đó thử kéo thật nhanh và đi ra ngoài rồi quay lại: đoạn nằm ngoài tấm không được biến thành một đường nối xuyên qua dữ liệu.

## Viết code từng bước

### 1. Chỉ nhận tọa độ thật sự nằm trong tấm

`input.hpp` gọi `SDL_RenderCoordinatesFromWindow` một lần cho mỗi mouse event, lấy `x,y` logical. Sau đó dùng hàm thuần trong `layout.hpp`:

{/* snippet include/layout.hpp#logical-cell */}
```cpp title="include/layout.hpp — đổi logical coordinates thành ô"
inline bool logicalCell(const Field& field, float logicalX, float logicalY, int& x, int& y, bool showcase = false) {
    if (!std::isfinite(logicalX) || !std::isfinite(logicalY)) {
        return false;
    }
    const Rect rectangle = sceneRect(field, showcase);
    if (!inside(rectangle, logicalX, logicalY)) {
        return false;
    }
    x = static_cast<int>(std::floor((logicalX - rectangle.x) * field.width / rectangle.width));
    y = static_cast<int>(std::floor((logicalY - rectangle.y) * field.height / rectangle.height));
    return field.contains(x, y);
}
```

Mép phải/dưới bị loại bằng khoảng nửa mở. Nếu nhận luôn điểm đúng `view.x + view.width`, phép chia có thể cho `x == field.width`, vượt mảng. Kiểm finite cũng phải trước khi đổi float sang int.

### 2. Đóng một dấu bút lên dữ liệu

Thêm `include/brush.hpp`; hàm dưới chỉ đi qua một hình vuông nhỏ quanh tâm, rồi bỏ các điểm ngoài đĩa hoặc ngoài field:

{/* snippet include/brush.hpp#paint-disk */}
```cpp title="include/brush.hpp — đặt nhiệt độ trong một đĩa"
inline void paintDisk(Field& field, const Settings& settings, int centerX, int centerY, int radius, double value, BrushMode mode = BrushMode::Temperature) {
    if (!field.contains(centerX, centerY) || !std::isfinite(value)) {
        return;
    }
    radius = std::clamp(radius, 0, 24);
    value = std::clamp(value, 0.0, 1.0);
    for (int offsetY = -radius; offsetY <= radius; ++offsetY) {
        for (int offsetX = -radius; offsetX <= radius; ++offsetX) {
            if (offsetX * offsetX + offsetY * offsetY > radius * radius) {
                continue;
            }
            const int x = centerX + offsetX;
            const int y = centerY + offsetY;
            if (!field.contains(x, y)) {
                continue;
            }
            const std::size_t index = field.index(x, y);
            field.current[index] = value;
        }
    }
    static_cast<void>(settings);
    static_cast<void>(mode);
}
```

Clamp `value` ở đây giới hạn **đầu vào của bút**, không sửa kết quả solver. Ta sẽ không dùng cách này để che một nghiệm nhiệt bị âm ở bài 6. Radius 0 vẫn tô đúng tâm vì `0 ≤ 0`.

### 3. Nối các mẫu chuột bằng nhiều dấu bút

Event không xuất hiện ở mọi pixel bạn đi qua. Lấy `steps=max(|dx|,|dy|)`, nội suy tâm brush từ mẫu trước đến mẫu hiện tại, rồi gọi cùng `paintDisk`:

{/* snippet include/brush.hpp#paint-stroke */}
```cpp title="include/brush.hpp — nối hai mẫu input"
inline void paintStroke(Field& field, const Settings& settings, int x0, int y0, int x1, int y1, int radius, double value, BrushMode mode = BrushMode::Temperature) {
    if (!field.contains(x0, y0) || !field.contains(x1, y1)) {
        return;
    }
    const int dx = x1 - x0;
    const int dy = y1 - y0;
    const int steps = std::max(std::abs(dx), std::abs(dy));
    if (steps == 0) {
        paintDisk(field, settings, x0, y0, radius, value, mode);
        return;
    }
    for (int step = 0; step <= steps; ++step) {
        const double fraction = static_cast<double>(step) / steps;
        const int x = static_cast<int>(std::lround(x0 + fraction * dx));
        const int y = static_cast<int>(std::lround(y0 + fraction * dy));
        paintDisk(field, settings, x, y, radius, value, mode);
    }
}
```

Không chia cho 0 khi hai điểm trùng nhau. Cả hai đầu phải nằm trong field; khi ra ngoài, input đặt `previousValid=false`. Lần trở lại bắt đầu một đoạn mới thay vì nối qua vùng ngoài.

### 4. Dùng chung thao tác cho chuột và phím

`Workshop` giữ cursor, brush, điểm trước và cờ `dirty`; nó không chứa một solver bí mật. `stamp` là chỗ gọi brush và báo ảnh cần vẽ lại:

{/* snippet include/workshop.hpp#stamp */}
```cpp title="include/workshop.hpp — một thao tác tô dùng chung"
inline void stamp(Field& field, Workshop& state, int x, int y, bool join) {
    double value = state.brushValue;
    if (state.erasing) {
        value = 0;
    }
    if (join && state.previousValid) {
        paintStroke(field, state.settings, state.previousX, state.previousY, x, y, state.radius, value, state.brushMode);
    } else {
        paintDisk(field, state.settings, x, y, state.radius, value, state.brushMode);
    }
    state.cursorX = x;
    state.cursorY = y;
    state.previousX = x;
    state.previousY = y;
    state.previousValid = true;
    state.dirty = true;
}
```

`erasing` ở đây nghĩa là chuột phải đặt theta=0, không xóa ô khỏi lưới. Bút nóng/lạnh đều giữ nguyên số ô.

## Ghép các phần lại

`pollInput(renderer,field,state,running)` đã nằm trong vòng `while` của `main`. Nối các nhánh mouse button down/motion/up tới `stamp`: down bắt đầu nét và tô ngay, motion nối khi `drawing`, up kết thúc nét. Source checkpoint có đầy đủ hàm này để bạn theo từ event tới dữ liệu và vòng vẽ.

Native dùng `SDL_CaptureMouse` khi kéo; mất focus, resize hoặc kết thúc input hủy nét. Canvas dùng pointer capture; nếu pointer ra ngoài hình tấm, chỉ xóa điểm nối chứ không ép nó vào mép.

Phím 1/2 chọn nóng/lạnh, `[`/`]` đổi radius; mũi tên chọn ô và Enter đóng dấu. `C` xóa nhiệt, `R` tạo lại Gaussian. `Field` được giữ qua các frame như bài trước; chỉ reset mới thay nó.

Build/run `project_47_checkpoint_2`. Đóng cửa sổ trước khi build lại trên Windows để tránh executable đang bị khóa.

## Thử làm sai để hiểu đúng

Tạm bỏ `paintStroke`, chỉ gọi `paintDisk` ở mỗi motion. Giảm radius về 0 rồi kéo nhanh: dấu bút có thể đứt vì thiếu mẫu. Khôi phục nội suy, không chữa bằng cách phóng brush thật to.

Tiếp theo, bỏ kiểm ngoài viewport trong một bản thử riêng. Tô lên panel hoặc letterbox có thể chạm vào mép tấm nếu bạn clamp tọa độ. Đây là lỗi input, không phải lỗi hiển thị. Khôi phục kiểm bounds trước khi sang bài sau.

## Tự kiểm tra kết quả

- Radius 0 tô một ô; radius 1 ở góc chỉ tô ba ô hợp lệ.
- Chuột phải làm lạnh đúng chỗ; 1/2 và Enter cho cùng kết quả như chuột.
- Kéo nhanh không để khoảng hở lớn; ra ngoài và quay lại không tạo đường nối lạ.
- `C` xóa, `R` khôi phục Gaussian; resize không đổi mảng và không làm lệch dấu bút.
- Để yên vẫn không có nhiệt lan. Không thêm một phép blur trong vòng vẽ để tạo chuyển động sớm.
