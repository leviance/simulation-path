# Chọn cách nhiệt, vành lạnh và heater

## Vấn đề cần giải quyết

Một chấm nóng giữa tấm chưa nói hết mô hình. Khi nhiệt tới mép, nó bị giữ lại hay truyền ra môi trường? Nếu muốn giữ một vùng luôn nóng, bút đặt nhiệt một lần có đủ không?

Từ checkpoint 4, bài này thêm hai điều khiển nhìn thấy được: B đổi biên, H/E tạo hoặc bỏ vùng giữ nhiệt. Dự kiến đọc 25 phút, viết 45 phút, thử 35 phút. Ta cũng bắt đầu ghi rõ **khi nào được đòi hỏi bảo toàn**, thay vì dùng “tổng phải không đổi” cho mọi cảnh.

## Hiểu ý tưởng trước khi viết code

Biên cách nhiệt đóng các mặt ngoài của miền. Ghost cell bằng chính ô sát mặt khiến thông lượng qua mặt ấy bằng 0. Nhiệt vẫn truyền giữa những ô bên trong; tấm không vì “cách nhiệt” mà đứng yên.

Chế độ vành lạnh khác hẳn: giữ **tâm các ô ngoài** ở theta=0. Nó có thể lấy nhiệt khỏi tấm. Việc chuyển sang vành lạnh còn xóa tức thì nhiệt đã nằm trên vành. Hai cách đặt biên không cùng hình học: miền cách nhiệt có mặt ngoài cách tâm ô nửa bước, còn vành lạnh giữ nhiệt độ ngay ở tâm ô ngoài. Không dùng chúng như hai lời giải trên cùng miền để so convergence.

Heater trong bài là một thermostat: sau bước khuếch tán, ép các ô được chọn về theta=0 hoặc 1. Nó tự thêm/lấy lượng cần thiết để giữ nhiệt độ, không cấp một công suất cố định.

Đoán trước: tô một chấm 1 bằng bút thường rồi tiến bước; sau đó thử cùng chấm bằng bút heater. Lần nào tâm phải giữ đúng 1? Nếu bút đứng yên mà nguồn vẫn hoạt động, hoạt động đó phải đến từ mask heater chứ không từ số event chuột.

## Viết code từng bước

### 1. Áp vành lạnh khi người dùng đổi biên

`Boundary::ColdRim` được bật bằng B. `applyBoundary` đặt các ô mép về 0 và bỏ pin trên chúng:

{/* snippet include/field.hpp#boundary */}
```cpp title="include/field.hpp — giữ vành ngoài ở 0"
inline void applyBoundary(Field& field, const Settings& settings) {
    if (settings.boundary != Boundary::ColdRim) {
        return;
    }
    for (int y = 0; y < field.height; ++y) {
        for (int x = 0; x < field.width; ++x) {
            if (field.edge(x, y)) {
                field.current[field.index(x, y)] = 0;
                field.pins[field.index(x, y)] = Pin::None;
            }
        }
    }
}
```

Hàm được gọi lúc tạo/reset scene và khi đổi biên. Trong solver, `fixedRim` cho ứng viên tại vành bằng 0. Brush cũng kiểm vành trước khi ghi: không chờ tới bước N mới sửa lại nét vẽ làm nóng sai trên mép.

### 2. Lưu vị trí nguồn bằng mask riêng

`Field` thêm `pins`, một phần tử `Pin` cho mỗi ô, khởi tạo `None=-1`. Hot=1, Cold=0; không dùng theta hiện tại để suy ra ô có phải heater hay không. Một ô thường có theta=1 vẫn không phải nguồn giữ nhiệt.

Brush giờ có ba chế độ. Đây là phiên bản đầy đủ sau bài:

{/* snippet include/brush.hpp#paint-disk */}
```cpp title="include/brush.hpp — tô nhiệt, ghim nhiệt và bỏ ghim"
inline void paintDisk(Field& field, const Settings& settings, int centerX, int centerY, int radius, double value, BrushMode mode = BrushMode::Temperature) {
    if (!field.contains(centerX, centerY) || !std::isfinite(value)) {
        return;
    }
    radius = std::clamp(radius, 0, 24);
    value = std::clamp(value, 0.0, 1.0);
    for (int offsetY = -radius; offsetY <= radius; ++offsetY) {
        for (int offsetX = -radius; offsetX <= radius; ++offsetX) {
            if (offsetX * offsetX + offsetY * offsetY > radius * radius) {
                continue;
            }
            const int x = centerX + offsetX;
            const int y = centerY + offsetY;
            if (!field.contains(x, y)) {
                continue;
            }
            const std::size_t index = field.index(x, y);
            if (settings.boundary == Boundary::ColdRim && field.edge(x, y)) {
                field.current[index] = 0;
                field.pins[index] = Pin::None;
                continue;
            }
            if (mode == BrushMode::EraseHeater) {
                field.pins[index] = Pin::None;
                continue;
            }
            field.pins[index] = Pin::None;
            if (mode == BrushMode::Heater) {
                field.pins[index] = Pin::Cold;
                if (value >= 0.5) {
                    field.pins[index] = Pin::Hot;
                }
            }
            field.current[index] = value;
        }
    }
    static_cast<void>(settings);
    static_cast<void>(mode);
}
```

`EraseHeater` chỉ bỏ mask và `continue`, nên nhiệt đã có không bị xóa. Bút thường bỏ pin ở ô nó đi qua rồi đặt theta, cho phép sửa một nguồn thành vùng nhiệt tự do. Trong mode heater, chọn 1/2 để tạo nguồn nóng/lạnh. Chuột phải đặt mức 0 của mode đang dùng.

### 3. Ghi nguồn sau phần trao đổi, trước khi publish

Sau khi đã tính `value` không nguồn, solver áp pin rồi cộng phần thay đổi vào ledger:

{/* snippet include/diffusion.hpp#source-ledger */}
```cpp title="include/diffusion.hpp — nguồn thay đổi tích phân bao nhiêu"
if (!fixedRim && field.pins[index] != Pin::None) {
    const double target = static_cast<double>(field.pins[index]);
    result.sourceChange += (target - value) * settings.dx * settings.dy;
    value = target;
}
```

`sourceChange` có đơn vị theta×diện tích. Nó cộng `(target - value)*dx*dy`, không chỉ đếm số heater. Hai nguồn giữ cùng nhiệt độ có thể thêm lượng khác nhau khi vùng xung quanh khác nhau.

Ở biên cách nhiệt và không có input/nguồn, đại lượng rời rạc cần kiểm là:

$$
I^*=dx\,dy\sum_{x,y}\theta_{x,y}.
$$

Chưa biết bề dày, mật độ hay nhiệt dung nên không gọi nó là Joule. Khi có heater, so chênh lệch I* với ledger ở fixture thích hợp; khi có vành lạnh, còn có lượng nhiệt bị lấy ra ở biên.

## Ghép các phần lại

Action B dừng đồng hồ, đổi `settings.boundary`, áp vành nếu cần và đánh dấu ảnh cần cập nhật. Action H đổi bút thường/heater; E chọn bỏ pin. Mọi thao tác đi qua cùng `applyAction`/`stamp`, dù đến từ nút hay phím.

Build/run `project_47_checkpoint_5`. Trong native, bạn tự tô heater bằng H, 1/2 và chuột/Enter; `--preset 4` cũng tạo fixture hai thermostat. Gallery P đầy đủ sẽ thêm ở bài 8. Canvas cung cấp sẵn fixture này để tiện đối chiếu, không có nghĩa bạn phải giấu thuật toán tương lai trong checkpoint.

## Thử làm sai để hiểu đúng

Bỏ nhánh giữ lạnh trong brush rồi tô lên vành lúc pause. Nếu mép nóng lên và chỉ lạnh lại sau N, input đang phá điều kiện biên. Sửa ngay ở nơi đặt dữ liệu.

Thử “xóa heater” bằng cách đặt cả pin lẫn theta về 0. Bạn sẽ thấy một vùng lạnh mới xuất hiện dù chỉ định bỏ nguồn. Khôi phục hành vi unpin: bỏ ràng buộc nhưng giữ nhiệt đã có.

## Tự kiểm tra kết quả

- Trường hằng 0,4 đứng yên ở biên cách nhiệt; trường ấy không đứng yên khi có vành lạnh.
- Vành luôn bằng 0 kể cả sau input; đổi về cách nhiệt không tự trả lại nhiệt đã xóa.
- Heater nóng/lạnh giữ đúng 1/0 sau mỗi bước, mask đếm đúng số ô; unpin không lập tức xóa theta.
- Chỉ kiểm bảo toàn I* khi không input, không reset, không heater và biên cách nhiệt.
- Fixture một ô heater ở lưới 5×5, D=1, dt=0,2, dx=dy=1 cho `sourceChange=0,8` ở bước đầu. Đây là thay đổi do nguồn, không phải lỗi bảo toàn.
