# Vẽ tấm kim loại trước khi cho nhiệt lan

## Vấn đề cần giải quyết

Chấm một điểm nóng lên tấm kim loại lạnh: vùng nào sẽ nóng trước, vùng nào nóng sau? Ta chưa cần giải ngay câu hỏi đó. Trước hết, chương trình phải lưu được nhiệt độ và cho ta nhìn thấy nó. Nếu ngay cả bước vẽ còn sai, một solver đúng cũng sẽ tạo ra bức hình khó hiểu.

Bài này bắt đầu từ một cửa sổ SDL đang chạy. Kết thúc bài, bạn có một tấm **32×32 ô đứng yên**, nóng ở giữa và nhiệt độ giảm dần ra ngoài. Chưa có bước lan nhiệt nào; nhấn chạy không được âm thầm kích hoạt thuật toán của bài sau. Bản cuối sẽ nâng lên 192×192, không dừng ở lưới học thử này.

Dự kiến: đọc 20 phút, tự viết 40 phút, thử và kiểm 25 phút. Không tính thời gian cài compiler/SDL; nếu môi trường chưa chạy, xem [Getting Started](/getting-started).

## Hiểu ý tưởng trước khi viết code

Trong hộp cát, mỗi ô là nhãn vật liệu. Ở đây mỗi ô là một số thực `theta`. Ta chọn một nhiệt độ nền và một mức nóng tham chiếu:

$$
\theta=\frac{T-T_{\mathrm{nen}}}{T_{\mathrm{nong}}-T_{\mathrm{nen}}}.
$$

Vì thế 0 là nền, 1 là mốc nóng, 0,5 nằm giữa hai mốc. Đây không phải “0,5 độ C” và cũng không phải nhiệt lượng. Renderer biến con số ấy thành màu; nó không quyết định mô hình nóng hay nguội.

Lưới vẫn lưu theo row-major: `index = y * width + x`. Chỉ dữ liệu đầu vào thay đổi: thay một mảng màu bằng mảng `double`. Mỗi ô đại diện cho một vùng nhỏ của tấm, không nhất thiết là một pixel màn hình.

Thử đổi cảnh sang tấm trống và đặt lại. Quan sát rằng hình chỉ đổi khi ta đổi dữ liệu, không tự chuyển động. Thang màu không tự đổi theo min/max của ảnh: cùng một theta luôn cho cùng một màu. Muốn so chính xác nhiệt độ, đọc theta và chú giải thay vì chỉ so độ sáng bằng mắt.

## Viết code từng bước

### 1. Chạy khung SDL trước khi thêm dữ liệu

[Tải source Project 47](/downloads/project-47-heat-plate.zip), giải nén và mở terminal tại thư mục có `CMakeLists.txt`:

```powershell title="Terminal — chạy starter"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON -DBUILD_TESTING=ON
cmake --build build --config Debug --target project_47_starter --parallel 1
.\build\Debug\project_47_starter.exe
```

Starter cung cấp `SdlResources`, window/renderer, logical presentation 1200×860, event loop, panel chữ, kiểu `Field` chứa các ô ban đầu bằng 0 và kiểm lỗi SDL. Nó chưa tạo vùng nóng hoặc vẽ ô nhiệt. Ta sẽ đọc cách lưu dữ liệu ấy, tự viết phần khởi tạo vùng nóng và vòng vẽ; không cần xóa bộ khung rồi viết lại chỉ để giống đoạn trích.

`SdlResources` chỉ quản lý tài nguyên: hủy texture trước renderer, renderer trước window và cuối cùng `SDL_Quit`, cả khi có exception. Ta không học lại cách tạo window, nhưng sẽ chỉ rõ chỗ nối dữ liệu và lời gọi vẽ.

Trong ZIP, sửa `starter/` nếu muốn tự xây từ đầu. Dùng `project_47_checkpoint_1` khi cần đối chiếu đáp án sau bài; đừng sửa `final/` rồi vô tình build target starter.

### 2. Cho mỗi ô một con số

Trong `include/field.hpp`, phần đầu của `Field` là:

{/* snippet include/field.hpp#field-storage */}
```cpp title="include/field.hpp — dữ liệu của một tấm"
struct Field {
    int width;
    int height;
    std::vector<double> current;
```

Constructor kiểm mỗi chiều trong 1–512 trước khi nhân và cấp phát. Bài này dùng 32×32, tức 1.024 số `double` khởi tạo bằng 0. Phần còn lại của struct có trong source đầy đủ cuối bài, không cần tự đoán các include hoặc dấu đóng ngoặc.

{/* snippet include/field.hpp#field-index */}
```cpp title="include/field.hpp — kiểm tọa độ trước khi lấy index"
bool contains(int x, int y) const {
    return x >= 0 && y >= 0 && x < width && y < height;
}

// Kiểm contains trước khi dùng index với dữ liệu từ input.
std::size_t index(int x, int y) const {
    return static_cast<std::size_t>(y) * static_cast<std::size_t>(width) + static_cast<std::size_t>(x);
}
```

`index` không tự sửa tọa độ. Sau này, input phải gọi `contains` trước; kéo một điểm ngoài tấm vào mép sẽ khiến bút tô nhầm lên vành.

### 3. Tạo một vùng nóng có mép chuyển dần

`include/presets.hpp` tạo dữ liệu một lần. Với cảnh Gaussian, các ô xa tâm có theta nhỏ hơn. Công thức này chỉ tạo **ảnh ban đầu**, không sinh chuyển động:

{/* snippet include/presets.hpp#make-field */}
```cpp title="include/presets.hpp — tạo trường nhiệt ban đầu"
inline Field makeField(Preset preset = Preset::Hotspot, int size = 32) {
    Field field(size, size);
    for (int y = 0; y < field.height; ++y) {
        for (int x = 0; x < field.width; ++x) {
            double value = 0;
            const double normalizedX = (static_cast<double>(x) + 0.5) / field.width;
            const double normalizedY = (static_cast<double>(y) + 0.5) / field.height;
            if (preset == Preset::Hotspot) {
                const double offsetX = normalizedX - 0.5;
                const double offsetY = normalizedY - 0.5;
                value = std::exp(-72 * (offsetX * offsetX + offsetY * offsetY));
            }
            field.current[field.index(x, y)] = value;
        }
    }
    static_cast<void>(preset);
    return field;
}
```

`normalizedX`/`normalizedY` lấy ở tâm ô, từ gần 0 đến gần 1. Hệ số 72 chọn độ rộng vùng nóng; chưa phải hệ số dẫn nhiệt D. Lưới chẵn không có tâm ô nằm đúng giữa tấm, nên max ở 32×32 xấp xỉ 0,965 chứ không đúng 1.

### 4. Vẽ số thực bằng hình chữ nhật SDL

`sceneRect` dành hình vuông 720×720 logical units cho tấm. Mỗi ô rộng `view.width / field.width`; resize window chỉ đổi cách logical coordinates xuất hiện trên màn hình.

{/* snippet include/view.hpp#draw-grid */}
```cpp title="include/view.hpp — vẽ toàn bộ các ô"
inline void drawGrid(SDL_Renderer* renderer, const Field& field) {
    const Rect view = sceneRect(field, false);
    const float cellWidth = view.width / field.width;
    const float cellHeight = view.height / field.height;
    for (int y = 0; y < field.height; ++y) {
        for (int x = 0; x < field.width; ++x) {
            setColor(renderer, heatColor(field.current[field.index(x, y)]));
            const SDL_FRect rectangle{view.x + x * cellWidth, view.y + y * cellHeight, cellWidth, cellHeight};
            requireSdl(SDL_RenderFillRect(renderer, &rectangle), "draw temperature cell");
        }
    }
}
```

`heatColor` giữ palette cố định: xanh đậm → cyan → vàng → cam → kem sáng. `setColor` gọi `SDL_SetRenderDrawColor`; `requireSdl` báo lỗi nếu lời gọi vẽ thất bại. Không ghi màu trở lại `current`.

## Ghép các phần lại

Trước vòng `while`, `main` tạo `Workshop` chứa trạng thái giao diện và **một** `Field`. `Options` chỉ đọc các tham số dòng lệnh; các cờ chưa học bị từ chối, không âm thầm bật tính năng tương lai.

{/* snippet src/main.cpp#create-scene */}
```cpp title="src/main.cpp — tạo tấm trước vòng lặp"
heat::Workshop state;
state.settings = options.settings;
state.size = options.size;
state.preset = options.preset;
state.showcase = options.clean;
state.paused = !options.run;
if (options.run) {
    state.message = "RUNNING: bounded work per frame";
}
heat::Field field = heat::makeField(options.preset, options.size);
state.cursorX = field.width / 2;
state.cursorY = field.height / 2;
heat::selectProbe(field, state, state.cursorX, state.cursorY);
heat::recordProbe(field, state);
heat::setPresentation(sdl.renderer, field, state.showcase);
```

Trong vòng lặp, sau khi đọc event, thứ tự vẽ là:

{/* snippet src/main.cpp#render-frame */}
```cpp title="src/main.cpp — clear rồi vẽ cảnh và panel"
heat::setColor(sdl.renderer, {9, 16, 29, 255});
heat::requireSdl(SDL_RenderClear(sdl.renderer), "clear renderer");
const auto drawStart = Clock::now();
heat::drawGrid(sdl.renderer, field);
state.submitMs = millisecondsSince(drawStart);
if (!state.showcase) {
    heat::drawPanel(sdl.renderer, field, state);
}
```

Ngay sau phần này, `SDL_RenderPresent` đưa frame ra cửa sổ. `submitMs` chỉ đo thời gian CPU gửi lệnh vẽ tấm; nó không phải GPU time hay thời gian toàn frame. Chưa có `diffuse` ở checkpoint 1.

Build `project_47_checkpoint_1` bằng cùng lệnh trên, đổi tên target và executable. Mở từng file trong mục **Mã chạy được sau bài** để đối chiếu toàn chương trình, không chỉ các đoạn trích.

## Thử làm sai để hiểu đúng

Đoán trước rồi mới thử: nếu tạo lại `field` bên trong `while`, điều gì sẽ xảy ra với một nét vẽ ở bài sau? Mọi thay đổi sẽ bị xóa sau mỗi frame. Đưa nó lại trước vòng lặp.

Tiếp theo, nhân giá trị Gaussian với 0,5. Vùng nóng phải tối đi. Nếu tự co palette theo min/max của ảnh, đỉnh 0,5 có thể vẫn sáng như 1; đó là cách hiển thị che mất ý nghĩa dữ liệu.

## Tự kiểm tra kết quả

- Có 1.024 ô; `(3,2)` có index 67, `(32,0)` nằm ngoài.
- Max ban đầu gần 0,965; đợi vài giây vẫn không đổi.
- Resize không đổi `current`; hình không bị kéo méo vì logical presentation có letterbox.
- Đóng bằng Esc hoặc nút X được; không còn cửa sổ/tiến trình sau khi thoát.

## Bài tập mở rộng

Thay Gaussian bằng dải tăng tuyến tính từ trái sang phải mà không sửa `drawGrid`. Nếu bạn làm được, dữ liệu và cách vẽ đã tách đúng. Bài sau sẽ [dùng chuột đặt vùng nóng/lạnh](/projects/heat-plate/02-dat-nhiet-bang-chuot), để không phải biên dịch lại mỗi lần muốn đổi hình.
