# Một hạt có sống như nhau trong hai cách lưu?

## Vấn đề cần giải quyết

Hai cách lưu đã cho cùng một hình lúc dừng. Nhưng nhấn `N` sau khi chuyển sang SoA thì làm sao biết một giọt vừa lên tới đỉnh sẽ rơi về đúng vị trí như khi dùng AoS? Và quan trọng hơn: khi giọt đó hết tuổi, hai bên có phát ra **cùng một hạt mới** không?

Từ bài này, SoA sẽ tự cập nhật được cả đài phun. Ta giữ AoS làm lời giải đối chiếu, không dùng hình hai tia nước “trông cũng giống” làm bằng chứng duy nhất.

## Hiểu ý tưởng trước khi viết code

Lấy một ô có `age = lifetime - dt/2`. Sau một bước, cả hai cách lưu phải giữ nguyên ID, tăng `generation` thêm một và có tuổi mới `dt/2`. Nếu khác thế hệ, không epsilon nào cứu được: ta đang so hai lần sinh khác nhau. Nếu chỉ khác nhau chút ít ở một tọa độ thực, cần hỏi **khác bao nhiêu mét**.

Cũng đừng đợi đến khi cả đài phun đông nghịt mới kiểm. Một lỗi ở đúng một giọt giữa hàng nghìn giọt thường không hiện ra bằng mắt, nhất là khi bộ vẽ chỉ lấy một phần hạt để hiển thị.

## Viết code từng bước

### Cho SoA tiến đúng một bước như AoS

{/* snippet include/storage.hpp#update-soa-range */}
```cpp title="include/storage.hpp — Cập nhật theo cột nhưng giữ nguyên thứ tự tính"
inline std::size_t updateSoARange(ParticlesSoA& particles, std::size_t begin, std::size_t end, const FountainConfig& config, float dt, MemoryWorkload workload, std::size_t oldActive) {
    std::size_t respawned = 0;
    if (workload == MemoryWorkload::gravityOnly) {
        for (std::size_t index = begin; index < end; ++index) {
            particles.velocityY[index] += config.gravity * dt;
        }
    } else {
        for (std::size_t index = begin; index < end; ++index) {
            if (index >= oldActive || dt >= particles.lifetime[index] - particles.age[index]) {
                ParticleAoS particle = readParticle(particles, index);
                if (advanceParticle(particle, config, dt, index >= oldActive))
                    ++respawned;
                writeParticle(particles, index, particle);
            } else {
                particles.velocityY[index] += config.gravity * dt;
                particles.positionX[index] += particles.velocityX[index] * dt;
                particles.positionY[index] += particles.velocityY[index] * dt;
                particles.positionZ[index] += particles.velocityZ[index] * dt;
                particles.age[index] += dt;
            }
        }
    }
    return respawned;
}
```

Với một hạt còn sống qua hết bước, sửa `velocityY[index]`, dùng vận tốc **vừa sửa** để tiến `positionY[index]`, rồi tăng tuổi như ở bài 02. Với ô mới phát hoặc hạt hết tuổi, gọi lại `advanceParticle` đã kiểm chứng rồi ghi kết quả về đúng chỉ số. Đừng viết hai phiên bản lấy số ngẫu nhiên; cùng một ID và thế hệ phải ra cùng một hướng phóng.

### So ngay một ô bị đặt sai chỉ số

{/* snippet include/storage.hpp#maximum-layout-difference */}
```cpp title="include/storage.hpp — Đọc hạt từ hai cách lưu tại cùng một chỉ số"
inline float maximumLayoutDifference(std::span<const ParticleAoS> aos, const ParticlesSoA& soa) {
    if (!soa.valid() || aos.size() != soa.size())
        return std::numeric_limits<float>::infinity();
    float maximum = 0;
    for (std::size_t index = 0; index < aos.size(); ++index) {
        maximum = std::max(maximum, particleDifference(aos[index], readParticle(soa, index)));
    }
    return maximum;
}
```

`maximumLayoutDifference` giúp bắt lỗi sao chép hoặc cột sai độ dài. Ở đây ta chỉ cần hỏi giá trị nào đó có khác 0 hay không. Đừng dùng một con số tổng hợp từ vị trí, vận tốc và tuổi làm thước đo vật lý: 0,001 m và 0,001 s tuy giống chữ số nhưng không biểu thị cùng một sai khác.

### Kiểm các vòng đời với đơn vị riêng

{/* snippet include/storage.hpp#particle-error-ratio */}
```cpp title="include/storage.hpp — Mỗi đại lượng có khoảng sai số riêng"
inline float fieldErrorRatio(float first, float second, float absoluteTolerance, float relativeTolerance) {
    const float allowed = absoluteTolerance + relativeTolerance * std::max(std::abs(first), std::abs(second));
    return std::abs(first - second) / allowed;
}

inline float particleErrorRatio(const ParticleAoS& first, const ParticleAoS& second) {
    if (first.id != second.id || first.generation != second.generation || !finiteParticle(first) || !finiteParticle(second))
        return std::numeric_limits<float>::infinity();
    // Position: 1e-5 m; velocity: 1e-5 m/s; age/lifetime: 1e-6 s; hue: 1e-7.
    // Each group also gets a relative tolerance of 1e-6. A ratio <= 1 passes.
    return std::max({
        fieldErrorRatio(first.positionX, second.positionX, 1e-5F, 1e-6F),
        fieldErrorRatio(first.positionY, second.positionY, 1e-5F, 1e-6F),
        fieldErrorRatio(first.positionZ, second.positionZ, 1e-5F, 1e-6F),
        fieldErrorRatio(first.velocityX, second.velocityX, 1e-5F, 1e-6F),
        fieldErrorRatio(first.velocityY, second.velocityY, 1e-5F, 1e-6F),
        fieldErrorRatio(first.velocityZ, second.velocityZ, 1e-5F, 1e-6F),
        fieldErrorRatio(first.age, second.age, 1e-6F, 1e-6F),
        fieldErrorRatio(first.lifetime, second.lifetime, 1e-6F, 1e-6F),
        fieldErrorRatio(first.hue, second.hue, 1e-7F, 1e-6F),
    });
}
```

Điều kiện cho một trường là $|a-b|\leq A+r\max(|a|,|b|)$. Phần tuyệt đối $A$ bảo vệ phép so gần 0; phần tương đối $r=10^{-6}$ cho phép sai số làm tròn tăng theo độ lớn. Ở đây vị trí dùng $A=10^{-5}$ m, vận tốc $10^{-5}$ m/s, tuổi và tuổi thọ **10⁻⁶ s**, màu $10^{-7}$. Tỉ số trả về vượt 1 nghĩa là đã có ít nhất một trường vượt ngưỡng. ID và thế hệ phải bằng nhau tuyệt đối; `NaN` hay vô cực đều bị loại.

## Thử làm sai để hiểu đúng

1. Trong nhánh SoA, thử tiến `positionY` trước rồi mới sửa `velocityY`. Dùng ca một hạt có $v_y=2$, $g=-8$, $dt=1/32$. Kết quả lệch ngay bước đầu. Hãy sửa thứ tự phép tính, không nới ngưỡng để phép thử sang xanh.
2. Cho hạt mới dùng số ngẫu nhiên lấy từ thứ tự vòng lặp thay vì ID và thế hệ. Chọn một ô sắp hết tuổi: trước thời điểm ấy hai bên có thể giống hệt, ngay sau đó vận tốc phóng có thể khác. Trả về cùng quy tắc sinh hạt.

## Tự kiểm tra kết quả

- Đài phun chạy được ở AoS lẫn SoA; đổi layout không reset hoặc làm tăng thời gian mô phỏng.
- Ca hết tuổi giữa bước cho đúng ID, thế hệ và phần tuổi mới. Khi cùng đi qua nhiều lần sinh lại, tỉ số sai số lớn nhất không vượt 1.
- Báo `updated` theo số hạt thực sự cập nhật; đừng lấy số điểm hiện trên màn hình thay cho nó.

## Bài tập mở rộng

Tạo hai hạt có cùng vị trí nhưng khác thế hệ. Cố ý hoán đổi chúng chỉ trong một container rồi kiểm tổng tọa độ, sau đó kiểm từng ID. Phép nào bắt được lỗi? Kết quả cho biết vì sao checksum trong benchmark chỉ là một phần của việc đối chiếu.
