# Chọn chiều quay và giới hạn tốc độ

## Vấn đề cần giải quyết

Góc từ acos chỉ cho biết sai lệch bao nhiêu. Để nòng quay đúng, ta còn cần biết nên quay trái hay phải và trong một frame được phép đi bao xa. Bài này ghép hai câu hỏi ấy thành steering, không gán thẳng turretAngle từ vị trí mouse.

## Hiểu ý tưởng trước khi viết code

Trong world Y hướng lên, crossZ(a,b)=ax×by−ay×bx dương khi b ở phía quay ngược kim đồng hồ so với a. Dot cho cosine, cross của hai hướng đơn vị cho sine có dấu, nên atan2(cross,dot) cho góc sai lệch trong [−π,π].

Với tốc độ tối đa turnSpeed rad/s, frame deltaTime giây được phép quay nhiều nhất maximumStep=turnSpeed×deltaTime. Bước thực tế là clamp(remaining,−maximumStep,+maximumStep). Nếu sai lệch còn ít hơn một bước, chỉ đi đúng phần còn lại.

Bấm Tạm dừng, chọn Vuông trái rồi Tiến 0,1 s. Tốc độ mặc định π/2 rad/s cho một bước 9°. Thử tiếp tới khi chạm target: nòng phải dừng đúng hướng, không dao động qua lại. Chọn Ngược hướng để xem quy ước khi hai đường quay đều dài bằng nhau.

## Viết code từng bước

### Bước 1 — Lấy dấu trái/phải bằng crossZ

Trong include/lab.hpp:

```cpp title="include/lab.hpp — thành phần Z của cross product 2D"
inline double crossZ(Vec2 a, Vec2 b) {
    return a.x * b.y - a.y * b.x;
}
```

Đây là một scalar có dấu, không phải một Vec3 cần dựng lên. Dấu chỉ có nghĩa theo quy ước world Y lên; nếu truyền screen direction Y xuống, bạn sẽ đảo chiều quay.

### Bước 2 — Ghép cross và dot thành góc có dấu

```cpp title="include/lab.hpp — atan2 giữ cả dấu lẫn độ lớn sai lệch"
inline double signedAngleBetween(Vec2 from, Vec2 to) {
    if (!hasDirection(from) || !hasDirection(to)) {
        return 0.0;
    }
    const Vec2 a = normalize(from);
    const Vec2 b = normalize(to);
    const double sine = crossZ(a, b);
    const double cosine = dot(a, b);
    // Đối nhau chính xác: hai đường đều ngắn; chọn chiều dương, kể cả sine=-0.
    if (sine == 0.0 && cosine < 0.0) {
        return kPi;
    }
    return std::atan2(sine, cosine);
}
```

Chuẩn hóa trước giúp hai đầu vào atan2 ở miền số vừa phải. Khi hai hướng đối nhau **chính xác**, cross bằng +0 hoặc −0 và dot âm. Cả hai chiều đều là đường ngắn π; ta chọn +π để quy ước không phụ thuộc signed zero. Với hai hướng gần đối nhau nhưng chưa đúng đối nhau, dấu thực tế vẫn quyết định đường ngắn.

Ví dụ nòng 359°, target 1° cho sai lệch +2°, không phải −358°. Không lấy targetAngle−currentAngle rồi bỏ qua việc hai góc nằm hai phía của cùng một vòng.

### Bước 3 — Giới hạn bước và tránh overshoot

```cpp title="include/lab.hpp — một bước steering có giới hạn"
inline double rotateTowards(double currentAngle, Vec2 targetDirection, double maximumStep) {
    const double current = normalizeAngle(currentAngle);
    if (!std::isfinite(maximumStep) || maximumStep <= 0.0 || !hasDirection(targetDirection)) {
        return current;
    }
    const double remaining = signedAngleBetween(directionFromAngle(current), targetDirection);
    const double step = std::clamp(remaining, -maximumStep, maximumStep);
    return normalizeAngle(current + step);
}
```

Nếu còn 0,01 rad mà maximumStep=0,2 rad, step chỉ là 0,01. Với target zero hoặc bước không hợp lệ, giữ heading đã normalize. Không nhân sai lệch với một hệ số 0.1 mỗi frame rồi gọi đó là giới hạn rad/s.

### Bước 4 — Thêm tốc độ vào scene rồi cập nhật

Scene của checkpoint 05 có một trường mới:

```cpp title="include/scene.hpp — state gồm tốc độ quay tối đa"
struct Scene {
    Vec2 targetOffset{4.0, 3.0};
    double turretAngle{};
    bool followMouse = true;
    bool dragging{};
    double turnSpeed = kPi / 2.0;
};
```

```cpp title="include/scene.hpp — update chỉ nhận bước thời gian hợp lệ"
inline void advanceScene(Scene& scene, double deltaTime) {
    if (!std::isfinite(deltaTime) || deltaTime <= 0.0 || deltaTime > 0.1 || !targetHasDirection(scene)) {
        return;
    }
    scene.turretAngle = rotateTowards(scene.turretAngle, scene.targetOffset, scene.turnSpeed * deltaTime);
}
```

targetHasDirection kiểm vùng tâm trước khi steering. turnSpeed có đơn vị rad/s; turretAngle vẫn là nguồn duy nhất cho forward và hình nòng.

### Bước 5 — Đo delta time ở vòng ứng dụng

Trong src/main.cpp, previousTicks được khởi tạo trước while. Sau input:

```cpp title="src/main.cpp — đo frame rồi cập nhật khi không pause"
const std::uint64_t now = SDL_GetTicks();
const double deltaTime = std::min(0.1, static_cast<double>(now - previousTicks) / 1000.0);
previousTicks = now;
if (!paused) {
    lab::advanceScene(scene, deltaTime);
    dirty = true;
}
```

previousTicks cập nhật cả lúc pause, tránh cộng toàn bộ thời gian dừng khi resume. Ứng dụng chặn hitch ở 0,1 giây; advanceScene từ chối bước lớn hơn thay vì tự diễn giải lại nó. Đây là thời gian mô phỏng được chấp nhận, không bù toàn bộ wall time ở debugger hoặc tab ẩn.

Khi so FPS, dùng target đứng yên và cùng tổng deltaTime hợp lệ. Với target di chuyển, thời điểm lấy input cũng ảnh hưởng đường đi; đừng hứa hai chuỗi mouse khác nhau tạo cùng trajectory chỉ vì đã dùng dt.

## Thử làm sai để hiểu đúng

1. Gán turretAngle=atan2(target.y,target.x) mỗi frame. Hình bám mouse nhưng snap ngay, không còn giới hạn tốc độ.
2. Luôn quay đúng ±maximumStep dù remaining nhỏ hơn. Nòng vượt target rồi quay ngược, tạo rung quanh hướng cần ngắm.
3. Lấy targetAngle−currentAngle không wrap. Tình huống 359°→1° có thể quay gần cả vòng sai chiều.
4. Gán góc mới theo remaining×0.1 mỗi frame. FPS thay đổi sẽ đổi thời gian hội tụ; đó không phải turnSpeed rad/s.

## Tự kiểm tra kết quả

- Sai lệch trái/phải lần lượt dương/âm trong world Y lên.
- 359°→1° chọn +2°; đúng đối nhau có quy ước +π.
- Mỗi bước không vượt turnSpeed×deltaTime và không vượt target.
- Tốc độ 0 đứng yên; target trong vùng tâm giữ heading cũ.
- Với target cố định, 120 bước 1/120 s, 10 bước 0,1 s và chuỗi không đều cùng tổng 1 s cho cùng góc trong sai số số thực.
- Forward, target direction và projection/rejection vẫn hiện khi nòng đang quay.

## Bài tập mở rộng

Viết oracle bằng remainder(targetAngle−currentAngle,2π), xử lý riêng tie −π rồi clamp theo bước. So với rotateTowards trên nhiều cặp góc, không dùng signedAngleBetween để tạo expected của chính nó.
