# Vẽ tháp pháo rồi đặt mục tiêu bằng chuột

## Vấn đề cần giải quyết

Ở Project 07, bạn đã biến một góc thành vị trí bằng sin/cos. Bây giờ ta dùng hướng đó để vẽ một tháp pháo có thân và nòng, rồi đặt một mục tiêu theo chuột. **Bài này chưa cho nòng đuổi theo mục tiêu.** Ta cần một cảnh quan sát được trước khi dùng dot product để giải thích nó.

Sau bài này, tháp pháo ở giữa vùng vẽ; mục tiêu theo chuột, mũi tên vàng chỉ forward và mũi tên xanh chỉ target direction.

## Hiểu ý tưởng trước khi viết code

World có gốc tại tháp pháo, X sang phải, Y lên trên. Ta lưu targetOffset là độ dời từ gốc tới mục tiêu. Forward là hướng đơn vị suy từ turretAngle; target direction là hướng đơn vị của targetOffset.

Bảng logic rộng 1100, cao 760. Gốc screen ở (550,410); một world unit bằng 40 pixel logic. Ví dụ targetOffset=(4,3) xuất hiện tại (710,290). Đường tròn xám bán kính 6.5 world là **miền thao tác**: giữ target và các hình chiếu sau này trong vùng nhìn, không phải tầm bắn.

Di chuột trong bảng, không cần giữ nút. Bỏ Theo chuột để giữ nguyên hình khi đọc số. Trên touch/pen, nhấn và kéo; bàn phím dùng các phím mũi tên. Mũi tên forward được vẽ dài 3.0 world, target direction dài 3.5 world để cả hai vẫn thấy được khi cùng hướng. Đây chỉ là độ phóng đại khi vẽ; dữ liệu của cả hai vẫn là vector đơn vị. Đường xám tới target mới cho biết khoảng cách thật.

## Viết code từng bước

### Bước 1 — Chạy bộ khung SDL3

Tải ZIP Project 08 và mở terminal tại thư mục có CMakeLists.txt:

```bash title="Terminal — mở starter trước khi sửa code"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_8_starter --parallel 2
.\build\Debug\project_8_starter.exe
```

Starter đã có window/event loop, ảnh CPU, texture, grid/trục, circle miền thao tác và các helper Vec2/normalize/arrow từ Project 06. Chưa có thân/nòng hoặc target. Resize dùng letterbox nên bảng không méo; không phải cấp lại ảnh mỗi lần kéo cửa sổ.

### Bước 2 — Thêm dữ liệu và phép đổi tọa độ

Thay Scene rỗng trong include/scene.hpp bằng:

```cpp title="include/scene.hpp — trạng thái đầu tiên của tháp pháo"
struct Scene {
    Vec2 targetOffset{4.0, 3.0};
    double turretAngle{};
    bool followMouse = true;
    bool dragging{};
};
```

targetOffset lưu qua các frame; turretAngle=0 hướng sang phải. followMouse cho phép tắt hover để đọc số; dragging dùng cho lần nhấn/kéo có capture.

Hai phép đổi đã có sẵn trong starter; đối chiếu trước khi nối input:

```cpp title="include/scene.hpp — world sang bảng logic"
inline Vec2 worldToScreen(Vec2 world) {
    return {kOrigin.x + kPixelsPerUnit * world.x, kOrigin.y - kPixelsPerUnit * world.y};
}
```

```cpp title="include/scene.hpp — mouse trên bảng logic sang world"
inline Vec2 screenToWorld(Vec2 screen) {
    return {(screen.x - kOrigin.x) / kPixelsPerUnit, (kOrigin.y - screen.y) / kPixelsPerUnit};
}
```

Không đưa screen point trực tiếp vào normalize. Cần trừ gốc và đổi Y trước, nếu không hướng tới chuột sẽ sai ngay cả khi nòng được vẽ đúng.

### Bước 3 — Vẽ thân, nòng và mục tiêu

Trong include/view.hpp, thêm hai hàm sau. arrow đã có trong starter; nó dùng normalize để dựng hai cánh đầu mũi tên và bỏ qua vector zero.

```cpp title="include/view.hpp — thân tròn và nòng có bề rộng"
inline void drawTurret(Framebuffer& image, Vec2 forward) {
    disc(image, 550, 410, 24, kGrid);
    drawCircle(image, 550, 410, 24, kWhite);
    const Vec2 side{-forward.y * 0.15, forward.x * 0.15};
    const Vec2 muzzle = scale(forward, 2.4);
    lineBetween(image, worldToScreen(side), worldToScreen(add(muzzle, side)), kWhite);
    lineBetween(image, worldToScreen(scale(side, -1.0)), worldToScreen(subtract(muzzle, side)), kWhite);
    lineBetween(image, worldToScreen(add(muzzle, side)), worldToScreen(subtract(muzzle, side)), kWhite);
    arrow(image, {}, scale(forward, 3.0), kNeedle);
}
```

```cpp title="include/view.hpp — chấm mục tiêu và dấu ngắm"
inline void drawTarget(Framebuffer& image, Vec2 target, std::uint32_t color) {
    const Vec2 screen = worldToScreen(target);
    const int x = static_cast<int>(std::lround(screen.x));
    const int y = static_cast<int>(std::lround(screen.y));
    disc(image, x, y, 8, color);
    drawLine(image, x - 13, y, x + 13, y, kWhite);
    drawLine(image, x, y - 13, x, y + 13, kWhite);
}
```

side là vector vuông góc với forward, dài 0.15 world. Hai cạnh nòng nằm ở ±side; muzzle dài 2.4 world. Nhờ vậy hình tháp pháo vẫn nhận ra được, không chỉ là hai mũi tên debug.

Trong renderScene của checkpoint 01: suy forward bằng directionFromAngle(scene.turretAngle), vẽ đường tới target; nếu target đủ xa tâm thì vẽ normalize(targetOffset); sau đó gọi drawTurret/drawTarget. Toàn bộ renderScene có trong source checkpoint cuối bài.

### Bước 4 — Đưa vị trí chuột vào scene

Trong include/scene.hpp, setter nhận world point và giữ nó trong miền thao tác:

```cpp title="include/scene.hpp — giới hạn target bằng bán kính, không clamp riêng X/Y"
inline Vec2 boundedTarget(Vec2 target) {
    if (!std::isfinite(target.x) || !std::isfinite(target.y)) {
        return {};
    }
    if (length(target) > kTargetRadius) {
        return scale(normalize(target), kTargetRadius);
    }
    return target;
}
```

```cpp title="include/scene.hpp — một đường ghi dữ liệu target"
inline void setTarget(Scene& scene, Vec2 target) {
    scene.targetOffset = boundedTarget(target);
}
```

src/main.cpp gọi SDL_ConvertEventToRenderCoordinates trước các nhánh mouse. Khi không có lần kéo nào, đoạn hover sau nhận vị trí chuột đã ở bảng logic:



```cpp title="src/main.cpp — cả nhánh mouse motion, có phân biệt capture và hover"
if (event.type == SDL_EVENT_MOUSE_MOTION) {
    if (scene.dragging && event.motion.which == owner) {
        if ((event.motion.state & SDL_BUTTON_LMASK) == 0) {
            cancelDrag();
        } else {
            lab::setTarget(scene, lab::screenToWorld({event.motion.x, event.motion.y}));
            dirty = true;
        }
    } else if (!scene.dragging && scene.followMouse && event.motion.state == 0) {
        if (event.motion.x >= 0.0f && event.motion.x < 1100.0f && event.motion.y >= 0.0f && event.motion.y < 760.0f) {
            lab::setTarget(scene, lab::screenToWorld({event.motion.x, event.motion.y}));
            dirty = true;
        }
    }
}
```

owner và cancelDrag là phần vòng đời input quen thuộc từ Project 06–07. Khai báo chúng trước while(running), cùng với Scene:


```cpp title="src/main.cpp — một mouse owner và một đường hủy capture"
SDL_MouseID owner{};
const auto cancelDrag = [&]() {
    lab::cancelDrag(scene);
    SDL_CaptureMouse(false);
};
```

Source đầy đủ ở cuối bài còn có nhánh mouse-down/up: nhấn trái ghi owner và capture; thả áp dụng mẫu tọa độ cuối rồi hủy. Blur/hidden/resize cũng thả capture. Không bỏ những nhánh ấy nếu muốn hỗ trợ kéo ra ngoài window; hover không cần capture nhưng một lần nhấn/kéo thì có.

## Ghép các phần lại

Build project_8_checkpoint_1. Dữ liệu đi theo chuỗi mouse → tọa độ logic → screenToWorld → setTarget → renderScene. Angle vẫn do preset góc hoặc A/D điều khiển, chưa có steering.

F bật/tắt follow; F1–F7 đặt các tình huống và tắt follow để mousemove không ghi đè. Preset/reset cũng pause. Trên Linux/macOS với generator một cấu hình, đặt CMAKE_BUILD_TYPE=Debug và chạy executable trực tiếp trong build; đường build/Debug ở trên dành cho Visual Studio.

Ở vùng 8 pixel quanh tâm, UI ghi chưa có hướng và không vẽ target direction. Đó là chính sách thao tác, không phải mọi vector nhỏ đều không thể normalize.

## Thử làm sai để hiểu đúng

1. Bỏ phép trừ gốc trong screenToWorld. Khi chuột ở đúng thân pháo, targetOffset không còn gần (0,0).
2. Dùng mouseY−410 thay vì 410−mouseY. Mục tiêu đi xuống khi chuột đi lên; bạn đã dùng screen Y như world Y.
3. Lưu target trong renderScene rồi khởi tạo lại mỗi frame. Chuột vẫn phát sự kiện nhưng target cứ trở về vị trí mặc định.
