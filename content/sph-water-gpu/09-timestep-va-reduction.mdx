# Chọn timestep từ dữ liệu đang nằm trên GPU

## Vấn đề cần giải quyết

Tăng độ phân giải làm h nhỏ. Dùng dt cũ cho một triệu hạt có thể làm bước quá lớn, dù GPU tính force đúng. Ta cần extrema của chính state/force hiện tại mà không tải mọi velocity/acceleration về CPU.

## Hiểu ý tưởng trước khi viết code

Dùng dt=min(maxDt,0.25 h/(c+vmax),0.25 sqrt(h/amax)), maxDt=0.0005 s. Đây là bound thực hành, không phải chứng minh mọi cảnh luôn ổn định. Dt dưới 1e−6 là lỗi, không được kẹp lên rồi tiếp tục.

Reduction gom record(vmax,amax,rhoMax,error). Mỗi workgroup tạo một record; max.comp tiếp tục thu các record tới một. Error dùng max như phép OR cho flag 0/1. NaN phải được đổi thành error trước khi làm max.

$$
\Delta t=\min\left(0.0005,\frac{0.25h}{c+v_{\max}},0.25\sqrt{\frac{h}{\max(a_{\max},10^{-12})}}\right).
$$

Đọc dt sau một tick. Đổi c hoặc state có thể thay dt; không lấy số frame làm dt. Canvas double chỉ kiểm math; source compute reduction giữ data trên GPU.

## Viết code từng bước

### Bước 1 — Pad lane nhưng không bỏ barrier

Trong stats.comp:

```glsl title="shaders/stats.comp — GLSL thống kê của một lane"
vec4 value = vec4(0.0);
if (i < uCount) {
    value = vec4(length(velocities[i].xyz), length(acceleration[i].xyz), density[i].x, max(density[i].w, acceleration[i].w));
    if (bad(value.xyz)) value = vec4(0.0, 0.0, 0.0, 1.0);
}
partial[lane] = value;
barrier();
```

Inactive lane vẫn đến mọi barrier. Return trước barrier ở ca 257 hạt có thể làm workgroup cuối sai hoặc treo. Shared partial có 256 vec4, cần 4096 byte.

### Bước 2 — Thu tới một record

Host ping-pong hai scratch buffers, mỗi vòng giảm count khoảng 256 lần:

```cpp title="include/passes.hpp — max hierarchy"
while (count > 1) {
    gl.UseProgram(programs.maximum);
    gl.Uniform1ui(requireUniform(gl, programs.maximum, "uCount"), count);
    bind(gl, 0, storage.scratch[source]);
    bind(gl, 1, storage.scratch[1 - source]);
    dispatch(gl, count);
    count = ceilDivide(count, 256);
    source = 1 - source;
}
return storage.scratch[source];
```

Không readback block sums rồi để CPU tính max. Root buffer được bind cho integration; sau fence host chỉ đọc 16 byte để cập nhật time/diagnostics.

### Bước 3 — Chọn dt trước khi integrate

Trong integrate.comp:

```glsl title="shaders/integrate.comp — GLSL dt của force hiện tại"
dt = min(dt, min(0.25 * uH / (uC + stats[0].x), 0.25 * sqrt(uH / max(stats[0].y, 1e-12))));
if (stats[0].w > 0.0 || dt < 1e-6) {
    nextPositions[i] = positions[i];
    nextVelocities[i] = velocities[i];
    return;
}
```

Force→reduction→integration có SSBO barrier giữa các pass. Không dùng extrema của frame trước để gọi dt này là bound của tick hiện tại. Nếu flag lỗi, bank mới không được host commit.

## Ghép các phần lại

Checkpoint 9 N dùng adaptive dt. CPU chooseDt tính lại cùng bound từ root record sau fence để ghi simulated time. Sai khác float/double nhỏ không được biến thành kiểm bitwise.

## Thử làm sai để hiểu đúng

1. Luôn return maxDt. Dùng plan 100³/c 20/velocity 0: acoustic bound nhỏ hơn maxDt, test phải thất bại.
2. Return cho i>=N trước barrier trong stats. Ca 257 hạt phải bắt lỗi tail; giữ neutral padding.

## Tự kiểm tra kết quả

Có test riêng khi acoustic chi phối và khi force chi phối; không dùng ca cả hai bound đều lớn hơn maxDt. NaN/Infinity và dt dưới 1e−6 bị từ chối. Root được đọc sau fence, không readback từng hạt.
