# Dựng spatial grid 3D hoàn toàn trên GPU

## Vấn đề cần giải quyết

All-pairs với 512 hạt vẫn đủ nhỏ để kiểm. Nhưng với một triệu hạt, mỗi pass phải xét tới 10¹² cặp. Ta chuyển sang spatial grid để tìm ứng viên lân cận, còn kernel và công thức lực giữ nguyên. Grid được dựng trên GPU; không upload bucket CPU hay âm thầm bỏ hạt khi một cell chứa hơn 32 hạt.

## Hiểu ý tưởng trước khi viết code

Đặt cạnh cell bằng bán kính support R=2h. Khi tìm hàng xóm của một hạt, ta xét cell của nó cùng các cell kề theo ba trục: 3×3×3=27 cell. Đây mới là bước tìm ứng viên; mỗi cặp vẫn phải được lọc bằng khoảng cách 3D thật.

CSR gồm counts, exclusive offsets và indices. Counts quyết định mỗi cell có bao nhiêu ID; offsets cho vị trí bắt đầu. Scatter dùng atomic cursor để mỗi ID nhận một slot riêng. Thứ tự ID trong cell có thể khác giữa các dispatch, nên float sums không được hứa khớp từng bit.

## Viết code từng bước

### Bước 1 — Tính cell và đếm

common.glsl flatten theo row-major 3D; count.comp chỉ làm histogram:

{/* snippet shaders/count.comp#count-particles */}
```glsl title="shaders/count.comp — GLSL histogram"
void main() {
    // Atomic count reserves no particle slot yet.
    uint i = gl_GlobalInvocationID.x;
    if (i >= uCount || bad(positions[i].xyz))
        return;
    atomicAdd(counts[flatten(cellOf(positions[i].xyz))], 1u);
}
```

Clear counts trước count. CellOf kẹp p=1 vào cell cuối, không wrap qua phía đối diện. Biên không tuần hoàn.

### Bước 2 — Exclusive scan nhiều tầng

Ví dụ counts `[2,0,3]` cần offsets `[0,2,2]`: cell 0 giữ slot 0–1, cell 1 rỗng, cell 2 giữ slot 2–4. Muốn có offsets cho mọi cell, ta cần exclusive scan. Shader `scan.comp` dùng 256 lane để scan 512 giá trị bằng Blelloch: nạp hai giá trị/lane, upsweep lấy tổng block, đặt root=0 rồi downsweep tạo prefix. Lane đuôi nạp 0 nhưng vẫn đi qua barrier.

Một workgroup không thể đồng bộ toàn GPU. Vì vậy `buildGrid` scan từng block, scan tiếp mảng block sums cho tới một block, rồi đi ngược các tầng để cộng prefix của block cha. Đây là chỗ áp dụng prefix sum ở Project 39; đọc cả hàm host để thấy thứ tự dispatch và barrier, không chỉ một vòng lặp bị tách khỏi caller:

{/* snippet include/passes.hpp#build-grid */}
```cpp title="include/passes.hpp — hierarchy scan trên GPU"
inline void buildGrid(lab::GlApi& gl, const Programs& programs, Storage& storage, int current, Queue* profiler = nullptr) {
    const auto& plan = storage.plan;
    Settings settings;
    use(gl, programs.clear, plan, settings, true);
    gl.Uniform1ui(requireUniform(gl, programs.clear, "uCount"), plan.cells);
    bind(gl, 0, storage.counts);
    dispatch(gl, plan.cells);
    if (profiler)
        profiler->mark(gl, "Grid clear");
    use(gl, programs.count, plan, settings, true);
    bind(gl, 0, storage.positions[current]);
    bind(gl, 1, storage.counts);
    dispatch(gl, plan.count);
    if (profiler)
        profiler->mark(gl, "Grid count");
    GLuint source = storage.counts;
    for (const auto& level : storage.scan) {
        gl.UseProgram(programs.scan);
        gl.Uniform1i(requireUniform(gl, programs.scan, "uElementCount"), static_cast<GLint>(level.level.input));
        bind(gl, 0, source);
        bind(gl, 1, level.output);
        bind(gl, 2, level.sums);
        gl.DispatchCompute(level.level.groups, 1, 1);
        gl.MemoryBarrier(GL_SHADER_STORAGE_BARRIER_BIT);
        source = level.sums;
    }
    for (std::size_t i = storage.scan.size() - 1; i > 0; --i) {
        const auto& level = storage.scan[i - 1];
        gl.UseProgram(programs.add);
        gl.Uniform1i(requireUniform(gl, programs.add, "uElementCount"), static_cast<GLint>(level.level.input));
        bind(gl, 0, level.output);
        bind(gl, 1, storage.scan[i].output);
        dispatch(gl, level.level.input);
    }
    use(gl, programs.cursors, plan, settings, true);
    if (profiler)
        profiler->mark(gl, "Grid scan / add");
    gl.Uniform1ui(requireUniform(gl, programs.cursors, "uCount"), plan.cells);
    bind(gl, 0, storage.offsets);
    bind(gl, 1, storage.cursors);
    dispatch(gl, plan.cells);
    use(gl, programs.scatter, plan, settings, true);
    bind(gl, 0, storage.positions[current]);
    bind(gl, 1, storage.cursors);
    bind(gl, 2, storage.indices);
    dispatch(gl, plan.count);
    if (profiler)
        profiler->mark(gl, "Grid scatter");
}
```

Lần theo `source=counts` lên các mảng sums, rồi vòng `i>0` đi xuống. `scan[i].output` là prefix của các block mà tầng dưới cần. Sau uniform-add mới chép offsets sang cursors và scatter. Mỗi dispatch có SSBO barrier trước consumer tiếp theo; CPU chỉ tổ chức pass, không tự cộng prefix.

Phân biệt `plan.cells` với `plan.count`: clear/scan làm việc trên cell, count/scatter làm việc trên hạt. Preset 48³ có 110.592 hạt nhưng 47³=103.823 cell; fixture scan cuối khóa có 257 hạt trong grid 4.096 cell. Không thay hai số này cho nhau dù một cảnh nhỏ tình cờ cho chúng bằng nhau.

### Bước 3 — Scatter ID, không scatter position

Sau cursors=offsets, scatter.comp:

{/* snippet shaders/scatter.comp#scatter-particles */}
```glsl title="shaders/scatter.comp — GLSL slot duy nhất"
void main() {
    // Each particle ID is stored exactly once, without fixed cell capacities.
    uint i = gl_GlobalInvocationID.x;
    if (i >= uCount || bad(positions[i].xyz))
        return;
    uint slot = atomicAdd(cursors[flatten(cellOf(positions[i].xyz))], 1u);
    indices[slot] = i;
}
```

Position vẫn ở bank cũ. Density/force lấy j=indices[slot] khi duyệt range của 27 cell; kernel loại ứng viên ngoài support. Giới hạn 4096 ứng viên là safety failure: ghi flag và không commit tick, không trả một lực bị cắt ngầm.

## Ghép các phần lại

Chạy checkpoint 8, bấm N một lần rồi L xem density. G đổi grid/all-pairs khi idle và N≤512; bấm N để tính lại từ cùng trạng thái nếu đang ở phần thử lực, hoặc dùng oracle cuối khóa để so không làm lệch trajectory. Camera không đổi search. `buildGrid` chạy mỗi tick trước density, dựa trên position đã commit gần nhất; không giữ grid cũ sau khi hạt đã đi qua ranh cell.

## Thử làm sai để hiểu đúng

1. Chỉ duyệt 9 cell trên mặt xy. Hàng xóm ở lớp z±1 bị mất; kiểm pair khác lớp trước khi nhìn dam.
2. Scatter position tại chỗ thay vì ID. Bạn vừa làm thay đổi state mà các hạt khác đang đọc; giữ indices riêng.

## Tự kiểm tra kết quả

Counts cộng ra N, offsets liên tiếp và mỗi ID xuất hiện đúng một lần ở đúng cell. Density/force khớp all-pairs trong tolerance. Có test điểm sát cell boundary và support cutoff; không đòi atomic order cố định.
