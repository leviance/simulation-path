# Dựng bể và nhìn rõ từng lớp hạt

## Vấn đề cần giải quyết

Project 50 đã cho ta một bể nước trên mặt phẳng. Lần này, bể có cả chiều sâu: nước có thể chảy vòng qua một vật cản, một hạt có thể che hạt khác và cùng một cảnh phải nhìn đúng từ nhiều phía. Ta chưa thêm lực ngay. Mục tiêu đầu tiên là dựng một khối 4 × 4 × 4 hạt đứng yên và điều khiển góc nhìn mà không làm thay đổi chúng.

## Hiểu ý tưởng trước khi viết code

Bể dùng mét, không dùng pixel: x chạy dọc bể, y hướng lên và z là chiều sâu. Kích thước bể là 1,65 × 0,825 × 1,10 m. Khối nước ban đầu có cạnh 0,55 m. Camera chỉ quyết định cách nhìn khối ấy; kéo camera không được sửa position, spacing hay mass. Trong ZIP, starter đã có cửa sổ OpenGL, bộ nạp hàm GL và các tiện ích quản lý tài nguyên. Đây là bộ khung được cung cấp để ta không phải chép lại Project 33. Hãy build starter, thấy cửa sổ trống rồi mới chuyển sang checkpoint 01.

## Viết code từng bước

### 1. Giữ đúng vòng đời cửa sổ OpenGL

Mở src/main.cpp và giữ phần khởi tạo dưới đây trong main. Cửa sổ này dùng OpenGL nên không tạo thêm SDL_Renderer cho cùng cửa sổ. Renderer dùng cho chữ ở bảng điều khiển là software renderer trên một SDL_Surface riêng.

{/* snippet src/main.cpp#context */}

```cpp title="src/main.cpp — Giữ đúng vòng đời cửa sổ OpenGL"
// Setup: create the SDL window and OpenGL context before any GL resources.
if (!SDL_Init(SDL_INIT_VIDEO))
    throw std::runtime_error(SDL_GetError());
SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 4);
SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 3);
SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_CORE);
SDL_GL_SetAttribute(SDL_GL_DOUBLEBUFFER, 1);
SDL_GL_SetAttribute(SDL_GL_DEPTH_SIZE, 24);
SDL_WindowFlags flags = SDL_WINDOW_OPENGL | SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY;
if (options.hidden)
    flags |= SDL_WINDOW_HIDDEN;
window = SDL_CreateWindow("Project 51 - SPH Water 3D", 1280, 800, flags);
if (!window)
    throw std::runtime_error(SDL_GetError());
SDL_SetWindowMinimumSize(window, 800, 600);
context = SDL_GL_CreateContext(window);
if (!context)
    throw std::runtime_error(SDL_GetError());
SDL_GL_SetSwapInterval(0);
// Cleanup: run() destroys GL objects before their context and SDL window are destroyed.
auto shaderRoot = std::filesystem::path(COURSE_SHADER_DIRECTORY);
if (!std::filesystem::exists(shaderRoot)) {
    const char* base = SDL_GetBasePath();
    if (base == nullptr)
        throw std::runtime_error(SDL_GetError());
    shaderRoot = std::filesystem::path(base) / COURSE_SHADER_FALLBACK_SUBDIRECTORY;
}
const int result = water51::run(window, options, shaderRoot);
SDL_GL_DestroyContext(context);
SDL_DestroyWindow(window);
SDL_Quit();
```

run() chứa vòng sự kiện và tài nguyên GL. Khi run trả về, các object GL đã bị hủy; sau đó mới hủy context và window. Nếu đảo thứ tự, destructor có thể gọi GL vào context không còn tồn tại.

### 2. Đặt hạt vào tâm từng ô

Một chỉ số liên tiếp phải xác định được ba chỉ số nguyên. Viết seedPoint trong model.hpp. Dù cửa sổ đang rộng hay hẹp, hàm vẫn trả cùng một vị trí world.

{/* snippet include/fluid/model.hpp#seed-point */}

```cpp title="include/fluid/model.hpp — Đặt hạt vào tâm từng ô"
inline Vec3 seedPoint(const Model& m, std::uint32_t id) {
    if (id >= m.count)
        throw std::out_of_range("Seed id");
    int nx = m.side;
    int ny = m.side;
    Vec3 origin{0, 0, blockWidth / 2};
    if (m.preset == Preset::Pool) {
        nx = 2 * m.side;
        ny = m.side / 4;
        origin = {blockWidth / 2, 0, 0};
    }
    const int x = static_cast<int>(id) % nx;
    const int y = (static_cast<int>(id) / nx) % ny;
    const int z = static_cast<int>(id) / (nx * ny);
    return {origin.x + (x + 0.5) * m.spacing, origin.y + (y + 0.5) * m.spacing, origin.z + (z + 0.5) * m.spacing};
}
```

x thay nhanh nhất, rồi y, cuối cùng z. Thêm 0,5 đặt hạt vào tâm ô, tránh đặt tâm đúng trên thành bể. Preset Pool đổi số hàng và lớp nhưng không đổi tổng số hạt hoặc tổng khối lượng. Ở bài này hãy dùng Dam.

### 3. Tính vị trí người quan sát

Camera giữ yaw, pitch và distance. Mỗi khi resize hoặc kéo chuột, gọi update với chiều cao viewport để dựng lại eye và ba vector cơ sở.

{/* snippet include/app/camera.hpp#camera-frame */}

```cpp title="include/app/camera.hpp — Tính vị trí người quan sát"
void update(int height) {
    pitch = std::clamp(pitch, 0.10, 1.25);
    distance = std::clamp(distance, 1.35, 4.5);
    const double sy = std::sin(yaw), cy = std::cos(yaw), sp = std::sin(pitch), cp = std::cos(pitch);
    eye = add(target, scale({sy * cp, sp, cy * cp}, distance));
    forward = {-sy * cp, -sp, -cy * cp};
    right = {cy, 0, -sy};
    up = {-sy * sp, cp, -cy * sp};
    focal = height / (2 * std::tan(25 * std::numbers::pi / 180));
}
```

forward trỏ về khối nước; right và up nằm trên mặt phẳng ảnh. focal phụ thuộc chiều cao cửa sổ. Đây là phép chiếu perspective, không phải xoay tọa độ của hạt để giả làm 3D.

### 4. Dùng đường vẽ được cung cấp để kiểm vị trí

Bộ khung có sẵn đường vẽ sphere impostor. Đoạn vertex shader sau cho thấy vị trí world được đọc và chiếu ra màn hình ở đâu; lúc này ta chỉ dùng nó để kiểm dữ liệu tạo trên CPU.

{/* snippet shaders/water/sphere.vert#billboard */}

```glsl title="shaders/water/sphere.vert — Dùng đường vẽ được cung cấp để kiểm vị trí"
void main() {
    const vec2 quad[6] = vec2[6](vec2(-1, -1), vec2(1, -1), vec2(1, 1), vec2(-1, -1), vec2(1, 1), vec2(-1, 1));
    uint i = uint(gl_InstanceID);
    center = position[i].xyz;
    diagnostic = vec2(field[i].x, length(velocity[i].xyz));
    vec3 delta = center - eye;
    float z = dot(delta, forward);
    vec2 pixel = vec2(dot(delta, right), dot(delta, up)) * focal / max(z, .04);
    float pixels = radius * focal / max(z - radius, .04);
    vec2 ndc = (pixel + quad[gl_VertexID] * pixels) * 2.0 / viewport;
    gl_Position = vec4(ndc, 0, 1);
}
```

Checkpoint 01 ghi vị trí CPU vào buffer dùng để vẽ; chưa có GPU SPH. Mỗi instance ứng với một hạt, không giảm số hạt theo góc nhìn. Bài 03 sẽ thay việc nạp vị trí CPU bằng initialization compute shader.

## Ghép các phần lại

Gói ZIP trên trang tổng quan đã chứa đầy đủ file của mỗi checkpoint. Nếu muốn tự viết, bắt đầu từ bản cuối bài trước, thêm những phần vừa giải thích rồi đối chiếu bản dưới đây; không ghép các mảnh code thành một file main tùy ý.

```powershell title="Terminal — checkpoint 01"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_51_checkpoint_1 --parallel 1
.\build\Debug\project_51_checkpoint_1.exe
```

Trên Linux, dùng executable trong build thay cho thư mục Debug. Driver cần hỗ trợ OpenGL 4.3 compute; lỗi thiếu khả năng phải được báo rõ, không chuyển sang một animation giả.

## Thử làm sai để hiểu đúng

1. Giữ mô phỏng đứng yên, kéo góc nhìn rồi resize cửa sổ. Dự đoán cái gì được đổi và cái gì phải giữ nguyên: hình chiếu có thể đổi, nhưng vẫn phải có 64 hạt và khối vẫn có cạnh 0,55 m trong world space. Nếu khối bị kéo dài, hãy kiểm focal và aspect ratio, đừng sửa vị trí hạt để bù lỗi camera.
2. Trong một bản nháp của seedPoint, tạm cho mọi hạt có cùng z. Nhìn chính diện có thể chưa rõ lỗi, nhưng nhìn bên hông sẽ thấy khối bị ép thành một mặt phẳng. Khôi phục cách tính z trước khi sang bài sau; thay đổi góc nhìn không thể tạo lại chiều sâu đã mất trong dữ liệu.

Build target project_51_checkpoint_1. Phải có đúng 64 hạt, camera xoay được và khối giữ nguyên kích thước world sau resize. Starter chỉ mở cửa sổ trống. Checkpoint này chưa chạy lực; đừng dùng việc hạt đứng yên để kết luận solver sai.
