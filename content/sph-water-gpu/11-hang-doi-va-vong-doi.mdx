# Giữ cửa sổ phản hồi khi GPU đang tính

## Vấn đề cần giải quyết

Một solver đúng nhưng khóa cửa sổ trong lúc chờ GPU vẫn là một sản phẩm khó dùng. Ta chỉ cho phép một batch đang chờ, mỗi batch tối đa bốn tick. CPU tiếp tục nhận input và vẽ state đã được chấp nhận thay vì bận chờ completion.

## Hiểu ý tưởng trước khi viết code

Shader-storage barrier bảo đảm pass GPU sau đọc đúng dữ liệu; fence cho biết các lệnh trước nó đã hoàn tất. Chúng không thay thế nhau. Ba bank giữ state committed không bị integration của batch mới ghi đè. Batch lỗi không được nhận một phần kết quả vì vài hạt trông vẫn bình thường.

Canvas là mô hình CPU phục vụ học tập, không phải ứng dụng GPU của bài. Thời gian mô phỏng được ghi riêng và có thể chạy chậm hơn thời gian thực. Chuyển chế độ hiển thị không thay đổi phương trình SPH.

## Viết code từng bước

### 1. Đọc một báo cáo nhỏ sau batch

Cờ lỗi, updated, leakage và invalid được ghi riêng trong GpuMeta. Chúng giúp host quyết định có nhận bank mới hay không.

{/* snippet include/gpu/storage.hpp#meta-layout */}

```cpp title="include/gpu/storage.hpp — Đọc một báo cáo nhỏ sau batch"
struct alignas(16) GpuMeta {
    std::uint32_t flags = 0;
    std::uint32_t updated = 0;
    std::uint32_t leakage = 0;
    std::uint32_t invalid = 0;
    float dt = 0;
    float elapsed = 0;
    float maximumSpeed = 0;
    float maximumAcceleration = 0;
    float minimumDensity = 0;
    float maximumDensity = 0;
    std::uint32_t ticks = 0;
    std::uint32_t padding = 0;
    Float4 body{0.92f, 0.22f, 0.55f, 0};
    Float4 target = body;
    Float4 bodyVelocity{};
};

static_assert(sizeof(GpuMeta) == 96);
static_assert(offsetof(GpuMeta, body) == 48);
```

Không dùng timer như dấu hiệu state hợp lệ. Batch nhanh vẫn có thể sai; batch chậm không tự động là sai vật lý. Timestamp chỉ được đọc sau khi query báo available.

### 2. Gửi một lượng công việc hữu hạn

Chọn hai bank làm việc khác committed. Tick tiếp theo đọc kết quả của tick trước trong cùng batch, nhưng không ghi lên bank đang được hiển thị.

{/* snippet include/gpu/engine.hpp#submit-batch */}

```cpp title="include/gpu/engine.hpp — Gửi một lượng công việc hữu hạn"
void submit(int steps = 4) {
    if (pending() || !ready())
        return;
    if (steps < 1 || steps > 4)
        throw std::invalid_argument("A batch contains one to four ticks");
    validate(parameters);
    const auto start = std::chrono::steady_clock::now();
    meta_.elapsed = 0;
    meta_.ticks = 0;
    meta_.flags = 0;
    meta_.updated = 0;
    meta_.leakage = 0;
    meta_.invalid = 0;
    storage_->meta.write(&meta_, sizeof(meta_));
    timer_.start();
    int source = committed_;
    const int a = (committed_ + 1) % 3;
    const int b = (committed_ + 2) % 3;
    const bool grid = true;
    for (int tick = 0; tick < steps; ++tick) {
        int target = a;
        if (source == a)
            target = b;
        passes_.prepare(*storage_);
        if (grid)
            timer_.measure(Phase::Grid, [&] {
                passes_.grid(*storage_, source, parameters);
            });
        timer_.measure(Phase::Density, [&] {
            passes_.density(*storage_, source, parameters, grid);
        });
        timer_.measure(Phase::Force, [&] {
            passes_.force(*storage_, source, parameters, grid);
        });
        timer_.measure(Phase::Extrema, [&] {
            passes_.extrema(*storage_, source, parameters);
        });
        timer_.measure(Phase::Integration, [&] {
            passes_.integrate(*storage_, source, target);
        });
        source = target;
    }
    candidate_ = source;
    timer_.finish();
    fence();
    enqueueMs = std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - start).count();
}
```

Mỗi submit nhận 1–4 tick, không xếp backlog theo số frame bị chậm. GPU chưa xong thì submit trả về. Pause ngăn gửi công việc mới, không thể thu hồi compute đã gửi.

### 3. Poll không khóa event loop

ClientWaitSync dùng timeout bằng 0. Nếu chưa xong, hàm trả false và ứng dụng tiếp tục nhận sự kiện.

{/* snippet include/gpu/engine.hpp#poll-fence */}

```cpp title="include/gpu/engine.hpp — Poll không khóa event loop"
bool poll() {
    if (!pending())
        return false;
    const GLenum result = gl_.ClientWaitSync(fence_, 0, 0);
    if (result == GL_TIMEOUT_EXPIRED) {
        if (std::chrono::steady_clock::now() - submitted_ > std::chrono::seconds(5)) {
            stopped_ = true;
            fatalGpu("GPU batch exceeded five seconds; stopping without further GL calls");
        }
        return false;
    }
    if (result == GL_WAIT_FAILED) {
        stopped_ = true;
        fatalGpu("GPU fence failed; stopping without further GL calls");
    }
    if (!initializing_ && !timer_.ready()) {
        if (std::chrono::steady_clock::now() - submitted_ > std::chrono::seconds(5)) {
            stopped_ = true;
            fatalGpu("GPU timestamp result exceeded five seconds");
        }
        return false;
    }
    gl_.DeleteSync(fence_);
    fence_ = nullptr;
    const auto target = meta_.target;
    storage_->meta.read(&meta_, sizeof(meta_));
    meta_.target = target;
    completionMs = std::chrono::duration<double, std::milli>(std::chrono::steady_clock::now() - submitted_).count();
    if (meta_.flags != 0) {
        stopped_ = true;
        throw std::runtime_error("GPU transaction rejected; flags=" + std::to_string(meta_.flags));
    }
    if (!initializing_) {
        if (meta_.updated != model().count)
            throw std::runtime_error("Incomplete particle update");
        timing = timer_.read();
        modelTime += meta_.elapsed;
        ticks += meta_.ticks;
    }
    committed_ = candidate_;
    initializing_ = false;
    return true;
}
```

Sau năm giây chưa hoàn tất, ứng dụng dừng submit và báo lỗi. Đây không phải khả năng cưỡng chế hủy shader đang chạy trên driver; watchdog tiến trình ngoài vẫn cần thiết khi kiểm thử workload lớn. Cờ lỗi hoặc updated khác N không được swap bank.

### 4. Đổi cảnh mà không thay tài nguyên đang dùng

Yêu cầu reset được giữ lại cho tới khi hết pending. Kiểm limits và peak memory của old + new trước allocation; chỉ thay storage sau khi candidate đã được tạo thành công.

{/* snippet include/gpu/engine.hpp#reset-transaction */}

```cpp title="include/gpu/engine.hpp — Đổi cảnh mà không thay tài nguyên đang dùng"
void reset(Model model) {
    if (pending())
        throw std::logic_error("Wait for the pending transaction before reset");
    // Same-size resets reuse an idle bank; one million particles need no second allocation.
    const bool reuse = storage_ && model.count == storage_->model.count && model.cells == storage_->model.cells;
    std::size_t previous = 0;
    if (storage_ && !reuse)
        previous = plannedBytes(storage_->model);
    capabilities_.validateModel(model, previous);
    std::unique_ptr<Storage> candidate;
    Storage* work = nullptr;
    int targetBank = 0;
    if (reuse) {
        work = storage_.get();
        targetBank = (committed_ + 1) % 3;
    } else {
        candidate = std::make_unique<Storage>(gl_, model);
        work = candidate.get();
    }
    work->model = model;
    GpuMeta initial;
    if (model.preset == Preset::Obstacle)
        initial.body.w = 0.14f;
    work->meta.write(&initial, sizeof(initial));
    passes_.initialize(*work, targetBank);
    const bool grid = true;
    passes_.grid(*work, targetBank, parameters);
    passes_.density(*work, targetBank, parameters, grid);
    passes_.force(*work, targetBank, parameters, grid);
    passes_.extrema(*work, targetBank, parameters);
    gl_.check("Initialize water model");
    if (!reuse)
        storage_ = std::move(candidate);
    candidate_ = targetBank;
    meta_ = initial;
    modelTime = 0;
    ticks = 0;
    timing = {};
    enqueueMs = 0;
    completionMs = 0;
    stopped_ = false;
    initializing_ = true;
    fence();
}
```

Đặt lại cùng độ phân giải dùng một bank rảnh, không cấp phát lại cả bộ buffer. Nhờ vậy Reset vẫn hoạt động ở mốc một triệu hạt mà không cần nhân đôi bộ nhớ. Chỉ khi đổi kích thước dữ liệu mới cần kiểm peak old + new; nếu vượt budget, giữ state cũ và báo rõ thay vì xóa nó trước rồi mới phát hiện allocation thất bại.

## Ghép các phần lại

Gói ZIP trên trang tổng quan đã chứa đầy đủ file của mỗi checkpoint. Nếu muốn tự viết, bắt đầu từ bản cuối bài trước, thêm những phần vừa giải thích rồi đối chiếu bản dưới đây; không ghép các mảnh code thành một file main tùy ý.

```powershell title="Terminal — checkpoint 11"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_51_checkpoint_11 --parallel 1
.\build\Debug\project_51_checkpoint_11.exe
```

Trên Linux, dùng executable trong build thay cho thư mục Debug. Driver cần hỗ trợ OpenGL 4.3 compute; lỗi thiếu khả năng phải được báo rõ, không chuyển sang một animation giả.

## Thử làm sai để hiểu đúng

1. Trong C++, chạy rồi Pause, xoay camera và yêu cầu Reset giữa lúc GPU pending. Dự đoán Reset được thực hiện ngay hay phải chờ. Input vẫn phải được nhận, nhưng reset chỉ dùng buffer khi batch hữu hạn đã xong, sau đó đưa model time về 0.
2. Chuyển sang cửa sổ khác khi đang chạy rồi quay lại. Bể phải paused, drag đã kết thúc và benchmark đang chờ không tự khởi động lại. Reset cảnh trước khi so kết quả. Không tạo shader vô hạn để thử deadline.

Nếu fence hoặc timestamp vượt deadline, bản C++ kết thúc với mã lỗi 2, không gửi thêm GL work hoặc gọi cleanup GL có nguy cơ chờ driver. Hệ điều hành thu hồi tài nguyên tiến trình; đây không phải cơ chế thu hồi compute đã gửi hay bảo đảm driver sẽ phục hồi.

## Tự kiểm tra kết quả

Không dùng glFinish, không spin loop chờ query, không có hai simulation batch pending. Dữ liệu lỗi không được commit. Reset không đọc/ghi buffer đang bị GPU dùng. Đóng cửa sổ hoặc Esc phải kết thúc bình thường.

## Bài tập mở rộng

Trong một bản test riêng, cố ý đặt error flag trước integration và chứng minh committed bank không đổi. Không tạo shader vòng lặp vô hạn để thử watchdog: đó là ca có thể làm treo driver và không cần thiết để kiểm logic host.
