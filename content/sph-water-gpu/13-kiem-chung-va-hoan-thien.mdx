# Kiểm chứng rồi đóng gói bể nước hoàn chỉnh

## Vấn đề cần giải quyết

Bài cuối không thêm một hiệu ứng để che những chỗ chưa kiểm. Ta đối chiếu GPU với một đáp án CPU độc lập, chạy cảnh động ở mốc chuẩn rồi kiểm trải nghiệm của chương trình tải về. Ba phần này đều cần thiết: công thức, quy mô và khả năng sử dụng.

## Hiểu ý tưởng trước khi viết code

CPU double all-pairs chậm nhưng không phụ thuộc GPU CSR. Một ca nhỏ có thể bắt lỗi index, dấu lực và thứ tự pass; nó không chứng nhận hiệu năng hoặc chất lượng nước ở 110.592 hạt. Ngược lại, scale run chỉ chứng minh workload và thống kê của cảnh đã chạy, không chứng minh mô hình hội tụ về nghiệm vật lý chính xác.

Canvas là mô hình CPU phục vụ học tập, không phải ứng dụng GPU của bài. Thời gian mô phỏng được ghi riêng và có thể chạy chậm hơn thời gian thực. Chuyển chế độ hiển thị không thay đổi phương trình SPH.

## Viết code từng bước

### 1. So sánh trên cùng input, không cùng implementation

Verifier nạp cùng position/velocity float vào GPU rồi chuyển các giá trị ấy sang CPU double. CPU tự tính kernel, neighbors, pressure, viscosity và integration.

{/* snippet include/app/verification.hpp#independent-oracle */}

```cpp title="include/app/verification.hpp — So sánh trên cùng input, không cùng implementation"
inline void verifyGpu(Gl& gl, const std::filesystem::path& root) {
    Passes passes(gl, root);
    Capabilities limits(gl);
    for (int fixture = 0; fixture < 6; ++fixture) {
        std::uint32_t count = 512;
        if (fixture == 0)
            count = 2;
        if (fixture == 1)
            count = 64;
        if (fixture == 2)
            count = 257;
        if (fixture == 5)
            count = 257;
        Preset preset = Preset::Dam;
        if (fixture == 4)
            preset = Preset::Obstacle;
        int side = 8;
        if (fixture == 5)
            side = 100;
        auto model = makeModel(side, preset, count);
        limits.validateModel(model);
        Storage storage(gl, model);
        std::vector<Float4> positions(count), velocities(count);
        auto cpu = makeReference(model);
        Body body;
        body.enabled = preset == Preset::Obstacle;
        if (body.enabled)
            body.velocity = {.35, 0, 0};
        Parameters parameters;
        for (std::uint32_t i = 0; i < count; ++i) {
            Vec3 point = seedPoint(model, i);
            if (fixture == 3) {
                point = add(scale(point, .90), {.15, .03, .03});
            }
            if (fixture == 4) {
                point = add(point, {.50, .03, 0});
            }
            positions[i] = {static_cast<float>(point.x), static_cast<float>(point.y), static_cast<float>(point.z), 1};
            velocities[i] = {static_cast<float>(.05 * std::sin(i)), static_cast<float>(.03 * std::cos(i)), 0, 0};
            cpu.position[i] = {positions[i].x, positions[i].y, positions[i].z};
            cpu.velocity[i] = {velocities[i].x, velocities[i].y, velocities[i].z};
        }
        referenceFields(model, parameters, body, cpu);
        storage.banks[0].position.write(positions.data(), positions.size() * sizeof(Float4));
        storage.banks[0].velocity.write(velocities.data(), velocities.size() * sizeof(Float4));
        GpuMeta initial;
        if (body.enabled)
            initial.body.w = static_cast<float>(body.radius);
        initial.bodyVelocity = {static_cast<float>(body.velocity.x), static_cast<float>(body.velocity.y), static_cast<float>(body.velocity.z), 0};
        storage.meta.write(&initial, sizeof(initial));
        passes.grid(storage, 0, parameters);
        passes.density(storage, 0, parameters, true);
        passes.force(storage, 0, parameters, true);
        passes.extrema(storage, 0, parameters);
        waitFinite(gl);
        GpuMeta meta;
        storage.meta.read(&meta, sizeof(meta));
        if (meta.flags)
            throw std::runtime_error("Oracle grid flags=" + std::to_string(meta.flags));
        std::vector<DensityPressure> fields(count);
        std::vector<Float4> accelerations(count);
        storage.banks[0].field.read(fields.data(), fields.size() * sizeof(DensityPressure));
        storage.acceleration.read(accelerations.data(), accelerations.size() * sizeof(Float4));
        double rhoError = 0, pressureError = 0, forceError = 0;
        for (std::uint32_t i = 0; i < count; ++i) {
            rhoError = std::max(rhoError, std::abs(fields[i].density - cpu.density[i]));
            pressureError = std::max(pressureError, std::abs(fields[i].pressure - cpu.pressure[i]));
            const Vec3 actualAcceleration{accelerations[i].x, accelerations[i].y, accelerations[i].z};
            for (int axis = 0; axis < 3; ++axis)
                forceError = std::max(forceError, std::abs(actualAcceleration[axis] - cpu.acceleration[i][axis]) / (1 + std::abs(cpu.acceleration[i][axis])));
        }
        if (rhoError > .05 || pressureError > 25 || forceError > .003)
            throw std::runtime_error("CPU/GPU oracle mismatch: rho=" + std::to_string(rhoError) + " p=" + std::to_string(pressureError) + " force=" + std::to_string(forceError));
        passes.density(storage, 0, parameters, false);
        passes.force(storage, 0, parameters, false);
        waitFinite(gl);
        std::vector<DensityPressure> pairs(count);
        std::vector<Float4> pairForces(count);
        storage.banks[0].field.read(pairs.data(), pairs.size() * sizeof(DensityPressure));
        storage.acceleration.read(pairForces.data(), pairForces.size() * sizeof(Float4));
        for (std::uint32_t i = 0; i < count; ++i) {
            if (std::abs(pairs[i].density - fields[i].density) > .05 || length(subtract({pairForces[i].x, pairForces[i].y, pairForces[i].z}, {accelerations[i].x, accelerations[i].y, accelerations[i].z})) > .2)
                throw std::runtime_error("GPU CSR differs from GPU all-pairs");
        }
        const double dt = referenceTimestep(model, parameters, cpu);
        if (std::abs(meta.dt - dt) > 1e-7)
            throw std::runtime_error("Adaptive dt differs from CPU reduction");
        std::vector<std::uint32_t> offsets(model.cellCount + 1), ids(count);
        storage.offsets.read(offsets.data(), offsets.size() * sizeof(std::uint32_t));
        storage.indices.read(ids.data(), ids.size() * sizeof(std::uint32_t));
        if (offsets.front() != 0 || offsets.back() != count || !std::is_sorted(offsets.begin(), offsets.end()))
            throw std::runtime_error("Invalid CSR offsets");
        // A permutation alone is insufficient: each ID must also belong to its recorded cell.
        for (std::uint32_t cell = 0; cell < model.cellCount; ++cell) {
            for (auto slot = offsets[cell]; slot < offsets[cell + 1]; ++slot) {
                const auto id = ids[slot];
                if (id >= count)
                    throw std::runtime_error("CSR contains an out-of-range ID");
                const Vec3 point{positions[id].x, positions[id].y, positions[id].z};
                std::array<int, 3> coordinate{};
                for (int axis = 0; axis < 3; ++axis)
                    coordinate[axis] = std::clamp(static_cast<int>(std::floor(point[axis] / (2 * model.h))), 0, model.cells[axis] - 1);
                const auto expected = static_cast<std::uint32_t>(coordinate[0] + model.cells[0] * (coordinate[1] + model.cells[1] * coordinate[2]));
                if (expected != cell)
                    throw std::runtime_error("CSR ID belongs to another cell");
            }
        }
        std::sort(ids.begin(), ids.end());
        for (std::uint32_t i = 0; i < count; ++i)
            if (ids[i] != i)
                throw std::runtime_error("CSR is not a permutation");
        passes.integrate(storage, 0, 1);
        waitFinite(gl);
        storage.meta.read(&meta, sizeof(meta));
        if (meta.flags || meta.updated != count)
            throw std::runtime_error("Incomplete oracle integration");
        Body endBody = body;
        endBody.position = add(body.position, scale(body.velocity, dt));
        referenceIntegrate(model, endBody, cpu, dt);
        storage.banks[1].position.read(positions.data(), positions.size() * sizeof(Float4));
        storage.banks[1].velocity.read(velocities.data(), velocities.size() * sizeof(Float4));
        double positionError = 0, velocityError = 0;
        for (std::uint32_t i = 0; i < count; ++i) {
            positionError = std::max(positionError, length(subtract({positions[i].x, positions[i].y, positions[i].z}, cpu.position[i])));
            velocityError = std::max(velocityError, length(subtract({velocities[i].x, velocities[i].y, velocities[i].z}, cpu.velocity[i])));
        }
        if (positionError > 2e-5 || velocityError > .002)
            throw std::runtime_error("Integration differs from independent CPU oracle");
        std::cout << "ORACLE PASS fixture=" << fixture << " N=" << count << " rhoAbs=" << rhoError << " pressureAbs=" << pressureError << " forceScaled=" << forceError << " position=" << positionError << " velocity=" << velocityError << '\n';
    }
    verifyResetReuse(gl, root);
    verifyWaterSurface(gl, root);
}
```

Sáu fixture có tail 257, khối nén có pressure khác 0, vận tốc tương đối, vật cản và sparse grid đủ lớn cho scan nhiều tầng. GPU CSR còn được so với GPU all-pairs. Không chỉ so density của một lattice đứng yên.

### 2. Giữ reference không phụ thuộc CSR

Đọc lại vòng all-pairs: không gọi GPU grid hoặc dùng indices GPU để tạo đáp án. Nếu cả hai đường cùng dùng một danh sách sai, phép so sánh sẽ bỏ sót lỗi.

{/* snippet include/fluid/reference.hpp#reference-force */}

```cpp title="include/fluid/reference.hpp — Giữ reference không phụ thuộc CSR"
for (std::uint32_t i = 0; i < model.count; ++i) {
    Vec3 acceleration{0, -parameters.gravity, 0};
    for (std::uint32_t j = 0; j < model.count; ++j) {
        if (i == j)
            continue;
        const Vec3 displacement = subtract(state.position[i], state.position[j]);
        if (length(displacement) >= 2 * model.h)
            continue;
        const double viscosity = artificialViscosity(displacement, subtract(state.velocity[i], state.velocity[j]), state.density[i], state.density[j], model, parameters);
        const double pressureTerm = state.pressure[i] / (state.density[i] * state.density[i]) + state.pressure[j] / (state.density[j] * state.density[j]);
        acceleration = add(acceleration, scale(kernelGradient(displacement, model.h), -model.mass * (pressureTerm + viscosity)));
    }
    for (const auto& sample : boundarySamples(model, state.position[i], body)) {
        const Vec3 displacement = subtract(state.position[i], sample.position);
        const double viscosity = artificialViscosity(displacement, subtract(state.velocity[i], sample.velocity), state.density[i], referenceDensity, model, parameters);
        const double pressureTerm = state.pressure[i] / (state.density[i] * state.density[i]) + state.pressure[i] / (referenceDensity * referenceDensity);
        acceleration = add(acceleration, scale(kernelGradient(displacement, model.h), -model.mass * (pressureTerm + viscosity)));
    }
    state.acceleration[i] = acceleration;
}
```

Tolerance nằm trong verifier: rho tuyệt đối 0,05 kg/m³, pressure 25 Pa, force scaled 0,003, position 2e−5 m và velocity 0,002 m/s. Không tăng tolerance chỉ để làm ca đỏ thành xanh; phải xác định nguyên nhân.

### 3. Kiểm một bước từ state cũ

Reference cập nhật velocity trước rồi position, dùng cùng contact model. So sánh GPU sau fence, không đọc lúc shader còn ghi.

{/* snippet include/fluid/reference.hpp#integrate */}

```cpp title="include/fluid/reference.hpp — Kiểm một bước từ state cũ"
for (std::uint32_t i = 0; i < model.count; ++i) {
    state.velocity[i] = add(state.velocity[i], scale(state.acceleration[i], dt));
    state.position[i] = add(state.position[i], scale(state.velocity[i], dt));
    collide(model, body, state.position[i], state.velocity[i]);
}
```

Kiểm acceleration trước integration giúp tách lỗi force khỏi lỗi dt/contact. Một vị trí cuối gần đúng có thể che hai sai số bù trừ nhau, nên cần kiểm từng tầng.

### 4. Lưu thống kê có thể đối chiếu

Báo cáo ghi N thực tế, model time, mass, density extrema, leakage/invalid và profiler từng pass. Nó không chứa một nhãn PASS thay cho các số đo.

{/* snippet include/app/report.hpp#report */}

```cpp title="include/app/report.hpp — Lưu thống kê có thể đối chiếu"
inline void writeReport(const Engine& e, const std::filesystem::path& file) {
    std::ostream* output = &std::cout;
    std::ofstream stream;
    if (!file.empty()) {
        stream.open(file);
        if (!stream)
            throw std::runtime_error("Cannot write report");
        output = &stream;
    }

    auto& out = *output;
    out << std::setprecision(10);
    out << "{\n";
    out << "  \"count\": " << e.model().count << ",\n";
    out << "  \"allocated\": " << e.model().count << ",\n";
    out << "  \"alive\": " << e.model().count << ",\n";
    out << "  \"updated\": " << e.meta().updated << ",\n";
    out << "  \"drawn\": " << e.model().count << ",\n";
    out << "  \"modelTime\": " << e.modelTime << ",\n";
    out << "  \"ticks\": " << e.ticks << ",\n";
    out << "  \"dt\": " << e.meta().dt << ",\n";
    out << "  \"massKg\": " << e.model().count * static_cast<double>(e.model().mass) << ",\n";
    out << "  \"rhoMin\": " << e.meta().minimumDensity << ",\n";
    out << "  \"rhoMax\": " << e.meta().maximumDensity << ",\n";
    out << "  \"leakage\": " << e.meta().leakage << ",\n";
    out << "  \"invalid\": " << e.meta().invalid << ",\n";
    out << "  \"flags\": " << e.meta().flags << ",\n";
    out << "  \"simulationBufferEstimate\": " << plannedBytes(e.model()) << ",\n";
    out << "  \"gpuBatchMs\": " << e.timing.total << ",\n";
    out << "  \"enqueueMs\": " << e.enqueueMs << ",\n";
    out << "  \"completionMs\": " << e.completionMs << ",\n";

    out << "  \"passesMs\": {";
    for (std::size_t i = 0; i < 5; ++i) {
        if (i > 0)
            out << ", ";
        out << '"' << phaseNames[i] << "\": " << e.timing.milliseconds[i];
    }
    out << "}\n}\n";
}
```

Density được đo ở đầu tick cuối của batch, còn position đã tới cuối tick. Khi phân tích từng bước, phải nhớ sự lệch thời điểm này. Mass là N × mass mỗi hạt, không phải một con số cố định được in sẵn.

## Thử làm sai để hiểu đúng

1. Chạy --verify với N nhỏ, rồi trong bản nháp chỉ sửa dấu gradient ở shader. Dự đoán nhóm sai số sẽ tăng: density có thể còn khớp nhưng force/integration phải bị phát hiện. Khôi phục shader và yêu cầu mọi fixture PASS; đừng nới tolerance để làm mất thông báo lỗi.
2. Chạy riêng --time 0.30 ở mốc chuẩn, kiểm báo cáo và ảnh tại thời điểm mô hình ấy, rồi thử Orbit/Move obstacle, Pause/Step/Reset, N, debug và benchmark/cancel. Oracle nhỏ PASS không thay ca 110.592 hạt; ảnh đẹp cũng không chứng minh phép tính đúng. Không chạy các ca GPU nặng đồng thời.

## Tự kiểm tra kết quả

Build starter, 13 checkpoint và final; chạy CTest ở Debug/Release. `--verify` còn chạy `verifyWaterSurface` trong `include/app/surface-verification.hpp`: một fixture 80 × 80 đi qua đúng shader và RG framebuffer trên GPU. Depth phẳng phải giữ nguyên; thickness checker phải về trung bình 0,2 ở vùng trong; pixel rỗng vẫn rỗng và bước nhảy depth 2→4 không bị trộn. GPU readback này chỉ nằm trong verifier, không được đưa vào vòng render thông thường.

ZIP phải chứa README, source, shader, tests và CMake, không chứa SDL tải về, build tree hay binary. Mã trong bài phải khớp marker của đúng checkpoint. Sau các phép kiểm số, vẫn phải xem cảnh Pool/Dam/Obstacle đang chạy và thử tương tác. PASS tự động không chứng minh nước đã nhìn tự nhiên ở mọi góc.

## Bài tập mở rộng

Nếu muốn nâng cao, đo hydrostatic error theo độ sâu, convergence khi giảm spacing hoặc coupling hai chiều với vật rắn. Không đưa những mở rộng ấy vào nhãn đã hoàn thành trước khi có phép kiểm riêng. Tiếp theo là Project 52: dùng ray để tìm điểm chạm trên hình học 3D.

```powershell title="Terminal — kiểm bản hoàn chỉnh, từng lệnh riêng"
cmake --build build --config Debug --parallel 1
ctest --test-dir build -C Debug --output-on-failure --timeout 30
cmake --build build --config Release --parallel 1
ctest --test-dir build -C Release --output-on-failure --timeout 30
.\build\Release\project_51_final.exe --verify --hidden
.\build\Release\project_51_final.exe --time 0.30 --seconds 120 --report scale.json --capture water.bmp
.\build\Release\project_51_final.exe --benchmark --seconds 60
```

Không chạy đồng thời các lượt GPU. --seconds là deadline của chương trình, không phải bảo đảm có thể thu hồi lệnh đang chạy trong driver. File tests dùng checks vẫn hoạt động khi NDEBUG được bật. Bản nhỏ PASS không chứng nhận solver nước đã hội tụ; bản 100.000 hạt PASS cũng không chứng nhận mốc một triệu hạt.
