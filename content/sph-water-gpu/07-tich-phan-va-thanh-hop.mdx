# Cho khối nước chuyển động mà không ghi đè state

## Vấn đề cần giải quyết

Đến đây force đã được tính xong, nhưng hạt vẫn đứng yên. Ta thêm gravity và integrate. Đây là lúc sai lầm ghi position ngay tại chỗ có thể làm kết quả phụ thuộc lịch chạy invocation.

## Hiểu ý tưởng trước khi viết code

Semi-implicit Euler cập nhật vNew=vOld+dt*a, rồi xNew=xOld+dt*vNew. Toàn bộ force đọc state cũ; integration ghi bank khác. Hộp có sáu mặt, mỗi mặt chỉ phản xạ velocity normal đang hướng ra ngoài.

Collision là boundary đơn giản: nó giữ hạt trong hộp, không bù support kernel. Density gần thành vẫn có thể sai; không gọi collision là hydrostatic boundary SPH.

$$
\mathbf v_{\mathrm{new}}=\mathbf v_{\mathrm{old}}+\Delta t\,\mathbf a_{\mathrm{old}},\qquad
\mathbf x_{\mathrm{new}}=\mathbf x_{\mathrm{old}}+\Delta t\,\mathbf v_{\mathrm{new}}.
$$

Bấm 20 tick để nhìn displacement rõ hơn, rồi đọc time/dt. Đây là thời gian mô phỏng, không phải 20 frame. Hạt ban đầu đứng yên nhận gravity; phần pressure chỉ xuất hiện khi density cao hơn rho0.

## Viết code từng bước

### Bước 1 — Integrate cùng thứ tự trên CPU

Reference dùng ba thành phần độc lập:

{/* snippet include/reference.hpp#reference-integration */}
```cpp title="include/reference.hpp — semi-implicit Euler"
inline void integrate(Vec3& position, Vec3& velocity, Vec3 acceleration, double dt, double radius) {
    velocity.x += dt * acceleration.x;
    velocity.y += dt * acceleration.y;
    velocity.z += dt * acceleration.z;
    position.x += dt * velocity.x;
    position.y += dt * velocity.y;
    position.z += dt * velocity.z;
    collide(position.x, velocity.x, radius);
    collide(position.y, velocity.y, radius);
    collide(position.z, velocity.z, radius);
}
```

Không dùng velocity cũ ở ba dòng position; đó là integrator khác. Dt chỉ nhân ở integration, không nhân thêm trong force.

### Bước 2 — Đọc cũ, ghi mới trên GPU

Viết `main` của `integrate.comp`. Nó đọc current bank và ghi `nextPositions/nextVelocities`; vòng lặp ba trục xử lý đủ sáu mặt hộp:

{/* snippet shaders/integrate.comp#integrate-particles */}
```glsl title="shaders/integrate.comp — GLSL bank mới"
void main() {
    uint i = gl_GlobalInvocationID.x;
    if (i >= uCount)
        return;
    float dt = 0.0005;
    vec3 velocity = velocities[i].xyz + dt * acceleration[i].xyz;
    vec3 position = positions[i].xyz + dt * velocity;
    for (int axis = 0; axis < 3; axis++) {
        float radius = uSpacing / 2.0;
        if (position[axis] < radius) {
            position[axis] = radius;
            if (velocity[axis] < 0.0)
                velocity[axis] *= -0.1;
        }
        if (position[axis] > 1.0 - radius) {
            position[axis] = 1.0 - radius;
            if (velocity[axis] > 0.0)
                velocity[axis] *= -0.1;
        }
    }
    nextPositions[i] = vec4(position, 1.0);
    nextVelocities[i] = vec4(velocity, 0.0);
}
```

`radius=spacing/2` là khoảng cách tâm tối thiểu tới thành, không phải bán kính support `2h` hoặc bán kính sphere dùng để vẽ. Collision chỉ phản xạ thành phần vận tốc hướng ra ngoài; hai thành phần tiếp tuyến giữ nguyên. Đây là va chạm giải tích, không bổ sung hạt tường cho tổng SPH.

Engine nối pass vào cuối batch, sau khi lực của **mọi hạt** đã được tính. Đọc binding dưới đây từ trái sang phải: current position/velocity, acceleration, next position/velocity. `statsRoot` chưa được shader checkpoint 7 dùng; nó phục vụ adaptive dt ở Bài 09.

{/* snippet include/engine.hpp#integrate-pass */}
```cpp title="include/engine.hpp — input cũ và output mới"
use(gl, programs.integrate, storage.plan, settings, grid);
bind(gl, 0, storage.positions[current]);
bind(gl, 1, storage.velocities[current]);
bind(gl, 2, storage.acceleration);
bind(gl, 3, storage.positions[1 - current]);
bind(gl, 4, storage.velocities[1 - current]);
bind(gl, 5, statsRoot);
dispatch(gl, storage.plan.count);
queue.mark(gl, "Integration");
```

Không alias hai bank; SSBO barrier không thể chữa lỗi khi một hạt ghi đè state mà hạt khác còn đọc.

### Bước 3 — Commit sau khi batch xong

Trong Engine.poll, chỉ chạy đoạn này sau fence:

{/* snippet include/engine.hpp#bank-commit */}
```cpp title="include/engine.hpp — commit state đã hoàn tất"
current = 1 - current;
++steps;
time += lastDt;
```

Nếu bước thất bại, không đổi current. GPU không quyết định bank từ frame parity; host giữ ownership và view đọc đúng bank đã commit.

## Ghép các phần lại

Checkpoint 7 dùng dt cố định 0.0005 s và N cho một tick. Khối nằm sát đáy; gravity kéo các hàng phía trên xuống, compression tạo pressure và khối dần lan ra. Tâm hạt được giữ trong [spacing/2,1−spacing/2]. Một tick chỉ là nửa mili giây mô hình nên chuyển động ban đầu rất nhỏ: dùng 20 tick trên Canvas và đọc time, không tăng dt để ép hình chạy nhanh. Workload C++ vẫn≤512; Bài 09 mới chọn dt thích nghi cho hệ lớn.

## Thử làm sai để hiểu đúng

1. Bind current vào cả input/output. So hai lần chạy cùng state: thứ tự đọc/ghi có thể đổi force; khôi phục bank khác.
2. Luôn nhân velocity normal với−0.1, kể cả khi nó đang đi vào hộp. Hạt sát thành có thể bị quay ngược không đúng; kiểm dấu hướng ra.

## Tự kiểm tra kết quả

Gravity-only có vy=−g*dt ở tick đầu. Collision không đổi tangent. Mỗi tick tăng steps đúng một và chỉ đổi current sau fence. Camera không ảnh hưởng trajectory.
