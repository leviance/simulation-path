# Nối ba điểm thành tam giác 3D

## Vấn đề cần giải quyết

Ở P11 ta đã đưa một point 3D tới đúng vị trí trên màn hình. Bây giờ hãy giữ lại phép chiếu đó, thêm hai point nữa và nối thành tam giác. Chưa cần quay ngay: trước hết phải thấy được ba đỉnh, ba cạnh và cảnh nền có chiều sâu.

Tải ZIP ở trang tổng quan, giải nén rồi mở thư mục có CMakeLists.txt. Starter đã có framebuffer, putPixel, drawLine, window/renderer/texture và projection từ P11. Chạy project_12_starter trước: cửa sổ chỉ có sàn lưới cùng các khung world ở depth 4/8/12. Ta sẽ vẽ tam giác lên nền ấy.

## Hiểu ý tưởng trước khi viết code

Triangle3 chỉ là ba Vec3. Chúng vẫn là world coordinates, chưa phải pixel:

- A=(-1.4,-0.9,5.7)
- B=(1.3,-0.7,6.4)
- C=(0.1,1.6,5.9)

Camera nhìn +Z, Y hướng lên. Mỗi đỉnh đi qua worldToCamera, guard near/far, perspective divide rồi NDC→screen như P11. Ba cạnh là AB, BC, CA; cạnh cuối phải nối trở về A.

Có hai việc khác nhau: projectTriangle cho biết **từng đỉnh** có visible hay không; line3D cắt và chiếu **từng đoạn cạnh**. Một đỉnh ngoài frustum không có nghĩa mọi cạnh đều mất. Đây là lý do ta giữ cả world triangle lẫn projection result, không chỉ ba pixel rồi vứt dữ liệu 3D.

### Bước 1 — Lưu ba đỉnh bằng dữ liệu world

```cpp title="include/lab.hpp — tam giác chưa chứa tọa độ screen"
struct Triangle3 {
    Vec3 a{};
    Vec3 b{};
    Vec3 c{};
};
```

```cpp title="include/lab.hpp — ba đỉnh đặt trước camera"
inline Triangle3 defaultWorldTriangle() {
    return {{-1.4, -0.9, 5.7}, {1.3, -0.7, 6.4}, {0.1, 1.6, 5.9}};
}
```

Các số có Z khác nhau để ngay từ hình đứng yên bạn đã có một tam giác nằm trong không gian, không chỉ hình phẳng được gắn một nhãn “3D”.

### Bước 2 — Chiếu từng đỉnh và giữ status

```cpp title="include/lab.hpp — không biến đỉnh bị loại thành pixel giả"
inline TriangleProjection projectTriangle(const Triangle3& triangle, const Camera3D& camera, const PerspectiveLens& lens, const Viewport& viewport) {
    TriangleProjection result;
    result.vertices = {projectPerspective(triangle.a, camera, lens, viewport), projectPerspective(triangle.b, camera, lens, viewport), projectPerspective(triangle.c, camera, lens, viewport)};
    result.allVisible = true;
    for (const auto& vertex : result.vertices) {
        if (vertex.status != ProjectionStatus::Visible) {
            result.allVisible = false;
        }
    }
    return result;
}
```

result.vertices giữ đủ ba ProjectionResult từ P11. allVisible là số đo tổng hợp để đọc debug, **không** phải điều kiện xóa cả hình. Đỉnh bị near/behind loại sẽ không có screen, còn outside vẫn có số chiếu hữu hạn.

### Bước 3 — Nối cạnh và đưa ảnh lên SDL

```cpp title="include/view.hpp — cạnh world được clip trước raster"
inline void line3D(Framebuffer& image, Vec3 start, Vec3 end, const Scene& scene, std::uint32_t color) {
    start = worldToCamera(start, scene.camera);
    end = worldToCamera(end, scene.camera);
    if (!clipDepth(start, end, scene.lens)) {
        return;
    }
    const Camera3D origin{};
    const auto a = projectPerspective(start, origin, scene.lens, viewportFor());
    const auto b = projectPerspective(end, origin, scene.lens, viewportFor());
    if (!a.screen || !b.screen) {
        return;
    }
    Vec2 from = *a.screen;
    Vec2 to = *b.screen;
    if (clipScreen(from, to, viewportFor())) {
        drawLine(image, static_cast<int>(std::lround(from.x)), static_cast<int>(std::lround(from.y)), static_cast<int>(std::lround(to.x)), static_cast<int>(std::lround(to.y)), color);
    }
}
```

Hàm này kế thừa P11: đổi cả hai đầu sang camera space, clip depth, chiếu rồi clip screen, cuối cùng mới làm tròn để gọi Bresenham. Khi project một endpoint camera-space, ta dùng camera origin để không trừ camera.position lần nữa.

```cpp title="include/view.hpp — AB, BC, CA là ba lời gọi rõ ràng"
inline void drawProjectedTriangle(Framebuffer& image, const Triangle3& world, const TriangleProjection& projection, const Scene& scene) {
    line3D(image, world.a, world.b, scene, 0xFFB454FFu);
    line3D(image, world.b, world.c, scene, kShape);
    line3D(image, world.c, world.a, scene, kAxisY);
    if (scene.debug) {
        for (const auto& vertex : projection.vertices) {
            if (vertex.status == ProjectionStatus::Visible && vertex.screen) {
                marker(image, *vertex.screen, kWhite);
            }
        }
    }
}
```

Marker trắng chỉ vẽ khi endpoint visible. Các cạnh vẫn được xét riêng, nên preset cắt near có thể giữ lại phần nhìn thấy của chúng.

## Ghép các phần lại

renderScene vẽ nền trước, dựng world triangle rồi chiếu và nối các cạnh. Chưa có rotation; scene.position chỉ dịch cả tam giác. Giữ phần upload từ Starter:

```cpp title="src/main.cpp — upload framebuffer sau khi vẽ"
if (dirty) {
    lab::renderScene(image, scene);
    if (!SDL_UpdateTexture(texture, nullptr, image.pixels.data(), lab::Framebuffer::width * static_cast<int>(sizeof(std::uint32_t))) || !lab::presentFramebuffer(renderer, texture, scene)) {
        std::cerr << SDL_GetError() << '\n';
        failed = true;
        break;
    }
    dirty = false;
}
```

Build checkpoint 1. AB màu cam, BC xanh lá, CA xanh lam; ba marker trắng nằm ở đầu cạnh. Mũi tên dịch XY, PageUp/Down dịch Z từng nấc 0.1 world. R về trạng thái đầu, Esc thoát. Resize letterbox bảng logic 1100×800, không tự kéo dãn hình.

## Thử làm sai để hiểu đúng

1. Bỏ cạnh CA. Hình chỉ còn hai đoạn dù ba marker vẫn đủ. Khôi phục và kiểm đường khép kín trước khi thêm rotation.

2. Chọn Cắt near. A có camera Z=0.4, trước near 0.5. Kiểm status A, rồi quan sát phần cạnh còn trong khung; không dùng allVisible=false để xóa toàn bộ hình.

3. Thay một Z bằng 0 trong một bản sao. Point phải bị guard loại trước chia, không được tạo pixel Inf rồi đưa vào drawLine.

## Tự kiểm tra kết quả

- Starter chạy được và chỉ có nền; checkpoint 1 thêm tam giác rõ ràng.
- Ba cạnh đúng AB/BC/CA, giữ world point riêng với screen result.
- Endpoint không visible không tạo marker giả.
- Cạnh được cắt ở near/far và viewport, không làm rasterizer chạy vô hạn.
- Model đi xa thì hình thu hẹp theo perspective, không chỉ đổi size marker.
