# Quay quanh X bằng sin và cos

## Vấn đề cần giải quyết

Giờ mới đến rotation đầu tiên. Ta chỉ quay quanh X, chưa ghép yaw/roll, để kiểm từng dấu sin/cos bằng một ví dụ thật đơn giản. Pipeline local→world đã có sẵn nên không cần dựng lại vòng lặp SDL.

## Hiểu ý tưởng trước khi viết code

Nhìn dọc trục X, hai thành phần còn lại là một vector 2D trên mặt phẳng YZ. Viết y=r cosφ, z=r sinφ. Quay thêm θ rồi khai triển công thức cộng góc:

$$
x'=x,\quad y'=y\cos\theta-z\sin\theta,\quad
z'=y\sin\theta+z\cos\theta.
$$

Dương quanh X đưa +Y về +Z theo quy tắc bàn tay phải. Vì camera nhìn +Z nên một chuyển động có Z lớn hơn là đi sâu vào cảnh, không phải đi lên trên screen. Đừng suy dấu chỉ từ ảnh chiếu.

Với point (1,2,3) và θ=π/2, cos=0, sin=1 nên kết quả (1,-3,2). X không đổi; y²+z² cũng không đổi. Đây là oracle biết trước, không cần dùng inverse để sinh expected.

### Bước 1 — Tính từ dữ liệu cũ, trả Vec3 mới

```cpp title="include/lab.hpp — quay cặp YZ, giữ X"
inline Vec3 rotateX(Vec3 point, double angle) {
    const double cosine = std::cos(angle);
    const double sine = std::sin(angle);
    return {point.x, cosine * point.y - sine * point.z, sine * point.y + cosine * point.z};
}
```

Không ghi point.y trước rồi dùng point.y đã đổi để tính Z. Trả một Vec3 mới giúp cả hai công thức đọc cùng tọa độ đầu vào.

### Bước 2 — Áp dụng cùng góc cho ba vertex

```cpp title="include/lab.hpp — không quay dồn kết quả frame trước"
inline Triangle3 rotateTriangleX(const Triangle3& triangle, double angle) {
    return {rotateX(triangle.a, angle), rotateX(triangle.b, angle), rotateX(triangle.c, angle)};
}
```

Đầu vào là localTriangle gốc, không phải rotatedLocal vừa vẽ ở frame trước. Nhờ vậy kéo về góc 0 phục hồi hình thay vì giữ lại lỗi tích lũy.

### Bước 3 — Chèn vào giữa local và translation

```cpp title="include/scene.hpp — localTriangle → rotateTriangleX → translate"
inline Triangle3 worldTriangle(const Scene& scene) {
    const Triangle3 localTriangle = toLocalTriangle(defaultWorldTriangle());
    Triangle3 rotatedLocal = localTriangle;
    rotatedLocal = rotateTriangleX(localTriangle, scene.angles.pitch);
    return translateTriangle(rotatedLocal, scene.position);
}
```

```cpp title="src/main.cpp — W/S thay góc theo nấc 5 độ"
const double angleStep = 5.0 * lab::kPi / 180.0;
if (event.key.key == SDLK_W) {
    scene.angles.pitch = lab::wrapAngle(scene.angles.pitch + angleStep);
    scene.paused = true;
}
if (event.key.key == SDLK_S) {
    scene.angles.pitch = lab::wrapAngle(scene.angles.pitch - angleStep);
    scene.paused = true;
}
```

Hàm toán nhận radian. Chỉ khối input đổi 5° sang radian. Đây là thao tác chỉnh góc theo nấc, không phải mô phỏng angular velocity; đến bài 7 ta mới dùng dt cho tự quay.

## Ghép các phần lại

Build checkpoint 3, dùng W/S hoặc slider pitch. Ghost xám là hình chưa quay ở cùng model position để so trước/sau; tam giác màu vẫn quay tại pivot đỏ.

Mỗi frame worldTriangle(scene) lấy lại local gốc, rotateTriangleX rồi translate. Đổi góc không làm modelPosition tự đi một vòng. Hàm wrapAngle chỉ giữ số góc trong [-π,π]; nó không chặn tam giác lật qua mặt sau.

## Thử làm sai để hiểu đúng

1. Đổi dấu trừ thành dấu cộng ở y′. Point (1,2,3), X90 sẽ không còn ra (1,-3,2), và norm có thể đổi. Khôi phục trước khi dựa vào hình để nhận xét.

2. Quay world vertex thay vì local vertex. Pivot đang ở Z=6 sẽ rời vị trí; đây là orbit quanh world origin, không phải xoay tại chỗ. Đưa rotation về trước translation.

3. Ghi y′ vào point.y rồi tính z′ từ point.y mới. Kiểm y²+z² để bắt lỗi, sau đó trả Vec3 từ input bất biến.

## Tự kiểm tra kết quả

- X90 của (1,2,3) đúng (1,-3,2).
- X giữ nguyên; norm và ba độ dài cạnh không đổi trong sai số.
- Góc 0 và 2π đưa hình về gần trạng thái cũ.
- Pivot/model position không đổi khi chỉ sửa pitch.
- Ghost chưa quay và hình quay là hai kết quả khác nhau, không sửa local gốc.
