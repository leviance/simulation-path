# Chuẩn hóa normal và đo diện tích

## Vấn đề cần giải quyết

Raw normal đã vuông góc với tam giác, nhưng độ dài của nó tăng khi tam giác lớn lên. Nếu dùng raw normal làm hướng chiếu sáng hoặc hướng mặt, hai tam giác song song có kích thước khác nhau sẽ cho kết quả khác nhau. Ta cần tách **hướng** thành unit normal có độ dài 1 và giữ **độ lớn** để tính diện tích.

Trường hợp raw normal bằng zero cũng bắt đầu xuất hiện. Chia zero vector cho độ dài 0 sẽ tạo NaN, rồi các giá trị đó lan sang phép chiếu và tọa độ pixel. Vì vậy `normalize` phải có đường thoát an toàn ngay từ khi được viết.

## Hiểu ý tưởng trước khi viết code

Độ dài vector 3D vẫn đến từ dot product với chính nó:

$$
\lVert v\rVert=\sqrt{v\cdot v}=\sqrt{x^2+y^2+z^2}
$$

Với vector đủ dài:

$$
\hat v=\frac{v}{\lVert v\rVert}
$$

Cross product còn cho biết diện tích. Hai cạnh AB và AC dựng thành một hình bình hành có diện tích $\lVert AB\times AC\rVert$. Tam giác chiếm một nửa:

$$
Area=\frac{1}{2}\lVert AB\times AC\rVert
$$

## Viết code từng bước

### Bước 1 — Xây magnitude từ dot product

Viết `dot` trước giúp công thức độ dài ngắn và dùng lại được trong bài winding.

```cpp title="include/lab.hpp — dot và magnitude của Vec3"
inline double dot(Vec3 left, Vec3 right) {
    return left.x * right.x + left.y * right.y + left.z * right.z;
}

inline double magnitude(Vec3 vector) {
    return std::sqrt(dot(vector, vector));
}
```

`dot(vector,vector)` không âm về mặt toán học. Ta dùng `double` để các kiểm tra gần zero ở bài cuối có đủ độ chính xác.

### Bước 2 — Normalize có xử lý zero vector

Không viết `return scale(vector,1.0/magnitude(vector))` trên một dòng. Tách `length` ra giúp kiểm tra điều kiện trước phép chia.

```cpp title="include/lab.hpp — normalize không sinh NaN"
inline Vec3 normalize(Vec3 vector, double epsilon = 1e-9) {
    const double length = magnitude(vector);
    if (length <= epsilon) {
        return {};
    }
    return scale(vector, 1.0 / length);
}
```

Zero vector trả về ở đây là một giá trị số an toàn, không phải một normal hợp lệ. UI sẽ chịu trách nhiệm báo “degenerate” thay vì vẽ nó như một hướng thật.

### Bước 3 — Đặt tên rõ cho unit normal và diện tích

Hai hàm đều lấy raw normal từ ba point hiện tại:

```cpp title="include/lab.hpp — hướng normal và diện tích"
inline Vec3 triangleUnitNormal(const Triangle& triangle) {
    return normalize(triangleRawNormal(triangle));
}

inline double triangleArea(const Triangle& triangle) {
    return magnitude(triangleRawNormal(triangle)) * 0.5;
}
```

Không cần công thức Heron hay đo cạnh trong screen space. Diện tích này nằm trong world space 3D và không phụ thuộc vào góc nhìn của sơ đồ.

### Bước 4 — Chỉ scale unit normal ở lúc vẽ

Checkpoint 4 thay raw normal bằng unit normal rồi nhân chiều dài mũi tên cố định:

```cpp title="src/main.cpp — mũi tên dùng hướng đã chuẩn hóa"
const lab::Vec3 displayNormal = lab::scale(lab::triangleUnitNormal(triangle), 1.35);
const lab::Vec3 endpoint = lab::add(centroid, displayNormal);
drawWorldLine(pixels, width, height, centroid, endpoint, rgba(196, 132, 255));
```

Giá trị `1.35` là kích thước minh họa. Unit normal trong `lab.hpp` vẫn dài 1 và có thể dùng cho các phép toán khác.
