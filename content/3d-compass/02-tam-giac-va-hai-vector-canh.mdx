# Vẽ tam giác và hai vector cạnh

## Vấn đề cần giải quyết

Ta đã nhìn thấy ba trục. Giờ thêm một tam giác và hai vector xuất phát từ cùng điểm để chuẩn bị cho cross product. Chưa vẽ normal ở bài này; cần kiểm hai đầu vào trước.

## Hiểu ý tưởng trước khi viết code

Để không lẫn tên điểm với tên vector, ta gọi các đỉnh là P0/P1/P2. Hai cạnh là:

$$
A=P_1-P_0,\qquad B=P_2-P_0.
$$

A và B là độ dời, không phải tọa độ điểm P1/P2. Nếu P0 thay đổi thì cả hai vector đều thay đổi. Nếu dịch **cả ba điểm** cùng một độ dời, A/B giữ nguyên.

Mỗi tọa độ đỉnh được giới hạn [-2,2] world. Giới hạn này giữ editor dễ quan sát, không phải điều kiện toán học để một tam giác tồn tại.

## Viết code từng bước

### Bước 1 — Lưu ba đỉnh, không lưu bản sao hai cạnh

```cpp title="include/lab.hpp — ba điểm có thể chỉnh lúc chạy"
struct Triangle {
    Vec3 p0{-1.0, -1.0, 0.0};
    Vec3 p1{1.0, -1.0, 0.0};
    Vec3 p2{0.0, 1.0, 1.0};
};
```

```cpp title="include/lab.hpp — suy lại hai cạnh từ cùng P0"
inline Edges triangleEdges(const Triangle& triangle) {
    return {subtract(triangle.p1, triangle.p0), subtract(triangle.p2, triangle.p0)};
}
```

Edges có hai trường a/b. Không dùng P1 trực tiếp thay cho A trừ khi P0 đúng là zero; lỗi đó thường bị che bởi ví dụ có gốc ở (0,0,0).

### Bước 2 — Chọn một đỉnh và đổi dữ liệu world

```cpp title="include/scene.hpp — trả đúng đỉnh đang chọn"
inline Vec3& selectedVertex(Scene& scene) {
    if (scene.selected == 0) {
        return scene.triangle.p0;
    }
    if (scene.selected == 1) {
        return scene.triangle.p1;
    }
    return scene.triangle.p2;
}
```

```cpp title="include/scene.hpp — clamp từng thành phần sau input"
inline void moveVertex(Scene& scene, Vec3 delta) {
    if (!finite(delta)) {
        return;
    }
    Vec3& vertex = selectedVertex(scene);
    vertex.x = std::clamp(vertex.x + delta.x, -2.0, 2.0);
    vertex.y = std::clamp(vertex.y + delta.y, -2.0, 2.0);
    vertex.z = std::clamp(vertex.z + delta.z, -2.0, 2.0);
}
```

Nhấn 1/2/3 chọn P0/P1/P2. Phím mũi tên đổi X/Y mỗi lần 0.1, PageUp/Down đổi Z. Dấu Y vẫn là world Y-up; không đảo input chỉ vì screen Y hướng xuống.

### Bước 3 — Nối cạnh và vẽ hai vector

Trong renderScene của checkpoint 02, line3D nối P0→P1→P2→P0. Hai arrow3D đi từ P0 đến P0+A và P0+B. A màu cam, B cyan; đỉnh đang chọn màu vàng. Source checkpoint có đầy đủ đoạn gọi này, cùng marker và nhãn P0/P1/P2.

Cùng một hàm line3D vẽ cả tam giác lẫn vector, nên tất cả dùng đúng camera perspective của bài trước.

## Ghép các phần lại

Build project_10_checkpoint_2. Chọn P0 rồi di chuyển: cả hai cạnh đổi. Sau đó chỉ đổi P2.Z bằng PageUp: vector B và tam giác đổi, vector A giữ nguyên.

Dùng F2 cho tam giác 3–4. Từ P0=(−1.5,−2,0), hai cạnh là A=(3,0,0), B=(0,4,0). Tọa độ điểm đều nằm trong miền editor dù độ dài cạnh có thể lớn hơn 2.

## Thử làm sai để hiểu đúng

1. Cố ý thay A bằng P1. Ở preset có P0 khác zero, mũi tên không còn kết thúc tại P1 nếu vẫn cộng P0 khi vẽ. Khôi phục phép trừ P1−P0.

2. Chỉ lưu hai cạnh một lần khi khởi tạo. Di chuyển P0: tam giác đổi nhưng vector giữ dữ liệu cũ. Đưa triangleEdges trở lại đường render/readout để mọi kết quả dùng cùng state.

## Tự kiểm tra kết quả

- A/B luôn xuất phát từ P0 và đi tới P1/P2.
- P0 đổi thì cả hai cạnh đổi; chỉ P2 đổi thì chỉ B đổi.
- Chọn/sửa đỉnh không làm camera đổi góc.
- Chỉnh Z làm thay đổi perspective, không bị bỏ qua như dữ liệu trang trí.
- Reset khôi phục đỉnh, camera và trạng thái pause.
