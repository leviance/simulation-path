# Vẽ tam giác và hai vector cạnh

## Vấn đề cần giải quyết

Ba trục đã giúp ta định hướng trong không gian. Hãy thêm ba điểm P0, P1, P2, nối chúng thành tam giác rồi vẽ hai vector cùng xuất phát từ P0. Đây là đầu vào của cross product ở bài sau; ta chưa vẽ pháp tuyến khi chưa kiểm được hai cạnh.

Điểm tham chiếu (1,1,1) của bài 1 không còn được vẽ ở mốc này. Trong vùng hình học, các nhãn P0/P1/P2 giờ chỉ ba đỉnh bạn đang chỉnh, không lẫn thêm một điểm trắng không có vai trò.

Thử chọn P0 rồi dịch nó sang phải. Nếu hai mũi tên vẫn giữ nguyên như cũ, chương trình đang dùng cạnh đã tính từ lần trước. Bài này giúp bạn giữ một nguồn dữ liệu duy nhất: ba điểm hiện tại.

## Hiểu ý tưởng trước khi viết code

Để không lẫn tên điểm với tên vector, ta gọi các đỉnh là P0/P1/P2. Hai cạnh là:

$$
A=P_1-P_0,\qquad B=P_2-P_0.
$$

A và B là độ dời, không phải tọa độ điểm P1/P2. Nếu P0 thay đổi thì cả hai vector đều thay đổi. Nếu dịch **cả ba điểm** cùng một độ dời, A/B giữ nguyên.

Mỗi tọa độ đỉnh được giới hạn [-2,2] world. Giới hạn này giữ editor dễ quan sát, không phải điều kiện toán học để một tam giác tồn tại.

## Viết code từng bước

### Bước 1 — Lưu ba đỉnh, không lưu bản sao hai cạnh

```cpp title="include/lab.hpp — ba điểm có thể chỉnh lúc chạy"
struct Triangle {
    Vec3 p0{-1.0, -1.0, 0.0};
    Vec3 p1{1.0, -1.0, 0.0};
    Vec3 p2{0.0, 1.0, 1.0};
};
```

```cpp title="include/lab.hpp — suy lại hai cạnh từ cùng P0"
inline Edges triangleEdges(const Triangle& triangle) {
    return {subtract(triangle.p1, triangle.p0), subtract(triangle.p2, triangle.p0)};
}
```

Edges có hai trường a/b. Không dùng P1 trực tiếp thay cho A trừ khi P0 đúng là zero; lỗi đó thường bị che bởi ví dụ có gốc ở (0,0,0).

### Bước 2 — Chọn một đỉnh và đổi dữ liệu world

```cpp title="include/scene.hpp — trả đúng đỉnh đang chọn"
inline Vec3& selectedVertex(Scene& scene) {
    if (scene.selected == 0) {
        return scene.triangle.p0;
    }
    if (scene.selected == 1) {
        return scene.triangle.p1;
    }
    return scene.triangle.p2;
}
```

```cpp title="include/scene.hpp — clamp từng thành phần sau input"
inline void moveVertex(Scene& scene, Vec3 delta) {
    if (!finite(delta)) {
        return;
    }
    Vec3& vertex = selectedVertex(scene);
    vertex.x = std::clamp(vertex.x + delta.x, -2.0, 2.0);
    vertex.y = std::clamp(vertex.y + delta.y, -2.0, 2.0);
    vertex.z = std::clamp(vertex.z + delta.z, -2.0, 2.0);
}
```

Nhấn 1/2/3 chọn P0/P1/P2. Phím mũi tên đổi X/Y mỗi lần 0.1, PageUp/Down đổi Z. Dấu Y vẫn là world Y-up; không đảo input chỉ vì screen Y hướng xuống.

Nối hai helper vào nhánh SDL_EVENT_KEY_DOWN trong vòng SDL_PollEvent của main như sau. scene là Scene đã khởi tạo trước vòng lặp; dirty được bật ở đầu nhánh key-down để ảnh được vẽ lại sau khi dữ liệu đổi. Không sửa trực tiếp vị trí một marker trên ảnh:

```cpp title="src/main.cpp — phím sửa dữ liệu world của đỉnh đang chọn"
if (event.key.key >= SDLK_1 && event.key.key <= SDLK_3) {
    scene.selected = static_cast<int>(event.key.key - SDLK_1);
}
lab::Vec3 delta{};
if (event.key.key == SDLK_LEFT) {
    delta.x = -0.1;
}
if (event.key.key == SDLK_RIGHT) {
    delta.x = 0.1;
}
if (event.key.key == SDLK_UP) {
    delta.y = 0.1;
}
if (event.key.key == SDLK_DOWN) {
    delta.y = -0.1;
}
if (event.key.key == SDLK_PAGEUP) {
    delta.z = 0.1;
}
if (event.key.key == SDLK_PAGEDOWN) {
    delta.z = -0.1;
}
lab::moveVertex(scene, delta);
```

### Bước 3 — Nối cạnh và vẽ hai vector

Trong renderScene của checkpoint 02, line3D nối P0→P1→P2→P0. Hai arrow3D đi từ P0 đến P0+A và P0+B. A màu cam, B cyan; đỉnh đang chọn màu vàng. Source checkpoint có đầy đủ đoạn gọi này, cùng marker và nhãn P0/P1/P2.

Thêm đoạn sau vào renderScene trong include/view.hpp, sau phần trục. Scene được truyền từ main nên các đỉnh và hai cạnh luôn là dữ liệu hiện tại:

```cpp title="include/view.hpp — vẽ từ cùng ba điểm hiện tại"
const Triangle& triangle = scene.triangle;
const Edges edges = triangleEdges(triangle);
line3D(image, triangle.p0, triangle.p1, scene.camera, kWhite);
line3D(image, triangle.p1, triangle.p2, scene.camera, kWhite);
line3D(image, triangle.p2, triangle.p0, scene.camera, kWhite);
arrow3D(image, triangle.p0, add(triangle.p0, edges.a), scene.camera, 0xFFB454FFu);
arrow3D(image, triangle.p0, add(triangle.p0, edges.b), scene.camera, 0x53DFEFFFu);
```

line3D vẽ cạnh; arrow3D vẽ mũi tên bằng cùng camera. Gọi renderScene trong nhánh dirty của vòng lặp đang có, không dựng thêm một tam giác chỉ để minh họa hai vector.

## Ghép các phần lại

Khai báo triangle và selected trong Scene, sau đó để nhánh key-down chọn P0/P1/P2 hoặc tạo delta cho moveVertex. Trong renderScene, lấy triangle từ scene, tính edges mới, nối ba cạnh rồi gọi hai arrow3D. Như vậy sửa dữ liệu ở input sẽ xuất hiện đồng thời trên tam giác, mũi tên và bảng số ở frame được vẽ tiếp theo.

Chọn P0 và di chuyển: cả A lẫn B phải đổi. Sau đó chỉ đổi P2.Z bằng PageUp: B đổi nhưng A giữ nguyên. F2 tạo P0=(−1,5; −2; 0), P1=(1,5; −2; 0), P2=(−1,5; 2; 0), nên A=(3,0,0), B=(0,4,0). Tọa độ đỉnh nằm trong miền editor nhưng độ dài cạnh không bị giới hạn bằng 2.

```bash title="Terminal — chạy checkpoint 02"
cmake --build build --config Debug --target project_10_checkpoint_2 --parallel 2
./build/Debug/project_10_checkpoint_2.exe
```

Với Visual Studio trên Windows, executable nằm trong Debug hoặc Release. Với Ninja/Make, chọn CMAKE_BUILD_TYPE lúc configure và chạy ngay trong build; dùng build tree riêng nếu muốn giữ cả hai cấu hình.

## Thử làm sai để hiểu đúng

1. Cố ý thay A bằng P1. Ở preset có P0 khác zero, mũi tên không còn kết thúc tại P1 nếu vẫn cộng P0 khi vẽ. Khôi phục phép trừ P1−P0.

2. Chỉ lưu hai cạnh một lần khi khởi tạo. Di chuyển P0: tam giác đổi nhưng vector giữ dữ liệu cũ. Đưa triangleEdges trở lại đường render/readout để mọi kết quả dùng cùng state.

## Tự kiểm tra kết quả

- A/B luôn xuất phát từ P0 và đi tới P1/P2.
- P0 đổi thì cả hai cạnh đổi; chỉ P2 đổi thì chỉ B đổi.
- Chọn/sửa đỉnh không làm camera đổi góc.
- Chỉnh Z làm thay đổi perspective, không bị bỏ qua như dữ liệu trang trí.
- Reset khôi phục đỉnh, camera và trạng thái pause.
