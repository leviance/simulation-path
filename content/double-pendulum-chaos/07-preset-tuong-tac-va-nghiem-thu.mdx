# Hoàn thiện bàn thí nghiệm và mã nguồn

## Vấn đề cần giải quyết

Phép tính và hai loại đồ thị đã có. Bài cuối biến chúng thành một bàn thí nghiệm có thể dùng lại: chọn điều kiện đầu, sửa góc bằng chuột, chạy nhanh mà vẫn dừng được, xem chế độ sạch và kiểm bài làm bằng tests độc lập.

Sản phẩm cuối phải là một executable C++/SDL3 thật. Canvas chỉ minh họa cùng mô hình; một graph đẹp trên web không thay thế ứng dụng mà người học tải về và chạy.

## Hiểu ý tưởng trước khi viết code

Ba preset chỉ tạo điều kiện đầu, không có solver riêng:

- Calm: theta1=0,2 và theta2=0,3 rad, omega=0. Đây là góc nhỏ, không phải một chứng minh rằng mọi chuyển động năng lượng thấp đều đơn giản.
- Chaotic: theta1=2 và theta2=1,1 rad, omega=0. Cấu hình này giúp quan sát độ nhạy đã kiểm ở horizon 10 s.
- Near upright: hai góc gần π, bắt đầu gần tư thế ngược lên.

Kéo quả cuối của A trong bài này là **đặt lại điều kiện đầu**, không phải tác dụng lực lên một hệ đang chạy. Khi bắt đầu kéo, lấy tư thế hiện tại làm initial mới, đưa hai omega về 0 và dựng lại A/B/reference. Vì là một thí nghiệm mới, có thể chọn biểu diễn góc ban đầu trong một vòng; điều đó khác với wrap state sau mỗi bước RK4.

Job 30 s cũng không có thuật toán tích phân riêng. Nó chỉ yêu cầu thêm một số bước hữu hạn rồi để advanceFrame thực hiện tối đa 32 bước/frame. Nếu không có chính sách này, một click handler “hữu hạn” nhưng chạy rất lâu vẫn có thể làm người dùng không bấm được Stop.

### Bước 1 — Tạo preset và một API chạy thử cho tests

Trong include/lab.hpp, thêm enum, presetState, ChaosRunResult và runChaosExperiment ở cuối namespace. Các góc được gán bằng tên field để người đọc không phải nhớ thứ tự một dãy số.

```cpp title="include/lab.hpp — điều kiện đầu có tên"
enum class ChaosPreset {
    calm,
    chaotic,
    nearUpright,
};

inline DoublePendulumState presetState(ChaosPreset preset) {
    DoublePendulumState state{};
    if (preset == ChaosPreset::calm) {
        state.theta1 = 0.2;
        state.theta2 = 0.3;
    } else if (preset == ChaosPreset::nearUpright) {
        state.theta1 = kPi - 0.08;
        state.theta2 = kPi - 0.16;
    } else {
        state.theta1 = 2.0;
        state.theta2 = 1.1;
    }
    return state;
}
```

```cpp title="include/lab.hpp — kết quả của một run có budget"
struct ChaosRunResult {
    ChaosExperiment experiment{};
    ChaosMetrics metrics{};
    int steps{};
    bool completed{};
};

inline ChaosRunResult runChaosExperiment(ChaosPreset preset, const DoublePendulumParameters& parameters, double perturbationRadians, double duration, double deltaSeconds) {
    ChaosRunResult result{};
    result.experiment = makeChaosExperiment(presetState(preset), perturbationRadians);
    if (!validParameters(parameters) || !std::isfinite(perturbationRadians) || !std::isfinite(duration) || duration < 0.0 || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0) {
        return result;
    }
    const double requested = std::floor(duration / deltaSeconds + kChaosEpsilon);
    // API headless cũng có budget; không cast một thương vô hạn sang int.
    if (!std::isfinite(requested) || requested > 120000.0) {
        return result;
    }
    const int plannedSteps = static_cast<int>(requested);
    for (int step = 0; step < plannedSteps; ++step) {
        if (!stepChaosExperiment(result.experiment, parameters, deltaSeconds)) {
            break;
        }
        ++result.steps;
    }
    result.metrics = measureChaos(result.experiment, parameters);
    result.completed = result.steps == plannedSteps && result.metrics.finite;
    return result;
}
```

runChaosExperiment là API headless cho tests, có số bước dự tính và trần 120.000 bước; thương không hữu hạn bị từ chối trước khi đổi sang int. Không gọi nó từ nhánh Enter của UI. UI vẫn phải dùng job chia batch từ bài 6.

### Bước 3 — Kéo đúng quả nặng và giữ lệch điểm cầm

Thêm hai hàm sau. beginAngleDrag chỉ chấp nhận một điểm gần bob2 thật của A. Góc lệch giữa vị trí cầm và tâm quả được giữ lại để không nhảy tư thế ngay khi bấm xuống.

```cpp title="include/scene.hpp — bắt đầu đặt góc mới"
inline bool beginAngleDrag(Scene& scene, Vec2 pointer, double hitRadius) {
    if (!std::isfinite(pointer.x) || !std::isfinite(pointer.y) || !std::isfinite(hitRadius) || hitRadius <= 0.0 || !finiteState(primaryState(scene)) || !validParameters(scene.parameters)) {
        return false;
    }
    const auto geometry = pendulumGeometry(primaryState(scene), scene.parameters);
    if (length(subtract(pointer, geometry.bob2)) > hitRadius) {
        return false;
    }
    const Vec2 delta = subtract(pointer, geometry.bob1);
    if (length(delta) <= 1e-12) {
        return false;
    }
    const double pointerAngle = std::atan2(delta.x, -delta.y);
    scene.initial = primaryState(scene);
    scene.initial.theta1 = wrapAngle(scene.initial.theta1);
    scene.initial.theta2 = wrapAngle(scene.initial.theta2);
    scene.initial.omega1 = 0.0;
    scene.initial.omega2 = 0.0;
    const double offset = scene.initial.theta2 - pointerAngle;
    resetScene(scene);
    scene.dragging = true;
    scene.dragOffset = offset;
    return true;
}
```

```cpp title="include/scene.hpp — cập nhật góc ban đầu"
inline void moveAngleDrag(Scene& scene, Vec2 pointer) {
    if (!scene.dragging || !std::isfinite(pointer.x) || !std::isfinite(pointer.y)) {
        return;
    }
    const auto geometry = pendulumGeometry(scene.initial, scene.parameters);
    const Vec2 delta = subtract(pointer, geometry.bob1);
    if (length(delta) <= 0.1) {
        return;
    }
    const double angle = std::atan2(delta.x, -delta.y) + scene.dragOffset;
    scene.initial.theta2 = wrapAngle(angle);
    const double offset = scene.dragOffset;
    resetScene(scene);
    scene.dragging = true;
    scene.dragOffset = offset;
}
```

Mỗi lần đổi góc đều reset đồng hồ, E0, trails và history. Không giữ omega cũ rồi gán một theta mới giữa run; thao tác đó sẽ bơm năng lượng không được mô hình hóa vào hệ.

### Bước 4 — Hoàn thiện vòng lặp SDL và lifecycle của input

Thay src/main.cpp bằng bản hoàn chỉnh dưới đây. Phần quan trọng cần đọc kỹ là: đổi tọa độ event đúng một lần; tạo candidate trước khi capture; chỉ commit nếu capture thành công; lưu đúng mouse ID; dùng tọa độ BUTTON_UP cuối; hủy capture khi mất focus, ẩn/minimize hoặc resize.

```cpp title="src/main.cpp — ứng dụng hoàn chỉnh"
#include "presentation.hpp"
#include <SDL3/SDL_main.h>
#include <cstdlib>
#include <iostream>
#include <string_view>

int main(int argc, char** argv) {
    const bool smoke = argc > 1 && std::string_view(argv[1]) == "--smoke";
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        std::cerr << SDL_GetError() << '\n';
        return EXIT_FAILURE;
    }
    SDL_WindowFlags flags = SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY;
    if (smoke) {
        flags |= SDL_WINDOW_HIDDEN;
    }
    SDL_Window* window = SDL_CreateWindow("Project 26 - Double Pendulum", 1100, 820, flags);
    SDL_Renderer* renderer = nullptr;
    SDL_Texture* texture = nullptr;
    if (window) {
        renderer = SDL_CreateRenderer(window, nullptr);
    }
    if (renderer) {
        texture = SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_STREAMING, 1100, 820);
    }
    if (!window || !renderer || !texture || !SDL_SetRenderLogicalPresentation(renderer, 1100, 820, SDL_LOGICAL_PRESENTATION_LETTERBOX)) {
        std::cerr << SDL_GetError() << '\n';
        SDL_DestroyTexture(texture);
        SDL_DestroyRenderer(renderer);
        SDL_DestroyWindow(window);
        SDL_Quit();
        return EXIT_FAILURE;
    }
    SDL_SetWindowMinimumSize(window, 660, 492);
    lab::Framebuffer image{};
    lab::Scene scene = lab::makeScene();
    bool running = true;
    bool failed = false;
    bool dirty = true;
    int frames = 0;
    const double frequency = static_cast<double>(SDL_GetPerformanceFrequency());
    std::uint64_t previous = SDL_GetPerformanceCounter();
    SDL_MouseID owner = 0;
    const auto cancelCapture = [&]() {
        scene.dragging = false;
        SDL_CaptureMouse(false);
    };
    const auto updateDrag = [&](float x, float y) {
        const auto view = lab::makeWorldView(scene.parameters, 0);
        lab::moveAngleDrag(scene, lab::screenToWorld({x, y}, view));
        dirty = true;
    };
    while (running) {
        SDL_Event event{};
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_EVENT_QUIT) {
                running = false;
            }
            if (event.type == SDL_EVENT_WINDOW_FOCUS_LOST || event.type == SDL_EVENT_WINDOW_HIDDEN || event.type == SDL_EVENT_WINDOW_MINIMIZED || event.type == SDL_EVENT_WINDOW_RESIZED || event.type == SDL_EVENT_WINDOW_PIXEL_SIZE_CHANGED) {
                cancelCapture();
                lab::stopScene(scene);
            }
            if (event.type == SDL_EVENT_KEY_DOWN && !event.key.repeat && !(event.key.mod & (SDL_KMOD_CTRL | SDL_KMOD_ALT | SDL_KMOD_GUI))) {
                const auto key = event.key.key;
                cancelCapture();
                if (key == SDLK_ESCAPE) {
                    running = false;
                }
                if (key == SDLK_R) {
                    lab::resetScene(scene);
                }
                if (key == SDLK_F) {
                    scene.debug = !scene.debug;
                }
                if (key == SDLK_A || key == SDLK_D || key == SDLK_W || key == SDLK_S) {
                    if (key == SDLK_A) {
                        scene.initial.theta1 -= 0.05;
                    }
                    if (key == SDLK_D) {
                        scene.initial.theta1 += 0.05;
                    }
                    if (key == SDLK_S) {
                        scene.initial.theta2 -= 0.05;
                    }
                    if (key == SDLK_W) {
                        scene.initial.theta2 += 0.05;
                    }
                    scene.initial.theta1 = std::clamp(scene.initial.theta1, -lab::kPi, lab::kPi);
                    scene.initial.theta2 = std::clamp(scene.initial.theta2, -lab::kPi, lab::kPi);
                    lab::resetScene(scene);
                }
                if (key == SDLK_SPACE) {
                    const bool wasPaused = scene.paused;
                    const bool hadJob = scene.fastRemaining > 0;
                    lab::stopScene(scene);
                    scene.paused = !wasPaused;
                    if (hadJob) {
                        scene.paused = true;
                    }
                }
                if (key == SDLK_N) {
                    lab::singleStep(scene);
                }
                if (key == SDLK_LEFTBRACKET || key == SDLK_RIGHTBRACKET) {
                    const int change = key == SDLK_LEFTBRACKET ? 1 : -1;
                    scene.dtIndex = std::clamp(scene.dtIndex + change, 0, 5);
                    lab::resetScene(scene);
                }
                if (key == SDLK_UP || key == SDLK_DOWN || key == SDLK_0) {
                    if (key == SDLK_0) {
                        scene.perturbation = 0.0;
                    }
                    if (key == SDLK_UP) {
                        scene.perturbation = std::min(1e-2, std::max(1e-8, scene.perturbation * 10.0));
                    }
                    if (key == SDLK_DOWN) {
                        scene.perturbation = scene.perturbation <= 1e-8 ? 0.0 : scene.perturbation / 10.0;
                    }
                    lab::resetScene(scene);
                }
                if (key >= SDLK_1 && key <= SDLK_3) {
                    lab::choosePreset(scene, static_cast<lab::ChaosPreset>(key - SDLK_1));
                }
                if (key == SDLK_P) {
                    auto preset = lab::ChaosPreset::calm;
                    if (scene.preset == lab::ChaosPreset::calm) {
                        preset = lab::ChaosPreset::chaotic;
                    }
                    if (scene.preset == lab::ChaosPreset::chaotic) {
                        preset = lab::ChaosPreset::nearUpright;
                    }
                    lab::choosePreset(scene, preset);
                }
                if (key == SDLK_RETURN) {
                    lab::requestFast(scene, 30.0);
                }
                if (key == SDLK_BACKSPACE) {
                    lab::stopScene(scene);
                }
            }
            // Một lần đổi từ window coordinates sang logical board; không nhân thêm DPR.
            if (event.type == SDL_EVENT_MOUSE_BUTTON_DOWN || event.type == SDL_EVENT_MOUSE_BUTTON_UP || event.type == SDL_EVENT_MOUSE_MOTION) {
                if (!SDL_ConvertEventToRenderCoordinates(renderer, &event)) {
                    failed = true;
                    running = false;
                    break;
                }
            }
            if (event.type == SDL_EVENT_MOUSE_BUTTON_DOWN && event.button.button == SDL_BUTTON_LEFT && !scene.dragging && event.button.x >= 40 && event.button.x <= 530 && event.button.y >= 100 && event.button.y <= 530) {
                const auto view = lab::makeWorldView(scene.parameters, 0);
                auto candidate = scene;
                if (lab::beginAngleDrag(candidate, lab::screenToWorld({event.button.x, event.button.y}, view), 14.0 / view.scale) && SDL_CaptureMouse(true)) {
                    scene = std::move(candidate);
                    owner = event.button.which;
                }
            }
            if (event.type == SDL_EVENT_MOUSE_MOTION && scene.dragging && event.motion.which == owner) {
                if (!(event.motion.state & SDL_BUTTON_LMASK)) {
                    cancelCapture();
                    lab::stopScene(scene);
                } else {
                    updateDrag(event.motion.x, event.motion.y);
                }
            }
            if (event.type == SDL_EVENT_MOUSE_BUTTON_UP && event.button.button == SDL_BUTTON_LEFT && scene.dragging && event.button.which == owner) {
                updateDrag(event.button.x, event.button.y);
                cancelCapture();
            }
            dirty = true;
        }
        if (!running) {
            break;
        }
        const auto now = SDL_GetPerformanceCounter();
        const double frameSeconds = static_cast<double>(now - previous) / frequency;
        previous = now;
        if (smoke) {
            ++frames;
            if (frames < 16) {
                lab::singleStep(scene);
            }
            if (frames == 20) {
                scene.debug = false;
            }
            if (frames == 24 && !SDL_SetWindowSize(window, 880, 656)) {
                failed = true;
                break;
            }
            if (frames >= 32) {
                break;
            }
            dirty = true;
        } else {
            bool advancing = !scene.paused;
            advancing = advancing || scene.fastRemaining > 0;
            if (advancing) {
                lab::advanceFrame(scene, frameSeconds);
                dirty = true;
            }
        }
        if (dirty) {
            lab::drawScene(image, scene);
            if (!SDL_UpdateTexture(texture, nullptr, image.pixels.data(), 1100 * static_cast<int>(sizeof(std::uint32_t))) || !SDL_SetRenderDrawColor(renderer, 11, 16, 32, 255) || !SDL_RenderClear(renderer) || !SDL_RenderTexture(renderer, texture, nullptr, nullptr) || !lab::drawHud(renderer, scene) || !SDL_RenderPresent(renderer)) {
                std::cerr << SDL_GetError() << '\n';
                failed = true;
                break;
            }
            dirty = false;
        }
        SDL_Delay(16);
    }
    cancelCapture();
    SDL_DestroyTexture(texture);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return failed ? EXIT_FAILURE : EXIT_SUCCESS;
}
```

Không có vòng lặp hàng nghìn step trong nhánh Enter. Enter yêu cầu +30 s; Space hoặc Backspace dừng job. Sau mỗi frame vòng lặp vẫn poll event. dirty tránh render lại liên tục khi đã pause; SDL_Delay(16) tránh vòng lặp nghỉ chiếm toàn bộ một core.

SDL_ConvertEventToRenderCoordinates đưa tọa độ window về logical board 1100×820, đã tính letterbox. Đừng nhân thêm device-pixel-ratio một lần nữa. SDL_CaptureMouse có thể thất bại, nên thao tác chưa được quyền sửa state trước khi kết quả capture thành công. Xem [hợp đồng SDL_CaptureMouse](https://wiki.libsdl.org/SDL3/SDL_CaptureMouse) khi muốn mở rộng tương tác.

```cpp title="include/presentation.hpp — thông tin bản hoàn chỉnh"
    }
    const auto metrics = measureChaos(scene.experiment, scene.parameters);
    std::snprintf(line, sizeof(line), "h/h2: %.3e | finite=%s", metrics.numericalSeparation, metrics.finite ? "yes" : "NO");
    text(650, 788, line);
    std::snprintf(line, sizeof(line), "Space pause | N step | [/] dt | Enter +30s | Backspace stop | remaining %d steps", scene.fastRemaining);
    text(30, 64, line);
    text(30, 84, "P/1/2/3 presets | Up/Down epsilon | 0 identical twins | drag A bob2: edit initial angles");
    if (!scene.message.empty()) {
        text(30, 808, scene.message.c_str());
    }
    return ok;
}
```

### Bước 6 — Kiểm bài làm, không kiểm nhầm bản tham khảo
