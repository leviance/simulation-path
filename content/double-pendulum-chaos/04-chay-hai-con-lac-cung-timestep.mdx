# Đặt hai điều kiện đầu gần nhau và chạy đồng bộ

## Vấn đề cần giải quyết

Một con lắc chuyển động chưa cho biết nó nhạy với điều kiện đầu đến đâu. Ta cần một bản thứ hai dùng đúng cùng mô hình và solver, nhưng có góc ban đầu lệch rất nhỏ.

Bài này tạo A/B, đặt chúng ở hai khung cạnh nhau và vẽ vệt của quả cuối. Hai khung chỉ giúp nhìn cho rõ; không có hai thế giới vật lý khác nhau hoặc hai bộ đồng hồ chạy độc lập.

## Hiểu ý tưởng trước khi viết code

Từ điều kiện đầu $y_0=(\theta_1,\omega_1,\theta_2,\omega_2)$ của A, tạo B bằng đúng một thay đổi:

$$
\tilde y_0=(\theta_1,\omega_1,\theta_2+\varepsilon,\omega_2).
$$

Mỗi bước, cả hai đi qua cùng hàm RK4 với cùng h. Tính hai candidate trước; chỉ khi cả hai thành công mới thay state và tăng bộ đếm. Nếu B lỗi nhưng A đã tiến, phép so sánh sau đó không còn ở cùng thời điểm.

Giữ hai initial state riêng để reset tái tạo đúng cặp ban đầu. E0 của A và B cũng phải đo riêng: lệch một góc ban đầu có thể làm năng lượng ban đầu lệch rất nhỏ; chênh lệch ấy không phải lỗi solver.

<InteractiveLab demo="double-pendulum-chaos" mode="chaos-twins" />

Chọn epsilon=0 rồi chạy: hai hình trong hai khung phải có cùng tư thế và vệt. Đặt lại, chọn 1e-4 rad rồi chạy tiếp. Lúc đầu chúng gần như giống hệt; muốn nhìn sự khác biệt cần chờ đủ thời gian mô phỏng. Chưa được kết luận chaos chỉ từ hình ở bài này.

## Viết code từng bước

Viết phần của bạn trong starter/include và starter/src. Khi thay một hàm, xóa bản cũ rồi thay bằng bản mới, không thêm hàm trùng tên. Các hàm thuộc header đặt trong namespace lab đã có sẵn. Checkpoint 4 là bản tham khảo ở cuối bài; build checkpoint không kiểm phần bạn vừa viết trong Starter.

### Bước 1 — Tạo cặp state chỉ khác điều kiện đầu

Trong include/lab.hpp, thêm struct và hai hàm sau các hàm của bài 3. Không tạo B bằng random hoặc đổi vận tốc, vì như vậy ta không còn biết chính xác yếu tố nào đã khác.

```cpp title="include/lab.hpp — dữ liệu A/B và khởi tạo"
struct TwinPendulums {
    DoublePendulumState initialPrimary{};
    DoublePendulumState initialPerturbed{};
    DoublePendulumState primary{};
    DoublePendulumState perturbed{};
    std::size_t stepCount{};
};

inline TwinPendulums makeTwinPendulums(const DoublePendulumState& initial, double perturbationRadians) {
    DoublePendulumState perturbed = initial;
    perturbed.theta2 += perturbationRadians;
    TwinPendulums twins{};
    twins.initialPrimary = initial;
    twins.initialPerturbed = perturbed;
    twins.primary = initial;
    twins.perturbed = perturbed;
    return twins;
}
```

```cpp title="include/lab.hpp — một bước đồng bộ và nguyên tử"
inline bool stepTwinPendulums(TwinPendulums& twins, const DoublePendulumParameters& parameters, double deltaSeconds) {
    if (!sameTime(twins.primary.elapsed, twins.perturbed.elapsed)) {
        return false;
    }
    const DoublePendulumState primary = stepRk4(twins.primary, parameters, deltaSeconds);
    const DoublePendulumState perturbed = stepRk4(twins.perturbed, parameters, deltaSeconds);
    if (primary.elapsed <= twins.primary.elapsed || perturbed.elapsed <= twins.perturbed.elapsed || !sameTime(primary.elapsed, perturbed.elapsed)) {
        return false;
    }
    twins.primary = primary;
    twins.perturbed = perturbed;
    ++twins.stepCount;
    return true;
}
```

sameTime là helper kiểm nhãn thời gian; bản Starter có sẵn helper cùng các phép kiểm hữu hạn. Tolerance của nó chỉ xử lý sai số cộng số thực rất nhỏ, không cho phép so hai state lệch một physics step. Hàm này không sửa nhãn thời gian của một trajectory chưa chạy.

### Bước 2 — Thay state đơn trong Scene bằng cặp A/B

Thay struct Scene trong include/scene.hpp bằng bản sau. Các phần điều khiển frame và history cũ vẫn được giữ; trường single được thay bằng twins.

```cpp title="include/scene.hpp — state và vệt của hai con lắc"
struct Scene {
    DoublePendulumParameters parameters{};
    DoublePendulumState initial{2.0, 0.0, 1.1, 0.0, 0.0};
    bool paused{true};
    bool debug{true};
    std::string message{};
    int dtIndex{3};
    double accumulator{};
    double droppedTime{};
```

Thay primaryState và thêm perturbedState ngay sau nó. Những chỗ chỉ đọc A không cần biết Scene đang giữ một state đơn hay một cặp:

```cpp title="include/scene.hpp — truy cập đúng trajectory"
inline const DoublePendulumState& primaryState(const Scene& scene) {
    return scene.twins.primary;
}

inline const DoublePendulumState& perturbedState(const Scene& scene) {
    return scene.twins.perturbed;
}
```

Thay resetScene. E0_B lấy từ initialPerturbed, không lấy từ initialPrimary:

```cpp title="include/scene.hpp — reset cùng điều kiện đầu"
inline void resetScene(Scene& scene) {
    stopScene(scene);
    scene.initial.elapsed = 0.0;
    scene.message.clear();
    scene.twins = makeTwinPendulums(scene.initial, scene.perturbation);
    scene.steps = 0;
    scene.droppedTime = 0.0;
    scene.maximumEnergyErrorA = 0.0;
    scene.initialEnergyA = pendulumEnergy(primaryState(scene), scene.parameters);
    scene.history.clear();
    scene.initialEnergyB = pendulumEnergy(perturbedState(scene), scene.parameters);
    scene.maximumEnergyErrorB = 0.0;
    scene.trailA.clear();
    scene.trailB.clear();
    recordHistory(scene, true);
}
```

### Bước 3 — Chỉ ghi vệt và số đo sau bước được chấp nhận

HistorySample cần thêm trường energyErrorB. Thay struct bằng bản này:

```cpp title="include/scene.hpp — mẫu năng lượng của A/B"
struct HistorySample {
    double time{};
    double energyErrorA{};
    double energyErrorB{};
};
```

Thay recordHistory và stepScene. Vệt được lấy từ bob2 của state thật, cùng nhịp lấy mẫu với history. Không dùng các điểm trên vệt để tích phân ngược trở lại.

```cpp title="include/scene.hpp — lấy mẫu hai vệt"
inline void recordHistory(Scene& scene, bool force = false) {
    const auto& primary = primaryState(scene);
    if (!scene.history.empty()) {
        const double interval = primary.elapsed - scene.history.back().time;
        if (interval <= 1e-12 || (!force && interval < 0.04 - 1e-12)) {
            return;
        }
    }
    HistorySample sample{};
    sample.time = primary.elapsed;
    sample.energyErrorA = pendulumEnergy(primary, scene.parameters) - scene.initialEnergyA;
    sample.energyErrorB = pendulumEnergy(perturbedState(scene), scene.parameters) - scene.initialEnergyB;
    scene.trailA.push_back(pendulumGeometry(primary, scene.parameters).bob2);
    scene.trailB.push_back(pendulumGeometry(perturbedState(scene), scene.parameters).bob2);
    if (scene.trailA.size() > 751) {
        scene.trailA.erase(scene.trailA.begin());
        scene.trailB.erase(scene.trailB.begin());
    }
    scene.history.push_back(sample);
    if (scene.history.size() > 751) {
        scene.history.erase(scene.history.begin());
    }
}
```

```cpp title="include/scene.hpp — tiến cả cặp trước khi tăng đồng hồ"
inline bool stepScene(Scene& scene) {
    if (scene.dtIndex < 0 || scene.dtIndex >= 6) {
        stopScene(scene);
        scene.message = "Stopped: invalid dt index.";
        return false;
    }
    const double dt = kStepOptions[scene.dtIndex];
    bool accepted = false;
    TwinPendulums candidate = scene.twins;
    accepted = stepTwinPendulums(candidate, scene.parameters, dt);
    accepted = accepted && withinExperiment(candidate.primary) && withinExperiment(candidate.perturbed) && std::isfinite(pendulumEnergy(candidate.primary, scene.parameters)) && std::isfinite(pendulumEnergy(candidate.perturbed, scene.parameters));
    if (accepted) {
        scene.twins = candidate;
    }
    if (!accepted) {
        stopScene(scene);
        scene.message = "Stopped: invalid, non-finite or unsafe step. Reduce dt or reset; state was not clamped.";
        return false;
    }
    ++scene.steps;
    ++scene.substeps;
    scene.maximumEnergyErrorA = std::max(scene.maximumEnergyErrorA, std::abs(pendulumEnergy(primaryState(scene), scene.parameters) - scene.initialEnergyA));
    scene.maximumEnergyErrorB = std::max(scene.maximumEnergyErrorB, std::abs(pendulumEnergy(perturbedState(scene), scene.parameters) - scene.initialEnergyB));
    recordHistory(scene);
    return true;
}
```

Giữ nguyên singleStep, advanceFrame và planner của bài 3. Chúng gọi stepScene nên tự đi qua phép cập nhật A/B mới, không cần một accumulator thứ hai.

### Bước 4 — Vẽ hai khung và giữ đúng số liệu năng lượng

```cpp title="include/view.hpp — vệt chuyển động trong world space"
inline void drawTrail(Framebuffer& image, const std::vector<Vec2>& trail, const WorldView& view, std::uint32_t color) {
    for (std::size_t i = 1; i < trail.size(); ++i) {
```

Thay energyGraphBound và drawEnergyGraph để tính thang theo cả A/B và vẽ thêm đường đỏ:

```cpp title="include/view.hpp — năng lượng của cả hai con lắc"
inline double energyGraphBound(const Scene& scene) {
    double bound = 1e-12;
    for (const auto& sample : scene.history) {
        bound = std::max(bound, std::abs(sample.energyErrorA));
        bound = std::max(bound, std::abs(sample.energyErrorB));
    }
    return bound;
}

inline void drawEnergyGraph(Framebuffer& image, const Scene& scene) {
    rectangle(image, 570, 590, 1060, 730, kGrid, false);
    drawLine(image, 570, 660, 1060, 660, kRail);
    if (scene.history.empty()) {
        return;
    }
    const double first = scene.history.front().time;
    const double span = std::max(kStepOptions[scene.dtIndex], scene.history.back().time - first);
    const double bound = energyGraphBound(scene);
    for (std::size_t i = 1; i < scene.history.size(); ++i) {
        const auto& a = scene.history[i - 1];
        const auto& b = scene.history[i];
        const double x0 = graphTimeX(a.time, first, span, 570);
        const double x1 = graphTimeX(b.time, first, span, 570);
        drawLine(image, x0, 660.0 - 70.0 * a.energyErrorA / bound, x1, 660.0 - 70.0 * b.energyErrorA / bound, kPrimary);
        drawLine(image, x0, 660.0 - 70.0 * a.energyErrorB / bound, x1, 660.0 - 70.0 * b.energyErrorB / bound, kPerturbed);
    }
}
```

## Ghép các phần lại

## Thử làm sai để hiểu đúng

1. Cộng epsilon vào current state sau mỗi frame. Bạn đang liên tục tác động lên B, không còn thử một sai khác duy nhất lúc bắt đầu.
2. Cập nhật A trước rồi thoát hàm khi B bị từ chối. Bộ đếm chung sẽ che mất việc hai trajectory đã lệch thời gian; dùng candidate và commit cả cặp.
3. Dùng E0_A cho đồ thị ΔE_B. Một chênh lệch năng lượng ban đầu hợp lệ sẽ bị ghi nhầm thành drift.
4. Vẽ vệt bằng tọa độ pixel rồi resize. Vệt sẽ không còn đi cùng mô hình; lưu world position và đổi sang pixel khi vẽ.

## Tự kiểm tra kết quả

- Ban đầu B chỉ khác A ở theta2 đúng epsilon; omega và tham số giống nhau.
- Epsilon=0 giữ các field của A/B trùng nhau trong cùng run.
- Một bước làm cả hai tiến cùng thời gian, bộ đếm chỉ tăng một lần.
- Khi một candidate bị từ chối, cả cặp giữ state cũ.
- Hai khung và hai vệt nhìn rõ, không cắt mất phần phía trên khi con lắc quay hết vòng.
- Đổi epsilon/reset không nối một vệt cũ vào thí nghiệm mới.

## Bài tập mở rộng

Lưu lại cả cặp initial state, chạy một số bước cố định rồi reset và chạy lại cùng số bước. So các field bằng phép kiểm số thay vì chỉ nhìn hình. Đây là phép thử tính tái lập; nó chưa nói gì về độ chính xác của quỹ đạo.
