# Đo độ tách mà không nhầm ở biên góc

## Vấn đề cần giải quyết

Hai vệt đang tách nhau, nhưng “trông khác” chưa phải một phép đo. Ta cần biết độ tách tăng bao nhiêu và ở thời điểm nào. Khoảng cách hai quả cuối cũng chưa mô tả hết: hai hệ có thể gần cùng vị trí nhưng đang đi theo hai hướng khác nhau.

Bài này giữ hai phép đo riêng: khoảng cách quả cuối bằng mét và khoảng cách trạng thái trong phase space. Ta còn phải xử lý góc tuần hoàn, nếu không +179° và −179° sẽ bị ghi thành chênh 358° thay vì 2°.

## Hiểu ý tưởng trước khi viết code

Với mỗi góc, chỉ lấy hiệu nhỏ nhất sau khi quy về một vòng:

$$
\delta\theta_i=\operatorname{wrap}(\tilde\theta_i-\theta_i)\in[-\pi,\pi].
$$

Không wrap góc đang được RK4 tích phân; chỉ wrap hiệu khi so sánh. Để ghép vận tốc góc với góc, chọn thang thời gian đặc trưng:

$$
\tau=\sqrt{\frac{(L_1+L_2)/2}{g}},\qquad
d=\sqrt{\delta\theta_1^2+\delta\theta_2^2+
(\tau\delta\omega_1)^2+(\tau\delta\omega_2)^2}.
$$

Tau có đơn vị giây, nên tau·delta omega có cùng cách biểu diễn không thứ nguyên với góc radian. Đây là một quy ước chọn norm, không phải “khoảng cách vật lý chính xác duy nhất”. Khi so các run, phải giữ cùng mô hình và cùng norm.

Khoảng cách hai quả cuối thì đơn giản là $|p_{2,B}-p_{2,A}|$, lấy từ world geometry. Đừng trừ tọa độ screen giữa hai panel: lúc đầu screen đã cách nhau 530 pixel dù trạng thái gần như trùng.

Ta vẽ d(t) trên trục log để thấy cả mức 1e-4 lẫn mức gần 1. Nếu d=0, log không xác định; renderer vẽ tại sàn 1e-12 và ghi rõ đó chỉ là sàn hiển thị. Số đo d vẫn phải giữ bằng 0.

## Viết code từng bước

Viết phần của bạn trong starter/include và starter/src. Khi thay một hàm, xóa bản cũ rồi thay bằng bản mới, không thêm hàm trùng tên. Các hàm thuộc header đặt trong namespace lab đã có sẵn. Checkpoint 5 là bản tham khảo ở cuối bài; build checkpoint không kiểm phần bạn vừa viết trong Starter.

### Bước 1 — Xử lý tính tuần hoàn tại đúng chỗ

Trong include/lab.hpp, thêm wrapAngle sau stepTwinPendulums. Hai góc cách nhau nguyên một vòng phải được xem là cùng hướng khi đo.

```cpp title="include/lab.hpp — wrap hiệu góc"
inline double wrapAngle(double angle) {
    if (!std::isfinite(angle)) {
        return std::numeric_limits<double>::quiet_NaN();
    }
    double wrapped = std::fmod(angle + kPi, 2.0 * kPi);
    if (wrapped < 0.0) {
        wrapped += 2.0 * kPi;
    }
    wrapped -= kPi;
    if (wrapped == -kPi && angle > 0.0) {
        wrapped = kPi;
    }
    return wrapped;
}
```

### Bước 2 — Viết hai khoảng cách với ý nghĩa khác nhau

Thêm hai hàm dưới. Cả hai đọc state gốc, không đọc vệt hoặc điểm pixel. phaseSpaceSeparation còn kiểm hai nhãn thời gian trước khi tính.

```cpp title="include/lab.hpp — khoảng cách trạng thái"
inline double phaseSpaceSeparation(const DoublePendulumState& first, const DoublePendulumState& second, const DoublePendulumParameters& parameters) {
    if (!finiteState(first) || !finiteState(second) || !validParameters(parameters) || !sameTime(first.elapsed, second.elapsed)) {
        return std::numeric_limits<double>::quiet_NaN();
    }
    const double timeScale = std::sqrt((0.5 * parameters.length1 + 0.5 * parameters.length2) / parameters.gravity);
    const double angle1Difference = wrapAngle(second.theta1 - first.theta1);
    const double angle2Difference = wrapAngle(second.theta2 - first.theta2);
    const double omega1Difference = (second.omega1 - first.omega1) * timeScale;
    const double omega2Difference = (second.omega2 - first.omega2) * timeScale;
    return std::hypot(std::hypot(angle1Difference, angle2Difference), std::hypot(omega1Difference, omega2Difference));
}
```

```cpp title="include/lab.hpp — khoảng cách hai quả cuối theo mét"
inline double secondBobSeparation(const DoublePendulumState& first, const DoublePendulumState& second, const DoublePendulumParameters& parameters) {
    const DoublePendulumGeometry firstGeometry = pendulumGeometry(first, parameters);
    const DoublePendulumGeometry secondGeometry = pendulumGeometry(second, parameters);
    return length(subtract(secondGeometry.bob2, firstGeometry.bob2));
}
```

### Bước 3 — Gom số liệu và xử lý trường hợp chưa có exponent

Thêm TwinMetrics và measureTwins. Thời lượng dùng để tính tốc độ tăng trưởng phải là elapsed hiện tại trừ elapsed ban đầu, không phải thời gian hệ thống kể từ khi mở chương trình.

```cpp title="include/lab.hpp — dữ liệu phép đo"
struct TwinMetrics {
    double phaseSeparation{};
    double secondBobDistance{};
    double finiteTimeExponent{std::numeric_limits<double>::quiet_NaN()};
    double relativeEnergyDrift{std::numeric_limits<double>::quiet_NaN()};
    double perturbedRelativeEnergyDrift{std::numeric_limits<double>::quiet_NaN()};
    double absoluteEnergyDrift{};
    double perturbedAbsoluteEnergyDrift{};
    bool finite{};
};
```

```cpp title="include/lab.hpp — đo cặp trạng thái"
inline TwinMetrics measureTwins(const TwinPendulums& twins, const DoublePendulumParameters& parameters) {
    TwinMetrics metrics{};
    metrics.phaseSeparation = phaseSpaceSeparation(twins.primary, twins.perturbed, parameters);
    metrics.secondBobDistance = secondBobSeparation(twins.primary, twins.perturbed, parameters);
    const double initialSeparation = phaseSpaceSeparation(twins.initialPrimary, twins.initialPerturbed, parameters);
    const double duration = twins.primary.elapsed - twins.initialPrimary.elapsed;
    if (duration > 0.0 && initialSeparation > 0.0 && metrics.phaseSeparation > 0.0) {
        metrics.finiteTimeExponent = (std::log(metrics.phaseSeparation) - std::log(initialSeparation)) / duration;
    }
    const double initialEnergy = pendulumEnergy(twins.initialPrimary, parameters);
    const double perturbedInitialEnergy = pendulumEnergy(twins.initialPerturbed, parameters);
    metrics.absoluteEnergyDrift = pendulumEnergy(twins.primary, parameters) - initialEnergy;
    metrics.perturbedAbsoluteEnergyDrift = pendulumEnergy(twins.perturbed, parameters) - perturbedInitialEnergy;
    if (std::abs(initialEnergy) > kChaosEpsilon) {
        metrics.relativeEnergyDrift = metrics.absoluteEnergyDrift / std::abs(initialEnergy);
    }
    if (std::abs(perturbedInitialEnergy) > kChaosEpsilon) {
        metrics.perturbedRelativeEnergyDrift = metrics.perturbedAbsoluteEnergyDrift / std::abs(perturbedInitialEnergy);
    }
    metrics.finite = finiteState(twins.primary) && finiteState(twins.perturbed) && std::isfinite(metrics.phaseSeparation) && std::isfinite(metrics.secondBobDistance) && std::isfinite(metrics.absoluteEnergyDrift) && std::isfinite(metrics.perturbedAbsoluteEnergyDrift);
    return metrics;
}
```

Giá trị log(d/d0)/t chỉ là tốc độ tăng trưởng trên một khoảng thời gian cụ thể. Nó có thể âm, thay đổi theo thời lượng hoặc mất ý nghĩa sau khi khoảng cách đã bão hòa. Chưa có renormalization hay giới hạn thời gian vô hạn, nên không gọi nó là Lyapunov exponent đã hội tụ.

Khi t=0 hoặc d0=0 hoặc d=0, để exponent là NaN và hiển thị “chưa xác định”. Nếu E0=0 thì relative drift cũng chưa xác định; absolute energy drift vẫn đo được. Không biến một phép chia không xác định thành số 0 chỉ để bảng nhìn đẹp.

### Bước 4 — Đưa số đo vào history của physics

Thay HistorySample và recordHistory trong include/scene.hpp. Những hàm update khác của bài 4 giữ nguyên.

```cpp title="include/scene.hpp — mẫu có độ tách"
struct HistorySample {
    double time{};
    double energyErrorA{};
    double energyErrorB{};
    double physical{};
};
```

```cpp title="include/scene.hpp — lấy mẫu cùng thời điểm"
inline void recordHistory(Scene& scene, bool force = false) {
    const auto& primary = primaryState(scene);
    if (!scene.history.empty()) {
        const double interval = primary.elapsed - scene.history.back().time;
        if (interval <= 1e-12 || (!force && interval < 0.04 - 1e-12)) {
            return;
        }
    }
    HistorySample sample{};
    sample.time = primary.elapsed;
    sample.energyErrorA = pendulumEnergy(primary, scene.parameters) - scene.initialEnergyA;
    sample.energyErrorB = pendulumEnergy(perturbedState(scene), scene.parameters) - scene.initialEnergyB;
    scene.trailA.push_back(pendulumGeometry(primary, scene.parameters).bob2);
    scene.trailB.push_back(pendulumGeometry(perturbedState(scene), scene.parameters).bob2);
    if (scene.trailA.size() > 751) {
        scene.trailA.erase(scene.trailA.begin());
        scene.trailB.erase(scene.trailB.begin());
    }
    sample.physical = phaseSpaceSeparation(primary, perturbedState(scene), scene.parameters);
    scene.history.push_back(sample);
    if (scene.history.size() > 751) {
        scene.history.erase(scene.history.begin());
    }
}
```

### Bước 5 — Vẽ trục log nhưng không sửa dữ liệu

inline double separationGraphY(double value) {
    const double logarithm = std::log10(std::max(1e-12, value));
    const double normalized = std::clamp((logarithm + 12.0) / 14.0, 0.0, 1.0);
    return 730.0 - 140.0 * normalized;
}

inline void drawSeparationGraph(Framebuffer& image, const Scene& scene) {
    rectangle(image, 40, 590, 530, 730, kGrid, false);
    if (scene.history.empty()) {
        return;
    }
    const double first = scene.history.front().time;
    const double span = std::max(kStepOptions[scene.dtIndex], scene.history.back().time - first);
    for (std::size_t i = 1; i < scene.history.size(); ++i) {
        const auto& a = scene.history[i - 1];
        const auto& b = scene.history[i];
        const double x0 = graphTimeX(a.time, first, span, 40);
        const double x1 = graphTimeX(b.time, first, span, 40);
        drawLine(image, x0, separationGraphY(a.physical), x1, separationGraphY(b.physical), kPhysicalGraph);
    }
}

## Ghép các phần lại

Không thêm solver hoặc accumulator mới vào main. Các phép đo đều nằm sau một bước A/B đã chấp nhận, rồi đi vào history và renderer.

Đọc đường tím cùng số d và khoảng cách quả cuối. Hai giá trị có thể tăng giảm khác nhau vì chúng đo hai thứ khác nhau. Trục log hiển thị trong khoảng 1e-12 đến 1e2; nếu điểm ra ngoài, phần vẽ bị cắt chứ state và metric không bị clamp.

## Thử làm sai để hiểu đúng

1. Lấy abs(thetaB−thetaA) mà không wrap. Kiểm cặp +179°/−179° trước khi tin một đỉnh nhọn trên graph.
2. Cộng trực tiếp chênh lệch omega vào chênh lệch theta mà không có thang thời gian. Bạn đã trộn hai đơn vị khác nhau.
3. Dùng index mẫu làm trục X. Tạo các mẫu ở 0, 1 và 4 s: điểm giữa phải nằm ở 1/4 bề ngang, không phải chính giữa.
4. Gán d=max(d,1e-12) vào metric. Epsilon=0 sẽ không còn được báo đúng; chỉ đặt sàn ở renderer.

## Tự kiểm tra kết quả

- +179° và −179° cho chênh lệch hướng 2°, không phải 358°.
- Hai hướng lệch một vòng có wrapped difference gần 0.
- A/B giống hệt nhau cho d=0 và không tạo exponent giả.
- Khoảng cách quả cuối lấy trong world space, không đổi chỉ vì hai panel đặt xa nhau.
- Trục X đọc timestamp, trục dọc log ghi rõ sàn hiển thị; ΔE vẫn là graph Joule riêng.
- Hai state khác thời điểm bị từ chối khi gọi phép đo phase space.
