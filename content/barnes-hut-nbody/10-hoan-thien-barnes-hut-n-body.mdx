# Theo dõi năng lượng và tách sai số theo dt

## Vấn đề cần giải quyết

Một thiên hà có thể nhìn thuyết phục ngay cả khi đang âm thầm tăng năng lượng. Sản phẩm cuối phải kể được cả hai câu chuyện: người xem nhận ra hình khối 3D, còn người viết chương trình chỉ ra được sao vừa đi đâu, vì sao nó đi và phép tính có đáng tin đến đâu.

## Hiểu ý tưởng trước khi viết code

Theo dõi động năng $K=\tfrac12\sum_i m_i\lVert\mathbf v_i\rVert^2$ và thế năng dùng **cùng softening** với lực: $U=-G\sum_{i<j}m_i m_j/\sqrt{r_{ij}^2+\epsilon^2}$. Điều kiện $i<j$ chỉ giữ một trong hai cặp $(i,j)$ và $(j,i)$. Khác bài 03, năng lượng cả hệ không cần hai đóng góp có hướng.

Hãy tách hai thí nghiệm. Đổi `theta`, giữ vị trí và `epsilon`, rồi so **gia tốc** với direct để đo sai số xấp xỉ theo không gian. Sau đó giữ `theta` và `epsilon`, giảm `dt` và so **vị trí** tại cùng thời điểm cuối để xem sai số tích phân. Một cặp sao quay tròn kiểm được bước thời gian tốt hơn việc cố nhớ thiên hà trông thế nào mười giây trước.

## Viết code từng bước

### Chốt xem ta đang đo thời điểm nào

```cpp title="include/experiments.hpp — Giữ nguyên trạng thái trong suốt phép đo"
void start(const Simulation& simulation) {
    *this = {};
    snapshot = simulation.bodies;
    time = simulation.time;
    epsilon = simulation.epsilon;
    result.centerOfMass = centerOfMass(snapshot);
    result.momentum = totalMomentum(snapshot);
    for (const Body& body : snapshot) {
        result.kineticEnergy += 0.5 * body.mass * lengthSquared(body.velocity);
    }
    active = true;
}
```

`start` chép các sao, thời điểm và `epsilon`. Mỗi sao chỉ có một đóng góp động năng; động lượng và tâm khối cùng đọc từ bản chụp này. Nếu dùng vị trí mới với vận tốc cũ, tổng năng lượng không còn là của một thời điểm nào.

### Chia phép tính cho nhiều lượt mà không bỏ cặp

{/* snippet include/experiments.hpp#energy-batch */}
```cpp title="include/experiments.hpp — Mỗi cặp chỉ đóng góp đúng một lần"
void tick() {
    const auto until = std::chrono::steady_clock::now() + std::chrono::milliseconds(6);
    while (first < snapshot.size()) {
        for (std::size_t second = first + 1; second < snapshot.size(); ++second) {
            const double r2 = lengthSquared(snapshot[second].position - snapshot[first].position);
            result.potentialEnergy -= gravity * snapshot[first].mass * snapshot[second].mass / std::sqrt(r2 + epsilon * epsilon);
        }
        ++first;
        if (std::chrono::steady_clock::now() >= until) {
            return;
        }
    }
    result.totalEnergy = result.kineticEnergy + result.potentialEnergy;
    active = false;
}
```

Với 4.096 vật có 8.386.560 cặp độc lập. `first` giữ vị trí tiếp tục sau khi trả quyền cho cửa sổ. Chỉ cộng `kineticEnergy + potentialEnergy` và công bố mẫu khi đã xét hết; không ngoại suy từ một vùng đông sao.

### Tự kiểm integrator bằng hệ hai vật

```cpp title="include/experiments.hpp — So cùng thời điểm cuối với quỹ đạo đã biết"
for (int step = 0; step < count; ++step) {
    const auto tree = buildMassOctree(bodies);
    const auto acceleration = barnesHutAccelerations(tree, bodies, 0.5, gravity, 0.02);
    integrateSymplecticEuler(bodies, acceleration, dt);
}
// Exact softened circular orbit at T=1, independent of both integrators.
const Vec3 exact{-std::cos(omega), -std::sin(omega), 0};
const double energy = systemDiagnostics(bodies, gravity, 0.02).totalEnergy;
rows.push_back({dt, length(bodies[0].position - exact), (energy - initialEnergy) / std::abs(initialEnergy)});
```

Ở đây `count` bước có độ dài `dt = 1 / count`, nên điểm đến luôn là `T = 1`. Vị trí đúng đến từ nghiệm tròn đã biết, không phải từ chính solver đang được kiểm. Hãy đọc cả sai số vị trí: riêng năng lượng trôi ít chưa chứng minh ngôi sao đến đúng chỗ.


## Thử làm sai để hiểu đúng

Tạm đổi `second = first + 1` thành `second = 0`. Khi đó sẽ có cặp tự thân và cặp đếm đôi; dù chương trình vẫn trả số hữu hạn, nó không còn là thế năng của hệ. Khôi phục giới hạn đúng.

Lấy hai mẫu ở hai giá trị `epsilon` rồi kết luận năng lượng không bảo toàn. Thật ra bạn vừa đổi thế năng của mô hình; bắt đầu lại và chỉ đổi một đại lượng mỗi lần.
