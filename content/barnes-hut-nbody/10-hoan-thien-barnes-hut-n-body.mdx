# Theo dõi năng lượng và tách sai số theo dt

## Vấn đề cần giải quyết

Hình đẹp, lực gần đúng và benchmark chưa đủ khép lại mô phỏng. Ta còn phải biết hệ đang trôi bao nhiêu, năng lượng đổi ra sao và phần sai lệch nào đến từ bước thời gian. Bài cuối nối diagnostics vào ứng dụng thật rồi thực hiện quy trình nghiệm thu 4.096 body.

## Hiểu ý tưởng trước khi viết code

Động năng dùng mọi body; thế năng dùng mọi cặp $i<j$ đúng một lần và cùng epsilon với solver:

$$
K=\frac12\sum_i m_i\|\mathbf v_i\|^2,\qquad
U=-\sum_{i<j}\frac{Gm_im_j}{\sqrt{\|\mathbf p_i-\mathbf p_j\|^2+\epsilon^2}}.
$$

Không lấy 512 body đầu để gọi là energy toàn hệ 4.096 body. EnergyJob giữ snapshot đầy đủ, chia phép cộng theo first index và ghi N/t cạnh kết quả. C++ lưu mẫu định kỳ khi chạy; Canvas cho chủ động dừng và lấy mẫu, giữ tối đa 64 mẫu. Momentum và center of mass cũng dùng toàn snapshot.

Barnes–Hut có force approximation; symplectic Euler có integration error. Không kỳ vọng E/P bất biến đến machine epsilon. Để tách integration error, dùng hai body bằng mass quay tròn trong potential mềm, giữ theta=0,5, epsilon=0,02, T=1; chỉ đổi dt. Tần số tròn được suy từ lực hướng tâm, không lấy từ integrator:

$$
\omega^2=\frac{G(m_1+m_2)}{(r^2+\epsilon^2)^{3/2}}.
$$

Đây là kiểm thời gian ngắn có nghiệm độc lập, không phải so hai quỹ đạo hỗn loạn sau rất lâu.

## Viết code từng bước

### Cộng đủ hệ mà vẫn nhận input

```cpp title="include/experiments.hpp — Cộng đủ hệ mà vẫn nhận input"
struct EnergyJob {
    std::vector<Body> snapshot{};
    SystemDiagnostics result{};
    double time{};
    double epsilon{0.02};
    std::size_t first{};
    bool active{};

    void start(const Simulation& simulation) {
        *this = {};
        snapshot = simulation.bodies;
        time = simulation.time;
        epsilon = simulation.epsilon;
        result.centerOfMass = centerOfMass(snapshot);
        result.momentum = totalMomentum(snapshot);
        for (const Body& body : snapshot) {
            result.kineticEnergy += 0.5 * body.mass * lengthSquared(body.velocity);
        }
        active = true;
    }

    // [snippet:energyBatch]
    void tick() {
        const auto until = std::chrono::steady_clock::now() + std::chrono::milliseconds(6);
        while (first < snapshot.size()) {
            for (std::size_t second = first + 1; second < snapshot.size(); ++second) {
                const double r2 = lengthSquared(snapshot[second].position - snapshot[first].position);
                result.potentialEnergy -= gravity * snapshot[first].mass * snapshot[second].mass / std::sqrt(r2 + epsilon * epsilon);
            }
            ++first;
            if (std::chrono::steady_clock::now() >= until) {
                return;
            }
        }
        result.totalEnergy = result.kineticEnergy + result.potentialEnergy;
        active = false;
    }

    // [/snippet:energyBatch]
};
```

start giữ snapshot và các tổng O(N). tick tính phần cặp O(N²) theo từng first index; chỉ đánh dấu xong khi cộng hết. Một energy sample phải mang thời điểm của snapshot, không gắn nhãn thời điểm frame vừa vẽ.

### Giữ mô hình, theta và thời điểm so sánh

```cpp title="include/experiments.hpp — Giữ mô hình, theta và thời điểm so sánh"
inline std::vector<TimestepRow> timestepStudy() {
    std::vector<TimestepRow> rows{};
    const auto initial = presetBodies(2, 2);
    const double omega = std::abs(initial[0].velocity.y);
    const double initialEnergy = systemDiagnostics(initial, gravity, 0.02).totalEnergy;
    for (const int count : {60, 120, 240}) {
        auto bodies = initial;
        const double dt = 1.0 / double(count);
        for (int step = 0; step < count; ++step) {
            const auto tree = buildMassOctree(bodies);
            const auto acceleration = barnesHutAccelerations(tree, bodies, 0.5, gravity, 0.02);
            integrateSymplecticEuler(bodies, acceleration, dt);
        }
        // Exact softened circular orbit at T=1, independent of both integrators.
        const Vec3 exact{-std::cos(omega), -std::sin(omega), 0};
        const double energy = systemDiagnostics(bodies, gravity, 0.02).totalEnergy;
        rows.push_back({dt, length(bodies[0].position - exact), (energy - initialEnergy) / std::abs(initialEnergy)});
    }
    return rows;
}
```

Ba run có cùng initial state, force model và T. Mỗi run chỉ đổi dt. Vị trí exact được tính bằng sin/cos của omega, không gọi lại solver làm expected value.

## Ghép các phần lại

Quy trình cần làm trên bản final: mở preset 4.096, đo E tại t=0; chạy rồi pause, đo lại; chọn target, sweep theta; đổi góc nhìn để kiểm snapshot không đổi; Reset cùng preset/seed. C++ E lấy mẫu năng lượng, I chạy thí nghiệm dt; Canvas có các nút tương ứng.

Đừng chỉ nhìn bảng số. Ở preset đĩa, bạn phải phân biệt được lõi dày và hai nhánh sao ở trạng thái đầu; khi xoay camera, đĩa phải có chiều dày thật. Chạy một lúc rồi dừng để xem các sao đã rời vị trí đầu như thế nào. Hai nhánh không bị giữ nguyên hình dạng: vận tốc quay khác nhau theo bán kính và tương tác hấp dẫn sẽ làm chúng biến đổi. Halo sáng là cách vẽ position hiện tại, không phải ảnh nền hay phần bổ sung vào energy.

Preset hai thiên hà tạo hai hệ riêng, mỗi hệ có central mass 60 và đĩa tổng mass xấp xỉ 60. Đĩa thứ hai nghiêng so với đĩa thứ nhất; cả position lẫn velocity được quay cùng một phép biến đổi. Nhờ vậy ta có thể quan sát một cuộc gặp trong không gian 3D mà không dùng đường đi định sẵn. Đổi camera chỉ đổi hình chiếu; đổi preset mới thay điều kiện đầu.

Bạn cũng có thể bấm N để tiến một bước rồi E để lấy mẫu tiếp theo. Các mẫu trước vẫn được giữ. HUD C++ hiển thị thay đổi năng lượng tương đối và độ dài vector thay đổi động lượng so với mẫu đầu trong lịch sử. Mẫu số năng lượng là max(|Eref|, 10⁻¹² energy unit), để trường hợp energy gần 0 không gây chia cho 0. Đọc `ref t` để biết mốc đối chiếu: lịch sử chỉ giữ 64 mẫu nên mốc này có thể dịch về sau, không phải lúc nào cũng là t=0. Reset hoặc đổi cấu hình sẽ bắt đầu một thí nghiệm mới.

## Thử làm sai để hiểu đúng

Cố ý đo energy chỉ trên một prefix rồi ghi N=4.096: số hữu hạn nhưng nhãn sai phạm vi. Khôi phục full snapshot. Thay epsilon giữa hai mẫu nhưng vẫn diễn giải ΔE như một định luật bảo toàn: bạn đã đổi potential. Cuối cùng, giảm dt mà đồng thời đổi theta để thấy thí nghiệm không còn tách được nguồn sai số.
