# Gộp khối lượng từ lá lên gốc Octree

## Vấn đề cần giải quyết

Chọn một sao rồi tưởng tượng bạn đứng tại đó nhìn về phía bên kia thiên hà. Một cụm nằm rất xa có thể thay bằng một vật nặng; nhưng đặt vật thay thế ở tâm cái hộp chứa cụm hay ở nơi khối lượng tập trung? Bài này dựng cái cây mang thông tin để trả lời.

## Hiểu ý tưởng trước khi viết code

Octree ở Project 30 giúp tìm các điểm nằm trong một vùng. Ở đây mỗi ô còn lưu tổng khối lượng và tâm khối: $M=\sum m_i$, $\mathbf c=\sum m_i\mathbf x_i/M$. Nếu một góc của hộp chứa nhiều sao nặng, tâm khối lệch về góc ấy. Tâm hình học của hộp thì không hề đổi.

Ta làm hai lượt. Lượt đầu đưa từng ID vào đúng lá. Lượt sau mới đi ngược từ lá lên gốc, cộng các cụm con. Đừng tính tâm khối lúc chưa biết cụm còn nhận thêm sao nào.

## Viết code từng bước

### Cho mỗi ô một chỗ giữ kết quả

{/* snippet include/tree.hpp#tree-node */}
```cpp title="include/tree.hpp — Một ô cây giữ hình học và khối lượng"
struct BarnesHutNode {
    Bounds3D bounds{};
    int depth{};
    std::vector<std::size_t> bodyIndices{};
    std::array<std::size_t, 8> children{
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
    };
    double totalMass{};
    Vec3 centerOfMass{};

    bool isLeaf() const {
        return children[0] == noNodeIndex;
    }
};
```

Lá giữ `bodyIndices` thật. Ô đã chia dùng tám chỉ số con; nó không cần lưu lần thứ hai các sao đang ở lá. Dùng chỉ số vì khi `vector` nở ra, một tham chiếu cũ có thể hết hiệu lực.

### Biết lúc nào không nên chia nhỏ hơn

```cpp title="include/tree.hpp — Điểm trùng tọa độ vẫn có chỗ ở"
if (
    tree.nodes[nodeIndex].bodyIndices.size() < tree.config.leafCapacity ||
    !nodeCanSplit(tree.nodes[nodeIndex], tree.config) ||
    tree.nodes.size() + 8U > 262'145U
) {
    tree.nodes[nodeIndex].bodyIndices.push_back(bodyIndex);
    return;
}
```

Đừng ép hai sao trùng nhau tách sang hai lá. Giới hạn độ sâu/kích thước bảo đảm việc dựng cây kết thúc; khi đó một lá có thể chứa nhiều hơn số sao thường lệ.

### Cộng từ con lên cha

```cpp title="include/tree.hpp — Lá cân sao thật, ô cha cân các cụm con"
if (tree.nodes[nodeIndex].isLeaf()) {
    for (const std::size_t bodyIndex : tree.nodes[nodeIndex].bodyIndices) {
        mass += bodies[bodyIndex].mass;
        weightedPosition += bodies[bodyIndex].position * bodies[bodyIndex].mass;
    }
} else {
    for (const std::size_t childIndex : tree.nodes[nodeIndex].children) {
        accumulateNodeMass(tree, bodies, childIndex);
        mass += tree.nodes[childIndex].totalMass;
        weightedPosition +=
            tree.nodes[childIndex].centerOfMass * tree.nodes[childIndex].totalMass;
    }
}
```

Lấy khối lượng con làm trọng số cho **tâm khối con**. Sau vòng cộng, ô cha chia tổng có trọng số cho tổng khối lượng. Xem thứ tự gọi: cây có đủ tất cả sao trước khi tính tổng lần đầu.

```cpp title="include/tree.hpp — Chèn hết ID rồi mới tính tâm khối từ gốc"
tree.nodes.push_back({cubicBoundsForBodies(bodies), 0});
for (std::size_t bodyIndex = 0; bodyIndex < bodies.size(); ++bodyIndex) {
    insertBodyAtNode(tree, bodies, bodyIndex, 0);
}
accumulateNodeMass(tree, bodies, 0);
```

## Thử làm sai để hiểu đúng

Thử chia tổng tâm khối các ô con cho số ô có sao. Hai cụm khối lượng 1 và 9 ở `x = 0` và `x = 10` sẽ cho 5 thay vì 9. Khôi phục đúng trọng số.

## Tự kiểm tra kết quả

- Mỗi ID chỉ nằm ở một lá; ô trong không giữ lại bản sao của ID.
- Tổng khối lượng ở gốc bằng tổng khối lượng quét trực tiếp qua `bodies`.
- Các sao trùng tọa độ không làm cây chia mãi. Đổi góc nhìn không dựng một phân bố sao mới.
