# Gộp khối lượng từ lá lên gốc Octree

## Vấn đề cần giải quyết

Direct solver đã có chuyển động và đáp án đối chứng. Bây giờ mới dùng Octree. Khác Project 30, node ở đây không chỉ nói điểm nằm ở đâu: nó phải đại diện cho tổng khối lượng và tâm khối của cả subtree.

## Hiểu ý tưởng trước khi viết code

Hộp node là vùng hình học dùng chia dữ liệu. Center of mass là đại lượng vật lý, có thể lệch xa tâm hộp. Leaf cộng body thật; internal node cộng children bằng trọng số:

$$
M=\sum_k M_k,\qquad\mathbf c=\frac{\sum_k M_k\mathbf c_k}{M}.
$$

Cây chia tám octant trong XYZ. Body đúng trên mặt chia đi về phía dương của trục tương ứng. Điểm trùng phải dừng tách ở maximumDepth/minimumNodeSize hoặc node budget, không tạo chuỗi node vô hạn.

Giới hạn của bản này là N≤8.192, maximumDepth≤20 khi cấu hình, mặc định depth 16, và tối đa 262.145 node. Khi chạm node budget, leaf giữ nhiều body hơn; traversal vẫn phải tính exact trên bucket ấy.

## Viết code từng bước

### Thêm dữ liệu vật lý vào node

```cpp title="include/tree.hpp — Thêm dữ liệu vật lý vào node"
struct BarnesHutNode {
    Bounds3D bounds{};
    int depth{};
    std::vector<std::size_t> bodyIndices{};
    std::array<std::size_t, 8> children{
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
        noNodeIndex,
    };
    double totalMass{};
    Vec3 centerOfMass{};

    bool isLeaf() const {
        return children[0] == noNodeIndex;
    }
};
```

Leaf lưu indices; internal node lưu children theo index. totalMass và centerOfMass tính từ dưới lên. Không gán tâm bounds vào centerOfMass.

### Chia mà không giữ reference hỏng

```cpp title="include/tree.hpp — Chia mà không giữ reference hỏng"
inline void insertBodyAtNode(
    BarnesHutTree& tree,
    std::span<const Body> bodies,
    std::size_t bodyIndex,
    std::size_t nodeIndex
) {
    if (!tree.nodes[nodeIndex].isLeaf()) {
        const int octant = barnesHutOctant(
            bodies[bodyIndex].position,
            tree.nodes[nodeIndex].bounds
        );
        const std::size_t childIndex = tree.nodes[nodeIndex].children[octant];
        insertBodyAtNode(tree, bodies, bodyIndex, childIndex);
        return;
    }

    if (
        tree.nodes[nodeIndex].bodyIndices.size() < tree.config.leafCapacity ||
        !nodeCanSplit(tree.nodes[nodeIndex], tree.config) ||
        tree.nodes.size() + 8U > 262'145U
    ) {
        tree.nodes[nodeIndex].bodyIndices.push_back(bodyIndex);
        return;
    }

    std::vector<std::size_t> indices = std::move(tree.nodes[nodeIndex].bodyIndices);
    indices.push_back(bodyIndex);
    const Bounds3D parentBounds = tree.nodes[nodeIndex].bounds;
    const int childDepth = tree.nodes[nodeIndex].depth + 1;
    const std::size_t firstChildIndex = tree.nodes.size();
    for (int octant = 0; octant < 8; ++octant) {
        BarnesHutNode child{};
        child.bounds = barnesHutChildBounds(parentBounds, octant);
        child.depth = childDepth;
        tree.nodes.push_back(std::move(child));
    }
    for (int octant = 0; octant < 8; ++octant) {
        tree.nodes[nodeIndex].children[octant] = firstChildIndex + std::size_t(octant);
    }
    for (const std::size_t oldIndex : indices) {
        const int octant = barnesHutOctant(bodies[oldIndex].position, parentBounds);
        const std::size_t childIndex = tree.nodes[nodeIndex].children[octant];
        insertBodyAtNode(tree, bodies, oldIndex, childIndex);
    }
}
```

Vector nodes có thể reallocate khi thêm tám child. Hàm giữ nodeIndex, sao bounds/depth trước push_back rồi truy cập lại bằng index để gắn children.

### Cộng từ lá lên gốc

```cpp title="include/tree.hpp — Cộng từ lá lên gốc"
inline void accumulateNodeMass(
    BarnesHutTree& tree,
    std::span<const Body> bodies,
    std::size_t nodeIndex
) {
    double mass = 0.0;
    Vec3 weightedPosition{};
    if (tree.nodes[nodeIndex].isLeaf()) {
        for (const std::size_t bodyIndex : tree.nodes[nodeIndex].bodyIndices) {
            mass += bodies[bodyIndex].mass;
            weightedPosition += bodies[bodyIndex].position * bodies[bodyIndex].mass;
        }
    } else {
        for (const std::size_t childIndex : tree.nodes[nodeIndex].children) {
            accumulateNodeMass(tree, bodies, childIndex);
            mass += tree.nodes[childIndex].totalMass;
            weightedPosition +=
                tree.nodes[childIndex].centerOfMass * tree.nodes[childIndex].totalMass;
        }
    }
    tree.nodes[nodeIndex].totalMass = mass;
    if (mass > 0.0) {
        tree.nodes[nodeIndex].centerOfMass = weightedPosition / mass;
    } else {
        tree.nodes[nodeIndex].centerOfMass = {};
    }
}
```

weightedPosition cộng m·p ở leaf hoặc M_child·c_child ở internal node. Child rỗng có mass 0, không đóng góp; không lấy trung bình tám center.

### Nối lifecycle với snapshot

```cpp title="include/tree.hpp — Nối lifecycle với snapshot"
inline BarnesHutTree buildMassOctree(
    std::span<const Body> bodies,
    const BarnesHutConfig& config = {}
) {
    if (bodies.size() > 8192 || config.leafCapacity < 1 || config.maximumDepth < 1 ||
        config.maximumDepth > 20 || !std::isfinite(config.minimumNodeSize) || config.minimumNodeSize <= 0) {
        throw std::invalid_argument("Invalid tree budget/configuration");
    }
    for (const Body& body : bodies) {
        if (!finiteVector(body.position) || !finiteVector(body.velocity) ||
            !std::isfinite(body.mass) || body.mass <= 0) {
            throw std::invalid_argument("Body state must be finite, mass positive");
        }
    }
    const auto started = std::chrono::steady_clock::now();
    BarnesHutTree tree{};
    tree.config = config;
    tree.bodyCount = bodies.size();
    tree.nodes.push_back({cubicBoundsForBodies(bodies), 0});
    for (std::size_t bodyIndex = 0; bodyIndex < bodies.size(); ++bodyIndex) {
        insertBodyAtNode(tree, bodies, bodyIndex, 0);
    }
    accumulateNodeMass(tree, bodies, 0);
    for (const BarnesHutNode& node : tree.nodes) {
        tree.maximumObservedDepth = std::max(tree.maximumObservedDepth, node.depth);
        if (node.isLeaf()) {
            ++tree.leafCount;
            tree.maximumLeafOccupancy =
                std::max(tree.maximumLeafOccupancy, node.bodyIndices.size());
        } else {
            ++tree.internalNodeCount;
        }
    }
    const auto finished = std::chrono::steady_clock::now();
    tree.rebuildMicroseconds =
        std::chrono::duration<double, std::micro>(finished - started).count();
    return tree;
}
```

Input phải hữu hạn, mass dương và nằm trong budget. Insert xong mới accumulate. Kết quả thuộc snapshot hiện tại: rebuild sau physics commit, không rebuild chỉ vì camera xoay.

## Thử làm sai để hiểu đúng

1. Đổi weightedPosition thành tổng position của child. Hộp vẫn vẽ đúng và storage vẫn đủ, nhưng tâm khối sai. Dùng fixture mass không bằng nhau để lộ lỗi rồi khôi phục trọng số.
2. Đặt 256 body trùng position và dự đoán cây sẽ dừng ở đâu. Giữ giới hạn depth để kiểm hữu hạn; không chạy bản bỏ mọi điều kiện dừng trên UI. Kiểm leaf cuối vẫn giữ đủ indices.

## Tự kiểm tra kết quả

- Mỗi body index ở đúng một leaf; internal node không giữ bodyIndices.
- Mass/COM của fixture khớp tính tay, absolute tolerance 10⁻⁹ trong reduced units.
- Vị trí trùng vẫn kết thúc, depth≤16 ở cấu hình mặc định.
- Sau physics commit, cây dùng position mới; camera không sửa aggregates.
