# Một vật thể hút vật thể khác như thế nào?

## Vấn đề cần giải quyết

Đĩa sao đã hiện ra, nhưng chưa có nguyên nhân khiến nó chuyển động. Ta bắt đầu bằng một câu hỏi nhỏ: một source body gây gia tốc gì cho một target body? Viết đúng phép tính này trước sẽ giúp kiểm cả direct solver lẫn Barnes–Hut bằng những ca tính được bằng tay.

## Hiểu ý tưởng trước khi viết code

Lực hướng từ target về source. Vì tính gia tốc a=F/m_target, mass của target triệt tiêu; sourceMass vẫn còn. Gọi r=source−target, ta dùng Plummer softening:

$$
\mathbf a=Gm_s\frac{\mathbf r}{(\|\mathbf r\|^2+\epsilon^2)^{3/2}}.
$$

Epsilon có đơn vị độ dài. Nó thay potential ở cự ly gần; không phải tham số sửa integrator và không phải radius cutoff. Nguồn xa vẫn tác dụng lực. Khi position trùng nhau và epsilon>0, displacement bằng 0 nên gia tốc hữu hạn bằng 0.

Checkpoint 02 vẽ vector của một cặp lên scene đứng yên. Đừng chạy cả thiên hà để đoán dấu của một công thức. Với target tại x=−1, source tại x=1, sourceMass=3, G=1 và epsilon=0,1, thành phần X phải là 6/(4,01)^(3/2).

## Viết code từng bước

### Tính gia tốc từ một nguồn

```cpp title="include/lab.hpp — Tính gia tốc từ một nguồn"
inline Vec3 softenedAcceleration(
    const Vec3& targetPosition,
    const Vec3& sourcePosition,
    double sourceMass,
    double gravitationalConstant,
    double softening
) {
    const Vec3 displacement = sourcePosition - targetPosition;
    const double softenedDistanceSquared =
        lengthSquared(displacement) + softening * softening;
    if (softenedDistanceSquared <= 0.0 || sourceMass <= 0.0) {
        return {};
    }
    const double inverseDistanceCubed =
        1.0 / std::pow(softenedDistanceSquared, 1.5);
    return displacement * (gravitationalConstant * sourceMass * inverseDistanceCubed);
}
```

displacement giữ hướng; softenedDistanceSquared giữ độ dài bình phương. Nhân với G·sourceMass/(r²+epsilon²)^(3/2) cho đơn vị length/time². Không normalize vector rồi vô tình làm mất một lũy thừa khoảng cách.

### Lấy dữ liệu từ state đang mở

```cpp title="include/simulation.hpp — Lấy dữ liệu từ state đang mở"
inline Vec3 pairAccelerationForSelected(const Simulation& simulation) {
    const Body& target = simulation.bodies[simulation.selected];
    const Body& source = simulation.bodies[0];
    return softenedAcceleration(target.position, source.position, source.mass, gravity, simulation.epsilon);
}
```

Target là body được chọn, source là body 0. Hàm không biết pixel hay camera. Đây là điểm nối giúp helper không bị bỏ rời khỏi ứng dụng.

### Gọi phép tính trong đường vẽ

```cpp title="include/presentation.hpp — Gọi phép tính trong đường vẽ"
inline void drawScene(std::span<std::uint32_t> pixels, int width, int height, const lab::Simulation& simulation) {
```

## Thử làm sai để hiểu đúng

Đổi source−target thành target−source: mũi tên quay sai hướng. Thay lũy thừa 3/2 trong mẫu bằng 1: ở cự ly xa, quy luật giảm không còn inverse-square. Khôi phục code trước khi học bài tiếp.

## Tự kiểm tra kết quả

- Fixture hai vật khớp tính tay với absolute tolerance 10⁻¹².
- Tăng source mass ba lần làm gia tốc tăng ba lần; đổi target mass không đổi gia tốc do nguồn ấy.
- Position trùng và epsilon>0 không tạo NaN/Inf.
- Xoay camera không đổi vector gia tốc trong world space.
