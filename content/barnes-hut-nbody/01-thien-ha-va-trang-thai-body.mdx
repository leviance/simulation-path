# Dựng đĩa sao từ một chương trình SDL đang chạy

## Vấn đề cần giải quyết

Ta đã dùng Octree để tìm điểm trong một vùng ở Project 30. Bây giờ câu hỏi khác hẳn: nếu mọi vật thể hút mọi vật thể khác, có cách nào giảm số phép tính mà vẫn giữ chuyển động hợp lý? Chưa nên trả lời bằng Barnes–Hut ngay. Trước hết, hãy mở được đĩa sao đứng yên, đổi góc nhìn và biết state nào thuộc về mô phỏng.

## Hiểu ý tưởng trước khi viết code

Starter đã có renderer CPU và event loop. Checkpoint 01 thêm phép đọc tổng khối lượng, tâm khối và momentum; chưa tiến thời gian. Body có position, velocity, mass trong XYZ thật. Đĩa nằm gần mặt phẳng XY nhưng có chiều dày theo Z. Camera tạo pixel để quan sát, không sửa position. Đây là mô hình học thuật dùng reduced units, không phải mô hình thiên hà quan trắc.

G=0,001; central body có mass 120, tổng mass đĩa xấp xỉ 120. Tăng N làm đĩa được lấy mẫu dày hơn, không làm mass tăng tỉ lệ với N. Velocity ban đầu là điều kiện đầu gần quỹ đạo tròn, không phải đường đi sẽ bị áp đặt. Ta trừ cùng bulk velocity khỏi mọi body để bỏ chuyển động tịnh tiến toàn hệ.

$$
\mathbf c=\frac{\sum_i m_i\mathbf p_i}{\sum_i m_i},\qquad\mathbf P=\sum_i m_i\mathbf v_i
$$

### Giữ một chương trình chạy được

```cpp title="src/main.cpp — Giữ một chương trình chạy được"
int main(int argc, char** argv) {
    bool smoke = false;
    bool workflow = false;
    bool benchmark = false;
    for (int index = 1; index < argc; ++index) {
        if (std::strcmp(argv[index], "--smoke") == 0) {
            smoke = true;
        } else if (std::strcmp(argv[index], "--smoke-workflow") == 0) {
            smoke = true;
            workflow = true;
        } else if (std::strcmp(argv[index], "--benchmark") == 0) {
            benchmark = true;
        } else {
            std::cerr << "Unknown argument: " << argv[index] << '\n';
            return EXIT_FAILURE;
        }
    }
    if (benchmark) {
        std::cerr << "Runtime study starts at checkpoint 09\n";
        return EXIT_FAILURE;
    }
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        std::cerr << SDL_GetError() << '\n';
        return EXIT_FAILURE;
    }
    SDL_Window* window = SDL_CreateWindow("Project 31 | 3D Barnes-Hut galaxy", 1120, 820, SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY);
    if (!window) {
        std::cerr << SDL_GetError() << '\n';
        SDL_Quit();
        return EXIT_FAILURE;
    }
    SDL_Renderer* renderer = SDL_CreateRenderer(window, nullptr);
    if (!renderer) {
        std::cerr << SDL_GetError() << '\n';
        SDL_DestroyWindow(window);
        SDL_Quit();
        return EXIT_FAILURE;
    }
    SDL_Texture* texture = SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_STREAMING, 1120, 570);
    if (!texture) {
        std::cerr << SDL_GetError() << '\n';
        SDL_DestroyRenderer(renderer);
        SDL_DestroyWindow(window);
        SDL_Quit();
        return EXIT_FAILURE;
    }
    SDL_SetRenderLogicalPresentation(renderer, 1120, 820, SDL_LOGICAL_PRESENTATION_LETTERBOX);
    SDL_SetRenderVSync(renderer, 1);
    int result = EXIT_SUCCESS;
    try {
        result = project31::runApplication(window, renderer, texture, smoke, workflow);
    } catch (const std::exception& error) {
        std::cerr << error.what() << '\n';
        result = EXIT_FAILURE;
    }
    // Reverse ownership order on every exit, including bounded-job failures.
    SDL_CaptureMouse(false);
    SDL_DestroyTexture(texture);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return result;
}
```

Đọc main theo thứ tự tạo window → renderer → texture, kiểm lỗi rồi gọi runApplication. Khi thất bại, chỉ hủy tài nguyên đã tạo. Starter cung cấp phần trình bày để bạn không phải viết lại SDL từ đầu.

### Sinh lại cùng thí nghiệm

```cpp title="include/lab.hpp — Sinh lại cùng thí nghiệm"
inline std::vector<Body> makeGalaxyBodies(std::size_t count, std::uint32_t seed) {
    if (count > 8192) {
        throw std::invalid_argument("Body budget: 1..8192");
    }
    const std::size_t safeCount = std::max<std::size_t>(1U, count);
    XorShift32 random(seed);
    std::vector<Body> bodies{};
    bodies.reserve(safeCount);
    bodies.push_back({{}, {}, 120.0});

    for (std::size_t index = 1; index < safeCount; ++index) {
        const double radius = 0.08 + std::sqrt(random.unit()) * 0.9;
        const double angle = random.unit() * 6.283185307179586;
        const double thickness = (random.unit() - 0.5) * 0.08 * (1.1 - radius);
        // Reduced units: G=0.001, central mass=120, disk mass approximately 120.
        // Increasing N refines the disk instead of increasing its total mass.
        const double mass = (0.7 + random.unit() * 0.6) * 120.0 / double(safeCount - 1);
        const double enclosedMass = 120.0 + 120.0 * radius * radius;
        const double orbitalSpeed = std::sqrt(0.001 * enclosedMass / radius);
        const double speedJitter = 0.92 + random.unit() * 0.16;
        bodies.push_back({
            {std::cos(angle) * radius, std::sin(angle) * radius, thickness},
            {
                -std::sin(angle) * orbitalSpeed * speedJitter,
                std::cos(angle) * orbitalSpeed * speedJitter,
                (random.unit() - 0.5) * 0.01,
            },
            mass,
        });
    }

    Vec3 momentum{};
    for (const Body& body : bodies) {
        momentum += body.velocity * body.mass;
    }
    double systemMass = 0;
    for (const Body& body : bodies) {
        systemMass += body.mass;
    }
    // A common velocity shift removes bulk drift without kicking the central body.
    const Vec3 bulkVelocity = momentum / systemMass;
    for (Body& body : bodies) {
        body.velocity = body.velocity - bulkVelocity;
    }
    return bodies;
}
```

Cùng count và seed phải cho cùng từng body. Chú ý mass của mỗi sao chia cho count−1. Cuối hàm, bulkVelocity được trừ khỏi toàn hệ; không đẩy riêng central body với velocity lớn để bù momentum.

### Dùng đúng trọng số

```cpp title="include/lab.hpp — Dùng đúng trọng số"
inline Vec3 centerOfMass(std::span<const Body> bodies) {
    double mass = 0.0;
    Vec3 weightedPosition{};
    for (const Body& body : bodies) {
        mass += body.mass;
        weightedPosition += body.position * body.mass;
    }
    if (mass <= 0.0) {
        return {};
    }
    return weightedPosition / mass;
}
```

weightedPosition là tổng m·p. Chỉ sau khi chia cho tổng mass mới có một vị trí. Tâm hộp bao hoặc trung bình các position không thay thế được nó.
