# Khi nào một cụm xa có thể thay bằng một nguồn?

## Vấn đề cần giải quyết

Cây đã giữ đúng mass và center of mass. Ta muốn một cụm xa được tính như một nguồn duy nhất, nhưng không thể thay mọi internal node bằng aggregate: ở gần, các nguồn phân bố trong cụm không còn tạo lực giống một điểm.

## Hiểu ý tưởng trước khi viết code

Gọi s là cạnh hộp node, d là khoảng cách từ target đến centerOfMass. Opening criterion của bản này là $s/d < \theta$. Theta nhỏ thường mở nhiều node hơn; theta lớn thường chấp nhận nhiều aggregate hơn. Không có cam kết error hay runtime giảm đơn điệu ở mọi snapshot.

Điều kiện hình học chưa đủ. Node chứa target không được chấp nhận dù s/d nhỏ, vì totalMass của nó chứa cả target. Phải mở tiếp đến leaf, rồi bỏ đúng sourceIndex==targetIndex. Không dùng khoảng cách đến tâm hộp thay cho center of mass.

Barnes–Hut vẫn tính nguồn xa, chỉ gộp chúng lại. Đây không phải radius cutoff như tìm hàng xóm Boids. Với một phân bố xấu hoặc theta gần 0, lượng việc có thể tiến gần direct.

## Viết code từng bước

### Ghi lại quyết định trong chính traversal

```cpp title="include/tree.hpp — Ghi lại quyết định trong chính traversal"
struct ForceTrace {
    std::vector<std::size_t> opened{};
    std::vector<std::size_t> accepted{};
};
```

opened và accepted là các node của target đang theo dõi. Chúng không phải danh sách mọi leaf trên màn hình. Ta chỉ bật trace khi cần xem một target, không lưu trace cho toàn bộ 4.096 body.

### Chọn nguồn tổng hợp hay mở tiếp

```cpp title="include/tree.hpp — Chọn nguồn tổng hợp hay mở tiếp"
inline void accumulateBarnesHutNode(
    const BarnesHutTree& tree,
    std::span<const Body> bodies,
    std::size_t targetIndex,
    std::size_t nodeIndex,
    double theta,
    double gravitationalConstant,
    double softening,
    AccelerationResult& result,
    ForceTrace* trace = nullptr
) {
    const BarnesHutNode& node = tree.nodes[nodeIndex];
    ++result.metrics.visitedNodes;
    if (node.totalMass <= 0.0) {
        return;
    }

    if (node.isLeaf()) {
        for (const std::size_t sourceIndex : node.bodyIndices) {
            if (sourceIndex == targetIndex) {
                continue;
            }
            result.acceleration += softenedAcceleration(
                bodies[targetIndex].position,
                bodies[sourceIndex].position,
                bodies[sourceIndex].mass,
                gravitationalConstant,
                softening
            );
            ++result.metrics.exactInteractions;
        }
        return;
    }

    const Vec3 displacement = node.centerOfMass - bodies[targetIndex].position;
    const double distanceToCenter = length(displacement);
    const double nodeSize = node.bounds.maximum.x - node.bounds.minimum.x;
    const bool containsTarget = pointInsideBounds(bodies[targetIndex].position, node.bounds);
    if (
        !containsTarget && distanceToCenter > 0.0 &&
        nodeSize / distanceToCenter < theta
    ) {
        result.acceleration += softenedAcceleration(
            bodies[targetIndex].position,
            node.centerOfMass,
            node.totalMass,
            gravitationalConstant,
            softening
        );
        ++result.metrics.approximatedNodes;
        if (trace) {
            trace->accepted.push_back(nodeIndex);
        }
        return;
    }

    if (trace) {
        trace->opened.push_back(nodeIndex);
    }
    for (const std::size_t childIndex : node.children) {
        accumulateBarnesHutNode(
            tree,
            bodies,
            targetIndex,
            childIndex,
            theta,
            gravitationalConstant,
            softening,
            result,
            trace
        );
    }
}
```

Đọc theo thứ tự: bỏ node rỗng; leaf cộng từng source thật; internal node kiểm containsTarget và s/d; nếu chưa được nhận thì đệ quy vào children. Gia tốc của nguồn tổng hợp dùng đúng softenedAcceleration đã kiểm ở bài 02.

### Giữ interface đối chiếu với direct

```cpp title="include/tree.hpp — Giữ interface đối chiếu với direct"
inline AccelerationResult barnesHutAcceleration(
    const BarnesHutTree& tree,
    std::span<const Body> bodies,
    std::size_t targetIndex,
    double theta,
    double gravitationalConstant,
    double softening,
    ForceTrace* trace = nullptr
) {
    AccelerationResult result{};
    if (targetIndex < bodies.size() && !tree.nodes.empty()) {
        accumulateBarnesHutNode(
            tree,
            bodies,
            targetIndex,
            0,
            theta,
            gravitationalConstant,
            softening,
            result,
            trace
        );
    }
    return result;
}
```

Wrapper trả vector acceleration và work counters như directAcceleration. Integrator không đổi công thức hoặc dt khi bạn đổi solver. Đó là điều kiện để quy sai khác lực cho xấp xỉ thay vì cho một mô hình khác.

## Thử làm sai để hiểu đúng

1. Bỏ containsTarget khỏi điều kiện nhận node và thử theta lớn trên fixture nhỏ. So vector với direct ở body gần tâm khối: self-force có thể xuất hiện. Khôi phục kiểm target trước khi đo tiếp.
2. Đặt theta rất nhỏ, giữ nguyên snapshot. Kết quả thường gần direct hơn nhưng lượng việc tăng; đọc cả sai số và số node mở, không chỉ nhìn quỹ đạo. Trả theta về preset đã chọn.

## Tự kiểm tra kết quả

- Mọi accepted node đều không chứa position của target.
- Một body duy nhất có acceleration=0, không có self interaction.
- Theta gần 0 khớp direct trong absolute tolerance 10⁻¹⁰ trên fixture nhỏ.
- Đổi Direct/BH ở cùng preset nhỏ giữ cùng integrator/dt và điều kiện đầu khi Reset.
