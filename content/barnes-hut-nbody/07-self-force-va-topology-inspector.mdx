# Tìm self-force và lỗi cấu trúc cây

## Vấn đề cần giải quyết

Một cây vẽ đẹp vẫn có thể giữ body hai lần hoặc cộng mass sai ở lá. Một thiên hà chuyển động được cũng chưa chứng minh traversal không tự tác động. Ta cần những phép kiểm có đáp án, trước khi xem runtime.

## Hiểu ý tưởng trước khi viết code

Inspector không gọi traversal để tự chứng minh traversal đúng. Nó đọc storage và aggregates, đối chiếu leaf với bodies thật, kiểm bounds/quan hệ cha con và đếm số lần mỗi index xuất hiện. Cây này được cấp phát theo thứ tự cha trước con: child phải có index lớn hơn parent, sâu hơn một mức và có đúng một cha.

Không được chỉ kiểm root mass bằng tổng child mass: nếu cùng một giá trị sai được lan từ leaf lên root, phép kiểm đó vẫn xanh. Leaf cần một reference độc lập là các body thực trong bucket. COM của leaf có mass khác nhau cũng phải được kiểm.

## Viết code từng bước

### Giữ tên cho từng loại lỗi

```cpp title="include/tree.hpp — Giữ tên cho từng loại lỗi"
struct BarnesHutTopologyReport {
    bool everyBodyStoredOnce{true};
    bool internalNodesEmpty{true};
    bool childIndicesValid{true};
    bool childBoundsValid{true};
    bool aggregateMassValid{true};
    bool centerOfMassValid{true};
    bool statisticsMatch{true};
};
```

Không nén mọi kết quả thành một boolean từ đầu. Storage, child indices/bounds, mass, center of mass và statistics là các hợp đồng khác nhau; tên lỗi giúp biết cần mở phần source nào.

### Kiểm cấu trúc mà không duyệt theo cạnh hỏng

```cpp title="include/tree.hpp — Kiểm cấu trúc mà không duyệt theo cạnh hỏng"
inline BarnesHutTopologyReport inspectMassOctree(
    const BarnesHutTree& tree,
    std::span<const Body> bodies
) {
    BarnesHutTopologyReport report{};
    std::vector<int> insertionCounts(bodies.size(), 0);
    std::vector<int> parentCounts(tree.nodes.size(), 0);
    std::size_t leaves = 0;
    std::size_t internalNodes = 0;
    for (std::size_t nodeIndex = 0; nodeIndex < tree.nodes.size(); ++nodeIndex) {
        const BarnesHutNode& node = tree.nodes[nodeIndex];
        if (node.isLeaf()) {
            ++leaves;
            double leafMass = 0;
            Vec3 weightedPosition{};
            for (const std::size_t bodyIndex : node.bodyIndices) {
                if (bodyIndex >= bodies.size()) {
                    report.childIndicesValid = false;
                } else {
                    ++insertionCounts[bodyIndex];
                    leafMass += bodies[bodyIndex].mass;
                    weightedPosition += bodies[bodyIndex].position * bodies[bodyIndex].mass;
                    report.childBoundsValid = report.childBoundsValid && pointInsideBounds(bodies[bodyIndex].position, node.bounds);
                }
            }
            report.aggregateMassValid = report.aggregateMassValid && nearlyEqual(leafMass, node.totalMass);
            if (leafMass > 0) {
                report.centerOfMassValid = report.centerOfMassValid && length(weightedPosition / leafMass - node.centerOfMass) <= 1e-9;
            }
            continue;
        }

        ++internalNodes;
        report.internalNodesEmpty = report.internalNodesEmpty && node.bodyIndices.empty();
        double childMass = 0.0;
        Vec3 weightedCenter{};
        for (int octant = 0; octant < 8; ++octant) {
            const std::size_t childIndex = node.children[octant];
            if (childIndex >= tree.nodes.size()) {
                report.childIndicesValid = false;
                continue;
            }
            const BarnesHutNode& child = tree.nodes[childIndex];
            ++parentCounts[childIndex];
            report.childIndicesValid = report.childIndicesValid && childIndex > nodeIndex && child.depth == node.depth + 1;
            report.childBoundsValid = report.childBoundsValid &&
                sameBounds(child.bounds, barnesHutChildBounds(node.bounds, octant));
            childMass += child.totalMass;
            weightedCenter += child.centerOfMass * child.totalMass;
        }
        report.aggregateMassValid =
            report.aggregateMassValid && nearlyEqual(childMass, node.totalMass);
        if (childMass > 0.0) {
            report.centerOfMassValid = report.centerOfMassValid &&
                length(weightedCenter / childMass - node.centerOfMass) <= 1.0e-9;
        }
    }
    report.everyBodyStoredOnce = std::all_of(
        insertionCounts.begin(),
        insertionCounts.end(),
        [](int count) {
            return count == 1;
        }
    );
    for (std::size_t index = 0; index < parentCounts.size(); ++index) {
        int expected = 1;
        if (index == 0) {
            expected = 0;
        }
        report.childIndicesValid = report.childIndicesValid && parentCounts[index] == expected;
    }
    report.statisticsMatch = leaves == tree.leafCount &&
        internalNodes == tree.internalNodeCount &&
        leaves + internalNodes == tree.nodes.size();
    return report;
}
```

Inspector đi tuyến tính qua vector nodes. Nó không recurse theo một cạnh có thể tạo chu trình. parentCounts và điều kiện childIndex>nodeIndex phát hiện cạnh ngược hoặc node không có cha; leaf được đối chiếu mass/COM bằng body thật.

### Dùng fixture để buộc lỗi lộ ra

```cpp title="tests/tests.cpp — Dùng fixture để buộc lỗi lộ ra"
void testMassOctreeTopology() {
    const std::vector<lab::Body> bodies = lab::makeGalaxyBodies(512, 0x31c0ffeeU);
    const lab::BarnesHutTree tree = lab::buildMassOctree(bodies);
    const lab::BarnesHutTopologyReport report = lab::inspectMassOctree(tree, bodies);
    check(report.everyBodyStoredOnce, "each body index appears in exactly one leaf");
    check(report.internalNodesEmpty, "internal nodes do not retain body indices");
    check(report.childIndicesValid, "every child index points to an existing node");
    check(report.childBoundsValid, "child bounds match their octant bits");
    check(report.aggregateMassValid, "each internal mass equals the sum of child masses");
    check(report.centerOfMassValid, "each center of mass is a mass-weighted child average");
    check(report.statisticsMatch, "stored topology matches reported tree statistics");
    check(
        near(tree.nodes[0].totalMass, lab::totalMass(bodies)),
        "root aggregate mass equals total system mass"
    );
}
```

Tests đặt cạnh nhau invariant storage và aggregate. Hãy bổ sung fixture tính tay với mass khác nhau; không chỉ dùng hàng trăm body cùng mass rồi xem mọi cờ đều true. CTest mặc định build final/include nên vẫn chạy được toàn bộ tests ở cuối khóa.

## Thử làm sai để hiểu đúng

Trong một bản tree dùng riêng cho test, tăng totalMass ở leaf thêm 100. Nếu chỉ so parent với children, có thể bỏ sót khi lỗi được lan lên. Đổi child index trỏ về parent để kiểm inspector báo lỗi và kết thúc. Đừng gọi force traversal trên cây cố ý có chu trình.

## Tự kiểm tra kết quả

- Fixture mass/COM khác nhau khớp tính tay trong tolerance công bố.
- Sửa leaf mass, duplicate body index hoặc child index làm đúng cờ kiểm tra chuyển false.
- Inspector kết thúc với cạnh tự trỏ, không recurse theo đồ thị hỏng.
- 256 position trùng nhau kết thúc trong giới hạn depth và không sinh NaN/self-force.
