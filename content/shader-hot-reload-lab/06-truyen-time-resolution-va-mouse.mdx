# Time, pixel và mouse: dữ liệu đổi từng frame

## Vấn đề cần giải quyết

Shader đã sửa được khi ứng dụng đang chạy, nhưng hình vẫn tĩnh. Ta muốn màu thay đổi theo thời gian và phản ứng với chuột mà không compile lại mỗi frame.

Uniform là dữ liệu C++ truyền vào program đã link. Bài này thêm time, resolution, mouse và zoom, đồng thời giải quyết một lỗi phổ biến: tọa độ chuột SDL và tọa độ pixel OpenGL không cùng hệ.

## Hiểu ý tưởng trước khi viết code

SDL mouse input dùng kích thước logical của cửa sổ, gốc trên trái. OpenGL dùng framebuffer pixels, gốc dưới trái. Trên màn hình high-DPI, cửa sổ logical 640×480 có thể chứa framebuffer 1280×960.

Ta giữ chuột dạng chuẩn hóa x/W, y/H trong ShaderScene. Khi tạo uniform snapshot, nhân với kích thước framebuffer và đảo trục y. Ví dụ chuột ở 1/4 chiều ngang, 1/4 chiều dọc cửa sổ sẽ thành (320,720) trong framebuffer 1280×960.

uTime tính bằng giây; uResolution và uMouse dùng pixel vật lý; uZoom không có đơn vị. Cả frame dùng một snapshot thống nhất, tránh renderer và phần debug hiển thị hai bộ số khác nhau.

## Viết code từng bước

### Bước 1 — Chuẩn hóa input một lần

```cpp title="include/pipeline.hpp — từ input logical sang tọa độ chuẩn hóa"
inline void setShaderMouse(ShaderScene& scene, double x, double y, int logicalWidth, int logicalHeight) {
    if (logicalWidth <= 0 || logicalHeight <= 0 || !std::isfinite(x) || !std::isfinite(y))
        return;
    scene.mouseX = std::clamp(x / logicalWidth, 0.0, 1.0);
    scene.mouseY = std::clamp(y / logicalHeight, 0.0, 1.0);
}
```

logicalWidth/logicalHeight lấy từ SDL_GetWindowSize. Clamp giữ con trỏ trong khoảng 0–1 kể cả khi drag ra ngoài cửa sổ nhờ mouse capture. Không nhân DPR tại đây rồi lại nhân thêm ở renderer.

### Bước 2 — Tạo snapshot theo framebuffer thực

```cpp title="include/pipeline.hpp — đổi sang pixel OpenGL"
inline UniformSnapshot makeUniformSnapshot(const ShaderScene& scene, int width, int height) {
    if (width <= 0 || height <= 0 || !std::isfinite(scene.timeSeconds) ||
        !std::isfinite(scene.mouseX) || !std::isfinite(scene.mouseY) ||
        !std::isfinite(scene.zoom) || scene.zoom <= 0) {
        throw std::invalid_argument("Invalid shader uniform snapshot");
    }
    return {float(scene.timeSeconds), float(width), float(height), float(std::clamp(scene.mouseX, 0.0, 1.0) * width), float((1 - std::clamp(scene.mouseY, 0.0, 1.0)) * height), scene.zoom};
}
```

width/height đến từ SDL_GetWindowSizeInPixels, không phải kích thước logical. Dấu 1 - mouseY đảo chiều y đúng một lần. Không cộng offset của overlay: shader vẫn phủ toàn cửa sổ, overlay chỉ vẽ đè lên phía dưới.

Nếu cửa sổ minimize làm kích thước không hợp lệ, event loop tiếp tục xử lý event nhưng chưa tạo snapshot/draw. Không gửi resolution bằng 0 rồi hy vọng GLSL tự chữa mọi phép chia.

### Bước 3 — Cập nhật time nhưng không relink

```cpp title="include/pipeline.hpp — clock của mô phỏng"
inline void advanceShaderTime(ShaderScene& scene, double seconds) {
    if (!scene.paused && std::isfinite(seconds) && seconds > 0)
        scene.timeSeconds += std::min(seconds, 0.05);
}
```

delta time lấy từ steady_clock. Mỗi frame cộng tối đa 0.05 giây để tránh nhảy quá xa sau một lần dừng dài; đây là clock trình diễn, không phải phép đo thời gian thực chính xác. Pause giữ time; N tiến đúng 1/30 giây; mất focus sẽ pause.

### Bước 4 — Upload rồi vẽ

```cpp title="include/shader_renderer.hpp — dữ liệu mới, program cũ"
    void draw(GlApi& gl, const UniformSnapshot& uniform) const {
        gl.Disable(GL_DEPTH_TEST);
        gl.Disable(GL_CULL_FACE);
        gl.Disable(GL_SCISSOR_TEST);
        gl.Viewport(0, 0, int(uniform.width), int(uniform.height));
        gl.UseProgram(activeProgram);
        gl.Uniform2f(locations.resolution, uniform.width, uniform.height);
        gl.Uniform1f(locations.time, uniform.time);
        gl.Uniform2f(locations.mouse, uniform.mouseX, uniform.mouseY);
        gl.Uniform1f(locations.zoom, uniform.zoom);
        gl.BindVertexArray(vertexArray);
        gl.DrawArrays(GL_TRIANGLES, 0, 3);
        gl.BindVertexArray(0);
    }
```

UseProgram chọn program trước khi upload. Uniform2f dùng cho vec2, Uniform1f dùng cho float. Uniform không active ở checkpoint trước có location -1; OpenGL bỏ qua upload vào -1. Từ checkpoint 6, buildProgramCandidate yêu cầu đủ bốn uniform có kiểu đúng.

Viewport dùng kích thước framebuffer, còn DrawArrays vẫn chỉ có ba đỉnh. Time/mouse/zoom/resize không gọi compileShader hay LinkProgram; chúng chỉ thay giá trị uniform.

## Ghép các phần lại

```bash title="Terminal — checkpoint 6"
cmake --build build --config Debug --target project_35_checkpoint_6 --parallel 2
./build/Debug/project_35_checkpoint_6.exe
```

Kéo chuột trái để đổi vùng sáng, cuộn để zoom. Space pause/chạy, N tiến một bước, R đưa time/chuột/zoom về mốc đầu và pause. R không đổi hiệu ứng, auto reload hay chế độ debug.

Mouse capture giúp kéo ra ngoài cửa sổ vẫn nhận chuyển động. Escape trong lúc kéo khôi phục tọa độ trước khi kéo và nhả capture; nếu không có gesture, Escape đóng app. Các phím mũi tên và +/− là cách điều khiển không cần chuột.

## Thử làm sai để hiểu đúng

1. Dùng SDL_GetWindowSize thay cho kích thước pixel khi upload: thử trên màn hình DPR khác 1 và quan sát shader chỉ dùng sai một phần hệ tọa độ.
2. Bỏ phép đảo y: điểm sáng chạy ngược chiều dọc con trỏ.
3. Giữ time cố định rồi di chuyển/resize: generation không được tăng vì không có reload.
4. Pause, đổi SPEED trong GLSL rồi F5: thời gian không reset, chỉ program thay đổi.

Khôi phục code chuẩn sau khi thử. Với Canvas, giảm độ phân giải preview chỉ để tính CPU nhẹ hơn; uniform readout vẫn dùng kích thước backing canvas có DPR.
