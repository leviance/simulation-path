# Link program, kiểm interface bằng driver

## Vấn đề cần giải quyết

Hai shader đã compile được, nhưng chưa có program để vẽ: GPU còn phải ghép các stage. Ứng dụng cũng cần biết địa chỉ các uniform.

Ngoài yêu cầu của OpenGL, gallery có quy ước riêng: gradient cần uResolution kiểu vec2; từ bài 06 còn cần uTime, uMouse và uZoom. Shader có thể link hợp lệ nhưng không đáp ứng quy ước này. Bài này tách rõ hai loại kiểm tra.

## Hiểu ý tưởng trước khi viết code

Compile kiểm từng bộ phận; link lắp chúng lại; kiểm interface xem sản phẩm đã lắp có đúng đầu nối ứng dụng cần hay không.

Không tìm tên uniform trong văn bản để kết luận nó tồn tại. Tên đó có thể nằm trong comment hoặc biến không dùng và đã bị compiler loại bỏ. Ta hỏi program đã link bằng GetUniformLocation/GetActiveUniform để lấy uniform đang hoạt động, kiểu và số phần tử.

Checkpoint 3 chỉ bắt buộc uResolution. Các uniform thời gian/chuột/zoom được phép chưa có, vì bài này chưa sử dụng chúng.

## Viết code từng bước

### Bước 1 — Link hai stage, hủy object trung gian

```cpp title="include/shader_renderer.hpp — tạo program từ hai stage"
inline GLuint linkShaderProgram(GlApi& gl, const ShaderSources& sources, std::string& diagnostics, ProgramBuildAudit* audit = nullptr) {
    const auto vertex = compileShader(gl, GL_VERTEX_SHADER, sources.vertex, sources.vertexLabel, diagnostics, audit);
    if (!vertex)
        return 0;
    const auto fragment = compileShader(gl, GL_FRAGMENT_SHADER, sources.fragment, sources.fragmentLabel, diagnostics, audit);
    if (!fragment) {
        gl.DeleteShader(vertex);
        return 0;
    }
    const auto program = gl.CreateProgram();
    if (audit && program)
        audit->programs.push_back(program);
    if (!program) {
        gl.DeleteShader(vertex);
        gl.DeleteShader(fragment);
        diagnostics = "glCreateProgram failed";
        return 0;
    }
    gl.AttachShader(program, vertex);
    gl.AttachShader(program, fragment);
    gl.LinkProgram(program);
    GLint linked = GL_FALSE;
    gl.GetProgramiv(program, GL_LINK_STATUS, &linked);
    gl.DetachShader(program, vertex);
    gl.DetachShader(program, fragment);
    gl.DeleteShader(vertex);
    gl.DeleteShader(fragment);
    if (linked != GL_TRUE) {
        diagnostics = "[link] " + sources.vertexLabel + " + " + sources.fragmentLabel + "\n" + programInfoLog(gl, program);
        gl.DeleteProgram(program);
        return 0;
    }
    diagnostics.clear();
    return program;
}
```

Nếu fragment compile thất bại, vertex object đã tạo trước đó vẫn phải được hủy. Khi link xong, cả hai shader được detach rồi delete: program giữ kết quả executable, không cần giữ object trung gian nữa.

GL_LINK_STATUS quyết định program có dùng được không. Log program khác log shader; lỗi nối stage được đọc bằng GetProgramInfoLog. Program link thất bại cũng bị hủy trước khi trả 0.

### Bước 2 — Hỏi interface đang hoạt động

```cpp title="include/shader_renderer.hpp — kiểm uniform bằng reflection"
inline bool findUniform(GlApi& gl, GLuint program, const char* name, GLenum requiredType, bool required, GLint& location, std::string& diagnostics) {
    location = gl.GetUniformLocation(program, name);
    if (location < 0) {
        if (!required)
            return true;
        diagnostics = std::string("[interface] Missing active uniform ") + name + " (it may be unused and optimized out).";
        return false;
    }
    GLint count = 0;
    gl.GetProgramiv(program, GL_ACTIVE_UNIFORMS, &count);
    for (GLint index = 0; index < count; ++index) {
        std::array<GLchar, 256> uniformName{};
        GLsizei written = 0;
        GLint size = 0;
        GLenum type = 0;
        gl.GetActiveUniform(program, GLuint(index), GLsizei(uniformName.size()), &written, &size, &type, uniformName.data());
        if (std::string_view(uniformName.data()) == name) {
            if (type == requiredType && size == 1)
                return true;
            diagnostics = std::string("[interface] Wrong type/array size for ") + name;
            return false;
        }
    }
    diagnostics = std::string("[interface] Cannot find scalar/non-array uniform ") + name;
    return false;
}
```

location bằng -1 có thể nghĩa là uniform không tồn tại hoặc đã bị tối ưu bỏ. Uniform tùy chọn được phép vắng mặt; uniform bắt buộc phải có. Không gọi Uniform2f vào vec3 chỉ vì tên giống nhau.

Vòng lặp reflection kiểm cả type và size bằng 1. Mảng uniform có cách đặt tên/size riêng; gallery không dùng chúng nên không cố chấp nhận một interface rộng hơn yêu cầu.

### Bước 3 — Gom program và locations vào candidate

```cpp title="include/shader_renderer.hpp — bản mới chưa đưa lên màn hình"
struct ProgramCandidate {
    GLuint program{};
    UniformLocations locations{};
};
```

Candidate là bản mới đang được thử, chưa thay program đang vẽ. locations thuộc về chính program trong candidate: sau mỗi lần link phải lấy lại, không dùng location của program trước.

buildProgramCandidate kiểm uResolution là GL_FLOAT_VEC2. Từ checkpoint 6, requireLive bật thêm ba uniform còn lại. Yêu cầu tăng theo chức năng đã học, không buộc bạn khai báo biến chưa dùng.

## Thử làm sai để hiểu đúng

1. Chỉ đổi tên uniform trong comment: interface thật không thay đổi.
2. Thay chỗ dùng uResolution bằng hằng số: kiểm xem uniform còn active hay không.
3. Đổi uResolution thành vec3 và sửa phép tính để GLSL vẫn hợp lệ: kiểm type phải bắt lỗi mà GetUniformLocation một mình không phát hiện được.

Những thí nghiệm này cần compiler OpenGL thật. Canvas chỉ mô phỏng việc từ chối candidate, không kết luận source GLSL tùy ý đúng hay sai.
