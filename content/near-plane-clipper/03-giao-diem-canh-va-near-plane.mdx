# Tìm giao điểm thật trên một cạnh

## Vấn đề cần giải quyết

Ta biết cạnh nào đi qua near plane, nhưng vẫn chưa biết phải cắt ở đâu. Không thể lấy đỉnh ngoài rồi đổi riêng Z thành near: cách đó di chuyển điểm theo hướng khác cạnh ban đầu, làm biến dạng hình và màu.

## Hiểu ý tưởng trước khi viết code

Trên đoạn S→E, mọi thành phần dùng chung một tham số:

$$P(t)=S+t(E-S),\qquad t=\frac{near-S_z}{E_z-S_z}.$$

Ví dụ S=(−2,0,0.5), E=(2,2,1.5), near=1 cho t=0.5 và P=(0,1,1). Nếu kênh đỏ hai đầu là 0 và 100 thì giao điểm có đỏ=50. Position và color dùng chung t, vì chúng cùng mô tả một điểm trên cạnh.

Đây là giao của **segment**, không chỉ của đường thẳng kéo dài. t ngoài [0,1] nghĩa là không có giao trên đoạn. Đoạn song song nằm ngoài plane cũng không có giao; không bịa ra điểm bằng cách clamp t hoặc sửa Z.

### Bước 1 — Nội suy toàn bộ dữ liệu của vertex

Trong clip.hpp, sau classifyTriangle, thêm mix và interpolateVertex:

```cpp title="include/clip.hpp — cùng một t cho vị trí và RGB"
inline double mix(double start, double end, double t) {
    return start + (end - start) * t;
}

inline ClipVertex interpolateVertex(const ClipVertex& start, const ClipVertex& end, double t) {
    return {{mix(start.position.x, end.position.x, t), mix(start.position.y, end.position.y, t), mix(start.position.z, end.position.z, t)}, {mix(start.color.red, end.color.red, t), mix(start.color.green, end.color.green, t), mix(start.color.blue, end.color.blue, t)}};
}
```

Color chưa đổi sang uint8_t; chỉ lúc packColor vào framebuffer mới làm tròn. Đây là nội suy thuộc tính trên cạnh trong camera space, chưa phải perspective-correct interpolation của fragment.

### Bước 2 — Tìm giao thật, trả rỗng khi không có

Thêm intersectNearPlane ngay sau interpolateVertex:

```cpp title="include/clip.hpp — giao segment-plane có kiểm tra"
inline std::optional<ClipVertex> intersectNearPlane(const ClipVertex& start, const ClipVertex& end, double nearPlane) {
    if (!isFinite(start) || !isFinite(end) || !std::isfinite(nearPlane) || nearPlane <= 0.0) {
        return std::nullopt;
    }
    // Endpoint trên plane được trả nguyên vẹn để tránh sinh bản sao hơi lệch.
    if (start.position.z == nearPlane) {
        return start;
    }
    if (end.position.z == nearPlane) {
        return end;
    }
    const double change = end.position.z - start.position.z;
    if (!std::isfinite(change) || change == 0.0) {
        return std::nullopt;
    }
    const double t = (nearPlane - start.position.z) / change;
    if (!std::isfinite(t) || t < 0.0 || t > 1.0) {
        return std::nullopt;
    }
    ClipVertex result = interpolateVertex(start, end, t);
    if (!isFinite(result)) {
        return std::nullopt;
    }
    result.position.z = nearPlane;
    return result;
}
```

Hai endpoint đúng trên plane được trả nguyên vẹn. Với cạnh crossing còn lại, ta tính t thật rồi mới đặt Z của **điểm giao mới** bằng near để bỏ phần dư số học. Đỉnh đầu vào không bị sửa. Điều này khác hoàn toàn việc ghim Z của mọi đỉnh outside.

Không dùng một ngưỡng dz tùy ý để kết luận song song. Hai đầu ở z=1±2⁻⁴² có dz rất nhỏ nhưng vẫn cắt near=1 ở t=0.5; kiểm `change == 0` xử lý đúng trường hợp này. Input không hữu hạn bị từ chối trước mọi phép tính.

### Bước 3 — Hiện giao điểm trong mặt cắt đang có

Trong drawProfile của view.hpp, sau vòng vẽ ba marker nguồn và trước dấu đóng hàm, thêm vòng dưới:

```cpp title="include/view.hpp — chỉ vẽ giao điểm trên cạnh crossing"
for (int i = 0; i < 3; ++i) {
    const auto a = vertexAt(stats.source, i), b = vertexAt(stats.source, (i + 1) % 3);
    if (isInsideNearPlane(a, scene.nearPlane) != isInsideNearPlane(b, scene.nearPlane)) {
        const auto p = intersectNearPlane(a, b, scene.nearPlane);
        if (p) {
            const auto q = profilePoint(*p);
            if (q.x >= 770 && q.x <= 1070 && q.y >= 644 && q.y <= 784) {
                disc(image, static_cast<int>(q.x), static_cast<int>(q.y), 3, kWhite);
            }
        }
    }
}
```

Marker trắng phải nằm trên đường near màu vàng. Viewport chính vẫn chưa clip; marker giúp ta kiểm chứng công thức độc lập trước khi dùng nó để tạo polygon. Canvas hiển thị cả hai t nếu có hai cạnh crossing.

## Ghép các phần lại

Build Starter, chọn preset 2 và kéo chậm. Hai cạnh cắt near có hai marker trắng; màu, vị trí giao điểm thay đổi theo đầu vào thật. Khi một đỉnh vừa chạm biên, endpoint trả về không bị lệch vị trí hoặc màu. Nếu cả cạnh nằm ngoài và song song, optional phải rỗng.

## Thử làm sai để hiểu đúng

1. Thay t thật bằng 0.5: marker chỉ đúng khi plane cắt đúng giữa cạnh. Các preset khác sẽ lệch.

2. Clamp t vào [0,1] khi hai đầu cùng ở ngoài: bạn biến giao của đường kéo dài thành một endpoint giả. Khôi phục trả nullopt.

3. Nội suy màu bằng t² nhưng vị trí bằng t: giao điểm đúng hình học nhưng màu bị gãy. Tất cả thuộc tính phải dùng chung t.

## Tự kiểm tra kết quả

- Ví dụ tính tay cho P=(0,1,1), đỏ=50.
- Cạnh đảo chiều cho cùng vị trí/màu giao; tham số mới bằng 1−t.
- Song song ngoài plane hoặc t ngoài segment trả nullopt.
- Cạnh crossing rất ngắn vẫn có giao thật; đầu vào và endpoint trên plane không bị sửa.
