# Cắt tam giác thành một polygon có thứ tự

## Vấn đề cần giải quyết

Bây giờ ta có thể cắt một cạnh. Nhưng renderer cần một biên khép kín cho phần tam giác còn lại, không phải hai giao điểm rời nhau. Bài này duyệt ba cạnh có hướng để tạo polygon theo đúng thứ tự quanh biên.

## Hiểu ý tưởng trước khi viết code

Một bước Sutherland–Hodgman với một plane chỉ cần hai quyết định: có đổi phía không, và endpoint hiện tại có ở trong không?

| Cạnh | Thêm vào output |
| --- | --- |
| in→in | current |
| in→out | intersection |
| out→in | intersection, rồi current |
| out→out | không thêm |

Khởi đầu previous=C để xử lý C→A trước, sau đó A→B và B→C. Với tam giác không suy biến và không chỉ chạm biên, số đỉnh thường là 3/4/3/0 khi outside=0/1/2/3. Nếu chỉ còn một điểm hoặc một cạnh trên plane, polygon có thể có 1 hoặc 2 đỉnh; không được ép chúng thành một tam giác.

### Bước 1 — Lưu đỉnh duy nhất, không cắt cụt output

ClippedPolygon với array bốn phần tử đã có trong types.hpp. Thêm hai helper vào clip.hpp sau intersectNearPlane:

```cpp title="include/clip.hpp — bỏ bản sao kề nhau và kiểm capacity"
inline bool samePosition(const ClipVertex& a, const ClipVertex& b) {
    return a.position.x == b.position.x && a.position.y == b.position.y && a.position.z == b.position.z;
}

inline bool appendVertex(ClippedPolygon& polygon, const ClipVertex& vertex) {
    if (!polygon.valid) {
        return false;
    }
    if (!isFinite(vertex) || polygon.count > polygon.vertices.size()) {
        polygon = {};
        polygon.valid = false;
        return false;
    }
    if (polygon.count > 0 && samePosition(polygon.vertices[polygon.count - 1], vertex)) {
        return true;
    }
    if (polygon.count >= polygon.vertices.size()) {
        polygon = {};
        polygon.valid = false;
        return false;
    }
    polygon.vertices[polygon.count++] = vertex;
    return true;
}
```

samePosition dùng vị trí đã có, không gộp hai điểm khác nhau chỉ vì gần nhau theo epsilon. Nếu capacity bị vượt, output thành invalid và count=0; ta không giữ bốn đỉnh đầu rồi âm thầm bỏ phần còn lại.

### Bước 2 — Duyệt vòng kín để tạo biên mới

Thêm hàm clipTriangleToNearPlane:

```cpp title="include/clip.hpp — một bước Sutherland–Hodgman"
inline ClippedPolygon clipTriangleToNearPlane(const Triangle3& triangle, double nearPlane, double epsilon = 1e-9) {
    ClippedPolygon output{};
    if (!classifyTriangle(triangle, nearPlane, epsilon).valid) {
        output.valid = false;
        return output;
    }
    ClipVertex previous = triangle.c;
    bool previousInside = isInsideNearPlane(previous, nearPlane);
    for (int i = 0; i < 3; ++i) {
        const ClipVertex current = vertexAt(triangle, i);
        const bool currentInside = isInsideNearPlane(current, nearPlane);
        if (currentInside != previousInside) {
            const auto intersection = intersectNearPlane(previous, current, nearPlane);
            if (!intersection || !appendVertex(output, *intersection)) {
                output = {};
                output.valid = false;
                return output;
            }
        }
        if (currentInside && !appendVertex(output, current)) {
            return output;
        }
        previous = current;
        previousInside = currentInside;
    }
    if (output.count > 1 && samePosition(output.vertices[0], output.vertices[output.count - 1])) {
        --output.count;
    }
    return output;
}
```

Crossing luôn thêm giao điểm trước; sau đó current ở trong thì thêm current. Cách viết này diễn đạt đủ bốn trường hợp mà không cần bốn nhánh lặp. Endpoint trên biên có thể vừa là intersection vừa là current; appendVertex bỏ bản sao liền kề. Cuối cùng, nếu output cuối trùng đầu thì bớt một đỉnh để chỉ đóng vòng khi vẽ.

### Bước 3 — Nối output vào mặt cắt, chưa đổi renderer

Trong renderScene, ngay sau inputCounts, thêm:

```cpp title="include/view.hpp — lưu polygon của frame"
stats.clip.polygon = clipTriangleToNearPlane(stats.source, scene.nearPlane);
```

Trong drawProfile, sau vòng marker giao điểm, thêm:

```cpp title="include/view.hpp — đường xanh là biên sau cắt"
const auto& polygon = stats.clip.polygon;
for (std::size_t i = 0; i < polygon.count; ++i) {
    line(polygon.vertices[i], polygon.vertices[(i + 1) % polygon.count], kShape);
}
```

Modulo nối đỉnh cuối về đầu. Count=0 thì vòng không chạy, không có phép modulo zero. Canvas có nút Tiến một cạnh: đường xanh ở đây là output tạm sau từng cạnh, không phải kết quả render hoàn chỉnh.

## Ghép các phần lại

Build Starter rồi chọn lần lượt 1/2/3/4: HUD chưa có triangle fan, nhưng mặt cắt phải hiện output với 3/4/3/0 đỉnh. Trong Canvas, đặt số cạnh về 0 rồi tiến đến 3 để đọc chính thứ tự append. Bề mặt chính vẫn dùng discard cho đến bài 6; có polygon trong debug không tự có nghĩa renderer đã dùng nó.

## Thử làm sai để hiểu đúng

1. Bắt đầu previous=A thay vì C: cạnh C→A bị bỏ quên và output có thể hở hoặc thiếu giao.

2. Bỏ dedup khi current nằm trên plane: cùng endpoint xuất hiện hai lần, dễ sinh tam giác diện tích zero ở fan.

3. Sort output theo X thay vì giữ thứ tự duyệt: biên có thể tự cắt. Sutherland–Hodgman đã tạo đúng thứ tự, không cần sort.

## Tự kiểm tra kết quả

- All-inside giữ ba đỉnh; one-out tạo bốn; two-out tạo ba; all-out rỗng.
- Đỉnh kề nhau không trùng, đỉnh cuối không lặp lại đỉnh đầu.
- Chỉ chạm một điểm hoặc một đoạn cho count 1/2 hợp lệ.
- Mọi đỉnh output hữu hạn và z≥near; input không đổi.
