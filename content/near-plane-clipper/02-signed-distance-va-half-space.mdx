# Signed distance: đỉnh đang ở phía nào?

## Vấn đề cần giải quyết

Trước khi cắt cạnh, ta cần trả lời một câu hỏi đơn giản: mỗi đỉnh nằm ở phía được giữ hay phía bị bỏ? Nếu câu trả lời này khác điều kiện của phép projection, một polygon vừa được nhận vẫn có thể biến mất ở bước kế tiếp.

## Hiểu ý tưởng trước khi viết code

Một mặt phẳng có normal n và offset b cho biểu thức d(P)=n·P+b. Với near plane, n=(0,0,1), b=−near nên:

$$d(P)=z-near.$$

Giữ `d >= 0`, kể cả điểm đúng trên biên. Epsilon ở đây chỉ dùng cho nhãn onPlane: `abs(d) <= epsilon`. Một điểm có d=−0.5×10⁻⁹ vẫn ở ngoài, dù được báo là gần plane. Vì vậy onPlane không phải nhóm thứ ba tách khỏi inside/outside; tổng inside+outside bằng 3, còn onPlane là số đo bổ sung.

### Bước 1 — Biểu diễn plane bằng dữ liệu rõ nghĩa

Plane và NearPlaneCounts đã có trong types.hpp; đọc lại, không chép thêm struct trùng tên:

```cpp title="include/types.hpp — mặt phẳng và số liệu chẩn đoán"
struct Plane {
    Vec3 normal{0.0, 0.0, 1.0};
    double offset{-1.0};
};

struct NearPlaneCounts {
    int inside{};
    int outside{};
    int onPlane{};
    bool valid{true};
};
```

Với n có độ dài 1, d chính là khoảng cách có dấu theo đơn vị world. Ta không tự coi mọi normal bất kỳ là unit; bài này dùng normal (0,0,1).

### Bước 2 — Viết phép phân loại và giữ biên chính xác

Trong clip.hpp, bên trong namespace lab, thêm lần lượt bốn hàm sau. signedDistance trả NaN nếu đầu vào lỗi; classifyTriangle dùng cờ valid thay vì để dữ liệu sai âm thầm trở thành outside.

```cpp title="include/clip.hpp — signed distance và half-space chính xác"
inline double signedDistance(const ClipVertex& vertex, const Plane& plane) {
    if (!isFinite(vertex) || !std::isfinite(plane.normal.x) || !std::isfinite(plane.normal.y) || !std::isfinite(plane.normal.z) || !std::isfinite(plane.offset)) {
        return std::numeric_limits<double>::quiet_NaN();
    }
    return plane.normal.x * vertex.position.x + plane.normal.y * vertex.position.y + plane.normal.z * vertex.position.z + plane.offset;
}

inline double signedDistanceToNearPlane(const ClipVertex& vertex, double nearPlane) {
    return signedDistance(vertex, {{0.0, 0.0, 1.0}, -nearPlane});
}

inline bool isInsideNearPlane(const ClipVertex& vertex, double nearPlane) {
    const double d = signedDistanceToNearPlane(vertex, nearPlane);
    return std::isfinite(nearPlane) && nearPlane > 0.0 && std::isfinite(d) && d >= 0.0;
}

inline NearPlaneCounts classifyTriangle(const Triangle3& triangle, double nearPlane, double epsilon = 1e-9) {
    NearPlaneCounts counts{};
    if (!std::isfinite(nearPlane) || nearPlane <= 0.0 || !std::isfinite(epsilon) || epsilon < 0.0) {
        counts.valid = false;
        return counts;
    }
    for (int i = 0; i < 3; ++i) {
        const double d = signedDistanceToNearPlane(vertexAt(triangle, i), nearPlane);
        if (!std::isfinite(d)) {
            return {0, 0, 0, false};
        }
        if (std::abs(d) <= epsilon) {
            ++counts.onPlane;
        }
        if (d >= 0.0) {
            ++counts.inside;
        } else {
            ++counts.outside;
        }
    }
    return counts;
}
```

Không thay d≥0 bằng d≥−epsilon. projectVertex đã có guard z≥near; hai bước phải đồng ý với nhau. Counts không sửa một tọa độ nào.

## Ghép các phần lại

Chạy Starter: preset 1 phải báo 3/0/0, preset 2 là 2/1/0, preset 3 là 1/2/0, preset 4 là 0/3/0. Preset 5 có hai đỉnh đúng biên: inside=3, outside=0, on=2. Thử đổi near bằng W/S để thấy số đếm đổi theo geometry thật.

## Thử làm sai để hiểu đúng

1. Đổi inside thành `d > 0`: preset 5 mất hai điểm biên. Khôi phục `>=`.

2. Dùng `d >= -epsilon` rồi giữ guard projection cũ: điểm hơi ngoài được nhận ở đầu pipeline nhưng bị loại ở cuối. Đây là lỗi cần tránh, không phải cách làm mượt biên.

3. Tính onPlane bằng d==0: đúng cho endpoint đặt tay, nhưng kém hữu ích khi đọc số sau transform. Giữ epsilon cho chẩn đoán, không cho quyết định geometry.

## Tự kiểm tra kết quả

- Bốn trường hợp inside 0/1/2/3 có counts tương ứng.
- Inside+outside luôn bằng ba với input hợp lệ; onPlane được đếm độc lập.
- Điểm z=near ở trong; z=near−0.5×10⁻⁹ ở ngoài.
- Geometry không thay đổi sau classify; viewport chưa dùng clipping.
