# Cảnh 3D sạch và toàn bộ mã hoàn chỉnh

## Vấn đề cần giải quyết

Phần toán đã đúng, nhưng một mặt cắt và vài con số chưa phải sản phẩm cuối. Bài cuối đặt bề mặt vào một cảnh phối cảnh dễ đọc, cho camera dịch độc lập và tắt toàn bộ overlay mà vẫn giữ hình 3D.

## Hiểu ý tưởng trước khi viết code

World và camera là hai dữ liệu khác nhau. depthOffset chỉ dịch tam giác theo Z; lưới sàn không dùng offset đó. Cả hai cùng đổi từ world sang camera space bằng:

$$P_{view}=P_{world}-C.$$

Camera nhìn cố định +Z, X trong [−1,1], Z trong [−0.5,0.5]. Đây là camera dịch để quan sát, không phải FPS/orbit đầy đủ. Scene chỉ có một bề mặt nhằm tập trung vào clipping; chưa tích hợp Z-buffer, culling, far-plane polygon clipping hay perspective-correct color.

Debug dành 1100×600 cho ảnh, 200 hàng dưới cho HUD/mặt cắt. Clean dùng toàn bộ 1100×800. Aspect thay đổi nên hình chiếu có thể khác, nhưng vị trí world và kết quả clipping không đổi.

### Bước 1 — Vẽ lưới world qua cùng camera

Trong view.hpp, thêm drawWorldGrid trước renderScene:

```cpp title="include/view.hpp — lưới phối cảnh không đi theo vật thể"
inline void drawWorldGrid(Framebuffer& image, const Scene& scene) {
    const auto line = [&](Vec3 a, Vec3 b) {
        ClipVertex p{{a.x - scene.camera.x, a.y - scene.camera.y, a.z - scene.camera.z}, {}}, q{{b.x - scene.camera.x, b.y - scene.camera.y, b.z - scene.camera.z}, {}};
        const bool inP = isInsideNearPlane(p, scene.nearPlane), inQ = isInsideNearPlane(q, scene.nearPlane);
        if (!inP && !inQ) {
            return;
        }
        if (inP != inQ) {
            const auto hit = intersectNearPlane(p, q, scene.nearPlane);
            if (!hit) {
                return;
            }
            if (!inP) {
                p = *hit;
            } else {
                q = *hit;
            }
        }
        const Viewport viewport{0, 0, Framebuffer::width, viewportHeight(scene)};
        const auto x = projectVertex(p, 1.0471975511965976, viewport, scene.nearPlane), y = projectVertex(q, 1.0471975511965976, viewport, scene.nearPlane);
        if (x && y) {
            screenLine(image, x->position, y->position, viewport.height, kGrid);
        }
    };
    for (int x = -6; x <= 6; ++x) {
        line({double(x), -1.8, 2.0}, {double(x), -1.8, 9.0});
    }
    for (int z = 2; z <= 9; ++z) {
        line({-6.0, -1.8, double(z)}, {6.0, -1.8, double(z)});
    }
}
```

Mỗi đoạn grid được trừ camera, clip near trước divide rồi clip screen trước Bresenham. Ta không bỏ cả đoạn chỉ vì một endpoint outside. Sau `image.clear(kBackground);` trong renderScene, thêm:

```cpp title="include/view.hpp — grid là nền scene, không phải debug"
drawWorldGrid(image, scene);
```

Giữ lời gọi này ngoài if(scene.debug), trước vòng tô tam giác. Trong Scene, đổi preset mặc định từ 1 thành 2 để bản hoàn chỉnh mở ngay ví dụ đang cắt:

```cpp title="include/scene.hpp — mặc định một đỉnh outside"
int preset{2};
```



### Bước 2 — Tách camera và chế độ sạch khỏi geometry

Thay handleKey bằng bản hoàn chỉnh dưới để thêm F và J/L/I/K:

```cpp title="include/controls.hpp — camera độc lập và clean mode"
inline void handleKey(Scene& scene, SDL_Keycode key, bool repeat) {
    if (!repeat && (key == SDLK_R || (key >= SDLK_1 && key <= SDLK_5))) {
        int preset = scene.preset;
        if (key != SDLK_R) {
            preset = static_cast<int>(key - SDLK_0);
        }
        resetScene(scene, preset);
    }
    if (key == SDLK_W) {
        scene.nearPlane = std::min(2.0, scene.nearPlane + 0.05);
        scene.paused = true;
    }
    if (key == SDLK_S) {
        scene.nearPlane = std::max(0.25, scene.nearPlane - 0.05);
        scene.paused = true;
    }
    if (!repeat && key == SDLK_V) {
        scene.clipping = !scene.clipping;
        scene.paused = true;
    }
    if (!repeat && key == SDLK_SPACE) {
        scene.paused = !scene.paused;
    }
    if (!repeat && key == SDLK_N && scene.paused) {
        stepSweep(scene, 0.08);
    }
    if (!repeat && key == SDLK_F) {
        scene.debug = !scene.debug;
    }
    if (key == SDLK_J) {
        scene.camera.x = std::max(-1.0, scene.camera.x - 0.1);
        scene.paused = true;
    }
    if (key == SDLK_L) {
        scene.camera.x = std::min(1.0, scene.camera.x + 0.1);
        scene.paused = true;
    }
    if (key == SDLK_I) {
        scene.camera.z = std::min(0.5, scene.camera.z + 0.1);
        scene.paused = true;
    }
    if (key == SDLK_K) {
        scene.camera.z = std::max(-0.5, scene.camera.z - 0.1);
        scene.paused = true;
    }

    (void)scene;
    (void)key;
    (void)repeat;
}
```

Thay presentFramebuffer bằng bản hoàn chỉnh, giữ createFramebufferTexture như cũ:

```cpp title="include/presentation.hpp — upload CPU, HUD và clean"
inline bool presentFramebuffer(SDL_Renderer* renderer, SDL_Texture* texture, const Scene& scene, const FrameStats& stats) {
```

### Bước 3 — Chạy và kiểm mã của chính mình

ZIP chứa README, Starter, tám checkpoint chạy độc lập, final, tests và CMake. Phần toàn bộ mã nguồn cuối bài hiển thị từng file hoàn chỉnh; không phải một tập mảnh rời để đoán chỗ ghép.

CTest mặc định dùng final/include. Sau khi viết đủ tám bài, đổi đúng dòng sau trong **CMakeLists.txt của ZIP đã giải nén**, không sửa generator của website:

```cmake title="CMakeLists.txt — kiểm mã người học"
target_include_directories(project_18_tests PRIVATE starter/include)
```

Chạy lại configure, build app và test ở cả hai cấu hình:

```powershell title="Build và kiểm Starter Debug/Release"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_18_starter project_18_tests --parallel 2
ctest --test-dir build -C Debug --output-on-failure --timeout 30
cmake --build build --config Release --target project_18_starter project_18_tests --parallel 2
ctest --test-dir build -C Release --output-on-failure --timeout 30
```

Runner dùng check/EXIT_FAILURE, không dùng assert bị Release tắt. Native test gồm oracle giao điểm/RGB, bốn topology, sáu hoán vị, winding/diện tích, contact điểm/đoạn, invalid input, sweep 1001 vị trí toán nhỏ và mask ray/triangle. Nó còn render scene CPU clean để chứng minh còn surface/grid; không chỉ kiểm helper math.

Nếu muốn chạy bản tham khảo hoàn chỉnh, build target project_18_final rồi mở executable trong build/Debug. Nó không nhận thay đổi từ Starter.

## Ghép các phần lại

Project 18 đã hoàn chỉnh khi có một ứng dụng SDL3 tương tác: tam giác đi xuyên camera, phần còn nhìn thấy vẫn được clip và tô; debug before/after tắt riêng; clean giữ cảnh phối cảnh. Chạy project_18_starter để kiểm mã vừa học, project_18_final để xem bản tham khảo.

Native: 1–5 preset; giữ A/D hoặc kéo ngang đổi độ sâu; W/S đổi near; V so clip/discard; Space chạy/dừng sweep; N bước khi paused; F clean/debug; J/L camera X; I/K camera Z; R reset tình huống đang chọn; Esc thoát. Resize/blur/hidden nhả capture, xóa held input và pause.

Canvas dùng đúng công thức nhưng buffer 220×120 hoặc 220×160 để minh họa; C++ tô 1100×600 hoặc 1100×800. --smoke chỉ tạo cửa sổ ẩn và render hữu hạn. CTest/callback tests không thay việc tự thử mouse/keyboard/HiDPI trong cửa sổ thật.

## Thử làm sai để hiểu đúng

1. Đưa depthOffset vào lưới: vật thể kéo cả world đi cùng, mất đối chứng không gian. Chỉ tam giác nhận offset.

2. Đặt cả grid/raster trong if(debug): F làm scene biến mất. Chỉ HUD và mặt cắt thuộc debug.

3. Chạy CTest mặc định rồi kết luận Starter đúng: làm sai một dòng trong Starter, kiểm include path của project_18_tests và chạy lại để thấy sự khác biệt.

- Viewport phối cảnh chiếm vùng chính, clean còn RGB surface cùng grid.
