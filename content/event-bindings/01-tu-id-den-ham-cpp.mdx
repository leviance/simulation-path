# Nút Pause tìm thấy hàm C++ bằng cách nào?

## Vấn đề cần giải quyết

Nếu kéo nút Pause xuống cuối bảng, bạn muốn nó vẫn dừng đàn. Không thể viết 'nút thứ hai thì dừng' hoặc 'click bên trái toolbar thì dừng'. Cần một cái tên bền hơn vị trí: `id="pause"`.

## Hiểu ý tưởng trước khi viết code

Trong lần nạp tài liệu, tên trong file được đổi thành WidgetId của phiên hiện tại. Với mỗi cặp WidgetId và loại sự kiện, đăng ký một callback. Khi click, callback nhận model đang sống, không sửa một bản sao trong widget.

## Viết code từng bước

### Đặt tên cho những thứ người dùng điều khiển

Ba widget trong toolbar là ba đích khác nhau, dù dùng chung khung cha. Checkbox có nhãn Links chứ không cần giả làm một thanh kéo hai mức.

```html title="assets/panel.html — Các ID dùng để nối callback"
<div id="desk" class="sheet">
```

### Tra một ID trong chính tài liệu đang mở

Không có tên thì trả ID 0. Không tạo node mới để lấp chỗ trống: ở bài cuối ứng dụng sẽ báo rõ binding bắt buộc nào còn thiếu.

{/* snippet include/events/bus.hpp#lookup */}

```cpp title="include/events/bus.hpp — Tra một ID trong chính tài liệu đang mở"
inline lab::WidgetId elementById(const Page& page, const std::string& name) {
    const auto found = page.document.byId.find(name);
    if (found == page.document.byId.end())
        return 0;
    return page.handles.at(static_cast<std::size_t>(found->second));
}
```

### Đưa lệnh về đúng mô hình đàn

Pause đổi đồng hồ, Reset khởi tạo lại đàn, Observe chỉ đổi lớp nhìn. Radius và Separation có chung đường xác nhận giá trị theo range nhưng tới hai tham số khác nhau.

{/* snippet include/events/binding.hpp#host-binding */}

```cpp title="include/events/binding.hpp — Đưa lệnh về đúng mô hình đàn"
inline void hostCommand(Desk& d, const std::string& name, double value) {
    if (name == "pause")
        lab::setPaused(d.model, !d.model.paused);
    if (name == "reset")
        lab::resetSimulation(d.model);
    if (name == "observe")
        d.model.colony.showNeighbors = !d.model.colony.showNeighbors;
    if (name == "radius" || name == "separation")
        applyRange(d, elementById(d.page, name), value);
}
```
