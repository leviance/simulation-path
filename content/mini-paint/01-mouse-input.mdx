# Từ cú click đến một nét vẽ

## Vấn đề cần giải quyết

Project 02 đã dùng một ảnh logic 960×540 để vẽ ô vuông rồi đưa ảnh lên cửa sổ. Mini Paint dùng lại cách hiển thị đó, nhưng có một khác biệt quan trọng: **tranh phải được giữ lại**. Nếu xóa framebuffer mỗi frame như khi vẽ nhân vật, mọi nét vừa vẽ sẽ biến mất.

Trước khi đọc lời giải, thử tự làm: click trái tạo một pixel xanh, rê chuột không giữ nút thì không vẽ, giữ nút trái mới để lại các chấm. Tạm chấp nhận nét đứt; bài này học cách nhận chuột và quản lý một nét, chưa học đầu bút tròn hay nội suy.

Starter có window, renderer, framebuffer, texture và nền trống. Từ thư mục project trong ZIP:

```bash title="Terminal — build điểm bắt đầu và bài 1"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_3_starter project_3_checkpoint_1 --parallel 2
```

Windows chạy `.\build\Debug\project_3_starter.exe`. Với Ninja/Makefiles, đặt `-DCMAKE_BUILD_TYPE=Debug` lúc configure và chạy executable trong `build/`. “Checkpoint” là source chạy được sau một bài. Cuối trang có đầy đủ file đầu vào, thay đổi và mã hoàn chỉnh sau bài; bạn không phải đoán bộ khung quanh các đoạn dưới đây.

## Hiểu ý tưởng trước khi viết code

Một nét gồm ba giai đoạn: nhấn mở nét, nhiều motion tiếp tục nét, thả đóng nét. Cần giữ `drawing` và `previous` qua nhiều event. Không phải mỗi lần nhận event lại tạo một nét mới.

Ta dùng ba hệ tọa độ khác nhau: vị trí chuột trong window, vị trí trong ảnh logic và pixel vật lý khi hiển thị. Window 960×540 có thể khiến chúng trông giống nhau, nhưng khi resize hoặc dùng HiDPI thì không còn đúng. Ảnh logic vẫn là 960×540; SDL dùng LETTERBOX để giữ tỉ lệ, có thể chừa viền.

**Quy ước của Mini Paint:** bắt đầu nét chỉ trong vùng ảnh. Ra ngoài vùng ảnh, mất focus hoặc resize sẽ kết thúc nét; muốn vẽ tiếp phải thả rồi nhấn lại. Không ép tọa độ ngoài ảnh vào cạnh vì cách đó dễ tạo vệt dài dọc mép.

## Viết code từng bước

### Bước 1 — Giữ tranh trong RAM, chỉ clear khi thật sự cần

Trước vòng lặp, tạo ảnh và tô nền một lần:


```cpp title="src/main.cpp — ảnh tồn tại suốt phiên vẽ"
lab::Framebuffer framebuffer;
    framebuffer.clear(lab::kBackground);
    bool running = true;
    bool failed = false;
    bool dirty = true;
```


`dirty` cho biết ảnh CPU đã thay đổi và cần upload. Các frame không thay tranh vẫn present texture để cửa sổ được vẽ lại, nhưng không chép lại cả ảnh lên GPU.

`include/presentation.hpp` đã có từ starter. Phần upload quen thuộc của Project 01 là:


```cpp title="include/presentation.hpp — pitch vẫn tính bằng byte"
inline bool uploadFramebuffer(SDL_Texture* texture, const Framebuffer& framebuffer) {
    const int pitch = Framebuffer::width * static_cast<int>(sizeof(std::uint32_t));
    return SDL_UpdateTexture(texture, nullptr, framebuffer.pixels.data(), pitch);
}
```


`SDL_UpdateTexture` không tự xóa tranh. `SDL_RenderClear` cũng không xóa vector: nó chỉ xóa render target trước khi copy texture. Dữ liệu gốc cần giữ là `framebuffer.pixels`.

### Bước 2 — Đặt tên cho một vị trí trong ảnh

Tạo `include/lab.hpp` với `#pragma once`, include `framebuffer.hpp` và `<cmath>`; đặt các khai báo sau trong namespace `lab`:


```cpp title="include/lab.hpp — tọa độ và điều kiện nằm trong ảnh"
struct Point {
    double x{};
    double y{};
    friend bool operator==(Point, Point) = default;
};

inline bool insideCanvas(Point point) {
    return std::isfinite(point.x) && std::isfinite(point.y) && point.x >= 0.0 && point.y >= 0.0 && point.x < Framebuffer::width && point.y < Framebuffer::height;
}
```


Hai tọa độ dùng `double` để không cắt phần lẻ từ event quá sớm. `insideCanvas` kiểm cả số không hữu hạn trước khi sau này chuyển sang `int`. Tọa độ X = 960 nằm ngoài ảnh; cột cuối là 959.

Trong `include/brush.hpp`, include hai header trên rồi thêm hàm đầu bút một pixel:


```cpp title="include/brush.hpp — đặt một dấu nhỏ nhất"
inline void stampPoint(Framebuffer& framebuffer, Point point, std::uint32_t color) {
    if (!insideCanvas(point)) {
        return;
    }
    const int x = static_cast<int>(std::floor(point.x));
    const int y = static_cast<int>(std::floor(point.y));
    framebuffer.putPixel(x, y, color);
}
```


`floor` chọn ô pixel chứa con trỏ. Với tọa độ (120,9; 220,2), ta ghi pixel (120,220). `putPixel` tiếp tục kiểm biên trước phép tính `index = y × width + x`.

### Bước 3 — Lưu trạng thái của nét, không lưu lại mọi event

Tạo `include/paint.hpp`, include `brush.hpp` và đặt các phần dưới đây trong namespace `lab`:


```cpp title="include/paint.hpp — trạng thái tối thiểu của bài 1"
struct PaintState {
    bool drawing = false;
    Point previous{};
    std::uint32_t color = rgba(83, 240, 174);
};
```



```cpp title="include/paint.hpp — đóng nét và đặt dấu"
inline void cancelStroke(PaintState& state) {
    state.drawing = false;
}

inline void applyStamp(Framebuffer& framebuffer, PaintState& state, Point point) {
    stampPoint(framebuffer, point, state.color);
}
```


`color` là màu dùng cho dấu mới, còn các dấu cũ đã thành pixel nên không cần lưu cả lịch sử event. `applyStamp` hiện chỉ gọi đầu bút một pixel; bài 2 sẽ đổi đúng chỗ này.

Bắt đầu nét phải vẽ ngay, không chờ motion:


```cpp title="include/paint.hpp — click đơn cũng để lại dấu"
inline bool beginStroke(Framebuffer& framebuffer, PaintState& state, Point point) {
    if (state.drawing || !insideCanvas(point)) {
        return false;
    }
    state.drawing = true;
    state.previous = point;
    applyStamp(framebuffer, state, point);
    return true;
}
```


Giá trị `true` báo rằng ảnh đã đổi. Nhấn lần nữa trong khi một nét đang mở không được thay `previous` của nét hiện tại.

### Bước 4 — Tiếp tục rồi kết thúc nét


```cpp title="include/paint.hpp — chỉ vẽ khi đã nhấn chuột"
inline bool moveStroke(Framebuffer& framebuffer, PaintState& state, Point current) {
    if (!state.drawing) {
        return false;
    }
    if (!insideCanvas(current)) {
        cancelStroke(state);
        return false;
    }
    if (current == state.previous) {
        return false;
    }
    // Bài 1–3 cố ý chỉ đặt dấu ở mẫu mới, chưa nối khoảng giữa hai mẫu.
    applyStamp(framebuffer, state, current);
    state.previous = current;
    return true;
}
```


Mỗi motion được chấp nhận đặt dấu tại `current` rồi mới cập nhật `previous`. Hai điểm trùng nhau không cần đặt thêm dấu. Ra ngoài ảnh thì cancel thay vì nối một đoạn cực dài.


```cpp title="include/paint.hpp — thả chuột phải xử lý cả vị trí cuối"
inline bool endStroke(Framebuffer& framebuffer, PaintState& state, Point endpoint) {
    const bool changed = moveStroke(framebuffer, state, endpoint);
    cancelStroke(state);
    return changed;
}
```


Sự kiện thả nút có thể chứa vị trí chưa xuất hiện trong motion cuối. Vì vậy ta xử lý nó trước khi tắt `drawing`. Còn `cancelStroke` không xử lý endpoint: khi mất focus, không nên đoán thêm một đoạn.

### Bước 5 — Đổi tọa độ event đúng một lần

Thêm `#include "paint.hpp"` trong `main.cpp` và khai báo `lab::PaintState state;`, `SDL_MouseID strokeMouse = 0;` trước vòng lặp. Sau xử lý Close/Escape, trước khi dùng tọa độ chuột:


```cpp title="src/main.cpp — chuyển từ window sang ảnh logic"
const bool mouseEvent = event.type == SDL_EVENT_MOUSE_BUTTON_DOWN || event.type == SDL_EVENT_MOUSE_BUTTON_UP || event.type == SDL_EVENT_MOUSE_MOTION;
            if (mouseEvent && !SDL_ConvertEventToRenderCoordinates(renderer, &event)) {
                std::cerr << "Mouse coordinates failed: " << SDL_GetError() << '\n';
                failed = true;
                running = false;
                break;
            }
```


SDL tính cả logical presentation, viewport và scale. Kết quả **vẫn có thể nằm ngoài vùng render**, nên không bỏ `insideCanvas` sau khi đổi. Không gọi conversion lần thứ hai trên cùng event. [Tài liệu SDL](https://wiki.libsdl.org/SDL3/SDL_ConvertEventToRenderCoordinates).

### Bước 6 — Gọi các hàm trên từ ba nhánh chuột


```cpp title="src/main.cpp — nhấn trái và nhận quyền kéo chuột"
if (event.type == SDL_EVENT_MOUSE_BUTTON_DOWN && event.button.button == SDL_BUTTON_LEFT) {
                const lab::Point point{event.button.x, event.button.y};
                if (lab::beginStroke(framebuffer, state, point)) {
                    strokeMouse = event.button.which;
                    dirty = true;
                    if (!SDL_CaptureMouse(true)) {
                        std::cerr << "Capture unavailable: " << SDL_GetError() << '\n';
                    }
                }
            }
```


`strokeMouse` ghi thiết bị đang sở hữu nét để thiết bị khác không vô tình đóng nó. Capture giúp nhận event ngoài window nhưng có thể không được nền tảng hỗ trợ; lỗi này được báo và ta vẫn vẽ trong ảnh. SDL thường tự capture khi đang giữ nút; lời gọi tường minh chỉ kéo dài trong thao tác, không giữ suốt ứng dụng. [SDL_CaptureMouse](https://wiki.libsdl.org/SDL3/SDL_CaptureMouse).


```cpp title="src/main.cpp — kéo rồi thả chuột"
if (event.type == SDL_EVENT_MOUSE_MOTION && event.motion.which == strokeMouse && state.drawing) {
                if ((event.motion.state & SDL_BUTTON_LMASK) == 0) {
                    lab::cancelStroke(state);
                } else {
                    const lab::Point current{event.motion.x, event.motion.y};
                    if (lab::moveStroke(framebuffer, state, current)) {
                        dirty = true;
                    }
                }
                if (!state.drawing) {
                    SDL_CaptureMouse(false);
                }
            }
if (event.type == SDL_EVENT_MOUSE_BUTTON_UP && event.button.button == SDL_BUTTON_LEFT && event.button.which == strokeMouse) {
                const lab::Point endpoint{event.button.x, event.button.y};
                if (lab::endStroke(framebuffer, state, endpoint)) {
                    dirty = true;
                }
                SDL_CaptureMouse(false);
            }
```


Kiểm mask nút trái trong motion giúp đóng nét nếu một event thả bị bỏ lỡ. Khi thao tác thực sự vẽ được, đặt `dirty = true`. Đừng viết `dirty = dirty || moveStroke(...)`: nếu dirty vốn đã true, toán tử `||` sẽ bỏ qua lời gọi cần vẽ.

Trong nhóm window event, mất focus/minimize/resize/mouse leave gọi `cancelStroke` và nhả capture. Phần đó có đầy đủ trong mã cuối trang.

## Ghép các phần lại

Build rồi chạy `project_3_checkpoint_1`. Lần lượt click một lần, di chuột không giữ nút, kéo rồi thả, tạo nét thứ hai ở xa. Hình chỉ là chuỗi pixel nhỏ nên hãy nhìn gần hoặc dùng zoom màn hình để quan sát.

Luồng hiện tại là event → đổi tọa độ → begin/move/end → stampPoint → putPixel → dirty upload → present. Các hàm xử lý nét không phụ thuộc SDL; app chỉ chuyển dữ liệu vào chúng.

## Thử làm sai để hiểu đúng

1. Clear framebuffer ở đầu mỗi frame. Chấm biến mất vì dữ liệu tranh bị xóa, không phải do event chuột.
2. Bỏ dấu đầu trong `beginStroke`. Click không kéo không còn vẽ được.
3. Bỏ conversion rồi resize window. Vị trí bút lệch khỏi con trỏ, nhất là khi có viền letterbox.
4. Cancel trước khi gọi `moveStroke` trong `endStroke`. Mẫu cuối chỉ có ở up sẽ bị bỏ mất.

## Tự kiểm tra kết quả

- Click trái tạo dấu ngay; hover và nút khác không vẽ.
- Thả trái dừng nét; nét mới không nối với nét cũ.
- Ra ngoài ảnh/mất focus/resize thì dừng, trở lại không tự vẽ tiếp khi chưa nhấn lại.
- Ảnh giữ nguyên qua nhiều frame và resize; nét nằm đúng chỗ con trỏ.
- Chưa có hình tròn hoặc nội suy. Escape và Close vẫn thoát sạch.
