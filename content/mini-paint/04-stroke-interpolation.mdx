# Nối mẫu thành nét liền

## Vấn đề cần giải quyết

Bài trước đã biết khoảng trống nằm ở đâu: giữa previous và current. Bây giờ ta đặt thêm dấu dọc đoạn này, không đổi đầu bút, phần chuột hay dữ liệu thí nghiệm.

Hãy thử với đoạn dài 17 pixel, khoảng tâm tối đa 8 pixel. Cần bao nhiêu khoảng, bao nhiêu điểm? Hai khoảng cho mỗi khoảng 8,5 pixel nên chưa đạt. Phải dùng ba khoảng và bốn điểm.

## Hiểu ý tưởng trước khi viết code

Một điểm giữa A và B được tính bằng:

$$
P(t) = A + (B-A)t,\qquad 0 \le t \le 1.
$$

t = 0 là A, t = 1 là B, t = 0,5 là trung điểm. Với chiều dài d và khoảng cách tối đa s:

$$
n = \left\lceil \frac{d}{s} \right\rceil.
$$

Dùng n khoảng thì có n+1 điểm. Làm tròn lên bảo đảm d/n ≤ s. Hai tọa độ dùng cùng t nên điểm nằm trên đoạn thẳng. **Đây không phải cách khôi phục quỹ đạo đã mất**: nếu chuột đi qua một góc nhưng điểm ở góc bị bỏ, nội suy sẽ cắt thẳng qua góc đó.

## Viết code từng bước

### Bước 1 — Viết lerp rõ hai thành phần

Trong `include/lab.hpp` thêm `<algorithm>`, `<vector>` rồi đặt hàm này sau distance:


```cpp title="include/lab.hpp — tính điểm bên trong một đoạn"
inline Point lerp(Point start, Point end, double t) {
    return {
        start.x + (end.x - start.x) * t,
        start.y + (end.y - start.y) * t,
    };
}
```


Phép nhân t dùng số thực. Nếu index/steps bị chia theo số nguyên, gần như mọi điểm giữa đều dồn về đầu đoạn.

### Bước 2 — Tính danh sách điểm có giới hạn rõ ràng


```cpp title="include/lab.hpp — toàn bộ sampleStroke"
inline std::vector<Point> sampleStroke(Point start, Point end, double spacing) {
    if (!std::isfinite(start.x) || !std::isfinite(start.y) || !std::isfinite(end.x) || !std::isfinite(end.y)) {
        return {};
    }
    const double segmentLength = distance(start, end);
    constexpr double kMaximumSegmentLength = 2048.0;
    if (!std::isfinite(segmentLength) || segmentLength > kMaximumSegmentLength) {
        return {};
    }
    if (segmentLength == 0.0) {
        return {start};
    }

    double safeSpacing = 0.5;
    if (std::isfinite(spacing)) {
        safeSpacing = std::max(spacing, 0.5);
    }
    const int steps = std::max(1, static_cast<int>(std::ceil(segmentLength / safeSpacing)));
    std::vector<Point> points;
    points.reserve(static_cast<std::size_t>(steps) + 1);
    points.push_back(start);
    for (int index = 1; index < steps; ++index) {
        const double t = static_cast<double>(index) / static_cast<double>(steps);
        points.push_back(lerp(start, end, t));
    }
    points.push_back(end);
    return points;
}
```


Đọc theo thứ tự: từ chối tọa độ không hữu hạn; đo chiều dài; từ chối đoạn quá 2.048 pixel; trả một điểm nếu hai đầu trùng; chuẩn hóa spacing; cuối cùng mới tính số bước và cấp phát.

Sàn spacing 0,5 pixel **một mình không ngăn được cấp phát lớn** nếu hai đầu cách nhau cực xa. Vì vậy cần cả giới hạn chiều dài. Với 2.048/0,5, tối đa có 4.096 khoảng và 4.097 điểm. Đoạn giữa hai vị trí hợp lệ trong ảnh 960×540 luôn ngắn hơn mức này. Helper từ chối đoạn ngoài hợp đồng, không âm thầm tăng spacing.

`start` và `end` được đưa trực tiếp vào vector; chỉ điểm bên trong dùng lerp. Nhờ vậy hai endpoint giữ đúng giá trị đầu vào, không dựa vào phép cộng số thực ở t = 1. `reserve` chỉ cấp phát chỗ chứa, chưa làm tăng size; `push_back` mới thêm điểm.

### Bước 3 — Thay một dấu bằng các dấu dọc đoạn

Trong `moveStroke`, thay lời gọi đặt dấu tại current bằng:


```cpp title="include/paint.hpp — dùng mẫu hiện có để tạo nét liền"
const double spacing = static_cast<double>(state.radius) * 0.8;
    for (Point point : sampleStroke(state.previous, current, spacing)) {
        applyStamp(framebuffer, state, point);
    }
    state.previous = current;
```


`previous` vẫn đổi sau khi xử lý xong đoạn. Hai đoạn kề nhau có thể đặt dấu lặp tại điểm chung; project chấp nhận việc này để thuật toán dễ theo dõi. Vì bút đục và không blend alpha, lặp dấu không làm nó đậm thêm.

Mức 0,8r là lựa chọn thực hành để các dấu chồng nhau. Khoảng tâm này được tính **trước khi floor về pixel**; kết quả raster còn cần kiểm riêng, không dùng bất đẳng thức liên tục để tuyên bố mọi pixel đã đúng.

### Bước 4 — Giữ endpoint và việc đóng nét như cũ


```cpp title="include/paint.hpp — up đi qua cùng nội suy trước khi đóng nét"
inline bool endStroke(Framebuffer& framebuffer, PaintState& state, Point endpoint) {
    const bool changed = moveStroke(framebuffer, state, endpoint, true);
    cancelStroke(state);
    return changed;
}
```


Down đã có dấu đầu; move nối các vị trí được giữ; up ép giữ vị trí thả rồi cancel. Mất focus và ra ngoài vùng ảnh vẫn chỉ cancel, không đoán endpoint mới. Không nối qua viền hoặc nối hai lần nhấn khác nhau.

## Ghép các phần lại

Chạy checkpoint 3 và 4, cùng chọn S = 1/4 rồi D. Cả hai có input gap 800 px. Checkpoint 3 chỉ có dấu ở hai đầu, còn checkpoint 4 tạo đủ dấu giữa đoạn. **Input gap không phải stamp gap**: số đo input lớn không có nghĩa nội suy thất bại.

Thử tiếp bằng chuột thật. Phiên bản này không làm phần cứng chuột gửi thêm event; nó tự tạo điểm vẽ giữa những vị trí đã biết.

## Thử làm sai để hiểu đúng

1. Đổi ceil thành floor trong đoạn 17/8. Chỉ còn hai khoảng, mỗi khoảng vượt 8.
2. Chỉ chạy index < steps nhưng quên push end. Nét hụt ở vị trí cuối.
3. Dùng phép chia int cho t. Các điểm bị dồn về đầu.
4. Bỏ giới hạn chiều dài rồi thử tọa độ rất lớn. Chỉ kiểm helper bằng test có giới hạn, không dùng event giả khổng lồ làm ứng dụng treo.
