# Một hạt đóng góp vào vùng xung quanh thế nào?

## Vấn đề cần giải quyết

Cho các chấm rơi không khiến chúng tạo thành một khối nước. Ta cần một cách ước lượng lượng chất lỏng quanh mỗi vị trí. Nhưng trước khi cộng hàng xóm, phải quyết định một hạt ở gần hay xa đóng góp bao nhiêu.

## Hiểu ý tưởng trước khi viết code

Kernel `W(r)` là trọng số theo khoảng cách. Nó lớn gần tâm, giảm dần và tắt hẳn ngoài `2h`. `h=1.3*spacing=0.091 m`; support là `0.182 m`. Hai số này không phải bán kính chấm trên màn hình.

Ta dùng cubic spline chuẩn hóa **theo diện tích 2D**. Đặt `q=r/h`:

$$W(r)=\frac{10}{7\pi h^2}\begin{cases}1-\frac32q^2+\frac34q^3,&0\le q<1,\\\frac14(2-q)^3,&1\le q<2,\\0,&q\ge2.\end{cases}$$

`W` có đơn vị m⁻². Nhân với mass kg sẽ cho density kg/m². Không lấy hệ số 3D `1/(πh³)` rồi vẫn gọi kết quả là cùng mô hình. Công thức chuẩn hóa được đối chiếu với [tài liệu kernel của PySPH](https://pysph.readthedocs.io/en/main/reference/kernels.html).

Đoán trước khi thử: hạt ở đúng `r=2h` có còn đóng góp không? Gradient tại tâm nên là một vector theo hướng nào?

## Viết code từng bước

Viết hai hàm trong `sph/kernel.hpp`:

{/* snippet include/sph/kernel.hpp#kernel */}

```cpp title="include/sph/kernel.hpp — kernel và gradient 2D"
inline double kernel(double distance) {
    const double q = std::abs(distance) / h;
    const double normalization = 10 / (7 * std::numbers::pi * h * h);
    if (q >= 2) {
        return 0;
    }
    if (q < 1) {
        return normalization * (1 - 1.5 * q * q + 0.75 * q * q * q);
    }
    const double tail = 2 - q;
    return normalization * 0.25 * tail * tail * tail;
}

inline Vec2 gradient(double dx, double dy) {
    const double distance = std::sqrt(dx * dx + dy * dy);
    const double q = distance / h;
    if (distance == 0 || q >= 2) {
        return {};
    }
    const double normalization = 10 / (7 * std::numbers::pi * h * h);
    double derivative = -0.75 * (2 - q) * (2 - q);
    if (q < 1) {
        derivative = -3 * q + 2.25 * q * q;
    }
    const double factor = normalization * derivative / (h * distance);
    return {factor * dx, factor * dy};
}
```

`gradient(dx,dy)` lấy đạo hàm theo `q`, nhân `1/h`, rồi nhân hướng `displacement/r`. Vì chia cho r, phải xử lý `distance==0` trước. Tại tâm, độ dốc của kernel đối xứng bằng 0; trả `{0,0}` là giá trị đúng, không phải cách né lỗi.

## Ghép các phần lại

Chưa thêm lực ở bài này. Renderer/Canvas dùng `support` để vẽ vòng quanh hạt đang chọn; đồ thị nhỏ biểu diễn `W(r)/W(0)`. Ở bài tiếp, `computeDensity` mới gọi `kernel` trong neighbor loop. `gradient` sẽ được dùng khi viết lực pressure, không dùng để di chuyển chấm ngay bây giờ.

## Thử làm sai để hiểu đúng

Bỏ nhánh `distance==0`. Hạt sẽ trở thành hàng xóm của chính nó ở bài sau, nên phép `0/0` chắc chắn xảy ra. Tiếp đó đổi support thành h nhưng giữ nguyên công thức: bạn vừa cắt bỏ đuôi của kernel, tích phân sẽ không còn bằng 1.

## Tự kiểm tra kết quả

- `kernel(0)>kernel(h)>kernel(2h)=0` và hai nhánh liên tục ở h.
- `gradient(0,0)` bằng 0, không NaN; gradient đổi dấu khi đảo displacement.
- Tích phân theo diện tích `2π∫rW(r)dr` gần 1, sai số dưới 1e−6 với 10.000 midpoint samples.
- So gradient với finite difference ở `0.3h`, `1.2h`, `1.8h`; không chỉ gọi cùng một công thức hai lần.

## Bài tập mở rộng

Vẽ cùng `W(r)` khi h gấp đôi và dự đoán chiều cao đỉnh. Tổng diện tích vẫn là 1 nên đỉnh không thể giữ nguyên. [Tiếp: tính density từ hàng xóm](./04-density-va-mau-tuong).
