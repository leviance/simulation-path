# Một hạt ảnh hưởng tới vùng xung quanh như thế nào?

## Vấn đề cần giải quyết

Một đám điểm riêng lẻ chưa cho ta density hay pressure. SPH giải quyết bằng cách coi mỗi hạt đóng góp vào một vùng xung quanh. Gần hạt thì trọng số lớn; càng xa thì nhỏ; ngoài support thì bằng 0. Hàm trọng số ấy gọi là kernel.

Bài này chưa dùng kernel để đẩy hạt. Ta viết kernel/gradient, chọn một hạt và vẽ vòng support. Tách bước này ra giúp bắt lỗi hệ số 2D trước khi nó lan sang mọi density và lực.

## Hiểu ý tưởng trước khi viết code

Chọn smoothing length h=1.3*spacing=0.0585 m. Cubic spline dưới đây có support **2h**, không phải h. Đặt q=r/h:

$$
W(r)=\frac{10}{7\pi h^2}
\begin{cases}
1-\frac32q^2+\frac34q^3,&0\le q<1,\\
\frac14(2-q)^3,&1\le q<2,\\
0,&q\ge2.
\end{cases}
$$

Hệ số trước ngoặc bảo đảm tích phân kernel theo **diện tích** bằng 1. Kernel có đơn vị m⁻². Vì đang viết mô hình 2D, ta không lấy hệ số 1/(πh³) của 3D. [Tài liệu kernel của PySPH](https://pysph.readthedocs.io/en/main/reference/kernels.html) dùng đúng quy ước q=r/h và support 2h này.

Để tính lực, cần gradient theo vị trí hạt i. Với displacement=x_i−x_j và r là độ dài của nó:

$$
\nabla_iW=\frac{10}{7\pi h^3}f'(q)\frac{\mathbf x_i-\mathbf x_j}{r}.
$$

Khi r=0, gradient bằng vector 0 do đối xứng; không chia cho r rồi mới sửa NaN. Kernel vẫn có giá trị dương tại r=0. Hai điều này khác nhau.

## Viết code từng bước

### Bước 1 — Khai báo kích thước dùng chung

Trong `include/model.hpp`, các giá trị đã có từ bộ khung nay được dùng để định nghĩa vùng ảnh hưởng:

```cpp title="include/model.hpp — spacing, smoothing length và support"
constexpr double spacing = 0.045;
constexpr double h = 1.3 * spacing;
constexpr double support = 2 * h;
```

Vòng nhỏ trên Canvas là h, vòng lớn là 2h. Các đường nối đi tới hạt trong vòng lớn; chúng chưa biểu diễn độ lớn lực.

### Bước 2 — Viết hai nhánh của kernel

Thêm `kernel(double r)` vào `include/kernel.hpp`; include `<numbers>` cho π. Hàm nhận khoảng cách, không nhận bình phương khoảng cách:

```cpp title="include/kernel.hpp — kernel cubic spline 2D"
const double q = std::abs(r) / h;
const double normalization = 10 / (7 * std::numbers::pi * h * h);
if (q >= 2) {
    return 0;
}
if (q < 1) {
    return normalization * (1 - 1.5 * q * q + 0.75 * q * q * q);
}
return normalization * 0.25 * std::pow(2 - q, 3);
```

Không bỏ normalization rồi tăng mass để nhìn “gần giống”. Làm vậy sẽ mất ý nghĩa đơn vị và phép kiểm density.

### Bước 3 — Viết gradient và xử lý tâm

Trong `gradient`, tính r/q trước, trả 0 ở gốc và ngoài support. Sau đó lấy đạo hàm f′ ở nhánh tương ứng:

```cpp title="include/kernel.hpp — nhánh gradient hữu hạn"
if (r == 0 || q >= 2) {
    return {0, 0};
}
const double normalization = 10 / (7 * std::numbers::pi * h * h);
double derivative = -0.75 * std::pow(2 - q, 2);
if (q < 1) {
    derivative = -3 * q + 2.25 * q * q;
}
const double scale = normalization * derivative / (h * r);
return {scale * displacement.x, scale * displacement.y};
```

Ở `view.hpp`, vòng support được vẽ bằng 64 đoạn thẳng quanh position đang chọn. Dùng `700*support` để đổi bán kính sang logical pixel. Click chọn hạt gần nhất; phím trái/phải chọn index để thao tác không phụ thuộc chuột.

## Thử làm sai để hiểu đúng

1. Đổi cutoff thành r=h trong phần chọn hàng xóm nhưng giữ kernel support 2h. Vòng ngoài còn nhiều đóng góp dương bị bỏ sót; density sẽ thấp sai ở bài tiếp theo.
2. Bỏ nhánh r=0 của gradient. Self pair tạo 0/0. Khôi phục nhánh, kiểm gradient(0,0) bằng vector 0.

## Tự kiểm tra kết quả

W không âm, bằng 0 tại/ngoài 2h; W(0)=10/(7πh²). Gradient đảo dấu khi displacement đảo dấu. Tích phân số `2π∫rW(r)dr` phải gần 1; phép kiểm này được chạy đầy đủ ở Bài 10. Đừng chỉ kiểm diện tích dưới đồ thị W(r): thiếu hệ số 2πr sẽ sai phép đo 2D.
