# Cho hạt rơi, rồi giữ chúng trong bể

## Vấn đề cần giải quyết

Ở bài trước, các chấm chỉ đứng yên. Bây giờ ta cho chúng rơi dưới trọng lực và dừng ở thành bể. Đừng vội gọi kết quả là nước: các hạt lúc này vẫn đi xuyên qua nhau vì chưa có density hay pressure.

## Hiểu ý tưởng trước khi viết code

Acceleration cho biết vận tốc thay đổi nhanh thế nào. Semi-implicit Euler cập nhật vận tốc trước, rồi dùng vận tốc mới để đổi vị trí:

$$v^{n+1}=v^n+a^n\Delta t,\qquad x^{n+1}=x^n+v^{n+1}\Delta t.$$

Gravity nằm trên y nên `ax=0`, `ay=-g`. Ở các bài chưa có pressure, N tiến 0,01 s. Sau mười lần N, tổng thời gian là 0,1 s; một hạt chưa chạm biên có `vy=-0.981 m/s`. Với cách tích phân này, quãng rơi là 0,053955 m, không phải đúng nghiệm liên tục 0,04905 m. Sai khác đó là sai số tích phân, không phải do SDL.

## Viết code từng bước

### Đổi state bằng dt, không bằng số frame

Trong `sph/solver.hpp`, `step` đặt acceleration cho toàn bộ hạt. Sau đó gọi hàm sau, không đặt phép cộng vị trí trong `draw`:

{/* snippet include/sph/boundary.hpp#integrate */}

```cpp title="include/sph/boundary.hpp — tích phân một bước"
inline void integrate(State& state, double dt) {
    for (auto& p : state.particles) {
        p.vx += p.ax * dt;
        p.vy += p.ay * dt;
        p.x += p.vx * dt;
        p.y += p.vy * dt;
        collide(state, p);
    }
    state.time += dt;
    state.dt = dt;
    ++state.tick;
    state.updated = state.particles.size();
}
```

`updated` đếm số hạt thật đã đi qua lượt cập nhật. `tick` tăng một lần cho cả hệ, không tăng theo từng hạt.

### Chỉ sửa vận tốc đang hướng ra ngoài

Khi tâm hạt vượt biên, ta đưa nó về mặt giới hạn và phản xạ một phần nhỏ vận tốc pháp tuyến. Hệ số 0,05 làm va chạm rất ít nảy. Thành trái chỉ sửa `vx` âm; nó không được đảo một `vx` dương đang đưa hạt trở vào bể.

{/* snippet include/sph/boundary.hpp#boundary */}

```cpp title="include/sph/boundary.hpp — va chạm với bốn thành"
inline void collide(State& state, Particle& p) {
    const double radius = spacing / 2;
    if (p.x < radius) {
        p.x = radius;
        if (p.vx < 0) {
            p.vx *= -0.05;
        }
        ++state.contacts;
    }
    if (p.x > width - radius) {
        p.x = width - radius;
        if (p.vx > 0) {
            p.vx *= -0.05;
        }
        ++state.contacts;
    }
    if (p.y < radius) {
        p.y = radius;
        if (p.vy < 0) {
            p.vy *= -0.05;
        }
        ++state.contacts;
    }
    if (p.y > height - radius) {
        p.y = height - radius;
        if (p.vy > 0) {
            p.vy *= -0.05;
        }
        ++state.contacts;
    }
}
```

Đây là bể kín bốn cạnh, kể cả trần. Đường biên phía trên không phải một miệng mở cho nước tràn ra.

## Ghép các phần lại

Phím N trong `app/input.hpp` pause trước, gọi `App.oneStep`, rồi cập nhật inspector. `oneStep` gọi `water::step`; `step` gọi `integrate`; cuối cùng renderer đọc vị trí mới. Sau bài này, hãy chạy checkpoint 2 và đối chiếu chuỗi gọi đó bằng debugger.

Đây là `step` hoàn chỉnh ở checkpoint 2. Lượt đầu gán acceleration, lượt trong `integrate` mới đổi velocity/position. Bạn có thể thấy chính xác nơi hàm vừa viết được gọi:

{/* snippet include/sph/solver.hpp#step */}

```cpp title="include/sph/solver.hpp — nối gravity và integrate"
inline void step(State& state, const Settings& settings) {
    validate(settings);
    requireFinite(state);
    for (auto& p : state.particles) {
        p.ax = 0;
        p.ay = -settings.gravity;
    }
    requireFinite(state);
    const double dt = 0.01;
    integrate(state, dt);
    requireFinite(state);
}
```

Để kiểm con số velocity trong C++, đặt breakpoint ngay trước `collide` và chọn một hạt chưa chạm thành; xem `p.vy` ở cửa sổ Watch. Canvas có hàng Velocity để thử nhanh. Đừng dùng một hạt đã chạm đáy để so với công thức rơi tự do.

## Thử làm sai để hiểu đúng

Đổi `p.vy += p.ay * dt` thành `p.vy += p.ay`. Mười bước sẽ tạo tốc độ lớn gấp 100 lần ở dt=0,01. Tiếp theo, thử đảo velocity ở thành trái mà không kiểm dấu: một hạt đang đi vào bể sẽ bị hãm sai. Hoàn tác trước khi tiếp tục.

## Tự kiểm tra kết quả

- Một hạt tự do sau 10 bước có `vy=-0.981`, quãng rơi 0,053955 m trong sai số số thực nhỏ.
- Velocity tiếp tuyến không bị sửa chỉ vì chạm thành.
- Hạt không ra ngoài vùng tâm `[spacing/2, width-spacing/2] × [spacing/2, height-spacing/2]`.
- Chưa có force giữa các hạt. Nếu chúng chồng lên nhau, đó là điều bài này chưa giải quyết.
