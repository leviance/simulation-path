# Dựng bể và vẽ 1.000 hạt đầu tiên

## Vấn đề cần giải quyết

Bạn có thể vẽ hàng nghìn chấm xanh mà chưa tạo ra một giọt nước nào. Nhưng nếu chưa biết dữ liệu nào tạo ra các chấm ấy, viết thêm công thức sẽ chỉ khiến chương trình khó hiểu hơn. Bài đầu dừng ở một việc rõ ràng: mở cửa sổ, dựng bể và vẽ đúng 1.000 hạt đứng yên.

[Tải ZIP Project 50](/downloads/project-50-sph-water.zip), giải nén rồi mở terminal ở thư mục có `CMakeLists.txt`:

```bash title="Terminal — bắt đầu từ khung SDL3"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_50_starter --parallel 1
.\build\Debug\project_50_starter.exe
```

Starter có bể trống và panel để bạn không phải viết lại phần giao diện SDL3. Chưa có thuật toán chất lưu giấu trong đó. Bạn sửa `starter/`, hoặc chạy target `project_50_checkpoint_1` để đối chiếu. Mỗi checkpoint trong ZIP là một bộ source độc lập; phần cuối bài trên web cũng có đầy đủ các file.

## Hiểu ý tưởng trước khi viết code

Ta chọn bể rộng 12,6 m, cao 7,56 m. Đây là kích thước của mô hình 2D, không phải kích thước cửa sổ. Trục y hướng lên. Một hạt giữ vị trí và vận tốc; màu xanh chỉ xuất hiện lúc vẽ.

{/* snippet include/sph/model.hpp#particle */}

```cpp title="include/sph/model.hpp — dữ liệu một hạt"
struct Particle {
    double x = 0;
    double y = 0;
    double vx = 0;
    double vy = 0;
    double density = restDensity;
    double pressure = 0;
    double ax = 0;
    double ay = 0;
};
```

Vì chưa có chuyển động, `vx`, `vy`, `ax`, `ay` đều bằng 0. Hai số `density` và `pressure` chưa được dùng để tính lực; đừng nhầm việc có tên biến với việc đã có một solver.

Thử đoán trước: kéo rộng cửa sổ có nên làm hạt tự cách xa nhau trong world space không?

## Viết code từng bước

### Mở cửa sổ theo từng bước có kiểm lỗi

`main.cpp` trong scaffold đã có phần này. Đọc qua một lần để biết tài nguyên được tạo và giải phóng ở đâu. Renderer không được tạo bằng một biểu thức viết tắt khó dò lỗi:

{/* snippet src/main.cpp#window */}

```cpp title="src/main.cpp — khởi tạo SDL3 và logical presentation"
if (!SDL_Init(SDL_INIT_VIDEO)) {
    std::cerr << SDL_GetError() << '\n';
    return EXIT_FAILURE;
}
SDL_WindowFlags flags = SDL_WINDOW_RESIZABLE;
if (options.hidden) {
    flags |= SDL_WINDOW_HIDDEN;
}
SDL_Window* window = SDL_CreateWindow("Project 50 - SPH Water Tank", 1280, 820, flags);
if (window == nullptr) {
    std::cerr << SDL_GetError() << '\n';
    SDL_Quit();
    return EXIT_FAILURE;
}
SDL_Renderer* renderer = SDL_CreateRenderer(window, nullptr);
if (renderer == nullptr) {
    std::cerr << SDL_GetError() << '\n';
    SDL_DestroyWindow(window);
    SDL_Quit();
    return EXIT_FAILURE;
}
if (!SDL_SetRenderLogicalPresentation(renderer, 1280, 820, SDL_LOGICAL_PRESENTATION_LETTERBOX)) {
    std::cerr << SDL_GetError() << '\n';
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return EXIT_FAILURE;
}
```

Logical presentation 1280×820 làm panel và thao tác chuột ổn định khi resize. Nó không quyết định bể rộng bao nhiêu mét.

### Đặt các hạt vào một cột

`makeState` tạo dữ liệu bằng hai chỉ số hàng/cột. Với 1.000 hạt, cột có 20 hạt mỗi hàng và 50 hàng. Khoảng cách tâm là `spacing=0.07`. Không dùng bán kính vẽ để quyết định vị trí vật lý.

{/* snippet include/sph/scenes.hpp#scene */}

```cpp title="include/sph/scenes.hpp — tạo cảnh"
inline State makeState([[maybe_unused]] Preset preset = Preset::Dam, std::size_t count = 5000) {
    if (count != 1000 && count != 5000 && count != 10000) {
        throw std::invalid_argument("Choose 1000, 5000 or 10000 particles");
    }
    State state;
    if (preset != Preset::Empty) {
        std::size_t columns = count / 100;
        if (count == 1000) {
            columns = 20;
        }
        if (preset == Preset::Pool) {
            columns = 125;
        }
        state.particles.reserve(capacity);
        for (std::size_t i = 0; i < count; ++i) {
            const double x = (static_cast<double>(i % columns) + 0.5) * spacing;
            const double y = (static_cast<double>(i / columns) + 0.5) * spacing;
            state.particles.push_back({x, y});
        }
    }
    return state;
}
```

`include/app/state.hpp` giữ `state` giữa các frame. Bạn không được gọi `makeState` trong mỗi lượt vẽ, nếu không chuyển động về sau sẽ liên tục bị đặt lại.

### Đổi vị trí world thành pixel

Một hạt ở y=0 nằm ở đáy bể, còn pixel y=0 nằm phía trên cửa sổ. `toScreen` là nơi duy nhất đảo trục. Ta chia vị trí cho kích thước world để được tỉ lệ, nhân kích thước viewport rồi cộng góc viewport:

{/* snippet include/app/draw.hpp#mapping */}

```cpp title="include/app/draw.hpp — ánh xạ world và screen"
inline water::Vec2 toScreen(double x, double y) {
    return {viewport.x + viewport.w * x / water::width, viewport.y + viewport.h * (1 - y / water::height)};
}

inline bool fromScreen(float x, float y, water::Vec2& point) {
    if (x < viewport.x || x > viewport.x + viewport.w || y < viewport.y || y > viewport.y + viewport.h) {
        return false;
    }
    point.x = water::width * (x - viewport.x) / viewport.w;
    point.y = water::height * (1 - (y - viewport.y) / viewport.h);
    return true;
}
```

`fromScreen` đi ngược lại để dùng cho con trỏ ở các bài sau; bạn chưa phải viết input vào solver lúc này. Điểm giữa bể phải vào giữa viewport, không phải giữa cả cửa sổ có panel bên phải.

### Vẽ đĩa nhỏ bằng scanline SDL3

Với mỗi độ lệch `dy`, nửa chiều dài đường ngang của hình tròn là `sqrt(radius²−dy²)`. Đây là cùng ý tưởng hình tròn đã gặp ở Project 04, lần này dùng `SDL_RenderLine` để vẽ một hạt:

{/* snippet include/app/draw.hpp#disk */}

```cpp title="include/app/draw.hpp — primitive vẽ một hạt"
inline void disk(SDL_Renderer* renderer, float x, float y, float radius) {
    for (int dy = -static_cast<int>(radius); dy <= static_cast<int>(radius); ++dy) {
        const float span = std::sqrt(std::max(0.0f, radius * radius - dy * dy));
        SDL_RenderLine(renderer, x - span, y + dy, x + span, y + dy);
    }
}
```

Cuối cùng, trong `draw`, duyệt các hạt, đổi tọa độ rồi gọi primitive vừa viết:

{/* snippet include/app/draw.hpp#draw-particles */}

```cpp title="include/app/draw.hpp — nối dữ liệu với renderer"
for (const auto& p : app.state.particles) {
    const auto point = toScreen(p.x, p.y);
    SDL_SetRenderDrawColor(renderer, 40, 170, 239, 255);
    disk(renderer, static_cast<float>(point.x), static_cast<float>(point.y), 2.2f);
}
```

Màu `(40,170,239,255)` và bán kính 2,2 pixel chỉ là cách vẽ. Chúng không quyết định mass hoặc vùng ảnh hưởng giữa các hạt. Giữ `SDL_RenderPresent` ở cuối vòng lặp để trình bày cả frame một lần, không present sau từng chấm.

## Ghép các phần lại

`main` tạo `tank::App`; constructor gọi `rebuild`, rồi `draw` duyệt `state.particles`. `toScreen` trong `app/draw.hpp` đổi tọa độ trước khi `disk` vẽ từng chấm bằng scanline. Chỉ hàm đổi tọa độ đảo y; dữ liệu vật lý vẫn hướng lên.

## Thử làm sai để hiểu đúng

Tạm bỏ phép `1-y/height` khi đổi y sang screen. Cột hạt sẽ xuất hiện gần trần thay vì đáy, dù dữ liệu không đổi. Sau đó thử tạo lại state trong vòng vẽ. Hiện tại chưa thấy lỗi; ghi lại dự đoán lỗi sẽ xuất hiện khi ta thêm velocity, rồi hoàn tác cả hai thay đổi.
