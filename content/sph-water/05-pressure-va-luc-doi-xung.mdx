# Biến độ nén thành lực pressure

## Vấn đề cần giải quyết

Density cho biết vùng quanh hạt đang thưa hay dày, nhưng bản thân con số đó không đẩy được hạt nào. Ta cần đổi độ nén thành pressure, rồi đổi chênh lệch ảnh hưởng quanh hạt thành acceleration. Đây là lúc các chấm bắt đầu tác động lẫn nhau.

## Hiểu ý tưởng trước khi viết code

Ta dùng một EOS tuyến tính đơn giản:

$$p_i=\max(0,c^2(\rho_i-\rho_0)).$$

`c` điều khiển độ cứng của mô hình: cùng mức nén, c lớn tạo pressure lớn hơn. Nó **không đổi gravity**. Clamp pressure âm là lựa chọn của mô hình này để không hút các hạt thưa lại với nhau; nó không tự sửa được sai số ở mặt thoáng. Đây không phải pressure projection của Project 49: ta **không giải Poisson**.

Với density kg/m² và c m/s, pressure có đơn vị **N/m**, không phải Pa. Force pressure được viết đối xứng:

$$a_i^{p}=-\sum_j m\left(\frac{p_i}{\rho_i^2}+\frac{p_j}{\rho_j^2}\right)\nabla_iW_{ij}.$$

Nếu đảo i và j, coefficient giữ nguyên còn gradient đổi dấu. Vì hai mass bằng nhau, lực nội của cặp phải triệt tiêu. Điều đó không yêu cầu momentum của cả bể bảo toàn: gravity và tường là lực ngoài.

## Viết code từng bước

### Tính pressure sau khi có đầy đủ density

{/* snippet include/sph/forces.hpp#pressure */}

```cpp title="include/sph/forces.hpp — EOS và pressure"
inline double pressure(double density, double soundSpeed) {
    return std::max(0.0, soundSpeed * soundSpeed * (density - restDensity));
}

inline void computePressure(State& state, const Settings& settings) {
    for (auto& p : state.particles) {
        p.pressure = pressure(p.density, settings.soundSpeed);
    }
}
```

### Cộng lực từ state chưa bị tích phân

{/* snippet include/sph/forces.hpp#force */}

```cpp title="include/sph/forces.hpp — lực pressure đối xứng"
inline void computeForces(State& state, const Search& search, const Settings& settings) {
    const std::size_t count = state.particles.size();
    for (std::size_t i = 0; i < count; ++i) {
        auto& p = state.particles[i];
        p.ax = 0;
        p.ay = -settings.gravity;
        for (const int j : search.lists[i]) {
            if (static_cast<std::size_t>(j) == i) {
                continue;
            }
            const auto& point = search.samples[j];
            double densityB = restDensity;
            double pressureB = p.pressure;
            if (static_cast<std::size_t>(j) < count) {
                densityB = state.particles[j].density;
                pressureB = state.particles[j].pressure;
            }
            const double dx = p.x - point.x;
            const double dy = p.y - point.y;
            const auto grad = gradient(dx, dy);
            double coefficient = p.pressure / (p.density * p.density) + pressureB / (densityB * densityB);
            p.ax -= mass * coefficient * grad.x;
            p.ay -= mass * coefficient * grad.y;
        }
    }
}
```

Mẫu rắn dùng `densityB=ρ₀`, `pressureB=p_i`; đây là xấp xỉ boundary. Với hạt nước, phải lấy pressure/density của **hạt j**, không tái dùng giá trị i. Acceleration được ghi ra trường riêng; chưa hạt nào đổi position trong lượt này.

## Ghép các phần lại

Pipeline của `step` bây giờ là `neighbors → density → pressure → forces → integrate`. Từ bài này, bước cố định giảm từ 0,01 xuống **0,00025 s**. Lực pressure cứng hơn gravity rất nhiều; giữ bước rơi tự do cũ có thể làm hệ nổ số. Bài 8 sẽ chọn dt theo state thay vì giữ cố định.

Đừng chỉ chép helper tính lực rồi quên gọi nó. Thay thân `step` bằng đúng pipeline của checkpoint này:

{/* snippet include/sph/solver.hpp#step */}

```cpp title="include/sph/solver.hpp — ghép pressure vào bước mô phỏng"
inline void step(State& state, const Settings& settings) {
    validate(settings);
    requireFinite(state);
    for (auto& p : state.particles) {
        p.ax = 0;
        p.ay = -settings.gravity;
    }
    bool useGrid = false;
    auto search = buildNeighbors(state, useGrid);
    computeDensity(state, search);
    state.candidates = search.candidates;
    computePressure(state, settings);
    computeForces(state, search, settings);
    requireFinite(state);
    const double dt = 0.00025;
    integrate(state, dt);
    requireFinite(state);
}
```

Trong Canvas, mở **Thí nghiệm lực trên hai hạt độc lập**. Ở đó density được cho trước để cô lập phép tính lực, không gọi summation density, gravity hoặc wall. Với m=4,9 kg, khoảng cách h, ρA=1100, ρB=1200 và c=20: pressure là 40.000/80.000 N/m; lực pressure lên A/B là −962,899070/+962,899070 N. Đây là ca đo, không phải preset hai hạt có thể tự tạo density ấy.

## Thử làm sai để hiểu đúng

Bỏ `p_j/rho_j²` ở một phía hoặc cập nhật position của i ngay trong neighbor loop. Đầu tiên kiểm tổng lực cặp, rồi đảo thứ tự hạt để xem quỹ đạo có phụ thuộc index không. Hoàn tác trước khi chạy cả bể.

## Tự kiểm tra kết quả

- Hai hạt ở density thấp hơn ρ₀ có pressure bằng 0; không có lực hút bí mật.
- Cặp cho trước ở trên có lực đẩy ngược hướng, tổng lực dưới 1e−8 N.
- C đổi stiffness, không đổi gravity/mass/h; lực có dt ở integrate, không nhân dt hai lần.
- Một N chỉ tiến 0,00025 s: đọc velocity/tick để kiểm, không mong một substep tạo sóng lớn.
