# Viết vòng lặp tô kín tam giác

## Vấn đề cần giải quyết

Ta đã có bounds và phép kiểm một sample. Lần đầu tô kín tam giác chỉ cần bọc coverage trong hai vòng for. Điều cần giữ rõ là: tìm pixel, quyết định coverage, rồi mới chọn màu và ghi framebuffer.

## Hiểu ý tưởng trước khi viết code

RasterStats tách candidateCount (mọi ô trong bounds), testedCount (số mẫu đã xét) và coveredCount (số callback thực sự được gọi). Duyệt y ngoài, x trong khớp row-major framebuffer. Candidate limit cho phép dừng đúng một bước, thay vì viết một thuật toán riêng cho animation.

Callback là một hàm được truyền vào rasterizer. Rasterizer gọi shadePixel(x,y,weights) khi inside=true; nó không cần biết SDL, RGBA hay cách lưu mảng.

### Bước 1 — Đọc kết quả của vòng raster

RasterStats đã có trong Starter:

```cpp title="include/lab.hpp — ba count khác nhau"
struct RasterStats {
    IntRect bounds{};
    std::size_t candidateCount{};
    std::size_t testedCount{};
    std::size_t coveredCount{};
    bool degenerate{};
};
```

### Bước 2 — Thêm vòng lặp đầy đủ

Thêm template này vào cuối lab.hpp, sau sampleTriangle. template cho phép C++ nhận lambda callback mà chưa gắn nó với một kiểu framebuffer cụ thể:

```cpp title="include/lab.hpp — coverage trước shading, dừng đúng budget"
template <typename ShadePixel>
RasterStats rasterizeTriangle(Triangle2 triangle, int width, int height, FillRule rule, std::size_t candidateLimit, ShadePixel shadePixel) {
    RasterStats stats{};
    stats.bounds = triangleBounds(triangle, width, height);
    stats.candidateCount = candidatePixelCount(stats.bounds);
    stats.degenerate = classifyWinding(triangle) == Winding::Degenerate;
    if (stats.degenerate || stats.candidateCount == 0) {
        return stats;
    }
    const std::size_t safeLimit = std::min(candidateLimit, stats.candidateCount);
    for (int y = stats.bounds.minY; y <= stats.bounds.maxY; ++y) {
        for (int x = stats.bounds.minX; x <= stats.bounds.maxX; ++x) {
            if (stats.testedCount >= safeLimit) {
                return stats;
            }
            const CoverageSample sample = sampleTriangle(triangle, pixelCenter(x, y), rule);
            ++stats.testedCount;
            if (!sample.inside) {
                continue;
            }
            ++stats.coveredCount;
            shadePixel(x, y, sample.barycentric);
        }
    }
    return stats;
}
```

safeLimit không vượt candidateCount. Degenerate trả ngay, tested tăng đúng một lần cho sample; covered tăng ngay trước callback. Vòng lặp chỉ chạy trong bounds đã clamp.

Một số test cần tô hết tam giác mà không truyền candidateLimit. Thêm overload dưới **ngay sau hàm vừa viết**, vẫn trong namespace lab. Đây là hàm cùng tên với danh sách tham số ngắn hơn; nó gọi lại đúng vòng raster ở trên, không tạo một thuật toán thứ hai:

```cpp title="include/lab.hpp — dùng cùng rasterizer khi không cần dừng từng bước"
template <typename ShadePixel>
RasterStats rasterizeTriangle(Triangle2 triangle, int width, int height, FillRule rule, ShadePixel shadePixel) {
    return rasterizeTriangle(triangle, width, height, rule, std::numeric_limits<std::size_t>::max(), shadePixel);
}
```

Giá trị max của size_t đóng vai trò “không giới hạn”; safeLimit vẫn chặn số lượt xét ở candidateCount. Không cần cấp phát một buffer lớn tương ứng với giá trị này.

Trong renderScene, sau sampleTriangle và trước if(scene.debug), thêm block sau. coverage đã được cấp phát một lần trong main và truyền vào renderScene; nó được clear ở đầu lần vẽ, không cấp phát lại trong từng callback:

```cpp title="include/view.hpp — lambda ghi đúng pixel được phủ"
result.primary = rasterizeTriangle(triangle, Framebuffer::width, height, rule, scene.candidateLimit, shade);
```

### Bước 4 — Quét từng candidate bằng cùng thuật toán

Trong handleKey, sau phần di chuyển vertex, thêm hai nhánh Space/N:

```cpp title="include/controls.hpp — pause không phụ thuộc key repeat"
if (!repeat && key == SDLK_SPACE) {
    scene.paused = !scene.paused;
    if (!scene.paused) {
        scene.candidateLimit = 0;
    }
}
if (!repeat && key == SDLK_N && scene.paused) {
    if (scene.candidateLimit == kAllCandidates) {
        scene.candidateLimit = 0;
    }
    scene.candidateLimit = std::min(std::size_t(1760000), scene.candidateLimit + 1);
}
```

Trong main, sau SDL_PollEvent và trước smoke/render, thêm:

```cpp title="src/main.cpp — tăng budget khi quét"
if (!scene.paused && scene.candidateLimit < 1760000) {
    scene.candidateLimit = std::min(std::size_t(1760000), scene.candidateLimit + 4096);
    dirty = true;
}
```

Sau lời gọi renderScene, thêm điều kiện kết thúc bên dưới. Không tăng một con trỏ mẫu riêng ở ngoài rasterizer:

```cpp title="src/main.cpp — dừng khi đã xét hết candidate"
if (!scene.paused && scene.candidateLimit >= stats.primary.candidateCount + stats.secondary.candidateCount) {
    scene.paused = true;
}
```

## Ghép các phần lại

Build Starter: tam giác được tô xanh. Space bắt đầu quét, Space lần nữa dừng tại chỗ; N tiến một candidate khi paused. Nếu ảnh đã hoàn chỉnh, N bắt đầu từ candidate đầu. Thay geometry sẽ reset scan về bản vẽ đầy đủ để bạn không nhầm lỗi fill với một lượt quét chưa xong.

## Thử làm sai để hiểu đúng

1. Gọi shadePixel trước if(!sample.inside). Cả bounds bị tô; chuyển callback về sau coverage.

2. Tăng coveredCount cho mọi sample. Count không còn bằng số callback dù hình có thể giống; kiểm cả dữ liệu lẫn ảnh.

3. Bỏ giới hạn x/y và quét cả framebuffer. Hình có thể đúng nhưng tested không còn khớp bounds; trả vòng lặp về đúng vùng.

## Tự kiểm tra kết quả

- Limit=0 không test hoặc tô pixel nào.
- coveredCount bằng số callback; testedCount không vượt safeLimit.
- Không quét cả framebuffer khi bounds nhỏ.
- Một sample ở tâm được tạo cho mỗi candidate và đi qua cùng sampleTriangle.
