# Edge function và chiều đi quanh tam giác

## Vấn đề cần giải quyết

Một điểm nằm trong bounding box chưa chắc nằm trong tam giác. Ta cần biết điểm đang ở phía nào của từng cạnh. Edge function giải quyết việc đó bằng phép nhân và trừ; trước hết phải chốt dấu.

## Hiểu ý tưởng trước khi viết code

Với cạnh A→B và sample P:

$$E_{AB}(P)=(B_x-A_x)(P_y-A_y)-(B_y-A_y)(P_x-A_x).$$

E=0 nghĩa là P nằm trên đường thẳng AB, nhưng chưa chắc nằm trên đoạn AB. Khi thay P bằng C, kết quả là hai lần diện tích có dấu của tam giác ABC, gọi là signed double area. Trên màn hình, Y tăng xuống dưới nên thứ tự A→B→C cho area dương sẽ trông như đi thuận chiều kim đồng hồ. Ta dùng tên Positive/Negative theo dấu của số, tránh nhầm với hệ tọa độ Y hướng lên trong sách toán.

A=(0,0), B=(4,0), C=(0,4) cho area=16. Đổi B/C cho −16; đây là đáp án tính tay, không lấy từ một helper khác.

### Bước 1 — Viết cross product rõ hai vector

Thêm các hàm sau vào lab.hpp, sau phần bounds:

```cpp title="include/lab.hpp — AB nhân chéo AP"
inline double orient2D(Vec2 a, Vec2 b, Vec2 point) {
    const Vec2 edge{b.x - a.x, b.y - a.y};
    const Vec2 offset{point.x - a.x, point.y - a.y};
    return edge.x * offset.y - edge.y * offset.x;
}
```

```cpp title="include/lab.hpp — dùng cùng quy ước cho area"
inline double signedDoubleArea(const Triangle2& triangle) {
    return orient2D(triangle.a, triangle.b, triangle.c);
}
```

### Bước 2 — Phân loại trước khi chia

Winding là enum đã có trong Starter. classifyWinding từ chối dữ liệu không hữu hạn và area gần 0:

```cpp title="include/lab.hpp — positive, negative và degenerate"
inline Winding classifyWinding(const Triangle2& triangle, double epsilon = 1e-9) {
    const double area = signedDoubleArea(triangle);
    if (!finite(triangle) || !std::isfinite(area)) {
        return Winding::Degenerate;
    }
    if (area > epsilon) {
        return Winding::Positive;
    }
    if (area < -epsilon) {
        return Winding::Negative;
    }
    return Winding::Degenerate;
}
```

### Bước 3 — Chuẩn hóa bản sao, không sửa geometry gốc

```cpp title="include/lab.hpp — swap B/C trong bản sao"
inline Triangle2 normalizePositiveWinding(Triangle2 triangle) {
    if (classifyWinding(triangle) == Winding::Negative) {
        std::swap(triangle.b, triangle.c);
    }
    return triangle;
}
```

Trong renderScene, sau const int height, thêm các phép đo dưới; HUD đọc trực tiếp result.area và ba edge này:

```cpp title="include/view.hpp — số đo của sample do người học chọn"
result.area = signedDoubleArea(triangle);
result.sample.position = scene.sample;
result.sample.edgeAB = orient2D(triangle.a, triangle.b, scene.sample);
result.sample.edgeBC = orient2D(triangle.b, triangle.c, scene.sample);
result.sample.edgeCA = orient2D(triangle.c, triangle.a, scene.sample);
```

## Thử làm sai để hiểu đúng

1. Đổi AB×AP thành AP×AB. Area +16 thành −16; khôi phục để giữ quy ước đã công bố.

2. Dùng giá trị tuyệt đối cho cả ba edge. Bạn sẽ không còn biết sample ở phía nào; không lấy abs trước coverage.

3. Đổi B/C ngay trong Scene thay vì bản sao. Thuộc tính đi kèm đỉnh có thể bị tách khỏi geometry; giữ dữ liệu gốc và chuẩn hóa cục bộ.
