# Dựng khung tam giác trong screen space

## Vấn đề cần giải quyết

Ở Project 15, ta đã đưa các đỉnh của mô hình đến screen space. Từ ba đỉnh đó, làm thế nào để vẽ được cả bề mặt tam giác? Trước khi tô các pixel bên trong, ta cần nhìn thấy tam giác và kéo được từng đỉnh. Bài này dựng bộ khung tương tác ấy; sau khi hoàn thiện thuật toán tô, ta sẽ dùng nó để vẽ tam giác trong cảnh 3D ở bài cuối.

## Hiểu ý tưởng trước khi viết code

Rasterizer nhận Triangle2 gồm ba Vec2. Trong hệ tọa độ này, X tăng sang phải, Y tăng xuống dưới và khoảng cách được tính bằng pixel. Tọa độ đỉnh vẫn là số thực; ta chỉ làm tròn khi vẽ cạnh bằng Bresenham. Khung vẽ giữ kích thước 1100×800, trong đó vùng tam giác chiếm 1100×600 khi bật HUD. Khi thay đổi kích thước cửa sổ hoặc dùng màn hình HiDPI, SDL co giãn ảnh theo kiểu letterbox; dữ liệu tam giác và kích thước framebuffer không đổi.

Starter đã có các kiểu dữ liệu trong lab.hpp, Scene/DragState trong scene.hpp, framebuffer/Bresenham, SDL init/upload/present và projector từ P11 trong space.hpp. Các kiểu bên dưới là phần **đọc lại**, không phải yêu cầu khai báo thêm.

### Bước 1 — Biết dữ liệu nào đang được sửa

```cpp title="include/lab.hpp — đọc ba vertex đã có"
struct Triangle2 {
    Vec2 a{};
    Vec2 b{};
    Vec2 c{};
};
```

Thêm vertexAt trong namespace lab của lab.hpp để mọi nơi đọc cùng thứ tự A/B/C:

```cpp title="include/lab.hpp — chọn đúng một vertex"
inline Vec2 vertexAt(const Triangle2& triangle, int index) {
    if (index == 0) {
        return triangle.a;
    }
    if (index == 1) {
        return triangle.b;
    }
    return triangle.c;
}
```

### Bước 2 — Vẽ ảnh trước khi nhận chuột

screenLine đã có trong Starter: nó clip rồi mới làm tròn và gọi drawLine. Thêm drawOutline vào view.hpp trước renderScene, sau đó thay renderScene bằng bản của bài này:

```cpp title="include/view.hpp — ba cạnh AB, BC, CA"
inline void drawOutline(Framebuffer& image, const Triangle2& triangle, int height, std::uint32_t color) {
    screenLine(image, triangle.a, triangle.b, height, color);
    screenLine(image, triangle.b, triangle.c, height, color);
    screenLine(image, triangle.c, triangle.a, height, color);
}
```

```cpp title="include/view.hpp — ảnh đầu tiên và handle"
inline FrameStats renderScene(Framebuffer& image, std::vector<std::uint8_t>& coverage, const Scene& scene) {
    image.clear(kBackground);
    std::fill(coverage.begin(), coverage.end(), std::uint8_t(0));
    FrameStats result;
    const auto projected = screenTriangle(scene);
    if (!projected) {
        result.rejected = true;
        return result;
    }
    const Triangle2 triangle = *projected;
    const int height = viewportHeight(scene);
    if (scene.debug) {
        drawOutline(image, triangle, height, kWhite);
        for (int i = 0; i < 3; ++i) {
            const Vec2 point = vertexAt(triangle, i);
            if (point.x >= 0.0 && point.x < Framebuffer::width && point.y >= 0.0 && point.y < height) {
                disc(image, static_cast<int>(std::lround(point.x)), static_cast<int>(std::lround(point.y)), 5, kMarker);
            }
        }
    }
    return result;
}
```

### Bước 3 — Tách việc chọn và sửa đỉnh

Thêm ba hàm dưới trong scene.hpp. beginDrag chỉ nhận khi gần một handle, lưu khoảng lệch chỗ nắm nên click không làm tâm nhảy. updateDrag sửa đúng đỉnh đã chọn. Nhánh worldMode dùng projector/inverse đã có từ P11; bài 8 sẽ dùng nó, hiện tại worldMode=false.

```cpp title="include/scene.hpp — tham chiếu tới đỉnh cần sửa"
inline Vec2& editableVertex(Triangle2& triangle, int index) {
    if (index == 0) {
        return triangle.a;
    }
    if (index == 1) {
        return triangle.b;
    }
    return triangle.c;
}
```

```cpp title="include/scene.hpp — hit-test và grab offset"
inline bool beginDrag(const Scene& scene, Vec2 mouse, DragState& drag) {
    const auto triangle = screenTriangle(scene);
    if (!triangle || !finite(mouse)) {
        return false;
    }
    for (int i = 0; i < 3; ++i) {
        const Vec2 point = vertexAt(*triangle, i);
        if (std::hypot(mouse.x - point.x, mouse.y - point.y) <= 18.0) {
            drag.index = i;
            drag.offset = {mouse.x - point.x, mouse.y - point.y};
            drag.depth = scene.world[static_cast<std::size_t>(i)].z - scene.camera.position.z;
            return true;
        }
    }
    return false;
}
```

```cpp title="include/scene.hpp — ghi dữ liệu thay vì vẽ đè pixel"
inline void updateDrag(Scene& scene, const DragState& drag, Vec2 mouse) {
    if (drag.index < 0 || drag.index > 2 || !finite(mouse)) {
        return;
    }
    const Vec2 target{mouse.x - drag.offset.x, mouse.y - drag.offset.y};
    if (scene.worldMode) {
        const auto point = worldAtScreen(target, drag.depth, scene.camera, 1100, viewportHeight(scene));
        if (point) {
            scene.world[static_cast<std::size_t>(drag.index)] = {std::clamp(point->x, -6.0, 6.0), std::clamp(point->y, -4.0, 4.0), point->z};
        }
    } else {
        editableVertex(scene.triangle, drag.index) = {std::clamp(target.x, -200.0, 1300.0), std::clamp(target.y, -200.0, 1000.0)};
        scene.shared = false;
    }
    scene.selected = drag.index;
    resetScan(scene);
}
```

### Bước 4 — Nối SDL event với các hàm vừa viết

Trong main.cpp, trước while (running), thêm state kéo và lambda hủy:

```cpp title="src/main.cpp — state sống qua các frame"
lab::DragState drag;
SDL_MouseID owner{};
const auto cancelDrag = [&]() {
    drag = {};
    SDL_CaptureMouse(false);
};
```

Bên trong SDL_PollEvent, sau nhánh key-down, thêm toàn bộ khối sau. SDL_ConvertEventToRenderCoordinates chạy đúng một lần để mouse dùng cùng board với framebuffer:

```cpp title="src/main.cpp — down, motion và mẫu thả cuối"
const bool mouseEvent = event.type == SDL_EVENT_MOUSE_BUTTON_DOWN || event.type == SDL_EVENT_MOUSE_MOTION || event.type == SDL_EVENT_MOUSE_BUTTON_UP;
if (mouseEvent && !SDL_ConvertEventToRenderCoordinates(renderer, &event)) {
    failed = true;
    running = false;
    break;
}
if (event.type == SDL_EVENT_MOUSE_BUTTON_DOWN && event.button.button == SDL_BUTTON_LEFT && drag.index < 0) {
    const lab::Vec2 mouse{event.button.x, event.button.y};
    if (mouse.x >= 0.0 && mouse.x < 1100.0 && mouse.y >= 0.0 && mouse.y < lab::viewportHeight(scene)) {
        if (lab::beginDrag(scene, mouse, drag)) {
            owner = event.button.which;
            scene.selected = drag.index;
            scene.paused = true;
            if (!SDL_CaptureMouse(true)) {
                cancelDrag();
            }
        } else {
            scene.sample = mouse;
        }
        dirty = true;
    }
}
if (event.type == SDL_EVENT_MOUSE_MOTION && drag.index >= 0 && event.motion.which == owner) {
    if ((event.motion.state & SDL_BUTTON_LMASK) == 0) {
        cancelDrag();
    } else {
        lab::updateDrag(scene, drag, {event.motion.x, event.motion.y});
        dirty = true;
    }
}
if (event.type == SDL_EVENT_MOUSE_BUTTON_UP && event.button.button == SDL_BUTTON_LEFT && drag.index >= 0 && event.button.which == owner) {
    lab::updateDrag(scene, drag, {event.button.x, event.button.y});
    cancelDrag();
    dirty = true;
}
```

Gọi cancelDrag() trước handleKey, trong nhánh focus/hidden/minimize/resize và trước SDL_DestroyTexture khi thoát. Thay handleKey rỗng trong controls.hpp bằng:

```cpp title="include/controls.hpp — keyboard chọn và di chuyển vertex"
inline void handleKey(Scene& scene, SDL_Keycode key, bool repeat) {
    if (!repeat && (key == SDLK_R || (key >= SDLK_1 && key <= SDLK_5))) {
        int preset = 1;
        if (key != SDLK_R) {
            preset = static_cast<int>(key - SDLK_0);
        }
        applyPreset(scene, preset);
    }
    if (!repeat && key == SDLK_TAB) {
        scene.selected = (scene.selected + 1) % 3;
    }

    Vec2 delta{};
    if (key == SDLK_LEFT) {
        delta.x = -1.0;
    }
    if (key == SDLK_RIGHT) {
        delta.x = 1.0;
    }
    if (key == SDLK_UP) {
        delta.y = -1.0;
    }
    if (key == SDLK_DOWN) {
        delta.y = 1.0;
    }
    if (delta.x != 0.0 || delta.y != 0.0) {
        if (scene.worldMode) {
            Vec3& point = scene.world[static_cast<std::size_t>(scene.selected)];
            point.x = std::clamp(point.x + delta.x * 0.1, -6.0, 6.0);
            point.y = std::clamp(point.y - delta.y * 0.1, -4.0, 4.0);
        } else {
            Vec2& point = editableVertex(scene.triangle, scene.selected);
            point.x = std::clamp(point.x + delta.x, -200.0, 1300.0);
            point.y = std::clamp(point.y + delta.y, -200.0, 1000.0);
            scene.shared = false;
        }
        resetScan(scene);
    }
    (void)scene;
    (void)key;
    (void)repeat;
}
```

## Ghép các phần lại

main.cpp đã gọi renderScene trước SDL_UpdateTexture, rồi presentFramebuffer trình bày ảnh. Giữ nguyên đường này; không tạo thêm main hoặc vòng lặp. Build Starter: kéo từng handle, dùng Tab chọn vertex và mũi tên dịch một pixel. Nhấn R về mặc định. Mouse owner khác/nút phải không được giành thao tác; thả chuột nhận mẫu cuối trước khi release capture.

## Thử làm sai để hiểu đúng

1. Nối AB, BC rồi lại AB. Cạnh CA biến mất; khôi phục ba cạnh đúng thứ tự để loại lỗi topology trước khi viết fill.

2. Bỏ grabOffset trong updateDrag. Nhấn lệch tâm làm đỉnh giật tới chuột; khôi phục và kiểm down không thay geometry.

3. Không nhận mouse-button-up cuối. Kéo nhanh rồi thả có thể bỏ vị trí cuối; dùng updateDrag trước cancelDrag.

## Tự kiểm tra kết quả

- Starter vẽ outline và ba handle, chưa có fill.
- Triangle2 giữ số thực; drawLine chỉ nhận tọa độ đã clip.
- Kéo giữ offset, chỉ đúng mouse owner được sửa đỉnh.
- Reset/blur/resize/keyboard kết thúc capture; resize không tự tạo một triangle khác.
