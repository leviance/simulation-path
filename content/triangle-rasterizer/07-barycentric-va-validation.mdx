# Nội suy màu và kiểm chứng rasterizer

## Vấn đề cần giải quyết

Coverage đã chọn được pixel; bây giờ ta dùng ba tỉ lệ diện tích để tìm màu. Mục tiêu không phải một gradient có vẻ mượt, mà là màu gắn đúng với từng vertex, kể cả khi winding bị đảo.

## Hiểu ý tưởng trước khi viết code

Trên triangle chuẩn hóa:

$$w_A=E_{BC}/area,\quad w_B=E_{CA}/area,\quad w_C=E_{AB}/area,\quad w_A+w_B+w_C=1.$$

Trong sampleTriangle, ta có thể đã đổi B và C ở bản sao để xử lý winding. Vì màu vẫn gắn với các đỉnh ban đầu, ta phải đổi hai trọng số tương ứng về đúng thứ tự trước khi tính màu. Nếu bỏ bước này, tam giác vẫn được tô kín, tổng các trọng số vẫn bằng 1, nhưng màu của B và C lại bị tráo. Đây là lý do chỉ kiểm tổng bằng 1 chưa đủ để kết luận phép nội suy đúng.

RGB thuần đỏ/xanh lá/xanh dương biểu diễn ba weights. Tại vertex toán học B phải có weight B=1; không có nghĩa mọi pixel gần B đều là màu xanh thuần, vì ta lấy mẫu tại tâm pixel.

### Bước 2 — Chỉ lượng tử hóa khi ghi channel

Thêm các hàm dưới vào cuối lab.hpp. Color đã có từ Starter:

```cpp title="include/lab.hpp — finite, clamp rồi round"
inline std::uint8_t toByte(double value) {
    if (!std::isfinite(value)) {
        return 0;
    }
    return static_cast<std::uint8_t>(std::lround(std::clamp(value, 0.0, 255.0)));
}
```

```cpp title="include/lab.hpp — một bộ weights cho mọi channel"
inline Color interpolateColor(Color colorA, Color colorB, Color colorC, Barycentric weights) {
    return {
        toByte(weights.a * colorA.red + weights.b * colorB.red + weights.c * colorC.red),
        toByte(weights.a * colorA.green + weights.b * colorB.green + weights.c * colorC.green),
        toByte(weights.a * colorA.blue + weights.b * colorB.blue + weights.c * colorC.blue),
        toByte(weights.a * colorA.alpha + weights.b * colorB.alpha + weights.c * colorC.alpha),
    };
}
```

```cpp title="include/lab.hpp — đo sai số tổng"
inline double barycentricSumError(Barycentric weights) {
    return std::abs(weights.a + weights.b + weights.c - 1.0);
}
```

```cpp title="include/lab.hpp — helper kiểm owner tại một sample"
inline int sharedEdgeCoverageCount(Triangle2 first, Triangle2 second, Vec2 samplePosition, FillRule rule) {
    int count = 0;
    if (sampleTriangle(first, samplePosition, rule).inside) {
        ++count;
    }
    if (sampleTriangle(second, samplePosition, rule).inside) {
        ++count;
    }
    return count;
}
```

### Bước 3 — Dùng màu trong callback đang có

Thêm packColor trước renderScene trong view.hpp, sau đó thay lambda shade cũ bằng lambda mới. Không thay vòng raster:

```cpp title="include/view.hpp — đóng gói RGBA8888"
inline std::uint32_t packColor(Color color) {
    return (std::uint32_t(color.red) << 24U) | (std::uint32_t(color.green) << 16U) | (std::uint32_t(color.blue) << 8U) | color.alpha;
}
```

```cpp title="include/view.hpp — callback RGB của ba vertex"
const auto shade = [&](int x, int y, Barycentric weights) {
    const std::size_t index = static_cast<std::size_t>(y) * Framebuffer::width + static_cast<std::size_t>(x);
    ++coverage[index];
    std::uint32_t color = kShape;
    if (scene.barycentricColor) {
        color = packColor(interpolateColor(scene.colors[0], scene.colors[1], scene.colors[2], weights));
    }
    image.putPixel(x, y, color);
};
```

Trong controls.hpp thêm phím C để so màu đơn với nội suy:

```cpp title="include/controls.hpp — shading không thay coverage"
if (!repeat && key == SDLK_C) {
```

## Ghép các phần lại

Build Starter. C chỉ đổi shading: geometry, bounds và coveredCount phải giữ nguyên. Preset 2 đảo cả vị trí B/C lẫn thuộc tính đi kèm nên gradient vật lý vẫn như cũ. Ở Canvas, preset đảo thứ tự giữ quy ước màu gắn theo tên input; chú ý phân biệt đổi tên vertex với làm sai weights.

tests/tests.cpp có oracle cho vertex B/C của input negative, hai đường chéo quad, subpixel shift và màu (0.25,0.25,0.5) → RGB (64,64,128). Bài 8 sẽ nối 3D và chỉ cách chạy toàn tests trên Starter của bạn.

## Thử làm sai để hiểu đúng

1. Bỏ đổi weights B/C sau normalize. Coverage vẫn đúng và tổng vẫn bằng 1, nhưng test weight B tại input.b thất bại.

2. Round từng weight trước nội suy. Gradient thành mảng; giữ double tới toByte.

3. Chỉ kiểm tổng=1. Dùng weights (A,C,B) vẫn qua test tổng; thêm oracle ở từng vertex và test màu cụ thể.

## Tự kiểm tra kết quả

- Tại từng vertex gốc, weight của chính nó bằng 1 cho cả hai winding.
- Color (0.25,0.25,0.5) cho (64,64,128) khi ba màu gốc là RGB thuần.
- C không đổi coverage và candidate count.
- Đổi geometry và thuộc tính cùng nhau không làm gradient đổi nhầm.
- Degenerate vẫn không chia hoặc shade.
