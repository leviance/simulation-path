# Khoanh vùng pixel bằng bounding box

## Vấn đề cần giải quyết

Quét toàn framebuffer cho một tam giác nhỏ sẽ làm hàng trăm nghìn phép thử vô ích. Ta khoanh vùng trước, nhưng cần phân biệt hình chữ nhật chứa candidate với tập pixel thực sự thuộc tam giác.

## Hiểu ý tưởng trước khi viết code

Với minX=2.2 và maxX=20.2, ta chọn chỉ số từ floor(2.2)=2 tới ceil(20.2)−1=20. Đây là bounds **bảo thủ** của các ô giao với AABB, không phải tập tâm pixel tối thiểu: tâm 20.5 vẫn được thử rồi coverage có thể loại.

$$minX=\lfloor \min(A_x,B_x,C_x)\rfloor,\qquad maxX=\lceil\max(A_x,B_x,C_x)\rceil-1.$$

IntRect dùng hai đầu inclusive. Phải kiểm triangle nằm hẳn ngoài viewport trước clamp, nếu không hai min/max ngoài trái có thể cùng bị ép thành 0 và tạo một cột candidate giả.

### Bước 1 — Đọc quy ước rectangle rỗng

IntRect đã có trong Starter. Thêm isEmpty vào lab.hpp:

```cpp title="include/lab.hpp — rectangle rỗng khi max nhỏ hơn min"
inline bool isEmpty(IntRect bounds) {
    return bounds.maxX < bounds.minX || bounds.maxY < bounds.minY;
}
```

### Bước 2 — Clamp trước khi đổi sang int

Thêm triangleBounds sau isEmpty. Dữ liệu NaN/Inf trả rỗng; floor/ceil còn là double khi clamp nên không cast số ngoài miền int:

```cpp title="include/lab.hpp — bounds an toàn, kể cả triangle nằm ngoài"
inline IntRect triangleBounds(const Triangle2& triangle, int width, int height) {
    if (width <= 0 || height <= 0 || !finite(triangle)) {
        return {};
    }
    const double minimumX = std::min({triangle.a.x, triangle.b.x, triangle.c.x});
    const double minimumY = std::min({triangle.a.y, triangle.b.y, triangle.c.y});
    const double maximumX = std::max({triangle.a.x, triangle.b.x, triangle.c.x});
    const double maximumY = std::max({triangle.a.y, triangle.b.y, triangle.c.y});
    // Phải kiểm rời nhau trước clamp; triangle ngoài màn hình có bounds rỗng.
    if (maximumX < 0.0 || maximumY < 0.0 || minimumX >= width || minimumY >= height) {
        return {};
    }
    IntRect bounds{};
    // Clamp double trước int: không cast NaN/Inf hoặc số vượt miền int.
    bounds.minX = static_cast<int>(std::clamp(std::floor(minimumX), 0.0, double(width - 1)));
    bounds.minY = static_cast<int>(std::clamp(std::floor(minimumY), 0.0, double(height - 1)));
    bounds.maxX = static_cast<int>(std::clamp(std::ceil(maximumX) - 1.0, -1.0, double(width - 1)));
    bounds.maxY = static_cast<int>(std::clamp(std::ceil(maximumY) - 1.0, -1.0, double(height - 1)));
    return bounds;
}
```

### Bước 3 — Đếm candidate, chưa gọi chúng là covered

```cpp title="include/lab.hpp — đếm hàng nhân cột"
inline std::size_t candidatePixelCount(IntRect bounds) {
    if (isEmpty(bounds)) {
        return 0;
    }
    return static_cast<std::size_t>(bounds.maxX - bounds.minX + 1) * static_cast<std::size_t>(bounds.maxY - bounds.minY + 1);
}
```

Trong renderScene, sau const int height và trước nhánh if (scene.debug), thêm:

```cpp title="include/view.hpp — nối bounds vào kết quả render"
result.primary.bounds = triangleBounds(triangle, Framebuffer::width, height);
result.primary.candidateCount = candidatePixelCount(result.primary.bounds);
```

## Ghép các phần lại

Build Starter. HUD nhận FrameStats từ renderScene nên candidate count xuất phát từ bounds thật. Dùng preset 4 để triangle cắt mép. Một triangle nằm hoàn toàn ngoài phải có bounds rỗng; không được dùng clamp để kéo geometry trở lại màn hình.

## Thử làm sai để hiểu đúng

1. Bỏ kiểm rời nhau trước clamp rồi đưa cả ba đỉnh ra ngoài trái. Bounds giả xuất hiện ở cột 0; khôi phục kiểm sớm.

2. Cast floor(minimumX) sang int trước clamp rồi dùng số rất lớn hoặc NaN trong test. Đây có thể là chuyển đổi không hợp lệ; giữ kiểm finite và clamp double.

3. Đếm max−min mà quên +1. Rectangle [2,3]..[5,7] sẽ báo 12 thay vì 20; kiểm hai đầu inclusive.

## Tự kiểm tra kết quả

- [2,3]..[5,7] có 20 candidate.
- Triangle ngoài hoàn toàn trả 0 candidate; dữ liệu invalid không được cast sang int.
- Triangle cắt mép có bounds trong [0,width−1]×[0,height−1].
- Bounding box chưa quyết định pixel nào sẽ được tô.

## Bài tập mở rộng

Đo tỉ lệ candidate/(width×height) cho tam giác lớn và nhỏ. Dùng count, đừng kết luận từ một lần đo thời gian có SDL present.
