# Để cạnh chung chỉ có một chủ

## Vấn đề cần giải quyết

Hai tam giác ghép thành quad có chung một đường chéo. Nếu mọi cạnh đều dùng >=0, mẫu nằm trên đường chéo được nhận hai lần. Đổi hết sang >0 lại tạo khe hở. Ta cần giao quyền sở hữu biên, không nới hoặc thu cả tam giác.

## Hiểu ý tưởng trước khi viết code

Với winding dương và Y-down, cạnh đi lên hoặc cạnh ngang đi sang phải là top-left. Edge dương được nhận, edge âm bị loại, vùng gần zero chỉ được nhận khi cạnh có nhãn top-left.

Hai triangle đi qua cạnh chung theo hai hướng ngược nhau, nên chỉ một phía nhận sample trên cạnh. Quy tắc đúng phải giữ quad kín khi đổi đường chéo hoặc dịch subpixel, không chỉ đúng một pixel ta tình cờ chọn.

### Bước 1 — Nhận diện hướng của cạnh

Đặt hai helper dưới trong lab.hpp, trước sampleTriangle:

```cpp title="include/lab.hpp — top-left trong quy ước Y-down"
inline bool isTopLeftEdge(Vec2 a, Vec2 b, double epsilon = 1e-9) {
    const double deltaX = b.x - a.x;
    const double deltaY = b.y - a.y;
    const bool goesUp = deltaY < -epsilon;
    const bool horizontalTop = std::abs(deltaY) <= epsilon && deltaX > epsilon;
    return goesUp || horizontalTop;
}
```

### Bước 2 — Xử lý rõ vùng edge bằng zero

```cpp title="include/lab.hpp — inclusive và top-left"
inline bool acceptsEdge(double edgeValue, bool topLeft, FillRule rule, double epsilon = 1e-9) {
    if (edgeValue > epsilon) {
        return true;
    }
    if (edgeValue < -epsilon) {
        return false;
    }
    if (rule == FillRule::Inclusive) {
        return true;
    }
    return topLeft;
}
```

### Bước 3 — Thay ba điều kiện inclusive

Trong sampleTriangle, thay (void)rule và sample.inside cũ bằng:

```cpp title="include/lab.hpp — ba cạnh dùng cùng rule"
const bool insideAB = acceptsEdge(sample.edgeAB, isTopLeftEdge(triangle.a, triangle.b), rule);
const bool insideBC = acceptsEdge(sample.edgeBC, isTopLeftEdge(triangle.b, triangle.c), rule);
const bool insideCA = acceptsEdge(sample.edgeCA, isTopLeftEdge(triangle.c, triangle.a), rule);
sample.inside = insideAB && insideBC && insideCA;
```

Trong renderScene, ngay sau FillRule rule=Inclusive thêm rule=scene.rule. Sau lần rasterize triangle chính, thêm nhánh dưới. Scene.second và preset 5 đã có từ Starter; lúc này chúng mới tham gia raster:

```cpp title="include/view.hpp — hai triangle dùng chung một budget"
if (scene.shared && !scene.worldMode) {
    // Một budget chung cho cả hai triangle; triangle thứ hai không chạy lén khi pause.
    const std::size_t remaining = scene.candidateLimit - result.primary.testedCount;
    result.secondary = rasterizeTriangle(scene.second, Framebuffer::width, height, rule, remaining, [&](int x, int y, Barycentric) {
        const std::size_t index = static_cast<std::size_t>(y) * Framebuffer::width + static_cast<std::size_t>(x);
        ++coverage[index];
        std::uint32_t color = kGhost;
        if (coverage[index] > 1) {
            ++result.overlap;
            color = kAxisX;
        }
        image.putPixel(x, y, color);
    });
}
```

### Bước 4 — Cho người học chọn rule

Thêm nhánh T vào handleKey:

```cpp title="include/controls.hpp — đổi rule rồi tính lại coverage"
if (!repeat && key == SDLK_T) {
    if (scene.rule == FillRule::TopLeft) {
        scene.rule = FillRule::Inclusive;
    } else {
        scene.rule = FillRule::TopLeft;
    }
    resetScan(scene);
}
```

## Ghép các phần lại

Build Starter, nhấn 5 để mở quad ở bàn 2D. T chuyển top-left/inclusive. Bộ đếm coverage tăng trong callback; sample có count>1 được vẽ đỏ, không suy overlap bằng màu cuối cùng. Limit dùng chung: triangle thứ hai chỉ được xét phần budget còn lại, không tô lén toàn bộ khi đang pause.

Trong Canvas, chọn preset Hai tam giác chung cạnh và so hai rule. Các cạnh debug có thể che một vài pixel; hãy nhìn cả overlap và coverage buffer trong tests.

## Thử làm sai để hiểu đúng

1. Cho mọi edge zero là outside. Đường chéo có thể hở; khôi phục quyền sở hữu một phía.

2. Không chuẩn hóa winding trước khi xét top-left. Input âm không còn đi cùng quy ước hướng cạnh; trả normalize về trước phép thử.

3. Cho triangle thứ hai dùng limit vô hạn khi triangle đầu paused. Tested count không còn biểu diễn bước toàn scene; dùng remaining.

## Tự kiểm tra kết quả

- Inclusive có owner=2 tại sample đúng cạnh chung; top-left có owner=1.
- Quad không có crack hoặc overlap ở mọi tâm pixel bên trong.
- Hai đường chéo của cùng quad tạo cùng coverage buffer.
- Đảo winding và dịch quad 0.2 pixel vẫn giữ một owner.
- Cả hai triangle tuân cùng candidateLimit.
