# Lấy mẫu tại tâm pixel và quyết định coverage

## Vấn đề cần giải quyết

Biết một điểm nằm về phía nào của từng cạnh, ta có thể kiểm tra nó có nằm trong cả ba nửa mặt phẳng của tam giác hay không. Tuy nhiên, pixel là một ô vuông chứ không phải một điểm. Ta sẽ lấy tâm ô làm điểm đại diện để quyết định có tô pixel đó hay không — đây là phép kiểm tra coverage. C++, Canvas và tests đều phải lấy mẫu theo cùng quy ước.

## Hiểu ý tưởng trước khi viết code

Pixel (x,y) lấy mẫu tại tâm (x+0.5,y+0.5). Sau khi chuẩn hóa winding dương:

$$inside=E_{AB}(P)\ge0\ \land\ E_{BC}(P)\ge0\ \land\ E_{CA}(P)\ge0.$$

Bài này dùng biên inclusive với epsilon nhỏ. Bài 6 sẽ giải quyết quyền sở hữu cạnh chung. CoverageSample cũng giữ ba tỉ lệ edge/area; bài 7 sẽ dùng chúng để nội suy màu. Chúng phải thuộc A/B/C **của input gốc**, kể cả khi bản sao đã swap B/C.

### Bước 1 — Tạo sample tại tâm pixel

```cpp title="include/lab.hpp — nửa pixel là một quy ước chung"
inline Vec2 pixelCenter(int x, int y) {
    return {double(x) + 0.5, double(y) + 0.5};
}
```

### Bước 2 — Viết toàn bộ phép thử một sample

CoverageSample, Barycentric và FillRule đã có trong Starter; không khai báo lại. Thêm sampleTriangle sau pixelCenter:

```cpp title="include/lab.hpp — guard, ba edge, weights và coverage"
inline CoverageSample sampleTriangle(Triangle2 triangle, Vec2 samplePosition, FillRule rule) {
    CoverageSample sample{};
    sample.position = samplePosition;
    if (!finite(samplePosition) || classifyWinding(triangle) == Winding::Degenerate) {
        return sample;
    }
    const bool reversed = classifyWinding(triangle) == Winding::Negative;
    triangle = normalizePositiveWinding(triangle);
    const double area = signedDoubleArea(triangle);
    sample.edgeAB = orient2D(triangle.a, triangle.b, samplePosition);
    sample.edgeBC = orient2D(triangle.b, triangle.c, samplePosition);
    sample.edgeCA = orient2D(triangle.c, triangle.a, samplePosition);
    if (!std::isfinite(sample.edgeAB) || !std::isfinite(sample.edgeBC) || !std::isfinite(sample.edgeCA)) {
        return sample;
    }
    sample.barycentric = {sample.edgeBC / area, sample.edgeCA / area, sample.edgeAB / area};
    // Edge dùng triangle chuẩn hóa; weights vẫn thuộc A/B/C của input gốc.
    if (reversed) {
        std::swap(sample.barycentric.b, sample.barycentric.c);
    }
    static_cast<void>(rule);
    sample.inside = sample.edgeAB >= -1e-9 && sample.edgeBC >= -1e-9 && sample.edgeCA >= -1e-9;
    return sample;
}
```

Hàm kiểm finite/degenerate trước chia. Ba edge lấy trên triangle chuẩn hóa; nếu đã đảo winding, chỉ đổi lại weights B/C để callback vẫn hiểu đúng thuộc tính gốc. (void)rule giữ interface cho bài 6, chưa giả rằng top-left đã hoạt động.

### Bước 3 — Đưa kết quả vào renderer

Sau các số đo edge ở bài 3, thêm dòng dưới; nó thay dữ liệu sample bằng phép kiểm tại tâm pixel:

```cpp title="include/view.hpp — pixel center được dùng thật"
result.sample = sampleTriangle(triangle, {std::floor(scene.sample.x) + 0.5, std::floor(scene.sample.y) + 0.5}, scene.rule);
```

## Ghép các phần lại

Build Starter, click gần một cạnh và đọc inside cùng ba edge trong HUD. Canvas cho đổi Corner/Center để nhìn sai khác nửa pixel; executable chính luôn dùng center. Không tô toàn triangle ở bài này: ta đang kiểm một sample trước khi bọc nó trong vòng lặp.

## Thử làm sai để hiểu đúng

1. Đổi && thành || trong sample.inside. Chỉ cần đúng phía một cạnh là sample được nhận, gần như cả bounds sẽ có vẻ inside; khôi phục phép giao.

2. Bỏ guard degenerate rồi thử preset 3. Area=0 không thể làm mẫu số; giữ early return.

3. Bỏ swap weights B/C khi reversed. Coverage vẫn có thể đúng, nhưng thuộc tính ở B/C bị đổi chỗ; ghi lại lỗi để so ở bài 7.

## Tự kiểm tra kết quả

- pixelCenter(1,1)=(1.5,1.5).
- Cả ba cạnh phải chấp nhận sample; một edge âm là đủ loại.
- Suy biến/invalid không chia cho area và không tô pixel.
- Weights của input negative vẫn cho B=1 tại chính input.b.
