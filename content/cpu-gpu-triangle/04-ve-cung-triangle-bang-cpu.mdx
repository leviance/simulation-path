# Vẽ lại tam giác bằng CPU

## Vấn đề cần giải quyết

Nửa phải đã vẽ được tam giác bằng GPU. Bây giờ ta đưa renderer CPU trở lại nửa trái để có một kết quả tham chiếu có thể kiểm tra từng pixel. Không cần ghép ZIP Project 16 bằng tay: phần nền của bài đó đã có trong gói này, và ta sẽ lần theo cách nối nó vào cửa sổ OpenGL.

Đầu vào vẫn là `kSourceTriangle` và `Transform2D`. CPU tự tính coverage và màu trong một mảng RGBA8; OpenGL chỉ giúp trình bày mảng pixel đã tính xong dưới dạng texture. Như vậy có hai đường rasterization độc lập, không phải cùng một tam giác GPU được vẽ hai lần.

## Hiểu ý tưởng trước khi viết code

CPU rasterizer lấy mẫu ở tâm pixel `(x + 0.5, y + 0.5)`, tính barycentric weights rồi ghi RGBA8. Texture presenter chỉ upload bằng `glTexSubImage2D` và vẽ một quad; nó không được quyết định pixel nào nằm trong tam giác.

Row 0 của framebuffer CPU là hàng trên cùng. Texture shader lật tọa độ V đúng một lần để trình bày ảnh ấy; không sửa tọa độ các đỉnh chỉ để bù cho ảnh bị lật.

## Viết code từng bước

### Bước 1 — Framebuffer top-left có storage rõ ràng

```cpp title="include/pipeline.hpp — resize CPU framebuffer"
bool resize(int nextWidth, int nextHeight) {
    // Check dimensions before multiplying. Failed resize preserves the old image.
    constexpr std::size_t maximumPixels = 4U * 1024U * 1024U;
    if (nextWidth <= 0 || nextHeight <= 0 || nextWidth > 4096 || nextHeight > 4096) {
        return false;
    }
    if (std::size_t(nextWidth) > maximumPixels / std::size_t(nextHeight)) {
        return false;
    }
    try {
        rgba.resize(std::size_t(nextWidth) * std::size_t(nextHeight) * 4U);
    } catch (const std::bad_alloc&) {
        return false;
    }
    width = nextWidth;
    height = nextHeight;
    return true;
}
```

Mỗi pixel có bốn byte RGBA. Row 0 là hàng trên cùng. resize trả false trước khi nhân kích thước không hợp lệ hoặc vượt 4M pixel; nếu cấp phát thất bại, ảnh cũ còn nguyên. Chỉ cập nhật width/height khi vector đã resize thành công.

`clear` và `putPixel` là hai thao tác duy nhất rasterizer cần biết về vùng nhớ. Cả hai đều đổi màu float `[0, 1]` sang byte `[0, 255]`; `putPixel` còn chặn tọa độ ngoài biên trước khi tính offset:

```cpp title="include/pipeline.hpp — clear và putPixel"
void clear(Color color) {
    const std::uint8_t red = std::uint8_t(std::lround(std::clamp(color.red, 0.0F, 1.0F) * 255.0F));
    const std::uint8_t green = std::uint8_t(std::lround(std::clamp(color.green, 0.0F, 1.0F) * 255.0F));
    const std::uint8_t blue = std::uint8_t(std::lround(std::clamp(color.blue, 0.0F, 1.0F) * 255.0F));
    for (std::size_t offset = 0; offset < rgba.size(); offset += 4U) {
        rgba[offset] = red;
        rgba[offset + 1U] = green;
        rgba[offset + 2U] = blue;
        rgba[offset + 3U] = 255U;
    }
}

void putPixel(int x, int y, Color color) {
    if (x < 0 || y < 0 || x >= width || y >= height) {
        return;
    }
    const std::size_t offset = (std::size_t(y) * std::size_t(width) + std::size_t(x)) * 4U;
    rgba[offset] = std::uint8_t(std::lround(std::clamp(color.red, 0.0F, 1.0F) * 255.0F));
    rgba[offset + 1U] = std::uint8_t(std::lround(std::clamp(color.green, 0.0F, 1.0F) * 255.0F));
    rgba[offset + 2U] = std::uint8_t(std::lround(std::clamp(color.blue, 0.0F, 1.0F) * 255.0F));
    rgba[offset + 3U] = 255U;
}
```

### Bước 2 — Rasterize tại pixel center

Trước vòng lặp pixel, ta transform ba vertex, đổi từ NDC sang tọa độ panel và chỉ quét bounding box của tam giác:

```cpp title="include/pipeline.hpp — chuẩn bị screen triangle và bounding box"
framebuffer.clear({11.0F / 255.0F, 16.0F / 255.0F, 32.0F / 255.0F});
const std::array<GpuVertex, 3> transformed = transformedTriangle(triangle, transform);
std::array<ScreenVertex, 3> screen{};
for (std::size_t index = 0; index < screen.size(); ++index) {
    // Invalid geometry must not reach a float-to-integer bounding-box cast.
    if (!std::isfinite(transformed[index].positionX) || !std::isfinite(transformed[index].positionY) ||
        std::abs(transformed[index].positionX) > 10000 || std::abs(transformed[index].positionY) > 10000) {
        return;
    }
    screen[index] = {
        ndcToCpuScreen({transformed[index].positionX, transformed[index].positionY}, framebuffer.width, framebuffer.height),
        {transformed[index].red, transformed[index].green, transformed[index].blue},
    };
}

const float minimumX = std::min({screen[0].position.x, screen[1].position.x, screen[2].position.x});
const float maximumX = std::max({screen[0].position.x, screen[1].position.x, screen[2].position.x});
const float minimumY = std::min({screen[0].position.y, screen[1].position.y, screen[2].position.y});
const float maximumY = std::max({screen[0].position.y, screen[1].position.y, screen[2].position.y});
const int left = std::clamp(int(std::floor(minimumX)), 0, framebuffer.width - 1);
const int right = std::clamp(int(std::ceil(maximumX)), 0, framebuffer.width - 1);
const int top = std::clamp(int(std::floor(minimumY)), 0, framebuffer.height - 1);
const int bottom = std::clamp(int(std::ceil(maximumY)), 0, framebuffer.height - 1);
```

Không quét toàn bộ framebuffer rồi mới hỏi pixel có nằm trong tam giác không. Bounding box giữ thuật toán dễ hiểu mà đã tránh phần lớn phép tính thừa.

```cpp title="include/pipeline.hpp — hot loop CPU rasterizer"
for (int y = top; y <= bottom; ++y) {
    for (int x = left; x <= right; ++x) {
        const BarycentricSample sample = barycentricAtPoint(screen, {float(x) + 0.5F, float(y) + 0.5F}, smoothColor);
        if (sample.inside) {
            framebuffer.putPixel(x, y, sample.color);
        }
    }
}
```

`+0.5` đặt sample ở tâm pixel. Checkpoint 4 dùng solid color nên ta tập trung vào coverage; smooth interpolation sẽ bật ở bài 7.

### Bước 3 — Cấp texture storage khi panel đổi size

Presenter tạo program dành riêng cho texture, một VAO rỗng cho Core Profile và texture dùng nearest filtering. Nó không nhận mesh tam giác:

```cpp title="include/gpu_renderer.hpp — initialize CPU texture presenter"
program = createProgram(api, kTextureVertexShader, kTextureFragmentShader, diagnostics);
if (program == 0U) {
    return false;
}
textureLocation = api.GetUniformLocation(program, "uTexture");
api.GenVertexArrays(1, &vertexArray);
api.GenTextures(1, &texture);
api.BindTexture(GL_TEXTURE_2D, texture);
api.TexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_NEAREST);
api.TexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_NEAREST);
api.TexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
api.TexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
api.BindTexture(GL_TEXTURE_2D, 0U);
return textureLocation >= 0 && vertexArray != 0U && texture != 0U;
```

```cpp title="include/gpu_renderer.hpp — allocate CPU texture"
bool resize(GlApi& api, int nextWidth, int nextHeight) {
    GLint maximumTextureSize = 0;
    api.GetIntegerv(GL_MAX_TEXTURE_SIZE, &maximumTextureSize);
    if (nextWidth <= 0 || nextHeight <= 0 || nextWidth > maximumTextureSize || nextHeight > maximumTextureSize) {
        return false;
    }
    api.BindTexture(GL_TEXTURE_2D, texture);
    api.PixelStorei(GL_UNPACK_ALIGNMENT, 1);
    api.TexImage2D(GL_TEXTURE_2D, 0, GL_RGBA8, nextWidth, nextHeight, 0, GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
    api.BindTexture(GL_TEXTURE_2D, 0U);
    if (api.GetError() != GL_NO_ERROR) {
        return false;
    }
    width = nextWidth;
    height = nextHeight;
    return true;
}
```

`glTexImage2D` cấp storage. Mỗi frame bình thường chỉ gọi `glTexSubImage2D` để thay pixels, tránh cấp allocation mới liên tục.

### Bước 4 — Presenter vẽ một quad không có VBO

Texture vertex shader dùng `gl_VertexID` để tạo bốn corners. Vì CPU row 0 là phía trên, shader đặt `vUv.y = 1 - uv.y`; việc flip nằm đúng ở biên trình bày, không làm sai coordinate math của CPU rasterizer.

Phần upload và draw vì thế rất ngắn. `TexSubImage2D` chỉ chép byte; `DrawArrays` vẽ full-screen quad trong viewport hiện tại:

```cpp title="include/gpu_renderer.hpp — upload rồi trình bày CPU framebuffer"
void upload(GlApi& api, const Framebuffer& framebuffer) const {
    api.BindTexture(GL_TEXTURE_2D, texture);
    api.PixelStorei(GL_UNPACK_ALIGNMENT, 1);
    api.TexSubImage2D(
        GL_TEXTURE_2D,
        0,
        0,
        0,
        framebuffer.width,
        framebuffer.height,
        GL_RGBA,
        GL_UNSIGNED_BYTE,
        framebuffer.rgba.data()
    );
}

void draw(GlApi& api) const {
    api.UseProgram(program);
    api.ActiveTexture(GL_TEXTURE0);
    api.BindTexture(GL_TEXTURE_2D, texture);
    api.Uniform1i(textureLocation, 0);
    api.BindVertexArray(vertexArray);
    api.DrawArrays(GL_TRIANGLE_STRIP, 0, 4);
    api.BindVertexArray(0U);
    api.BindTexture(GL_TEXTURE_2D, 0U);
}
```

## Ghép các phần lại

Trong phần setup, tạo CpuTexturePresenter và Framebuffer sau khi program/VBO đã sẵn sàng. Trong vòng lặp, chỉ resize ảnh và texture khi kích thước panel đổi; kiểm cả hai kết quả trước khi upload.

Sau đó rasterizeCpuTriangle → cpuPresenter.upload → viewport trái → cpuPresenter.draw. tam giác GPU vẫn vẽ ở viewport phải. Bản chuẩn giới hạn mỗi panel ở 4M pixel, mỗi chiều ảnh CPU không quá 4096; khi vượt giới hạn, cửa sổ báo cần thu nhỏ thay vì cố cấp phát vô hạn.

```bash title="Terminal — build và chạy checkpoint 04"
cmake --build build --config Debug --target project_33_checkpoint_4 --parallel 2
./build/Debug/project_33_checkpoint_4.exe
```

Đường chạy trên dành cho Visual Studio trên Windows. Với Ninja, chọn CMAKE_BUILD_TYPE khi configure và chạy executable ngay trong build, không có thư mục Debug/Release trung gian. Mọi checkpoint và final đều nằm trong cùng ZIP; bạn không cần Node.js để build C++.

## Thử làm sai để hiểu đúng

Chỉ thay một chi tiết mỗi lần trên bản thử nghiệm. Ghi dự đoán trước, chạy để quan sát rồi phục hồi mã đúng trước khi đi tiếp.

1. Bỏ phép lật V trong texture shader. Panel CPU lật dọc còn GPU giữ nguyên; trả lại flip sau khi xác nhận lỗi thuộc bước trình bày ảnh.
2. Bỏ +0.5 ở tâm mẫu CPU. So đường biên trước/sau; đừng đổi vertex shader để che sai khác do vị trí lấy mẫu.

## Tự kiểm tra kết quả

- [ ] CPU rasterizer không include hoặc gọi OpenGL API.
- [ ] Framebuffer có đúng `width × height × 4` bytes.
- [ ] Pixel center dùng `(x+0.5, y+0.5)`.
- [ ] Texture storage chỉ realloc khi panel đổi size.
- [ ] Presenter dùng nearest sampling và flip V có chủ đích.
- [ ] Hai panel có cùng solid tam giác.

## Bài tập mở rộng

1. Tắt GPU draw để xác nhận panel trái không vô tình phụ thuộc tam giác GPU program.
2. In checksum CPU framebuffer ở hai frame đứng yên; giá trị phải lặp lại.
3. Đổi background CPU thành màu dễ nhận biết nhưng giữ tam giác color giống GPU.

Bài sau sẽ cho tam giác xoay, scale và dịch chuyển bằng cùng transform ở C++ và vertex shader.
