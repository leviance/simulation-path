# Đưa dữ liệu tam giác vào VBO và VAO

## Vấn đề cần giải quyết

Ta đã có context và shader program, nhưng GPU chưa biết tam giác có những đỉnh nào. Bài này nối hai đầu ấy: đặt ba đỉnh vào một vùng nhớ của GPU, rồi mô tả cách đọc từng đỉnh.

Cuối bài, nửa phải xuất hiện một tam giác xanh, nửa trái vẫn chỉ có nền. Đừng thêm chuyển động lúc này. Một hình đứng yên giúp bạn phân biệt lỗi dữ liệu với lỗi cập nhật góc xoay ở các bài sau.

## Hiểu ý tưởng trước khi viết code

VBO chứa byte, không tự hiểu byte nào là position hay color. VAO ghi lại cách đọc chúng: location, số thành phần, type, stride và offset. Với `GpuVertex`, mỗi đỉnh có năm float: hai số tọa độ, ba số màu.

Đừng học thuộc các số 8 và 20. `offsetof(GpuVertex, red)` cho vị trí bắt đầu màu; `sizeof(GpuVertex)` cho khoảng cách tới đỉnh kế tiếp. Ta dùng `static_assert` để phát hiện sớm nếu cấu trúc C++ không còn đúng như shader mong đợi.

## Viết code từng bước

### Bước 1 — Khóa vertex contract trong C++

```cpp title="include/pipeline.hpp — GpuVertex layout"
struct GpuVertex {
    float positionX{};
    float positionY{};
    float red{};
    float green{};
    float blue{};
};

static_assert(std::is_standard_layout_v<GpuVertex>);
static_assert(sizeof(GpuVertex) == sizeof(float) * 5U);
static_assert(offsetof(GpuVertex, positionX) == 0U);
static_assert(offsetof(GpuVertex, red) == sizeof(float) * 2U);
```

Ba vertex dùng tọa độ 2D quanh gốc; shader áp transform rồi ghi clip position với w = 1, nên x/y đầu ra cũng chính là NDC. Mỗi vertex có hai float position và ba float color; các static_assert giúp ta kiểm rõ kích thước và offset, không đoán cách struct được xếp trong bộ nhớ.

Ngay sau các static_assert trong include/pipeline.hpp, khai báo dữ liệu tam giác. Mỗi dòng có x, y rồi red, green, blue; tọa độ Y dương hướng lên. Dùng cùng mảng này cho cả renderer CPU ở bài sau, không viết thêm một mảng vị trí gần giống ở main:

```cpp title="include/pipeline.hpp — ba vertex đầu vào"
inline constexpr std::array<GpuVertex, 3> kSourceTriangle{
    GpuVertex{0.0F, 0.66F, 0.97F, 0.42F, 0.35F},
    GpuVertex{-0.70F, -0.58F, 0.35F, 0.78F, 0.48F},
    GpuVertex{0.70F, -0.58F, 0.38F, 0.68F, 0.94F},
};
```

Transform2D và transformPosition nằm cùng file để bài sau nối CPU vào cùng hệ tọa độ. Ở lần vẽ đầu, angle bằng 0, translation bằng (0,0) và scale bằng 0,82. Vì thế shader đã có uniform nhưng chưa cần chuyển động để kiểm kết nối dữ liệu.

### Bước 2 — Upload đúng một lần vào VBO

```cpp title="include/gpu_renderer.hpp — tạo VBO và VAO"
api.GenVertexArrays(1, &vertexArray);
api.GenBuffers(1, &vertexBuffer);
if (vertexArray == 0U || vertexBuffer == 0U) {
    return false;
}
api.BindVertexArray(vertexArray);
api.BindBuffer(GL_ARRAY_BUFFER, vertexBuffer);
api.BufferData(GL_ARRAY_BUFFER, GLsizeiptr(sizeof(kSourceTriangle)), kSourceTriangle.data(), GL_STATIC_DRAW);
```

`GL_STATIC_DRAW` mô tả pattern dùng: data upload một lần rồi được đọc nhiều lần. Rotation sau này đi qua uniform, không upload lại VBO mỗi frame.

### Bước 3 — Nói cho VAO cách đọc hai attributes

```cpp title="include/gpu_renderer.hpp — position attribute"
api.EnableVertexAttribArray(0U);
api.VertexAttribPointer(
    0U,
    2,
    GL_FLOAT,
    GL_FALSE,
    GLsizei(sizeof(GpuVertex)),
    reinterpret_cast<const void*>(offsetof(GpuVertex, positionX))
);
```

Color dùng location 1, ba components và `offsetof(GpuVertex, red)`. `stride` luôn là `sizeof(GpuVertex)`, không phải số components của riêng attribute.

Tiếp ngay sau phần position attribute trong initializeMesh, thêm:

```cpp title="include/gpu_renderer.hpp — color attribute"
api.EnableVertexAttribArray(1U);
api.VertexAttribPointer(
    1U,
    3,
    GL_FLOAT,
    GL_FALSE,
    GLsizei(sizeof(GpuVertex)),
    reinterpret_cast<const void*>(offsetof(GpuVertex, red))
);
```

Cuối initializeMesh, unbind buffer và VAO rồi kiểm GetError. Các lời gọi VertexAttribPointer đã ghi lại VBO liên quan trong VAO; unbind GL_ARRAY_BUFFER sau đó không làm mất liên kết này. Phương thức trả bool để main dừng nếu tạo mesh thất bại, thay vì tiếp tục vẽ với resource bằng 0.

### Bước 4 — Draw trong viewport phải

```cpp title="include/gpu_renderer.hpp — draw triangle"
void draw(GlApi& api, const Transform2D& transform, bool smoothColor) const {
    api.UseProgram(program);
    api.Uniform1f(angleLocation, transform.angleRadians);
    api.Uniform1f(scaleLocation, transform.scale);
    api.Uniform2f(translationLocation, transform.translation.x, transform.translation.y);
    int smoothColorFlag = 0;
    if (smoothColor) {
        smoothColorFlag = 1;
    }
    api.Uniform1i(smoothColorLocation, smoothColorFlag);
    api.BindVertexArray(vertexArray);
    api.DrawArrays(GL_TRIANGLES, 0, 3);
    api.BindVertexArray(0U);
}
```

Draw call không mang vertex pointer. Nó dùng program, uniforms, VAO và viewport đang active tại thời điểm gọi.

Ở đây `api.DrawArrays` là function pointer trỏ tới `glDrawArrays`. Bộ ba `GL_TRIANGLES, 0, 3` yêu cầu ghép một tam giác từ ba đỉnh đầu tiên; nó không gửi lại dữ liệu VBO.

## Ghép các phần lại

Sau initializeProgram, gọi initializeMesh đúng một lần. Trong mỗi frame, clear trước, đặt glViewport bên phải, gọi gpuTriangle.draw rồi swap. Đổi thứ tự này có thể làm draw rơi vào viewport cũ hoặc bị clear đè.

Bạn phải thấy một tam giác xanh ở panel phải. Uniform scale khởi đầu là 0,82, angle và translation bằng 0. Màu nội suy chưa bật; không cần sửa color attribute chỉ vì cả tam giác đang xanh.

```bash title="Terminal — build và chạy checkpoint 03"

```

## Thử làm sai để hiểu đúng

Chỉ thay một chi tiết mỗi lần trên bản thử nghiệm. Ghi dự đoán trước, chạy để quan sát rồi phục hồi mã đúng trước khi đi tiếp.

1. Giảm draw count từ 3 xuống 2. Dự đoán liệu có còn một tam giác hoàn chỉnh không, rồi chạy để kiểm; không tăng count vượt vùng VBO.
2. Cho color attribute đọc từ offset position. Quan sát màu sai, rồi trả về offsetof(GpuVertex, red). Nếu hình mất hẳn, kiểm stride/location trước khi sửa shader.

## Tự kiểm tra kết quả

- [ ] `GpuVertex` có đúng năm float và standard layout.
- [ ] VBO upload đúng ba vertex một lần.
- [ ] Location 0 là vec2 position, location 1 là vec3 color.
- [ ] Cả hai attributes dùng cùng stride và offset bằng `offsetof`.
- [ ] tam giác GPU xuất hiện ở viewport phải.
- [ ] `glGetError` bằng `GL_NO_ERROR` sau setup mesh.

## Bài tập mở rộng

1. Đổi thứ tự ba đỉnh và quan sát winding mà chưa bật culling.
2. Thêm một vertex thứ tư nhưng giữ `GL_TRIANGLES`; giải thích vì sao nó chưa tạo hình thứ hai.
3. In `sizeof(GpuVertex)` và hai offsets cạnh shader locations trong terminal.

Bài tiếp theo sẽ làm panel trái sống lại bằng chính CPU rasterizer, rồi upload framebuffer đó như một texture.
