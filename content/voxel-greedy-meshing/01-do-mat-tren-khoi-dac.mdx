# Đếm số mặt trước khi gộp

## Vấn đề cần giải quyết

Project 59 đã bỏ những mặt nằm giữa hai block đặc. Nhưng một bức tường phẳng 16×16 vẫn còn 256 quad dù cùng mặt phẳng, cùng vật liệu. Trước khi gộp, ta cần một bản đang chạy đúng để so sánh. Nếu bắt đầu ngay từ vòng lặp greedy, rất khó biết một lỗ trên hình do mesher mới hay camera cũ.

## Hiểu ý tưởng trước khi viết code

Một **mặt đơn vị** là mặt ngoài của một block, diện tích 1. Baseline dùng một quad cho mỗi mặt; một quad gồm hai triangle. Chunk đặc cạnh 16 có $6\times16^2=1536$ quad, tức 3072 triangle. Greedy thay các ô vuông nhỏ bằng hình chữ nhật lớn, không xóa block.

ZIP đã có storage, camera trực giao, Z-buffer và phần đưa ảnh CPU lên SDL texture. Starter phải hiện được khối đất, không phải cửa sổ trống. Hãy theo đường dữ liệu: `Chunk → buildBaseline → Mesh → render → Frame → upload → SDL_RenderTexture`. Upload copy từng hàng theo pitch, không giả định texture luôn liền mạch.

## Viết code từng bước

### Bước 1 — Chạy starter và nhận diện phần đã có

Cấu hình CMake với BUILD_CHECKPOINTS=ON rồi chạy target starter. Khung tạo texture RGBA32; camera/rasterizer đã có từ Project 59. Không cần tự đoán cách vẽ block. Đoạn này kiểm từng tài nguyên, không gọi tiếp với renderer null.

```cpp title="src/main.cpp"
SDL_Window* window = SDL_CreateWindow("Greedy voxel meshing", 960, 600, flags);
SDL_Renderer* renderer = nullptr;
if (window != nullptr) {
    renderer = SDL_CreateRenderer(window, nullptr);
}
SDL_Texture* texture = nullptr;
if (renderer != nullptr) {
    texture = SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGBA32, SDL_TEXTUREACCESS_STREAMING, voxel::imageWidth, voxel::imageHeight);
}
```


### Bước 2 — Theo dấu một mặt ngoài

Trong buildBaseline, ô đặc chỉ sinh mặt nếu neighbor là Air hoặc ngoài miền hiển thị. Grass sát Stone vẫn che nhau vì đều opaque. Rectangle của baseline có width=height=1; chưa có phép gộp.

```cpp title="include/baseline.hpp"
const auto& d = offsets[face];
const std::array<int, 3> n{{x + d[0], y + d[1], z + d[2]}};
++built.samples;
if (activeBlock(chunk, n, slice) != Block::Air) {
    continue;
}
const int axis = face / 2;
int plane = cell[axis];
if (face % 2 == 0) {
    ++plane;
}
const Rectangle r{face, plane, cell[(axis + 1) % 3], cell[(axis + 2) % 3], 1, 1, material};
```


### Bước 3 — Đưa số đếm lên cửa sổ

Bài 01 thêm readout. unitFaces đếm diện tích theo ô đơn vị; quads.size() đếm rectangle thật sự gửi xuống rasterizer. Hiện chúng bằng nhau, từ bài 05 sẽ khác. mesh.size() mới là số triangle; không lấy số block nhân 12 nữa.

```cpp title="include/app.hpp"
const std::string counts = "unit faces=" + std::to_string(app.cache.built.unitFaces) + " quads=" + std::to_string(app.cache.built.quads.size()) + " triangles=" + std::to_string(app.cache.built.mesh.size());
require(SDL_RenderDebugText(renderer, 12, 520, counts.c_str()));
```


## Ghép các phần lại

Build starter trước để xác nhận bộ khung hoạt động, rồi chạy checkpoint 01 để thấy readout mới. Mỗi snapshot chứa đủ source và build độc lập, không liên kết ngược đến module khác. Phần mã hoàn chỉnh dưới bài cho phép kiểm toàn bộ file thay vì ghép các mảnh bằng trí nhớ.

```bash title="Terminal — checkpoint 1"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_61_starter --parallel 2
cmake --build build --config Debug --target project_61_checkpoint_1 --parallel 2
.\build\Debug\project_61_checkpoint_1.exe
```

Windows/Visual Studio dùng đường dẫn trên. Với generator single-config, đặt CMAKE_BUILD_TYPE=Debug và chạy executable trực tiếp trong build. Nhãn native dùng ASCII; giải thích tiếng Việt nằm trong bài và Canvas.

## Thử làm sai để hiểu đúng

1. Tạm bỏ điều kiện neighbor rồi chạy khối đặc: số mặt tăng mạnh nhưng hình ngoài gần như không đổi. Hoàn tác trước bài sau.
2. Tính triangle bằng 12×số block rồi so với mesh.size(): hai số khác nhau vì baseline đã bỏ mặt tiếp giáp.

Chỉ sửa trên bản thử riêng rồi hoàn tác thí nghiệm trước khi đi tiếp; code tải về là bản đúng.
