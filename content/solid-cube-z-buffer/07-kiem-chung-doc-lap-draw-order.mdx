# Kiểm chứng renderer độc lập với draw order

## Vấn đề cần giải quyết

Nhìn một ảnh đẹp chưa đủ để kết luận Z-buffer đúng. Ta cần giữ nguyên scene, vẽ hai lần với hai thứ tự triangle và so kết quả ở mọi pixel. Đồng thời, depth view và pixel inspector giúp tìm chỗ sai thay vì đoán từ màu.

## Hiểu ý tưởng trước khi viết code

Color buffer phải giống từng phần tử. Depth là số thực nên so với tolerance nhỏ, nhưng NaN không được coi là bằng nhau. Chỉ so tổng, checksum hoặc pass/reject count có thể bỏ sót hai pixel đổi chỗ.

Độ sáng của depth view chỉ là cách trình bày. Giá trị clear=1 được tô nền tối; các depth nhỏ hơn sáng hơn. Không dùng ảnh grayscale đã lượng tử hóa để so độ chính xác của buffer gốc.

### Bước 1 — So toàn bộ depth buffer

Thêm buffersNearlyEqual vào render.hpp, sau renderCube:

```cpp title="include/render.hpp — so số thực và từ chối NaN"
inline bool buffersNearlyEqual(const std::vector<double>& first, const std::vector<double>& second, double epsilon = 1e-9) {
    if (first.size() != second.size() || !std::isfinite(epsilon) || epsilon < 0.0) {
        return false;
    }
    for (std::size_t i = 0; i < first.size(); ++i) {
        if (!std::isfinite(first[i]) || !std::isfinite(second[i]) || std::abs(first[i] - second[i]) > epsilon) {
            return false;
        }
    }
    return true;
}
```


Hàm kiểm cả kích thước và từng giá trị. Color buffer là số nguyên packed RGBA, dùng so sánh vector trực tiếp.

### Bước 2 — Hiện depth và pixel được chọn

Thêm depthShade vào render.hpp:

```cpp title="include/render.hpp — chỉ đổi cách nhìn depth"
inline std::uint8_t depthShade(double depth) {
    if (!std::isfinite(depth) || depth >= 1.0) {
        return 12;
    }
    return std::uint8_t(std::lround((1.0 - std::clamp(depth, 0.0, 1.0)) * 235.0 + 20.0));
}
```


Trong renderScene, sau renderCube và trước return stats, thêm hai nhánh sau:

```cpp title="include/view.hpp — grayscale không thay depth buffer"
if (scene.debug && scene.depthView) {
    for (std::size_t i = 0; i < targets.image.pixels.size(); ++i) {
        const auto shade = depthShade(targets.depth.values()[i]);
        targets.image.pixels[i] = packColor({shade, shade, shade, 255});
    }
}
```



```cpp title="include/view.hpp — đánh dấu pixel đang đọc"
if (scene.debug) {
    screenLine(targets.image, {double(scene.inspectX - 4), double(scene.inspectY)}, {double(scene.inspectX + 4), double(scene.inspectY)}, viewportHeight(scene), kWhite);
```

### Bước 3 — Đọc bộ kiểm chứng độc lập trong ZIP

Các đoạn dưới đã nằm trong tests/tests.cpp của ZIP. Chúng là mã **đọc để đối chiếu**, không dán vào main SDL:

```cpp title="tests/tests.cpp — một frame giữ color, depth và stats"
struct RenderedFrame {
    std::vector<std::uint32_t> colors{};
    lab::DepthBuffer depths{1, 1};
    lab::RenderStats stats{};
};
```



```cpp title="tests/tests.cpp — render scene vào buffer thuần CPU"
RenderedFrame render(bool reverseOrder, bool depthEnabled) {
    constexpr int width = 160;
    constexpr int height = 120;
    RenderedFrame frame{
        std::vector<std::uint32_t>(std::size_t(width) * std::size_t(height), 0x090f1dffU),
        lab::DepthBuffer(width, height),
        {},
    };
    frame.stats = lab::renderCube(
        lab::makeCubeMesh(),
        width,
        height,
        -0.42,
        0.68,
        reverseOrder,
        depthEnabled,
        frame.colors,
        frame.depths
    );
    return frame;
}
```


Tests gọi render(false,true) và render(true,true), so colors trực tiếp, rồi dùng buffersNearlyEqual cho depths. Khi depth tắt, chúng phải thấy colors khác nhau. Bài 9 sẽ chỉ cách đổi target tests từ final/include sang Starter của bạn sau khi hoàn tất cả module.

## Thử làm sai để hiểu đúng

1. Cho NaN vào hai buffer rồi chỉ kiểm abs(a-b)>epsilon: so sánh với NaN có thể không báo sai. Giữ kiểm isfinite.

2. So tổng depth thay vì từng pixel: đổi chỗ hai giá trị vẫn giữ nguyên tổng. So đầy đủ vị trí.

3. Yêu cầu passCount bằng nhau giữa hai draw order: đó là thống kê trung gian, không phải ảnh cuối. So color/depth cuối.

## Tự kiểm tra kết quả

- Depth bật: color giống hoàn toàn, depth giống trong tolerance.
- Depth tắt: preset có mặt chồng nhau cho ảnh khác khi đảo order.
- NaN, khác kích thước hoặc tolerance sai không được báo bằng nhau.
- Depth view không sửa buffer dùng cho compare.
