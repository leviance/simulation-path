# Tạo depth buffer song song với color buffer

## Vấn đề cần giải quyết

Để chọn bề mặt gần nhất, mỗi pixel cần nhớ một số depth. Mảng này phải có cùng cách đánh chỉ số với color buffer và được clear ở đầu frame, không phải sau mỗi triangle.

## Hiểu ý tưởng trước khi viết code

Project dùng NDC depth trong [0,1]: gần là 0, xa là 1.0. Clear về 1.0 nghĩa là chưa có bề mặt nào thắng tại pixel đó. DepthBuffer chưa tự tô màu và chưa tự quyết định che khuất.

$$index=y\cdot width+x.$$

Color và depth cùng dùng board 1100×800. Window resize chỉ letterbox board, không cấp phát theo cửa sổ. Hàm resize của DepthBuffer vẫn được kiểm riêng để bảo đảm thay kích thước logic an toàn.

### Bước 1 — Thay stub bằng buffer thật

Trong depth.hpp, thay **toàn bộ struct DepthBuffer** đang giữ chỗ bằng cấu trúc dưới. Không giữ cả constructor cũ lẫn mới:

```cpp title="include/depth.hpp — cấp phát, clear và bounds"
struct DepthBuffer {
    explicit DepthBuffer(int width, int height, double clearDepth = 1.0) {
        if (!resize(width, height, clearDepth)) {
            throw std::invalid_argument("Invalid depth buffer size");
        }
    }

    bool resize(int width, int height, double clearDepth = 1.0) {
        constexpr std::size_t maxPixels = 4000000;
        if (width <= 0 || height <= 0 || !std::isfinite(clearDepth) || clearDepth < 0.0 || clearDepth > 1.0 || std::size_t(width) > maxPixels / std::size_t(height)) {
            return false;
        }
        std::vector<double> next(std::size_t(width) * std::size_t(height), clearDepth);
        values_.swap(next);
        width_ = width;
        height_ = height;
        return true;
    }

    void clear(double clearDepth = 1.0) {
        if (!std::isfinite(clearDepth) || clearDepth < 0.0 || clearDepth > 1.0) {
            throw std::invalid_argument("Invalid clear depth");
        }
        std::fill(values_.begin(), values_.end(), clearDepth);
    }

    std::size_t index(int x, int y) const {
        if (x < 0 || y < 0 || x >= width_ || y >= height_) {
            throw std::out_of_range("Depth pixel outside buffer");
        }
        return std::size_t(y) * std::size_t(width_) + std::size_t(x);
    }

    double at(int x, int y) const {
        return values_[index(x, y)];
    }

    double& at(int x, int y) {
        return values_[index(x, y)];
    }

    int width() const {
        return width_;
    }

    int height() const {
        return height_;
    }

    const std::vector<double>& values() const {
        return values_;
    }

    private:
    int width_{};
    int height_{};
    std::vector<double> values_{};
};
```


resize kiểm kích thước trước phép nhân và giới hạn 4 triệu phần tử. Nó tạo vector tạm rồi swap, nên không mất dữ liệu cũ khi tham số sai. Constructor báo lỗi nếu kích thước không hợp lệ; index báo lỗi nếu tọa độ nằm ngoài mảng.

## Ghép các phần lại

Build Starter. Hình vẫn sai che khuất vì ta mới có nơi lưu số, chưa compare/write. Trong Canvas, depth view toàn giá trị clear là kết quả đúng của giai đoạn này; chưa có fragment ghi depth.

## Thử làm sai để hiểu đúng

1. Clear về 0 khiến gần như mọi fragment thua khi dùng quy tắc nhỏ hơn thắng. Trả clear về 1.0.

2. Clear sau mỗi triangle làm mất kết quả các mặt trước. Đưa clear về đầu renderScene.

3. Dùng width cửa sổ để index một buffer có width logic: hàng bị lệch hoặc vượt mảng. Dùng cùng row stride cho color/depth.

## Tự kiểm tra kết quả

- DepthBuffer(4,3) có 12 giá trị; index(2,1)=6.
- clear đưa mọi giá trị về 1.0.
- resize không hợp lệ giữ dữ liệu cũ, không cấp phát khổng lồ.
- Chưa có compare/write ở checkpoint này; không coi che khuất là đã đúng.
