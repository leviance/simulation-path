# Đổi vận tốc bằng collision impulse

## Vấn đề cần giải quyết

Biết hai bóng đang chồng lấn chưa đủ để làm chúng nảy. Nếu phản xạ từng velocity như va vào tường, ta đã coi vật còn lại có khối lượng vô hạn. Với hai vật động, cả hai phải nhận tác động đối nhau và lượng đổi velocity phụ thuộc mass.

## Hiểu ý tưởng trước khi viết code

Gọi n đi từ A sang B và wA=1/mA, wB=1/mB. Vận tốc tương đối dọc normal là:

$$
v_n=(v_B-v_A)\cdot n,\qquad
j=-\frac{(1+e)v_n}{w_A+w_B}.
$$

Chỉ áp dụng khi vn âm: hai vật đang tiến vào nhau. A nhận −j·n, B nhận +j·n; velocity thay đổi bằng impulse nhân inverse mass. Thành phần tiếp tuyến không đổi vì chưa có ma sát.

Bóng mẫu có mA=1, mB=2, vA=1,5, vB=−0,5, e=1. Ta tính được j=8/3 N·s, vA mới=−7/6, vB mới=5/6 m/s. Momentum trước/sau đều 0,5 kg·m/s; động năng đều 1,375 J. Những phân số này là đối chứng tính tay, không phải output lấy từ chính solver.

### Bước 1 — Tách công thức j khỏi phép đổi vector

Thêm hai hàm sau vào lab.hpp. validContact từ chối normal không hữu hạn hoặc không có độ dài một; dữ liệu sai không được lan vào velocity.

```cpp title="include/lab.hpp — validContact"
inline bool validContact(const CircleContact& contact) {
    return contact.colliding && std::isfinite(contact.normal.x) && std::isfinite(contact.normal.y) && std::abs(lengthSquared(contact.normal) - 1.0) < 1e-8 && std::isfinite(contact.penetration) && contact.penetration >= 0.0;
}
```


```cpp title="include/lab.hpp — normalImpulseMagnitude"
inline double normalImpulseMagnitude(double normalSpeed, double inverseMassSum, double restitution) {
    if (!std::isfinite(normalSpeed) || normalSpeed >= 0.0 || !std::isfinite(inverseMassSum) || inverseMassSum <= kCollisionEpsilon || !std::isfinite(restitution)) {
        return 0.0;
    }
    return -(1.0 + std::clamp(restitution, 0.0, 1.0)) * normalSpeed / inverseMassSum;
}
```


Hai inverse mass đều zero thì không có vật động để nhận phản ứng. Hàm trả zero thay vì chia cho zero. Nếu một vật đứng yên và vật kia động, mẫu số vẫn hợp lệ.

### Bước 2 — Áp impulse có trọng số khối lượng

Thêm applyCollisionImpulse:

```cpp title="include/lab.hpp — applyCollisionImpulse"
inline double applyCollisionImpulse(Ball& first, Ball& second, const CircleContact& contact, double restitution) {
    if (!validContact(contact) || !finiteBall(first) || !finiteBall(second) || !std::isfinite(restitution)) {
        return 0.0;
    }
    const double inverseMassSum = first.inverseMass + second.inverseMass;
    if (inverseMassSum <= kCollisionEpsilon) {
        return 0.0;
    }
    const Vec2 relativeVelocity = subtract(second.velocity, first.velocity);
    const double velocityAlongNormal = dot(relativeVelocity, contact.normal);
    if (velocityAlongNormal >= 0.0) {
        return 0.0;
    }
    const double bounce = std::clamp(restitution, 0.0, 1.0) * std::min(first.restitution, second.restitution);
    const double impulseMagnitude = normalImpulseMagnitude(velocityAlongNormal, inverseMassSum, bounce);
    if (!std::isfinite(impulseMagnitude)) {
        return 0.0;
    }
    const Vec2 impulse = scale(contact.normal, impulseMagnitude);
    first.velocity = subtract(first.velocity, scale(impulse, first.inverseMass));
    second.velocity = add(second.velocity, scale(impulse, second.inverseMass));
    return impulseMagnitude;
}
```


e hiệu dụng được chọn bằng scale × min(eA,eB). Đây là quy ước vật liệu được công bố rõ, không phải một định luật kết hợp bắt buộc cho mọi mô phỏng. Các bóng mẫu đặt eA=eB=1 để kiểm trực tiếp công thức.

## Ghép các phần lại

Bấm N ở cảnh vừa reset. Kiểm j=2,66667, vA≈−1,16667, vB≈0,83333. Ở bước kế tiếp, nếu chúng còn overlap nhưng đã tách nhau, j phải bằng zero.

Velocity đã phản ứng đúng nhưng hai hình tròn vẫn có thể còn xuyên nhau. Đó không phải lý do áp impulse thêm lần nữa: bài 6 sẽ sửa phần vị trí còn lại.

Khi e=0, hai vận tốc dọc normal trở thành 1/6 m/s, bằng vận tốc tâm khối. Động năng giảm còn 1/24 J; phần giảm là hành vi của va chạm không đàn hồi, không phải một thất bại của kiểm thử.

## Thử làm sai để hiểu đúng

1. Bỏ điều kiện vn>=0. Hai vật đang rời nhau lại nhận impulse và có thể bị kéo vào nhau. Khôi phục guard rồi bước hai lần.

2. Quên chia cho wA+wB. Đổi mass nhưng phản ứng không còn khớp đáp án tính tay.

3. Dùng cùng một delta velocity cho cả hai vật. Với mass khác nhau, tổng momentum sẽ đổi dù không có tác động bên ngoài.

## Tự kiểm tra kết quả

- Cặp mẫu cho j=8/3, vA=−7/6, vB=5/6 khi e=1.
- Momentum và động năng của cặp cô lập giữ nguyên trong tolerance; e&lt;1 giảm động năng.
- Cặp đang tách nhau không nhận impulse mới.
- Velocity tiếp tuyến không đổi; không có friction/rotation ẩn trong code.

## Bài tập mở rộng

Giữ nguyên cặp mẫu nhưng đặt e=0,5. Tự tính j và hai velocity mới, sau đó kiểm mức giảm động năng. So riêng thành phần normal và tangent trong một cặp va chạm xiên.
