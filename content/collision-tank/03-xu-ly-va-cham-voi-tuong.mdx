# Xử lý va chạm với bốn bức tường

## Vấn đề cần giải quyết

Bóng ra khỏi khung vì ta chưa mô tả tương tác với tường. Một lỗi hay gặp là chỉ chặn tâm ở mép bể: nửa hình tròn vẫn nằm ngoài. Một lỗi khác là cứ chạm mép thì đảo vận tốc, kể cả khi vật đã đi vào trong.

## Hiểu ý tưởng trước khi viết code

Tường trái ở x=−10, nên tâm của bóng bán kính r không được nhỏ hơn −10+r. Tường phải tương ứng là 10−r. Y cũng làm tương tự.

Với tường đứng yên và không ma sát, chỉ thành phần vận tốc vuông góc mặt tường thay đổi. Nếu vx đang âm ở tường trái, vx mới bằng −e·vx; vy giữ nguyên. Trong project này, e hiệu dụng của tường bằng **restitution scale × e của vật liệu**.

Tường cũng làm thay đổi động lượng của bóng. Ta lưu Jwall = m(vsau−vtrước) ngay tại đây để bài 8 không nhầm hệ “chỉ gồm đàn bóng” với một hệ cô lập.

### Bước 1 — Chuẩn bị kết quả trả về

Thêm kiểu sau vào lab.hpp:

```cpp title="include/lab.hpp — WallCollisionResult"
struct WallCollisionResult {
    int hitCount{};
    double deepestPenetration{};
    Vec2 wallImpulse{};
};
```


deepestPenetration là phần xuyên trước khi sửa. wallImpulse là vector động lượng mà tường đã truyền cho bóng, đơn vị kg·m/s, cũng bằng N·s.

### Bước 2 — Giải bốn giới hạn theo radius

Thêm resolveWallCollision:

```cpp title="include/lab.hpp — resolveWallCollision"
inline WallCollisionResult resolveWallCollision(Ball& ball, const TankBounds& bounds, double restitution) {
    WallCollisionResult result{};
    if (!finiteBall(ball) || !validBounds(bounds) || !std::isfinite(restitution)) {
        return result;
    }
    if (2.0 * ball.radius > std::min(bounds.maximumX - bounds.minimumX, bounds.maximumY - bounds.minimumY) || ball.inverseMass == 0.0) {
        return result;
    }
    const Vec2 previousVelocity = ball.velocity;
    const double bounce = std::clamp(restitution, 0.0, 1.0) * ball.restitution;

    const double leftLimit = bounds.minimumX + ball.radius;
    if (ball.position.x < leftLimit) {
        result.deepestPenetration = std::max(result.deepestPenetration, leftLimit - ball.position.x);
        ball.position.x = leftLimit;
        if (ball.velocity.x < 0.0) {
            ball.velocity.x = -ball.velocity.x * bounce;
        }
        ++result.hitCount;
    }
    const double rightLimit = bounds.maximumX - ball.radius;
    if (ball.position.x > rightLimit) {
        result.deepestPenetration = std::max(result.deepestPenetration, ball.position.x - rightLimit);
        ball.position.x = rightLimit;
        if (ball.velocity.x > 0.0) {
            ball.velocity.x = -ball.velocity.x * bounce;
        }
        ++result.hitCount;
    }
    const double bottomLimit = bounds.minimumY + ball.radius;
    if (ball.position.y < bottomLimit) {
        result.deepestPenetration = std::max(result.deepestPenetration, bottomLimit - ball.position.y);
        ball.position.y = bottomLimit;
        if (ball.velocity.y < 0.0) {
            ball.velocity.y = -ball.velocity.y * bounce;
        }
        ++result.hitCount;
    }
    const double topLimit = bounds.maximumY - ball.radius;
    if (ball.position.y > topLimit) {
        result.deepestPenetration = std::max(result.deepestPenetration, ball.position.y - topLimit);
        ball.position.y = topLimit;
        if (ball.velocity.y > 0.0) {
            ball.velocity.y = -ball.velocity.y * bounce;
        }
        ++result.hitCount;
    }
    result.wallImpulse = scale(subtract(ball.velocity, previousVelocity), 1.0 / ball.inverseMass);
    return result;
}
```


Mỗi mặt có hai việc tách biệt: đưa tâm về giới hạn hợp lệ, rồi chỉ phản xạ nếu velocity còn hướng ra ngoài. Cặp thao tác đó tránh việc vật bị đảo qua đảo lại khi còn hơi xuyên tường nhưng đã rời tường.

Để nhìn riêng cơ chế này, thay rebuildScene theo checkpoint 03. Phần khác biệt là một bóng gần tường trái:

Đây là thí nghiệm tạm; bài 7 sẽ trở lại đủ 256 bóng.

## Ghép các phần lại

Ở t=0, bóng mẫu có tâm x=−9,7, radius=0,5, vx=−2 và mass=1. Sau một bước, tường đặt tâm về −9,5. Với e=1, vx thành +2, vy=0,8 không đổi và Jwall.x bằng +4 kg·m/s.

Thêm phím E trong key-down:

```cpp title="src/main.cpp — đổi restitution scale"
if (key == SDLK_E) {
    if (scene.restitution <= 0.01) {
        scene.restitution = 1.0;
    } else {
        scene.restitution = std::max(0.0, scene.restitution - 0.2);
    }
    lab::rebuildScene(scene);
}
```

Giảm restitution scale bằng control hoặc phím E. Ở scale=0, thành phần hướng vào tường mất đi nhưng thành phần tiếp tuyến vẫn còn. Đừng nhân cả vector velocity với e rồi gọi đó là phản xạ không ma sát.

## Thử làm sai để hiểu đúng

1. Đặt tâm ở −10 thay vì −10+r. Nửa bóng nằm ngoài tường; radius đã bị bỏ quên.

2. Bỏ kiểm vx&lt;0 ở tường trái. Cho bóng còn hơi xuyên nhưng vx>0: nó bị đẩy ngược lại vào tường.

3. Nhân cả vx và vy với e. Bóng mất vận tốc trượt dọc tường dù mô hình chưa có ma sát. Hoàn tác và so hai thành phần riêng.

## Tự kiểm tra kết quả

- Tâm nằm trong giới hạn đã trừ radius ở cả hai trục.
- Bóng mẫu ở e=1 cho vx=+2; vy=0,8; Jwall.x=+4.
- Vật đang đi vào trong không bị phản xạ lần nữa.
- Va vào góc có thể ghi hai mặt tường; không bỏ mất một thành phần.

## Bài tập mở rộng

Cho một bóng chạm góc trái dưới với vx=−3, vy=−4 và e=0,5. Tính hai thành phần velocity mới và phần động năng còn lại; đừng dùng tốc độ vô hướng để quyết định dấu.
