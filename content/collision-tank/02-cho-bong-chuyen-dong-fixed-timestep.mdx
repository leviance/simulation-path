# Cho cả đàn bóng chuyển động bằng fixed timestep

## Vấn đề cần giải quyết

Đàn bóng đã hiện đúng, nhưng còn đứng yên. Ta sẽ cho nó chuyển động mà không gắn tốc độ vật lý với số frame vẽ được. Bài này cố ý **chưa có tường**: nếu vật đi ra ngoài vùng nhìn, nó vẫn còn trong world state.

## Hiểu ý tưởng trước khi viết code

Với vận tốc không đổi trong bước này, vị trí mới là:

$$
p_{n+1}=p_n+v_n h.
$$

h là số giây của một physics step, không phải “một frame”. Nhiều frame có thể không đủ cho một bước; một frame chậm có thể cần nhiều bước. Accumulator giữ phần thời gian chưa dùng.

Ứng dụng chỉ xử lý tối đa **bốn substep mỗi frame**. Khi vượt ngân sách, nó công khai droppedTime. Do đó “không phụ thuộc render FPS” chỉ đúng khi các bước cần thiết còn được xử lý đủ; không được giấu thời gian bị bỏ rồi nói mô phỏng vẫn chạy đúng thời gian thực.

### Bước 1 — Tiến một Ball

Thêm integrateBall vào lab.hpp:

```cpp title="include/lab.hpp — integrateBall"
inline void integrateBall(Ball& ball, double deltaSeconds) {
    if (!finiteBall(ball) || !std::isfinite(deltaSeconds) || deltaSeconds <= 0.0) {
        return;
    }
    if (ball.inverseMass == 0.0) {
        return;
    }
    const Vec2 next = add(ball.position, scale(ball.velocity, deltaSeconds));
    if (std::isfinite(next.x) && std::isfinite(next.y)) {
        ball.position = next;
    }
}
```


Position mới đọc velocity cũ. Inverse mass bằng 0 được hiểu là vật đứng yên; hàm không tích phân vật đó. Kiểm finite trước khi nhận dữ liệu mới.

### Bước 2 — Dùng một bước physics cho cả đàn

Thay stepScene trong scene.hpp:

```cpp title="include/scene.hpp — stepScene"
inline bool stepScene(Scene& scene) {
    const double dt = scene.dt;
    if (!std::isfinite(dt) || dt < 1e-6 || dt > 1.0 / 30.0) {
        stopScene(scene);
        scene.message = "Invalid fixed dt rejected.";
        return false;
    }
    {
        auto candidate = scene.balls;
        for (auto& ball : candidate) {
            integrateBall(ball, dt);
        }
        scene.balls = std::move(candidate);
    }
    scene.elapsed += dt;
    ++scene.substeps;
    return true;
}
```


candidate là bản đang tính. Cả vector nhận cùng dt; elapsed chỉ tăng một lần sau khi cả đàn đã tiến. Renderer tuyệt đối không tăng elapsed.

### Bước 3 — Chia thời gian frame thành các bước hữu hạn

Thêm FixedStepPlan và planner vào lab.hpp:

```cpp title="include/lab.hpp — FixedStepPlan"
struct FixedStepPlan {
    int steps{};
    double remainder{};
    double droppedTime{};
};
```


```cpp title="include/lab.hpp — planFixedSteps"
inline FixedStepPlan planFixedSteps(double accumulator, double frameSeconds, double dt, int maximumSteps, double maximumFrameSeconds) {
    if (!std::isfinite(accumulator) || accumulator < 0.0 || !std::isfinite(frameSeconds) || frameSeconds < 0.0 || !std::isfinite(dt) || dt < 1e-6 || maximumSteps < 1 || maximumSteps > 256 || !std::isfinite(maximumFrameSeconds) || maximumFrameSeconds <= 0.0) {
        return {};
    }
    const double accepted = std::min(frameSeconds, maximumFrameSeconds);
    const double available = accumulator + accepted;
    const double count = std::floor((available + kCollisionEpsilon) / dt);
    if (!std::isfinite(available) || !std::isfinite(count)) {
        return {};
    }
    const int steps = static_cast<int>(std::min(count, static_cast<double>(maximumSteps)));
    const double remainder = std::max(0.0, std::fmod(available + kCollisionEpsilon, dt) - kCollisionEpsilon);
    const double dropped = std::max(0.0, frameSeconds - accepted) + std::max(0.0, available - remainder - static_cast<double>(steps) * dt);
    return {steps, remainder, dropped};
}
```


Kiểm count trước khi ép sang int. Chỉ clamp con số **double** vào maximumSteps rồi mới cast, tránh undefined behavior khi dt quá nhỏ hoặc accumulator quá lớn.

Thay advanceFrame trong scene.hpp:

```cpp title="include/scene.hpp — advanceFrame"
inline void advanceFrame(Scene& scene, double frameSeconds) {
    scene.substeps = 0;
    if (!scene.paused) {
        const auto plan = planFixedSteps(scene.accumulator, frameSeconds, scene.dt, 4, 0.05);
        scene.accumulator = plan.remainder;
        scene.droppedTime += plan.droppedTime;
        for (int i = 0; i < plan.steps; ++i) {
            if (!stepScene(scene))
                break;
        }
    }
}
```


Main đã có luồng gọi advanceFrame và phím N từ Starter. Trong nhánh N, substeps được đặt lại trước khi gọi stepScene; N luôn pause rồi tiến đúng một dt.

## Ghép các phần lại

Thêm nhánh chọn dt vào key-down của main.cpp:

```cpp title="src/main.cpp — chọn dt rồi dựng lại thí nghiệm"
if (key == SDLK_LEFTBRACKET || key == SDLK_RIGHTBRACKET) {
    const double steps[]{1.0 / 60.0, 1.0 / 120.0, 1.0 / 240.0};
    int index = scene.dt == steps[0] ? 0 : scene.dt == steps[1] ? 1
                                                                : 2;
    index = std::clamp(index + (key == SDLK_LEFTBRACKET ? -1 : 1), 0, 2);
    scene.dt = steps[index];
    lab::rebuildScene(scene);
}
```

Bấm N vài lần rồi chạy liên tục. Một bóng có vx=2 m/s sẽ đổi X đúng 2h mỗi bước, bất kể vị trí của nó được vẽ lại bao nhiêu lần. [ / ] chọn một trong ba dt: 1/60, 1/120, 1/240 s; đổi dt dựng lại thí nghiệm để dễ so.

Đừng thêm clamp vào phần tích phân để giữ bóng trong khung. Giới hạn hình học thuộc bài 3; clamp âm thầm ở đây sẽ che mất việc chưa có va chạm.

## Thử làm sai để hiểu đúng

1. Thay dt bằng 1. Bóng nhảy xa ở mỗi frame, tốc độ phụ thuộc FPS. Hoàn tác và đo lại displacement sau cùng số bước.

2. Tăng elapsed trong renderScene. Vẽ lại khi pause làm đồng hồ tăng dù Ball không chuyển động; số đo sau này sẽ sai thời điểm.

3. Bỏ giới hạn substep rồi đưa vào một frame rất dài. Vòng lặp phải làm hết công việc trước khi nhận input. Giữ hard cap và báo phần bị bỏ thay vì dùng thử trên UI không có watchdog.

## Tự kiểm tra kết quả

- N cho đúng một dt và pause; vẽ lại không tăng thời gian.
- Cùng tổng thời gian, các chuỗi frame 120×1/120 và 30×1/30 cho cùng state khi dt=1/120 và chưa vượt cap.
- Frame quá dài chỉ chạy nhiều nhất bốn bước; droppedTime thể hiện phần không xử lý.
- Bóng ra ngoài khung ở bài này không bị xóa hoặc teleport về trong bể.
