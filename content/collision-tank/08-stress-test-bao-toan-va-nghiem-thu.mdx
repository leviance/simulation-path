# Kiểm chứng bể 2D trước khi sang 3D

## Vấn đề cần giải quyết

Một bể bóng trông hợp lý vẫn có thể mất động lượng vì sai dấu hoặc đếm overlap sai thời điểm. Trước khi thêm trục Z, ta cần phân biệt rõ thứ gì phải được giữ nguyên và thứ gì đang nhận tác động từ bên ngoài.

Đây là **mốc kiểm chứng bể 2D**, chưa phải kết thúc Project 24. Phần sphere 3D và renderer còn ở ba bài sau.

## Hiểu ý tưởng trước khi viết code

Cặp cô lập chỉ nhận hai impulse đối nhau, nên giữ tổng động lượng. Với e=1, nó cũng giữ động năng. Khi e&lt;1, động năng giảm là kết quả mong đợi.

Riêng đàn bóng trong bể không phải hệ cô lập: tường đổi động lượng của nó. Vì đã lưu xung lực tường, ta kiểm:

$$
P=\sum_i m_i v_i,\quad K=\sum_i\frac12m_i\|v_i\|^2,
\qquad residual=\left\|P-P_0-\sum J_{wall}\right\|.
$$

Không bắt P cố định khi bóng nảy vào tường. Độ xuyên còn lại cũng phải quét trên **state sau solver và lần khóa tường cuối**, không lấy maximumPenetration đã ghi trong lúc giải.

History ghi t=0 và từng physics step, giữ tối đa 601 mẫu. Hai đồ thị K (J) và độ xuyên (m) dùng thang dọc riêng; một đường thấp không có nghĩa đại lượng đó gần zero nếu chưa đọc scale.

### Bước 1 — Đo độc lập với solver

Thêm WorldMetrics và measureWorld vào lab.hpp:

```cpp title="include/lab.hpp — WorldMetrics"
struct WorldMetrics {
    Vec2 totalMomentum{};
    double kineticEnergy{};
    std::size_t overlapCount{};
    double maximumPenetration{};
    bool finite{true};
};
```


```cpp title="include/lab.hpp — measureWorld"
inline WorldMetrics measureWorld(const std::vector<Ball>& balls) {
    WorldMetrics metrics{};
    for (const Ball& ball : balls) {
        if (!finiteBall(ball)) {
            metrics.finite = false;
            continue;
        }
        if (ball.inverseMass <= kCollisionEpsilon) {
            continue;
        }
        const double mass = 1.0 / ball.inverseMass;
        metrics.totalMomentum = add(metrics.totalMomentum, scale(ball.velocity, mass));
        metrics.kineticEnergy += 0.5 * mass * lengthSquared(ball.velocity);
    }
    for (std::size_t firstIndex = 0; firstIndex < balls.size(); ++firstIndex) {
        for (std::size_t secondIndex = firstIndex + 1; secondIndex < balls.size(); ++secondIndex) {
            const CircleContact contact = findCircleContact(balls[firstIndex], balls[secondIndex]);
            if (!contact.colliding) {
                continue;
            }
            ++metrics.overlapCount;
            metrics.maximumPenetration = std::max(metrics.maximumPenetration, contact.penetration);
        }
    }
    return metrics;
}
```


Lượt quét overlap này tốn N(N−1)/2 checks riêng. Nó không nằm trong stats.pairChecks của solver. Không quảng bá cả chương trình chỉ có đúng từng ấy phép kiểm hình học.

### Bước 2 — Mở mốc đo và ghi từng bước

Trong Scene thêm metrics, initialEnergy, initialMomentum, wallImpulse và deque history như source ở cuối bài. Thay beginMeasurement để lấy đúng baseline:

```cpp title="include/scene.hpp — beginMeasurement"
inline void beginMeasurement(Scene& scene) {
    stopScene(scene);
    scene.elapsed = 0.0;
    scene.droppedTime = 0.0;
    scene.substeps = 0;
    scene.stats = {};
    scene.metrics = measureWorld(scene.balls);
    scene.initialEnergy = scene.metrics.kineticEnergy;
    scene.initialMomentum = scene.metrics.totalMomentum;
    scene.wallImpulse = {};
    scene.history.clear();
    scene.history.push_back({0.0, scene.initialEnergy, scene.metrics.maximumPenetration});
}
```


Trong nhánh 2D của stepScene sau khi nhận candidate:

```cpp title="include/scene.hpp — cộng xung lực ngoài và đo state mới"
scene.metrics = measureWorld(scene.balls);
scene.initialEnergy = scene.metrics.kineticEnergy;
```


Sau khi tăng elapsed, thêm phần ghi mẫu và giới hạn bộ đệm:

```cpp title="include/scene.hpp — một mẫu cho mỗi bước physics"
double energy = scene.metrics.kineticEnergy;
double penetration = scene.metrics.maximumPenetration;
scene.history.push_back({scene.elapsed, energy, penetration});
if (scene.history.size() > 601)
    scene.history.pop_front();
return true;
```


Thêm momentumResidual:

```cpp title="include/scene.hpp — momentumResidual"
inline double momentumResidual(const Scene& scene) {
    return length(subtract(subtract(scene.metrics.totalMomentum, scene.initialMomentum), scene.wallImpulse));
}
```


Mở toàn bộ scene.hpp của checkpoint 08 để ghép các member. Thêm requestFast và thay advanceFrame bằng hai hàm sau:

```cpp title="include/scene.hpp — requestFast"
inline void requestFast(Scene& scene) {
    stopScene(scene);
    scene.fastRemaining = static_cast<int>(std::lround(2.0 / scene.dt));
}
```


```cpp title="include/scene.hpp — advanceFrame"
inline void advanceFrame(Scene& scene, double frameSeconds) {
    scene.substeps = 0;
    if (scene.fastRemaining > 0) {
        const int count = std::min(4, scene.fastRemaining);
        for (int i = 0; i < count; ++i) {
            if (!stepScene(scene))
                break;
            --scene.fastRemaining;
        }
        return;
    }
    if (!scene.paused) {
        const auto plan = planFixedSteps(scene.accumulator, frameSeconds, scene.dt, 4, 0.05);
        scene.accumulator = plan.remainder;
        scene.droppedTime += plan.droppedTime;
        for (int i = 0; i < plan.steps; ++i) {
            if (!stepScene(scene))
                break;
        }
    }
}
```

 Job chỉ gọi tối đa bốn bước mỗi frame; không nhét toàn bộ hai giây mô phỏng vào một event handler.

### Bước 3 — Dùng test có đáp án không phụ thuộc solver

Bộ tests đã nằm trong ZIP. Trong tests.cpp, kiểm cặp equal mass bằng đáp án đổi vận tốc; trong extra-cases.hpp có ca khác khối lượng và đàn 256 bóng. C++ không dùng assert bị loại bởi NDEBUG.

Ở bài này, target tests có thể kiểm trực tiếp phần Starter 2D. Đổi đường include trong CMake:
```cmake title="CMakeLists.txt — kiểm bài làm, không chỉ bản final tham khảo"
target_include_directories(project_24_tests PRIVATE starter/include)
```

Rồi build và chạy hai cấu hình:
```powershell title="Kiểm phần 2D của Starter"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON -DBUILD_TESTING=ON
cmake --build build --config Debug --target project_24_starter project_24_tests --parallel 2
ctest --test-dir build -C Debug --output-on-failure --timeout 45
cmake --build build --config Release --target project_24_starter project_24_tests --parallel 2
ctest --test-dir build -C Release --output-on-failure --timeout 45
```

Phần 3D chưa được bật trong Starter nên output mới có nhóm 2D. Không lấy lượt này làm bằng chứng rằng toàn bộ Project 24 đã xong.

## Thử làm sai để hiểu đúng

1. Assert P không đổi trong một bể có tường. Test có thể báo lỗi dù phản xạ đúng. Thay bằng cân bằng xung lực hoặc chọn riêng cặp cô lập.

2. Đo overlap trước khi correction rồi gọi nó là phần xuyên còn lại. So lại bằng một lượt quét sau solver.

3. Ghi history mỗi render frame. Khi pause mà redraw, số mẫu vẫn tăng; tốc độ vẽ đã làm thay đổi thống kê.
