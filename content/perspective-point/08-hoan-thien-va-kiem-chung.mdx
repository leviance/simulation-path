## Hiểu ý tưởng trước khi viết code

Round-trip rất hữu ích nhưng không phải bằng chứng duy nhất. Nếu chiều xuôi và chiều ngược cùng sai một quy ước, chúng vẫn có thể trả về điểm cũ.

Vì vậy cần một oracle tính tay. Chọn FOV90°, viewport origin (10,20), width800, height600. focalPixels=600/2=300. Với P=(1,0.5,4), camera tại origin:

$$
s_x=10+400+300\frac{1}{4}=485,\quad
s_y=20+300-300\frac{0.5}{4}=282.5.
$$

Đổi riêng Z=8 cho (447.5,301.25). Ví dụ này đồng thời kiểm perspective, Y flip và viewport origin.

Lỗi round-trip chỉ có nghĩa khi point visible và inverse có kết quả. Điểm sau camera trả “không xác định”, không phải 0 rồi được tính là một test thành công.

### Bước 2 — Viết test với đáp án độc lập

```cpp title="tests/tests.cpp — pixel biết trước, không lấy expected từ inverse"
void knownProjection() {
    const lab::Camera3D camera{};
    lab::PerspectiveLens lens;
    lens.verticalFovRadians = lab::kPi * 0.5;
    const lab::Viewport viewport{10.0, 20.0, 800.0, 600.0};
    // Tính tay bằng focalPixels = 300, không gọi inverse để tạo expected.
    const auto point = lab::projectPerspective({1.0, 0.5, 4.0}, camera, lens, viewport);
    check(point.status == lab::ProjectionStatus::Visible && point.screen.has_value(), "analytic point visible");
    check(close(point.screen->x, 485.0) && close(point.screen->y, 282.5), "independent analytic pixel");
    const auto farther = lab::projectPerspective({1.0, 0.5, 8.0}, camera, lens, viewport);
    check(close(farther.screen->x, 447.5) && close(farther.screen->y, 301.25), "double depth halves displacement");
    const auto centered = lab::projectPerspective({0.0, 0.0, 4.0}, camera, lens, viewport);
    check(close(centered.screen->x, 410.0) && close(centered.screen->y, 320.0), "viewport origin included");
    const auto translated = lab::worldToCamera({3.0, 2.0, 8.0}, {{1.0, -1.0, 2.0}});
    check(close(translated.x, 2.0) && close(translated.y, 3.0) && close(translated.z, 6.0), "world minus camera");
}
```

Tests còn kiểm near/far chính xác, invalid FOV/viewport/NaN, giao điểm clipping tính tay, ảnh CPU có lưới/marker ở clean mode và không vẽ marker behind. check ghi failure và trả EXIT_FAILURE; không dùng assert bị tắt ở Release.

### Bước 3 — Bổ sung round-trip, không lạm dụng nó

```cpp title="include/lab.hpp — không báo lỗi bằng zero khi phép đo chưa xác định"
inline std::optional<double> projectionRoundTripError(Vec3 point, const Camera3D& camera, const PerspectiveLens& lens, const Viewport& viewport) {
    const ProjectionResult projected = projectPerspective(point, camera, lens, viewport);
    if (projected.status != ProjectionStatus::Visible || !projected.screen) {
        return std::nullopt;
    }
    const auto restored = screenToCameraAtDepth(*projected.screen, projected.cameraPoint.z, lens, viewport);
    if (!restored) {
        return std::nullopt;
    }
    return std::hypot(restored->x - projected.cameraPoint.x, restored->y - projected.cameraPoint.y, restored->z - projected.cameraPoint.z);
}
```

Chạy trên nhiều FOV, aspect và depth hợp lệ. Mục tiêu error nhỏ hơn 10⁻⁹ world; nó bổ sung cho numeric oracle, không thay thế oracle.

## Ghép các phần lại

**Project 11 đã hoàn chỉnh.** Scene có point 3D thật, perspective tự viết, cảnh nền world, WASD/QE, camera tịnh tiến, FOV/aspect, near/far, quỹ đạo, pause/step/reset/preset, kéo chuột và clean/debug mode.

ZIP chứa README, CMakeLists.txt, starter, tám checkpoint, final và tests. Phần **Toàn bộ mã nguồn của dự án** phía dưới hiển thị đủ file, không chỉ một hàm rời. CMake dùng C++20, khóa SDL 3.4.8 và link SDL3::SDL3. Mặc định build target final; bật BUILD_CHECKPOINTS khi học từng bước.

```powershell title="Build tất cả target và kiểm chứng hai cấu hình"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --parallel 2
ctest --test-dir build -C Debug --output-on-failure --timeout 30
.\build\Debug\project_11_final.exe
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure --timeout 30
.\build\Release\project_11_final.exe
```

Không cần tự viết lại các file từ trí nhớ: final là bản hoàn chỉnh. lab.hpp giữ math/guard/inverse, scene.hpp giữ state/quỹ đạo/preset, framebuffer.hpp và view.hpp vẽ CPU, presentation.hpp đưa texture/chữ lên SDL, main.cpp quản lý input/lifecycle. Canvas không thay executable này.

Giới hạn có chủ ý: camera chưa xoay, marker là đĩa biểu diễn một point chứ không phải sphere mesh, scene wireframe chưa xử lý che khuất. Window resize letterbox bảng logic, V/Aspect mới đổi hình dạng viewport thật. Các giới hạn này không làm mất phép chiếu x/z,y/z đã tự xây.

## Thử làm sai để hiểu đúng

1. Cho projectPerspective luôn trả tâm màn hình, đồng thời sửa inverse để luôn trả point đầu vào. Một round-trip được dựng sai có thể vẫn xanh, nhưng test pixel (485,282.5) sẽ đỏ. Khôi phục và giữ oracle độc lập.

2. Tắt debug bằng F rồi thử FOV, depth, pause/step. Cảnh nền và point vẫn phải có chiều sâu. Nếu chúng biến mất, hãy tách debug overlay khỏi geometry.

3. Cố đưa test thất bại rồi chạy Release. CTest phải trả failure; sau đó khôi phục test. Không chấp nhận suite chỉ hoạt động ở Debug.

## Tự kiểm tra kết quả

- Numeric oracle đúng ở FOV90°, viewport origin khác 0; tăng depth gấp đôi giảm displacement một nửa.
- Depth/lens/viewport invalid không tới rasterizer; near/far boundary đúng.
- Round-trip được kiểm nhiều lens/aspect/depth, không tự báo zero cho điểm bị loại.
- Ảnh CPU clean vẫn có grid và marker; behind không vẽ marker.
- Cùng elapsed cho cùng quỹ đạo; manual input dừng auto, dt stall có cap.
- Starter, tám checkpoint, final và tests build Debug/Release; CTest chạy không cần window.
- Hidden --smoke kiểm init/present/resize/thoát, không thay kiểm thử mouse/keyboard/DPI trực tiếp.
- QA desktop còn cần thả chuột ngoài, mất focus, chuyển bài, reduced-motion và reload; không khẳng định đã kiểm nếu chưa mở server.
