# Vì sao điểm ở xa tiến về tâm?

## Vấn đề cần giải quyết

Ở bài trước, bạn đã dịch chuyển được điểm và camera. Nhưng hãy giữ nguyên X/Y rồi tăng Z từ 4 lên 8: điểm vẫn nằm ở chỗ cũ. Bản xem trước mới bỏ qua Z, nên nó chưa thể hiện được khoảng cách tới camera.

Bài này ta sẽ dùng cả ba tọa độ để tìm vị trí của điểm trên màn hình. Trước mắt chỉ cần một điểm sáng; đến bài 5, khi đã biết cách cắt đoạn ở near/far, ta mới thêm lưới và các khung 3D.

## Hiểu ý tưởng trước khi viết code

Hãy nhìn không gian từ bên cạnh. Camera nằm ở gốc tọa độ, nhìn theo +Z. Kẻ một tia từ camera đi qua điểm P(x,y,z), rồi đặt một mặt phẳng ảnh tưởng tượng ở Z=1. Vị trí tia xuyên qua mặt phẳng đó chính là ảnh của P.

Trong mặt cắt XZ, hai tam giác có chung góc tại camera và đều có một góc vuông. Đó là hai tam giác đồng dạng, nên tỉ lệ giữa cạnh đứng và cạnh ngang bằng nhau. Làm tương tự với YZ:

$$
\frac{x'}{1}=\frac{x}{z},\qquad \frac{y'}{1}=\frac{y}{z}.
$$

Vì thế x′=x/z, y′=y/z. Với P=(1,0.5,4), ta được (0.25,0.125). Nếu giữ nguyên X/Y và đưa điểm ra Z=8, kết quả còn (0.125,0.0625). Điểm càng xa, tia càng gần trục nhìn, nên ảnh càng gần tâm. Ta thu hẹp **độ lệch khỏi tâm**, không chia tọa độ pixel tuyệt đối.

Trong bài này focal scale tạm bằng 1, tương đương vertical FOV 90°. Bài 4 mới thay hệ số đó bằng thông số FOV có thể điều chỉnh. Ta cũng viết các nhánh kiểm tra near/far ngay từ lần chiếu đầu tiên để không chia cho Z=0; bài 5 sẽ giải thích kỹ từng trường hợp bị loại.

Trong hình nhìn ngang bên dưới viewport, chọn mặt cắt XZ. Đặt camera về (0,0,0), giữ Point.X=1, rồi đổi Point.Z từ 4 lên 8. Cạnh đứng của tam giác lớn không đổi, cạnh ngang dài gấp đôi; cạnh đứng của tam giác nhỏ vì thế giảm một nửa. Đổi sang YZ để kiểm tra cùng lập luận cho y/z.

### Bước 1 — Viết phép chia từ tỉ lệ vừa suy ra

```cpp title="include/lab.hpp — tọa độ trên mặt phẳng ảnh depth 1"
inline Vec2 perspectiveDivide(Vec3 cameraPoint) {
    return {cameraPoint.x / cameraPoint.z, cameraPoint.y / cameraPoint.z};
}
```

Hàm nhỏ này không tự biết near plane. Caller có trách nhiệm kiểm depth trước; không gọi nó tùy tiện ở mọi nơi trong renderer.

### Bước 2 — Ghép thành phép chiếu có guard

Thêm các khai báo dưới vào namespace lab, sau worldToCamera/cameraToWorld và trước projectPerspective. ProjectionResult có cameraPoint và hai optional là ndc/screen. isInsideNdc cũng phải có trước khi projectPerspective gọi nó.

```cpp title="include/lab.hpp — khai báo trước projectPerspective"
enum class ProjectionStatus {
    Visible,
    BehindCamera,
    BeforeNearPlane,
    BeyondFarPlane,
    OutsideFrustum,
    Invalid,
};

struct ProjectionResult {
    ProjectionStatus status = ProjectionStatus::Invalid;
    Vec3 cameraPoint{};
    std::optional<Vec2> ndc;
    std::optional<Vec2> screen;
};

inline bool validLens(const PerspectiveLens& lens, const Viewport& viewport) {
    return std::isfinite(lens.verticalFovRadians) && lens.verticalFovRadians > 0.0 && lens.verticalFovRadians < kPi &&
        std::isfinite(lens.nearPlane) && std::isfinite(lens.farPlane) && lens.nearPlane > 0.0 && lens.farPlane > lens.nearPlane &&
        std::isfinite(viewport.x) && std::isfinite(viewport.y) && std::isfinite(viewport.width) && std::isfinite(viewport.height) && viewport.width > 0.0 && viewport.height > 0.0;
}
inline bool isInsideNdc(Vec2 ndc) {
    return std::abs(ndc.x) <= 1.0 && std::abs(ndc.y) <= 1.0;
}
```

Chưa cần học hết enum ngay: bài 5 sẽ giải thích ý nghĩa từng nhánh. Chúng có mặt sớm để bản chạy thử luôn an toàn.

```cpp title="include/lab.hpp — pipeline an toàn với focal scale tạm"
inline ProjectionResult projectPerspective(Vec3 worldPoint, const Camera3D& camera, const PerspectiveLens& lens, const Viewport& viewport) {
    ProjectionResult result;
    if (!finite(worldPoint) || !finite(camera.position) || !validLens(lens, viewport)) {
        return result;
    }
    const Vec3 cameraPoint = worldToCamera(worldPoint, camera);
    result.cameraPoint = cameraPoint;
    if (!finite(cameraPoint)) {
        return result;
    }
    // Các guard đã có từ bài 3 để checkpoint không chia cho 0.
    // Bài 5 giải thích và đưa từng trạng thái ra giao diện.
    if (cameraPoint.z <= 0.0) {
        result.status = ProjectionStatus::BehindCamera;
        return result;
    }
    if (cameraPoint.z < lens.nearPlane) {
        result.status = ProjectionStatus::BeforeNearPlane;
        return result;
    }
    if (cameraPoint.z > lens.farPlane) {
        result.status = ProjectionStatus::BeyondFarPlane;
        return result;
    }
    const double aspectRatio = viewport.width / viewport.height;
    const Vec2 divided = perspectiveDivide(cameraPoint);
    // Ở bài 3 mặt phẳng ảnh tạm có focal scale = 1.
    const Vec2 ndc{divided.x / aspectRatio, divided.y};
    const Vec2 screen{viewport.x + viewport.width * 0.5 + ndc.x * viewport.width * 0.5, viewport.y + viewport.height * 0.5 - ndc.y * viewport.height * 0.5};
    if (!std::isfinite(ndc.x) || !std::isfinite(ndc.y) || !std::isfinite(screen.x) || !std::isfinite(screen.y)) {
        return result;
    }
    result.ndc = ndc;
    result.screen = screen;
    result.status = ProjectionStatus::OutsideFrustum;
    if (isInsideNdc(ndc)) {
        result.status = ProjectionStatus::Visible;
    }
    return result;
}
```

Theo thứ tự: kiểm finite/lens, đổi world sang camera, chặn depth, mới divide và chuyển về screen. X chia aspect để hình tròn không bị kéo rộng khi viewport không vuông. result.screen là optional: thiếu giá trị nghĩa là chưa có ảnh hợp lệ, không phải marker ở góc (0,0).

### Bước 3 — Đưa kết quả vào framebuffer

Hàm chiếu chỉ tính toán, không tự vẽ pixel. Trong view.hpp, thay toàn bộ renderScene cũ bằng hàm dưới. Không giữ lưới XY và nhánh preview nữa: chúng thuộc bản xem trước, không phải cảnh perspective.

```cpp title="include/view.hpp — perspective áp dụng cho vị trí và bán kính"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear(kBackground);
    const Viewport viewport = viewportFor(scene);
    [[maybe_unused]] const Vec2 center{viewport.x + viewport.width * 0.5, viewport.y + viewport.height * 0.5};
    const auto projected = projectPerspective(scene.point, scene.camera, scene.lens, viewport);
    if (projected.status == ProjectionStatus::Visible && projected.screen) {
        // Bán kính world 0.12, vị trí cũng được chiếu perspective; không giả depth bằng size.
        double focalPixels = viewport.height * 0.5;
        const int radius = static_cast<int>(std::clamp(std::lround(0.12 * focalPixels / projected.cameraPoint.z), 3L, 30L));
        drawPointMarker(image, *projected.screen, radius, viewport, scene.debug);
    }
}
```

`projectPerspective` trả tọa độ liên tục; `drawPointMarker` mới làm tròn và tô pixel. Chỉ vẽ khi status là Visible **và** screen có giá trị. Như vậy một điểm bị loại không bị vẽ nhầm ở góc (0,0).

Bán kính world 0.12 cũng chia cho Z, nhưng bị giới hạn trong [3,30] pixel để marker dễ nhìn. Đây chỉ là ký hiệu của điểm sáng, chưa phải bộ vẽ hình cầu. Điều cần kiểm tra ở bài này là **tâm marker đổi vị trí**, không chỉ kích thước của nó.

## Ghép các phần lại

### Hiển thị số đo của phép chiếu

HUD cũ vẫn ghi “XY PREVIEW ONLY”. Thêm statusText rồi **thay presentFramebuffer** trong presentation.hpp bằng hai hàm dưới; không giữ cả hai phiên bản presentFramebuffer. Chúng chỉ đọc kết quả để hiển thị, không tự chiếu lại theo một công thức khác. NDC/screen bị loại sẽ hiện “undefined” thay cho tọa độ giả.

```cpp title="include/presentation.hpp — tên của từng trạng thái"
inline const char* statusText(ProjectionStatus status) {
    switch (status) {
    case ProjectionStatus::Visible:
        return "visible";
    case ProjectionStatus::BehindCamera:
        return "behind";
    case ProjectionStatus::BeforeNearPlane:
        return "before-near";
    case ProjectionStatus::BeyondFarPlane:
        return "beyond-far";
    case ProjectionStatus::OutsideFrustum:
        return "outside";
    default:
        return "invalid";
    }
}
```

```cpp title="include/presentation.hpp — số đo đi cùng ảnh perspective"
inline bool presentFramebuffer(SDL_Renderer* renderer, SDL_Texture* texture, const Scene& scene) {
    // Letterbox phải dùng màu nền, không dùng lại màu chữ của frame trước.
    if (!SDL_SetRenderDrawColor(renderer, 17, 24, 43, 255) || !SDL_RenderClear(renderer) || !SDL_RenderTexture(renderer, texture, nullptr, nullptr) || !SDL_SetRenderDrawColor(renderer, 225, 232, 250, 255)) {
        return false;
    }
    if (!text(renderer, 16, 14, "PROJECT 11 | WASD: XY, Q/E: Z | IJKL U/O: camera | +/- FOV | V aspect | R reset | Esc quit") || !text(renderer, 16, 34, "F1 default, F2 far, F3 near, F4 behind, F5 beyond-far, F6 outside | [ ] near, ; ' far")) {
        return false;
    }
    char value[230]{};
    std::snprintf(value, sizeof(value), "world (%.3f, %.3f, %.3f) | camera at (%.2f, %.2f, %.2f)", scene.point.x, scene.point.y, scene.point.z, scene.camera.position.x, scene.camera.position.y, scene.camera.position.z);
    if (!text(renderer, 16, 58, value)) {
        return false;
    }
    const auto projected = projectPerspective(scene.point, scene.camera, scene.lens, viewportFor(scene));
    std::snprintf(value, sizeof(value), "camera point (%.3f, %.3f, %.3f) | status %s", projected.cameraPoint.x, projected.cameraPoint.y, projected.cameraPoint.z, statusText(projected.status));
    if (!text(renderer, 16, 80, value)) {
        return false;
    }
    if (projected.screen && projected.ndc) {
        std::snprintf(value, sizeof(value), "NDC (%.4f, %.4f) -> screen (%.2f, %.2f), continuous viewport coordinates", projected.ndc->x, projected.ndc->y, projected.screen->x, projected.screen->y);
    } else {
        std::snprintf(value, sizeof(value), "NDC / screen: undefined (depth rejected before division)");
    }
    if (!text(renderer, 16, 724, value)) {
        return false;
    }
    return SDL_RenderPresent(renderer);
}
```

Build lại project_11_starter. Giữ nguyên X/Y, dùng Q/E thay Z và đọc số đo trên HUD. Với viewport mặc định, tâm là (550,400), focalPixels=292.5. P=(1,0.5,4) phải tới (623.125,363.4375); đổi Z thành 8 được (586.5625,381.71875). Hai độ lệch (73.125,−36.5625) và (36.5625,−18.28125) đúng là hơn kém nhau hai lần.

Các giá trị này dùng FOV tạm 90° của riêng bài 3. Không lấy số đo từ bài 4–8 đang dùng FOV mặc định 60° để so trực tiếp.

## Thử làm sai để hiểu đúng

1. Thay x/z bằng x, giữ nguyên code đổi size marker. Bạn sẽ thấy đĩa nhỏ hơn nhưng tâm không tiến về giữa. Đó là fake depth; khôi phục perspectiveDivide.

2. Chọn preset Xa gấp đôi: X/Y giữ nguyên, Z tăng 4→8. Đo displacement so với tâm: cả X và Y phải giảm một nửa. Đừng so trực tiếp screen.x của hai lần.

3. Bỏ guard rồi thử Z=0 là một thí nghiệm trên bản sao, không đưa vào bản final. Dự đoán Inf/NaN, sau đó giữ lại guard để lỗi không tới rasterizer.

## Tự kiểm tra kết quả

- cameraPoint được tính trước phép chia và world point không bị sửa.
- Z tăng gấp đôi làm displacement giảm một nửa.
- Điểm được vẽ bằng projectPerspective, không còn đi qua previewPoint.
- Point behind/near không đi vào chia; NDC/screen bị loại được ghi là undefined.
- Ở checkpoint 3 focal scale bằng 1, không giả rằng lens FOV đã hoạt động.
