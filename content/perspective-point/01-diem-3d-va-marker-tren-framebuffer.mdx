# Vẽ điểm sáng và điều khiển ba tọa độ

## Vấn đề cần giải quyết

Ở Project 10, bạn đã dùng một camera helper để nhìn các vector trong không gian. Bây giờ ta sẽ tự xây phần chiếu đó từ đầu. Nhưng trước khi bàn đến phối cảnh, hãy làm một việc nhìn thấy được: vẽ một điểm sáng và điều khiển vị trí của nó.

Tải ZIP ở trang tổng quan, giải nén rồi mở thư mục có CMakeLists.txt. Starter đã có window, renderer, texture và framebuffer CPU từ Project 01. Các file được tách theo việc chúng làm: lab.hpp giữ kiểu toán học, scene.hpp giữ state, view.hpp vẽ pixel, presentation.hpp đưa ảnh lên SDL, main.cpp quản lý vòng lặp và input. Starter chỉ hiện nền; bài này thêm điểm sáng.

## Hiểu ý tưởng trước khi viết code

Ta lưu vị trí bằng ba số, nhưng tạm vẽ hai số đầu trên một lưới song song:

$$
s_x=c_x+70x,\qquad s_y=c_y-70y.
$$

70 là số pixel trên một world unit của bản xem trước. Dấu trừ ở Y đổi quy ước Y hướng lên trong world sang Y hướng xuống trên màn hình. Z vẫn nằm trong dữ liệu, chỉ chưa tham gia phép vẽ. Đây **không phải perspective projection**; nếu tăng Z mà hình chưa đổi, checkpoint này vẫn đúng.

Điểm sáng không phải một pixel quá nhỏ để quan sát. Ta vẽ một đĩa xanh có tâm trắng và crosshair vàng. Bán kính lúc này cố định 10 pixel; đến bài 3 cả vị trí lẫn kích thước sẽ phụ thuộc độ sâu.

### Bước 1 — Tạo dữ liệu trước khi vẽ

```cpp title="include/lab.hpp — một vị trí có ba thành phần"
struct Vec3 {
    double x{};
    double y{};
    double z{};
};
```

Scene là nơi lưu state của chương trình, tách khỏi framebuffer:

```cpp title="include/scene.hpp — point và các biến cấu hình giữ nguyên qua frame"
struct Scene {
    Vec3 point{1.0, 0.6, 4.0};
    Camera3D camera{};
    PerspectiveLens lens{};
    int aspect = 0;
    bool paused = true;
    bool debug = true;
    double elapsed = 0.0;

```

camera, lens, elapsed và debug đã có trong khung để các checkpoint dùng chung cấu trúc; hai bài đầu chưa dùng chúng để chiếu. point khởi đầu tại (1,0.6,4). Đừng đổi point thành pixel rồi ghi ngược vào state. Hàm previewPoint chỉ trả một Vec2 tạm:

```cpp title="include/lab.hpp — bản xem trước XY"
inline Vec2 previewPoint(Vec3 point) {
    return {point.x * 70.0, point.y * 70.0};
}
```

### Bước 2 — Tự vẽ marker vào framebuffer

```cpp title="include/view.hpp — vẽ từng pixel của điểm sáng"
inline void drawPointMarker(Framebuffer& image, Vec2 center, int radius, const Viewport& viewport, bool debug) {
    const int cx = static_cast<int>(std::lround(center.x));
    const int cy = static_cast<int>(std::lround(center.y));
    for (int y = -radius; y <= radius; ++y) {
        for (int x = -radius; x <= radius; ++x) {
            const int px = cx + x;
            const int py = cy + y;
            if (px < viewport.x || px >= viewport.x + viewport.width || py < viewport.y || py >= viewport.y + viewport.height) {
                continue;
            }
            const int distanceSquared = x * x + y * y;
            if (distanceSquared <= radius * radius) {
                std::uint32_t color = kShape;
                if (distanceSquared < radius * radius / 4) {
                    color = kWhite;
                }
                image.putPixel(px, py, color);
            }
            if (debug && (x == 0 || y == 0)) {
                image.putPixel(px, py, kMarker);
            }
        }
    }
}
```

Hai vòng lặp xét một hình vuông nhỏ quanh tâm. Điều kiện x²+y²≤r² giữ lại phần đĩa; phần giữa dùng màu trắng. Kiểm tra viewport chạy trước putPixel để marker không ghi sang vùng chữ. renderScene lấy preview, cộng tâm viewport và gọi hàm này. Đọc cả hàm để biết chính xác ảnh được ghép ở đâu:

```cpp title="include/view.hpp — từ world point tới ảnh xem trước"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear(kBackground);
    const Viewport viewport = viewportFor(scene);
    [[maybe_unused]] const Vec2 center{viewport.x + viewport.width * 0.5, viewport.y + viewport.height * 0.5};
    // Bản xem trước song song chỉ để kiểm framebuffer/input ở hai bài đầu.
    for (int offset = -280; offset <= 280; offset += 70) {
        drawLine(image, 550 + offset, 120, 550 + offset, 680, kGrid);
        drawLine(image, 30, 400 + offset, 1070, 400 + offset, kGrid);
    }
    Vec3 point = scene.point;
    const Vec2 preview = previewPoint(point);
    drawPointMarker(image, {center.x + preview.x, center.y - preview.y}, 10, viewport, true);
}
```

### Bước 3 — Bắt phím rồi cập nhật theo dt

W/A/S/D đổi Y/X; Q đưa điểm lại gần camera bằng cách giảm Z, E tăng Z. Đọc SDL_GetKeyboardState sau khi đã PollEvent. Dùng scancode, không dùng keycode làm chỉ số mảng. Đây là khối input trong main.cpp:

```cpp title="src/main.cpp — giữ phím và đi với tốc độ 2 world/s"
const bool* keys = SDL_GetKeyboardState(nullptr);
lab::Vec3 direction{};
if (keys[SDL_SCANCODE_A]) {
    direction.x -= 1.0;
}
if (keys[SDL_SCANCODE_D]) {
    direction.x += 1.0;
}
if (keys[SDL_SCANCODE_W]) {
    direction.y += 1.0;
}
if (keys[SDL_SCANCODE_S]) {
    direction.y -= 1.0;
}
if (keys[SDL_SCANCODE_Q]) {
    direction.z -= 1.0;
}
if (keys[SDL_SCANCODE_E]) {
    direction.z += 1.0;
}
const double length = std::hypot(direction.x, direction.y, direction.z);
if (length > 0.0 && (SDL_GetWindowFlags(window) & SDL_WINDOW_INPUT_FOCUS) != 0) {
    const double distance = 2.0 * deltaTime / length;
    lab::movePoint(scene, {direction.x * distance, direction.y * distance, direction.z * distance});
    dirty = true;
}
```

```cpp title="include/scene.hpp — input tay sửa world point, không sửa pixel"
inline void movePoint(Scene& scene, Vec3 delta) {
    if (!finite(delta)) {
        return;
    }
    scene.point.x = std::clamp(scene.point.x + delta.x, -6.0, 6.0);
    scene.point.y = std::clamp(scene.point.y + delta.y, -6.0, 6.0);
    scene.point.z = std::clamp(scene.point.z + delta.z, -2.0, 20.0);
    scene.paused = true;
}
```

movePoint từ chối delta không hữu hạn trước khi sửa bất kỳ thành phần nào. Clamp là giới hạn vùng điều khiển world, không phải clamp kết quả projection lên cạnh màn hình.

length chuẩn hóa hướng khi giữ nhiều phím để đi chéo không nhanh hơn. distance=2×dt/length chia đều quãng đường cho ba thành phần. Chỉ nhận input khi window có focus; movePoint giới hạn vùng di chuyển và đặt paused=true. Cuối frame, ảnh CPU được chuyển lên texture bằng SDL_UpdateTexture:

## Thử làm sai để hiểu đúng

1. Đổi dấu trừ trước preview.y thành dấu cộng. W sẽ kéo điểm xuống dù Y tăng. Khôi phục dấu trừ và giải thích hai quy ước trục.

2. Bỏ deltaTime khỏi distance rồi chạy ở nhiều tốc độ frame. Điểm sẽ chạy nhanh chậm theo máy. Khôi phục speed×dt; không dùng key-repeat để đo vận tốc.

3. Giữ W+D rồi chỉ giữ D trong cùng thời gian. Hai quãng đường world phải bằng nhau nhờ normalize, không phải hai thành phần đều chạy với tốc độ 2.
