# Kéo điểm mà không làm mất depth

## Vấn đề cần giải quyết

Marker đã đi tới đúng pixel. Bây giờ hãy kéo nó bằng chuột. Bài toán ngược có một điểm dễ nhầm: một pixel không xác định duy nhất một vị trí 3D. Cả một tia đi qua camera đều chiếu tới pixel đó.

## Hiểu ý tưởng trước khi viết code

Ta chọn giữ camera-space depth hiện tại. Khi đã biết z, đảo các công thức là đủ:

$$
n_x=\frac{2(s_x-v_x)}{w}-1,\quad n_y=1-\frac{2(s_y-v_y)}{h},
$$
$$
x=n_x z\tan(vFOV/2)a,\quad y=n_y z\tan(vFOV/2).
$$

Kết quả là camera point; cộng camera.position mới trở về world point. Đừng giữ world Z bằng cách đoán khi camera thay đổi; thao tác kéo lưu cameraDepth rồi cố định camera/lens cho tới khi thả.

Nhấn lên mép marker không được làm tâm nhảy đến chuột. Lưu grabOffset=mouse−screenCenter; khi kéo, targetCenter=mouse−grabOffset. Chỉ một pointer được quyền điều khiển thao tác.

### Bước 1 — Viết inverse với depth bắt buộc

```cpp title="include/lab.hpp — chọn một điểm trên tia tại depth đã biết"
inline std::optional<Vec3> screenToCameraAtDepth(Vec2 screen, double depth, const PerspectiveLens& lens, const Viewport& viewport) {
    if (!validLens(lens, viewport) || !std::isfinite(screen.x) || !std::isfinite(screen.y) || !std::isfinite(depth) || depth < lens.nearPlane || depth > lens.farPlane) {
        return std::nullopt;
    }
    const Vec2 ndc{(screen.x - viewport.x) * 2.0 / viewport.width - 1.0, 1.0 - (screen.y - viewport.y) * 2.0 / viewport.height};
    const double tanHalfFov = std::tan(lens.verticalFovRadians * 0.5);
    const double aspectRatio = viewport.width / viewport.height;
    const Vec3 point{ndc.x * depth * tanHalfFov * aspectRatio, ndc.y * depth * tanHalfFov, depth};
    if (!finite(point)) {
        return std::nullopt;
    }
    return point;
}
```

Hàm trả optional giống chiều xuôi: depth không thuộc [near,far] hoặc lens/viewport không hợp lệ thì không có kết quả. Một target ngoài viewport vẫn có thể tạo một camera point hữu hạn; điều này cần khi kéo ra ngoài, còn projection sau đó sẽ báo outside.

### Bước 2 — Nối chuột logic với inverse

Trong main.cpp, **trước while (running)** và sau các biến scene/dirty, thêm state của thao tác kéo và hàm hủy. owner lưu mouse đang điều khiển, grabOffset giữ chỗ nắm, dragDepth giữ độ sâu. Lambda dùng [&] để đọc/sửa những biến đó, vì thế chúng phải được khai báo trước lambda:

```cpp title="src/main.cpp — state và thao tác hủy nằm ngoài vòng lặp"
bool dragging = false;
SDL_MouseID owner{};
lab::Vec2 grabOffset{};
double dragDepth = 0.0;
const auto cancelDrag = [&]() {
    dragging = false;
    SDL_CaptureMouse(false);
};
```

Đặt updateDrag ngay sau cancelDrag, vẫn trước while (running):

```cpp title="src/main.cpp — giữ offset và depth trong suốt thao tác"
const auto updateDrag = [&](lab::Vec2 mouse) {
    const lab::Vec2 target{mouse.x - grabOffset.x, mouse.y - grabOffset.y};
    const auto cameraPoint = lab::screenToCameraAtDepth(target, dragDepth, scene.lens, lab::viewportFor(scene));
    if (cameraPoint) {
        const lab::Vec3 world = lab::cameraToWorld(*cameraPoint, scene.camera);
        scene.point = {std::clamp(world.x, -6.0, 6.0), std::clamp(world.y, -6.0, 6.0), std::clamp(world.z, -2.0, 20.0)};
        dirty = true;
    }
};
```

Lấy target từ chuột đã trừ offset, đảo sang camera point, đổi về world rồi giới hạn vùng thao tác. Ở biên world [-6,6], tâm có thể không theo kịp chuột vì giới hạn chủ ý này; depth không bị thay đổi.

### Bước 3 — Capture và kết thúc đúng owner

```cpp title="src/main.cpp — hit-test và sở hữu một SDL_MouseID"
const bool mouseEvent = event.type == SDL_EVENT_MOUSE_BUTTON_DOWN || event.type == SDL_EVENT_MOUSE_MOTION || event.type == SDL_EVENT_MOUSE_BUTTON_UP;
if (mouseEvent && !SDL_ConvertEventToRenderCoordinates(renderer, &event)) {
    failed = true;
    running = false;
    break;
}
if (event.type == SDL_EVENT_MOUSE_BUTTON_DOWN && event.button.button == SDL_BUTTON_LEFT && !dragging) {
    const auto viewport = lab::viewportFor(scene);
    const auto projected = lab::projectPerspective(scene.point, scene.camera, scene.lens, lab::viewportFor(scene));
    const bool insideViewport = event.button.x >= viewport.x && event.button.x <= viewport.x + viewport.width && event.button.y >= viewport.y && event.button.y <= viewport.y + viewport.height;
    if (insideViewport && projected.status == lab::ProjectionStatus::Visible && projected.screen && std::hypot(event.button.x - projected.screen->x, event.button.y - projected.screen->y) <= 24.0) {
        owner = event.button.which;
        grabOffset = {event.button.x - projected.screen->x, event.button.y - projected.screen->y};
        dragDepth = projected.cameraPoint.z;
        dragging = true;
        scene.paused = true;
        dirty = true;
        if (!SDL_CaptureMouse(true)) {
            cancelDrag();
        }
    }
}
if (event.type == SDL_EVENT_MOUSE_MOTION && dragging && event.motion.which == owner) {
    if ((event.motion.state & SDL_BUTTON_LMASK) == 0) {
        cancelDrag();
    } else {
        updateDrag({event.motion.x, event.motion.y});
    }
}
if (event.type == SDL_EVENT_MOUSE_BUTTON_UP && event.button.button == SDL_BUTTON_LEFT && dragging && event.button.which == owner) {
    updateDrag({event.button.x, event.button.y});
    cancelDrag();
}
```

Đặt toàn bộ khối mouse event trên **bên trong vòng SDL_PollEvent**, sau nhánh xử lý bàn phím. Không đặt nó sau vòng poll: lúc đó event có thể không còn là sự kiện bạn muốn xử lý.

SDL_ConvertEventToRenderCoordinates đổi vị trí từ window/HiDPI/letterbox về bảng logic đúng một lần. Capture chỉ bật khi nhấn gần một marker visible; pointer down không sửa point. Motion chỉ nhận đúng mouse owner và còn giữ nút trái. Up nhận mẫu cuối trước cancelDrag. Nếu capture thất bại, thao tác bị hủy.

Canvas dùng cùng inverse, nhưng pointerId và setPointerCapture của trình duyệt thay SDL_MouseID. Đừng nhân DPR vào mouse thêm lần nữa: DPR chỉ dành cho backing buffer.

## Ghép các phần lại

Còn ba chỗ phải gọi cancelDrag để state cũ không sống quá lâu:

- Trong nhánh SDL_EVENT_KEY_DOWN, đặt cancelDrag() ngay sau dirty=true, trước khi xử lý Space/N, reset, camera hay lens.
- Trong nhánh đọc phím liên tục ở bài 1, gọi cancelDrag() trong if (length > 0 ...), **trước movePoint**.
- Trước SDL_DestroyTexture ở cuối main, gọi cancelDrag() để nhả capture trước khi hủy window.

Thay nhánh lifecycle cũ bằng nhánh dưới; focus/resize không được để chuột tiếp tục điều khiển theo cameraDepth cũ:

```cpp title="src/main.cpp — hủy kéo và pause khi môi trường thay đổi"
if (event.type == SDL_EVENT_WINDOW_RESIZED || event.type == SDL_EVENT_WINDOW_PIXEL_SIZE_CHANGED || event.type == SDL_EVENT_WINDOW_FOCUS_LOST || event.type == SDL_EVENT_WINDOW_HIDDEN || event.type == SDL_EVENT_WINDOW_MINIMIZED) {
    scene.paused = true;
    dirty = true;
    cancelDrag();
}
```

Ngay khi bắt đầu kéo, paused=true và dirty=true: HUD phải hiện PAUSED kể cả khi bạn mới nhấn giữ mà chưa di chuyển chuột. Trong Canvas, phím N/nút tiến một bước cũng nhả capture trước khi đặt point theo quỹ đạo; mẫu thả của thao tác cũ không được ghi đè bước mới.

Build lại project_11_starter, pause, nhấn lệch tâm marker khoảng 10 pixel rồi kéo. Marker phải giữ khoảng lệch đó và giữ nguyên cameraDepth. Nhấn lên nền không làm điểm nhảy.

Blur/hidden/resize, reset, preset và input thay camera/lens đều hủy capture. Nếu không hủy, thao tác cũ có thể tiếp tục dùng cameraDepth hoặc offset đã lỗi thời. Trong Canvas, đổi bất kỳ slider/preset nào cũng kết thúc drag; phím Tab vẫn ra khỏi Canvas bình thường.

## Thử làm sai để hiểu đúng

1. Bỏ grabOffset và gán targetCenter=mouse ngay từ down. Marker sẽ giật khi nhấn lệch tâm. Khôi phục offset và kiểm down không đổi point.

2. Chỉ xử lý motion, không nhận vị trí của up. Di chuyển rồi thả nhanh: điểm cuối có thể bị bỏ. Khôi phục mẫu cuối của owner trước release capture.

3. Bỏ cameraToWorld ở cuối inverse khi camera không ở origin. Điểm lệch đúng bằng camera.position. Dùng Camera.X=1 để thấy lỗi rõ, rồi khôi phục phép cộng.

## Tự kiểm tra kết quả

- Down gần marker giữ nguyên point, down trên nền/nút phải không kéo.
- Pointer khác không thay thao tác đang giữ; up/cancel/lost capture dọn đúng owner.
- Depth không đổi khi kéo, world XY thay đúng hướng.
- Up nhận mẫu cuối; rời viewport không làm rớt thao tác; mất nút trái hủy.
- Capture không còn sau blur/resize/reset/preset/chỉnh lens/camera.
- Inverse tại pixel (485,282.5), depth4, FOV90°, viewport (10,20,800,600) trả (1,0.5,4).
