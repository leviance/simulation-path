# Chặn điểm không thể nhìn thấy

## Vấn đề cần giải quyết

Phép chia x/z đúng về hình học nhưng không thể áp dụng cho mọi dữ liệu. Point ở sau camera không nên lộn ngược lên màn hình; point sát Z=0 không được tạo tọa độ cực lớn. Ta sẽ đọc lại guard đã dùng từ bài 3 và biến nó thành hành vi có thể kiểm tra.

## Hiểu ý tưởng trước khi viết code

Trình tự xử lý quan trọng hơn tên các nhánh:

- invalid: dữ liệu nonfinite, FOV/viewport không hợp lệ hoặc near/far sai.
- behind: camera-space Z≤0.
- before-near: Z dương nhưng nhỏ hơn near.
- beyond-far: Z>far.
- outside: depth hợp lệ, nhưng ít nhất một NDC nằm ngoài [-1,1].
- visible: depth hợp lệ và cả hai NDC nằm trong khung.

Near và far ở đây đều nhận điểm đúng trên plane. Guard kiểm Z **trước** cameraToNdc. Chặn sau phép chia vẫn để Inf/NaN lọt vào những bước trung gian.

Với behind/near/far/invalid, screen và NDC chưa tồn tại. Với outside, phép chiếu vẫn cho số hữu hạn, nhưng renderer không vẽ marker. Không clamp số outside về cạnh viewport rồi gọi nó là visible.

### Bước 1 — Trả kết quả có trạng thái, không trả pixel giả

```cpp title="include/lab.hpp — status và hai giá trị tùy chọn"
struct ProjectionResult {
    ProjectionStatus status = ProjectionStatus::Invalid;
    Vec3 cameraPoint{};
    std::optional<Vec2> ndc;
    std::optional<Vec2> screen;
};
```

`std::optional<Vec2>` cho phép phân biệt không có ảnh với ảnh ở (0,0). Muốn dùng screen, caller phải kiểm có giá trị; status còn quyết định có nên vẽ hay không.

### Bước 2 — Đặt guard trước công thức chiếu

```cpp title="include/lab.hpp — kiểm depth rồi mới gọi cameraToNdc"
inline ProjectionResult projectPerspective(Vec3 worldPoint, const Camera3D& camera, const PerspectiveLens& lens, const Viewport& viewport) {
    ProjectionResult result;
    if (!finite(worldPoint) || !finite(camera.position) || !validLens(lens, viewport)) {
        return result;
    }
    const Vec3 cameraPoint = worldToCamera(worldPoint, camera);
    result.cameraPoint = cameraPoint;
    if (!finite(cameraPoint)) {
        return result;
    }
    // Các guard đã có từ bài 3 để checkpoint không chia cho 0.
    // Bài 5 giải thích và đưa từng trạng thái ra giao diện.
    if (cameraPoint.z <= 0.0) {
        result.status = ProjectionStatus::BehindCamera;
        return result;
    }
    if (cameraPoint.z < lens.nearPlane) {
        result.status = ProjectionStatus::BeforeNearPlane;
        return result;
    }
    if (cameraPoint.z > lens.farPlane) {
        result.status = ProjectionStatus::BeyondFarPlane;
        return result;
    }
    const double aspectRatio = viewport.width / viewport.height;
    const Vec2 ndc = cameraToNdc(cameraPoint, lens, aspectRatio);
    const Vec2 screen = ndcToScreen(ndc, viewport);
    if (!std::isfinite(ndc.x) || !std::isfinite(ndc.y) || !std::isfinite(screen.x) || !std::isfinite(screen.y)) {
        return result;
    }
    result.ndc = ndc;
    result.screen = screen;
    result.status = ProjectionStatus::OutsideFrustum;
    if (isInsideNdc(ndc)) {
        result.status = ProjectionStatus::Visible;
    }
    return result;
}
```

Đọc lần lượt các return sớm. Kết quả mặc định là Invalid; chỉ nhánh đã xác nhận mới đổi status. Sau khi chia vẫn kiểm finite lần nữa để lỗi overflow không thành tọa độ raster.

```cpp title="include/lab.hpp — hai biên góc nhìn trong NDC"
inline bool isInsideNdc(Vec2 ndc) {
    return std::abs(ndc.x) <= 1.0 && std::abs(ndc.y) <= 1.0;
}
```

### Bước 3 — Cắt đoạn lưới thay vì xóa cả đoạn

Một point bị loại có thể bỏ luôn. Nhưng một đoạn cắt qua near plane vẫn có phần nhìn thấy được. Ta tìm giao điểm bằng t=a/(a−b), với a/b là signed distance theo depth:

```cpp title="include/lab.hpp — near/far clipping trước perspective divide"
inline bool clipDepth(Vec3& start, Vec3& end, const PerspectiveLens& lens) {
    if (!finite(start) || !finite(end)) {
        return false;
    }
    for (const auto& plane : {Vec2{lens.nearPlane, 1.0}, Vec2{lens.farPlane, -1.0}}) {
        const double a = (start.z - plane.x) * plane.y;
        const double b = (end.z - plane.x) * plane.y;
        if (a < 0.0 && b < 0.0) {
            return false;
        }
        if (a < 0.0 || b < 0.0) {
            const double t = a / (a - b);
            Vec3 hit{start.x + t * (end.x - start.x), start.y + t * (end.y - start.y), plane.x};
            if (a < 0.0) {
                start = hit;
            } else {
                end = hit;
            }
        }
    }
    return true;
}
```

Cả hai endpoint ngoài cùng phía thì bỏ. Nếu chỉ một endpoint ngoài, thay nó bằng giao điểm và gán Z đúng bằng plane; cách gán này tránh sai số rất nhỏ làm guard sau đó loại nhầm giao điểm. Sau khi chiếu, clipScreen lại cắt theo bốn cạnh viewport trước khi làm tròn sang int.

## Ghép các phần lại

Build checkpoint 5 rồi thử F1–F6: mặc định visible, xa gấp đôi vẫn visible, trước near, sau camera, vượt far và ngoài góc nhìn. Canvas có cùng sáu preset. Các phím [ và ] chỉnh near trong [0.1,2]; ; và dấu nháy đơn chỉnh far trong [8,24].

Chỉ điểm sáng bị loại; nền vẫn vẽ phần còn trong frustum. Đừng xóa cả scene khi point không visible. HUD hiển thị nguyên status, NDC/pixel “undefined” nếu chưa chia; nhờ đó ta phân biệt “marker không xuất hiện” với “renderer bị hỏng”.

## Thử làm sai để hiểu đúng

1. Cho point Z chạy lần lượt −1,0,10⁻¹²,near,far,far+0.01. Dự đoán từng status trước khi nhìn HUD; near/far chính xác phải visible nếu X=Y=0.

2. Với near=0.5, đoạn từ (−1,0,0) đến (1,0,2) phải bị cắt tại (−0.5,0,0.5). Tự tính t=0.25, rồi đối chiếu clipDepth; đây là expected độc lập.

3. Thay outside bằng clamp NDC về [-1,1]. Marker sẽ bám cạnh dù point không nhìn thấy. Khôi phục phân loại, không dùng clamp để giấu lỗi projection.

## Tự kiểm tra kết quả

- Các guard chạy trước phép chia; không cast số không hữu hạn sang int.
- Before-near khác behind, beyond-far khác outside.
- Near/far đúng trên plane được nhận; invalid lens trả Invalid.
- Đoạn cắt plane còn phần nhìn thấy được; screen clipping giữ rasterizer hữu hạn.
- Marker ngoài khung không bị đẩy giả lên cạnh.
