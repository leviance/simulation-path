# Chọn FOV và hình dạng viewport

## Vấn đề cần giải quyết

Perspective đã hoạt động nhưng độ mở của camera vẫn cố định. Ta cần một thông số dễ hiểu hơn một hằng số pixel: field of view. Đồng thời, viewport có thể rộng hoặc vuông; chỉ kéo dãn ảnh cuối sẽ làm sai hình học.

## Hiểu ý tưởng trước khi viết code

Vertical FOV là góc mở từ cạnh dưới tới cạnh trên. Xét nửa khung nhìn ở mặt phẳng depth 1: nửa chiều cao world bằng tan(vFOV/2). Muốn cạnh trên về NDC.y=1, ta nhân với nghịch đảo:

$$
f=\frac{1}{\tan(vFOV/2)},\quad a=\frac{w}{h},\quad
n_x=\frac{x f}{z a},\quad n_y=\frac{y f}{z}.
$$

FOV phải đổi từ độ sang radian trước khi gọi tan. FOV rộng làm f nhỏ, nên điểm tiến gần tâm hơn. FOV là góc, f không có đơn vị; focalPixels=h×f/2 mới là độ dài tính theo pixel.

Screen có origin riêng (vₓ,vᵧ), không mặc định (0,0):

$$
s_x=v_x+\frac{n_x+1}{2}w,\qquad
s_y=v_y+\frac{1-n_y}{2}h.
$$

Đây là tọa độ liên tục trên viewport. NDC.x=+1 nằm trên **cạnh phải** vₓ+w, không phải chỉ số pixel cuối. Pixel raster nằm ở miền nửa kín [vₓ,vₓ+w); hàm vẽ chịu trách nhiệm clip, không sửa công thức bằng width−1 rồi làm lệch tỉ lệ.

### Bước 1 — Đổi góc mở thành focal scale

```cpp title="include/lab.hpp — lens có FOV và hai plane"
struct PerspectiveLens {
    double verticalFovRadians = kPi / 3.0;
    double nearPlane = 0.5;
    double farPlane = 16.0;
};
```

```cpp title="include/lab.hpp — dùng tangent của nửa góc"
inline double verticalFocalScale(const PerspectiveLens& lens) {
    return 1.0 / std::tan(lens.verticalFovRadians * 0.5);
}
```

Mặc định 60°=π/3. validLens đã chặn góc không nằm trong (0,π); UI giới hạn hẹp hơn [25°,110°] để thí nghiệm dễ quan sát.

### Bước 2 — Chuẩn hóa đúng chiều FOV

```cpp title="include/lab.hpp — camera point tới NDC"
inline Vec2 cameraToNdc(Vec3 cameraPoint, const PerspectiveLens& lens, double aspectRatio) {
    const Vec2 divided = perspectiveDivide(cameraPoint);
    const double focalScale = verticalFocalScale(lens);
    return {divided.x * focalScale / aspectRatio, divided.y * focalScale};
}
```

Tại sao chỉ X chia aspect? FOV đang đo chiều dọc. Khi w tăng mà h giữ nguyên, camera thấy rộng hơn theo X; cùng một world displacement chiếm phần nhỏ hơn bề ngang. Nhân aspect vào Y sẽ thay đổi cả góc dọc, trái với định nghĩa.

### Bước 3 — Đổi NDC sang viewport có origin

```cpp title="include/lab.hpp — đặt ảnh trong bảng logic"
inline Vec2 ndcToScreen(Vec2 ndc, const Viewport& viewport) {
    return {viewport.x + (ndc.x + 1.0) * 0.5 * viewport.width, viewport.y + (1.0 - ndc.y) * 0.5 * viewport.height};
}
```

```cpp title="include/scene.hpp — ba viewport thật, không scale ảnh méo"
inline Viewport viewportFor(const Scene& scene) {
    if (scene.aspect == 1) {
        return {150.0, 100.0, 800.0, 600.0};
    }
    if (scene.aspect == 2) {
        return {250.0, 100.0, 600.0, 600.0};
    }
    return {};
}
```

## Ghép các phần lại

Window resize vẫn **letterbox bảng logic 1100×800**, không đổi aspect ngầm và không làm méo ảnh. Muốn kiểm aspect của phép chiếu, dùng V/Aspect. Hai việc này khác nhau; việc kéo window rộng mà scene không đổi FOV là chủ ý của bản triển khai này.

## Thử làm sai để hiểu đúng

1. Giữ point, đổi FOV 60°→90°. Displacement giảm, không phải tăng; f giảm từ √3 xuống 1. Nếu ngược, hãy kiểm tan và radian.

2. Bỏ phép chia aspect ở ndc.x, chọn viewport 16:9. Cùng world length trên X/Y sẽ không còn cùng scale pixel. Khôi phục chia aspect.

3. Dùng viewport (10,20,800,600), FOV90°, point (1,0.5,4): tính focalPixels=300, screen=(485,282.5). Không dùng inverse làm expected cho test này.

## Tự kiểm tra kết quả

- FOV60° có focal scale √3; FOV90° có focal scale 1.
- Point trên trục nhìn nằm đúng tâm viewport, kể cả viewport có origin khác 0.
- X/Y cùng dùng focalPixels theo chiều cao, không bị kéo méo ở các aspect.
- NDC +1 được hiểu là cạnh liên tục, marker không ghi sang panel.
- Resize và đổi Aspect được mô tả/hoạt động đúng hai nhiệm vụ riêng.

## Bài tập mở rộng
