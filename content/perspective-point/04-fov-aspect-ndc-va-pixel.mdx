# Từ FOV và aspect ratio tới NDC và pixel

## Vấn đề cần giải quyết

Perspective divide đã tạo cảm giác gần–xa, nhưng `0.38*min(width,height)` chỉ là một focal length chọn bằng mắt. Ta chưa thể trả lời lens rộng bao nhiêu, biên nhìn nằm ở đâu hoặc resize cửa sổ ngang có làm hình méo không.

Bài này chuẩn hóa kết quả thành NDC. Từ đó, mọi viewport—960×640 hay 1280×720—đều dùng chung biên `[-1,+1]`, còn bước đổi sang pixel chỉ nằm ở cuối pipeline.

## Hiểu ý tưởng trước khi viết code

Lens được mô tả bằng vertical field of view. Xét nửa trên của frustum, cạnh đối diện có chiều cao chuẩn hóa 1:

$$
\tan\left(\frac{FOV_y}{2}\right)=\frac{1}{f}
$$

Do đó:

$$
f=\frac{1}{\tan(FOV_y/2)}
$$

Sau perspective divide:

$$
x_{ndc}=\frac{x\,f}{z\,aspect},\qquad y_{ndc}=\frac{y\,f}{z}
$$

với `aspect = width/height`. Vì FOV được chốt theo chiều dọc, viewport rộng hơn phải chứa thêm không gian theo chiều ngang.

## Viết code từng bước

### Bước 1 — Lưu FOV bằng radian

`std::tan` nhận radian, nên lens khởi tạo 60° bằng phép đổi rõ ràng:

```cpp title="include/lab.hpp — lens và vertical FOV"
struct PerspectiveLens {
    double verticalFovRadians{60.0 * kPi / 180.0};
};

inline double verticalFocalScale(const PerspectiveLens& lens) {
    return 1.0 / std::tan(lens.verticalFovRadians * 0.5);
}
```

Focal scale là số không thứ nguyên. Nó không phụ thuộc số pixel và vì thế có thể test độc lập.

### Bước 2 — Đưa camera point vào NDC

Aspect ratio chỉ xuất hiện ở X vì lens đang dùng vertical FOV:

```cpp title="include/lab.hpp — camera space sang NDC"
inline Vec2 cameraToNdc(Vec3 cameraPoint, const PerspectiveLens& lens, double aspectRatio) {
    const double focalScale = verticalFocalScale(lens);
    return {
        cameraPoint.x * focalScale / (cameraPoint.z * aspectRatio),
        cameraPoint.y * focalScale / cameraPoint.z,
    };
}
```

Ở bước này, `(-1,+1)` đã mang nghĩa biên viewport chứ chưa phải góc pixel cụ thể.

### Bước 3 — Đổi NDC sang quy ước pixel của SDL

NDC có tâm `(0,0)` và Y tăng lên; framebuffer có gốc trên-trái và Y tăng xuống:

```cpp title="include/lab.hpp — NDC sang screen space"
inline Vec2 ndcToScreen(Vec2 ndc, int width, int height) {
    return {
        (ndc.x + 1.0) * 0.5 * width,
        (1.0 - ndc.y) * 0.5 * height,
    };
}
```

Ta viết luôn chiều ngược để bài cuối kéo marker và đo round-trip error:

```cpp title="include/lab.hpp — screen space trở lại NDC"
inline Vec2 screenToNdc(Vec2 screen, int width, int height) {
    return {
        screen.x * 2.0 / width - 1.0,
        1.0 - screen.y * 2.0 / height,
    };
}
```

### Bước 4 — Ghép đúng thứ tự trong render loop

Width và height hiện tại tạo aspect ratio sau mỗi resize:

```cpp title="src/main.cpp — NDC rồi mới tới pixel"
const lab::Vec2 ndc = lab::cameraToNdc(cameraPoint, lens, double(width) / double(height));
screen = lab::ndcToScreen(ndc, width, height);
```

Phím ngoặc vuông thay FOV trong khoảng an toàn:

```cpp title="src/main.cpp — giảm vertical FOV"
if (event.key.key == SDLK_LEFTBRACKET) {
    lens.verticalFovRadians = std::max(
        25.0 * lab::kPi / 180.0,
        lens.verticalFovRadians - 2.0 * lab::kPi / 180.0
    );
}
```

## Ghép các phần lại

Build `project_11_checkpoint_4`. Point trên trục nhìn phải ở `(width/2,height/2)`. Với point lệch tâm, `[` thu hẹp FOV và đẩy marker xa tâm; `]` mở rộng FOV và kéo nó gần tâm.

Resize từ 960×640 sang một cửa sổ rộng. Vertical framing giữ nguyên vì `ndc.y` không dùng aspect; horizontal framing mở rộng vì `ndc.x` chia cho aspect mới. Đây là hành vi đúng của vertical FOV, không phải lỗi scale.

## Thử làm sai để hiểu đúng

1. Bỏ aspect ratio. Cùng một scene sẽ bị kéo ngang khi viewport thay tỉ lệ.
2. Nhân X với aspect thay vì chia. Viewport càng rộng thì point càng dễ văng khỏi màn hình.
3. Tính screen Y bằng `(ndc.y+1)/2*height`. NDC Y=+1 sẽ xuống đáy thay vì lên đỉnh.

## Tự kiểm tra kết quả

- NDC `(0,0)` đổi thành tâm viewport.
- NDC `(-1,+1)` đổi thành pixel `(0,0)`.
- NDC `(+1,-1)` đổi thành `(width,height)` ở biên ngoài cùng.
- FOV lớn hơn cho focal scale nhỏ hơn và marker gần tâm hơn.
- Resize thay aspect ratio nhưng không làm sai vertical framing.

## Bài tập mở rộng

Vẽ bốn marker có NDC cố định tại các góc `±0.8`. Sau đó resize cửa sổ và kiểm tra chúng luôn giữ vị trí tương đối 10% cách biên, bất kể số pixel.

Ta vẫn đang ép point ở trước camera bằng một giới hạn tạm. Bài sau sẽ bỏ giới hạn đó, cho phép dữ liệu sai xuất hiện và phân loại an toàn trước khi vẽ.
