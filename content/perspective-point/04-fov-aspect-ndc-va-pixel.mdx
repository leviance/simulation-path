# Chọn FOV và hình dạng viewport

## Vấn đề cần giải quyết

Bạn đã thấy điểm tiến về tâm khi đi xa. Nhưng vì sao camera ở bài trước lại dùng focal scale bằng 1? Nếu muốn thấy một vùng rộng hơn mà không di chuyển camera, ta cần thay đổi góc nhìn, gọi là field of view (FOV).

Bài này nối góc FOV với công thức chiếu và xử lý cả trường hợp viewport rộng hoặc vuông. Ta phải tính lại phép chiếu cho hình dạng mới, không kéo dãn ảnh đã vẽ.

## Hiểu ý tưởng trước khi viết code

Vertical FOV là góc mở từ cạnh dưới tới cạnh trên. Xét nửa khung nhìn ở mặt phẳng depth 1: nửa chiều cao world bằng tan(vFOV/2). Muốn cạnh trên về NDC.y=1, ta nhân với nghịch đảo:

$$
f=\frac{1}{\tan(vFOV/2)},\quad a=\frac{w}{h},\quad
n_x=\frac{x f}{z a},\quad n_y=\frac{y f}{z}.
$$

FOV phải đổi từ độ sang radian trước khi gọi tan. FOV rộng làm f nhỏ, nên điểm tiến gần tâm hơn. FOV là góc, f không có đơn vị; focalPixels=h×f/2 mới là độ dài tính theo pixel.

NDC (Normalized Device Coordinates) là bước trung gian trước pixel: tâm ảnh là (0,0), hai cạnh trái/phải có X=−1/+1, hai cạnh dưới/trên có Y=−1/+1. Nhờ vậy, cùng một phép chiếu có thể dùng với nhiều kích thước viewport.

Vì FOV được đo theo chiều dọc, chiều ngang phải tính thêm aspect a=w/h. Có thể kiểm ngay: độ lệch X theo pixel bằng (x/z)×f/a×w/2, rút gọn thành (x/z)×f×h/2. Hệ số pixel trên cả hai trục vì thế bằng nhau. Nếu quên chia X cho aspect, viewport rộng sẽ kéo cảnh theo chiều ngang.

Screen có origin riêng (vₓ,vᵧ), không mặc định (0,0):

$$
s_x=v_x+\frac{n_x+1}{2}w,\qquad
s_y=v_y+\frac{1-n_y}{2}h.
$$

Đây là tọa độ liên tục trên viewport. NDC.x=+1 nằm trên **cạnh phải** vₓ+w, không phải chỉ số pixel cuối. Pixel raster nằm ở miền nửa kín [vₓ,vₓ+w); hàm vẽ chịu trách nhiệm clip, không sửa công thức bằng width−1 rồi làm lệch tỉ lệ.

### Bước 1 — Đổi góc mở thành focal scale

PerspectiveLens đã có từ Starter; giữ nguyên struct này. Thêm verticalFocalScale, cameraToNdc và ndcToScreen theo thứ tự dưới, không định nghĩa lại PerspectiveLens:

```cpp title="include/lab.hpp — lens có FOV và hai plane"
struct PerspectiveLens {
    double verticalFovRadians = kPi / 3.0;
    double nearPlane = 0.5;
    double farPlane = 16.0;
};
```

```cpp title="include/lab.hpp — dùng tangent của nửa góc"
inline double verticalFocalScale(const PerspectiveLens& lens) {
    return 1.0 / std::tan(lens.verticalFovRadians * 0.5);
}
```

Mặc định 60°=π/3. validLens đã chặn góc không nằm trong (0,π); UI giới hạn hẹp hơn [25°,110°] để thí nghiệm dễ quan sát.

### Bước 2 — Chuẩn hóa đúng chiều FOV

```cpp title="include/lab.hpp — camera point tới NDC"
inline Vec2 cameraToNdc(Vec3 cameraPoint, const PerspectiveLens& lens, double aspectRatio) {
    const Vec2 divided = perspectiveDivide(cameraPoint);
    const double focalScale = verticalFocalScale(lens);
    return {divided.x * focalScale / aspectRatio, divided.y * focalScale};
}
```

Tại sao chỉ X chia aspect? FOV đang đo chiều dọc. Khi w tăng mà h giữ nguyên, camera thấy rộng hơn theo X; cùng một world displacement chiếm phần nhỏ hơn bề ngang. Nhân aspect vào Y sẽ thay đổi cả góc dọc, trái với định nghĩa.

### Bước 3 — Đổi NDC sang viewport có origin

```cpp title="include/lab.hpp — đặt ảnh trong bảng logic"
inline Vec2 ndcToScreen(Vec2 ndc, const Viewport& viewport) {
    return {viewport.x + (ndc.x + 1.0) * 0.5 * viewport.width, viewport.y + (1.0 - ndc.y) * 0.5 * viewport.height};
}
```

viewportFor đã có trong Starter. Giữ nguyên hàm này; đọc lại để thấy phím V sẽ chọn vùng nào, không thêm một định nghĩa trùng tên:

```cpp title="include/scene.hpp — ba viewport thật, không scale ảnh méo"
inline Viewport viewportFor(const Scene& scene) {
    if (scene.aspect == 1) {
        return {150.0, 100.0, 800.0, 600.0};
    }
    if (scene.aspect == 2) {
        return {250.0, 100.0, 600.0, 600.0};
    }
    return {};
}
```

## Ghép các phần lại

Trong projectPerspective, thay ba dòng tính aspect/ndc/screen tạm ở bài 3 bằng:

```cpp title="include/lab.hpp — thay nhánh focal scale tạm"
const double aspectRatio = viewport.width / viewport.height;
const Vec2 ndc = cameraToNdc(cameraPoint, lens, aspectRatio);
const Vec2 screen = ndcToScreen(ndc, viewport);
```

Giữ nguyên các guard và cách gán ProjectionResult. Tiếp theo, thay renderScene bằng hàm dưới để **bán kính marker cũng dùng focal mới**, không chỉ tâm marker:

```cpp title="include/view.hpp — cùng focal cho tâm và bán kính"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear(kBackground);
    const Viewport viewport = viewportFor(scene);
    [[maybe_unused]] const Vec2 center{viewport.x + viewport.width * 0.5, viewport.y + viewport.height * 0.5};
    const auto projected = projectPerspective(scene.point, scene.camera, scene.lens, viewport);
    if (projected.status == ProjectionStatus::Visible && projected.screen) {
        // Bán kính world 0.12, vị trí cũng được chiếu perspective; không giả depth bằng size.
        double focalPixels = viewport.height * 0.5;
        focalPixels *= verticalFocalScale(scene.lens);
        const int radius = static_cast<int>(std::clamp(std::lround(0.12 * focalPixels / projected.cameraPoint.z), 3L, 30L));
        drawPointMarker(image, *projected.screen, radius, viewport, scene.debug);
    }
}
```

Trong nhánh SDL_EVENT_KEY_DOWN, sau các phím camera, thêm:

```cpp title="src/main.cpp — chỉnh FOV và chuyển viewport"
if (event.key.key == SDLK_EQUALS) {
    scene.paused = true;
    scene.lens.verticalFovRadians = std::max(25.0 * lab::kPi / 180.0, scene.lens.verticalFovRadians - lab::kPi / 180.0);
}
if (event.key.key == SDLK_MINUS) {
    scene.paused = true;
    scene.lens.verticalFovRadians = std::min(110.0 * lab::kPi / 180.0, scene.lens.verticalFovRadians + lab::kPi / 180.0);
}
if (event.key.key == SDLK_V && !event.key.repeat) {
    scene.paused = true;
    scene.aspect = (scene.aspect + 1) % 3;
}
```

Trong presentFramebuffer, sau khối in NDC/screen và trước SDL_RenderPresent, thêm dòng lens:

```cpp title="include/presentation.hpp — đọc đúng FOV và aspect đang dùng"
std::snprintf(value, sizeof(value), "vFOV %.1f deg | near %.2f far %.2f | aspect %.4f | resize letterboxes, V changes viewport", scene.lens.verticalFovRadians * 180.0 / kPi, scene.lens.nearPlane, scene.lens.farPlane, viewportFor(scene).width / viewportFor(scene).height);
if (!text(renderer, 16, 746, value)) {
    return false;
}
```

Build lại project_11_starter. Khi sửa nhiều nơi, hãy kiểm từng đường đi: phím sửa scene.lens → projectPerspective đổi NDC → renderScene vẽ ảnh mới → HUD hiện đúng lens.

Trong SDL, +/− thay FOV, V chuyển 16:9 → 4:3 → 1:1. Trong Canvas dùng Vertical FOV và Aspect. Cả ba viewport có cùng tâm (550,400), nhưng kích thước khác nhau. Khi thử số, nhớ focalPixels còn phụ thuộc chiều cao.

Window resize vẫn **letterbox bảng logic 1100×800**, không đổi aspect ngầm và không làm méo ảnh. Muốn kiểm aspect của phép chiếu, dùng V/Aspect. Hai việc này khác nhau; việc kéo window rộng mà scene không đổi FOV là chủ ý của bản triển khai này.

## Thử làm sai để hiểu đúng

1. Giữ point, đổi FOV 60°→90°. Displacement giảm, không phải tăng; f giảm từ √3 xuống 1. Nếu ngược, hãy kiểm tan và radian.

2. Bỏ phép chia aspect ở ndc.x, chọn viewport 16:9. Cùng world length trên X/Y sẽ không còn cùng scale pixel. Khôi phục chia aspect.

3. Dùng viewport (10,20,800,600), FOV90°, point (1,0.5,4): tính focalPixels=300, screen=(485,282.5). Không dùng inverse làm expected cho test này.

## Tự kiểm tra kết quả

- FOV60° có focal scale √3; FOV90° có focal scale 1.
- Point trên trục nhìn nằm đúng tâm viewport, kể cả viewport có origin khác 0.
- X/Y cùng dùng focalPixels theo chiều cao, không bị kéo méo ở các aspect.
- NDC +1 được hiểu là cạnh liên tục, marker không ghi sang panel.
- Resize và đổi Aspect được mô tả/hoạt động đúng hai nhiệm vụ riêng.

## Bài tập mở rộng

Thêm chế độ nhập focalPixels thay vì FOV. Suy lại vFOV=2×atan(h/(2×focalPixels)) và kiểm rằng hai chế độ cho cùng pixel.
