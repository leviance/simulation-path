# Đặt camera vào không gian

## Vấn đề cần giải quyết

Hiện point được vẽ như thể người quan sát luôn ở gốc. Nếu dời camera sang phải thì điểm cần xuất hiện ở bên nào? Ta sẽ thêm camera nhưng chưa cho nó xoay, để trả lời bằng một phép trừ dễ kiểm tra.

## Hiểu ý tưởng trước khi viết code

Trong bài này camera nhìn theo +Z, X sang phải và Y lên trên. Đây là quy ước camera riêng của P11; không chép nguyên orbit basis của P10. Camera chỉ tịnh tiến, nên một điểm có hai cách mô tả:

$$
P_c=P_w-C,\qquad P_w=P_c+C.
$$

Ví dụ world point (3,2,8), camera (1,-1,2) cho camera point (2,3,6). Điểm trong world không hề chạy. Chỉ gốc mà ta dùng để đo nó thay đổi.

Đừng gọi camera-space Z là khoảng cách Euclidean. Nó là độ sâu theo trục nhìn; point lệch sang bên có distance lớn hơn Z.

### Bước 1 — Giữ camera thành dữ liệu riêng

Camera3D và trường Scene::camera đã có từ Starter. Đây là khai báo cần đọc lại, không phải một struct mới cần dán thêm:

```cpp title="include/lab.hpp — camera chưa có góc quay"
struct Camera3D {
    Vec3 position{};
};
```

Scene có point và camera độc lập. Khi đổi camera.position, tuyệt đối không cộng/trừ trực tiếp vào scene.point; làm vậy mỗi frame sẽ khiến điểm trôi không ngừng.

### Bước 2 — Đổi gốc đúng một lần

```cpp title="include/lab.hpp — từ world sang camera"
inline Vec3 worldToCamera(Vec3 worldPoint, const Camera3D& camera) {
    return {worldPoint.x - camera.position.x, worldPoint.y - camera.position.y, worldPoint.z - camera.position.z};
}
```

Từng thành phần trừ cùng thành phần vị trí camera. Camera đi +X làm cameraPoint.x giảm; dấu trừ này diễn tả cảnh trượt ngược chiều người quan sát.

### Bước 3 — Viết phép đổi ngược và dùng camera point

```cpp title="include/lab.hpp — từ camera trở lại world"
inline Vec3 cameraToWorld(Vec3 point, const Camera3D& camera) {
    return {point.x + camera.position.x, point.y + camera.position.y, point.z + camera.position.z};
}
```

Thêm worldToCamera và cameraToWorld vào namespace lab của lab.hpp. Sau đó thay renderScene bằng hàm dưới: đặt worldToCamera ngay trước previewPoint, không sau khi đã nhân pixel:

```cpp title="include/view.hpp — preview lấy tọa độ nhìn từ camera"
inline void renderScene(Framebuffer& image, const Scene& scene) {
    image.clear(kBackground);
    const Viewport viewport = viewportFor(scene);
    [[maybe_unused]] const Vec2 center{viewport.x + viewport.width * 0.5, viewport.y + viewport.height * 0.5};
    // Bản xem trước song song chỉ để kiểm framebuffer/input ở hai bài đầu.
    for (int offset = -280; offset <= 280; offset += 70) {
        drawLine(image, 550 + offset, 120, 550 + offset, 680, kGrid);
        drawLine(image, 30, 400 + offset, 1070, 400 + offset, kGrid);
    }
    Vec3 point = scene.point;
    point = worldToCamera(scene.point, scene.camera);
    const Vec2 preview = previewPoint(point);
    drawPointMarker(image, {center.x + preview.x, center.y - preview.y}, 10, viewport, true);
}
```

### Bước 4 — Nối phím điều khiển camera

Trong nhánh SDL_EVENT_KEY_DOWN của main.cpp, đặt sáu nhánh dưới **sau phần R/F1–F6** đã có. Đầu nhánh key-down đã đặt dirty=true, vì thế camera đổi là ảnh được vẽ lại. Mỗi lần chỉnh camera cũng đặt paused=true, để quỹ đạo không chạy tiếp khi bạn đang đo tọa độ.

```cpp title="src/main.cpp — camera đổi riêng, world point giữ nguyên"
if (event.key.key == SDLK_J) {
    scene.paused = true;
    scene.camera.position.x = std::max(-2.0, scene.camera.position.x - 0.1);
}
if (event.key.key == SDLK_L) {
    scene.paused = true;
    scene.camera.position.x = std::min(2.0, scene.camera.position.x + 0.1);
}
if (event.key.key == SDLK_I) {
    scene.paused = true;
    scene.camera.position.y = std::min(2.0, scene.camera.position.y + 0.1);
}
if (event.key.key == SDLK_K) {
    scene.paused = true;
    scene.camera.position.y = std::max(-2.0, scene.camera.position.y - 0.1);
}
if (event.key.key == SDLK_U) {
    scene.paused = true;
    scene.camera.position.z = std::max(-2.0, scene.camera.position.z - 0.1);
}
if (event.key.key == SDLK_O) {
    scene.paused = true;
    scene.camera.position.z = std::min(2.0, scene.camera.position.z + 0.1);
}
```

## Ghép các phần lại

Build lại project_11_starter, dùng J/L để dời camera X, I/K cho Y, U/O cho Z. Mỗi nấc là 0.1 world, camera bị giới hạn [-2,2] ở từng trục. WASD/QE vẫn điều khiển point. Trong Canvas có ba slider Camera.X/Y/Z tương ứng.

Giữ point cố định và tăng Camera.X: marker đi trái. Tăng Camera.Z hiện chỉ đổi số đo Z vì preview vẫn chưa perspective. Đừng thêm phép chia cho đến bài kế tiếp; ở đây ta đang kiểm riêng việc đổi gốc.

## Thử làm sai để hiểu đúng

1. Thử cộng camera.position thay vì trừ. Camera đi phải làm cảnh đi phải cùng chiều. Dùng ví dụ số trong bài để thấy sai trước khi nhìn ảnh, rồi khôi phục.

2. Cho worldPoint và camera cùng tăng 1 theo X. Camera point và ảnh preview phải không đổi. Nếu thay đổi, rất có thể một nơi đã đổi gốc hai lần.

## Tự kiểm tra kết quả

- Ví dụ (3,2,8) − (1,-1,2) đúng (2,3,6).
- cameraToWorld(worldToCamera(P,C),C) trả P trong sai số.
- Camera đi phải làm cảnh đi trái, world point không đổi.
- WASD/QE và camera controls không sửa nhầm dữ liệu của nhau.
