# Lưu cả khối, không chỉ tính một ảnh

## Vấn đề cần giải quyết

Bài trước gọi phantom cho từng pixel. Cách đó cho ta một ảnh đẹp, nhưng chưa phải trình xem dữ liệu volume: không có bộ dữ liệu nào được lưu lại để tra cứu.

Bây giờ ta lấy mẫu phantom **một lần**, lưu scalar tại tâm các voxel, rồi dựng ảnh chỉ bằng những mẫu đã lưu. Bạn sẽ nhìn gần giống ảnh cũ, nhưng đường đi của dữ liệu đã khác hẳn. Đó là lý do cần kiểm cả bộ nhớ, không chỉ nhìn hình rồi kết luận đúng.

Hết bài này có volume 64³ thật, nút chọn dataset và nút đổi sang 128³. Bản C++ cuối mặc định 128³. Dành khoảng 20 phút đọc, 40 phút viết và 20 phút kiểm địa chỉ, tâm mẫu, mép khối.

## Hiểu ý tưởng trước khi viết code

Voxel là một ô nhỏ trong không gian. Ta lưu **một scalar ở tâm ô**, không lưu tám góc của mỗi ô. Với count=(nx,ny,nz), x thay nhanh nhất:

$$
index(x,y,z)=x+n_x(y+n_yz).
$$

Tăng x một đơn vị đi sang phần tử kế tiếp. Tăng y đi qua nx phần tử. Tăng z đi qua cả một lớp nx·ny phần tử.

Dùng ví dụ nhỏ 3×2×4 và đặt giá trị voxel bằng 100z+10y+x. Voxel (2,1,3) phải có giá trị 312 ở địa chỉ 23. Số 312 là **giá trị**, còn 23 là **địa chỉ**; đừng dùng chúng thay nhau.

Khối thử của ứng dụng luôn rộng 3.2×3.84×4.8 world units. Khi tăng từ 64³ lên 128³, spacing giảm một nửa; cảnh không to gấp đôi:

| Độ phân giải | Số scalar thật | Bộ nhớ double/Float64 | Spacing x/y/z |
| --- | ---: | ---: | --- |
| 64³ | 262.144 | 2 MiB | 0.05 / 0.06 / 0.075 |
| 128³ | 2.097.152 | 16 MiB | 0.025 / 0.03 / 0.0375 |

Đây chỉ là mảng scalar; texture và buffer ảnh có bộ nhớ riêng. Các voxel không lập phương trong world, dù số mẫu mỗi trục bằng nhau.

Mép thấp của box là lower=−count·spacing/2. Tâm voxel i ở lower+(i+0.5)·spacing. Đổi ngược lại phải trừ 0.5:

$$
g=\frac{world-lower}{spacing}-0.5.
$$

## Viết code từng bước

### 1. Phân biệt count và spacing ngay trong kiểu dữ liệu

{/* snippet include/model.hpp#grid */}
```cpp title="include/model.hpp — cùng vùng world ở hai độ phân giải"
// Count tells us how many samples exist; spacing tells us how far apart they are.
struct Grid {
    std::array<int, 3> count{128, 128, 128};
    Point spacing{3.2 / 128, 3.84 / 128, 4.8 / 128};
};

inline Grid makeGrid(int side) {
    if (side != 64 && side != 128) {
        throw std::invalid_argument("Viewer resolution must be 64 or 128");
    }
    return {{side, side, side}, {3.2 / side, 3.84 / side, 4.8 / side}};
}
```

makeGrid chỉ nhận 64 hoặc 128 cho giao diện. Volume bên dưới vẫn cho phép fixture nhỏ không lập phương để viết test. Không dùng độ phân giải nhỏ của fixture làm sản phẩm cuối.

Các hàm chuyển đổi dùng chung một quy ước tâm mẫu:

{/* snippet include/model.hpp#coordinates */}
```cpp title="include/model.hpp — từ index tới tâm voxel rồi đổi ngược"
// The origin of world space is the centre of the box, not voxel (0,0,0).
inline double lower(const Grid& grid, int axis) {
    return -grid.count[axis] * grid.spacing[axis] / 2;
}

inline double worldCoordinate(const Grid& grid, int axis, double index) {
    return lower(grid, axis) + (index + 0.5) * grid.spacing[axis];
}

inline double gridCoordinate(const Grid& grid, int axis, double world) {
    return (world - lower(grid, axis)) / grid.spacing[axis] - 0.5;
}
```

Ở khối chẵn, world 0 nằm giữa hai tâm. Cursor khởi đầu tại world 0, vì ta muốn mặt cắt giữa khối; không ép nó thành index nguyên rồi âm thầm lệch nửa voxel.

### 2. Cấp phát và kiểm giới hạn trước khi nhân kích thước

{/* snippet include/volume.hpp#storage */}
```cpp title="include/volume.hpp — scalar storage và địa chỉ x nhanh nhất"
struct Volume {
    Grid grid;
    std::vector<double> values;

    explicit Volume(Grid shape = {})
        : grid(shape) {
        std::size_t total = 1;
        for (int axis = 0; axis < 3; ++axis) {
            if (grid.count[axis] < 1 || grid.count[axis] > 128 || !std::isfinite(grid.spacing[axis]) || grid.spacing[axis] <= 0) {
                throw std::invalid_argument("Count 1..128; spacing finite and positive");
            }
            total *= static_cast<std::size_t>(grid.count[axis]);
        }
        values.resize(total);
    }

    std::size_t index(int x, int y, int z) const {
        if (x < 0 || x >= grid.count[0] || y < 0 || y >= grid.count[1] || z < 0 || z >= grid.count[2]) {
            throw std::out_of_range("Voxel index outside volume");
        }
        return static_cast<std::size_t>(x) + static_cast<std::size_t>(grid.count[0]) * (y + static_cast<std::size_t>(grid.count[1]) * z);
    }

    double voxel(int x, int y, int z) const {
        return values.at(index(x, y, z));
    }
};
```

Giới hạn mỗi trục 1..128 và spacing dương hữu hạn được kiểm trước allocation. Tổng tối đa là 128³, không nhân kích thước tùy ý rồi mới phát hiện thiếu bộ nhớ. values là vector double liên tục, không phải một vector ảnh 2D độc lập cho từng hướng xem.

index từ chối tọa độ ngoài mảng. Sau đó voxel dùng at để đọc giá trị. Những kiểm tra này hữu ích cả khi học lẫn khi test; không đánh đổi chúng lấy một phép truy cập khó chẩn đoán.

### 3. Đi qua tất cả tâm và lưu scalar

{/* snippet include/volume.hpp#fill */}
```cpp title="include/volume.hpp — tạo bộ dữ liệu một lần"
inline void fillVolume(Volume& volume, Preset preset) {
    const Grid& grid = volume.grid;
    const double denominator = grid.count[0] - 1 + 2 * (grid.count[1] - 1) + 4 * (grid.count[2] - 1);
    for (int z = 0; z < grid.count[2]; ++z) {
        for (int y = 0; y < grid.count[1]; ++y) {
            for (int x = 0; x < grid.count[0]; ++x) {
                const Point point{worldCoordinate(grid, 0, x), worldCoordinate(grid, 1, y), worldCoordinate(grid, 2, z)};
                double value = 0;
                if (preset == Preset::Ramp) {
                    value = 0;
                    if (denominator > 0) {
                        value = (x + 2 * y + 4 * z) / denominator;
                    }
                } else {
                    value = fieldValue(point, preset);
                }
                volume.values[volume.index(x, y, z)] = value;
            }
        }
    }
}
```

Vòng x ở trong cùng đi liên tục theo memory layout. Sphere/Gaussian/Layers/Phantom dùng vị trí world; riêng Ramp mã hóa hướng theo index để kiểm tra dữ liệu. Khi chỉ kéo mặt cắt, **không gọi lại fillVolume**. State::rebuild chỉ chạy khi dataset hoặc độ phân giải đổi.

Các preset đơn giản có đáp án dễ đoán: Sphere bán kính 1 có giá trị 1 bên trong, 0 bên ngoài; Gaussian bằng 1 ở gốc; Layers có ba mức 0.15, 0.5, 0.85 theo z. Mẫu Material (Phantom trong enum) có lõi xoắn và ống rỗng để khảo sát hình dạng, không dùng làm đáp án duy nhất cho mọi phép kiểm.

Giá trị 1 ở gốc nói về hàm Gaussian liên tục. Khối có số mẫu chẵn không lưu đúng một mẫu tại gốc; nearest tại world 0 chọn một tâm lân cận nên có thể nhỏ hơn 1. Hãy phân biệt giá trị analytic với giá trị đọc từ mảng đã lấy mẫu.

### 4. Thay lời gọi phantom bằng nearest

{/* snippet include/volume.hpp#nearest */}
```cpp title="include/volume.hpp — lấy mẫu voxel gần nhất"
inline std::optional<double> sampleNearest(const Volume& volume, Point point) {
    if (!inside(volume.grid, point)) {
        return std::nullopt;
    }
    std::array<int, 3> index{};
    for (int axis = 0; axis < 3; ++axis) {
        const double coordinate = gridCoordinate(volume.grid, axis, point[axis]);
        index[axis] = std::clamp(static_cast<int>(std::floor(coordinate + 0.5)), 0, volume.grid.count[axis] - 1);
    }
    return volume.voxel(index[0], index[1], index[2]);
}
```

inside kiểm point nằm trong physical box trước. floor(g+0.5) chọn tâm gần nhất; đúng điểm giữa thì chọn phía index lớn hơn. Clamp chỉ xử lý nửa voxel từ tâm ngoài cùng tới mép box. Điểm nằm ngoài box phải trả nullopt, không bị kéo ngược vào dữ liệu hợp lệ.

Trong sampleImage của checkpoint 02, value đọc từ sampleNearest. Không còn gọi phantom ở vòng pixel. Không nên giữ đường tắt analytic để ảnh trông đúng khi storage hoặc index của ta đang sai.

## Ghép các phần lại

Build target project_53_checkpoint_2 với --parallel 1. Phím P lần lượt đổi năm dataset; N đổi 64³/128³; PageUp/Down dời lát nguyên; R đưa view/cursor/tương phản về mặc định nhưng **giữ dataset và độ phân giải đã chọn**. Bạn cũng có thể bấm nút hoặc kéo slider trong cửa sổ.

Chọn Ramp. Nhìn inspector voxel gần nhất, địa chỉ và scalar. Tự tính lại địa chỉ từ ba index. Sau đó đổi N: hình chiếm cùng vùng world, số mẫu và bộ nhớ đổi đúng hệ số tám.

## Thử làm sai để hiểu đúng

Trong bản sao, thay stride z từ nx·ny thành nx. Một số hàng sẽ đọc nhầm lớp; Sphere có thể méo còn Ramp lộ lỗi rõ hơn. Dùng fixture 3×2×4 với giá trị biết trước để tìm địa chỉ sai, rồi khôi phục công thức.

Bỏ −0.5 khi đổi world sang grid. Một tâm voxel không còn đọc đúng mẫu của chính nó. Đây là lỗi quy ước tọa độ, không phải lỗi làm tròn có thể vá bằng epsilon.

## Tự kiểm tra kết quả

64³ có 262.144 phần tử, 128³ có 2.097.152 phần tử. Physical extent không đổi. Tâm voxel đọc đúng giá trị, sáu mặt ngoài trả miss, spacing NaN/0/âm bị từ chối. Kéo slider không tái tạo volume. Reset không tự đổi dataset về Phantom.
