# Đọc cùng khối dữ liệu theo ba hướng cắt

## Vấn đề cần giải quyết

Lát XY chỉ cho thấy một phần cấu trúc. Ta muốn xem cùng khối theo XZ và YZ mà không sao chép hay transpose cả volume.

Một lỗi hay gặp là đổi trục cắt nhưng quên đổi trục đứng trên ảnh. Một lỗi khác là vẽ mỗi voxel thành ô vuông dù spacing khác nhau, khiến khối bị méo. Bài này xử lý cả bảng trục và tỉ lệ hiển thị.

## Hiểu ý tưởng trước khi viết code

Mỗi view có horizontal, vertical và cut axis. Quy ước của project:

| View | Ngang sang phải | Đứng lên trên | Giữ cố định |
| --- | --- | --- | --- |
| XY — axial | x | y | z |
| XZ — coronal | x | z | y |
| YZ — sagittal | y | z | x |

Các tên axial/coronal/sagittal giúp nhớ mặt phẳng, nhưng đây là quy ước toán của một phantom. Ta chưa có hướng giải phẫu bệnh nhân, không dùng radiology display convention hoặc dữ liệu DICOM.

Một pixel (u,v) đổi thành world theo hai extent; trục cut giữ giá trị cursor. V tăng xuống nên dùng 1−v trên trục đứng. Physical extent là count*spacing, không phải count đơn thuần.

Chọn lần lượt XY/XZ/YZ, dùng ramp để đoán chiều sáng tăng. So aspect khác nhau giữa ba ảnh. Đổi view giữ nguyên world cursor; chỉ thành phần được lấy làm cut thay đổi.

## Viết code từng bước

### Bước 1 — Đặt bảng trục vào một chỗ

axesFor trong include/model.hpp mở thêm hai trường hợp:

```cpp title="include/model.hpp — trục của XZ và YZ"
if (view == 1) {
    return {0, 2, 1};
}
if (view == 2) {
    return {1, 2, 0};
}
```

View 0 trả mặc định {0,1,2}. Cùng bảng này dùng cho lấy mẫu, fit image, input và crosshair sau này. Nếu mỗi phần tự viết một cách tráo trục riêng, ảnh có thể đúng nhưng chuột hoặc inspector lại sai.

### Bước 2 — Dựng world point trên plane

slicePoint trong include/display.hpp không thay volume:

```cpp title="include/display.hpp — pixel centre tới plane world"
const Axes axes = axesFor(view);
Point point = cursor;
point[axes.horizontal] = lower(grid, axes.horizontal) + u * grid.count[axes.horizontal] * grid.spacing[axes.horizontal];
point[axes.vertical] = lower(grid, axes.vertical) + (1 - v) * grid.count[axes.vertical] * grid.spacing[axes.vertical];
return point;
```

Chỉ hai thành phần đổi, nên point[cut] vẫn bằng cursor[cut]. Main nhận phím 1/2/3; PageUp/Down dùng axesFor(activeView).cut để dời đúng mặt phẳng. Không lấy mouse y làm world y cho mọi view.

### Bước 3 — Fit theo kích thước world

Trong include/layout.hpp:

```cpp title="include/layout.hpp — physical aspect"
const double width = grid.count[axes.horizontal] * grid.spacing[axes.horizontal];
const double height = grid.count[axes.vertical] * grid.spacing[axes.vertical];
const double scale = std::min(panel.width / width, panel.height / height);
return {panel.x + (panel.width - width * scale) / 2, panel.y + (panel.height - height * scale) / 2, width * scale, height * scale};
```

Cùng scale cho ngang/dọc giữ hình đúng tỉ lệ. Khoảng dư là letterbox bên trong panel, khác viền letterbox của cả SDL window. Input Bài 06 phải xét fitted rectangle này, không chỉ xét toàn panel.

## Ghép các phần lại

Build project_53_checkpoint_3. View 0/1/2 đọc cùng Volume.values. Chuyển XY→XZ không làm index trong mảng tự đổi; slicePoint chỉ chọn những world point khác để sampleNearest tra lại layout x-fast.

Trong default grid, XY aspect là 3.2/3.84, XZ là 3.2/4.8, YZ là 3.84/4.8. Bảng này giúp kiểm bằng số thay vì chỉ hỏi ảnh có “trông tròn” không.

## Thử làm sai để hiểu đúng

1. Trong XZ, vẫn dùng y làm vertical. Ảnh thực chất không quét z; dùng ramp để phân biệt rồi trả lại {0,2,1}.
2. Fit theo count ngang/count dọc mà bỏ spacing. Mỗi voxel trông vuông nhưng kích thước vật lý sai; tính ba aspect trên để kiểm và hoàn tác.

## Tự kiểm tra kết quả

Ba view đúng bảng trục, đổi view không sửa volume/cursor. Pixel top có world vertical lớn hơn pixel bottom. Fitted aspect đúng count*spacing; PageUp/Down dời đúng cut axis. Không có transpose, copy volume hoặc allocation mới khi chỉ đổi view.

## Bài tập mở rộng

Thêm nhãn +x/+y/+z ở các mép ảnh theo bảng trục, không viết nhãn cố định cho mọi view. Tiếp tục với [window/level](/projects/volume-slicer/04-window-level).
