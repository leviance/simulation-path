# Nhìn thấy lát cắt đầu tiên

## Vấn đề cần giải quyết

Ở Project 52, ta tìm điểm tia chạm bề mặt. Nhưng nếu điều muốn xem nằm **bên trong** một khối thì sao? Một ảnh nhìn từ ngoài không cho ta biết vùng đậm, nhạt nằm ở độ sâu nào. Cách đơn giản nhất là tưởng tượng cắt khối thành một lát mỏng rồi nhìn thẳng vào lát ấy.

Project này xây một công cụ như vậy. Đích đến là **một khối vật liệu có thể cắt mở một góc**, đi kèm ba ảnh XY/XZ/YZ đọc từ **cùng một mảng scalar 3D**. Bạn sẽ lần theo lõi xoắn bên trong khối, chọn một điểm và xem nó trên cả ba mặt. Trước khi cấp phát hàng triệu mẫu hay dựng hình khối, ta làm cho đường đi từ một con số tới một pixel hoạt động đã. Hết bài này, ứng dụng SDL phải hiện một lát XY; chưa có volume được lưu trong bộ nhớ.

Dành khoảng 20 phút đọc ý tưởng, 30 phút viết và 10 phút đối chiếu. Nếu muốn tự thử cả project trước, hãy quay lại thử thách ở trang tổng quan. [ZIP source của Project 53](/downloads/project-53-volume-slicer.zip) chứa starter, từng checkpoint, final và tests. Giải nén rồi mở thư mục có CMakeLists.txt; không chạy lệnh từ riêng thư mục src.

## Hiểu ý tưởng trước khi viết code

Ta gán cho mỗi điểm world một số trong [0,1]. Ở đây, số đó chỉ diễn tả độ đậm của dữ liệu tự tạo: 0 tối, 1 sáng. Nó không phải phép đo mật độ vật chất, không có đơn vị HU và không mang ý nghĩa chẩn đoán.

Hàm tạo dữ liệu thử gọi là **phantom**. Mẫu ở đây là một khối bo góc, bên trong có lõi xoắn sáng và một ống rỗng tối. Khi dời z, tiết diện của lõi xoắn chạy quanh ống rỗng; bạn sẽ thấy các đốm sáng ở những vị trí khác nhau. Các bài sau còn có Sphere để kiểm đối xứng và Layers để nhìn rõ từng hướng cắt.

Giữ z = 0. Trên mặt phẳng XY ấy, mỗi pixel đổi vị trí của nó thành x/y world rồi hỏi phantom. Một trong các thành phần tạo mẫu là Gaussian, dùng để tạo vùng sáng mềm:

$$
G(p;c,r)=\exp\left(-\sum_{a=0}^{2}\left(\frac{p_a-c_a}{r_a}\right)^2\right).
$$

r trong công thức này là bán kính làm giá trị giảm còn exp(−1) theo một trục, **không phải độ lệch chuẩn σ**. Bạn chưa cần thuộc công thức; điều quan trọng lúc này là hàm nhận một Point và trả một scalar.

Khối rộng 3.2, cao 3.84, sâu 4.8 world units, đặt giữa gốc tọa độ. Pixel ở tâm (x+0.5,y+0.5), x tăng sang phải, y world tăng lên trên. Ta đổi chiều y vì hàng pixel trên màn hình lại tăng xuống dưới.

## Viết code từng bước

### 1. Chạy bộ khung, rồi xác định phần cần thêm

Starter đã có main, event loop, khung giao diện sáng/tối và cleanup. Hãy build starter trước. Cửa sổ phải mở, resize được và thoát bằng Esc. Bạn không phải tự đoán cách dựng window/renderer:

{/* snippet src/main.cpp#initialize */}
```cpp title="src/main.cpp — khởi tạo SDL và tài nguyên đầu tiên"
if (!SDL_Init(SDL_INIT_VIDEO)) {
    std::cerr << SDL_GetError() << '\n';
    return EXIT_FAILURE;

if (window == nullptr) {

}
SDL_Renderer* renderer = SDL_CreateRenderer(window, nullptr);

    std::cerr << SDL_GetError() << '\n';

```

Mỗi nhánh lỗi chỉ hủy tài nguyên đã tạo thành công. Nếu renderer chưa có thì chỉ hủy window; nếu window chưa có thì chỉ SDL_Quit. Cuối chương trình, texture được hủy trước renderer.

Phần của bài này bắt đầu ở Image trong display.hpp: một ảnh 256×256, mỗi pixel có bốn byte RGBA, lưu trên heap. Đừng đặt ba ảnh lớn trong một array trên stack rồi trông chờ mọi máy Windows đều có đủ stack.

### 2. Tạo dữ liệu của một điểm

Mở model.hpp. Hàm gaussian cộng ba khoảng cách đã chuẩn hóa. Hàm phantom đi xa hơn một chút để tạo ra khối vật liệu ta muốn khảo sát. Bộ tạo mẫu này được cung cấp sẵn: nhiệm vụ chính của bạn là lấy giá trị nó trả về, dựng ảnh và sau đó lưu giá trị vào volume. Đọc toàn hàm một lượt, rồi đối chiếu các thành phần bên dưới; chưa cần tự suy ra công thức dựng khối bo góc.

{/* snippet include/model.hpp#phantom */}
```cpp title="include/model.hpp — dữ liệu thử tại một vị trí world"
inline double gaussian(Point point, Point centre, Point radius) {
    double q = 0;
    for (int axis = 0; axis < 3; ++axis) {
        const double d = (point[axis] - centre[axis]) / radius[axis];
        q += d * d;
    }
    return std::exp(-q);
}

inline double phantom(Point point) {
    // A rounded material block containing a helical inclusion and an axial void.
    const Point q{std::abs(point[0]) - 0.98, std::abs(point[1]) - 1.12, std::abs(point[2]) - 1.5};
    const double outside = std::hypot(std::max(0.0, q[0]), std::max(0.0, q[1]), std::max(0.0, q[2]));
    const double distance = outside + std::min(0.0, std::max({q[0], q[1], q[2]})) - 0.2;
    if (distance >= 0.07) {
        return 0;
    }
    const double t = std::clamp((0.07 - distance) / 0.13, 0.0, 1.0);
    const double support = t * t * (3 - 2 * t);
    const double shell = 0.22 * std::exp(-distance * distance / 0.008);
    const double theta = (point[2] + 1.5) * 2 * std::numbers::pi / 1.1;
    const double wireX = point[0] - 0.58 * std::cos(theta);
    const double wireY = point[1] - 0.58 * std::sin(theta);
    const double wire = 0.52 * std::exp(-(wireX * wireX + wireY * wireY) / 0.018);
    const double holeX = point[0] + 0.25;
    const double holeY = point[1] + 0.12;
    const double hole = 0.4 * std::exp(-(holeX * holeX + holeY * holeY) / 0.055);
    const double marker = 0.3 * gaussian(point, {0.55, 0.58, -0.7}, {0.22, 0.25, 0.3});
    return std::clamp((0.4 + shell + wire + marker - hole) * support, 0.0, 1.0);
}
```

Đọc hàm theo thứ tự này:

- distance mô tả khoảng cách tới vỏ khối bo góc; support làm giá trị giảm về 0 gần mép, tránh cắt cụt đột ngột.
- shell làm lớp vỏ sáng hơn phần nền bên trong. Nền vật liệu có giá trị 0.4, không phải khoảng trống.
- theta tăng theo z. Tâm tiết diện lõi ở (0.58·cos(theta), 0.58·sin(theta)); vì vậy lõi chạy thành một đường xoắn thay vì một cột thẳng.
- wire cộng vùng sáng quanh tâm ấy; hole trừ vùng quanh đường thẳng x=−0.25, y=−0.12, tạo ống rỗng. marker thêm một chi tiết lệch tâm để dễ nhận ra hướng ảnh.
- Cuối cùng, clamp giữ kết quả trong [0,1]. Đây là quy ước dữ liệu thử, không phải phương trình đo một loại vật liệu cụ thể.

Point không phải index voxel. Lúc này chưa có voxel nào được cấp phát; bạn có thể gọi phantom tại một điểm bất kỳ. Nếu muốn tập trung hoàn toàn vào luồng tạo ảnh, hãy giữ nguyên hàm đã cung cấp và quay lại thay mẫu sau khi viewer chạy được.

### 3. Dựng ảnh từ các tâm pixel

sampleImage là nơi nối vòng lặp pixel với phantom. Trong checkpoint 01, value được tính trực tiếp từ hàm; từ checkpoint 02, đúng vị trí này sẽ đọc volume:

{/* snippet include/display.hpp#sample-image */}
```cpp title="include/display.hpp — mỗi pixel hỏi một điểm trên mặt phẳng"
ScalarImage scalars(Image::side * Image::side);
for (int y = 0; y < Image::side; ++y) {
    for (int x = 0; x < Image::side; ++x) {
        const double u = (x + 0.5) / Image::side;
        const double v = (y + 0.5) / Image::side;
        const Point point = slicePoint(grid, view, cursor, u, v);
        double value = 0;
        value = phantom(point);
        scalars[static_cast<std::size_t>(x + y * Image::side)] = value;
    }
}
return scalars;
```

slicePoint giữ z của cursor và tính x/y trên cả vùng world. Kết quả trả về là mảng **scalar**, chưa phải màu. colorImage sau đó clamp scalar, đổi thành R/G/B giống nhau và A=255. Việc tách hai bước này cho phép ta thêm tương phản mà không phải tính lại dữ liệu.

### 4. Đưa ảnh lên SDL texture

Tạo streaming texture RGBA32. SDL dùng nearest khi phóng ảnh; đừng bật lọc texture để che các pixel mà sau này ta muốn so sánh:

{/* snippet src/main.cpp#textures */}
```cpp title="src/main.cpp — tạo texture cho các mặt cắt"
for (auto& texture : textures) {
    texture = SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGBA32, SDL_TEXTUREACCESS_STREAMING, slices::Image::side, slices::Image::side);
    if (texture == nullptr || !SDL_SetTextureScaleMode(texture, SDL_SCALEMODE_NEAREST)) {
        failed = true;
        break;
    }
}
```

Mảng textures khởi đầu bằng nullptr. Ta chuẩn bị ba texture nhỏ, nhưng bài này chỉ lấy mẫu và vẽ view XY. Khi lỗi giữa chừng, vòng cleanup vẫn an toàn.

upload phải tôn trọng pitch do SDL trả về. pitch là số **byte mỗi hàng**, không nhất thiết bằng chiều rộng ảnh nhân bốn:

{/* snippet include/view.hpp#upload */}
```cpp title="include/view.hpp — chép đủ từng hàng vào texture"
inline bool upload(SDL_Texture* texture, const Image& image) {
    void* pixels = nullptr;
    int pitch = 0;
    if (!SDL_LockTexture(texture, nullptr, &pixels, &pitch)) {
        return false;
    }
    for (int row = 0; row < Image::side; ++row) {
        auto* destination = static_cast<std::uint8_t*>(pixels) + row * pitch;
        const auto* source = image.rgba.data() + row * Image::side * 4;
        std::memcpy(destination, source, Image::side * 4);
    }
    SDL_UnlockTexture(texture);
    return true;
}
```

Sau unlock, drawSlice gọi SDL_RenderTexture. Cuối frame, main gọi SDL_RenderPresent. SliceCache chỉ dựng lại ảnh khi đầu vào thay đổi; resize không đòi hỏi tính lại phantom.

## Ghép các phần lại

Chạy từ thư mục gốc của ZIP:

```bash title="Terminal — starter rồi checkpoint 01"
cmake -S . -B build -DBUILD_CHECKPOINTS=ON
cmake --build build --config Debug --target project_53_starter --parallel 1
cmake --build build --config Debug --target project_53_checkpoint_1 --parallel 1
```

Visual Studio đặt executable trong build/Debug. Với generator single-config, thêm -DCMAKE_BUILD_TYPE=Debug khi configure và chạy executable trong build. [Getting Started](/getting-started) giải thích cài compiler/SDL/CMake nếu máy chưa sẵn sàng.

Luồng mới là: **main tạo texture → SliceCache gọi sampleImage → colorImage → upload → drawSlice → present**. Các hàm vẽ khung và chữ đã được cung cấp để tập trung vào ảnh lát cắt; mã đầy đủ của mọi file nằm ở phần source cuối bài.

## Thử làm sai để hiểu đúng

Đổi z của cursor từ 0 sang 0.8 trong State, chạy lại rồi trả về 0. Vùng sáng thay đổi vì ta nhìn một mặt phẳng khác, không phải vì camera quay quanh khối.

Tiếp theo, bỏ 0.5 ở tọa độ pixel trong một bản sao. Bạn vừa chuyển từ tâm pixel sang góc pixel. Quan sát chi tiết nhỏ bị lệch. Chỉ phân tích phép tính pitch trên giấy; **không thử ghi sai stride vào buffer thật**, vì đó có thể là ghi vượt bộ nhớ chứ không phải một hiệu ứng hình ảnh vô hại.
