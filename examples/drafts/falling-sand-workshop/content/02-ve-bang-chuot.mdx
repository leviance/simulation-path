# Biến chuột thành bút vẽ vật liệu

## Vấn đề cần giải quyết

Bệ và cát ở bài trước đều được đặt sẵn trong code. Bây giờ ta muốn tự vẽ một bức tường, đặt cát ở chỗ khác hoặc tẩy một khoảng trống. Vật liệu vẫn đứng yên, để khi một nét vẽ sai vị trí ta biết lỗi nằm ở input, không phải ở luật rơi.

Chạy bản của bạn sau Bài 1, rồi mở `include/input.hpp`. Bộ khung đã gọi `sand::pollInput` từ vòng lặp main. Ta mở rộng hàm đó; **không tạo thêm một vòng `SDL_PollEvent` ở nơi khác** vì hai vòng sẽ tranh nhau lấy event.

## Hiểu ý tưởng trước khi viết code

Event chuột trả tọa độ trong window. Lưới lại dùng tọa độ ô. Khi resize hoặc có letterbox, hai hệ này không còn trùng nhau. Ta đổi window → logical coordinates bằng SDL, kiểm điểm có ở trong lưới hay không, rồi mới lấy phần nguyên.

Một brush tròn chỉ cần xét các offset nguyên quanh tâm. Offset được tô khi:

$$dx^2+dy^2\le r^2.$$

`r=0` tô đúng một ô. `r=1` có năm offset trước khi cắt biên: tâm và bốn ô kề. Không dùng khoảng cách pixel màn hình để quyết định brush có bao nhiêu ô.

Chọn lưới trống, bán kính 0 rồi vẽ nhanh ngang qua Canvas. Nếu chỉ tô tại từng mouse event, các điểm cách xa nhau sẽ để lại lỗ. Ta cần nối các sample, nhưng không nối xuyên qua phần ngoài lưới.

## Viết code từng bước

### 1. Đổi tọa độ ngay tại chỗ đọc input

Thêm `mouseCell` vào `include/view.hpp`. Nó không sửa lưới, chỉ trả tọa độ hợp lệ qua `x`, `y`:

```cpp title="include/view.hpp — window coordinates tới ô lưới"
inline bool mouseCell(SDL_Renderer* renderer, const Grid& grid, float windowX, float windowY, int& x, int& y, bool showcase = false) {
    float logicalX = 0;
    float logicalY = 0;
    if (!SDL_RenderCoordinatesFromWindow(renderer, windowX, windowY, &logicalX, &logicalY)) {
        return false;
    }
    return logicalCell(grid, logicalX, logicalY, x, y, showcase);
}
```

`logicalCell` có sẵn trong `include/layout.hpp`. Ở mốc này, `sceneRect` là toàn lưới từ `(0,0)` đến `(96,64)`; hàm kiểm biên rồi dùng `floor`. Tham số `showcase` để nguyên `false`: nó dành cho chế độ xem ở các bài sau. Không tự chia tọa độ chuột cho 10; kích thước một ô trên màn hình không cố định.

Nếu điểm nằm trong letterbox, hàm trả `false`. Clamp một điểm ngoài lưới vào hàng/cột sát biên sẽ khiến người dùng tô vào lưới dù chuột đang ở ngoài.

### 2. Tô một đĩa trong dữ liệu, chưa gọi renderer

Thêm `paintDisk` trong `include/grid.hpp`:

```cpp title="include/grid.hpp — brush làm việc với Cell"
inline void paintDisk(Grid& grid, int centerX, int centerY, int radius, Cell material) {
    if (!grid.contains(centerX, centerY)) {
        return;
    }
    radius = std::clamp(radius, 0, 24);
    for (int dy = -radius; dy <= radius; ++dy) {
        for (int dx = -radius; dx <= radius; ++dx) {
            if (dx * dx + dy * dy <= radius * radius) {
                grid.set(centerX + dx, centerY + dy, material);
            }
        }
    }
}
```

Giới hạn 24 ô giữ một lần tô hữu hạn. `Grid::set` cắt phần brush vượt biên, nên bạn không cần làm méo brush để nhét nó vào khay. Tẩy cũng dùng cùng hàm: vật liệu cần ghi là `Cell::Empty`.

### 3. Nối hai sample bằng những tâm ô liên tiếp

Ngay sau `paintDisk`, thêm `paintStroke`. Số bước bằng độ dài lớn hơn của hai thành phần, để không nhảy quá một ô theo mỗi trục:

```cpp title="include/grid.hpp — nội suy nét vẽ"
inline void paintStroke(Grid& grid, int x0, int y0, int x1, int y1, int radius, Cell material) {
    if (!grid.contains(x0, y0) || !grid.contains(x1, y1)) {
        return;
    }
    const int dx = x1 - x0;
    const int dy = y1 - y0;
    const int steps = std::max(std::abs(dx), std::abs(dy));
    if (steps == 0) {
        paintDisk(grid, x0, y0, radius, material);
        return;
    }
    for (int i = 0; i <= steps; ++i) {
        const double t = static_cast<double>(i) / steps;
        const int x = static_cast<int>(std::lround(x0 + t * dx));
        const int y = static_cast<int>(std::lround(y0 + t * dy));
        paintDisk(grid, x, y, radius, material);
    }
}
```

Nhánh `steps==0` vừa xử lý click tại chỗ, vừa tránh chia cho 0. Tô lại một ô đã có cùng vật liệu không tạo thêm một hạt khác ở đó: lưới vẫn chỉ có một giá trị mỗi ô.

### 4. Giữ trạng thái của nét vẽ qua các event

`Workshop` trong `include/workshop.hpp` đã có các trường input. `drawing` cho biết nút chuột còn giữ; `previousValid` cho biết có được nối từ sample trước không. Bạn thêm `stamp` để hai loại event dùng cùng một đường xử lý:

```cpp title="include/workshop.hpp — chọn tô một điểm hay nối một đoạn"
inline void stamp(Grid& grid, Workshop& state, int x, int y, bool join) {
    Cell material = state.material;
    if (state.erasing) {
        material = Cell::Empty;
    }
    if (join && state.previousValid) {
        paintStroke(grid, state.previousX, state.previousY, x, y, state.radius, material);
    } else {
        paintDisk(grid, x, y, state.radius, material);
    }
    state.cursorX = x;
    state.cursorY = y;
    state.previousX = x;
    state.previousY = y;
    state.previousValid = true;
    state.dirty = true;
}
```

`dirty` báo rằng hình của lưới đã cũ; nó sẽ hữu ích khi dùng texture. Trong Bài 2 renderer vẫn đọc trực tiếp các ô, nên cờ này chưa quyết định cách vẽ.

## Ghép các phần lại

Trong `pollInput`, xử lý button down bằng cách kết thúc nét cũ, tìm ô rồi bắt đầu nét mới. Phần sau nằm trong nhánh `SDL_EVENT_MOUSE_BUTTON_DOWN`, sau khi loại các nút khác ngoài trái/phải:

```cpp title="include/input.hpp — bắt đầu một nét tại ô hợp lệ"
int x = 0;
int y = 0;
if (mouseCell(renderer, grid, event.button.x, event.button.y, x, y, state.showcase)) {
    state.drawing = true;
    state.erasing = event.button.button == SDL_BUTTON_RIGHT;
    stamp(grid, state, x, y, false);
}
```

Mouse motion dùng `event.motion.x/y`, gọi `stamp(..., true)` nếu đang vẽ. Khi motion ở ngoài lưới, đặt `previousValid=false`; lần vào lại chỉ tô tại điểm mới, không nối đường chéo qua khay. Button up, mất focus, resize hoặc rời window gọi `endStroke` để không giữ một nét vẽ bị mắc kẹt. Các nhánh này đều nằm trong `pollInput`, không nằm trong renderer.

Trong `commands.hpp`, `Action::Sand`, `Wall`, `Erase` đổi `state.material`; hai action radius giới hạn 0–24. `keyInput` ánh xạ `1/2/4`, `[`/`]` tới các action đó. `R` đặt lại, `K` xóa. Chưa bật lựa chọn nước: ta sẽ viết hành vi cho nó ở Bài 5.

Build `project_46_checkpoint_2` để đối chiếu đầy đủ các nhánh event. Bản tự viết phải cho tô/tẩy nhưng tất cả vật liệu vẫn đứng yên.

## Thử làm sai để hiểu đúng

1. Chỉ dùng `paintDisk` cho mouse motion. Với bán kính 0, kéo nhanh để thấy các sample rời; đưa nội suy trở lại.
2. Không xóa `previousValid` khi ra ngoài. Kéo ra khỏi một mép rồi vào ở vị trí khác: xuất hiện một đoạn nối không phải thao tác người dùng muốn.
3. Tạm clamp điểm trong letterbox vào ô biên. Click ngoài hình sẽ vẽ vào khay. Khôi phục cách trả `false`.

## Tự kiểm tra kết quả

Brush bán kính 1 tại góc `(0,0)` tô ba ô trong lưới. Một đoạn ngang radius 0 từ cột 0 tới cột 7 phải có tám ô, kể cả khi vẽ ngược. Tẩy trả chúng về Empty. Resize giữ nguyên dữ liệu, mất focus không để nút vẽ mắc kẹt. Không có tick nào chạy chỉ vì vừa vẽ một nét.
